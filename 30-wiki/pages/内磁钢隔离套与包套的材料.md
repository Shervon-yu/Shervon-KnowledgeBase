# 内磁钢隔离套与包套的材料

## 导环（`#L14602`）

内、外导环材料一般采用**碳钢、球墨铸铁或不锈钢**。

## 金属隔离套（`#L14608-#L14614`）

选材三条硬要求：

1. **非铁磁性、高电阻**——否则器壁内产生电涡流损失（磁损），发热并使转动力矩下降；
2. **较高机械性能与良好韧性**——便于减薄壁厚、缩小气隙、提高力矩；
3. **良好耐腐蚀性**。

常用材料：$0\mathrm{Cr}18\mathrm{Ni}9$、$0\mathrm{Cr}18\mathrm{Ni}12\mathrm{Mo}2\mathrm{Ti}$、**316L**、Hastelloy C、Inconel、Monel、工业纯钛；其中**前三种使用最广**。

关键数据：

| 项目 | 数值 |
|:---|:---|
| 涡流损失占正常总传动功率 | **15%~25%**（随材料而异） |
| 隔离套厚度 | 一般 **≥1.2 mm**，有的达 **2.3 mm**；0.5~1 mm 的薄套耐压能力与安全系数都低 |
| 低压设备内磁钢与隔离套间隙 | **1~2 mm** |

## 非金属隔离套（`#L14616-#L14622`）

塑料与陶瓷两类：

| 材料 | 耐温极限 | 说明 |
|:---|:---:|:---|
| 聚偏二氟乙烯 PVDF | 120 ℃ | 耐腐蚀 |
| 增强聚丙烯 | 100 ℃ | 耐腐蚀 |
| 氧化锆 $ZrO_2$ 等陶瓷 | — | 耐高温、耐强腐蚀，与磁钢间不产生热量 |

塑料耐压性普遍较差；有厂商用复合结构：内层 **20% 碳纤维增强氟塑料** + 外层 **Hastelloy C 保护套**提高承压。为确保安全可设**双层隔离套**，两层间装监测器，内层破裂时报警或停机。

总原则：非金属套可**消除涡流损失**，但强度低、太厚又会增大内、外磁环间隙、降低效率——最终按工艺条件与使用情况选材与结构。

## 材料温度极限参考（表11-11，`#L14626-#L14633`）

| 元件 | 材料 | 温度极限/℃ |
|:---|:---|:---:|
| 永磁铁 | 钕铁硼 | 121 |
| 永磁铁 | 钐钴 | 302 |
| 密封套（非金属） | 合成材料 | 121 |
| 密封套（金属） | Hastelloy C | 538 |
| 滑动轴承 | 碳化硅 | 538 |
| 胶黏剂 | 各种环氧树脂 | 121 |
| 永磁铁片包套（非金属） | 合成材料 | 121 |
| 永磁铁片包套（金属） | 金属 | 538 |

## 选用判据

1. 温度决定磁钢：钕铁硼只到 121 ℃，钐钴到 302 ℃；
2. 压力高、要薄壁 → 金属套（但吃 15%~25% 涡流损失）;
3. 要零涡流、腐蚀强、温度 ≤100~120 ℃ → 塑料套；更高温强腐蚀 → 陶瓷；
4. 高风险场合用双层套 + 泄漏监测；
5. 环氧胶黏剂同样是 121 ℃ 的短板——内外磁钢黏结结构在高温下先失效（原文 HMD 的顾虑，见 [[磁力传动搅拌设备的工作原理与结构]]）。

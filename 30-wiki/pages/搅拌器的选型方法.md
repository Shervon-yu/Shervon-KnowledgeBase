# 搅拌器的选型方法

## 四条考虑

选型尚无完善客观尺度，一般从**搅拌目的、物料黏度、容器容积大小、经济性**四方面考虑；同时要求功耗低、操作费用省、制造维护检修方便（`#L5058`）。

## 一、按搅拌目的选型（表5-8）

| 搅拌目的 | 挡板条件 | 推荐型式 | 流态 |
|:---|:---|:---|:---|
| 互溶液体混合及反应 | 无挡板 | 三叶折叶涡轮（$\theta=24^\circ$）、六叶折叶开启涡轮（$45^\circ$）、桨式、圆盘涡轮 | 湍流（低黏） |
| 同上 | 有导流筒 | 三叶折叶涡轮（24°）、六叶折叶开启涡轮（45°）、推进式 | 湍流 |
| 同上 | 有/无导流筒 | 桨式、螺杆式、框式、螺带式、锚式 | 层流（高黏） |
| 固-液相分散及溶解/反应 | 有/无挡板 | 桨式、六叶折叶开启涡轮（45°） | 湍流 |
| 固-液（同上） | 有导流筒 | 三叶折叶涡轮（24°）、六叶折叶开启涡轮（45°）、推进式 | 湍流 |
| 固-液（同上） | 有/无导流筒 | 螺带式、螺杆式、锚式 | 层流 |
| 液-液分散（互溶） | 有挡板 | 二叶折叶涡轮（24°）、六叶折叶开启涡轮（45°）、桨式、圆盘涡轮、推进式 | 湍流 |
| 液-液分散（不互溶） | 有挡板 | 圆盘涡轮、六叶折叶开启涡轮（45°） | 湍流 |
| 不互溶液-液 | 有反射物 | 三叶折叶涡轮（24°） | 湍流 |
| 不互溶液-液 | 有导流筒 | 三叶折叶涡轮（24°）、六叶折叶开启涡轮（45°）、推进式 | 湍流 |
| 不互溶液-液 | 有/无导流筒 | 螺带式、螺杆式、锚式 | 层流 |
| 气-液分散及传质/反应 | 有挡板 | 圆盘涡轮、闭式涡轮 | 湍流 |
| 气-液（同上） | 有反射物 | 三叶折叶涡轮（24°，$D/d\ge1.5$） | 湍流 |
| 气-液（同上） | 有导流筒 | 三叶折叶涡轮（24°）、六叶折叶开启涡轮（45°）、推进式 | 湍流 |
| 气-液（同上） | 有导流筒 | 螺杆式 | 层流（高黏） |
| 气-液（同上） | 无导流筒 | 锚式、螺带式 | 层流 |

## 二、按介质黏度选型（表5-9）

低黏介质可用小直径高转速搅拌器带动周围流体循环至远处；高黏介质必须**直接用桨叶推动**（`#L5094`）。

| 类别 | 覆盖范围 |
|:---|:---|
| 传统搅拌器 | 推进式、齿片式、桨式/涡轮式/三叶后掠式在低黏区；螺带与螺杆式在中高黏；INTERMIG、MIG、锚式、框式覆盖宽黏度带（至 $10^4$ Pa·s 量级） |
| 新型搅拌器 | 新轴向流叶轮、泛能式/最大叶片式/叶片组合式、超级叶片式/EKA-TO 同轴、前进式(AR)、锥螺带(VCR)、扭格子式、复动式、多臂行星式、均质器 |

（`#L5096-#L5119`）

补充判断：锚式/框式覆盖很宽，但**较高黏度时混合效果比螺带式差得多**；低黏区切应力不够、轴向循环差，且 $d/D$ 大导致回转部分体积大，只在要求不高时用；但**传热为主的场合锚式仍很适用**（`#L5119`）。

## 三、按型式与适用条件选型（表5-10）

| 型式 | 釜容积/m³ | 转速/r·min⁻¹ | 最高黏度/Pa·s |
|:---|:---|:---|:---|
| 涡轮式 | 1~100 | 10~300 | 50 |
| 桨式 | 1~200 | 10~300 | 50 |
| 推进式 | 1~1000 | 100~500 | 2 |
| 折叶开启涡轮式 | 1~1000 | 10~300 | 50 |
| 布鲁马金式 | 1~100 | 10~300 | 50 |
| 锚式 | 1~100 | 1~100 | 100 |
| 螺杆式 | 1~50 | 0.5~50 | 100 |
| 螺带式 | 1~50 | 0.5~50 | 100 |

（`#L5125-#L5137`）表中还逐项标注各型是否胜任对流循环、湍流扩散、剪切流与 12 类搅拌目的。

结论性判断（`#L5123`）：低黏混合推进式循环强、功耗小，可用于很大容积；涡轮式适用范围广、各种操作都适用，但**流体黏度不超过 50 Pa·s**；桨式小容积混合广用、大容积循环不足；高黏混合以锚式、螺杆式、螺带式更合适。

## 判断

三张表是**互相校验**的关系：表5-8 给"目的→型式"，表5-9 给"黏度→型式"，表5-10 给"型式→容积/转速/黏度上限"。三者交集才是可行方案；若两表结论冲突（如低黏混合既推推进式又推涡轮式），按工艺的控制因素（循环 vs 剪切）裁决。

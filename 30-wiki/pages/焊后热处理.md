## 一、热处理分类与方式（8.1，`#L16284-#L16294`）

四类：**恢复性能热处理、改善性能热处理、焊后热处理、其他热处理**。
三种方式：**炉内整体、分段炉内、局部**。条件许可时优先炉内整体，且宜避免现场热处理。

- 分段热处理：重复加热长度 $\ge1500$ mm，相邻部分保温隔热，温度梯度不得损害消应力效果、变形与性能；
- 局部热处理：仅限 B、C、D、E 类接头、球形封头与圆筒连接接头、缺陷返修部位；加热带、均温带、隔热带按 GB/T 30583；必要时对温度场与变形做模拟计算。

## 二、恢复性能热处理（8.3）

### 2.1 冷成形件的判据

非合金钢、低合金钢冷成形受压元件，**变形率 $>5\%$** 且满足下列任一条件，成形后须做恢复性能热处理：

a) 盛装毒性极度或高度危害介质；b) 注明有应力腐蚀；c) 成形前厚度 $>16$ mm；d) 成形后减薄量 $>10\%$。

铬镍奥氏体不锈钢冷成形件（封头、膨胀节除外）同样看 a)~d)，另加变形率门槛：设计温度 $>675^{\circ}\mathrm{C}$ 时 $>10\%$，$-196^{\circ}\mathrm{C}\le T<675^{\circ}\mathrm{C}$ 时 $>15\%$。

### 2.2 变形率（8.3.1.2，`#L16304-#L16318`）

| **符号式** | $\varepsilon=100\dfrac{r}{R}$ | （4-3） |
| **文字式** | $\text{弯管变形率}_{\text{【\%】}}=100\times\dfrac{\text{管子外半径}_{\text{【mm】}}}{\text{管子中心线弯曲半径}_{\text{【mm】}}}$ |  |

$R_0$ 对平板取 $\infty$；标准椭圆封头 EHA 型 $R_f=0.1727D_i+0.5\delta$，EHB 型 $R_f=0.1727D_o-0.5\delta$。

分步冷成形：不做恢复性能热处理时，变形率为各步之和；中间做过恢复性能热处理时，只累加其后的各步；投料钢板经开平的，须计入开平产生的变形率。

### 2.3 铁素体含量与固溶（8.3.1.4~8.3.1.5）

| 设计温度 | 铁素体显示含量上限（GB/T 1954） | 超限处置 |
|:--|:--|:--|
| 低于 $-40^{\circ}\mathrm{C}$，或做应变强化 | $\le15\%$ | 恢复性能热处理 |
| $-40^{\circ}\mathrm{C}\le T<675^{\circ}\mathrm{C}$ | $\le25\%$ | 恢复性能热处理 |
| 高于 $675^{\circ}\mathrm{C}$ | 必须做恢复性能热处理，且 $\le15\%$ | 固溶处理 |

### 2.4 其他恢复性要求

- 热成形或温成形改变了材料供货热处理状态，且供货状态与使用状态一致时，须做恢复性能热处理；
- 复合板按基层材料判断是否做、按基层定参数，但变形率与保温时间按**总厚度**算，且不得损害覆层；
- 非合金钢、低合金钢可按 PWHT 参数或供货热处理参数做；奥氏体不锈钢用**固溶处理**。

## 三、焊后热处理厚度（8.4.2，`#L16302-#L16320`）

| 接头/结构 | $\delta_{PWHT}$ 取法 |
|:--|:--|
| 等厚度全焊透对接接头 | 钢材厚度 |
| 对接焊缝连接 | 对接焊缝厚度 |
| 角焊缝连接 | 角焊缝厚度 |
| 组合焊缝 | 对接焊缝与角焊缝厚度较大者 |
| 螺柱焊缝 | 螺柱公称直径 |
| 不等厚对接 | 较薄元件的钢材厚度 |
| 壳体与管板、平封头、盖板、凸缘、容器法兰等的 B 类接头 | 壳体厚度 |
| 安放式接管与壳体 | 接管厚度、筒体或封头焊缝厚度、补强圈厚度、补强圈角焊缝厚度中**最大者** |
| 插入式接管与壳体 | 接管焊缝厚度、筒体或封头焊缝厚度、补强圈厚度、角焊缝厚度中**最大者** |
| 接管与法兰 | 接管颈厚度（图 14a 全厚度焊透结构取法兰厚度） |
| 封头置于筒体内的连接结构 | 圆筒厚度、封头厚度、角焊缝厚度中最大者 |
| 非受压元件与受压元件 | 连接焊缝厚度 |
| 换热管与管板 | 换热管厚度 |
| 单独堆焊（不与他件相焊） | 堆焊层厚度 |
| 焊接返修 | 填充焊缝金属厚度 |

## 四、是否必须做 PWHT（8.4.3，`#L16324-#L16328`）

满足其一即须做，且范围包括受压元件间、受压元件与非受压元件间的连接焊缝：

a) $\delta_{PWHT}$ 达到**表 4** 门槛；
b) 注明有应力腐蚀；
c) 盛装毒性**极度危害**介质的非合金钢、低合金钢容器（含以其为基层的复合板）；
d) 相关标准或设计文件另有规定。

表 4 的门槛值（单位 mm）：

| 材料组别 | 代表牌号 | 门槛 |
|:--|:--|:--|
| Fe-1-1、Fe-1-2、Fe-1-3、Fe-1-4 | Q245R、Q345R、Q370R、Q420R、Q490R 等 | 不预热时 $>32$；预热至 $>100^{\circ}\mathrm{C}$ 时 $>38$ |
| Fe-1-2 低温钢 | 16MnDR、16MnD | $>25$ |
| Fe-1-2/1-3 低温钢 | 09MnNiDR、09MnNiD、15MnNiNbDR | $T\ge-45^{\circ}\mathrm{C}$ 时 $>20$；$T<-45^{\circ}\mathrm{C}$ 时任意厚度 |
| Fe-1-4 低温钢 | 08MnNiMoVD、10Ni3MoVD 等 | 不预热 $>32$；预热 $>38$ |
| Fe-3-1、Fe-3-2、Fe-3-3 | 12CrMo、20MnMo、13MnNiMoR 等 | 任意厚度（20MnMoD 低温时 $T\ge-30^{\circ}\mathrm{C}$ 为 $>20$） |
| Fe-4、Fe-5A、Fe-5B、Fe-5C | 15CrMoR、12Cr2Mo1R、12Cr2Mo1VR 等 | 任意厚度 |
| Fe-7-1、Fe-7-2 | S11306、S11348、S11972 | $>10$ |
| Fe-9B | 08Ni3DR、08Ni3D | 任意厚度 |

补充规则：异种材料接头按**要求严者**；复合板接头按**基层**；铬镍奥氏体、奥氏体-铁素体不锈钢接头**可不做**（设计文件另有规定除外）。

## 五、工艺与实施（8.4.7~8.4.9）

- 保温温度与时间按 GB/T 30583；采用「降温延长时间」工艺时，**降温幅度 $\le55^{\circ}\mathrm{C}$**；
- 复合板按基层定保温温度、按**总厚度**定保温时间；基层与覆层不能直接熔焊的复合板、衬里容器须在**组焊衬里件前**完成 PWHT；
- 炉子：符合 GB/T 30583，气氛中性或弱氧化；燃气炉用于有色金属复合板/衬里/堆焊层时**硫 $<0.57$ g/m³**，燃油炉**硫 $<0.5\%$**；须有自动记录温度曲线的仪表；
- 测温点：接管与壳体、刚性构件与壳体的接头部位必须布点，相邻点沿壳体轮廓**间距 $\le4600$ mm**；外热源时多点布在内侧，内热源时多点布在外侧；
- 非合金钢、低合金钢炉内操作：
  ① 进炉炉温 $\le400^{\circ}\mathrm{C}$；
  ② 升温速度按 $5500/\delta_{PWHT}$ ℃/h 计算，**最快 $\le220$ ℃/h、最慢 $\ge15$ ℃/h**；仅热处理换热管-管板接头时不论厚度 $\le140$ ℃/h；
  ③ 升温时加热区内任意 4600 mm 长度温差 $\le140^{\circ}\mathrm{C}$；
  ④ 保温时最高与最低温度之差**不宜超过 $80^{\circ}\mathrm{C}$**；
  ⑤ 炉温 $>400^{\circ}\mathrm{C}$ 后降温按 $7000/\delta_{PWHT}$ ℃/h，**最快 $\le280$ ℃/h、最慢 $\ge15$ ℃/h**；
  ⑥ 出炉炉温 $\le400^{\circ}\mathrm{C}$，出炉后空冷；
- S11306、S11348 铁素体不锈钢：$>650^{\circ}\mathrm{C}$ 时降温 $\le55$ ℃/h，$<650^{\circ}\mathrm{C}$ 时快速降温。

## 判断

- $\delta_{PWHT}$ 不是「最厚的地方」，而是**焊缝厚度**：接管与壳体取四者最大值、壳体与管板取壳体厚度，取错一处就会把该做的 PWHT 漏掉。
- 表 4 里 Fe-1 类「不预热 32 / 预热 38」这 6 mm 差值是**预热换来的**，预热到 $100^{\circ}\mathrm{C}$ 以上才有资格用 38。
- 升温与降温速度都与厚度成反比（$5500/\delta$、$7000/\delta$），但被 $220/280$ 与 15 ℃/h 双向夹住：薄件不可能更快，厚件不可能更慢。
- 复合板的参数是「两层算法」：温度看基层、时间看总厚度——按覆层定温度会烧坏覆层，按基层厚度定时间会消应力不足。

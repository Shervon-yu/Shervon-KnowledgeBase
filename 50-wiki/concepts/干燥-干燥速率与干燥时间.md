# 干燥-干燥速率与干燥时间

## 定义

- **干燥速率 $u$**：单位时间内单位干燥表面积上汽化的水分量，kg 水/(m²·h)（#L14464）。
- **干燥实验曲线**：恒定空气条件（温度、湿度、流速、接触状况不变）下物料含水量 $X$ 与温度 $\theta$ 随时间的变化（#L14378）。
- **临界含水量 $X_c$**：恒速干燥阶段与降速干燥阶段分界点 C 处的物料含水量（#L14404）。
- **平衡含水量**：物料干燥的极限含水量（#L14410）。

## 判据 / 计算

干燥速率的微分定义：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=\dfrac{\mathrm dW}{A\,\mathrm d\tau}$ | （14-1） |
| **文字式** | $\text{干燥速率}_{\text{【kg/(m²·h)】}}=\dfrac{\mathrm d\text{水分蒸发量}_{\text{【kg】}}}{\text{干燥面积}_{\text{【m²】}}\times\mathrm d\text{干燥时间}_{\text{【h】}}}$ |  |

原书编号：式(7-33)（#L14468）。

以干基含水量表示（$\mathrm dW=-L_c\mathrm dX$）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=-\dfrac{L_c\,\mathrm dX}{A\,\mathrm d\tau}$ | （14-2） |
| **文字式** | $\text{干燥速率}_{\text{【kg/(m²·h)】}}=\dfrac{-\text{绝干物料质量}_{\text{【kg】}}\times\mathrm d\text{干基含水量}}{\text{干燥面积}_{\text{【m²】}}\times\mathrm d\text{干燥时间}_{\text{【h】}}}$ |  |

原书编号：式(7-34)（#L14476）；负号表示含水量随时间减小（#L14480）。

干燥三阶段（#L14384-#L14406）：

| 阶段 | 特征 | 表面温度 |
|:---|:---|:---|
| 预热段 AB | 空气传热大于汽化耗热，物料升温 | $\theta<t_w$ |
| 恒速段 BC | 表面被水膜覆盖，汽化速率恒定；主要受空气 $t$、$H$、流速与接触方式影响 | 恒为湿球温度 $t_w$ |
| 降速段 CDE | 内部水分来不及补充到表面，汽化面逐渐内移，速率下降 | 由 $t_w$ 向空气温度 $t$ 升 |

恒速段三点结论（#L14494-#L14500）：

1. 提高空气温度 $t$、降低湿度 $H$，增大传热与传质推动力 $(t-t_w)$、$(H_w-H)$；
2. 提高空气流速可增大 $\alpha$ 与 $k_H$；
3. 接触方式影响很大：颗粒悬浮于气流中最佳，气流穿过料层次之，掠过料层表面最差。

## 适用范围与边界

- 三阶段划分的前提是**恒定干燥条件**；空气条件变化时曲线移动（#L14398）。
- 恒速段的速率与物料性质关系很小，主要取决于外部空气条件；降速段则受物料内部水分扩散控制（#L14400）。
- 干燥时间计算须分段积分：恒速段从 $X_1$ 到 $X_c$，降速段从 $X_c$ 到最终含水量（#L14504）。
- 平衡含水量是极限：物料最终含水量不可能低于与空气状态对应的平衡值（#L14410）。

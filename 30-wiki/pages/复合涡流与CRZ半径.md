# 复合涡流与CRZ半径

## 两种涡流与复合涡流

无挡板圆筒容器中，中央桨式叶轮搅动的速度分布接近 Rankine 复合涡流：中心区像实心圆筒一样随桨同步旋转（强制涡流，称圆筒形旋转区 C.R.Z.），外围是自由涡流，两区之间没有明显过渡（`#L385`、`#L481`）。

自由涡流（恒能量环流）由动量平衡与 Bernoulli 方程联立得到（`#L393`、`#L423`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $vr=C$ | （1.5） |
| **文字式** | $\text{流速}_{\text{【m/s】}}\times\text{半径}_{\text{【m】}}=\text{常数}$ |  |

即流速与曲率半径成反比；恒压面为双曲线，自由液面呈漏斗形（`#L449`）。粘滞剪应力 $\tau=-\mu\,\mathrm{d}v/\mathrm{d}r$ 与 $r^{2}$ 成反比（式1.11），故中心若无强制涡流则剪应力与速度都趋于无限，实际由恒定角速度的 C.R.Z. 截断（`#L475`、`#L479`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r\le r_{c}:\ v=r\omega;\qquad r\ge r_{c}:\ v=\dfrac{\omega r_{c}^{2}}{r}$ | （1.12）（1.13） |
| **文字式** | $\text{半径}\le\text{临界半径}:\ \text{流速}=\text{半径}\times\text{角速度};\qquad \text{半径}\ge\text{临界半径}:\ \text{流速}=\dfrac{\text{角速度}\times\text{临界半径}^{2}}{\text{半径}}$ |  |

## 由液面外形求 CRZ 半径

强制涡流区液面为旋转抛物面，自由涡流区按式（1.16）外推，测得中心液面高 $Z_{0}$ 与壁面液面高 $Z_{2}$ 即可反算 $r_{c}$（`#L511`、`#L535`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r_{c}=\sqrt{r_{2}\left(r_{2}-\sqrt{r_{2}^{2}-k}\right)},\quad k=\dfrac{2g}{\omega^{2}}\left(Z_{2}-Z_{0}\right)$ | （1.17） |
| **文字式** | $\text{临界半径}_{\text{【m】}}=\sqrt{\text{容器内半径}_{\text{【m】}}\left(\text{容器内半径}_{\text{【m】}}-\sqrt{\text{容器内半径}_{\text{【m】}}^{2}-k}\right)},\quad k=\dfrac{2\times\text{重力加速度}_{\text{【m/s²】}}}{\text{角速度}_{\text{【rad/s】}}^{2}}\left(\text{壁面液面高}_{\text{【m】}}-\text{中心液面高}_{\text{【m】}}\right)$ |  |

另一条路是用体积守恒推出的无量纲式，令 $y=r_{c}/r_{2}$（`#L555`、`#L561`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{H-Z_{0}}{r_{2}^{2}}\cdot\dfrac{g}{\omega^{2}}=y^{2}-y^{4}\left\{2.303\log\dfrac{1}{y}+\dfrac{3}{4}\right\}$ | （1.19） |
| **文字式** | $\dfrac{\text{搅拌前液面高}_{\text{【m】}}-\text{中心液面高}_{\text{【m】}}}{\text{容器内半径}_{\text{【m】}}^{2}}\cdot\dfrac{\text{重力加速度}_{\text{【m/s²】}}}{\text{角速度}_{\text{【rad/s】}}^{2}}=y^{2}-y^{4}\left\{2.303\log\dfrac{1}{y}+\dfrac{3}{4}\right\}$ |  |

右端只是 $y$ 的函数，可先算出一族 $(H-Z_{0})g/(r_{2}^{2}\omega^{2})$ 值再反查 $y$（原书作图1.5）。

**例1.1**（`#L567`）：$r_{2}=7.05$ cm、$H=10$ cm、四叶桨 $r_{1}=2.35$ cm、400 r/min、实测 $Z_{0}=6.40$ cm、$Z_{2}=10.56$ cm。式（1.17）得 $r_{c}=1.55$ cm，式（1.19）得 $r_{c}=1.49$ cm，故 $r_{c}/r_{1}\approx0.64$——桨叶只有约 35% 的叶面积在有效做功。

## 功率消耗与 CRZ

桨叶位于 C.R.Z. 以内的部分不与液体产生相对运动，不消耗功率；位于 $r_{c}$ 以外的部分以相对速度 $u_{r}=2n\pi(r-r_{c}^{2}/r)$ 撞击液体（`#L621`、`#L635`）。把微元阻力积分可得以 $P_{l}/P_{桨}$ 表示的功率比（式1.24~1.27），据此可用不同宽度叶轮的实测功率反推 $r_{c}$。

实验归纳出 CRZ 半径与雷诺数的单一关联式（`#L698`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{r_{c}}{r_{1}}=\dfrac{Re}{10^{3}+1.6Re}$ | （1.28） |
| **文字式** | $\dfrac{\text{临界半径}_{\text{【m】}}}{\text{叶轮半径}_{\text{【m】}}}=\dfrac{\text{雷诺数}}{1000+1.6\times\text{雷诺数}}$ |  |

- $Re>4\times10^{4}$ 时 $r_{c}/r_{1}\approx0.6\sim0.65$ 趋常数；$Re<2000$ 时骤降；$Re\to100$ 时 $r_{c}/r_{1}\to0$（`#L686`、`#L688`、`#L702`）。
- 粘度增大、容器直径增大（桨尺寸与转速不变）都使 $r_{c}$ 减小，功率趋向最大值（`#L684`、`#L704`）。
- 由表1.1 实测：水（1 cP）$r_{c}/r_{1}=0.3\sim0.7$；500 cP 小米糊一律 $r_{c}/r_{1}=0$，即全叶面受流体阻力（`#L669`、`#L675`）。

## 与功率设计的接口

同一桨在无挡板、加挡板、偏心、加大容器直径四种情形下，功率上限相同（`#L706`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(P_{\max}\right)_{1}\cong\left(P_{\max}\right)_{2}\cong\left(P_{\max}\right)_{3}\cong\left(P_{\max}\right)_{4}$ | （1.29） |
| **文字式** | $\text{最大功率}_{1}\cong\text{最大功率}_{2}\cong\text{最大功率}_{3}\cong\text{最大功率}_{4}$ |  |

这就是用"全挡板功率"作上限、用 $r_{c}/r_{1}$ 折减来估算无挡板实际功率的依据（详见 [[永田进治功率关联式]]）。

## 边界

- 模型假设圆筒形容器、中央叶轮、无挡板、液面自由；方形槽、偏心、多层叶轮需另作修正。
- 实验只覆盖 $d/D=0.154\sim0.7$、$b/D=0.154\sim0.7$、1~500 cP（`#L671`）。
- $d/D$ 较大的桨一致性变差，$r_{c}$ 只能定性使用（`#L684`）。

# 精馏-理论板数与回流比

## 定义

**理论板**：离开该板的汽液两相达到平衡的理想塔板（#L12012）。实际需要的理论板数 $N$ 与**回流比** $R=L/D$ 直接相关（#L11720）：$R$ 大则 $N$ 小但能耗大，$R$ 小则 $N$ 大。**最少理论板数** $N_{\min}$ 对应全回流（$R\to\infty$，#L12264）；**最小回流比** $R_{\min}$ 对应操作线与平衡线相交、所需 $N\to\infty$（#L12332）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\min}=\dfrac{\lg\left[\left(\dfrac{x_{\mathrm{D}}}{1-x_{\mathrm{D}}}\right)\left(\dfrac{1-x_{\mathrm{W}}}{x_{\mathrm{W}}}\right)\right]}{\lg\alpha}$ | （6.3-7） |
| **文字式** | $\text{最少理论板数}=\dfrac{\lg\left[\left(\dfrac{\text{馏出组成}}{1-\text{馏出组成}}\right)\left(\dfrac{1-\text{釜残组成}}{\text{釜残组成}}\right)\right]}{\lg\text{相对挥发度}}$ |  |

（式 6-50，芬斯克-安德伍德形式，#L12264；$\alpha$ 用塔顶塔底的几何平均，见 [[相对挥发度与汽液平衡比]]。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R_{\min}=\dfrac{x_{\mathrm{D}}-y_{\mathrm{P}}}{y_{\mathrm{P}}-x_{\mathrm{P}}}$ | （6.3-8） |
| **文字式** | $\text{最小回流比}=\dfrac{\text{馏出组成}-\text{交点汽相组成}}{\text{交点汽相组成}-\text{交点液相组成}}$ |  |

（式 6-51，#L12332；$(x_{P},y_{P})$ 为 q 线与平衡线的交点；泡点进料时 $x_{P}=x_{F}$，$y_{P}=\alpha x_{F}/[1+(\alpha-1)x_{F}]$，#L12344。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R=\left(1.1\sim2.0\right)R_{\min}$ | （6.3-9） |
| **文字式** | $\text{操作回流比}=\left(1.1\sim2.0\right)\times\text{最小回流比}$ |  |

（式 6-52，工程取值习惯，#L12398。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{N-N_{\min}}{N+1}=0.75-0.75\left(\dfrac{R-R_{\min}}{R+1}\right)^{0.5668}$ | （6.3-10） |
| **文字式** | $\dfrac{\text{理论板数}-\text{最少理论板数}}{\text{理论板数}+1}=\text{吉利兰关联式（经验式，见式右）}$ |  |

（式 6-53，吉利兰关联式，#L12408；经验拟合，用于由 $R$、$R_{\min}$、$N_{\min}$ 快速估 $N$。）

**逐板计算法**：从塔顶开始，交替用平衡关系 $x=\frac{y}{\alpha-(\alpha-1)y}$ 与精馏段操作线 $y=\frac{R}{R+1}x+\frac{x_{D}}{R+1}$，算到 $x\le x_{F}$ 后换提馏段操作线 $y=\frac{R'+1}{R'}x-\frac{x_{W}}{R'}$，直到 $x\le x_{W}$（#L12026 的 (a)(b)(c) 三式为算例形式，#L12038）。

## 适用范围与边界

- 式 6-50 假定恒 $\alpha$ 与恒摩尔流，且塔顶为全凝器、塔底为釜式再沸器（#L12244 的连乘来源）。
- 吉利兰式是**经验关联**，$0.01\le(R-R_{\min})/(R+1)\le0.9$ 内误差较小；超出该区间不可用（#L12408）。
- $R_{\min}$ 对 q 线敏感：冷液进料 $q>1$ 时交点位置改变（#L11906）。
- 直接蒸汽加热（釜底通蒸汽）改变了提馏段衡算，用式 6-54~6-57，#L12639 起；此时 $W$ 与 $b$ 的关系不同。
- 多股进料见式 6-58~6-64，#L12701 起。

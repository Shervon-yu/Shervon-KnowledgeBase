# 立式钢制搅拌容器的选型参数

## 适用条件（GB 9845）

| 参数 | 范围 |
|:---|:---|
| 容积 | 0.040~100 m³ |
| 设计压力 | −0.1~12 MPa |
| 液体介质温度 | −40~350 ℃ |
| 动力黏度 | <500 Pa·s |
| 密度 | <2000 kg/m³ |
| 不适用 | 无盖、直接火焰加热 |

（`#L5986-#L5990`）

## 结构型式与主要参数

- 上封头与筒体连接分**不可拆与可拆**两种；筒体内径 ≤1200 mm 宜采用可拆连接；
- 表6-3 的"容积"指**筒体与下封头容积之和**（`#L5994`）；
- 不同封头受力不同，承压能力不同，见表6-4。

|:---:|:---|:---|:---|
| 0.040 | D400 | — | 230 |
| 0.16 | D600 / H450 | D600 / H450 | D600 / H520 |
| 0.40 | D800 / H650 | D800 / H600 | D800 / H750 |
| 1.00 | D1000 / H1100 | D1000 / H1050 | D1000 / H1100 |
| 2.0 | D1550 / H1500 | D1550 / H1550 | D1550 / H1700 |
| 5.0 | D1800 / H1650 | D1800 / H1550 | D1800 / H1650 |
| 10 | D2000 / H2850 | D2000 / H2750 | D2000 / H2850 |
| 20 | D2600 / H3350 | D2600 / H3200 | D2600 / H3350 |
| 50 | D3000 / H6550 | D3000 / H6250 | — |
| 100 | D3600 / H9200 | D3600 / H8000 | — |

（`#L6002-#L6089`；注：球形底+平盖宜用于内径 1600 mm 以下、设计压力 2.5 MPa 以上场合，`#L6091`）

| 封头型式 | 内径≤/mm | 压力范围/MPa |

（`#L6093-#L6129`）

## 传动与轴封

| 项目 | 要求 |
|:---|:---|
| 传动装置 | 输出轴转速与额定功率应符合表6-5（0.040 m³：0.55~1.5 kW、20~3000 r/min；100 m³：4~200 r/min 等；表内 OCR 有串行，**待核**） |
| 电动机 | 符合 GBJ 49 |
| 填料密封 | 轴颈线速度 >1 m/s 或介质温度 >100 ℃ 时宜采取冷却措施 |
| 机械密封 | 密封腔温度 >80 ℃ 应采取冷却措施 |
| 双端面密封 | 易燃、易爆、有毒或高真空场合 |
| 无轴封 | 渗透性强的易燃易爆剧毒介质或高真空 |

（`#L6131-#L6160`）

## 其他

- 换热型式：外部（整体夹套，或型钢/蜂窝/半圆管/外蛇管夹套）与内部两类（`#L6150`）；
- 搅拌轴可从顶部、底部或偏离中心插入，一根轴上可设两个以上搅拌器（`#L6152`）；
- 出料：上、下接管或放料阀（`#L6162`）。

## 判断

表6-3 的"容积—内径—高度"是**已圆整的标准组合**，与式（6-6）算出的理论 H 常差一档。选型时应先取标准组合再核 $H_L/D$，而不是把理论值硬改成非标尺寸——非标要重新出图、重新做强度计算，成本远超容积那几个百分点的偏差。

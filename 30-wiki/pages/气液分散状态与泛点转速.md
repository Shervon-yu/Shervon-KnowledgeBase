# 气液分散状态与泛点转速

## 两个基础参数

|  |  |  |
|:---|:---:|---:|
| **符号式** | $V_{G}=\dfrac{Q_{G}}{A_{t}}$ | （2-63） |
| **文字式** | $\text{表观气速}_{\text{【m/s】}}=\dfrac{\text{通气速率}_{\text{【m³/s】}}}{\text{搅拌设备横截面积}_{\text{【m²】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{A}=\dfrac{Q_{G}}{Nd^{3}}$ | （2-64） |
| **文字式** | $\text{通气数}=\dfrac{\text{通气速率}_{\text{【m³/s】}}}{\text{转速}_{\text{【1/s】}}\times\left(\text{搅拌器直径}_{\text{【m】}}\right)^{3}}$ |  |

涡轮式搅拌器 $V_G$ 一般 0.025~0.04 m/s，最大 0.1~0.12 m/s（`#L2148`）。

## 三个分散状态

固定通气速率、逐渐升转速（图2-14，`#L2150-#L2162`）：

| 状态 | 特征 | 判据 |
|:---|:---|:---|
| ① 气泛 Flooding | 大部分气体未分散，气泡很大，沿轴直上液面，相当于鼓泡釜 | 转速低于 $N_f$ |
| ② 载气 Loading | 气体基本分散、气泡可达釜壁，但分布器以下分散不良，气泡仅有限再循环 | $N_f<N<N_{cd}$ |
| ③ 完全分散 Complete Dispersion | 气泡小、随液体再循环，全釜良好分散 | $N>N_{cd}$ |

- 气泛↔载气的临界转速称**泛点转速** $N_f$，随通气速率增大而增大（`#L2160`）；
- 载气↔完全分散的临界转速称**完全分散转速** $N_{cd}$（`#L2162`）；
- 载气状态的操作区间窄，$N_f$ 与 $N_{cd}$ 差别不大，工程上不严格区分（`#L2162`）。

反过来，转速固定、增大通气速率时，状态按（e）→（a）退化（`#L2164`）。

## 泛点转速关联式（表2-13）

表中 $N_f$ 单位 r/s，$D$ 釜径 m，$d$ 搅拌器直径 m，$Q_G$ 通气速率 m³/s，$g$ 重力加速度，$\sigma$ 表面张力 N/m，$\rho$ 液体密度，$n_p$ 一个叶轮上的叶片数（`#L2183`）。

Nienow（`#L2175`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{f}=4.0\,Q_{G}^{0.5}D^{0.5}d^{-2}$ | （2-68） |
| **文字式** | $\text{泛点转速}_{\text{【r/s】}}=4.0\times\text{通气速率}_{\text{【m³/s】}}^{0.5}\times\text{釜径}_{\text{【m】}}^{0.5}\times\left(\text{搅拌器直径}_{\text{【m】}}\right)^{-2}$ |  |

同表 Nienow 另一式（`#L2176`）：$N_f=0.322\left(gQ_G/d^{4}\right)^{0.33}\left(D/d\right)^{1.17}$（2-69）。Lu 式引入叶片数（`#L2181`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{f}=C\left(\dfrac{D}{d}\right)^{1.17}\left(\dfrac{gQ_{G}}{d^{4}}\right)^{0.34}f(n_{p})$ | （2-74） |
| **文字式** | $\text{泛点转速}_{\text{【r/s】}}=C\times\left(\dfrac{\text{釜径}_{\text{【m】}}}{\text{搅拌器直径}_{\text{【m】}}}\right)^{1.17}\times\left(\dfrac{g\times\text{通气速率}_{\text{【m³/s】}}}{\left(\text{搅拌器直径}_{\text{【m】}}\right)^{4}}\right)^{0.34}\times f\left(\text{叶片数}\right)$ |  |

其中 $C=0.064$（下限）、$0.072$（上限），$f(n_p)=4.07+1.21n_p-0.147n_p^{2}$（`#L2181`）。其余：Westerterp（2-65，六直叶盘式涡轮 $A=1.22,B=1.25$；四直叶桨 $A=2.25,B=0.68$）、Dierendinck（2-66）、Smith（2-67）、高峰（2-70）、Greavas（2-71，$C=1.52$ 水/1.66 电解质）、Wiedmann（2-72）、Waemoeskerken（2-73）。

## 判据的使用

- 气泛时含气率与相界面都很小，严重限制传质与反应速率；实际生产应把转速控制在**泛点转速之上**（`#L2166`）。
- 例题思路：由 $Q_G$、$D$、$d$ 按式（2-68）或（2-74）算 $N_f$，操作转速取 1.2~2 倍并校核功率（见 [[通气搅拌功率]]）。
- 表2-13 各式的几何范围不同（$d/D=0.2\sim0.7$），外推需对照实验条件；空气-水系统用六叶圆盘涡轮时，流动形态还可按 $Fr$–$N_A$ 图（图2-15）判断哪些工况已属良好分散（`#L2185`）。

结构（挡板、分布环、层数）的推荐值见 [[气液搅拌设备设计要点]]。

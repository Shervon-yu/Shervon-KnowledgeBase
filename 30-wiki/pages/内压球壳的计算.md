# 内压球壳的计算

适用范围：$K\le1.35$ 或 $p_c\le0.6[\sigma]^t\varphi$（`#L5144`）。

## 计算厚度（式5-9、5-10）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta=\dfrac{p_cD_i}{4[\sigma]^t\varphi-p_c}$；$\quad \delta=\dfrac{p_cD_o}{4[\sigma]^t\varphi+p_c}$ | （5-9）（5-10） |
| **文字式** | $\text{计算厚度}_{\text{【mm】}}=\dfrac{\text{计算压力}\times\text{内直径}}{4\times\text{许用应力}\times\text{焊接接头系数}-\text{计算压力}}$ |  |

## 计算应力（式5-11~5-13）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma^t=\dfrac{p_c(D_i+\delta_e)}{4\delta_e}\le[\sigma]^t\varphi$ | （5-11）（5-13） |
| **文字式** | $\text{计算应力}_{\text{【MPa】}}=\dfrac{\text{计算压力}\times(\text{内直径}+\text{有效厚度})}{4\times\text{有效厚度}}$，且不大于许用应力乘焊接接头系数 |  |

## 最大允许工作压力（式5-14、5-15）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[p_w]=\dfrac{4\delta_e[\sigma]^t\varphi}{D_i+\delta_e}$；$\quad [p_w]=\dfrac{4\delta_e[\sigma]^t\varphi}{D_o-\delta_e}$ | （5-14）（5-15） |
| **文字式** | $\text{最大允许工作压力}_{\text{【MPa】}}=\dfrac{4\times\text{有效厚度}\times\text{许用应力}\times\text{焊接接头系数}}{\text{内直径}+\text{有效厚度}}$ |  |

## 判断

- 与圆筒公式只差分母的 **2 → 4**：球壳是双向等拉应力状态，膜应力只有同直径圆筒环向应力的一半，故同压同径下壁厚约省一半；
- 适用范围也更宽（$K\le1.35$、$p_c\le0.6[\sigma]^t\varphi$），因为球壳没有圆筒那种"环向应力集中 + 边缘弯矩"问题；
- 工程上球壳常用作**封头**（半球形封头）与大型储罐；球形储罐另有 GB/T 12337，不套本章。

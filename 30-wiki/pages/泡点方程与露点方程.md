# 泡点方程与露点方程

## 三个基本式（`#L11058-#L11110`）

理想溶液服从拉乌尔定律，汽相服从道尔顿分压定律：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p_A=p_A^{\circ}x_A$，$p_B=p_B^{\circ}(1-x_A)$，$p_A+p_B=p$ | （6-5~6-7） |
| **文字式** | $\text{两组分分压}=\text{各自饱和蒸气压}\times\text{液相组成}$，且两分压之和等于总压 |  |

消去 $p_A$、$p_B$ 得**泡点（温度-液相组成）方程**：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $x=\dfrac{p-p_B^{\circ}}{p_A^{\circ}-p_B^{\circ}}$ | （6-8） |
| **文字式** | $\text{液相中易挥发组分摩尔分数}=\dfrac{\text{总压}-\text{纯}B\text{的饱和蒸气压}}{\text{纯}A\text{的饱和蒸气压}-\text{纯}B\text{的饱和蒸气压}}$ |  |

由 $p_A=py_A$ 得**恒压下 $t$-$y$-$x$ 关系**：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y=\dfrac{p_A^{\circ}x}{p}$ | （6-9） |
| **文字式** | $\text{汽相中易挥发组分摩尔分数}=\dfrac{\text{纯}A\text{的饱和蒸气压}\times\text{液相组成}}{\text{总压}}$ |  |

将式6-8 代入式6-9 得**露点（温度-汽相组成）方程**：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y=\dfrac{p_A^{\circ}}{p}\cdot\dfrac{p-p_B^{\circ}}{p_A^{\circ}-p_B^{\circ}}$ | （6-10） |
| **文字式** | $\text{汽相组成}=\dfrac{\text{纯}A\text{饱和蒸气压}}{\text{总压}}\times\dfrac{\text{总压}-\text{纯}B\text{饱和蒸气压}}{\text{纯}A\text{饱和蒸气压}-\text{纯}B\text{饱和蒸气压}}$ |  |

## 四变量关系（表6-1 前的文字，`#L11114-#L11116`）

$p$、$t$、$y$、$x$ 四个变量中**给定两个即可定另外两个**（自由度 2）：

| 已知 | 求 | 方法 |
|:--|:--|:--|
| $p$、$t$ | $x$、$y$ | 由 $t$ 查 $p^{\circ}_A$、$p^{\circ}_B$ → 式6-8 → 式6-9 |
| $t$、$x$ | $y$、$p$ | 同上反算 $p$ |
| $t$、$y$ | $x$、$p$ | 由式6-9 解 $x=py/p^{\circ}_A$，再求 $p$ |
| $x$、$y$ | $p$、$t$ | 消去 $p$ 得 $\frac{p_A^{\circ}}{p_B^{\circ}}=\frac{y(1-x)}{x(1-y)}$，试差求 $t$ |
| $y$、$p$ | $t$、$x$ | 假设 $t$ → 算 $y$ 校核 |
| $x$、$p$ | $t$、$y$ | 假设 $t$ → 算 $x$ 校核 |

## 两个算例（`#L11125-#L11208`）

**例6-1** 正戊烷-正己烷（理想溶液），$p$=101.33 kPa：由表6-1 的 $p^{\circ}$-$t$ 数据逐温度算 $x$、$y$，得表6-2：36.1 ℃ 时 $x$=1、$y$=1；50 ℃ 时 $x$=0.45、$y$=0.71；68.7 ℃ 时 $x$=0、$y$=0。

**例6-2** 苯-甲苯（服从拉乌尔定律），安托因常数：
$\lg p^{\circ}_A=6.03055-\dfrac{1211.033}{t+220.79}$，$\lg p^{\circ}_B=6.07954-\dfrac{1344.8}{t+219.482}$。

1. $t$=100 ℃、$x$=0.3：$p^{\circ}_A$=180、$p^{\circ}_B$=74.17 kPa → $p$=105.9 kPa、$y$=0.51；
2. $p$=101.33 kPa、$x$=0.4：试差 3 次（90/93/97 ℃ → $x$=0.575/0.47/0.343），内插得 $t$=95.1 ℃、$p^{\circ}_A$=157.3 → $y$=0.621；
3. $x$=0.5、$y$=0.71：$\frac{p^{\circ}_A}{p^{\circ}_B}=\frac{0.71\times0.5}{0.5\times0.29}=2.448$，试差得 $t$=97.4 ℃、$p$=118.1 kPa。

## 判断

- 试差法的收敛方向要看单调性：$t$ 升高 → $p^{\circ}$ 升高 → 由式6-8 算出的 $x$ 减小。例6-2(2) 算得 $x>x_{\text{已知}}$ 说明 $t$ 假设偏小——这个判断必须记住，否则试差会乱走。
- 式6-9 假设汽相为理想气体（道尔顿定律），总压不高时成立；加压到几 MPa 时需改用逸度系数修正，本课程不展开。
- 泡点方程与露点方程本质是同一组方程的两种写法，$t$-$x$ 与 $t$-$y$ 曲线在图上互为"镜像"的边界。

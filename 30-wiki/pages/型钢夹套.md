# 型钢夹套

## 结构

一般由**角钢与筒体焊接**组成（图7-5）：角钢可沿筒体外壁**轴向**布置，也可**螺旋**布置；分螺旋形角钢互搭式与单根角钢螺旋缠绕两种（`#L6741-#L6759`）。

## 特点

- 型钢刚度大，比整体夹套能承受**更高压力**（表7-1：200 ℃、2.5 MPa）；
- 制造难度相应增加（焊缝多、装配要求高）（`#L6751`）。

## 筒体壁厚

型钢夹套覆盖的筒体壁厚 S 取式（7-1）与式（7-2）的**较大值**（`#L6755-#L6775`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $S=t\sqrt{\dfrac{p}{2[\sigma]^{t}\phi}}+\dfrac{Dp_{1}}{8[\sigma]^{t}\phi}+C$ | （7-1） |
| **文字式** | $\text{壁厚}_{\text{【mm】}}=\text{型钢宽度}_{\text{【mm】}}\sqrt{\dfrac{\text{内夹套压力较大值}_{\text{【MPa】}}}{2\times\text{许用应力}_{\text{【MPa】}}\times\text{接头系数}}}+\dfrac{\text{内径}_{\text{【mm】}}\times\text{容器内设计压力}_{\text{【MPa】}}}{8\times\text{许用应力}_{\text{【MPa】}}\times\text{接头系数}}+\text{附加量}_{\text{【mm】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $S=\dfrac{p_{1}D}{2[\sigma]^{t}\phi-p_{1}}+C$ | （7-2） |
| **文字式** | $\text{壁厚}_{\text{【mm】}}=\dfrac{\text{容器内设计压力}_{\text{【MPa】}}\times\text{内径}_{\text{【mm】}}}{2\times\text{许用应力}_{\text{【MPa】}}\times\text{接头系数}-\text{容器内设计压力}_{\text{【MPa】}}}+\text{附加量}_{\text{【mm】}}$ |  |

符号：$C$ 厚度附加量（负偏差+腐蚀裕量）；$p$ 容器内与夹套内设计压力中的大值；$p_1$ 容器内设计压力；$t$ 型钢宽度；$\phi$ 接头系数（GB 150）。

## 型钢壁厚

- 图7-5(a) 互搭式：$S_t$ 取式（7-3）~（7-5）**三式最大值**（7-3 按型钢宽度 j，7-4 按型钢宽度 t，7-5 按夹套内径 $D_2$）；
- 图7-5(b) 单根缠绕：按式（7-6）（`#L6777-#L6797`）。

## 判断

式（7-1）第一项 $t\sqrt{p/(2[\sigma]\phi)}$ 反映"型钢把夹套压力传给筒体的局部弯矩"，与型钢宽度成正比——型钢越宽，筒体受到的局部弯曲越大，反而要求更厚的筒体。这就是为什么不能靠"换更宽的角钢"来无限提高承压能力。

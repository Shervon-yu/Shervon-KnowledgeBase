# 停留时间分布与反应器计算

## 三种基准反应釜

恒温均相不可逆一级反应，$R=-\mathrm{d}C/\mathrm{d}t=k_1C$（5.14）。三种流型的出口浓度（`#L6076`、`#L6092`、`#L6100`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $C=C_ie^{-k_1t}$（间歇） | （5.15） |
| **文字式** | 间歇釜内浓度按时间指数衰减 |  |

|  |  |  |
|:---|:---:|---|
| **符号式** | $C=C_ie^{-k_1\theta\left(\frac{x}{L}\right)}$（活塞流） | （5.16） |
| **文字式** | 活塞流沿程指数衰减，$x=L$ 处即出口 |  |

|  |  |  |
|:---|:---:|---|
| **符号式** | $C_e=\dfrac{C_i}{1+k_1\theta}$（完全混合） | （5.17） |
| **文字式** | 完全混合流出口浓度只由 $k_1\theta$ 决定，与位置无关 |  |

**物理差别**（`#L6110`）：完全混合流中进料立即被稀释到出口浓度，故反应速率全程最低，要拿到高转化率必须把釜做大——这就是"容积效率"的由来。

## 非理想流：对 RTD 加权平均

对非理想流，出口浓度是各年龄微元浓度的加权平均（`#L6116`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\overline{C_e}=\int_{0}^{\infty}C(t)E(t)\,\mathrm{d}t$ | （5.18） |
| **文字式** | $\text{出口平均浓度}=\int\text{某年龄微元的浓度}\times\text{该年龄所占分数}\,\mathrm{d}t$ |  |

$C(t)$ 取该微元自身的反应历程：一级用 (5.15)；$n$ 级不可逆反应用（`#L6122`、`#L6124`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $C=\left[\dfrac{C_i^{\,n-1}}{1+(n-1)k_nC_i^{\,n-1}t}\right]^{1/(n-1)}$ | （5.20） |
| **文字式** | $n$ 级反应的微元浓度随时间按 $1/(1+\cdot)$ 次方衰减 |  |

## 什么时候不能这么算

式(5.18) 的前提是**反应速率不受微观混合影响**（`#L6126`）。反例：

- 悬浮于另一不互溶液体中的分散相，其中发生零级或二级反应，转化率按**凝并程度**而变；
- 快速反应、副反应竞争（选择性由局部浓度决定）——这类问题必须回到微观混合（见 [[宏观混合与微观混合]]）。

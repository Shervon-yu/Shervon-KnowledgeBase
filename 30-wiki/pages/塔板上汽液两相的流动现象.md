# 塔板上汽液两相的流动现象

## 三种接触状态（`#L12991-#L13017`）

| 状态 | 气速 | 传质面积 | 特点 |
|:--|:--|:--|:--|
| 鼓泡接触 | 很低 | 气泡表面 | 气泡少、湍动弱、传质阻力大 |
| 泡沫接触 | 增大 | 气泡间液膜 | 液膜不断更新，表面大，传热传质好 |
| 喷射接触 | 继续增大 | 液滴外表面 | 液相分散、汽相连续，液滴不断形成与合并 |

**转态规律**：液汽比 $L/V$ 大 → 泡沫；$L/V$ 小 → 喷射。常压精馏多在"混合泡沫状态"操作。

## 表面张力判据（`#L13027-#L13049`）

- $\sigma_{易}<\sigma_{难}$：液膜局部汽化后剩余难挥发组分多、局部 $\sigma$ 变大，把周围液膜拉来修复 → **气泡稳定** → 宜泡沫状态。
- $\sigma_{易}>\sigma_{难}$：局部 $\sigma$ 变小，被周围液体拉走 → 液滴**分裂变小** → 宜喷射状态。

例：正庚烷-甲苯，$\sigma_{庚}$=20.1、$\sigma_{甲}$=27.9 mN/m → $\sigma_{易}<\sigma_{难}$ → 泡沫；水-乙酸，$\sigma_{水}$=72.8、$\sigma_{乙}$=23.9 mN/m → 喷射。

孔径与开孔率大 → 易泡沫；小 → 易喷射。

## 液面落差（`#L13053-#L13057`）

液体从进口流向出口需克服阻力，清液层高度沿程下降，进出口高差称液面落差。落差使进口液层厚、气速小，出口液层薄、气速大 → 气速分布不均，对传质不利。液体流量大、行程长时用**双流型**减小落差。

## 漏液（`#L13059-#L13061`）

气速过小时液体从筛孔漏下。相对漏液量（漏液量/液流量）<10% 时对效率影响不大。

## 液泛（`#L13063-#L13091`）

降液管内清液层高度：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H_d=h_w+h_{0w}+\Delta+h_p+\sum H_f$ | （6-66） |
| **文字式** | $\text{降液管液高}=\text{堰高}+\text{堰上液高}+\text{液面落差}+\text{板压降}+\text{降液管阻力}$ |  |

汽液流量增大使各项增大，$H_d$ 超过降液管高度 → 降液管充满 → **液泛**。$h_p$ 太大通常是液泛主因。

## 液沫夹带（`#L13093-#L13099`）

下层液体被气流带到上层，使提浓作用变差。夹带量随气速增大、板间距减小而增大；要求**不超过 0.1 kg 液体/kg 干蒸气**。泡沫状态夹带少、板间距可小；喷射状态夹带多、板间距应大。

## 判断

- 五种现象分两类：**提高传质的**（泡沫/喷射）与**损害传质的**（漏液、液沫夹带、液泛）——设计就是在两者之间找操作窗口。
- 液泛的本质是"降液管排液能力不足"，所以它同时受气量与液量限制，是塔的**上限负荷**。
- 漏液是**下限负荷**；操作弹性 = 液泛气速/漏液气速。
- 表面张力判据常被忽略，但它直接决定"该设计成泡沫型还是喷射型塔板"，选错则效率打折。

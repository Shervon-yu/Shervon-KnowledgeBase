# 永田进治功率关联式

## 无挡板时的功率准数

二叶平桨、二叶斜桨可查图2-5，也可用永田进治的解析式（`#L1516-#L1520`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}=\dfrac{A}{Re}+B\left(\dfrac{10^{3}+1.2Re^{0.66}}{10^{3}+3.2Re^{0.66}}\right)^{p}\left(\dfrac{H}{D}\right)^{0.35+\frac{b}{D}}\left(\sin\theta\right)^{1.2}$ | （2-26） |
| **文字式** | $\text{功率准数}=\dfrac{A}{\text{雷诺数}}+\text{系数}B\times\left(\dfrac{1000+1.2\times\text{雷诺数}^{0.66}}{1000+3.2\times\text{雷诺数}^{0.66}}\right)^{指数p}\times\left(\dfrac{\text{液面高}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}\right)^{0.35+\frac{\text{桨宽}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}}\times\left(\sin\text{桨叶倾角}_{\text{【°】}}\right)^{1.2}$ |  |

式中（`#L1520`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=14+\left(\dfrac{b}{D}\right)\left[670\left(\dfrac{d}{D}-0.6\right)^{2}+185\right]$ | （2-26 参数 A） |
| **文字式** | $\text{系数}A=14+\dfrac{\text{桨宽}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}\times\left[670\left(\dfrac{\text{叶轮直径}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}-0.6\right)^{2}+185\right]$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $B=10^{\left[1.3-4\left(\frac{b}{D}-0.5\right)^{2}-1.14\frac{d}{D}\right]}$ | （2-26 参数 B） |
| **文字式** | $\text{系数}B=10^{\left[1.3-4\left(\frac{\text{桨宽}}{\text{釜内径}}-0.5\right)^{2}-1.14\frac{\text{叶轮直径}}{\text{釜内径}}\right]}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p=1.1+4\left(\dfrac{b}{D}\right)-2.5\left(\dfrac{d}{D}-0.5\right)^{2}-7\left(\dfrac{b}{D}\right)^{4}$ | （2-26 参数 p） |
| **文字式** | $\text{指数}p=1.1+4\dfrac{\text{桨宽}}{\text{釜内径}}-2.5\left(\dfrac{\text{叶轮直径}}{\text{釜内径}}-0.5\right)^{2}-7\left(\dfrac{\text{桨宽}}{\text{釜内径}}\right)^{4}$ |  |

$b/D\le0.3$ 时 $p$ 中四次方项可忽略（`#L1522`）。

## 多叶与多层的换算技巧

无挡板湍流下，式（2-26）可近似用于多层叶轮或单叶轮多叶片，前提：叶片非曲面、各层倾角与直径一致、**叶片宽度 b 与叶片总数 Z 的乘积相等**（`#L1524`）。例：六平直叶开启式涡轮（叶宽 $b$）≈ 叶宽 $3b$ 的二叶桨；两层四叶开启式涡轮 ≈ 叶宽 $4b$ 的二叶桨。这是把复杂叶轮折算成二叶桨的实用办法。

## 全挡板时的功率准数

1. 由式（2-28）算临界雷诺数 $Re_c$（`#L1536`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re_{c}=\dfrac{25}{b/D}\left(\dfrac{d}{D}-0.4\right)^{2}+\dfrac{b/D}{0.11(b/D)-0.0048}$ | （2-28） |
| **文字式** | $\text{临界雷诺数}=\dfrac{25}{\text{桨宽}/\text{釜内径}}\left(\dfrac{\text{叶轮直径}}{\text{釜内径}}-0.4\right)^{2}+\dfrac{\text{桨宽}/\text{釜内径}}{0.11\times(\text{桨宽}/\text{釜内径})-0.0048}$ |  |

2. 把 $Re_c$ 代回式（2-26），所得 $N_p$ 即全挡板的 $N_{p\max}$；低黏流体的启动功率也可用它算（`#L1538`）。
3. 倾角 $\theta$ 的折叶桨：$Re_{\theta}=10^{4(1-\sin\theta)}Re_{c}$，再代入式（2-26）得 $N_{p\max}$（`#L1540`）。

## 适用边界

- **多层叶轮不能用**：永田式未考虑层间距，有挡板时层间距影响显著（`#L1554`）。
- 内径 <1200 mm、$d/D<0.5$、无挡板时计算值与实际相符；内径 >1200 mm 时最大偏差可达 100%；全挡板、$d/D=0.35\sim0.5$、$b/D=0.1\sim0.25$、$\theta=45^{\circ}$ 时折叶桨偏差 <20%（`#L1564`）。
- 部分挡板另按 [[挡板系数与部分挡板]] 的插值式计算。

# 搅拌轴组合质量与离心力

## 组合质量

搅拌轴与各层搅拌器（含附件）的**组合质量**（`#L11846-#L11854`）：

悬臂轴：$m_{W1}=m_{L1}+\sum_{i=1}^{m}m_{i}$（9-43）；

单跨轴：$m_{W}=m_{L}+\sum_{i=1}^{m}m_{i}$（9-44）。

其中 $m_{L1}=\frac{\pi}{4}d_{L1}^{2}(1-N_{0}^{2})L_{1}\rho_{s}\times10^{-9}$ 为悬臂段轴质量，$m_{L}$ 为跨间段轴质量（符号说明 `#L11369-#L11375`）。

## 质量偏心引起的离心力

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{e}=\dfrac{\pi^{2}}{9}m_{W1}n^{2}[e]\left[\dfrac{1}{1-\left(\dfrac{n}{n_{cr}}\right)^{2}}\right]\times10^{-5}$ | （9-45） |
| **文字式** | $\text{离心力}_{\text{【N】}}=\dfrac{\pi^{2}}{9}\times\text{组合质量}_{\text{【kg】}}\times\text{转速}_{\text{【r/min】}}^{2}\times\text{许用偏心距}_{\text{【mm】}}\times\left[\dfrac{1}{1-\left(\dfrac{\text{转速}}{\text{临界转速}}\right)^{2}}\right]\times10^{-5}$ |  |

单跨轴同式，以 $m_{W}$ 代替 $m_{W1}$（9-46）。

**临界转速比初值**：刚性轴取 $(n/n_{cr})^{2}=0.5$，柔性轴取 $1.7$（`#L11864`）——因为 $F_{e}$ 与 $n_{cr}$ 互为隐式，先给初值迭代。

**为什么会有放大因子**：$1/[1-(n/n_{cr})^{2}]$ 是转子动力学中的**共振放大系数**，转速越接近临界转速，偏心引起的离心力被放大得越剧烈；$n/n_{cr}=0.7$ 时放大 1.96 倍，$0.9$ 时 5.26 倍。

## 许用偏心距 $[e]$

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[e]=9.55\dfrac{G}{n}$ |  |
| **文字式** | $\text{许用偏心距}_{\text{【mm】}}=9.55\times\dfrac{\text{平衡精度等级}_{\text{【mm/s】}}}{\text{转速}_{\text{【r/min】}}}$ |  |

平衡精度等级 $G$（`#L11868`）：

| 工况 | $G$/(mm·s⁻¹) |
|:---|:---:|
| 一般情况 | 6.3 |
| 操作压力高、转速高、危险物料（苛刻工况） | 2.5 |
| 操作压力低、转速低、一般物料 | 16 |

**含义**：$G$ 是许用不平衡度（质心速度），除以角速度即得许用偏心距；苛刻工况要求更小的偏心，故 $G$ 取 2.5。

## 组合重心距轴承的距离 $L_{e}$

悬臂轴：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $L_{e}=\dfrac{\sum\limits_{i=1}^{m}m_{i}L_{i}+m_{L1}\dfrac{L_{1}}{2}}{m_{W1}}$ | （9-47） |
| **文字式** | $\text{重心距}_{\text{【mm】}}=\dfrac{\sum\text{搅拌器质量}_{\text{【kg】}}\times\text{悬臂长度}_{\text{【mm】}}+\text{轴质量}_{\text{【kg】}}\times\dfrac{\text{悬臂长度}_{\text{【mm】}}}{2}}{\text{组合质量}_{\text{【kg】}}}$ |  |

单跨轴同式，以 $L/2$ 与 $m_{W}$ 代入（9-48）。

## 使用要点

1. $L_{e}$ 同时用于 $M_{R}$（式9-39/9-40）与径向位移（式9-60 起）——**一个量串起三处计算**。
2. 轴质量按**均质**取中点 $L_{1}/2$（或 $L/2$），因为假设轴段等直径（力学模型第 8 条）。
3. $[e]$ 与转速成反比：高转速轴对平衡要求更严，这也是高速搅拌轴必须做**动平衡**（见 [[搅拌器的技术要求]]）的原因。

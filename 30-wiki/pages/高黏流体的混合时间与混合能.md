# 高黏流体的混合时间与混合能

## 前提交代：小桨不行

高黏液体离开叶片一定距离后混合强度陡然下降，所以桨式/涡轮式/推进式这类小尺寸叶轮不适用；用错了就出现死角与停滞环，且长期与主体不相混（图4.20，`#L5380`、`#L5410`）。排序（`#L5412`）：

| 叶轮 | 能否均匀混合 | 适用场合 |
|:---|:---|:---|
| 锚式 | **不推荐**用于要求完全均匀 | 强化壁面传热、刮壁 |
| 框式 | 勉强（大尺寸） | 中黏 |
| 螺带式（R）、带导流筒螺杆式（Q） | **推荐**，能产生全釜循环 | 均匀混合，尤其拟塑性/宾汉塑性 |

## 转数判据：$N_{M}$ 就是"转几圈"

几何相似的螺带叶轮，黏度 1~400 P 与容器直径都不影响混合速率（`#L5414`、`#L5438`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $N_{M}=\theta_{M}n=k_{1}'\mu^{0}D^{0}$ | （4.22'） |
| **文字式** | $\text{无因次混合时间}=\text{混合时间}\times\text{转速}=\text{常数}$（与黏度、釜径无关） |  |

所以 $N_M$ 的物理身份是**完成混合所需的叶轮转数**，与转速高低无关。

## 循环时间与"三次循环"

循环时间与转速成反比，比例常数即 $k_2$（`#L5426`、`#L5434`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\theta_{c}n=k_{2}=\text{常数};\qquad \theta_{M}=\dfrac{k_{1}}{k_{2}}\theta_{c}=k_{3}\theta_{c}$ | （4.42）（4.43） |
| **文字式** | 循环时间 = 常数 ÷ 转速；混合时间 = $k_3$ × 循环时间 |  |

**$k_{3}\approx3$**（脱色法粗估，`#L5436`）：只要是循环式叶轮，不管型式，**三次循环后就完成宏观混合**。这条是全章最好用的工程判据——先算循环时间，再乘 3。

不同测量方法得到的 $k_3$ 不同，故它是"判据依赖"的量，与 §4.3.1 的判据敏感性同源。

## 混合能

由 $P=k\mu n d^{3}$ 与 $\theta_{M}=k_{1}/n$ 相乘（`#L5444`、`#L5448`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $E=P\theta_{M}=k\mu nd^{3};\qquad E_{v}=\dfrac{E}{\frac{\pi}{4}D^{3}}=k'\mu n$ | （4.44）（4.45） |
| **文字式** | $\text{混合能}=\text{常数}\times\text{黏度}\times\text{转速}\times\text{叶轮直径}^{3}$；单位体积混合能 ∝ 黏度 × 转速 |  |

关键张力（`#L5450`）：**在同样转速下混合速率与黏度无关（4.22'），但混合能正比于黏度（4.45）**。要加快混合只能提转速，而提转速就是按 $\mu n$ 线性加钱。

## 压头损失

用 $P=\gamma QH_{m}$ 与 $k_3=\theta_M Q/V$ 联立（`#L5462`、`#L5470`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $k_{3}=\dfrac{E}{\gamma H_{m}V}=\dfrac{k'\mu n}{\gamma H_{m}}\ \Rightarrow\ H_{m}=k''\mu n$ | （4.48）（4.49） |
| **文字式** | 循环压头损失 ∝ 黏度 × 转速；$k_3\approx3$ 时该式成立 |  |

所以**高黏混合的代价主要在摩擦压头**，选叶轮要选"同样 $P\theta_M$ 下压头损失更小"的结构（`#L5474`）。

## 最优几何

| 叶轮 | 螺距 | 叶宽 | 直径 |
|:---|:---|:---|:---|
| 双螺带（$n_p=2$） | $s=d$ | $b=0.1D$ | $d=0.95D$（`#L5488`） |
| 带导流筒螺杆式 | $s=d$ | 导流筒 $D'=0.7D$ | $d=0.95D$（`#L5492`） |

尺度判据（图4.23，Hoogendoorn）：层流域 $N_M$ 或 $E\theta_M/\mu D^{3}$ 近似常数（流型相似）；**湍流域里为高黏设计的叶轮效率极差**（`#L5496`、`#L5498`）——高黏叶轮不能跨区通用。

## 非牛顿体系

图4.24 对比多层桨式与螺带式（`#L5510`）：

- 螺带式：拟塑性液与宾汉塑性液（TiO₂ 泥浆）曲线**几乎重合**；
- 多层桨式：两者差距很大，且 $\theta_M$ 明显更长。

原因：多层桨以旋转流为主、垂直循环弱，示踪物只能靠桨叶剪切逐层传递；TiO₂ 泥浆中大量固体粒子之间会**滑动**，动量传递受阻，混合速度大减（`#L5516`）。

改进：在螺带中心轴上再加一根螺杆（Coyle），复合叶轮的输出流量按两个叶轮之和计（`#L5520`）。

**黏弹性液体反而更快**：Weissenberg 效应在局部产生二次流，而一般液体没有，故高黏黏弹性液体的混合要快得多（`#L5522`）。

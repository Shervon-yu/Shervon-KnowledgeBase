# 放大时的切应变速率变化

## 两条基本规律

| 量 | 与 $N$、$d$ 的关系 |
|:---|:---|
| 最大切应变速率 $\dot\gamma_{max}$ | $\propto Nd$（与转速、桨径**都**成正比） |
| 平均切应变速率 $\bar{\dot\gamma}$ | $\propto N$（几乎与桨径无关） |

（`#L3889`）

## 放大时的走向

几何相似放大、保持单位体积功率不变时：$N$ 下降、$d$ 增加。代入上表：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dot\gamma_{max}\propto Nd$；$\ \bar{\dot\gamma}\propto N$ | — |
| **文字式** | $\text{最大切应变速率}\propto\text{转速}\times\text{桨径}$；$\text{平均切应变速率}\propto\text{转速}$ |  |

- $Nd$ 在 $P_V$ 恒定时 $\propto d^{-1/3}$… 实际按 $N\propto d^{-2/3}$、$Nd\propto d^{1/3}$，即**最大切应变速率随放大而增大**；
- 平均切应变速率 $\propto N\propto d^{-2/3}$，**随放大而下降**。

图 4-1 给出两条曲线在放大时的交叉变化（`#L3891`）。

## 为什么这是大问题

1. 局部剪切变强 → 剪切敏感体系（乳液聚合、絮凝体、晶体）被打碎、破乳、粒径分布变宽；
2. 整体剪切变弱 → 混合、传质、传热变差；
3. 二者同向恶化：**大釜既更"局部暴力"又更"整体迟钝"**，这是放大效应的重要来源。

## 对策

1. 剪切敏感 → 降转速、增大桨径、改低剪切桨型（见 [[搅拌器流型与分类]]）；
2. 需要整体循环 → 多层桨、加大排量（见 [[放大因子与放大准则]]）；
3. 关键过程用冷模实测切应变速率分布，而不是只看 $P_V$。

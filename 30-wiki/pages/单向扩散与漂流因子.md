# 单向扩散与漂流因子

## 为什么吸收是"单向"扩散（`#L9110-#L9124`）

气液接触，A 溶于液相、B 不溶（液相中无 B）：
- A 在界面处被吸收 → 界面附近 $p_A$ 降低 → A 由主体向界面扩散；
- 界面处总压略低 → 混合气整体向界面移动（**整体移动**，bulk motion）；
- B 不被吸收，又随整体移动被带向界面 → 界面处 B 浓度升高 → B 反向扩散回主体；
- 稳态时 $J_B$ 与整体移动携带的 $N_{BM}$ 数值相等、方向相反：$J_B=-N_{BM}$，**B 表观静止**。

故称"组分 A 通过静止组分 B 的单方向扩散"。

## 速率方程的推导（`#L9126-#L9170`）

整体移动中 A、B 量之比等于分压之比，故 $N_{AM}=N_{BM}\,p_A/p_B$；A 的总传质 = 分子扩散 + 整体移动：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=J_A+N_{AM}=\left(1+\dfrac{p_A}{p_B}\right)J_A=-\dfrac{D}{RT}\dfrac{p}{p-p_A}\dfrac{\mathrm{d}p_A}{\mathrm{d}Z}$ | （5-17 的推导式 d） |
| **文字式** | $\text{总传质}=\text{分子扩散}+\text{整体移动}=\left(1+\dfrac{\text{A分压}}{\text{B分压}}\right)\times\text{分子扩散速率}$ |  |

沿 $Z$ 积分（$p_{A1}\to p_{A2}$、$p=p_A+p_B$ 恒定）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=\dfrac{D}{RTZ}\dfrac{p}{p_{Bm}}(p_{A1}-p_{A2})$ | （5-17） |
| **文字式** | $\text{传质速率}=\dfrac{\text{扩散系数}}{\text{气体常数}\times\text{温度}\times\text{距离}}\times\dfrac{\text{总压}}{\text{B分压对数均值}}\times\text{A分压差}$ |  |

其中

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p_{Bm}=\dfrac{p_{B2}-p_{B1}}{\ln(p_{B2}/p_{B1})}$ | （5-17 内定义） |
| **文字式** | $\text{B分压对数平均值}=\dfrac{\text{界面B分压}-\text{主体B分压}}{\ln(\text{界面B分压}/\text{主体B分压})}$ |  |

浓度形式（也适用于液相）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=\dfrac{D}{Z}\dfrac{c}{c_{Bm}}(c_{A1}-c_{A2})$ | （5-18） |
| **文字式** | $\text{传质速率}=\dfrac{\text{扩散系数}}{\text{距离}}\times\dfrac{\text{总浓度}}{\text{B浓度对数均值}}\times\text{A浓度差}$ |  |

## 漂流因子的含义（`#L9172`）

$p/p_{Bm}>1$，称**漂流因子**（drift factor）。它衡量整体移动在传质中的份额：

- $p/p_{Bm}$ 越大 → 整体移动贡献越大；
- 当 A 浓度很小（各处 $p_B\approx p$）→ $p/p_{Bm}\to1$ → 退化为等摩尔逆向扩散式；
- 物理意义：单向扩散比等摩尔扩散快 $p/p_{Bm}$ 倍，因为主体流动像"风"一样把 A 吹向界面。

## 例5-3（`#L9180-#L9196`）

20 ℃、101.325 kPa，CO₂-空气（$y_{A1}=0.2$）经 1 mm 静止空气层向 Na₂CO₃ 溶液扩散，界面上 $p_{A2}=0$，$D=0.18$ cm²/s：

- $p_{A1}=20.27$ kPa、$p_{B1}=81.06$ kPa、$p_{B2}=101.325$ kPa；
- $p_{Bm}=90.8$ kPa；
- $N_A=\frac{1.8\times10^{-5}}{8.314\times293\times0.001}\times\frac{101.325}{90.8}\times20.27=1.67\times10^{-4}$ kmol/(m²·s)。

## 判断

- 吸收、解吸一律用 5-17（或 5-18）；只有当溶质极稀（$p/p_{Bm}\approx1$）时才能偷懒用等摩尔式，否则会低估 10%~20% 甚至更多。
- 漂流因子是"对流传质增强"的分子级解释，但它只描述**膜内**的整体流动，不包括主体湍流；后者由对流传质系数处理。

# 列管式换热器的选用计算

## 管程/壳程的选择原则（`#L8066-#L8086`）

1. **不清洁或易结垢**的流体走易清洗侧：直管束走管程；U 形管束走壳程；
2. **腐蚀性**流体走管程（避免壳体与管束同时腐蚀）；
3. **压力高**的流体走管程（避免厚壳体）；
4. 需**提高流速**以增大 $\alpha$ 的流体走管程（管程流通面积小、易做多管程）；
5. 两流体温差大、固定管板式时，把 $\alpha$ 大的流体走壳程（减小管壁与壳体温差）；
6. **蒸气冷凝**走壳程（便于排冷凝液）；
7. 需冷却的流体走壳程（便于散热）；温度很高、热能要利用的流体走管程（减少热损失）；
8. **黏度大或流量小**的流体走壳程（折流挡板使 $Re>100$ 即可达湍流）。

八条常不能兼顾，按主要矛盾取舍，再用压降校核。

## 流速（`#L8088-#L8107`）

流速增大→$\alpha$ 增大、结垢减少，但阻力增大；压力降控制范围：液体 10~100 kPa、气体 1~10 kPa，对应 $Re$ 液体 $5\times10^3\sim2\times10^4$、气体 $10^4\sim10^5$。

表4-9 常用流速（m/s）：低黏液体 管程 0.5~3 / 壳程 0.2~1.5；易结垢液体 >1 / >0.5；气体 5~30 / 2~15。

表4-10 不同黏度液体在钢管中的最大流速（mPa·s → m/s）：>1500→0.6；1000~500→0.75；500~100→1.1；100~35→1.5；35~1→1.8；<1→2.4。

## 管子规格与排列（`#L8109-#L8131`）

- 管径：小管径单位体积传热面积大，清洁流体取小；黏度大或易结垢取大。常用 φ19×2、φ25×2、φ25×2.5；
- 管长系列：1.5、2、3、4.5、6、9 m；
- 排列：正三角形（紧凑、管数多、传热好、管外难清洗）；正方形直列/错列（管外清洗方便、$\alpha$ 略低，斜转 45° 可增强）。

## 壳程对流传热系数（`#L8151-#L8191`）

$Re=2\times10^3\sim10^6$、圆缺形挡板切去 25% 直径时：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Nu=0.36Re^{0.55}Pr^{1/3}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}$ | （4-67） |
| **文字式** | $\dfrac{\alpha d_e}{\lambda}=0.36\left(\dfrac{d_eu_0\rho}{\mu}\right)^{0.55}\left(\dfrac{c_p\mu}{\lambda}\right)^{1/3}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}$ |  |

当量直径（$t$ 为管中心距、$d_o$ 为管外径）：
- 正方形排列：$d_e=4\left(t^2-\frac{\pi}{4}d_o^2\right)/(\pi d_o)$；
- 正三角形排列：$d_e=4\left(\frac{\sqrt{3}}{2}t^2-\frac{\pi}{4}d_o^2\right)/(\pi d_o)$。

壳程流速按最大流通截面积：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $S=hD\left(1-\dfrac{d_o}{t}\right)$ | （4-69） |
| **文字式** | $\text{最大流通面积}=\text{挡板间距}\times\text{壳体内径}\times\left(1-\dfrac{\text{管外径}}{\text{管中心距}}\right)$ |  |

## 选型六步（`#L8195-#L8219`）

1. 掌握任务：流量、进出口温度、压力、腐蚀性/悬浮物、物性；
2. 算热负荷 $Q$；
3. 算 $\Delta t_m$（先按单壳程多管程，若 $\psi<0.8$ 增加壳程数）；
4. 经验取 $K$（表4-7）估 $A$；
5. 定管/壳程与流速 → 估单管程管数与管长 → 按系列标准选型号；
6. 分别算管程、壳程 $\alpha$，取污垢热阻求 $K$，与估值比较，差得多则重估；再算 $A$，要求 **10%~25% 余量**。

选型是反复试算过程，常需 2~3 次。

## 例4-27（`#L8221-#L8308`）

柴油 36000 kg/h、180→130 ℃ 走管程；油品 60→110 ℃ 走壳程。

1. $Q=1.24\times10^6$ W；
2. 逆流 $\Delta t_{m逆}=70$ ℃，$R=1.0$、$P=0.42$、$\psi=0.91$ → $\Delta t_m=63.7$ ℃；
3. 取 $K_估=250$ → $A_估=77.9$ m²；
4. 选 φ25×2.5、$u_1=1$ m/s → $n'=45$ 根、$L'=22$ m；4 管程、每程 6 m → 选 **BES600-2.5-90-6/25-4 Ⅰ**（$N=188$ 根、$n=47$、$t=32$ mm 正方形错列、$D=600$ mm、$h=200$ mm、挡板 29 块、$A_选=86.9$ m²）；
5. 校核：$\alpha_1=930$、$\alpha_2=530$（图4-53 查 $Nu Pr^{-1/3}(\mu/\mu_w)^{-0.14}=25$）、$K=267$；
6. $A=72.9$ m²，$A_选/A=1.19$ → 19% 裕量，可用。

## 载热体（`#L8310-#L8348`）

选择原则：满足温度、易调节、腐蚀小不结垢、不分解不易燃、价廉易得、传热性能好。

表4-11：加热剂——热水 40~100 ℃；饱和水蒸气 100~180 ℃（180 ℃ 对应 1.0 MPa，再高不经济，冷凝相变热大、$\alpha$ 大、易调节）；矿物油 <250 ℃（价廉、黏度大、$\alpha$ 小、>250 ℃ 易分解易燃）；联苯混合物（道生油，液 15~255 ℃、蒸气 255~380 ℃，温度范围宽、黏度比矿物油小）；熔盐（NaNO₃ 7%、NaNO₂ 40%、KNO₃ 53%）142~530 ℃；烟道气 500~1000 ℃（$\alpha$ 小）。冷却剂——冷水 15~20 ℃ 或 15~35 ℃（出口宜 ≤50 ℃ 以免结垢）；空气 <35 ℃（$\alpha$ 小）；冷冻盐水（CaCl₂）0~−15 ℃（成本高）。

## 判断

- 例4-27 的关键不是算术，而是"估值—选型—校核—面积裕量"的闭环：先按经验 $K$ 定尺寸，再用真实 $\alpha$ 反算 $K$，最后看裕量是否落在 10%~25%。裕量过大是浪费，过小则运行中结垢就能力不足。
- 管壳程八条原则互相冲突时（如"高压"要管程、"易结垢"要壳程），应按腐蚀/结垢/压力三者中最致命的那个决定，再用多管程或挡板弥补流速。

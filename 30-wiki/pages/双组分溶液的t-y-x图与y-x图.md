# 双组分溶液的 t-y-x 图与 y-x 图

## t-y-x 图（图6-1，`#L11028-#L11040`）

恒压（如 101.325 kPa）下测定汽液相平衡数据，绘成温度-组成图。以苯-甲苯为例：

- A、B 两点分别为苯（80.1 ℃）与甲苯（110.63 ℃）的沸点；
- 上方曲线 = **汽相线**（露点线）：$y$ 与平衡温度 $t$ 的关系，线上任一点为饱和蒸气；
- 下方曲线 = **液相线**（泡点线）：$x$ 与 $t$ 的关系，线上任一点为饱和液体；
- 汽相线以上 = 过热蒸气区；液相线以下 = 冷液区；两线之间 = **汽液共存区**。

**泡点** $t_1$：冷液恒压加热到开始起泡的温度，对应液相线；**露点** $t_2$：过热蒸气恒压冷却到开始析出液滴的温度，对应汽相线。

**核心事实**：平衡温度 $t$ 与总组成 $x_s$ 落在 S 点时，必分成互成平衡的两相，液相组成 $x$（L 点）、汽相组成 $y$（V 点），且 **$y>x$**——这是蒸馏能分离的原理基础。

## 杠杆定律（`#L11042-#L11044`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{L}{V}=\dfrac{\overline{VS}}{\overline{LS}}=\dfrac{y-x_s}{x_s-x}$ | （6-4） |
| **文字式** | $\dfrac{\text{液相摩尔量}}{\text{汽相摩尔量}}=\dfrac{\text{汽相点到总组成点的线段长}}{\text{总组成点到液相点的线段长}}=\dfrac{\text{汽相组成}-\text{总组成}}{\text{总组成}-\text{液相组成}}$ |  |

含义：两相量之比等于它们在 $t$-$y$-$x$ 图上到总组成点的**距离反比**（力臂反比）。

## y-x 图（图6-2，`#L11046-#L11052`）

恒压下互成平衡的 $y$ 与 $x$ 的关系曲线。

- 理想溶液 $y>x$ ⇒ 平衡曲线在**对角线 $y=x$ 上方**；
- 曲线离对角线越远 ⇒ 同一 $x$ 对应 $y$ 越大 ⇒ **越容易分离**；
- 曲线上每一点对应一个温度，因此每点的 $\alpha$ 不同（理想溶液变化不大，可近似取常数）。

## 两张图的分工

| 图 | 横纵坐标 | 主要用途 |
|:--|:--|:--|
| $t$-$y$-$x$ 图 | $x$、$y$ 对 $t$ | 读泡点/露点、判断相区、杠杆定律求两相量 |
| $y$-$x$ 图 | $y$ 对 $x$ | 精馏塔图解计算（操作线与平衡线同图） |

## 判断

- 蒸馏计算绝大多数在 $y$-$x$ 图上做，因为操作线与平衡线可以同图比较；$t$-$y$-$x$ 图主要用于读温度、定进料热状态与冷凝/再沸温度。
- 杠杆定律是"物料衡算的图形版"：它和后面精馏段的操作线方程本质相同，都是同一套衡算的两种表达。
- 若 $y$-$x$ 曲线与对角线相交（恒沸点），交点处 $\alpha=1$、普通精馏无法越过——这是判据一的来源。

# 填料层高度的基本计算式

## 为什么必须积分（`#L9830-#L9836`）

填料塔是连续接触设备，气液组成沿塔高连续变化 → 各截面推动力与传质速率都不同。所以不能"速率×面积"，只能取微元高度 $dZ$ 积分。

前提：只讨论**低浓度气体**（溶质组成 <0.1）的稳态吸收；高浓度时 G、L 沿塔变化，式子要修正。

## 微元衡算（`#L9838-#L9854`）

取微元高度 $dZ$，气液接触面积

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\mathrm{d}A=\Omega a\,\mathrm{d}Z$ | （5-58 内） |
| **文字式** | $\text{微元接触面积}=\text{塔截面积}\times\text{单位体积填料有效传质面积}\times\text{微元高度}$ |  |

$dZ$ 内传递的溶质量 = 气相减少 = 液相增多：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A a\Omega\,\mathrm{d}Z=G\,\mathrm{d}Y=L\,\mathrm{d}X$ | （5-58） |
| **文字式** | $\text{传质速率}\times\text{体积传质面积}=\text{惰性气体流量}\times\text{气相组成变化}=\text{吸收剂流量}\times\text{液相组成变化}$ |  |

## 基本微分式（`#L9856-#L9862`）

与速率方程联立（膜系数与总系数四种口径都成立）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\mathrm{d}Z=\dfrac{G\,\mathrm{d}Y}{K_Ya\Omega(Y-Y^{*})}=\dfrac{L\,\mathrm{d}X}{K_Xa\Omega(X^{*}-X)}=\dfrac{G\,\mathrm{d}Y}{k_Ya\Omega(Y-Y_i)}=\dfrac{L\,\mathrm{d}X}{k_Xa\Omega(X_i-X)}$ | （5-59） |
| **文字式** | $\text{微元高度}=\dfrac{\text{惰性气体流量}\times\text{气相组成微元}}{\text{体积传质系数}\times\text{塔截面积}\times\text{总推动力}}$（液侧同理） |  |

**体积传质系数**：$a$ 是单位体积填料的有效气液界面，既随设备与填料变，又随物性与流动状况变，直接测很难；故把 $a$ 与 $k$、$K$ 合成一体（$k_Ya$、$K_Ya$ 等），实验整体测定，单位 kmol/(m³·s)。低浓度时全塔可视为常数或取平均值。

## 积分式（`#L9864-#L9868`）

从塔顶积分到塔底：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Z=\dfrac{G}{K_Ya\Omega}\displaystyle\int_{Y_2}^{Y_1}\dfrac{\mathrm{d}Y}{Y-Y^{*}}=\dfrac{L}{K_Xa\Omega}\displaystyle\int_{X_2}^{X_1}\dfrac{\mathrm{d}X}{X^{*}-X}$（膜系数式同理） | （5-60） |
| **文字式** | $\text{填料层高度}=\dfrac{\text{惰性气体流量}}{\text{体积传质系数}\times\text{塔截面积}}\times\text{推动力倒数的积分}$ |  |

## 判断

- 积分式的物理读法：前面那团系数（$G/(K_Ya\Omega)$）是"设备与流体的传质能力"，后面那个积分是"分离任务的难度"。两者相乘就是塔高——这正是下一节拆成"传质单元高度×传质单元数"的由来。
- 不要把 $a$ 当已知量去反算 $K_Y$：实验测的都是 $K_Ya$ 整体，单独拆开既无必要也无可靠数据。

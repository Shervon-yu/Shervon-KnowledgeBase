# 干燥器的热效率

## 定义（派生量，非原文公式）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\eta_h=\dfrac{W r}{Q}\times100\%$ | （7-32 引申） |
| **文字式** | $\text{热效率}=\dfrac{\text{蒸发水分量}\times\text{汽化热}}{\text{总供热量}}\times100\%$ |  |

其中 $W$ 为蒸发水量、$r$ 为水在干燥温度下的汽化热、$Q=Q_P+Q_D$ 为总供热量（预热器 + 干燥器补充热）。

**说明**：书上没有单列"热效率"定义式，本页由（7-32）热量衡算的分配结果派生，属**判断/推导**，不是原文断言。

## 从例7-6 读出（`#L14257-#L14385`）

$Q_P$=143 kW 的分配：

- 加热空气本身（废气显热）96.1 kW，占 **67.1%**；
- 蒸发水分 44.3 kW，占 **30.8%**；
- 加热物料 3.03 kW，占 **2.1%**。

按上式计算 $\eta_h\approx30.8\%$——即约 2/3 的热量随废气排掉。预热温度提高到 100 ℃ 后，空气量降至 4820 kg/h、$Q_P$ 降至 117 kW，而水分蒸发量不变，故 $\eta_h$ 升到约 53%（$44.3/117$）。

## 为什么废气是主损失（`#L14255-#L14385`）

- 空气既是载热体又是载湿体：要带走 $W$ 就必须排走含湿废气，废气带走显热不可避免；
- 出气温度 $t_2$ 越高、风量 $G$ 越大，显热损失越大；
- 所以节能方向是"减少介质用量、部分废气再循环、提高进风温度（受物料耐热限制）、并流降低出口气温"。

## 判断

- 干燥器热效率典型值只有 30%~60%，比多数换热过程低，原因就是废气显热占比大。
- 把"提高进气温度"当作万能解药是错的：受物料热敏性与产品形态限制（见 [[干燥器的选用]]），且出口温度随之升高会抵消部分收益。
- 废气再循环同时提高热效率与改善产品质量（防开裂结壳），是干燥节能的首选手段。
- 若用废气余热预热进风，则热效率可进一步提高，但设备投资上升。

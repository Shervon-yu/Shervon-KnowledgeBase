# 管法兰的类型与密封面

## 定义

HGT 20592～20635-2009 中钢制管法兰按结构分 12 种类型（PN 系列）或 8~10 种类型（Class 系列），密封面分 7 种型式。选型时先按管系系列（PN/Class）、公称尺寸与压力等级查对应适用范围表，再按介质、温度和密封要求选密封面（#L927-#L1074）。

## 判据与计算

### PN 系列 12 种类型（HG/T 20592，#L927-#L1074）

| 代号 | 类型 | 备注 |
| :--- | :--- | :--- |
| PL | 板式平焊法兰 | 适用 PN2.5~PN40；禁用于易燃易爆和高度、极度危害介质（#L111-#L268） |
| SO | 带颈平焊法兰 | 颈部斜度 ≤7° |
| WN | 带颈对焊法兰 | PN10~PN160；锥颈 ≤45°＋直边段 ≤7° |
| IF | 整体法兰 | 与设备/管件整体成形 |
| SW | 承插焊法兰 | 颈部斜度 ≤7° |
| Th | 螺纹法兰 | 仅英制管，Rc/Rp/NPT 管螺纹 |
| PJ/SE | 对焊环松套法兰 | 腐蚀介质可省不锈钢 |
| PJ/RJ | 平焊环松套法兰 | 同上 |
| BL | 法兰盖 | — |
| BL(S) | 衬里法兰盖 | — |
| — | 孔板法兰 | 参照 ASME B16.36，PN10~PN160、DN25~DN600，仅突面 |
| — | 夹套法兰 | 参照 SH/T 3040，PN16~PN40、DN15×40~DN350×450，资料性附录 |

### 7 种密封面（#L1075-#L1319）

| 代号 | 名称 | 适用范围要点（表 3.2.2） |
| :--- | :--- | :--- |
| RF | 突面 | 各压力等级最常用 |
| FM/M | 凹面/凸面 | 成对使用 |
| T/G | 榫面/槽面 | 成对使用 |
| FF | 全平面 | 低压力、与铸铁法兰配合 |
| RJ | 环连接面 | 高温高压，≥Class600 常用 |

### Class 系列类型（HG/T 20615，#L8407-#L8509、#L8510-#L8777）

| 代号 | 类型 | 与 PN 系差异 |
| :--- | :--- | :--- |
| SO | 带颈平焊法兰 | 同 PN 系 |
| WN | 带颈对焊法兰 | 同 PN 系 |
| LWN | 长高颈法兰 | Class 系特有，颈高 229 mm（≤DN300） |
| SW | 承插焊法兰 | 同 |
| Th | 螺纹法兰 | Rc（GB/T 7306.2）/NPT（GB/T 12716） |
| LF/SE | 对焊环松套法兰 | 同 |
| IF | 整体法兰 | 同 |
| BL | 法兰盖 | 同 |

Class 系列无 PL、无 PJ/RJ；Class150~2500 对应 PN20~PN420；密封面突台高度 2 mm（≤Class300）/7 mm（＞Class300）（#L269-#L412）。

### 大直径法兰（HG/T 20623，#L11729-#L11758、#L11759-#L11890）

- 仅 WN 与 BL 两种类型，DN650~DN1500，A/B 两尺寸系列
- A 系列密封面 RF＋RJ；B 系列仅 RF
- 表面粗糙度：RF 为 Ra3.2~6.3；RJ 为 Ra0.4~1.6
- 突面为刀具自然锯齿形同心圆或螺旋齿槽，齿深约 0.05 mm、节距约 0.45 mm、刀具圆角 ≥1.5 mm
- 密封面缺陷允许尺寸（表 3.2.4）：DN650~900 为 12.5/6.0 mm；DN950~1200 为 14/7；DN1250~1500 为 16/8
- 螺栓支承面与密封面平行度 ≤1°

## 适用范围与边界

- 类型表只回答「有哪些、代号是什么」；具体 D/K/L/Th/n 连接尺寸与结构尺寸见 [[管法兰的连接尺寸与结构尺寸]]
- 材料与压力-温度额定值另见 HG/T 20592 第 4、7 章（本页未收录）
- 齿槽/缺陷数值为大直径法兰特有要求，小直径法兰不适用

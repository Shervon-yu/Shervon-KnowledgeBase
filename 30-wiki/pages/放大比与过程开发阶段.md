# 放大比与过程开发阶段

## 定义

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\text{放大比}=\dfrac{\dot m_{\text{工业}}}{\dot m_{\text{试验}}}$ | — |
| **文字式** | $\text{放大比}=\dfrac{\text{工业过程的生产速率}}{\text{试验规模的生产速率}}$ |  |

（`#L3837`）

## 经验取值

| 环节 | 放大比 |
|:---|:---|
| 实验室 → 中试 | 500~1000 |
| 中试 → 工业 | 不超过 200~500 |

放大比取决于对过程的理解深度：复杂过程取保守值；认识深入、基础数据完整时可取大值，甚至**一步放大**（`#L3839`）。

## 各阶段做什么

| 阶段 | 规模 | 重点 |
|:---|:---|:---|
| 小试 | 克~千克级 | 用尽量少的原料，理解基本特性、关键因素与可行性 |
| 模试/中试 | 数十升~ | 杂质影响、操作周期、设备可靠性、规模效应 |
| 模型演示 | 约真实过程 1/10 | 补充中试给不出的答案；费用昂贵、推迟工业化，非必要不做 |

（`#L3841`）

## 冷模与热模

- 冷模：有机玻璃釜 + 水/糖浆/CMC 等模拟物料，可直接观察流型；
- 热模：把冷模结果移植到真实物料与材质时的考核研究。

（`#L3845`）

## 判断

1. 资金与规模约成 **0.7 次方**关系（`#L3833`）——规模越大单位成本越低，这是放大的经济动机；
2. 中试不能替代全部答案，但能暴露"放大后才发现"的问题（如破乳、传热不足）；
3. 当代趋势：用计算减少中间环节（见 [[数模放大]]）。

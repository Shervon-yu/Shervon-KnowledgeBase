# 管外强制对流与自然对流

## 垂直流过管束（`#L6344-#L6382`）

管束排列分**直列**与**错列**。第一排两式相同；从第二排起，错列时流体受阻拦、湍动增强，故错列的 $\alpha$ 大于直列。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Nu=C\,\varepsilon\,Re^{n}Pr^{0.4}$ | （4-24） |
| **文字式** | $\text{努塞尔数}=\text{系数}C\times\text{排数修正}\varepsilon\times\text{雷诺数}^{n}\times\text{普朗特数}^{0.4}$ |  |

- 适用范围 $Re=5\times10^3\sim7\times10^4$，$x_1/d=1.2\sim5$，$x_2/d=1.2\sim5$；
- 流速取**最窄通道处**流速；定性温度取进出口平均；特征尺寸取管外径 $d$；
- 表4-3：直列第 1 排 $n=0.6$、$\varepsilon=0.171$，第 2 排起 $n=0.65$、$\varepsilon=0.157$；错列第 1 排同，第 2 排 $\varepsilon=0.228$、第 3 排起 $0.290$；$C$：$x_1/d=1.2\sim3$ 时 $C=1+0.1x_1/d$，$x_1/d>3$ 时 $C=1.3$。

各排 $\alpha$ 不同，管束平均按面积加权：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha_m=\dfrac{\sum\alpha_iA_i}{\sum A_i}$ | （4-25） |
| **文字式** | $\text{平均对流传热系数}=\dfrac{\sum\text{各排系数}\times\text{各排外表面积}}{\sum\text{各排外表面积}}$ |  |

## 大空间自然对流（`#L6384-#L6426`）

定义：传热壁面置于很大空间内，由壁温与周围流体温度差引起自然对流，周围无阻碍物（如管路/设备表面与大气之间）。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Nu=C(Gr\,Pr)^{n}$ | （4-26） |
| **文字式** | $\text{努塞尔数}=\text{系数}C\times\left(\text{格拉晓夫数}\times\text{普朗特数}\right)^{n}$ |  |

$Gr$ 中 $\Delta t=t_w-t$；定性温度取**膜温** $(t_w+t)/2$。

表4-4（部分）：水平圆管 $d<0.2$ m，$GrPr=10^4\sim10^9$ 时 $C=0.53$、$n=1/4$；$10^9\sim10^{12}$ 时 $C=0.13$、$n=1/3$；$<10^4$ 时 $C=1.09$、$n=1/5$。垂直管或板 $l<1$ m 的三段同理（$C=1.36/0.59/0.10$，$n=1/5,1/4,1/3$）。

**例4-9**：垂直蒸气管 φ152×4.5、长 0.5 m、外壁 110 ℃、空气 20 ℃：定性 65 ℃，$Gr=8.57\times10^8$、$GrPr=5.96\times10^8$，查表 $C=0.59$、$n=1/4$，$\alpha=0.59\times0.0293/0.5\times(5.96\times10^8)^{1/4}=5.39$ W/(m²·K)；$Q=\alpha\pi dl\Delta t=116$ W。

## 判断

- 错列优于直列的原因不是"面积更大"，而是"流道被迫转弯→湍动增强→有效膜变薄"，这与管内入口效应、弯管效应同源。
- 自然对流的 $GrPr$ 分段（$10^4$、$10^9$、$10^{12}$）实质是层流边界层→过渡→湍流边界层的分区；分段处 $C$、$n$ 的跳变就是流态改变的标志。

# 填料腔的结构与尺寸计算

## 四种填料腔结构（`#L12584-#L12590`）

| 图号 | 结构 | 特点与适用 |
|:---|:---|:---|
| 图10-5 | **简单填料腔** | 无液封环、无冷却室；仅用于**转速不高、介质腐蚀性不大**的室温类设备 |
| 图10-6 | **带液封环填料腔** | 腔壁设注液孔，注入润滑油或与设备内高压介质连通；介质含纤维/沉淀物时接**洁净冲洗液**；搅拌设备少用，多用于离心泵 |
| 图10-7 | **带冷却室填料腔** | 腔外冷却液循环，压盖也冷却（防热传入轴承）；用于**高温介质**，搅拌设备常用 |
| 图10-8 | **高温高压介质填料腔** | 填料部位注入冷却液冷却并循环；用于**不允许泄漏**的液体和气体，搅拌设备常用 |

## 填料腔设计四原则（`#L12574-#L12582`）

1. 容易加工；
2. 散热有效，接通冷却液方便；
3. 留有液封孔口，位置恰当，便于与高压封液相联通；
4. 转轴应与机械密封**可互换**。

## 填料圈数（表10-5，`#L12612`）

| 运动方式 | 介质压力/MPa | 填料圈数 z |
|:---|:---|:---|
| 旋转 | 0.1 | 4~5 |
| 旋转 | 0.5 | 5~7 |
| 旋转 | 1 | 6~8 |
| 往复 | <1 | 3~4 |
| 往复 | 1~3.5 | 4~5 |
| 往复 | 3.5~7 | 5~6 |
| 往复 | 7~10 | 6~7 |
| 往复 | >10 | 7~8 或更多 |

**注**：搅拌设备用旋转轴，按前三行取。

## 填料宽度

填料宽度 $w$ 按**图10-9**（填料腔尺寸选择图）由轴径查取，与轴径大小有关（`#L12606`）；腔的尺寸主要靠长期使用经验确定。

## 尺寸计算（图10-10，`#L12627-#L12637`）

| 量 | 公式 |
|:---|:---|
| 填料腔内径 | $D=d+2w$ |
| 填料总宽度 | $L=nw$（$n$ 为填料圈数） |
| 腔深（无液封环） | $L_{1}=nw+(5\sim10)\,\mathrm{mm}$，或 $L_{1}=1.2nw$ |
| 腔深（有液封环） | $L_{1}=(n+2)w+(5\sim10)\,\mathrm{mm}$ |

**公差与粗糙度**：

- 填料腔内壁表面粗糙度 $R_{a}=3.2\sim1.6\ \mu\mathrm{m}$；
- 与压盖的配合一般取 **H11/d11**，要求较高时 **H8/f9** 已足够；
- 填料腔内端面可为**垂直于轴线的平面**，也可为**斜面**。

**深度余量**：总深度还要加上压盖填入填料腔的深度，一般取 5~10 mm；往复运动轴配合应更深一些（`#L12608`）。

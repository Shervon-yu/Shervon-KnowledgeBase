# 锥形封头的加强面积与折边段

锥壳与圆筒连接处是**几何突变 + 刚度差**，内压或外压下都有一个"边缘影响区"，标准用面积法（加强面积）或厚度法（折边过渡段）解决。

## 一、内压：无折边锥壳的加强面积（7.6.4.3）

### 判定（表7-5）

按 $p_c/([\sigma]^t\varphi)$ 查表7-5 得需加强指数 $\Delta$（$p_c/([\sigma]^t\varphi)$=0.001 → 9.5°；0.010 → 9°；0.02 → 12.5°；>0.255 取 45°）。**$\Delta<\alpha$ 处需加强；$\Delta\ge\alpha$ 不需加强。**

### 大端（式7-18、7-19）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_{rL}=\dfrac{kQ_LD_{iL}\tan\alpha}{2[\sigma]_s^t\varphi}\left(\dfrac{1-\Delta}{\alpha}\right)$；$\quad A_{eL}=0.55(\delta_n-\delta-C)\sqrt{D_{iL}\delta_n}+0.55(\delta_{nc}-\delta_c-C)\sqrt{D_{iL}\delta_{nc}/\cos\alpha}$ | （7-18）（7-19） |
| **文字式** | $\text{需要加强面积}=\dfrac{k\times Q_L\times D_{iL}\times\tan\alpha}{2\times\text{圆筒许用应力}\times\varphi}\times\left(1-\dfrac{\Delta}{\alpha}\right)$；$\text{有效加强面积}$=圆筒侧与锥壳侧各取 $0.55\times$有效厚度$\times\sqrt{D_{iL}\times\text{厚度}}$ 之和 |  |

校核 $A_{eL}\ge A_{rL}$。可用加强截面须位于距连接处 $\sqrt{D_{iL}\delta_n/2}$ 范围内，且形心在 $\pm0.25\sqrt{D_{iL}\delta_n/2}$ 内。

### 小端（式7-20、7-21）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_{rs}=\dfrac{kQ_sD_{is}\tan\alpha}{2[\sigma]_s^t\varphi}\left(\dfrac{1-\Delta}{\alpha}\right)$；$\quad A_{es}=0.55(\delta_n-\delta-C)\sqrt{D_{is}\delta_n}+0.55(\delta_{nc}-\delta_c-C)\sqrt{D_{is}\delta_{nc}/\cos\alpha}$ | （7-20）（7-21） |
| **文字式** | 同上，把 $D_{iL}$ 换成小端 $D_{is}$ |  |

小端接法兰/平盖，或连接圆筒长度 $<\sqrt{D_{is}\delta_n}$ 时（式7-22、7-23，加强面积须**全部落在锥壳上**）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_{rs}=\dfrac{kQ_sD_{is}\tan\alpha}{2[\sigma]_c^t\varphi}$；$\quad A_{es}=0.55(\delta_{nc}-\delta_c-C)\sqrt{D_{is}\delta_{nc}/\cos\alpha}$ | （7-22）（7-23） |
| **文字式** | 需要加强面积不再乘 $\left(1-\Delta/\alpha\right)$，且许用应力改用锥壳材料 |  |

## 二、内压：折边锥壳过渡段（7.6.5）

### 大端（式7-24、7-25）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_r=\dfrac{Kp_cD_{iL}}{2[\sigma]_c^t\varphi-0.5p_c}$；$\quad \delta_r=\dfrac{fp_cD_{iL}}{[\sigma]_c^t\varphi-0.5p_c}$，$f=\dfrac{1-\frac{2r}{D_{iL}}(1-\cos\alpha)}{2\cos\alpha}$ | （7-24）（7-25） |
| **文字式** | 过渡段厚度与相接锥壳厚度分别按 K、f 系数计算，取**较大值** |  |

- K 按 α 与 $r/D_{iL}$ 查表7-6（例：α=30°、$r/D_{iL}$=0.10 → K=0.7544；α=60°、0.10 → 1.3500）；
- f 按 α 与 $r/D_{iL}$ 查表7-7，也可用式7-25 的显式计算（例：α=30°、0.10 → 0.5619）。

### 小端（7.6.5.2）

α≤45° 时按式7-16 计算、$Q_2$ 查图7-16；α>45° 时仍用式7-16、$Q_2$ 查图7-17。与过渡段相接的锥壳、圆筒加强段厚度**与过渡段相同**；加强段长度：锥壳侧 $L_1\ge\sqrt{D_{is}\delta_r/\cos\alpha}$，圆筒侧 $L\ge\sqrt{D_{is}\delta_r}$。

## 三、外压锥壳（7.6.6）

### 当量长度

|  |  |  |
|:---|:---:|---|
| **符号式** | $L_e=\dfrac{L_x}{2}\left(1+\dfrac{D_s}{D_L}\right)$ | （7-26） |
| **文字式** | $\text{当量长度}=\dfrac{\text{锥壳段轴向长度}}{2}\left(1+\dfrac{\text{小端外径}}{\text{大端外径}}\right)$ |  |

大端折边加 $(r+\delta_r)\sin\alpha$（式7-27），小端折边加 $r_s\frac{D_s}{D_L}\sin\alpha$（式7-28），两端都折边用式7-29。

### 校核步骤（7.6.6.2）

1. 假设名义厚度 $\delta_{nc}$；
2. 折算有效厚度 $\delta_{ec}=(\delta_{nc}-C)\cos\alpha$；
3. 按 6.3 外压法校核，用 $L_e/D_L$ 代替 $L/D_o$、$D_L/\delta_{ec}$ 代替 $D_o/\delta_e$；
4. 外压加强法仅适用于 $Q_L,Q_s$ 为压缩（正值）的情况。

### 外压大端加强面积（式7-30、7-31）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_{rL}=\dfrac{kQ_LD_{oL}\tan\alpha}{2[\sigma]_s^t\varphi}\left[1-\dfrac{1}{4}\left(\dfrac{p_cD_{oL}-2Q_L}{2Q_L}\right)\dfrac{\Delta}{\alpha}\right]$；$\quad A_{eL}=0.55(\delta_n-C)\sqrt{D_{oL}\delta_n}+0.55(\delta_{nc}-C)\sqrt{D_{oL}\delta_{nc}/\cos\alpha}$ | （7-30）（7-31） |
| **文字式** | 与内压式结构相同，但以 $D_{oL}$ 为基准、Δ 查表7-8（$p_c/([\sigma]_s^t\varphi)$=0 → 0°；0.005 → 7°；0.02 → 15°；0.08 → 29°） |  |

## 判断

- 面积法 vs 厚度法的分工：**无折边**用面积法（把多余材料折算成截面积补足边缘弯矩），**折边**用厚度法（让过渡段本身足够厚），两者不可混用；
- $A_r$ 里那个 $\left(1-\Delta/\alpha\right)$ 因子说明：需要的加强面积随"需加强角度"递减——$\Delta$ 越接近 α，加强需求越小，到 $\Delta=\alpha$ 归零，与判定条件自洽；
- 小端接法兰/平盖时面积只能落在锥壳上、且不乘折减因子，是因为圆筒侧无处放材料；
- 外压锥壳的 $\delta_{ec}$ 乘了 $\cos\alpha$，是**把锥面折算成等效圆柱面**——锥壳的周向失稳波长比同等厚度圆筒短。

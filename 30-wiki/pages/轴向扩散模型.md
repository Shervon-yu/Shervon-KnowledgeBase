# 轴向扩散模型

## 模型方程

把返混看成"轴向的费克扩散"，叠加在活塞流上（`#L6136`、`#L6150`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{\partial C}{\partial t}=D_t\dfrac{\partial^{2}C}{\partial x^{2}}-u\dfrac{\partial C}{\partial x}$ | （5.22） |
| **文字式** | 浓度随时间的变化 = 返混扩散项 − 平推流项 |  |

$D_t$（cm²/s）称**分散系数**或**返混扩散率**，是定量表征混合程度的单参数。只保留扩散项即式(5.21)（随坐标系 $X=x-ut$ 移走的观察者看到的纯扩散）。

## 边界条件与解

Danckwerts 边界条件（适用于"容器内混合强于器外"，`#L6158`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $x=0:\ D_t\left(\dfrac{\partial C}{\partial x}\right)_{0+}=uC_{0+}-uC_i;\qquad x=L:\ \left(\dfrac{\partial C}{\partial x}\right)_{L-}=0$ | （5.23）（5.24） |
| **文字式** | 入口：扩散通量与对流进料平衡；出口：浓度梯度为零（无回流） |  |

解得出口年龄分布为无穷级数（5.25），其中 $\mu_n$ 是式(5.26) $\cot\mu=\frac{1}{2}\left(\frac{\mu}{M}-\frac{M}{\mu}\right)$ 的第 $n$ 个实根。

## 唯一的参数 M

|  |  |  |
|:---|:---:|---|
| **符号式** | $M=\dfrac{Lu}{2D_t}=\dfrac{Pe}{2}$ | （5.27） |
| **文字式** | $\text{混合强度参数}=\dfrac{\text{活塞流项}}{2\times\text{返混扩散项}}$，即彼克列数的一半 |  |

判据：**$M$ 越大越接近活塞流，$M\to0$ 趋于完全混合**（图5.12）。

## 带反应的版本

稳态下把反应项 $\psi(C)$ 加进去（`#L6198`、`#L6210`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\overline{D_t}\dfrac{\mathrm{d}^{2}C}{\mathrm{d}x^{2}}-u\dfrac{\mathrm{d}C}{\mathrm{d}x}+\psi(C)=0$ | （5.31） |
| **文字式** | 稳态：扩散项 − 对流项 + 反应项 = 0 |  |

一级反应有解析解，令

|  |  |  |
|:---|:---:|---|
| **符号式** | $p=\left[1+\dfrac{2k_1\theta}{M}\right]^{1/2}$ | （5.34） |
| **文字式** | 反应-返混的合成参数；其中 $2k_1\theta$ 只关反应速率，$M$ 只关混合强度 |  |

则出口浓度（5.35）：

$$\frac{C_e}{C_i}=\frac{4\,p\,e^{2M}}{(1+p)^{2}e^{M(1+p)}-(1-p)^{2}e^{M(1-p)}}$$

**$M$ 越大转化越多**（`#L6234`）。零级/一级以外无解析解，二级反应（5.36）只能用数值解（图5.16）。

## 容积效率：数字最有用

一级反应、同样转化率下所需容积比（`#L6250`、`#L6254`）：

| 转化率 | 所需 $k_1\theta$：活塞流 vs 完全混合 | 完全混合/活塞流容积比 |
|:---|:---|:---|
| 50% | 0.69 vs 1.0 | **1.4** |
| 90% | 2.30 vs 9.0 | **3.91** |
| 99% | 4.61 vs 99 | **≈22** |

**这就是"高转化率必须抑制返混"的量化依据**——要求 99% 时，一个完全混合釜要顶 22 个活塞流釜的容积。

多级叶轮立式反应器（图5.13）横截面湍流不均匀，只能用**平均**扩散系数（`#L6190`）。

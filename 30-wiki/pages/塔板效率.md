# 塔板效率

## 全塔效率（`#L13105-#L13121`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $E_0=N_{理}/N_{实}$ | （6-67） |
| **文字式** | $\text{全塔效率}=\dfrac{\text{理论板数}}{\text{实际板数}}$ |  |

恒小于 1。影响它的因素很多（物性、板结构、操作），**可靠数据只能靠实验测定**。

**O'Connell 关联**：用 $\alpha\mu_L$（相对挥发度 × 进料液黏度，$\mu_L$ 单位 mPa·s，取塔顶塔底平均温度）关联 $E_0$；适用于泡罩塔与碳氢化合物精馏，可作粗估。

## 单板效率（莫弗里效率，`#L13123-#L13149`）

以汽相表示：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $E_{MV}=\dfrac{y_n-y_{n+1}}{y_n^{*}-y_{n+1}}$ | （6-68） |
| **文字式** | $\text{单板效率}=\dfrac{\text{实际板汽相组成增高值}}{\text{理论板汽相组成增高值}}$ |  |

以液相表示：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $E_{mL}=\dfrac{x_{n-1}-x_n}{x_{n-1}-x_n^{*}}$ | （6-69） |
| **文字式** | $\text{单板效率}=\dfrac{\text{实际板液相组成降低值}}{\text{理论板液相组成降低值}}$ |  |

$y_n^{*}$ 为与 $x_n$ 平衡的汽相组成；$x_n^{*}$ 为与 $y_n$ 平衡的液相组成。$E_{MV}$ 与 $E_{mL}$ 一般不相等，通常实验测定。

## 例6-21（`#L13151-#L13161`）

全回流下测得 $x_{n-1}$=0.75、$x_n$=0.60、$\alpha$=2.5：

- 全回流 → $y_n=x_{n-1}=0.75$；
- $x_n^{*}=\frac{0.75}{2.5-1.5\times0.75}=0.545$；
- $E_{mL}=\frac{0.75-0.60}{0.75-0.545}=0.732$。

## 判断

- 全塔效率是"平均折算系数"，单板效率是"逐板真实程度"；工程先用 $E_0$ 从 $N_{理}$ 折 $N_{实}$，再按单板效率校核关键板。
- O'Connell 图只适用泡罩塔与碳氢物系，用它估算其他体系（如含水物系）会有系统性偏差——只能作为初设。
- 单板效率低通常源于：接触时间短、液面落差大、漏液或液沫夹带；提高气速可改善到某点，超过则夹带反噬。

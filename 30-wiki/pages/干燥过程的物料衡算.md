# 干燥过程的物料衡算

## 两种含水量（`#L14127-#L14143`）

**湿基含水量 $w$**：水分质量/湿物料总质量，kg 水/kg 湿料。生产上常用。

**干基含水量 $X$**：水分质量/绝干物料质量，kg 水/kg 干料。干燥计算用。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $X=\dfrac{w}{1-w}$，$w=\dfrac{X}{1+X}$ | （7-25） |
| **文字式** | $\text{干基含水量}=\dfrac{\text{湿基含水量}}{1-\text{湿基含水量}}$；$\text{湿基含水量}=\dfrac{\text{干基含水量}}{1+\text{干基含水量}}$ |  |

**为什么用干基**：干燥中绝干物料质量不变，$X$ 与 $w$ 相比更便于守恒与相减。

## 物料衡算三式（`#L14145-#L14177`）

绝干物料守恒：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $L_c=L_1(1-w_1)=L_2(1-w_2)$ | （7-26） |
| **文字式** | $\text{绝干料流量}=\text{进料流量}\times(1-\text{进料湿基}) =\text{产品流量}\times(1-\text{产品湿基})$ |  |

水分衡算（蒸发量同时等于空气增湿量）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $W=L_c(X_1-X_2)=G(H_2-H_1)$ | （7-27） |
| **文字式** | $\text{蒸发水量}=\text{绝干料流量}\times(\text{进料干基}-\text{产品干基}) =\text{干空气流量}\times(\text{出气湿度}-\text{进气湿度})$ |  |

干空气消耗量：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $G=\dfrac{W}{H_2-H_1}$，$\dfrac{G}{W}=\dfrac{1}{H_2-H_1}$ | （7-28）（7-29） |
| **文字式** | $\text{干空气流量}=\dfrac{\text{蒸发水量}}{\text{出气湿度}-\text{进气湿度}}$；$\text{单位空气消耗量}=\dfrac{1}{H_2-H_1}$ |  |

## 关键结论（`#L14177`）

- $H_1$ 越大，单位空气消耗量越大 → 按**夏季**空气湿度定全年最大风量，据此选鼓风机。
- 选风机要把质量流量换成标定状态（20 ℃、101.325 kPa）的体积流量：$q_V=G\,v_H$。

## 例7-5（`#L14179-#L14209`）

$L_1$=800 kg/h、$w_1$=30%、$w_2$=4%；空气 15 ℃/50% → 预热 120 ℃ → 出 45 ℃/80%。

- $L_c$=560、$X_1$=0.429、$X_2$=0.042 → $W$=216.7 kg/h；
- $H_0$=$H_1$=0.005、$H_2$=0.052 → $G$=4610 kg 干气/h，湿空气 4633；
- $v_H$=0.836 m³/kg → $q_V$=3850 m³/h。

## 判断

- $w$ 与 $X$ 的差别在含水量高时极大：$w$=0.5 对应 $X$=1，直接用 $w$ 相减会算错蒸发量。
- 单位空气消耗量 $1/(H_2-H_1)$ 说明"空气的载湿能力"决定风量——提高 $H_2$（出气更湿）可省风量，但受物料与露点限制。
- 预热器不改变 $H$，故 $H_1=H_0$，这是例7-5 能直接算的前提。

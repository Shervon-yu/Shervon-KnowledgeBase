# 搅拌侧传热膜系数关联式

## 一般形式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha_1=a\dfrac{\lambda}{L}\left(\dfrac{\rho Nd^{2}}{\mu}\right)^{b}\left(\dfrac{C_p\mu}{\lambda}\right)^{c}\left(\dfrac{\mu}{\mu_w}\right)^{m}$ | （7-48） |
| **文字式** | $\text{物料侧膜系数}=\text{系数}\times\dfrac{\text{热导率}}{\text{定性长度}}\times\left(\text{搅拌雷诺数}\right)^{b}\times\left(\text{普朗特数}\right)^{c}\times\left(\text{黏度比}\right)^{m}$ |  |

（`#L7398-#L7418`；L 为定性长度，m；N 单位 r/min；$C_p$ 单位 kJ/(kg·K)）

## 标准釜（关联式的前提）

常数 $a$ 含几何因素，故关联式只在**几何相似**时可用；无特殊说明时由标准釜得出（`#L7420-#L7428`）：

| 几何比 | 数值 |
|:---|:---|
| $D/d$（釜径/桨径） | 3 |
| $H/D$（液面高/釜径） | 1 |
| $C/d$（离底高/桨径） | 1 |

| 搅拌器 | 传热面 | Re 范围 | L | a | b | c | m |
|:---|:---|:---|:---:|:---:|:---:|:---:|:---:|
| 平桨（二叶、四叶） | 夹套 | 300~3×10⁵ | D | 0.36 | 0.67 | 0.33 | 0.21 |
| 平直叶涡轮（挡板） | 夹套 | 10~10⁵ | D | 0.73 | 0.65 | 0.33 | 0.24 |
| 斜叶涡轮 | 夹套 | 80~200 | D | 0.53 | 0.67 | 0.33 | 0.24 |
| 平直圆盘涡轮 | 夹套 | 40~3×10⁵ | D | 0.54 | 0.67 | 0.25 | 0.14 |
| 推进式 | 夹套 | ~2×10⁵ | D | 0.54 | 0.67 | 0.25 | 0.14 |
| 三叶后掠式 | 夹套 | ~2×10⁵ | D | 0.37 | 0.67 | 0.33 | 0.14 |
| 锚式 | 夹套 | 10~300 | D | 1.0 | 0.5 | 0.33 | 0.18 |
| 锚式 | 夹套 | 300~4000 | D | 0.36 | 0.67 | 0.33 | 0.18 |
| 螺带式 | 夹套 | ~10⁵ | D | 0.633 | 0.5 | 0.33 | 0.18 |

## 非标准釜的两条修正

推进式（永田，`#L7455`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha_1=0.33\dfrac{\lambda}{D}Re^{2/3}Pr^{1/3}\left(\dfrac{d}{D}\right)^{-0.25}\left(\dfrac{C}{D}\right)^{0.15}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}$ | （7-49） |
| **文字式** | 其余项同上表，只把几何影响拆成 $(d/D)$ 与离底高度比 $(C/D)$ 两项 |  |

带挡板、釜内无盘管、桨式与涡轮式、$Re>100$（永田统一式，`#L7463`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha_1=1.40\dfrac{\lambda}{D}Re^{2/3}Pr^{1/3}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}\left(\dfrac{d}{D}\right)^{-0.3}\left(\dfrac{\sum b_i}{D}\right)^{0.45}n_p^{0.2}\left(\dfrac{\sum C_i}{iH}\right)^{0.2}(\sin\theta)^{0.5}\left(\dfrac{H}{D}\right)^{-0.6}$ | （7-50） |
| **文字式** | 叶宽、叶片数、各桨离底高、倾角、液面高都被显式修正 |  |

（$b_i$ 桨叶宽，$n_p$ 叶片数，$C_i$ 各桨离底高，$i$ 桨叶数，H 液面高，$\theta$ 桨叶倾角）

## 一个"功率不敏感"的通用式

桨式与涡轮式、湍流域、容器外壁为夹套（7-51）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha=0.512\dfrac{\lambda}{D}\left(\dfrac{P_mD^{4}}{\gamma^{3}}\right)^{0.227}Pr^{0.33}\left(\dfrac{d}{D}\right)^{0.52}\left(\dfrac{b}{D}\right)^{0.08}$ | （7-51） |
| **文字式** | $\text{膜系数}=0.512\times\dfrac{\text{热导率}}{\text{釜径}}\times\left(\dfrac{\text{单位质量功率}\times\text{釜径}^4}{\text{运动黏度}^3}\right)^{0.227}\times Pr^{0.33}\times\left(\dfrac{\text{桨径}}{\text{釜径}}\right)^{0.52}\times\left(\dfrac{\text{叶宽}}{\text{釜径}}\right)^{0.08}$ |  |

（`#L7485-#L7493`；$P_m$ 单位 W/kg，$\gamma$ 单位 m²/s）

特点：与搅拌器型式、安装高度、叶片数、倾角、有无盘管**均无关**，可用于平桨、锚式、涡轮、推进、三叶后弯、螺带，有/无挡板皆可；因指数 0.227 < 0.25，$P_m$ 差 90% 时 α 只差约 20%——**对功率估算精度要求低**。

## 原书 §2.1：无挡板容器的一整套关联式

原书把夹套侧传热写成 10 个变量的函数（式2.1，`#L2632`）：$Nu_{j}=f(Re,Pr,\mu/\mu_{w},d/D,b/D,c/D,H/D,n_{p},B,\sin\theta)$，再分三种容器逐一给式（`#L2636`）。

### 无挡板 + 内装冷却蛇管（容器1）

$Re>100$ 时（式2.2，`#L2660`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{h_{j}D}{k}=0.51\left(\dfrac{d^{2}n\rho}{\mu}\right)^{2/3}\left(\dfrac{C_{p}\mu}{k}\right)^{1/3}\left(\dfrac{\mu}{\mu_{w}}\right)^{0.14}\left(\dfrac{d}{D}\right)^{-0.25}\left(\dfrac{\Sigma b_{i}}{D}\right)^{0.15}\left(n_{p}\right)^{0.16}\left(\dfrac{\Sigma C_{i}}{iH}\right)^{0.15}\left(\sin\theta\right)^{0.5}$ | （2.2） |
| **文字式** | $\text{夹套侧努塞尔数}=0.51\times\text{搅拌雷诺数}^{2/3}\times\text{普朗特数}^{1/3}\times\text{黏度比}^{0.14}\times\left(\dfrac{\text{桨径}}{\text{釜径}}\right)^{-0.25}\times\left(\dfrac{\text{各桨叶宽之和}}{\text{釜径}}\right)^{0.15}\times\text{叶片数}^{0.16}\times\left(\dfrac{\text{各桨离底高之和}}{\text{桨数}\times\text{液面高}}\right)^{0.15}\times\left(\sin\text{桨叶倾角}\right)^{0.5}$ |  |

$H/D$ 的指数为 0，正常液位下可略去（`#L2714`）。蛇管尺寸在表2.4 范围内变（$D_{e}=210\sim240$ mm、管间距 10~20 mm）对 $h_{j}$ **没有影响**（`#L2716`）。

### 多层叶轮可当成"一片合并的叶轮"

两个同轴六叶涡轮的传热近似式（2.2′，`#L2691`）：$h_{i}\propto\left(\Sigma b_{i}\right)^{0.15}\left(\Sigma C_{i}/iH\right)^{0.15}$——**i 层叶轮等价于一片宽度取各桨之和、高度取各桨平均位置的叶轮**。表2.3（`#L2697`）给出 12 组几何的系数，都在 0.48~0.57（$d/D=0.5$、$b/D=0.2$ 单桨时为 0.55）。

### 无蛇管、夹套直接通冷却水（容器2）

水为介质时（式2.6，`#L2768`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{h_{j}D}{k}=0.75\left(\dfrac{d^{2}n\rho}{\mu}\right)^{2/3}\left(\dfrac{C_{p}\mu}{k}\right)^{1/3}\left(\dfrac{\mu}{\mu_{w}}\right)^{0.14}\left(\dfrac{d}{D}\right)^{-0.14}\left(\dfrac{b}{D}\right)^{0.14}\left(\dfrac{C}{H}\right)^{0.15}$ | （2.6） |
| **文字式** | $\text{夹套侧努塞尔数}=0.75\times\text{搅拌雷诺数}^{2/3}\times\text{普朗特数}^{1/3}\times\text{黏度比}^{0.14}\times\left(\dfrac{\text{桨径}}{\text{釜径}}\right)^{-0.14}\times\left(\dfrac{\text{叶宽}}{\text{釜径}}\right)^{0.14}\times\left(\dfrac{\text{离底高}}{\text{液面高}}\right)^{0.15}$ |  |

叶片数、倾角、层数、液位的影响与容器1 差别不大，把式(2.2) 的 0.51 换成 **0.54** 即可互算——**蛇管屏蔽只带来约 6% 的差别**（`#L2770`）。

### 有挡板时两者相等

有挡板时容器1 与容器2 的 $h_{j}$ **相等**，因为挡板的影响远大于蛇管屏蔽（`#L2774`）。$Re>100$ 的最终式为式（2.7）= 手册式（7-50）：

$Nu_{j}=1.40Re^{2/3}Pr^{1/3}\left(\mu/\mu_{w}\right)^{0.14}\left(d/D\right)^{-0.3}\left(\Sigma b_{i}/D\right)^{0.45}n_{p}^{0.2}\left(\Sigma C_{i}/iH\right)^{0.2}\left(\sin\theta\right)^{0.5}\left(H/D\right)^{-0.6}$（`#L2782`）

以 $d/D=1/2$、$C/H=1/2$、$b/D=1/10$ 的六叶涡轮为例：容器1 有挡板比无挡板**高 35%**，容器2 **高 25%**（`#L2786`）。注意这与 §2.2 的结论相反——**挡板不提高冷却蛇管本身的 $h_{c}$**。

### 别人给的三个式子与适用边界

| 作者 | 式 | 形式差异 |
|:---|:---:|---|
| Kraussold | （2.3）`#L2720` | $0.36\,Re^{2/3}Pr^{1/2}(\mu/\mu_{w})^{0.14}$，不含几何项，$Pr$ 指数取 1/2 |
| Pursell | （2.4）`#L2724` | $0.112\,Re^{3/4}Pr^{0.44}(\mu/\mu_{w})^{0.14}(d/D)^{-0.14}(b/D)^{0.13}$，$Re$ 指数 3/4 |
| Murakami | （2.5）`#L2758` | $0.46\,Re^{2/3}Pr(\mu/\mu_{w})^{0.14}(d/D)^{-0.1}\left(d\sin\theta\,n_{p}/H\right)^{0.15}$ |

- Pursell/Uhl 的数据与曲线偏差大，因为 $Re$、$Pr$ 指数与他人不同；把 $Re$ 指数统一为 2/3 后全体数据都落在式(2.2) 上（`#L2726`、`#L2736`）。
- **Hoechst 的数据低于曲线**：他用 $b/D=0.7$ 的大桨，流型接近锚式，数据反而与锚式关联一致（`#L2738`）。
- 挡板在 $Re<200$ 时不提高 $h_{j}$（Brook），因为流动既未湍流化也未到达器壁；**故式(2.2)、式(2.7) 都不能用到 $Re<100$**（`#L2788`、`#L2790`）。

## 判断

"标准釜"三比值是所有关联式的暗含前提：$D/d=3$ 意味着 $d/D\approx0.33$。实际设计常用 $d/D=0.4\sim0.5$，直接套表7-8 会偏保守或偏危险，必须用 7-49/7-50 这类带几何修正的式子，或至少按幂次估算偏差。

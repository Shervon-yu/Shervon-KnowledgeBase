# 离心泵的特性曲线与比例定律

## 特性曲线（`#L3449-#L3469`）

$H$、$P$、$\eta$ 与 $q_V$ 的关系曲线，在额定转速、标定状况（101.325 kPa、20 ℃ 清水）下实测，样本附有。

| 曲线 | 规律 | 操作含义 |
|:---|:---|:---|
| $H-q_V$ | 一般随 $q_V$ 增大而减小；平坦型流量变而压头稳、陡降型压头变而流量稳 | 按管路需要选曲线形状 |
| $P-q_V$ | 随 $q_V$ 增大而增大，**$q_V=0$ 时 $P$ 最小** | **启动时关出口阀**，减小启动电流 |
| $\eta-q_V$ | 先升后降，有最高点 | 最高点=设计工况点，最高效率以下 7% 为高效区 |

额定点：最高效率点对应的流量称额定流量。

## 比例定律（`#L3471-#L3479`）

同一泵、同一液体、效率不变，转速由 $n_1$ 变 $n_2$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{q_{V2}}{q_{V1}}=\dfrac{n_2}{n_1},\qquad \dfrac{H_2}{H_1}=\left(\dfrac{n_2}{n_1}\right)^2,\qquad \dfrac{P_2}{P_1}=\left(\dfrac{n_2}{n_1}\right)^3$ | （2-5） |
| **文字式** | $\dfrac{\text{流量}_2}{\text{流量}_1}=\dfrac{\text{转速}_2}{\text{转速}_1},\quad \dfrac{\text{扬程}_2}{\text{扬程}_1}=\left(\dfrac{\text{转速}_2}{\text{转速}_1}\right)^2,\quad \dfrac{\text{轴功率}_2}{\text{轴功率}_1}=\left(\dfrac{\text{转速}_2}{\text{转速}_1}\right)^3$ |  |

适用范围：转速变化**小于 20%** 时效率基本不变。

## 黏度影响（`#L3485-#L3493`）

黏度大于水时：流量减小（叶轮内流速降低）、扬程减小（摩擦损失增大）、轴功率增大（盖板与液体摩擦）、效率下降。**运动黏度 $\nu>20\times10^{-6}$ m²/s 时特性参数需换算**（查泵专著）。

## 密度影响（`#L3495-#L3501`）

- $q_V$：叶轮出口截面积×径向速度，与密度无关 → **不变**；
- $H$：$(p_2-p_1)$ 与 $\rho$ 成正比、$\rho g$ 也与 $\rho$ 成正比，比值不变 → **不变**；
- $P$：$P=q_V\rho gH/\eta$ → **随密度正比增大**。

## 判断

- 比例定律的三次方关系意味"降转速 20%，功率只剩 51%"——这是变频调速节能的物理基础。
- 密度对 $H$ 无影响但压力表读数会变，这是最容易混淆的一点：扬程是"液柱米数"，压力是"帕"。

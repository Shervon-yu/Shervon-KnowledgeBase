# 传质系数的各种表示与换算

## 一张表看全（`#L9578-#L9584`）

同一 $N_A$，四种口径写成一行：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=k_G(p_A-p_i)=k_L(c_i-c_A)=K_G(p_A-p_A^{*})=K_L(c_A^{*}-c_A)$ | （5-43） |
| **文字式** | $\text{传质速率}=\text{气膜系数}\times\text{气膜分压差}=\text{液膜系数}\times\text{液膜浓度差}=\text{气相总系数}\times\text{气相总分压差}=\text{液相总系数}\times\text{液相总浓度差}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=k_y(y-y_i)=k_x(x_i-x)=K_y(y-y^{*})=K_x(x^{*}-x)$ | （5-44） |
| **符号式** | $N_A=k_Y(Y-Y_i)=k_X(X_i-X)=K_Y(Y-Y^{*})=K_X(X^{*}-X)$ | （5-45） |

三行分别对应"分压/浓度""摩尔分数""摩尔比"三种推动力；每行的左两项是膜系数，右两项是总系数。

## 换算关系（`#L9586-#L9600`）

浓度口径 → 分压/浓度口径：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $k_y=pk_G$，$k_x=ck_L$，$K_y=pK_G$，$K_x=cK_L$ | （5-46） |
| **文字式** | $\text{摩尔分数口径的系数}=\text{总压（或总浓度）}\times\text{分压（或浓度）口径的系数}$ |  |

摩尔比口径：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $k_Y=\dfrac{k_y}{(1+Y)(1+Y_i)}$，$k_X=\dfrac{k_x}{(1+X_i)(1+X)}$；$K_Y=\dfrac{K_y}{(1+Y)(1+Y^{*})}$，$K_X=\dfrac{K_x}{(1+X^{*})(1+X)}$ | （5-47） |
| **文字式** | $\text{摩尔比系数}=\dfrac{\text{摩尔分数系数}}{(1+\text{主体比})(1+\text{界面（或平衡）比})}$ |  |

低浓度时简化为 $k_Y\approx k_y\approx pk_G$、$k_X\approx k_x\approx ck_L$、$K_Y\approx K_y\approx pK_G$、$K_X\approx K_x\approx cK_L$。

总阻力与分阻力（`#L9596-#L9600`）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{1}{K_G}=\dfrac{1}{k_G}+\dfrac{1}{Hk_L}$，$\dfrac{1}{K_L}=\dfrac{H}{k_G}+\dfrac{1}{k_L}$，$K_G=HK_L$ | （5-48） |
| **文字式** | $\text{气相总阻力}=\text{气膜阻力}+\text{液膜阻力（除以}H\text{）}$；$\text{液相总阻力}=\text{气膜阻力（乘}H\text{）}+\text{液膜阻力}$ |  |

同理（5-49）用 $k_y,k_x,m$：$\frac{1}{K_y}=\frac{1}{k_y}+\frac{m}{k_x}$，$mK_y=K_x$；（5-50）用 $k_Y,k_X,m$：$\frac{1}{K_Y}=\frac{1}{k_Y}+\frac{m}{k_X}$，$mK_Y=K_X$。

## 三条硬规矩（`#L9604-#L9610`）

1. **范畴对应**：膜系数配膜推动力，总系数配总推动力，不可混搭。
2. **单位对应**：系数单位 = 传质速率单位 ÷ 推动力单位，写成 kmol/(m²·s·[推动力])；无量纲推动力（如 $\Delta Y$）不写单位。
3. **只适用单截面**：这些式子给的是塔内某一截面的速率，全塔各截面推动力不同，不能直接乘面积算总量——全塔要积分（下一节）。

## 判断

- 换算最容易错的是 $H$ 与 $m$ 的方向：$1/(Hk_L)$ 是液膜项折算到**气相分压**口径，$H/k_G$ 是气膜项折算到**液相浓度**口径；记不住就回到 $p^{*}=c/H$、$p^{*}=Ex=mp$ 重新推一遍。
- 做题时先定推动力口径，再选系数，最后核单位——按这个顺序几乎不会错。

# 双臂捏合机

## 结构（`#L18505`）

两个在**方形槽**中反向转动的叶片；槽底为两个纵向半圆柱面（**鞍形截面**）；叶片一端或两端由齿轮传动；上部有盖与加料口。卸料方式三种：底部开门/阀、倾斜卸料（手动/机械/液压）、螺杆连续排料。鞍形钢槽为夹套式，可通加热或冷却介质；高精度混合室可抽真空排出水分与挥发物。

## 混合作用（`#L18515`）

主体运动、刮抹、张拉、叠合、切分，以及物料被叶片、鞍形面、侧壁拉挤时的复合作用叠加。叶片倾斜使物料**头对头循环**并向下翻过鞍脊。叶片外缘与混合室壁间隙约 **1 mm**。

## 相切 vs 搭接（关键选择，`#L18515-#L18527`）

| 项 | 相切式 | 搭接式 |
|:---|:---|:---|
| 外缘运动迹线 | 相切 | 相交 |
| 旋转方向 | 可同向可异向 | 只能同速同向 |
| 速比 | 1.5:1、2:1、3:1 | 1:1 |
| 强剪切区 | 两处（叶片相切处 + 叶片-壁间隙） | 一处（叶片-壁间隙） |
| 优势 | 相对位置不断变化，分散混合更快；单位体积刮擦传热面积大、带料少 | 相交区物料交叉运动，分布混合更有效；可避免黏料附着叶片 |
| 适合 | **分散混合为主**；片状/条状/块状料 | **分布混合为主**；粉状、糊状、高黏液态 |

## 五种叶片（图16-3，`#L18529-#L18541`）

| 叶片 | 特点 | 适用 |
|:---|:---|:---|
| (a) 西格马（Sigma） | 应用最广；液体/固体/混合物中均可启动；正面改进可增撕拉与滑移；易卸料、不易黏附 | 通用 |
| (b) 分散叶片 | 正面把物料楔入叶片与槽之间（不是刮抹），压挤与剪切更强 | 微细颗粒在黏性物中分散；胶料易附着，需撞杆保持物料在混合区 |
| (c) 多刮片搭接（MWOL） | 先把物料切成小碎片再增塑 | 难启动的胶性混合物；黏性强时卸料清洗困难 |
| (d) 单曲线叶片 | 专为纤维增强塑料研制 | 必须先用聚合物润湿纤维，避免玻璃纤维折断 |
| (e) 双铧叶片 | 不易「架桥」，叶片上保持大块物料 | 易架空、易架桥的物料 |

## 规格与功率（`#L18543`）

| 参数 | 范围 |
|:---|:---|
| 工作容积 | 2.7~3800 L |
| 驱动功率 | 0.37~234 kW |
| 单位容积功率 | 33~400 kW/m³ |
| 叶片转速 | 10~35 r/min（小型取高值） |

## 国产系列（表16-1，`#L18545-#L18569`）

NH 系列（如皋）：容量 5~2000 L；拌桨转速 33.23~45.30 r/min（双速）；主电机 0.75~45 kW；蒸汽压力 0.3 MPa、电加热 1~32.4 kW、真空型 0.094 MPa、压力型 0.45/0.35 MPa；质量 300~6500 kg。

## 国外典型数据（表16-2，`#L18571-#L18586`）

Baker Perkins 倾斜型两端驱动、尺寸号 4~23：工作容量 0.7~1000 gal（2.6~3785 L）、最大 1~1500 gal、功率 1~300 hp（0.75~224 kW）；换算 in×0.3048→m、gal×3.78×10⁻³→m³、hp×0.746→kW。工作容量指达到或接近叶片顶部时的容量，总容量是充满到与槽顶相平时的容积。

## 判断

- 选型第一步是**相切还是搭接**，不是容积：分散为主选相切（两处剪切区），分布为主选搭接（交叉运动）。
- 单位容积功率 33~400 kW/m³ 跨度极大，说明「同容积不同物料」的功率需求差一个数量级，不能按容积估功率。
- 表16-1 的转速为双速（如 33/23），实际是两种速比切换，不是无级调速。

# 吸收塔-物料衡算与最小液气比

## 定义

吸收塔的计算以**全塔物料衡算**为骨架：惰性气体流量 $G$（kmol/(m²·s) 或 kmol/h，以惰性组分为基准）、吸收剂流量 $L$、进出口摩尔比 $Y_{1},Y_{2},X_{1},X_{2}$（#L9676）。塔内任一截面的气液组成关系称**操作线**（#L9684）。**最小液气比** $(L/G)_{\min}$ 是使塔底达到平衡（传质推动力为零）时的液气比，实际取 $(1.1\sim2.0)(L/G)_{\min}$（#L9744、#L9750）。**回收率** $\eta$ 表示溶质被吸收的分数（#L9718）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{L}{G}=\dfrac{Y-Y_{2}}{X-X_{2}}$，$Y=\dfrac{L}{G}X+\left(Y_{2}-\dfrac{L}{G}X_{2}\right)$ | （5.4-1） |
| **文字式** | $\text{液气比}=\dfrac{\text{气相摩尔比}-\text{塔顶气相摩尔比}}{\text{液相摩尔比}-\text{塔顶液相摩尔比}}$ |  |

（式 5-51、5-52，操作线方程，#L9680、#L9684；$L/G$ 为操作线斜率。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\eta=\dfrac{Y_{1}-Y_{2}}{Y_{1}}=1-\dfrac{Y_{2}}{Y_{1}}$ | （5.4-2） |
| **文字式** | $\text{回收率}=\dfrac{\text{进塔气相摩尔比}-\text{出塔气相摩尔比}}{\text{进塔气相摩尔比}}$ |  |

（式 5-54，#L9718。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{L}{G}\right)_{\min}=\dfrac{Y_{1}-Y_{2}}{X_{1}^{*}-X_{2}}$ | （5.4-3） |
| **文字式** | $\text{最小液气比}=\dfrac{\text{进塔气相摩尔比}-\text{出塔气相摩尔比}}{\text{与进塔气相平衡的液相摩尔比}-\text{进塔液相摩尔比}}$ |  |

（式 5-55，#L9744；$X_{1}^{*}$ 为与 $Y_{1}$ 平衡的液相组成。平衡线为直线 $Y^{*}=mX$ 且为稀溶液时化简为式 5-57：$(L/G)_{\min}=(Y_{1}-Y_{2})/(Y_{1}/m-X_{2})$，#L9754。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{A}}a\Omega\,\mathrm{d}Z=G\,\mathrm{d}Y=L\,\mathrm{d}X$ | （5.4-4） |
| **文字式** | $\text{传质通量}_{\text{【mol/(m²·s)】}}\times\text{比表面积}_{\text{【m²/m³】}}\times\text{塔截面积}_{\text{【m²】}}\times\mathrm{d}\text{塔高}_{\text{【m】}}=\text{气相流量}\times\mathrm{d}\text{气相摩尔比}$ |  |

（式 5-58，微元塔高的物料衡算，#L9854；积分后得塔高式，见 [[吸收-传质单元数与单元高度]]。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta Y_{\mathrm{m}}=\dfrac{\Delta Y_{1}-\Delta Y_{2}}{\ln\dfrac{\Delta Y_{1}}{\Delta Y_{2}}}$，$N_{\mathrm{OG}}=\dfrac{Y_{1}-Y_{2}}{\Delta Y_{\mathrm{m}}}$ | （5.4-5） |
| **文字式** | $\text{对数平均推动力}=\dfrac{\text{塔底推动力}-\text{塔顶推动力}}{\ln\dfrac{\text{塔底推动力}}{\text{塔顶推动力}}}$，$\text{气相总传质单元数}=\dfrac{\text{进出口摩尔比之差}}{\text{对数平均推动力}}$ |  |

（式 5-72、5-73，#L9986、#L9990；当 $\Delta Y_{1}/\Delta Y_{2}\le2$ 时可取算术平均，式 5-74、5-75，#L9998、#L10002。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{OG}}=\dfrac{1}{1-\dfrac{mG}{L}}\ln\left[\left(1-\dfrac{mG}{L}\right)\dfrac{Y_{1}-mX_{2}}{Y_{2}-mX_{2}}+\dfrac{mG}{L}\right]$ | （5.4-6） |
| **文字式** | $\text{气相总传质单元数}=\dfrac{1}{1-\text{吸收因数}}\ln\left[\left(1-\text{吸收因数}\right)\times\dfrac{\text{塔底推动力}}{\text{塔顶推动力}}+\text{吸收因数}\right]$ |  |

（式 5-76，解析解，#L10020；吸收因数 $=L/(mG)$。式 5-77 是其与回收率、液气比的等价写法，#L10048。）

## 适用范围与边界

- 操作线为直线的前提是**惰性气体流量与吸收剂流量沿塔不变**（忽略溶解引起的体积变化），即稀溶液吸收（#L9680）。
- 最小液气比对应「塔底达平衡」，此时所需塔高无限；实际液气比由经济权衡取 $(1.1\sim2.0)$ 倍最小值（#L9750）。
- 式 5-76 仅适用于**平衡线为直线**；曲线平衡线须用图解积分或数值积分（#L9900 的 $N_{OG}$ 积分式）。
- 本页不做塔高尺寸计算，塔高 $Z=H_{OG}N_{OG}$ 见 [[吸收-传质单元数与单元高度]]。

# 导流筒的结构与安装尺寸

## 作用

导流筒是上下开口的圆筒，装在釜内起导流作用（`#L7833`）：

- 提高搅拌程度、加强搅拌器对流体的直接剪切；
- 造成定向循环流，使液体都经过筒内强混合区；
- 限定循环路径，**减少短路**。

主要用于推进式、螺杆式、涡轮式搅拌器的导流（`#L7837`）。

## 基本几何

| 项目 | 规定 |
|:---|:---|
| 分流面 | 导流筒把釜截面分成**面积相等**的两部分 |
| 直径 | 约为釜径的 70% |
| 流向 | 筒内向下、筒外向上 |
| 涡轮/桨式 | 导流筒置于桨叶**上方** |
| 推进式 | 筒套在桨叶外，或略高于桨叶 |
| 上端 | 低于静液面，筒身开孔/槽，液面下降后仍能进液 |
| 下端 | 桨在筒下且釜径大时，下端缩小，开口小于桨径 |

（`#L7837`）

## 推进式 + 导流筒（图8-6）

| 参数 | 取值 |
|:---|:---|
| 桨径 $d$ | $(0.3\sim0.33)D$ |
| 液深 $H$ | $0.75H_1$ |
| 桨离底 $C$ | $1.2d$ |
| $C_1$ | $0.8d$ |
| 筒内径 $d_1$ | $1.1d$ |
| $h_1$ | $d_1$ |
| $h_2$ | $0.5H_2$ |
| $h_3$（筒直段高） | = 搅拌器轮毂高度 |

## 螺杆式 + 导流筒（图8-7，较优组合）

| 比值 | 范围 |
|:---|:---|
| $D/d_r$ | $1.6\sim1.99$ |
| $d/d_r$ | $0.93\sim0.95$ |
| $p/d_r$ | $0.944\sim0.984$ |

| $L/d_r$ | $0.984\sim1.51$ |
| $L_r/d_r$ | $1.3$ |

（`#L7861-#L7871`；$d$ 螺杆直径，$D$ 釜径，$d_{to}$ 筒外径，$d_t$ 筒内径，$L_t$ 筒高，$L$ 螺旋面高，$H_1$ 液深，$C_r$ 筒底离釜底高度，$p$ 螺距）

## 判断

"截面积相等 → 筒径约 0.7D"是唯一一条硬约束，其余都是与桨型的配合关系。注意螺杆组合里 $d/d_r\approx0.94$：螺杆与导流筒内径几乎贴死，间隙很小——这是为了把回流短路压到最低，与锚式追求小间隙是同一个道理。

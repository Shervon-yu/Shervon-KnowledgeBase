# 非金属平垫片的材料与使用条件

## 定义

非金属平垫片是 HGT 20592～20635-2009 垫片六类中的第一类，按 HG/T 20606（PN 系）/HG/T 20627（Class 系）执行。本页收录 20606 第 3 章的材料种类、材料要求、使用条件与密封面适用范围（#L4872-#L4893）。

## 判据与计算

### 材料种类（#L4872-#L4893）

| 类别 | 材料 |
| :--- | :--- |
| 橡胶 | 天然橡胶 NR、氯丁 CR、丁苯 SBR、丁腈 NBR、三元乙丙 EPDM、氟橡胶 FKM |
| 石棉 | 石棉橡胶板（GB/T 3985）、耐油石棉橡胶板（GB/T 539） |
| 非石棉 | 非石棉纤维橡胶板 |
| PTFE | 聚四氟乙烯板、膨胀或填充改性 PTFE |
| 石墨 | 增强柔性石墨板 |
| 云母 | 高温云母复合板 |

注：非石棉纤维橡胶板＝有机/无机纤维与橡胶高温压延；增强柔性石墨板＝304/316/316L 冲齿或冲孔不锈钢板＋柔性石墨层；高温云母复合板＝316 双向冲齿不锈钢板＋云母层（#L4872-#L4893）。

### 材料要求（#L4894-#L4922）

- 橡胶板：硬度邵尔 A 70±5、拉伸强度 ≥10 MPa、扯断伸长率按表 3.2.1（CR/NBR/EPDM/FKM 分别规定）
- 石棉橡胶板按 GB/T 3985、GB/T 539；PTFE 板按 QB/T 3625—1999 SFB-2（有冷流倾向，须注意工况与密封面型式）
- 增强柔性石墨板符合 JB/T 6628；膨胀/填充改性 PTFE 与非石棉纤维橡胶板须注明厂商牌号并确认 p×T 值

### 使用条件（表 3.3，#L4923-#L4952）

| 材料 | 代号 | 压力上限 | 温度范围 ℃ | 最大 p×T |
| :--- | :--- | :--- | :--- | :--- |
| 天然橡胶 | NR | ≤PN16 | -50~+80 | 60 |
| 氯丁橡胶 | CR | ≤PN16 | -20~+100 | 60 |
| 丁苯橡胶 | SBR | ≤PN16 | -20~+90 | 60 |
| 丁腈橡胶 | NBR | ≤PN16 | -20~+110 | 60 |
| 三元乙丙橡胶 | EPDM | ≤PN16 | -30~+140 | 90 |
| 氟橡胶 | FKM | ≤PN16 | -20~+200 | 90 |
| 石棉橡胶板 | XB350/XB450 | ≤PN25 | -40~+300 | 650 |
| 非石棉纤维橡胶板 | NAS | ≤PN40 | -40~+290（无机纤维）/ -40~+200（有机纤维） | 960 |
| 聚四氟乙烯板 | PTFE | ≤PN16 | -50~+100 | — |
| 膨胀/填充改性 PTFE | ePTFE/RPTFE | ≤PN40 | -200~+200 | — |
| 增强柔性石墨板 | RSB | PN10~63 | -240~+650（氧化性介质 -240~+450） | — |
| 高温云母复合板 | — | PN10~63 | -196~+900 | — |

注 d：超过表列温度范围或饱和蒸汽压大于 1.0 MPa（表压）使用时，应确认具体产品适用条件（#L4949）。

### 密封面适用范围（表 3.4，#L4953-#L4965）

| 密封面 | 适用 PN |
| :--- | :--- |
| 全平面 FF | 2.5~16 |
| 突面 RF | 2.5~63 |
| 凹凸面 FM/M | 10~63 |
| 榫槽面 T/G | 10~63 |

### 选用与选配（#L4966-#L4975）

- 选用考虑操作介质、工况（压力温度）、密封面型式与粗糙度、螺栓载荷；临界场合咨询供应商（#L4966-#L4969）
- 与法兰及紧固件的选配按 HG/T 20614 执行（#L4970-#L4975）

## 适用范围与边界

- 本页为 20606（PN 系）口径；20627（Class 系）材料体系相同但代号/表格编号不同，需用时回查原文
- p×T（压力×温度）是垫片材料的适用包络，选用时不得超过表 3.3 限值
- 尺寸、标记（第 4、6 章）不在本页，另见相关页或回查原文

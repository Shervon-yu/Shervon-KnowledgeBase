# 物质导数与速度散度

## 物质导数的定义（§2.3）

跟踪一个运动流体微团，其密度从 $t_1$ 时刻的 $\rho_1$ 变到 $t_2$ 时刻的 $\rho_2$。对泰勒展开取 $t_2\to t_1$ 的极限，得到物质导数（《计算流体力学基础及其应用》§2.3，#L930-#L996）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{D}\rho}{\mathrm{D}t}=\dfrac{\partial\rho}{\partial t}+u\dfrac{\partial\rho}{\partial x}+v\dfrac{\partial\rho}{\partial y}+w\dfrac{\partial\rho}{\partial z}$ | （2-2） |
| **文字式** | $\text{物质导数}_{\text{【密度】}}=\text{当地导数}_{\text{【密度】}}+\text{速度}_x\times\dfrac{\partial\text{密度}}{\partial x}+\text{速度}_y\times\dfrac{\partial\text{密度}}{\partial y}+\text{速度}_z\times\dfrac{\partial\text{密度}}{\partial z}$ |  |

写成算子与向量形式（同节 #L994-#L1006）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{D}}{\mathrm{D}t}\equiv\dfrac{\partial}{\partial t}+(\boldsymbol{V}\cdot\nabla)$ | （2-5） |
| **文字式** | $\text{物质导数算子}=\text{当地导数算子}+(\text{速度向量}\cdot\nabla\text{算子})$ |  |

- $\mathrm{D}/\mathrm{D}t$ 跟踪运动微团；$\partial/\partial t$ 固定空间点；$\boldsymbol{V}\cdot\nabla$ 是微团从一点运动到另一点、因流场空间不均匀引起的变化（#L1008）。
- 书里用"进山洞被雪球击中"解释两项叠加：进洞变凉对应迁移导数，雪球造成瞬时降温对应当地导数（#L1014）。

## 与全导数等价（§2.3）

因 $\rho=\rho(x,y,z,t)$，全微分 $\mathrm{d}\rho$ 除以 $\mathrm{d}t$ 并代入 $\mathrm{d}x/\mathrm{d}t=u$ 等，得到与式（2-2）完全相同的式子（式 2-7～2-9，#L1016-#L1034）。结论：物质导数就是对时间的全导数；物理意义由式（2-2）的推导给出。

## 速度散度的物理意义（§2.4）

对随流体运动的控制体，表面面元 $\mathrm{d}\boldsymbol{S}$ 在 $\Delta t$ 内扫出的体积增量是 $(\boldsymbol{V}\Delta t)\cdot\mathrm{d}\boldsymbol{S}$（式 2-10）。对表面积分、再对 $\Delta t$ 求极限并用散度定理（#L1042-#L1066）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\nabla\cdot\boldsymbol{V}=\dfrac{1}{\delta\mathcal{V}}\dfrac{\mathrm{D}(\delta\mathcal{V})}{\mathrm{D}t}$ | （2-14） |
| **文字式** | $\text{速度散度}=\dfrac{1}{\text{微团体积}}\times\dfrac{\text{微团体积的物质导数}}{\text{时间}}$ |  |

即速度散度是**单位体积运动流体微团的体积相对变化率**（#L1080）。这是推导连续性方程时"体积变化率"一项的来源；不可压流动 $\nabla\cdot\boldsymbol{V}=0$ 即微团体积不变。

## 适用边界

- 物质导数对任意流场变量成立（$p$、$T$、$u$ 等），式（2-6）给出温度的展开（#L1010）。
- 式（2-5）是向量形式，与坐标系无关；式（2-2）只对笛卡儿坐标写出（#L1006）。
- 上述推导假设流场连续可微、微团足够小使 $\nabla\cdot\boldsymbol{V}$ 在 $\delta\mathcal{V}$ 内均匀（#L1072）。
- 物质导数与偏导数"在物理上和数值上都是完全不同的量"（#L976）；把两者混用会把定常流场的当地变化误当成随体变化。

## 判断

物质导数与速度散度不是两个独立公式，而是后面所有控制方程的两块积木：连续性方程由"质量守恒 + 体积变化率"得到，动量方程的对流项由"加速度 = 物质导数"得到。读懂 §2.3–§2.4，§2.5–§2.10 的推导就只剩记账。

# 建页规则（rules-page.md）

> 版本：v0.1（2026-11-27，从 `rules.md` §12.1 拆出，建立「先筛后建 + 页型增补」机制）
> 地位：本文件是**建页判据的唯一正文**；`rules.md` §12.1 只留指针。与 `rules.md`、`AGENTS.wiki.md` 冲突时以更严的一条为准；frontmatter 字段、引用格式、目录职责仍由那两份规定，本文件不重复。
> 适用：**只对新入库的书目生效**（ingest 第 3、4 步）。存量 570 页不追溯、不重做，除非整本重做该书。

## 0. 本文件管什么

只管两件事：

1. **筛**：一段文字有没有实质内容；
2. **建**：留下的材料怎么变成页（页型、要素、拆分、溯源）。

解析、图片、索引、lint、frontmatter 格式不在本文件。

## 1. 三个不变的问题

任何一页在建立前必须能回答：

1. 这页回答什么问题？——一个疑问句，全库唯一（`question` 字段，见 `rules.md` §13）。
2. 它自己讲完整了吗？——前因、结论、边界在同一页内闭合，不靠读者去别处拼。
3. 它凭什么算合格？——缺「边界与出处」即不合格；能被追问、能被判错。

「有用」的判定（替代旧 §12.1「能解决一个具体工程问题」），满足任一即可：

- **可被复用**：被 ≥2 处其他页引用；
- **可被追问**：能生成「为什么这样 / 怎么来的」问题并作答；
- **可被判错**：有适用条件、失效边界或反例。

## 2. 筛：有实质内容 / 无实质内容

ingest 第 3 步逐段判定，只问一句：**这段有没有讲出实质内容？**

### 2.1 无实质内容（丢弃，不产生材料）

- 版式噪声：页眉、页脚、页码、水印、出版社信息、装订线文字；
- 非正文：封面、版权页、序、致谢、广告、征订、作者简介；
- 导航件：目录、索引、符号说明、图表目录；
- 引文与出处：参考文献条目、纯引文块（引文本身含实质内容的，按材料处理）；
- 过渡与修辞：「下面我们讨论」「综上所述」「由此可见」等不承载信息的句子；
- 重复：与已判定材料或已建页同义重复的段落；
- 纯数值代入：只把数代进已给公式、没有新结论的算例（演示「怎么用这个方法」的算例不算此类）；
- 纯导语：只讲本节将要讲什么、没有实际内容的段落。

### 2.2 有实质内容（材料）

剩下的全部保留为**材料**，逐段记一句「它讲了什么」。

材料不等于页。是否建页、建几页，在 §3 判定。

### 2.3 输出：两张单子

第 3 步只出两张单子，写入该书 `sources\` 页的判定表（格式见 `AGENTS.wiki.md` §5）：

- **材料清单**：节号、行范围、一句摘要；
- **丢弃清单**：节号、行范围、丢弃原因（按 2.1 的类别）。

本步不产 `question`。

## 3. 建：页型与判据

### 3.1 断言页（P-01，现行唯一页型）

成立条件：同一结论的断言合为一页（定义 + 公式/判据 + 参数 + 边界 + 出处）；不同结论各自成页。

必填要素：

- **条件**：这条结论在什么前提下成立；
- **取值/公式**：可引用的数或式；
- **边界**：失效条件、适用范围、精度；
- **出处**：`sources` 三元组（书名 / 节号 / 行号），见 §4。

拆分与合并：

- 一章内含多个独立判据的**须各自成页**；一类校核、一个公式体系算一个独立判据。把整章压成一页即违反本条。
- 附录按内容分流：载有公式、判据或参数取值的附录按断言页正常建页——如 GB/T 150.3 附录 A 非圆形截面容器、E 低温容器、F 防低温脆断校核、G 夹套容器，150.4 附录 A 锻焊、B 套合、C 多层包扎、E 低温脆断容器制造附加要求；纯查表附录（许用应力表、高温性能表、牌号对照表）与文书表（提案表）不建页。
- 一段材料只服务一个结论、删去后不影响复现 → 并入已有断言页，不单独建页。

### 3.2 页型增补流程（不预写页型）

现行只有 P-01。遇到装不进 P-01 的材料，按下面流程长出新页型；**不得为尚未出现的知识形态预写判据**。

1. **登记**：在 §6 判据登记表加一行，状态 `草案`，写判别句、必填要素、「为什么 P-01 装不下」；
2. **攒实例**：同一候选页型出现 ≥2 个真实页例，才可申请 `试用`；
3. **试用**：用 1 本书验证，记录冲突与误判；
4. **转正**：无冲突 → `转正`，在 §3 增小节；判据总数上限 12 条；
5. **废止**：每条判据必须写「废止条件」；同类页型超过 8 个必须合并。

`草案` 状态不进入 ingest 执行流程，只作记录。

## 4. 溯源指针（新建页必填）

每页必须能指回 `20-md` 的具体行段，供溯源与复核。

### 4.1 frontmatter `sources`

```yaml
sources:
  - book: 计算流体力学基础及其应用
    section: §4.4
    lines: "#L1120-#L1186"
```

- `lines` 必填，形如 `#L起-#L止`，起 ≤ 止，止不超该书 md 总行数；
- 一页由多段材料合并时逐条列 `sources`，不得只挂第一条；
- **不新增 frontmatter 字段**（避免 schema 与 lint 连锁改动）。

### 4.2 正文覆盖行（人读用）

正文首段可加一行块引用：

```markdown
> 覆盖：《计算流体力学基础及其应用》§4.4（#L1120-#L1186）
```

机检不强制，但 sources 判定表的「去向」与本节 `lines` 必须对得上。

### 4.3 机检

`coverage.py -Book "<入库夹名>" --judged --strict` 检查：

- 每页 `lines` 非空、格式合法、起 ≤ 止、不超 md 行数；
- 判定表「材料」行必须有去向，且被某个页的 `lines` 覆盖；
- 本书 md 每个 `###` 小节在判定表中都有记录。

## 5. 全局禁止

- 禁止按书的目录/章节建页；
- 禁止预设「一本书多少页」再往里塞内容；
- 禁止为思考题、参考文献、符号说明、索引建页；
- 禁止把「无实质内容」的段落建成页；
- 禁止跳过查重直接建页（查重口径见 `AGENTS.wiki.md` §1）；
- 禁止在 `sources\` 页之外另建判定表文件。

非知识条目（思考题/参考文献/符号说明/索引）不建页，在该书 `sources\` 页章节地图与判定表中标注「未建页」。

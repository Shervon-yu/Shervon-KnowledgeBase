# 固体悬浮液的搅拌功率

## 两类悬浮液

| 类型 | 判据 | 流态 | 处理 |
|:---|:---|:---|:---|
| 沉降浆 | 颗粒尺寸、密度都大，停搅即迅速沉降 | 湍流 | 本节式(1.68)~式(1.73) |
| 非沉降浆 | 颗粒小而轻、充满全釜、沉降极慢 | 层流 | 按非牛顿流体处理，见 [[宾汉塑性流体搅拌功率]] |

（`#L1977`、`#L1979`）

## 标准挡板容器：只换密度

湍流下固体均匀悬浮，功率只随**叶轮周围的平均密度** $\bar{\rho}$ 变，仍按 $n^{3}d^{5}$ 走（`#L1991`、`#L1993`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_{s}g_{c}=K\bar{\rho}n^{3}d^{5},\qquad \dfrac{P_{s}}{P_{w}}=\dfrac{\bar{\rho}}{\rho_{w}}$ | （1.68）（1.69） |
| **文字式** | $\text{悬浮液功率}_{\text{【kg·m/s】}}\times g_{c}=\text{常数}\times\text{平均密度}_{\text{【kg/m³】}}\times\text{转速}_{\text{【1/s】}}^{3}\times\text{叶轮直径}_{\text{【m】}}^{5},\qquad \dfrac{\text{悬浮液功率}}{\text{清水功率}}=\dfrac{\text{平均密度}_{\text{【kg/m³】}}}{\text{水的密度}_{\text{【kg/m³】}}}$ |  |

平均密度按固相体积分率 $\phi$ 加权（`#L2023`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\bar{\rho}=\phi\rho_{s}+\left(1-\phi\right)\rho_{w}$ | （1.70） |
| **文字式** | $\text{平均密度}_{\text{【kg/m³】}}=\text{固相体积分率}\times\text{固体密度}_{\text{【kg/m³】}}+\left(1-\text{固相体积分率}\right)\times\text{水的密度}_{\text{【kg/m³】}}$ |  |

实测范围：六叶涡轮 $d=0.5D$、$D=0.15/0.30/0.585$ m、四块 $B_{w}=0.1D$ 挡板；物料为海砂（20~28、32~42 目）、铝粉（150~250 目）、闪光粉（60~100 目）、黄铁矿（250~325 目），$\bar{\rho}=1.00\sim1.52$（`#L1991`）。标准挡板下式(1.69) 的系数 $k=1.0$（`#L2041`）。

## 底部挡板：低转速悬浮，但 k>1

用尽量低的转速让颗粒离底，可在釜底装小挡板（"底部挡板"，`#L2027`、`#L2031`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $B_{w}=0.1D,\quad B_{H}=0.05D,\quad n_{B}=4$ | （1.71） |
| **文字式** | $\text{挡板宽}_{\text{【m】}}=0.1\times\text{容器内径}_{\text{【m】}},\quad \text{挡板高}_{\text{【m】}}=0.05\times\text{容器内径}_{\text{【m】}},\quad \text{挡板数}=4$ |  |

叶轮保持在离底 $D/4$ 处（`#L2033`）。此时功率比的斜率不再等于 1（`#L2037`、`#L2039`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{P_{s}}{P_{w}}-1=k\left(\dfrac{\bar{\rho}}{\rho_{w}}-1\right)$ | （1.72） |
| **文字式** | $\dfrac{\text{悬浮液功率}}{\text{清水功率}}-1=\text{斜率}k\times\left(\dfrac{\text{平均密度}_{\text{【kg/m³】}}}{\text{水的密度}_{\text{【kg/m³】}}}-1\right)$ |  |

$k>1$，且 $\rho_{s}$ 与颗粒直径 $d_{p}$ 越大 $k$ 越大——底部挡板把颗粒兜在桨区，局部浓度高于全釜平均，故按 $\bar{\rho}$ 算偏小（`#L2041`）。**通用做法**：由实测 $P_{s}/P_{w}$ 反推叶轮周围的实际密度（`#L2051`、`#L2055`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho^{*}=k\left(\bar{\rho}-\rho_{w}\right)+\rho_{w}$ | （1.73） |
| **文字式** | $\text{叶轮周围密度}_{\text{【kg/m³】}}=\text{斜率}k\times\left(\text{平均密度}_{\text{【kg/m³】}}-\text{水的密度}_{\text{【kg/m³】}}\right)+\text{水的密度}_{\text{【kg/m³】}}$ |  |

## 无挡板：三段斜率，没有普适关联

无挡板容器里，转速上升时颗粒从桨端逐渐浮起、再向中央与四周扩散，$\rho^{*}$ 随 $N$ 变，$P_{s}$–$N$ 曲线断成三段（`#L2059`、`#L2061`）：

| 区段 | 条件 | 斜率 $p$ | 机理 |
|:---|:---|:---|:---|
| 1 | $N<N_{f}$（浮游速度） | $p_{1}>3$ | 浮游量随 $N$ 增，$\rho^{*}$ 同时上升 |
| 2 | $N_{f}<N<N_{a}$（吸入空气转速） | $p_{2}<3$ | 颗粒向桨上方扩散，桨区密度下降 |
| 3 | $N>N_{a}$ | $p_{3}=3$ | 桨区密度稳定，只剩 $n^{3}$ 律 |

故无挡板悬浮液**不能套单一关联式**，必须按实际工况段取值；设计上要么加挡板，要么留足安全系数。

## 边界

- 只适用于**湍流**（沉降浆）。层流、高黏、非沉降浆见 [[宾汉塑性流体搅拌功率]]、[[幂律流体与表观黏度]]。
- 式(1.68)~(1.73) 的实验介质为水+惰性固体，无传质/溶解/反应；带反应的溶解速率另见 §6.7。

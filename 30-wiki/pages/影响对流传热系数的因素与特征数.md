# 影响对流传热系数的因素与特征数

## 五个方面（`#L6145-#L6163`）

1. **流体物性**：$\rho$、$c_p$、$\lambda$、$\mu$、体积膨胀系数 $\beta$；随相态、温度、压力而变。
2. **对流起因**：强制对流（泵、风机、压头）与自然对流（密度差浮升力）。浮升力 $(\rho_1-\rho_2)g=\rho_2g\beta\Delta t$。通常强制对流 $u$ 大、$\alpha$ 高：空气自然对流约 5~25 W/(m²·℃)，强制对流可达 10~250 W/(m²·℃)。
3. **流动状态**：湍流时质点混杂、传热充分，且 $Re$ 越大有效层流膜越薄，$\alpha$ 越大；层流时无质点混杂，$\alpha$ 较小。
4. **相态变化**：冷凝与沸腾的 $\alpha$ 比无相变大很多——因为相变放出/吸收汽化热 $r$，而同种液体 $r$ 远大于 $c_p$。
5. **传热面形状、相对位置与尺寸**：圆管/翅片管/管束/平板/螺旋板；水平/垂直、管内/管外、轴向/垂直流向；特征尺寸取对流动与传热有决定性影响的尺寸。

## 量纲分析（`#L6167-#L6194`）

无相变时 $\alpha=f(u,l,\mu,\lambda,\rho,c_p,\beta g\Delta t)$（4-15），共 8 个物理量、4 个基本量纲（M、L、T、Θ），由 $\pi$ 定理得 8−4=4 个独立特征数：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{\alpha l}{\lambda}=K\left(\dfrac{lu\rho}{\mu}\right)^a\left(\dfrac{c_p\mu}{\lambda}\right)^b\left(\dfrac{l^3\rho^2\beta g\Delta t}{\mu^2}\right)^c$ | （4-16） |
| **文字式** | $\text{努塞尔数}=K\times\text{雷诺数}^a\times\text{普朗特数}^b\times\text{格拉晓夫数}^c$ |  |

即一般形式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Nu=K\,Re^aPr^bGr^c$ | （4-17） |
| **文字式** | $\text{努塞尔数}=\text{系数}\times\text{雷诺数}^a\times\text{普朗特数}^b\times\text{格拉晓夫数}^c$ |  |

## 四个特征数（表4-2，`#L6183-#L6188`）

| 特征数 | 定义 | 意义 |
|:---|:---|:---|
| 努塞尔数 $Nu$ | $\alpha l/\lambda$ | 对流传热系数的无量纲化 |
| 雷诺数 $Re$ | $lu\rho/\mu$ | 流动状态与湍动程度对传热的影响 |
| 普朗特数 $Pr$ | $c_p\mu/\lambda$ | 流体物性对传热的影响 |
| 格拉晓夫数 $Gr$ | $\beta g\Delta t l^3\rho^2/\mu^2$ | 自然对流的影响 |

## 用关联式的三点注意（`#L6196-#L6204`）

1. **适用范围**：各式的 $Re$、$Pr$ 等范围由实验确定，不得超出；
2. **特征尺寸**：管内用内径 $d$，非圆形管常用当量直径 $d_e$；
3. **定性温度**：物性所依据的温度，各关联式规定不同（进出口算术平均、壁温或膜温 $(t_m+t_w)/2$），必须按该式规定取。

## 判断

- $\pi$ 定理把"8 个量"压缩成"4 个无量纲数"，这是对流传热能被实验归纳的根本原因；没有这一步，每种流体、每种尺寸都要单独做实验。
- 三个注意点其实是同一件事的三面：关联式只在"几何相似+物性范围+温度取值一致"时才能搬用，任何一项不符，误差都可能成倍。

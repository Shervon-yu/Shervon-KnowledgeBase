# 大型罐的旁入式与喷射混合

## 场景

几百立方米的贮罐装不下顶插搅拌器，混合靠**旁入（侧入）式叶轮**或**喷嘴喷射**。目标不是"快"，而是**用最小功率把油或加料成分弄均匀**——这类操作混合可以拖几个小时（`#L5613`）。

## 旁入式叶轮

Fox & Gex 的关联（图4.27）表明：旁入式叶轮的 $\theta_M$–$Re$ 关系与**顶插叶轮趋势相同**（`#L5615`）。若不存在密度分层，其混合时间直接套用式(4.53)（见 [[湍流域混合时间关联式]]，`#L5627`）。

## 密度分层：最容易被忽略的坑

Oldshue 的热水/冷水实验（图4.28，`#L5621`、`#L5623`）：

- 旁入叶轮浸在下层冷水里，下层确实循环起来了；
- **上下仍是两个液层**，界面的混合极慢——用几个高度的温度曲线才看得出来；
- 燃料油混合、四乙基铅在汽油中分布也见同样现象（Rushton）。

**对策**（`#L5625`）：把叶轮放在**两液的交界面处**，被处理的液体在**叶轮后面**加入（靠叶轮吸力先卷进去，而不是浮在液面上）。

## 喷嘴喷射混合

循环泵 + 管道把罐内液体抽出再喷回，需混合的液体加在**泵的吸入口**（泵本身就是强混合器，`#L5629`）。混合时间（`#L5635`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\theta_{M}=C_{d}\left(\dfrac{d_{0}}{V_{0}}\right)\left(\dfrac{D}{d_{0}}\right)^{3/2}\left(\dfrac{H}{d_{0}}\right)^{1/2}$ | （4.59） |
| **文字式** | $\text{混合时间}=C_d\times\dfrac{\text{喷嘴直径}}{\text{出口速度}}\times\left(\dfrac{\text{罐径}}{\text{喷嘴直径}}\right)^{3/2}\times\left(\dfrac{\text{液面高度}}{\text{喷嘴直径}}\right)^{1/2}$ |  |

$C_d=2.5\sim10$（`#L5637`）；$d_0$ 越小、$V_0$ 越大则越快，但 $D/d_0$ 的 $3/2$ 次方把"大罐用细喷嘴"的路堵死。

多个作者的实测值彼此差得不小，但定性一致（图4.29，`#L5633`）。

## 旁入叶轮 vs 喷射器

Rushton 的比较结论：**能耗上旁入式叶轮略优，但至今没有定论**（`#L5631`）。工程上按"有没有现成循环泵"和"罐内能否开孔"来选，比按能耗选更实际。

## 重液注入轻液：要额外压头

Fossett 研究：喷嘴装在距液面 $H_m$ 处、仰角 $\theta$，要把重液顶到液面所需的外加压头（`#L5641`、`#L5643`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $H=K\,H_{m}\dfrac{\rho_{2}-\rho_{1}}{\rho_{2}\sin^{2}(\theta+5^{\circ})}$ | （4.60） |
| **文字式** | $\text{所需压头}=K\times\text{喷嘴距液面高度}\times\dfrac{\text{重液密度}-\text{轻液密度}}{\text{重液密度}\times\sin^{2}(\text{仰角}+5^{\circ})}$ |  |

$\rho_1$ 轻液、$\rho_2$ 重液；$K$ 与密度差的关系见图4.30（`#L5649`）。$+5^\circ$ 是经验修正——仰角太平时射流贴壁而不是上冲。

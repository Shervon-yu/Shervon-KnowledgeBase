# 端面比压与pv值

## 定义

**pv值**（书内写作 p_c v、pcv 值）：它是密封副材料配合的相对性能，可表示所能承受住的接触压力与摩擦速度的乘积。密封流体性质对其影响很大，特别是碳化硅的 pv 值受烷烃的影响而增大。§4.4.1 #L2970

**pcv 值（同一量的另一种写法）**：pc_v 值是密封端面比压 p_c 与密封端面平均滑动速度 v 的乘积。§4.1.2 表下注 #L2191

**端面比压 p_c**：本书只给符号与量纲口径，无独立文字定义——

> 式中，p_c 为端面比压；D_m 为密封端面平均直径，m；b 为密封端面宽度；V 为密封面平均线速度，m/s。§6.1.1 #L5123

即 p_c 是端面载荷式中的压强项，单位 MPa；本库未查到「端面比压＝某力／某面积」的成文定义，出处缺，见开放问题。

**周速 v**：通常以密封面平均直径的圆周速度来表示密封的周速。§4.2.1 #L2293

## 判据 / 计算

pv 值定义式（原书以文字给出，此处按定义写成乘积式）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_{c}v=p_{c}\cdot\dfrac{\pi D_{\mathrm{m}}n}{60}$ | （2-1） |
| **文字式** | $\text{端面比压与周速乘积}_{\text{【MPa·m/s】}}=\text{端面比压}_{\text{【MPa】}}\times\dfrac{\pi\times\text{密封端面平均直径}_{\text{【m】}}\times\text{转速}_{\text{【r/min】}}}{60}$ |  |

式（2-1）由 #L2191 的文字定义与 #L2293 的周速口径合成，原书未给合并式。

**选材判据**：选材时若比压或 p_v 值超过允许值，则可采用减小面积比（采用平衡型密封）的办法；但必须注意随着面积比的减小，密封的可靠性也会下降，因为在缝隙内流体膜压作用下密封面有开启失效的可能性。§4.2.2 #L2341

**降低端面比压的既有手段**：采用平衡型密封可以减小密封面比压来改善工作条件；对离心泵还可用叶轮开平衡孔、背叶片、副叶轮等降低轴封箱前压力，从而减轻轴封载荷。§4.2.3 #L2762

**摩擦热侧写【推定，非原书公式】**：端面摩擦功率近似 $P_{f}=f\,p_{c}\,v\,A_{\mathrm{f}}$（f 为端面摩擦因数，A_f 为端面面积）；摩擦热需由冲洗液/介质带走，端面温升可按化工原理的总传热速率式粗估：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=K A \Delta t$ | （2-2） |
| **文字式** | $\text{传热速率}_{\text{【W】}}=\text{总传热系数}_{\text{【W/(m²·K)】}}\times\text{传热面积}_{\text{【m²】}}\times\text{传热温差}_{\text{【K】}}$ |  |

式（2-2）取自《化工原理》§（五）传热速率方程式 #L6364（书中 K 称为总传热系数，单位 W/(m²·K)）。用它反算端面温升需要端面给热系数，两书都没给，只能定性：pv 越高，摩擦热越大，越依赖冲洗/冷却。

## 工况口径（书内实测/选用值）

| 场合 | 数值 | 出处 |
|:---|:---|:---|
| 泵用机械密封试验曲线条件 | p_s ≤ 1.0 MPa、v ≤ 10 m/s、p_s v ≤ 5 MPa·m/s | §4.1.2 #L2221 |
| 周速分档（弹簧旋转式/静止式） | v < 20~30 m/s 用弹簧旋转式；v > 25 m/s 用弹簧静止式 | §4.2.1 #L2293 |
| 釜用密封 | 端面比压一般比泵用密封高；计算时不考虑旋转零件自重 | §4.6.1 #L3454 #L3458 |
| 低温（-50~0 ℃） | 端面比压要选高值 | §4.6.3 #L3600 |

## 与化工原理的连接点

化工原理书不涉及端面润滑与 pv 判据，只在「摩擦系数 λ」「黏度 μ」侧提供流体侧输入：层流摩擦系数由 λ=64/Re 给出（《化工原理》§二、层流的摩擦阻力损失计算 #L2197 附近的式 1-45）。端面间液膜属于动压/挤压膜润滑，两书都没有成文关联式——**跨书这一步在本库内尚无可引原文**，只能作为待补缺口记录。

## 开放问题

- 「端面比压」的文字定义（p_c = 弹簧力+介质压力作用于端面的合力 / 端面面积）在两本书里都没写成句子，只有符号与载荷式；需要补一本《机械密封技术》类教材或 GB/T 标准原文。
- pv 允许值与材料配对、介质、冲洗量的定量关系，本书只给「超过允许值则减小面积比」，未给允许值表。
- 端面摩擦因数 f 与 p_c、v 的关系（书中 §4.1.2 只给 f-p_s、f-v 定性特性曲线 #L2221 #L2253）。

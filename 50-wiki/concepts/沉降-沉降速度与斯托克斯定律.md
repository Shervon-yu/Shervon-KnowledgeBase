# 沉降-沉降速度与斯托克斯定律

## 定义

**自由沉降（free settling）**：单个颗粒在流体中沉降，或颗粒群分散得较好、互不接触不碰撞条件下的沉降（#L4617）。

球形颗粒在静止流体中，受重力 $F_g$、浮力 $F_b$ 与流体阻力 $F_d$ 三者作用；加速度随速度增大而减小，当加速度为零时颗粒进入**匀速沉降**，此时的速度称**沉降速度 $u_t$**（#L4619-#L4643）。

## 判据 / 计算

三力平衡（牛顿第二定律）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_g-F_b-F_d=m\dfrac{\mathrm d u}{\mathrm d\tau}$ | （6-1） |
| **文字式** | $\text{重力}_{\text{【N】}}-\text{浮力}_{\text{【N】}}-\text{阻力}_{\text{【N】}}=\text{颗粒质量}_{\text{【kg】}}\times\dfrac{\mathrm d\text{沉降速度}}{\mathrm d\text{时间}}$ |  |

匀速时（$\mathrm du/\mathrm d\tau=0$）的通用沉降速度：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\sqrt{\dfrac{4g d_p\left(\rho_p-\rho\right)}{3\zeta\rho}}$ | （6-2） |
| **文字式** | $\text{沉降速度}_{\text{【m/s】}}=\sqrt{\dfrac{4\times g\times\text{颗粒直径}_{\text{【m】}}\times\left(\text{颗粒密度}_{\text{【kg/m³】}}-\text{流体密度}_{\text{【kg/m³】}}\right)}{3\times\text{阻力系数}\times\text{流体密度}_{\text{【kg/m³】}}}}$ |  |

原书编号：式(3-11)（#L4645）。

层流区（$Re<2$）—— 斯托克斯式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\dfrac{g d_p^{2}\left(\rho_p-\rho\right)}{18\mu}$ | （6-3） |
| **文字式** | $\text{沉降速度}_{\text{【m/s】}}=\dfrac{g\times\left(\text{颗粒直径}_{\text{【m】}}\right)^{2}\times\left(\text{颗粒密度}_{\text{【kg/m³】}}-\text{流体密度}_{\text{【kg/m³】}}\right)}{18\times\text{黏度}_{\text{【Pa·s】}}}$ |  |

原书编号：式(3-12)，称**斯托克斯式或斯托克斯定律**（#L4655、#L4657）。

过渡区（$2<Re<500$）与湍流区（$500<Re<2\times10^{5}$）分别用式(3-13)、(3-14)（#L4659、#L4661）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\left[\dfrac{4g^{2}\left(\rho_p-\rho\right)^{2}}{225\mu\rho}\right]^{1/3}d_p$ | （6-4） |
| **文字式** | $\text{沉降速度}_{\text{【m/s】}}=\left[\dfrac{4\times g^{2}\times\left(\text{颗粒密度}_{\text{【kg/m³】}}-\text{流体密度}_{\text{【kg/m³】}}\right)^{2}}{225\times\text{黏度}_{\text{【Pa·s】}}\times\text{流体密度}_{\text{【kg/m³】}}}\right]^{1/3}\times\text{颗粒直径}_{\text{【m】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\sqrt{3.03\,g\left(\rho_p-\rho\right)d_p/\rho}$ | （6-5） |
| **文字式** | $\text{沉降速度}_{\text{【m/s】}}=\sqrt{3.03\times g\times\left(\text{颗粒密度}_{\text{【kg/m³】}}-\text{流体密度}_{\text{【kg/m³】}}\right)\times\text{颗粒直径}_{\text{【m】}}/\text{流体密度}_{\text{【kg/m³】}}}$ |  |

**求法**：$u_t$ 是待求量、$Re$ 又依赖 $u_t$，故须**试差**——先假定所在区，算出 $u_t$ 再回头验 $Re$，不符则换区重算（#L4667；例 3-1 #L4669-#L4673）。

## 适用范围与边界

- 三区公式只对**球形颗粒**成立；非球形颗粒需修正阻力系数（$Re>2$ 时）。
- $d_p$、$\rho_p$ 越大 $u_t$ 越大；层流区与过渡区还受黏度 $\mu$ 影响，液体黏度约为气体的 50 倍，故同一颗粒在液体中沉降比在气体中慢很多（#L4663）。
- 自由沉降假定颗粒互不干扰；浓度高时须按干扰沉降处理（§3.2 后文）。
- 加速段对**小颗粒**很短，可忽略，只按匀速段算（#L4637）。

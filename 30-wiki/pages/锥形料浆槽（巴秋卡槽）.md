# 锥形料浆槽（巴秋卡槽）

## 型式与用途（`#L17678`）

锥底、锥体顶角一般 **60°**，利于沉落固体循环；底部通气。国外称 Pachuca 槽，是水法冶金（铀、金矿石浸出）中仍在广泛使用的最重要设备之一。

## 四项功能（`#L17684-#L17692`）

1. 使矿浆保持悬浮；
2. 消除流体短路；
3. 使矿浆充气；
4. 浸出中促进液膜更新（「刮膜」作用）。

不同场合各功能重要性不同。**槽内料浆循环量是最重要的性能参数**（`#L17694`）。

## 气流搅拌对固体悬浮的能力边界（`#L17680`）

对自由沉降颗粒，气流搅拌一般**低效**，除非沉降速度特别低；但可用于**高密度料浆**（正是锥形槽的定位）。

## 三种常用型式（图15-10，`#L17698`）

按中央循环管长短与有无分 (a)(b)(c) 三型，分别适合不同矿石浸出；(d) 为建议方案、无实用报道。

## 循环量的两条定量规律

**① 液深修正**（`#L17722-#L17728`）：同气量下，循环量与液深的 **1/3 次方**成正比。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q_{V,2}=Q_{V,1}\left(\dfrac{H_2}{H_1}\right)^{0.33}$ | （液深修正） |
| **文字式** | $\text{液深2下循环量}_{\text{【m³/s】}}=\text{液深1下循环量}_{\text{【m³/s】}}\times\left(\dfrac{\text{液深2}_{\text{【m】}}}{\text{液深1}_{\text{【m】}}}\right)^{0.33}$ |  |

例：6.1 m 液深 $0.10$ m³/s → 9.1 m 时 $0.10\times(9.1/6.1)^{0.33}=0.11$ m³/s；4.1 m 时 $0.09$ m³/s。

**② 循环管直径比气量更关键**（`#L17736`）：图15-11 显示「很少的空气量即可建立较高程度循环」，而循环管直径对循环量的影响**大于**空气用量。

## 结构细节（`#L17738-#L17744`）

| 部位 | 要求 | 原因 |
|:---|:---|:---|
| 中央循环管进口（底端） | 做成钟形喇叭口 | 改善可靠性与空气经济性 |
| 循环管上端 | 自由排出优于侧壁开孔排出 | 侧孔需能量推料，同气量下循环量更小 |
| 管底与槽底距离 | 约 **1 倍管径** | 太近限制流动，太远造成槽底积料 |
| 引气管 | 不宜由内管引入 | 会使空气用量增加 **10%~35%** |
| 引气装置占截面 | ≤ 循环管截面积的 **15%** | 超过需特殊安排降阻 |

温度修正：图15-11 为 21 ℃ 数据；溶液蒸汽压不太低时按空气体积随温度折算，循环量可合理估计（`#L17730`）。

## 输气搅动功率（式15-15，`#L17750`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=p_1Q_1\ln\dfrac{10+\rho_L H}{10}$ | （15-15） |
| **文字式** | $\text{搅动功率}_{\text{【W】}}=\text{槽内压力}_{\text{【Pa】}}\times\text{气体体积流量}_{\text{【m³/s】}}\times\ln\dfrac{10+\text{悬浮液密度}_{\text{【kg/m³】}}\times\text{料浆液高}_{\text{【m】}}}{10}$ |  |

原文由积分式 $P=\int_0^H\dfrac{1000\rho_L g p_1Q_1}{p_1+1000\rho_L g(H-h)}\mathrm{d}h$ 积出，结果与排气高度 $h$ 无关。

## 判断

- 锥形槽的瓶颈是**循环管与局部阻力**，不是气量：管径选小、底端太近、侧孔排料、内管引气，每一项都能把循环量吃掉一截。
- 式15-15 是等温膨胀功，实际压缩空气带水、温升会略增耗功；按计算值配气源即可。

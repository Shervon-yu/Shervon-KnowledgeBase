# 离心泵-扬程与特性曲线

## 定义

- **扬程 $H$**（又称压头）：单位重量（1 N）液体流经泵所获得的能量，单位 J/N = m（#L3373）。注意与"升扬高度"区分：升扬高度只是 $H$ 中的位能部分。
- **流量 $q_V$**：单位时间泵输送的液体体积，m³/s、m³/min 或 m³/h（#L3369）。
- **特性曲线**：额定转速、标定状况（101.325 kPa、20 ℃ 清水）下 $H$、$P$、$\eta$ 与 $q_V$ 的关系曲线（#L3435）。

## 判据 / 计算

管路系统要求泵提供的压头：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=H_0+\Sigma H_{\mathrm f}$ | （3-1） |
| **文字式** | $\text{扬程}_{\text{【m】}}=\text{升扬高度加位差对应项}_{\text{【m】}}+\text{总压头损失}_{\text{【m】}}$ |  |

管路特性方程（把 $u=q_V/(\pi d^2/4)$ 代入压头损失式后归并）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=H_0+k\,q_V^{2}$ | （3-2） |
| **文字式** | $\text{扬程}_{\text{【m】}}=\text{固定位能压头}_{\text{【m】}}+\text{管路特性系数}\times\left(\text{流量}_{\text{【m³/s】}}\right)^{2}$ |  |

原书编号：式(2-8)、(2-9)、(2-10)、(2-11)，见 #L3509、#L3517、#L3525、#L3535；$H_0=\Delta z+\Delta p/(\rho g)$（#L3555 例 2-2）。

转速改变时的比例定律（效率不变前提，转速变化 <20% 时效率基本不变）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{q_{V2}}{q_{V1}}=\dfrac{n_2}{n_1},\quad\dfrac{H_2}{H_1}=\left(\dfrac{n_2}{n_1}\right)^{2},\quad\dfrac{P_2}{P_1}=\left(\dfrac{n_2}{n_1}\right)^{3}$ | （3-3） |
| **文字式** | $\dfrac{\text{流量}_2}{\text{流量}_1}=\dfrac{\text{转速}_2}{\text{转速}_1},\quad\dfrac{\text{扬程}_2}{\text{扬程}_1}=\left(\dfrac{\text{转速}_2}{\text{转速}_1}\right)^{2},\quad\dfrac{\text{功率}_2}{\text{功率}_1}=\left(\dfrac{\text{转速}_2}{\text{转速}_1}\right)^{3}$ |  |

原书编号：式(2-5)（#L3459-#L3463）。

特性曲线三条（#L3437-#L3453）：

1. $H$–$q_V$：通常 $H$ 随 $q_V$ 增大而减小；曲线平坦者流量变化大而压头变化小，陡降者反之。
2. $P$–$q_V$：$P$ 随 $q_V$ 增大而增大，$q_V=0$ 时 $P$ 最小 —— 故**启动应关闭出口阀**（#L3443）。
3. $\eta$–$q_V$：先升后降，最高效率点为设计工况点；取最高效率以下 7% 为**高效区**（#L3451）。

**工作点**：泵特性曲线与管路特性曲线的交点，此时流量与压头既为管路所需、又是泵所能提供（#L3543-#L3543）。

## 适用范围与边界

- 特性曲线是**标定状况、额定转速、清水**下测得；液体黏度或密度与清水差别大时须校正特性曲线（#L3467）。
- 比例定律仅在效率不变时成立，转速变化超过约 20% 后效率明显偏离（#L3463）。
- 管路特性方程的 $q_V$ 必须用 m³/s（#L3537）；$k$ 随阀门开度变化，故调节阀会移动工作点（#L3539）。
- 本章不讨论泵内部流道设计（超出课程范围，#L3277）。

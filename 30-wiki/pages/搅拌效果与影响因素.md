# 搅拌效果与影响因素

## 定义

搅拌效果按操作目的不同，用不同指标表示；常用表示法见《搅拌与混合设备设计选用手册》表1-1（`#L818-#L829`）。

| 操作目的 | 搅拌物系 | 效果表示法 |
|:---|:---|:---|
| 均匀混合 | 互溶液系 | 混合时间 $\theta_M$，或无量纲混合时间 $N_{\theta M}=N\theta_M$ |
| 非均相分散 | 液-液 | 均匀分散（乳化）时间 $\theta_M$；分散相比界面积 $a$、滴径分布或平均滴径 $d_y$ |
| 非均相分散 | 气-液 | 均匀分散时间 $\theta_M$；气泡比界面积 $a$、平均气泡直径 $d_B$ 及分布 |
| 非均相分散 | 固-液 | 悬浮状态、悬浮临界转速 $N_c$；悬浮固液浓度或比表面积 $a$ |
| 传质（溶解） | 固-液 | 溶解速度；以固粒表面积为基准的液膜传质系数 $k_c$、总传质系数 $K$ |
| 传质（萃取） | 液-液 | 萃取速度、效率；比界面积 $a$；总容积传质系数 $K_V$ 或液膜传质系数 $k_{Cd}$ |
| 传质（吸收） | 气-液 | 吸收速度；比界面积 $a$；总容积吸收系数 $K_V$、膜传质系数 $k_g$、$k_l$ |
| 传热 | 固-液 | 传热速度 $Q$、单位容积传热速率 $Q_v$、液膜传热系数 $\alpha_L$、总传热系数 $K$ |

无量纲混合时间与转速、混合时间的关系：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\theta M}=N\cdot\theta_{M}$ | （表1-1） |
| **文字式** | $\text{无量纲混合时间}=\text{搅拌转速}_{\text{【1/s】}}\times\text{混合时间}_{\text{【s】}}$ |  |

## 影响因素

表1-2 把因素分为四类（`#L835-#L842`）：流动状态（流型、循环速率、湍流扩散、剪切流）、物性（黏度及黏度差、密度及密度差、扩散系数、粒径、表面张力、比热容、导热系数、非牛顿流变性）、操作条件（叶轮型式与转速、溶质加入量与速度、加入位置）、几何因素（间歇或连续、釜体与叶轮及内构件的几何形状、相对尺寸与安装方式）。

表1-3 给出各操作对因素的敏感程度（`#L844-#L868`）：均相混合对循环速率与湍流扩散最敏感；液-液分散对剪切流、黏度、黏度差敏感；气-液分散对剪切流敏感；固体悬浮对循环速率与黏度敏感；传热对循环速率、黏度及导热系数敏感。星号 * 表示萃取、结晶等操作中液流湍动的影响尚不清楚（`#L870`）。

黏度在表中反复出现；非牛顿物料的"黏度"本身是切变速率的函数，取值口径见 [[物料流变分类]] 与 [[搅拌剪切速率量级]]。

## 边界与陷阱

- 同一目的存在大量彼此结果差异很大的关联式；选式时实验条件必须尽量贴合给定工况，否则要么不达标、要么经济性变差（`#L814`）。这条是"参数可查"却仍要复核的原因。
- 混合时间 $\theta_M$ 与 $N\theta_M$ 都是"达到规定均匀度所需的时间"，均匀度阈值不同则数值不同，引用时必须连阈值一起记。

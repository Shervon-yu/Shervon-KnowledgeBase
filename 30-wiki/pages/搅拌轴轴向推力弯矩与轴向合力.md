# 搅拌轴轴向推力弯矩与轴向合力

## 粗算 $M_{A}$

判据（`#L11884-#L11890`）：

- 当设计压力 $p\ge2$ MPa，**或**轴上任一搅拌器叶片倾角 $\theta_{i}\ne0$ 时：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_{A}=0.2M_{R}$ | （9-49） |
| **文字式** | $\text{轴向弯矩}_{\text{【N}\cdot\text{m】}}=0.2\times\text{径向力弯矩}_{\text{【N}\cdot\text{m】}}$ |  |

- 当 $p<2$ MPa 且所有 $\theta_{i}=0$ 时：$M_{A}=0$（9-50）。

**为什么**：$M_{A}$ 由轴向力对轴截面偏心产生，只有带倾角的叶片或带压设备才产生可观轴向力；直叶、常压时忽略。

## 精算 $M_{A}$

用粗算 $M_{A}$ 求得 $d_{2}$ 后，再按（`#L11892-#L11904`）：

悬臂轴：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_{A}=-K_{B}F_{A}\dfrac{d_{L1}(1+N_{0}^{2})}{8}\times10^{-3}$ | （9-51） |
| **文字式** | $\text{轴向弯矩}_{\text{【N}\cdot\text{m】}}=-\text{压缩系数}\times\text{轴向力}_{\text{【N】}}\times\dfrac{\text{悬臂段外径}_{\text{【mm】}}\times(1+\text{空心比}^{2})}{8}\times10^{-3}$ |  |

单跨轴以 $d_{L}$ 代替 $d_{L1}$（9-52）。

**压缩系数 $K_{B}$**：

- 当 $\dfrac{L_{B}}{I_{0}\sqrt{S_{0}}}<110$ 时，$K_{B}=\dfrac{1}{1-0.004\left(\dfrac{L_{B}}{I_{0}\sqrt{S_{0}}}\right)}$；
- 当 $\dfrac{L_{B}}{I_{0}\sqrt{S_{0}}}\ge110$ 时，$K_{B}=\dfrac{\sigma_{S}}{\pi^{2}E}\left(\dfrac{L_{B}}{I_{0}\sqrt{S_{0}}}\right)^{2}$。

其中回转半径 $I_{0}=\dfrac{d_{L1}}{4}\sqrt{1+N_{0}^{2}}$（悬臂轴）或 $\dfrac{d_{L}}{4}\sqrt{1+N_{0}^{2}}$（单跨轴）；$L_{B}$ 为计算段长度（图9-62、图9-63）；$\sigma_{S}$ 为压缩屈服限。

**物理含义**：$K_{B}$ 是**压杆稳定折减系数**——细长轴受压会因失稳而额外受弯，$L_{B}/(I_{0}\sqrt{S_{0}})$ 越大折减越重。

## 轴承型式系数 $S_{0}$（表9-102）

| 轴承类型＼支承形式 | 悬臂轴 | 单跨轴 |
|:---|:---:|:---:|
| 滚动轴承 | 0.25 | 1.0 |
| 滑动轴承 | 0.56 | 2.25 |

上下轴承类型不同时，$S_{0}$ 取两者系数的**平均值**（`#L11927`）。

## 轴向合力 $F_{A}$

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{A}=\dfrac{\pi d_{0}^{2}p}{4}\pm F_{W}\cos\alpha\pm\sum F_{vi}$ | （9-53） |
| **文字式** | $\text{轴向合力}_{\text{【N】}}=\dfrac{\pi\times\text{跨间段轴径}_{\text{【mm】}}^{2}\times\text{设计压力}_{\text{【MPa】}}}{4}\pm\text{轴与搅拌器重力}_{\text{【N】}}\times\cos\text{轴线倾角}\pm\sum\text{流体轴向推力}_{\text{【N】}}$ |  |

- $F_{vi}$：第 $i$ 层搅拌器上的流体轴向推力，按第五章（搅拌器强度计算）规定计算；
- $F_{W}$：当量长度 $L_{T}$ 的轴与搅拌器重力总和，如悬臂轴 $F_{W}=2.452\pi d_{L1}^{2}(1-N_{0}^{2})L_{T}\rho_{s}\times10^{-9}+9.81\sum m_{i}$。

**符号规则**（`#L11951`）：设计压力为负压时取 $p=0$；$F_{W}$、$F_{v}$ 为**轴向压力取负**，为**轴向拉力取正**。

## 迭代判据

- 求得 $F_{A}\ge0$（轴受拉）→ 取 $M_{A}=0$；
- $F_{A}<0$（轴受压）→ 按式（9-51）/（9-52）求 $M_{A}$；
- 若精确 $M_{A}$ **大于**粗算值 → 返回式（9-37）、（9-38）重算 $M$ 与 $d_{2}$；小于则不必重算（`#L11953`）。

## 使用要点

1. $M_{A}$ 前带**负号**：轴向压力使轴产生与径向力反向的弯曲，部分抵消 $M_{R}$，故 $M=M_{A}+M_{R}$ 是代数和。
2. 带倾角叶片（斜叶、推进式、后掠式）与带压设备是 $M_{A}$ 的主要来源。
3. 式（9-53）是**迭代的入口**：先假设 $d$，算 $F_{A}$，定 $M_{A}$，再算 $d$，一轮即可收敛。

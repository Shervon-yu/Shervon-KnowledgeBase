# 釜用机械密封的标准系列

## 现行标准（`#L13475-#L13483`）

| 标准 | 适用范围 |
|:---|:---|
| **HG/T 2098**《釜用机械密封系列及主要参数》 | 介质压力 $\le6.3\ \mathrm{MPa}$、温度 $\le150\ ℃$ 的钢制反应釜搅拌轴及类似立式旋转轴；搅拌轴（或轴套）外径 $40\sim220\ \mathrm{mm}$；转速 $\le3\ \mathrm{m/s}$；介质为除**强氧化性酸、高浓度碱**以外的各种流体 |
| **HG 21571**《搅拌传动装置——机械密封》 | 设计压力 $\le1.6\ \mathrm{MPa}$、设计温度 $-20\sim+300\ ℃$ 的搅拌设备搅拌轴 |
| HG 5—748《釜用机械密封基本型式及参数》 | 基本型式与参数 |
| HG/T 2057《搪玻璃搅拌容器用机械密封》 | 搪玻璃容器专用 |

## 常用系列（表10-34，`#L13487-#L13495`）

| 系列代号 | 结构特征 |
|:---|:---|
| 202、204 | 单端面、小弹簧 |
| 205、206、207、208、222 | 双端面、小弹簧 |
| 212 | 聚四氟乙烯波纹管 |

## 压力上限与适用范围（表10-35，`#L13497-#L13510`）

所有系列共用：轴径 $40\sim220\ \mathrm{mm}$、温度 $\le150\ ℃$、转速 $\le3\ \mathrm{m/s}$。

| 系列代号 | 压力上限 $p$/MPa |
|:---|:---:|
| 202 | ≤0.25 |
| 204 | ≤0.6 |
| 205 | ≤0.6 |
| 206 | ≤1.6 |
| 207 | ≤2.5 |
| 208 | ≤6.3 |
| 212 | ≤0.4 |
| 222 | ≤1.6 |

选型含义：单端面 202/204 用于低压（$\le0.6\ \mathrm{MPa}$）；双端面 206 起覆盖 1.6 MPa，208 可达 6.3 MPa（与 HG/T 2098 上限一致）；四氟波纹管 212 只到 0.4 MPa，但耐腐蚀最好。

## 选用顺序

1. 按 [[机械密封的选型原则]] 定单/双端面、平衡式、弹簧型式；
2. 按介质腐蚀性选环材料代号（表10-36）；
3. 按温度与介质选辅助圈（表10-37）与弹簧材料（表10-38）；
4. 按 $p$、$t$、$v$ 在表10-35 内核对系列上限，超限则改多级或串联结构。

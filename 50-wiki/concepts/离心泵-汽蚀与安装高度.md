# 离心泵-汽蚀与安装高度

## 定义

- **汽蚀（cavitation）**：叶轮入口最低压力点处压力降到该处温度下液体饱和蒸气压 $p_v$ 时，液体部分汽化、溶解气体解吸，生成气泡；气泡流到压力高于 $p_v$ 的区域突然破裂，周围液体高速冲向气泡中心，造成高频局部冲击，使叶轮表面呈海绵状、鱼鳞状剥蚀，并伴噪声与震动（#L3717-#L3721）。
- **气缚（air binding）**：启动前泵壳未充满液体、内存在空气，因空气密度小、离心力小，吸入口真空不足以吸入液体，泵空转不输液（#L3299）。与汽蚀是两件事：气缚在启动，汽蚀在运行。
- **有效汽蚀余量 $\Delta h_{\mathrm a}$（available NPSH）**：泵入口处压头余量，与吸液管路高度、管径有关，与泵本身无关（#L3735-#L3739）。
- **必需汽蚀余量 $\Delta h_{\mathrm r}$（required NPSH）**：液体从泵入口流到叶轮内最低压力点 K 处的全部压头损失，由泵结构与流量决定（#L3743）。

## 判据 / 计算

入口压头（槽液面 0—0 与泵入口 1—1 列伯努利方程）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{p_1}{\rho g}=\dfrac{p_0}{\rho g}-H_{\mathrm g}-\dfrac{u_1^{2}}{2g}-\Sigma H_{\mathrm f}$ | （4-1） |
| **文字式** | $\dfrac{\text{入口压力}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}\times g}=\dfrac{\text{液面压力}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}\times g}-\text{安装高度}_{\text{【m】}}-\dfrac{\left(\text{入口流速}_{\text{【m/s】}}\right)^{2}}{2g}-\text{吸入管路压头损失}_{\text{【m】}}$ |  |

有效汽蚀余量：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta h_{\mathrm a}=\left(\dfrac{p_1}{\rho g}+\dfrac{u_1^{2}}{2g}\right)-\dfrac{p_v}{\rho g}$ | （4-2） |
| **文字式** | $\text{有效汽蚀余量}_{\text{【m】}}=\left(\dfrac{\text{入口压力}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}\times g}+\dfrac{\left(\text{入口流速}_{\text{【m/s】}}\right)^{2}}{2g}\right)-\dfrac{\text{饱和蒸气压}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}\times g}$ |  |

原书编号：式(2-12)、(2-13)，见 #L3713、#L3737。最大允许安装高度由 (4-1)(4-2) 联立改写：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H_{\mathrm g}\le\dfrac{p_0-p_v}{\rho g}-\Sigma H_{\mathrm f}-\Delta h_{\mathrm r}$ | （4-3） |
| **文字式** | $\text{安装高度}_{\text{【m】}}\le\dfrac{\text{液面压力}_{\text{【Pa】}}-\text{饱和蒸气压}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}\times g}-\text{吸入管路压头损失}_{\text{【m】}}-\text{必需汽蚀余量}_{\text{【m】}}$ |  |

**说明**：式(4-3) 是原书 (2-12)、(2-13) 的代数改写（令 $\Delta h_{\mathrm a}\ge\Delta h_{\mathrm r}$），原书未单列此式，使用时以书中例题的算法为准。

汽蚀判据（#L3747）：

- $\Delta h_{\mathrm a}>\Delta h_{\mathrm r}$：$p_K>p_v$，不汽蚀；
- $\Delta h_{\mathrm a}\le\Delta h_{\mathrm r}$：发生（或接近发生）汽蚀。

## 适用范围与边界

- 汽蚀判据针对**叶轮入口最低压力点 K**，不是泵入口截面；$\Delta h_{\mathrm r}$ 由厂家样本给出，随流量变化（#L3725、#L3743）。
- $\Delta h_{\mathrm a}$ 随安装高度升高、吸入管流速与压头损失增大而减小（#L3739）—— 所以"泵装得越高越容易汽蚀"。
- 输送**接近沸点**的液体（如热水、液化气）时，$p_v$ 大，允许安装高度可能为负（泵必须装在槽面以下）。
- 气缚的处置是启动前灌泵（底阀 + 灌液），不是降安装高度（#L3299）。

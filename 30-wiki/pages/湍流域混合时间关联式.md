# 湍流域混合时间关联式

低黏液体的混合一般在湍流域进行，此时 $C_1$（混合准数 $N_{\theta M}$）为常数（`#L3041`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_1=N_{\theta M}=N\theta_M=K\left(\dfrac{D}{d}\right)^{\alpha}$ | （3-6） |
| **文字式** | $\text{混合准数}=\text{转速}_{\text{【1/s】}}\times\text{混合时间}_{\text{【s】}}=K\times\left(\dfrac{\text{搅拌设备内径}_{\text{【m】}}}{\text{搅拌器直径}_{\text{【m】}}}\right)^{\alpha}$ |  |

式中 $\alpha$ 为常数，通常在 1.5～2.5 之间；$K$ 为衰减常数（`#L3045-#L3047`，OCR 原文 $\alpha$ 上标残损、单位缺失，按上下文补）。

## 两条结论

1. **同一设备里 $d$ 越大 $C_1$ 越小**，混合性能越好——“大搅拌器的混合作用比小桨明显有效”（`#L3049`）。
2. 经验范围：设计得当的普通混合过程，$C_1=20\sim80$ 即可获得良好混合效果（`#L3051`）。

## 原书 §4.3.4–§4.5：把"循环"和"湍动"拆成两项的关联式

湍流有挡板、$Re=d^{2}n/\nu\sim10^{4}$ 时，永田把混合速率拆成**循环项 + 湍动项**（`#L5540`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{1}{\theta_{M}}=0.1\left\{n\left(\dfrac{d}{D}\right)^{3}N_{qd}+0.21\,n\left(\dfrac{d}{D}\right)\sqrt{\dfrac{N_{p}}{N_{qd}}}\right\}\left(1-e^{-13(d/D)^{2}}\right)$ | （4.53） |
| **文字式** | $\dfrac{1}{\text{混合时间}}=0.1\left\{\text{循环速度}+0.21\times\text{湍动速度}\right\}\times\left(1-e^{-13(\text{径比})^{2}}\right)$ |  |

三项的物理身份（`#L5548`、`#L5554`）：

- $n(d/D)^{3}N_{qd}$：循环速度。$q_{d}=N_{qd}nd^{3}$ 除以釜体积 $\propto D^{3}$ 即得。
- $n(d/D)\sqrt{N_{p}/N_{qd}}$：湍动速度。因为 $nd\sqrt{N_p/N_{qd}}$ 相当于波动速度，除以扩散距离 $D$ 即得。
- $\left(1-e^{-13(d/D)^{2}}\right)$：输出流的散布程度（级数型修正），$d/D$ 很小时急剧趋零——**小桨再快也搅不动全釜**。

无因次形式（`#L5544`）：

$$\frac{1}{N_{M}}=\frac{1}{\theta_{M}n}=0.1\left\{(d/D)^{3}N_{qd}+0.21(d/D)\sqrt{N_{p}/N_{qd}}\right\}\left(1-e^{-13(d/D)^{2}}\right)\tag{4.53'}$$

**两条限制**：① 系数 0.1 取决于混合判据（95%/99%）与示踪剂注入条件，不可当普适常数（`#L5579`）；② $Re<10^{4}$ 起 $1/(\theta_{M}n)$ 开始下降（图4.26，`#L5587`）。

### 配套的流数估算式

|  |  |  |
|:---|:---:|---|
| **符号式** | $N_{qd}\propto\left(\dfrac{d}{D}\right)^{-0.25}\left(\dfrac{b}{D}\right)n_{p}^{0.7}$ | （4.55） |
| **文字式** | 输出流数 ∝ 径比的 $-0.25$ 次方 × 相对叶宽 × 叶片数 $^{0.7}$ |  |

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{N_{p}}{N_{qd}}=1.83\sqrt{n_{p}}\left\{\left(\dfrac{d}{D}\right)+0.6\right\}^{3}\left\{0.55+5\left(\dfrac{d}{D}\right)\right\}^{0.4}$ | （4.56） |
| **文字式** | 剪切/循环比 = $1.83\times\sqrt{\text{叶片数}}\times(\text{径比}+0.6)^{3}\times(0.55+5\times\text{径比})^{0.4}$ |  |

注意式(4.55) 与 §3.3 的式(3.5) 口径不同（$-0.25$ vs $-2.5$ 次方），后者是对 $d/D$ 的强反比；两式来源不同，代入前先核对是否含挡板、是否同一 $N_{qd}$ 定义（`#L3919`、`#L5583`）。

### 无挡板时 C.R.Z. 拖的长尾

无挡板容器叶轮周围有 C.R.Z.，它与外侧拟自由涡流区之间的交换由湍动扩散控制（`#L5593`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\theta_{M}'=k_{4}\dfrac{r_{c}^{2}}{D_{\text{湍}}},\qquad k_{4}\approx1;\qquad (\theta_{M})_{\text{总}}=(2\sim3)\theta_{M}$ | （4.57）（4.58） |
| **文字式** | C.R.Z. 混合时间 = 涡核半径平方 ÷ 湍动扩散系数；总混合时间取式(4.53) 值的 2~3 倍 |  |

这就是"无挡板混合曲线有长尾巴"的定量说法，也是为什么加挡板后 $\theta_M$ 能掉一半以上。

### 湍流域的普遍结论

- $N_{M}=\theta_{M}n=$ 常数 → $\theta_{M}\propto1/n$（4.22)(4.52)，即**混合只数转了几圈**（`#L5332`、`#L5438`）。
- 层流域换成另一组不变量：$\theta_{M}^{2}P_{v}g_{c}/\mu=$ 常数、$E\theta_{M}/\mu D^{3}=$ 常数（4.41），其中 $E=P\theta_{M}$ 是**混合能**（`#L5366`、`#L5374`）。
- 功率与混合时间的关系比想象中弱：功率主要对应微观混合（$\varepsilon$），宏观混合由对流+湍动扩散决定（`#L5536`）。

## 用法

给定设备几何与转速，先用 （3-6） 估 $C_1$，再用 $\theta_M=C_1/N$ 得混合时间；反过来由允许的 $\theta_M$ 反算所需转速。

- $K$ 与 $\alpha$ 需按桨型取值或标定，书中未给全表，实际用时应以同类桨型实测数据回归；
- 该式只适用于湍流域；层流与过渡流见 [[层流域搅拌器混合效率对比]]、[[过渡流域混合特性]]；
- 体积很大时混合时间的体积效应不可忽略，见 [[混合过程的混合时间与循环时间]]。

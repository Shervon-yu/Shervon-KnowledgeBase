# 测速管与孔板流量计

## 测速管（皮托管）（`#L2725-#L2760`）

构造：两根弯成直角的同心套管，内管壁无孔、管口正对流向；外管近端点沿圆周开若干测压小孔；环隙端点封闭。U 形压差计两端分别接内管与环隙。

原理：流体到管口被截住、速度降为零，动能全部转为静压能，内管测得**冲压能** $\dfrac{p_1}{\rho}+\dfrac{u_1^2}{2}$；外管小孔与流向平行，只测静压能 $\dfrac{p_1}{\rho}$。两者之差即动能：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_1=\sqrt{\dfrac{2\Delta p}{\rho}}$ | （1-68） |
| **文字式** | $\text{点速度}_{\text{【m/s】}}=\sqrt{\dfrac{2\times\text{冲压能与静压能之差}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}}}$ |  |

U 形管读数 $R$、指示液密度 $\rho_0$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_1=\sqrt{\dfrac{2gR(\rho_0-\rho)}{\rho}}$ | （1-69a） |
| **文字式** | $\text{点速度}_{\text{【m/s】}}=\sqrt{\dfrac{2\times\text{重力加速度}\times\text{读数}_{\text{【m】}}\times(\text{指示液密度}-\text{流体密度})}{\text{流体密度}}}$ |  |

气体时 $\rho_0\gg\rho$，简化为 $u_1=\sqrt{\dfrac{2gR\rho_0}{\rho}}$（1-69b）。

**要点**：测速管测的是**点速度**。测平均速度要用管中心 $u_{\max}$ 算 $Re_{\max}$，再查图 1-40 得 $u/u_{\max}$。

例 1-23（`#L2761-#L2780`）：φ273×6.5 空气管（$d$=0.26 m）、30 ℃、表压 3 kPa、$R$=17 mm 水柱：

$\rho=\dfrac{pM}{RT}=1.2$ kg/m³ → $u_{\max}=16.7$ m/s → $Re_{\max}=2.8\times10^5$ → 查图 $u/u_{\max}=0.84$ → $u=14$ m/s → $q_m=0.892$ kg/s。

## 孔板流量计（`#L2781-#L2870`）

### 理想推导（`#L2805-#L2817`）

孔板前 1 截面（管截面 $A_1$）与缩脉 2 截面（$A_2$）间列机械能衡算（暂不计损失）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{u_2^2-u_1^2}{2}=\dfrac{p_1-p_2}{\rho}$ | （1-70） |
| **文字式** | $\dfrac{\text{缩脉流速}^2-\text{管流速}^2}{2}=\dfrac{\text{孔板前后压差}}{\text{密度}}$ |  |

用连续性 $u_1=u_2A_2/A_1$ 消去 $u_1$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_2=\dfrac{1}{\sqrt{1-(A_2/A_1)^2}}\sqrt{\dfrac{2\Delta p}{\rho}}$ | （1-71） |
| **文字式** | $\text{缩脉流速}_{\text{【m/s】}}=\dfrac{1}{\sqrt{1-(\text{缩脉面积}/\text{管截面积})^2}}\sqrt{\dfrac{2\times\text{压差}}{\text{密度}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_m=A_2u_2\rho=\dfrac{A_2}{\sqrt{1-(A_2/A_1)^2}}\sqrt{2\rho\Delta p}$ | （1-72） |
| **文字式** | $\text{质量流量}_{\text{【kg/s】}}=\dfrac{\text{缩脉面积}}{\sqrt{1-(\text{缩脉面积}/\text{管截面积})^2}}\sqrt{2\times\text{密度}\times\text{压差}}$ |  |

### 实际式（`#L2819-#L2835`）

缩脉位置与面积难测，实际用孔口面积 $A_0$、直径比 $\beta=d_0/D$，并引入校正系数 $C$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_m=\dfrac{CA_0}{\sqrt{1-\beta^4}}\sqrt{2\rho\Delta p}$ | （1-73） |
| **文字式** | $\text{质量流量}_{\text{【kg/s】}}=\dfrac{\text{校正系数}\times\text{孔口面积}}{\sqrt{1-\text{直径比}^4}}\sqrt{2\times\text{密度}\times\text{压差}}$ |  |

令流量系数 $\alpha=\dfrac{C}{\sqrt{1-\beta^4}}$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_m=\alpha A_0\sqrt{2\rho\Delta p}$ | （1-74） |
| **文字式** | $\text{质量流量}_{\text{【kg/s】}}=\text{流量系数}\times\text{孔口面积}\times\sqrt{2\times\text{密度}\times\text{压差}}$ |  |

气体/蒸气需乘膨胀系数 $\varepsilon$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_m=\varepsilon\alpha A_0\sqrt{2\rho\Delta p}$ | （1-75） |
| **文字式** | $\text{质量流量}_{\text{【kg/s】}}=\text{膨胀系数}\times\text{流量系数}\times\text{孔口面积}\times\sqrt{2\times\text{密度}\times\text{压差}}$ |  |

### 流量系数 α 与试差（`#L2829-#L2850`）

$\alpha$ 与取压方式、$\beta^2$、$Re$ 有关（图 1-42）。$Re$ 超过某限度后 $\alpha$ 近似定值，常用 0.6~0.7。**测流量范围应落在 α 为定值的区域**。

计算矛盾：$\alpha$ 要 $Re$，$Re$ 要流速，流速未知 → 试差：
1. 假设 $\alpha$ 与 $Re$ 无关，按 $\beta^2$ 查图得 $\alpha$；
2. 由 1-74/1-75 算 $q_m$；
3. 反算 $u_1=q_m/(\rho A_1)$、$Re=Du_1\rho/\mu$，查图得新 $\alpha$；
4. 与假设一致即收敛。

例 1-24（`#L2855-#L2885`）：400 ℃、1.962 MPa 表压、$D$=190 mm、$d_0$=130 mm、$\rho$=6.82 kg/m³、$\mu$=23.75 μPa·s、$\Delta p$=58.86 kPa、$\varepsilon$=1 → $q_m=8.1$ kg/s；校核 $u=42$ m/s、$Re=2.3\times10^6$、$\alpha=0.68$ 与原设一致。

### 安装与优缺点（`#L2850-#L2852`）

上游直管 ≥10$D$、下游 ≥5$D$；构造简单、易制造安装；**主要缺点是能量损失大**。喷嘴、文丘里管用型面引导减少涡流，损失更小，但制造复杂。

## 判断

- 测速管的 1-69b 在气体时把 $(\rho_0-\rho)$ 近似为 $\rho_0$，误差约 $\rho/\rho_0$——常压气体约 0.1%，可忽略；高压气体则不能省。
- 孔板的试差不是数学需要，而是"α 依赖 Re"这一实验事实的必然结果；把 α 当常数只在 α 定值区成立。

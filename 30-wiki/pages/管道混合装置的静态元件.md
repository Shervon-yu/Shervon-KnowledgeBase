# 管道混合装置的静态元件

## 一、三通混合元件（`#L18199-#L18215`）

三种型式（图15-25）：(a) 优于 (b)，(c) 最差——(c) 型两股流体**平行流动**混合，没有对冲。

适用：气体、低黏液体的快速混合。关键参数是支管与主管的**质量速度比**，一般约 **3**：过低不利注入，过高会造成「穿透」；良好混合所需的支管质量流速随支管尺寸增大而减小。

## 二、挡板式混合器（`#L18217-#L18253`）

### Ⅰ 型（常用，`#L18219-#L18225`）

- 适用较低黏液体；典型 3~5 块挡板，**挡板间距≈2 倍管径**；两种挡板交替排列——圆环形（内孔半径 $r_1$、外半径 $r_0$）与三圆缺形（圆缺半径 $r_2$、跨梁宽 $b$）；
- 设计三步：① 定设计压降、均摊到每块板，按表观流速算每块板的速度头数 $N_{VH}$；② 由表15-18 查开孔率 $a$、$r_1$、$r_2$、$b$；③ 按板厚与跨梁宽 $b$ 校核机械强度。

表15-18（`#L18241-#L18253`）节选：

| $N_{VH}$ | $a$ | $r_1/r_0$ | $r_2/r_0$ | $b/r_0$ |
|:---|:---|:---|:---|:---|
| 0.5 | 0.7583 | 0.8708 | 0.7796 | 0.1729 |
| 1 | 0.6847 | 0.8275 | 0.7365 | 0.2590 |
| 5 | 0.4762 | 0.6901 | 0.6039 | 0.5244 |
| 10 | 0.3837 | 0.6194 | 0.5376 | 0.6569 |
| 50 | 0.2063 | 0.4542 | 0.3871 | 0.9578 |
| 100 | 0.1523 | 0.3902 | 0.3304 | 1.0712 |
| 1000 | 0.0515 | 0.2269 | 0.1891 | 1.3539 |

### Ⅱ 型（Schaschlick，`#L18227-#L18237`）

梯形弧板对称交叉排列，每块占管截面一半（板空率 $\alpha=0.5$），板间距 1 倍管径。$Re=8000$ 时经 4~5 倍管径即可把不均匀强度降到 $10^{-4}$；每块板压降约 7 倍速度头。

## 三、孔板式混合器（`#L18255-#L18352`）

### 型式与适用（`#L18259-#L18281`）

| 型式 | 适用 | 要点 |
|:---|:---|:---|
| 多孔板串联（图15-27/15-29） | 气-液、液-液非均相；高黏难混（如油品硫酸洗涤） | 3~20 块，相邻孔交错；管截面/孔总面积 3~10；每板压降 0.007~0.02 MPa；无转动部件，适合难密封流体；能耗较大 |
| 单孔高速孔板（图15-28） | 可溶液体快速混合、快速气相反应稀释 | 孔径受腐蚀、磨蚀、污堵、成本限制；清洁环境可用 <φ0.5 mm，工程最小 φ3 mm，易污垢时用 φ12 mm 以上 |

### 设计计算（`#L18285-#L18351`）

**① 混合能**（单位体积耗能，`#L18297`）：一般油品碱洗、水洗等易混过程约 **71600 N·m/m³（0.072 MPa）**；难混过程（硫酸洗涤、丙烷碱洗脱 COS）约 **1.8×10⁵ N·m/m³（0.180 MPa）**。

**② 接触时间**（`#L18299`）：易混 10~30 s；难混约 50 s。

**③ 孔板数**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N=\dfrac{\Delta p}{\Delta p_1}$ | （15-31） |
| **文字式** | $\text{孔板数}=\dfrac{\text{混合能}_{\text{【MPa】}}}{\text{每块孔板压降}_{\text{【MPa】}}}$ |  |

$\Delta p_1$ 一般取 0.007~0.014 MPa。

**④ 孔面积**（柏努利原理）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_0=\dfrac{Q}{K}\sqrt{\dfrac{\rho_m}{0.204g\Delta p_1}}$ | （15-32） |
| **文字式** | $\text{孔面积}_{\text{【m²】}}=\dfrac{\text{液体流量}_{\text{【m³/s】}}}{\text{流量系数}}\times\sqrt{\dfrac{\text{混合液密度}_{\text{【kg/m³】}}}{0.204\times\text{重力加速度}_{\text{【m/s²】}}\times\text{每块孔板压降}_{\text{【Pa】}}}}$ |  |

工程式（$K=0.65$、$\Delta p_1$ 用 MPa、$Q$ 用 m³/h）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_0=0.302\times10^{-6}Q\sqrt{\dfrac{\rho_m}{\Delta p_1}}$ | （15-33） |
| **文字式** | $\text{孔面积}_{\text{【m²】}}=0.302\times10^{-6}\times\text{液体流量}_{\text{【m³/h】}}\times\sqrt{\dfrac{\text{混合液密度}_{\text{【kg/m³】}}}{\text{每块孔板压降}_{\text{【MPa】}}}}$ |  |

**⑤ 主管与间距**（`#L18335`）：主管 = 孔径的 2~10 倍（压降小取下限、大取上限）；相邻孔板间距约 3 倍主管直径。

**⑥ 接触时间校核**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $t=\dfrac{AL(N-1)}{Q}$ | （15-34） |
| **文字式** | $\text{接触时间}_{\text{【s】}}=\dfrac{\text{主管截面积}_{\text{【m²】}}\times\text{相邻孔板间距}_{\text{【m】}}\times\left(\text{孔板数}-1\right)}{\text{液体流量}_{\text{【m³/s】}}}$ |  |

不满足则调整孔板间距。

## 判断

- 挡板式与孔板式的共同逻辑是「把混合能摊到多级」：单级压降小、总压降等于 N 倍，靠反复分流—汇合累积混合。
- 孔板式最关键的两个数是**混合能**与**接触时间**，它们由工艺（易混/难混）先定，孔径与板数是从属结果，不要反过来先凑孔径。

# 搅拌设备的制造与检验要求

## 一、搅拌容器（`#L19372-#L19388`）

| 部位 | 依据标准 |
|:---|:---|
| 容器本体 | 常压：JB/T 4735 第 15 章；压力容器：GB 150 第 10 章 |
| 凸缘法兰 | HG 21564 技术要求 |
| 安装底盖 | HG 21565 技术要求 |

**抛光要求**：内表面 $R_a$ = 0.8~0.2 μm；焊缝平滑，凸起或凹坑 <0.5 mm；任意 4×10⁴ mm² 正方形内，深度 ≤0.5 mm、直径 ≤1.0 mm 的麻点不超过 5 个。

**压力试验补充**：$(p_2>p_1)$ 的小直径夹套容器，无法入内检查时，允许在焊夹套前把内容器试验压力提高到按夹套压力确定的试验压力；试压**不包括轴封**，轴封处加盲板。

## 二、搅拌器（`#L19392-#L19404`）

| 项 | 要求 |
|:---|:---|
| 未注公差（加工面） | GB 1804 第 12 级 |
| 未注公差（非加工面） | GB 1804 第 14 级；铸件非加工面 GB 6414 CT14 |
| 抛光 | 有抛光要求时，接触物料面同容器 |
| 垂直度 | 锚式/框式/桨式轴线与桨叶垂直，允差为桨叶总长的 **4/1000** 且 ≤5 mm |
| 静平衡 | 转速 **<60 r/min** 可不做；**≥60 r/min** 应做 |
| 焊接结构 | 设计须提出焊接材料/方法要求 |

## 三、搅拌轴（`#L19406-#L19428`）

| 项 | 要求 |
|:---|:---|
| 未注公差 | GB 1804 第 12 级 |
| 配合面同轴度 | GB 1184 第 8 级 |
| 直线度 | 见表17-1（见下） |
| 填料密封处 | $R_a\le0.8$ μm |
| 密封段硬度 | 35/40/45/40Cr 需调质：碳钢 HB190~250、铬合金钢 HB240~290；奥氏体不锈钢需硬化（镀硬铬、氮化、堆焊、喷陶瓷） |
| 长轴存放 | 吊挂直立，否则防变形 |

### 表17-1 轴的直线度允差

| 转速/r·min⁻¹ | 每米轴长允差/mm |
|:---|:---|
| <100 | <0.15 |
| 100~1000 | <0.10 |
| >1000~1800 | <0.08 |

## 四、静平衡与动平衡（`#L19430-#L19458`）

| 试验 | 判据 |
|:---|:---|
| 组装后静平衡 | 转速 <100 r/min 且轴长 <2.5 m 可不做 |
| 组装后动平衡 | 转速 ≥150 r/min 且轴长 ≥3.6 m 需做；**柔性轴组件均应做** |

许用不平衡度可用力矩或偏心距表示；用偏心距时，动平衡校正平面许用值取 $[e]$ 之半。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[M]=10^{-4}[e]Q$ | （17-1） |
| **文字式** | $\text{许用不平衡力矩}_{\text{【N·m】}}=10^{-4}\times\text{许用偏心距}_{\text{【mm】}}\times\text{组合件重力}_{\text{【N】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[e]=9.55G/n$ | （17-2） |
| **文字式** | $\text{许用偏心距}_{\text{【mm】}}=\dfrac{9.55\times\text{平衡精度等级}_{\text{【mm/s】}}}{\text{搅拌轴转速}_{\text{【r/min】}}}$ |  |

平衡精度等级 $G$：一般 **6.3 mm/s**；高压/高速/危险物料取 **2.5 mm/s**；低压/低速/一般物料取 **16 mm/s**。

## 五、试运转（`#L19464-#L19472`）

1. 组装后先**空载**试运转 ≥30 min（柔性轴除外），再以水代料负荷试运转：充满到工作液位、达工作压力、≥4 h，全面检查密封、噪声、运转性能；设备平稳、噪声 ≤85 dB(A)；
2. 机械密封时，试运转时间还要达到密封**跑合时间**；
3. 柔性轴：在正常工作**最低液位**充水试运转，严禁空载或低于工作液位试验。

## 六、旋转精度（`#L19474-#L19514`）

### 轴封处径向位移

取下列三者之一：所选轴封标准允许值；图纸注明值；无规定时按下式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[\delta]_{(x=l_0)}=0.1K_3\sqrt{d}$ | （17-3） |
| **文字式** | $\text{轴封处允许径向位移}_{\text{【mm】}}=0.1\times\text{径向位移系数}\times\sqrt{\text{设计轴径}_{\text{【mm】}}}$ |  |

$K_3$ 按表9-104 取；无轴封敞口设备可放宽到 0.5~1.0；$K_3$ 的含义是 **φ100 mm 轴时的实际允许径向位移（mm）**。

### 轴向窜动与泄漏

| 项 | 限值 |
|:---|:---|
| 波纹管型机械密封轴向窜动 | ±0.4 mm |
| 其他机械密封 | ±0.2 mm |
| 轴封泄漏量 | 符合工艺要求或密封标准允许值 |
| 悬臂轴末端径向位移 | 按工艺或防刮壁要求、图纸注明值 |

## 判断

- 这套检验的核心是两个「位移」：轴封处径向位移（17-3）与悬臂端位移——前者保密封寿命，后者保不刮壁，二者都不属于强度问题而是**刚度与制造精度**问题。
- 平衡门槛的两组数（60/100/150 r/min、2.5/3.6 m）说明：低速小轴靠制造精度即可，一旦进入柔性轴区间必须动平衡。

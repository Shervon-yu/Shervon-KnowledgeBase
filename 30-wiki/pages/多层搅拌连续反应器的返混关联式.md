# 多层搅拌连续反应器的返混关联式

## 装置型式

连续操作的多层叶轮反应器，长径比大时轴向返混急剧上升；靠分隔板把釜切成若干室可压制返混（`#L6520`、`#L6524`）。三种型式（图5.23）：

| 型式 | 结构 | 特点 |
|:---|:---|:---|
| (a) | 多层叶轮 | 结构最简单，返混最大 |
| (b1) | 分隔板 + 每室一叶轮 | 压制返混最好，但轴长、拆装难 |
| (b2) | 分隔板 + 每室两叶轮，通道在中心 | 折中 |
| (c) | 约束流道、便于拆装的改进型；(c2) 取消分隔板、加大旋转圆盘 | 牺牲部分返混控制换可维护性 |

实验叶轮条件（`#L6528`）：$d=D/2$、$b=0.05D$、$n_p=2$、$H_i=D/2$、$H_p=D/2$、$L=2\sim7D$。

## 返混分数 φ

**定义**：$\phi$ 是把实测 RTD 拟合成"活塞流段 + 完全混合段"（串联组合模型）时，**活塞流所占的容积分数**（见 [[循环流与组合模型]]）。$\phi\to1$ 近似活塞流，$\phi\to0$ 近似完全混合。

关联式（`#L6536`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi=1.9\left[\dfrac{Lu/\nu}{nd^{2}/\nu}\left(\dfrac{A_h}{A}\right)^{0.46D/H_p}\right]^{2/3}$ | （5.64） |
| **文字式** | 活塞流分数 $=1.9\times\left[\dfrac{\text{流动雷诺数}}{\text{搅拌雷诺数}}\times\text{通道面积比的幂}\right]^{2/3}$ |  |

$A_h$ 是分隔板与器壁间通道（间隙 $d_R-d_r$）的通流面积、$A$ 是反应器横截面积；$(c_1)$、$(c_2)$ 型实测偏差 <8%（`#L6540`）。适用 $\phi<0.5$ 区间。

**结构信息的去向**：$A_h/A$ 与 $D/H_p$ 把"隔板开多大孔、几层板"折进一个面积比里——所以 (b1)(b2)(c) 三种型式能用同一条式子（`#L6538`）。

## 经验规律

`#L6544` 给出量级规律：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi\propto(n\theta)^{-2/3}\left(\dfrac{L}{D}\right)^{4/3}$ | （5.65） |
| **文字式** | 转速越高、停留时间越长、长径比越小，返混越强（$\phi$ 越小） |  |

代 $\theta=L/u$ 后（`#L6556`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi=K\left[\dfrac{Du/\nu}{nd^{2}/\nu}\cdot\dfrac{L}{D}\left(\dfrac{d}{D}\right)^{2}\right]^{2/3}$ | （5.66） |
| **文字式** | $\phi$ 只取决于流动雷诺数与搅拌雷诺数之比、长径比、桨径比 |  |

**推论**：只要 $\dfrac{Du/\nu}{nd^2/\nu}$ 恒定，$\phi$ 不变——这直接决定了放大方式（下节）。$H_i$（叶轮间距）影响很小，取 $H_i/D=1/3$ 即可，得简化式(5.67)。$K$ 只与叶轮形状、$d/D$ 有关。

## 放大结论：必须保持转速

几何相似放大时（`#L6570`、`#L6576`）：

- 流量 $v=V/\theta\propto D^{3}$，故流速 $u\propto D$；
- 于是 $\dfrac{Du/\nu}{nD^{2}/\nu}\propto\dfrac{1}{n}$，与 $D$ 无关；
- 流向上的动能 $E_K=\frac{1}{2}v\rho u^{2}\propto D^{5}$；
- 叶轮给流体的能量 $E_A\propto n^{3}D^{5}$；
- 故 $\dfrac{E_K}{E_A}\propto\dfrac{1}{n^{3}}$。

**所以：几何相似的两釜要保持相同 $\phi$，必须保持相同转速 $n$**——不是等 $P/V$、也不是等叶端速度。这条与"等 $P/V$ 放大"（见 [[几何相似放大与转速关系]]）是两套不同判据，别混用（`#L6580`）。

## 例5.1：φ 的完整算法

任务（`#L6598`）：一级反应 $k_1=0.18\ \mathrm{min}^{-1}$，$C_i=5$ g·mol/l，要求转化率 85%（出口 0.75），处理量 24 m³/天。装置 $d/D=0.5$、$b/D=0.05$、$n_p=2$、$H_i/D=0.5$、$L/D=7$、$N=150$ r/min $=2.5$ r/s。

1. 由式(5.67) 得 $\phi=34.8\,\theta^{-2/3}$（$\theta$ 以 s 计）；
2. 试 $\theta=1000$ s → $\phi=0.348$ → 查图5.21 得 $M=1.4$、$\Phi=0.55$ → 两段出口浓度 $C_{pe}=0.25$、$C_{me}=1.25$ → $C_e=0.7005$（**小于目标 0.75，转化率不够**）；
3. 试 $\theta=900$ s → $\phi=0.374$ → $M=1.70$、$\Phi=0.58$ → $C_{pe}=0.338$、$C_{me}=1.35$ → $C_e=0.7638$（**过冲**）；
4. 内插 $\theta=920$ s → $V=v\theta=0.255\ \mathrm{m^3}$ → $D=0.36$ m、$L=2.52$ m。

**对照三种流型的容积代价**（`#L6670`）：

| 流型 | 所需停留时间 | 相对本设计 |
|:---|:---|:---|
| 完全混合流 | 1880 s | 49%（更费） |
| 活塞流 | 633 s | 145%（更省） |
| 本设计（$\phi\approx0.36$） | 920 s | 100% |

# 鞍式支座的允许载荷

## 定义

鞍式支座的允许载荷 [Q] 是标准给出的每个鞍座能承受的最大支座反力。其确定方法依据 GB/T 47042—2014《卧式容器》，由三种受力工况（腹板水平拉应力、地震组合截面压应力、温差组合截面压应力）分别导出允许值后取小（#L1205）。

## 判据与计算

### 2.1 腹板水平拉应力（工况 a，#L1209-#L1227）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{9}=\dfrac{K_{9}Q}{H_{\mathrm{s}}b_{0}+b_{\mathrm{r}}\delta_{\mathrm{re}}}$ | （2-1） |
| **文字式** | $\text{腹板水平拉应力}_{\text{【MPa】}}=\dfrac{K_{9}\times\text{每个支座反力}_{\text{【N】}}}{\text{计算高度}_{\text{【mm】}}\times\text{腹板厚度}_{\text{【mm】}}+\text{垫板有效宽度}_{\text{【mm】}}\times\text{垫板有效厚度}_{\text{【mm】}}}$ |  |

- 系数 K9：包角 θ = 120° 时 K9 = 0.204；θ = 150° 时 K9 = 0.259（#L1227）。

### 2.2 地震引起的组合截面压应力（工况 b，#L1229-#1253）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{sa}}=-\dfrac{Q}{A_{\mathrm{sa}}}-\dfrac{\alpha_{1}QH}{Z_{\mathrm{r}}}-\dfrac{2\alpha_{1}QH_{\mathrm{v}}}{A_{\mathrm{sa}}(L-2A)}$ | （2-2） |
| **文字式** | $\text{地震组合压应力}_{\text{【MPa】}}=-\dfrac{\text{支座反力}}{\text{组合截面积}}-\dfrac{\text{水平地震影响系数}\times\text{支座反力}\times\text{鞍座高度}}{\text{组合截面抗弯系数}}-\dfrac{2\times\text{水平地震影响系数}\times\text{支座反力}\times\text{圆筒中心至基础距离}}{\text{组合截面积}\times(\text{封头切线间距离}-2\times\text{鞍座中心至切线距离})}$ |  |

- 上式为 2α1Q ≤ 2fQ 时；当 2α1Q > 2fQ 时第三项分子用 2α1fs（fs = 0.05 钢对特氟隆），见原文式（#L1231）。
- 危险取值：设防烈度 9 度（α1 = 0.32）、fs = 0.05（#L1251-#L1253、#L1273）。

### 2.3 温差引起的组合截面压应力（工况 c，#L1255-#L1263）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{sa}}^{\mathrm{t}}=-\dfrac{Q}{A_{\mathrm{sa}}}-\dfrac{fQH}{Z_{\mathrm{r}}}$ | （2-3） |
| **文字式** | $\text{温差组合压应力}_{\text{【MPa】}}=-\dfrac{\text{支座反力}}{\text{组合截面积}}-\dfrac{\text{静摩擦系数}\times\text{支座反力}\times\text{鞍座高度}}{\text{组合截面抗弯系数}}$ |  |

- 危险取值：钢对水泥静摩擦系数 f = 0.4（#L1263、#L1275）。

### 2.4 工况比较与核算依据（§4.2，#L1269-#L1281）

b 工况最危险时 2α1 − fs = 2×0.32 − 0.05 = 0.59；经比较 b 工况最苛刻，取计算系数 f′ = 0.59 作组合截面压应力核算依据，可涵盖 9 度地震与最危险温差工况。允许载荷计算采用 a、c 两种工况，即：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left[\sigma\right]\leqslant\max\left[\sigma_{\mathrm{sa}}^{\mathrm{t}},\ \sigma_{9}\right]$ | （2-4） |
| **文字式** | $\text{材料许用应力}\leqslant\max(\text{温差组合压应力},\ \text{腹板水平拉应力})$ |  |

### 2.5 允许载荷 [Q] 的两种算法（§4.3，#L1285-#L1291）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q]_{\text{水平方法}}=\dfrac{[\sigma](H_{\mathrm{s}}b_{0}+b_{\mathrm{r}}\delta_{\mathrm{re}})}{K_{9}}$ | （2-5） |
| **文字式** | $\text{按水平方法确定的允许载荷}=\dfrac{\text{许用应力}\times(\text{计算高度}\times\text{腹板厚度}+\text{垫板有效宽度}\times\text{垫板有效厚度})}{K_{9}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q]_{\text{组合截面法}}=\dfrac{[\sigma]}{\dfrac{1}{A_{\mathrm{sa}}}+\dfrac{f^{\prime}H}{Z_{\mathrm{r}}}}$ | （2-6） |
| **文字式** | $\text{按组合截面法确定的允许载荷}=\dfrac{\text{许用应力}}{\dfrac{1}{\text{组合截面积}}+\dfrac{f^{\prime}\times\text{鞍座高度}}{\text{组合截面抗弯系数}}}$ |  |

### 2.6 [Q] 的确定（§4.3 d，#L1305-#L1309）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q]=\min\left\{[Q]_{\text{水平方法}},\ [Q]_{\text{组合截面法}}\right\}$ | （2-7） |
| **文字式** | $\text{允许载荷}=\min(\text{水平方法允许载荷},\ \text{组合截面法允许载荷})$ |  |

### 2.7 材料与许用应力取值（#L1293-#L1303）

- 推荐 Q345R：[σ] 取 170 MPa，设计温度范围 -40~200 ℃；
- Q235B 制鞍座：采用修正后的允许载荷（标准已给出）；
- 其他材料：先按 Q345R 初定允许载荷，再按实际材料许用应力修正。

## 适用范围与边界

- 只适用于标准双支点卧式容器鞍式支座（§1.2，#L176）；包角仅 120°/150° 两档（K9 只给了这两档值）。
- 高度修正：第 4 章给出的是标准高度下的允许载荷；鞍座高度高于标准高度时允许载荷降低，应修正（§8.2，#L797-#L799）。
- 本方法给的是支座本体强度校核（腹板拉应力 + 组合截面压应力），不替代圆筒本身在鞍座处的应力校核（后者按 GB/T 47042 卧式容器设计）。
- [Q] 的单位为 N（公式中各项量纲见原文式中说明，#L1215-#L1263）。

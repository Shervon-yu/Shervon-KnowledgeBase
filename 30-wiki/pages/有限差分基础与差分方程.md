# 有限差分基础与差分方程

## 网格与记号（§4.2）

把 $x$ 方向等距剖分 $x_i=i\Delta x$、$y$ 方向 $y_j=j\Delta y$、时间层 $t^n=n\Delta t$，流场量记作 $u_{i,j}=u(x_i,y_j)$、$u_{i,j}^n=u(x_i,y_j,t^n)$（#L2708 前后）。差分方法要做的就是用这些网格值近似导数。

## 用泰勒级数造差分

向后展开 $u_{i-1,j}$（式 4-1，＃L2712），一阶导数可得（式 4-2，＃L2782）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{\partial u}{\partial x}\right)_{i,j}=\dfrac{u_{i+1,j}-u_{i,j}}{\Delta x}+O(\Delta x)$ | （4-4） |
| **文字式** | $\left(\dfrac{\partial\text{函数}}{\partial x}\right)_{i,j}=\dfrac{\text{函数}_{i+1,j}-\text{函数}_{i,j}}{\Delta x}+O(\Delta x)$ |  |

同类结果（式 4-6、4-7、4-8，＃L2812-2824）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{\partial u}{\partial x}\right)_{i,j}=\dfrac{u_{i,j}-u_{i-1,j}}{\Delta x}+O(\Delta x)$；$\left(\dfrac{\partial u}{\partial x}\right)_{i,j}=\dfrac{u_{i+1,j}-u_{i-1,j}}{2\Delta x}+O[(\Delta x)^2]$ | （4-6、4-8） |
| **文字式** | 向后差分一阶精度；中心差分二阶精度 |  |

二阶导数用三点公式（式 4-12，＃L2844）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{\partial^2 u}{\partial x^2}\right)_{i,j}=\dfrac{u_{i+1,j}-2u_{i,j}+u_{i-1,j}}{(\Delta x)^2}+O[(\Delta x)^2]$ | （4-12） |
| **文字式** | $\left(\dfrac{\partial^2\text{函数}}{\partial x^2}\right)_{i,j}=\dfrac{\text{函数}_{i+1,j}-2\text{函数}_{i,j}+\text{函数}_{i-1,j}}{(\Delta x)^2}+O[(\Delta x)^2]$ |  |

要点：一阶导数的中心差分把 $\Delta x$ 项消掉、精度升到二阶；二阶导数的三点式也是二阶；混合导数 $\partial^2u/\partial x\partial y$ 用四点式（式 4-17，＃L2882）；需要更高精度时用五点式（式 4-18，＃L2948，$O[(\Delta x)^4]$）。

## 边界点的一侧差分

物面、入口等边界外侧没有网格点，不能套中心差分。用三点抛物线拟合得到一侧二阶精度公式（式 4-27、4-29，＃L3010-3024）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{\partial u}{\partial y}\right)_{1}=\dfrac{-3u_{1}+4u_{2}-u_{3}}{2\Delta y}+O[(\Delta y)^2]$ | （4-29） |
| **文字式** | $\left(\dfrac{\partial\text{函数}}{\partial y}\right)_{1}=\dfrac{-3\text{函数}_{1}+4\text{函数}_{2}-\text{函数}_{3}}{2\Delta y}+O[(\Delta y)^2]$ |  |

这正是壁面剪应力 $\tau_{\mathrm{w}}=\mu(\partial u/\partial y)_{\mathrm{w}}$（4-30）与壁面热流 $q_{\mathrm{w}}=k(\partial T/\partial y)_{\mathrm{w}}$（4-31）的离散依据——边界导数算不准，摩阻与热流就全错。

## 从偏微分方程到差分方程（§4.3）

以热传导方程（式 4-34，＃L3136）为例：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial T}{\partial t}=\alpha\dfrac{\partial^2 T}{\partial x^2}$ | （4-34） |
| **文字式** | $\dfrac{\partial\text{温度}}{\partial\text{时间}}=\text{热扩散系数}\times\dfrac{\partial^2\text{温度}}{\partial x^2}$ |  |

把时间导数用向前差分（4-32）、空间二阶导数用三点式（4-33）代入，得到显式差分方程（式 4-36、4-37，＃L3148-3182）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $T_i^{n+1}=T_i^{n}+\alpha\dfrac{\Delta t}{(\Delta x)^2}\left(T_{i+1}^{n}-2T_i^{n}+T_{i-1}^{n}\right)$ | （4-37） |
| **文字式** | $\text{温度}_i^{n+1}=\text{温度}_i^{n}+\text{热扩散系数}\times\dfrac{\Delta\text{时间}}{(\Delta x)^2}\left(\text{温度}_{i+1}^{n}-2\text{温度}_i^{n}+\text{温度}_{i-1}^{n}\right)$ |  |

书里强调（式 4-35，＃L3142）：**偏微分方程 = 差分方程 + 截断误差**。右边第一项是实际求解的差分方程，第二项是截断误差；只有截断误差随 $\Delta t,\Delta x\to0$ 趋于零（相容），差分解才可能收敛到原方程的解。

## 显式与隐式

- 显式（4-37）：$T_i^{n+1}$ 只依赖第 $n$ 层的已知值，逐点算、编程简单；但时间步长受稳定性限制（见 [[显式隐式方法与稳定性分析]]）。
- 隐式：若空间导数取第 $n+1$ 层（如 Crank-Nicolson，式 4-40，＃L3218），每步要解一个线性方程组。一维时系数矩阵是三对角（式 4-51，＃L3284），用[[托马斯算法]] 直接解（式 4-42～4-50，＃L3242-3278）。
- 非线性扩散系数 $\alpha=\alpha(T)$（式 4-52、4-53，＃L3290-3298）时，显式处理是把 $\alpha$ 取旧层值，隐式要把系数一起迭代——这是书里"差分方程一般化"的过渡。

## 适用边界

- 泰勒展开推导假设网格等距；非等距网格要用一般坐标变换（见 [[坐标变换与网格生成]]）。
- 截断误差是"格式本身"的误差；实际计算还有舍入误差，两者在稳定性分析里分别处理（§4.5）。
- 中心差分对一阶导数虽二阶精度，但在对流主导问题里会引发振荡（见第 6.6 节数值耗散/色散），不是万能的。

## 判断

差分格式的精度只看主截断误差项；但精度高不等于能用——显式格式的稳定性上限由 §4.5 的 von Neumann 分析给出，中心差分对流项在 $C>1$ 时放大误差。书里把"精度"和"稳定性"分成两节讲，就是提醒这两件事不能混为一谈。

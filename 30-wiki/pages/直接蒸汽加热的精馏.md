# 直接蒸汽加热的精馏

## 适用与装置（`#L12617-#L12625`）

分离**含水溶液**时，可把加热蒸汽直接通入塔釜，省去再沸器。蒸汽鼓泡通过釜液，离开液面的蒸气与釜液达平衡（釜仍相当于一块理论板）。

## 物料衡算（`#L12633-#L12647`）

对塔釜段作物料衡算（$S$ 为加热蒸汽量、$b$ 为釜液量）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $L'+S=V'+b$，$L'x_n=V'y_{n+1}+bx_b$ | （6-54）（6-55） |
| **文字式** | $\text{提馏段液量}+\text{加热蒸汽}=\text{提馏段汽量}+\text{釜液}$ |  |

恒摩尔流下 $S=V'$、$L'=b$，得提馏段操作线：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y=\dfrac{b}{S}x-\dfrac{b}{S}x_b$ | （6-56） |
| **文字式** | $\text{汽相组成}=\dfrac{\text{釜液量}}{\text{蒸汽量}}\times\text{液相组成}-\dfrac{\text{釜液量}}{\text{蒸汽量}}\times\text{釜液组成}$ |  |

## 三条几何特征（`#L12649-#L12657`）

1. 当 $x=x_b$ 时 $y=0$ → **提馏段线与 x 轴交于 $x_b$**（不是对角线上）；
2. 与对角线交点 $x=\dfrac{bx_b}{b-S}=x_W$（间接加热的釜液组成），因 $W=b-S$；
3. 图解法最后一个梯级必须**跨过 x 轴上的 $x_b$** 为止，而不是跨过 $(x_W,x_W)$。

## 为什么多一块板（`#L12659`）

直接蒸汽的冷凝水混入釜液，把釜液**稀释**，$x_b<x_W$ → 分离要求实际更严 → 一般多 1 块理论板。

## 例6-19（`#L12661-#L12687`）

甲醇-水，$F$=100 kmol/h、$x_F$=0.45、$D$=44.4、$x_D$=0.95、饱和液体进料、$R$=1.5：

- 间接加热：$W$=55.6、$x_W$=0.051；精馏段截距 $\frac{0.95}{2.5}=0.38$；
- 直接蒸汽：$L$=66.6、$V$=111、$b=L'=166.6、$S=V'$=111 → $x_b=\frac{45-42.18}{166.6}=0.0169$；
- 梯级：间接 7 块（第 5 块进料，提馏段 3 含釜）；直接 8 块（精馏段与进料板不变，提馏段 4 含釜，多一块）。

## 判断

- 直接蒸汽的"多一块板"代价换来的是"省掉再沸器"，对含水物系（水可凝、不污染）非常经济；对非水物系不适用。
- 提馏段线过 $(x_b,0)$ 而非 $(x_W,x_W)$ 是解题关键，画错这一点图解法结果全错。
- 釜液被稀释使 $x_b$ 低于 $x_W$，若产品是釜液（如回收水），要按实际 $x_b$ 报指标。

# 搅拌雷诺数与流态划分

## 定义

以叶端速度 $Nd$ 作定性速度（`#L4880`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{Re}=\dfrac{dN\rho}{\mu}=\dfrac{\rho Nd^{2}}{\mu}$ | （5-1） |
| **文字式** | $\text{搅拌雷诺数}=\dfrac{\text{桨径}_{\text{【m】}}\times\text{转速}_{\text{【r/s】}}\times\text{密度}_{\text{【kg/m³】}}}{\text{黏度}_{\text{【Pa·s】}}}$ |  |

式中 $d$ 桨径、$N$ 转速、$\rho$ 密度、$\mu$ 黏度（`#L4884-#L4890`）。

## 流态划分

| $N_{Re}$ | 流态 |
|:---|:---|
| <10 | 层流 |
| 10~$10^4$ | 过渡流 |
| >$10^4$ | 湍流 |

（`#L4892`）

$N_{Re}$ 不仅决定流态，还对搅拌器特性起决定性作用，其他准数往往与它定量关联（`#L4878`）。

## 设计前提与常数的可用性

设计搅拌器及附件时：**首先保证釜内没有死角**（任何位置都有流体流动），其次使釜内形成有效流动与适当流态（`#L4894-#L4896`）。

湍流区（$N_{Re}>20000$）时，$N_p$、$N_{qd}$、$N_{\theta M}$ 基本保持常数，可作为搅拌过程的特征量；通常 **$N_p$ 越小、$N_{qd}$ 越大、$N_{\theta M}$ 越小，搅拌性能越好**（`#L4898`）。

## 判断

"湍流区准数恒定"是选型计算能成立的前提：它把几何与流态解耦，使功率曲线可查。但 $10^4$ 与 $20000$ 两个门槛不同——$10^4$ 是流态界限，$20000$ 才是"准数稳定"的经验界限，工程上常取后者。

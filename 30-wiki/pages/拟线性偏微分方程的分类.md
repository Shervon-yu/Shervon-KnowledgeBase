# 拟线性偏微分方程的分类

## 特征线与判别式（§3.2–§3.3）

对拟线性方程组（式 3-1a,b，＃L2166-2168），加上 $u,v$ 的全微分（3-2a,b），得到关于四个一阶导数的四个线性方程（3-3，＃L2186）。导数唯一确定要求系数行列式不为零；行列式为零的方向就是**特征线**（#L2214）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left|A\right|=0\ \Rightarrow\ a\left(\dfrac{\mathrm{d}y}{\mathrm{d}x}\right)^{2}+b\dfrac{\mathrm{d}y}{\mathrm{d}x}+c=0$ | （3-7、3-10） |
| **文字式** | $\text{系数行列式}=0\ \Rightarrow\ \text{系数}_a\times\left(\dfrac{\mathrm{d}y}{\mathrm{d}x}\right)^{2}+\text{系数}_b\times\dfrac{\mathrm{d}y}{\mathrm{d}x}+\text{系数}_c=0$ |  |

特征线斜率由二次方程（3-11，＃L2244）给出，其判别式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $D=b^{2}-4ac$ | （3-12） |
| **文字式** | $\text{判别式}=\text{系数}_b^{2}-4\times\text{系数}_a\times\text{系数}_c$ |  |

分类（#L2252 附近）：$D>0$ 两条实特征线 → **双曲型**；$D=0$ 一条 → **抛物型**；$D<0$ 无实特征线（虚特征线）→ **椭圆型**。

## 特征值法（§3.3）

把方程组写成 $[K]\,\partial W/\partial x+[M]\,\partial W/\partial y=0$（式 3-17，＃L2309），消去一个方向得 $\partial W/\partial x+[N]\,\partial W/\partial y=0$（3-19，＃L2317）。特征值由 $|[N]-\lambda[I]|=0$ 定出（3-23，＃L2395）：特征值全为实数且互异 → 双曲型；有重根 → 抛物型；有复根 → 椭圆型。

例：二维定常无粘小扰动方程（3-20、3-21，＃L2331-2333）的特征线斜率为 $\pm1/\sqrt{Ma_\infty^2-1}$（3-22，＃L2353），特征值 $\lambda=\pm\sqrt{1/(Ma_\infty^2-1)}$（3-24，＃L2407）。所以 $Ma_\infty>1$ 双曲、$Ma_\infty<1$ 椭圆、$Ma_\infty=1$ 抛物。

## 三类方程的数学性质（§3.4）

| 类型 | 特征线 | 求解方式 | 边界/初始条件 | 典型流动 |
|:--|:--|:--|:--|:--|
| 双曲型 | 两条实特征线，有有限影响区与依赖区 | 可沿特征方向**推进**（marching） | 初值线 + 特征方向上的入流条件 | 定常无粘超声速绕流；非定常无粘流（对时间双曲） |
| 抛物型 | 一个特征方向 | 可推进，但每步要解一个椭圆型子问题 | 初值线 + 两侧边界条件 | 边界层方程；热传导方程（3-25～3-27，＃L2539-2549） |
| 椭圆型 | 虚特征线，信息向各方向传播 | 不能推进，全场**同时**求解（"陪审团"问题） | 整个封闭边界上给 Dirichlet、Neumann 或混合条件 | 定常亚声速/不可压无粘流动 |

- 双曲型推进的经典例子：定常超声速绕翼型从初值线向下游推进；非定常流沿时间推进（#L2435-2475）。
- 椭圆型：$P$ 点扰动影响整个区域，$P$ 点解又依赖整条边界，故必须全场联立（#L2574）。边界条件三种形式：Dirichlet（给函数值）、Neumann（给导数）、混合（#L2580-2584）。
- 混合型流动（钝体绕流的亚声速/超声速并存）用定常方程无法统一处理，**时间推进法**是出路：非定常欧拉方程对时间恒为双曲型，推进到时间充分大即得定常解（#L2608，Moretti 与 Abbett 1966）。
- N-S 方程同时具有抛物型（时间导数项）与椭圆型（粘性项向上游反馈）特性，但时间推进解法仍适定（#L2616）。

## 适定性（§3.5）

定义：若解存在、唯一，且连续依赖于初始条件与边界条件，则问题是**适定**的（#L2622）。书里强调，求解前确认适定性非常重要；定常混合流动若强行统一求解就是不适定问题，而改用非定常时间推进后变为适定（#L2620-2622）。

## 适用边界

- 判别式分类只对二阶拟线性方程最直接；一阶方程组用特征值法（3-23）。
- 分类依赖当地流动状态：同一套欧拉方程，当地 $Ma>1$ 双曲、$Ma<1$ 椭圆（#L2447、#L2594）。
- 边界条件条数必须与类型匹配，给多了或给少了都导致不适定（§3.5）。

## 判断

这一章是后面所有数值方法选择的依据：双曲型允许推进，于是有第 6、7 章的显式时间推进与空间推进；椭圆型必须全场联立，于是有第 6.8 节压力修正法的迭代；抛物型介于两者之间，于是有第 9 章 Crank-Nicolson 的隐式推进。看不懂分类，就看不懂为什么书里对同一套方程换着法子解。

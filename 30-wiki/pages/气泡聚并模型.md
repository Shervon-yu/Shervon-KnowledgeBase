# 气泡聚并模型

## 聚并三阶段（`#L3411`）

1. 两气泡靠近接触，**夹持一层液膜**；
2. 进一步靠近，液膜**排液、减薄**；
3. 液膜减薄到临界厚度后破裂，合并为大气泡。

靠近机制：湍流脉动、速度梯度（层流剪切）、涡捕获、浮力驱动、尾涡夹带。搅拌桨**排流区以湍流脉动为主**，循环流区还须计入浮力与涡捕获（`#L3411`）。

## 聚并速率的乘积形式（7.46，`#L3415-#L3421`）

$$c(d_1,d_2)=\omega_c(d_1,d_2)\,P_c(d_1,d_2)\tag{7.46}$$

**聚并速率 = 碰撞频率 × 聚并概率**，类比气体分子反应动力学。经验模型含若干可调参数，物理模型无。

## 碰撞频率（7.47~7.52，`#L3423-#L3459`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\omega_c=S_{12}u_{\mathrm{rel}}=\dfrac{\pi}{4}(d_1+d_2)^2u_{\mathrm{rel}}n_1n_2$ | （7.47） |
| **文字式** | $\text{碰撞频率}=\text{碰撞管截面积}\times\text{两气泡靠近速度}=\dfrac{\pi}{4}(\text{直径}_1+\text{直径}_2)^2\times\text{靠近速度}\times\text{数密度}_1\times\text{数密度}_2$ |  |

靠近速度（7.48）：$u_{\mathrm{rel}}=\sqrt{u_{\lambda1}^2+u_{\lambda2}^2}$；湍流涡速度（7.49）：$u_\lambda=\sqrt2(\varepsilon d)^{1/3}$。

代入得广泛使用的形式（7.50）：

$$\omega_c=c_{\omega2}\frac{\pi}{4}(d_1+d_2)^2\left(d_1^{2/3}+d_2^{2/3}\right)^{1/2}\varepsilon^{1/3}n_1n_2$$

### Colin 修正（7.51/7.52）

当气泡尺寸 > 湍流积分尺度 $l_e$ 时，涡不能有效驱动气泡，相对运动主要由**平均剪切流**引起：

- $d_1<l_e,\ d_2<l_e$：$u_{\mathrm{rel}}=\frac{c_t}{\sqrt{1.61}}\left(\varepsilon\frac{d_1+d_2}{2}\right)^{1/3}$；
- $d_1<l_e,\ d_2>l_e$：$u_{\mathrm{rel}}=\frac{c_t}{\sqrt{1.61}}(\varepsilon d_1)^{1/3}$。

### 气含率修正因子 γ（7.53~7.56）

气泡占据空间使自由程减小、碰撞增多：

| 作者 | 修正因子 | $\alpha_{\max}$ |
|:--|:--|:--|
| Wu | $\gamma=\dfrac{1}{\alpha_{\max}^{1/3}(\alpha_{\max}^{1/3}-\alpha^{1/3})}$ | 0.8 |
| Hibiki-Ishii | $\gamma=\dfrac{1}{\alpha_{\max}-\alpha}$ | 0.52 或 0.742 |
| Lehr | $\gamma=\exp\left[-\left(\dfrac{\alpha_{\max}^{1/3}-\alpha^{1/3}}{\alpha^{1/3}}\right)^2\right]$ | 0.6 |

## 聚并概率（7.57~7.67，`#L3479-#L3573`）

$P_c$ 取决于**接触时间 $t_{ij}$ 与排液时间 $\tau_{ij}$ 的竞争**：$P_c=\exp(-t_{ij}/\tau_{ij})$ 或 $\exp(-\tau_{ij}/t_{ij})$ 两类写法。

| 模型 | 判据 | 参数 |
|:--|:--|:--|
| Sovova（7.57~7.60） | 能量模型 | 见原文 |
| Simon（7.61/7.62） | 速度/能量 | 见原文 |

| Ross（7.64） | 排液 | 见原文 |

## 判断

- "频率 × 概率"是把**流体力学（碰撞）**与**界面物理（排液成膜）**解耦的标准做法；误差主要来自 $P_c$；
- $\gamma$ 的三种表达式在 $\alpha\to\alpha_{\max}$ 时都发散，这是模型的人为上限，**实际计算必须限幅**，否则聚并速率爆炸、计算发散；
- 本书选 Coulaloglou-Tavlarides，是因为它同时给出碰撞频率与排液时间、参数少，且与 Luo-Svendsen 破裂模型配套（同一套湍流理论）。

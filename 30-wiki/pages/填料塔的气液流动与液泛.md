# 填料塔的气液流动与液泛

## 持液量与压降（`#L10581-#L10583`）

液膜沿填料表面下降时，因液膜与填料、液膜与上升气体的摩擦，部分液体滞留于填料表面与空隙中——单位体积填料层滞留的液体体积称**持液量**。

液体流量一定时，气量越大 → 持液量越大 → 压降越大。

空塔气速 $u$ = 气体体积流量 ÷ 塔截面积。

## 压降曲线的三段（图5-29，`#L10585-#L10607`）

| 段 | 现象 | 斜率 |
|:--|:--|:--|
| 干填料（$L=0$） | $\Delta p$ 与 $u$ 的直线关系 | 1.8~2.0（类同管内湍流） |
| 载点 A 之前 | 液体几乎不受气流牵制，持液量基本不变 | 与干填料直线几乎平行 |
| 载点 A 之后 | 液膜受气流阻拦，持液量随气速增大而增多、通道减小，压降较快上升 | 斜率增大 |
| 液泛点 B | 填料层几乎充满液体，压降急剧上升并剧烈波动（曲线近垂直） | — |

**液泛点**：气速再增，液体受阻积聚、不能下流，甚至从塔顶溢出——是填料塔操作的**上限**。载点到液泛点之间是正常操作区。

泛点气速对应的空塔气速即**泛点气速** $u_f$。确定塔径时先求 $u_f$，再取

$$u=(0.5\sim0.8)u_f$$

保证操作正常。

## 埃克特（Eckert）关联图（`#L10615-#L10643`）

影响因素：气液流量与密度、液体黏度、填料特性（$a$、$\varepsilon$、$\phi$）。

图5-30 坐标：

|  |  |  |
|:---|:---:|--:|
| **符号式** | 横坐标 $\dfrac{L'}{G'}\left(\dfrac{\rho_G}{\rho_L}\right)^{1/2}$，纵坐标 $\dfrac{u^2\phi\psi}{g}\left(\dfrac{\rho_G}{\rho_L}\right)\mu_L^{0.2}$ | （图5-30 坐标，书内未编号） |
| **文字式** | 横坐标=液气质量流量比×密度比的平方根；纵坐标=气速平方×填料因子×密度修正÷重力加速度×密度比×黏度修正 |  |

其中 $L'$、$G'$ 为液、气质量流量（kg/s）；$\psi=\rho_{H_2O}/\rho_L$；$\mu_L$ 用 mPa·s。

图上有三条泛点线（格状填料、整砌拉西环、乱堆填料）与许多等压降线（每米填料压降）。

三种用法：
1. 已知液气流量密度 → 算横坐标 → 与泛点线相交读纵坐标 → 反算 $u_f$；
2. 已知压降 → 横坐标 + 等压降线 → 读纵坐标 → 算 $u$；
3. 已知 $u$ → 算纵坐标 → 与横坐标交点 → 读压降。

## 判断

- 液泛的本质是"气相对液膜的曳力超过重力"，与管内气液两相流的泛点同源；因此气速上限由流体力学定，与传质好坏无关。
- 取 0.5~0.8 倍泛点气速是折中：高气速 → 塔径小、设备省，但压降大、操作费高且接近液泛不稳；低气速 → 压降小但塔径大、且气液接触变差。工程上常取 0.6~0.8。
- 泛点气速 $\propto 1/\sqrt{\phi}$：换用填料因子小的填料（如鲍尔环替代拉西环）可直接提高允许气速、缩小塔径，代价是填料单价。

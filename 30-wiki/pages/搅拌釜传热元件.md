# 搅拌釜传热元件

## 常见型式

| 型式 | 结构 | 特点 |
|:---|:---|:---|
| 整体夹套 | 釜体外焊一圈封闭夹套 | 结构最简单；承压与传热面积有限 |
| 型钢夹套 | 用型钢（角钢/槽钢）焊成通道 | 承压能力高于整体夹套 |
| 半管夹套 | 半圆管螺旋焊在釜壁上 | 承压高、传热好，适合高压加热/冷却介质 |
| 蜂窝夹套 | 薄壁板上焊蜂窝状短管形成通道 | 壁薄、传热好、承压高 |
| 激光焊接蜂窝夹套 | 激光焊替代电阻焊 | 焊缝窄、热影响小、更薄更密 |
| 内盘管 | 釜内螺旋管，可兼作挡板 | 传热面积大，但妨碍搅拌、易结垢 |

（`#L3197`）

选用次序（工程惯例）：常压/低压小釜用整体夹套；需要高压介质用半管或蜂窝；内盘管只在夹套面积不足且物料不结垢时用。

## 内盘管的双重身份

内盘管既传热又起挡板作用——盘管的存在改变了流型与功耗（`#L3199`）。按"有挡板"工况算功率时，盘管可计入挡板；按无挡板算则偏保守。

## 放大的根本矛盾

几何相似放大时，传热面积 $A\propto D^2$，而体积 $V\propto D^3$，故**单位体积传热面积 $A/V\propto 1/D$**，随釜径增大反比减小（`#L3197`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{A}{V}\propto\dfrac{6}{D}$ | — |
| **文字式** | $\text{单位体积传热面积}_{\text{【m²/m³】}}\propto\dfrac{6}{\text{釜内径}_{\text{【m】}}}$ |  |

后果：大釜靠夹套已不够，必须加内盘管、外循环换热器或刮壁强化。式（3-8）~（3-10）的系数口径见 [[搅拌釜传热过程与总传热系数]]、[[表面传热系数的无因次关联]]。

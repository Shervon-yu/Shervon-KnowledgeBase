# 缠绕式垫片的标记与标志

## 定义

缠绕式垫片（HG/T 20610 PN 系 / HG/T 20631 Class 系）的标记供设计部门或客户订货用，由标准名称、类型、公称尺寸、公称压力、材料代号等要素组成（#L5888-#L5923、#L13543-#L13594）。

## 判据与计算

### 标记要素（#L13543-#L13594）

Class 系（20631）标记五要素：

1. 标准名称（HG/T 20631）
2. 垫片类型（A 基本型 / B 带内环型 / C 带对中环型 / D 带内环和对中环型）
3. 公称尺寸 DN；大于 DN600 时需加注 A 或 B（尺寸系列）
4. 公称压力 Class（或 PN）
5. 材料代号（金属带/内环/对中环＋填料）；无内环或对中环时代号写 0

### 标记示例（#L5888-#L5923、#L13942-#L13988）

- PN 系（20610）：`HG/T20610 缠绕垫 D100-40 1220`
- Class 系（20631）：`HG/T20631 缠绕垫 D100-900 1222`；DN1000 B 系列为 `…D1000B-900…`

### 标志（#L5888-#L5923、#L13595-#L13655）

- 带对中环型应在对中环上打钢印（永久性标志）；基本型/带内环型在包装上用标签标志，色标按生产厂或用户规定（#L13595-#L13655）
- 标志内容：生产厂名或商标、标准编号、公称压力 PN/Class、公称尺寸 DN、材料代号（#L5888-#L5923）

## 适用范围与边界

- PN 系与 Class 系标记格式一致，仅标准号与压力标记不同（PN 数字 vs Class 数字）
- 尺寸与技术要求（20610 第 4、5 章）不在本页；本页只收录标记/标志口径
- 缠绕垫的选配（何时能用、配什么紧固件）见 [[法兰连接选配规定]]

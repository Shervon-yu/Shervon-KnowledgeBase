# 填料塔塔径的计算

## 计算公式（`#L10647-#L10651`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $D=\sqrt{\dfrac{V_s}{\dfrac{\pi}{4}u}}$ | （5-81，书内未编号） |
| **文字式** | $\text{塔径}=\sqrt{\dfrac{\text{操作条件下气体体积流量}}{\dfrac{\pi}{4}\times\text{空塔气速}}}$ |  |

$V_s$ 按操作条件计（m³/s），$u$ 取泛点气速的 50%~80%。

## 气速的两难（`#L10653`）

- $u$ 小：压降小、动力省、操作费低，但塔径大、设备费高；气速太低还不利于气液接触、传质速率低。
- $u$ 大：塔径小、设备费低，但压降大、动力费高；接近泛点时操作不稳、难控制。

故需兼顾经济合理与技术可行。

## 例5-16（`#L10655-#L10693`）

清水吸收 SO₂：混合气 1000 m³/h、$\rho_G=1.34$ kg/m³、水 27000 kg/h、$\rho_L=1000$ kg/m³、101.325 kPa、20 ℃，乱堆填料。

(1) 泛点气速：
- $G'=1.34\times1000=1340$ kg/h；
- 横坐标 $=\dfrac{27000}{1340}\sqrt{\dfrac{1.34}{1000}}=0.738$；
- 查乱堆泛点线得纵坐标 0.028；
- 选 25×25×2.5 瓷拉西环 $\phi=450$ m⁻¹、$\psi=1$、$\mu_L=1$ mPa·s；

$$u_f=\sqrt{\frac{0.028\,g\rho_L}{\phi\psi\rho_G\mu_L^{0.2}}}=\sqrt{\frac{0.028\times9.81\times1000}{450\times1\times1.34\times1}}=0.675\ \mathrm{m/s}$$

(2) 塔径：取 $u=0.8u_f=0.54$ m/s，

$$D=\sqrt{\frac{1000}{3600\times0.785\times0.54}}=0.81\ \mathrm{m}$$

(3) 压降：纵坐标 $=\dfrac{0.54^2\times450}{9.81}\times\dfrac{1.34}{1000}\times1^{0.2}=0.0179$，横坐标 0.738 → 交点在 0.5 kPa 等压降线 → 每米填料压降 **0.5 kPa**。

(4) 改用 50×50×4.5 瓷鲍尔环（$\phi=130$）：横坐标不变，故纵坐标不变，$u_f\propto1/\sqrt{\phi}$：

$$u_{fp}=u_{fr}\sqrt{\frac{\phi_r}{\phi_p}}=0.675\sqrt{\frac{450}{130}}=1.26\ \mathrm{m/s}$$

取 $u=0.8u_{fp}=1.0$ m/s → $D=0.6$ m。

## 判断

- 塔径只由"气量 ÷ 允许气速"决定，与传质计算（$Z=H_{OG}N_{OG}$）完全解耦——这是填料塔设计的两个独立步骤：先定径、再定高。
- 换鲍尔环后塔径 0.81→0.6 m（面积降 45%），但填料单价上升；原文的结论是"应权衡塔体与填料两方面的费用"，不能只看塔径变小。
- 计算顺序固定：液气比 → 横坐标 → 泛点线 → $u_f$ → 取 0.5~0.8 → $D$ → 用同一纵坐标在等压降线上核压降。任何一步跳步都会造成压降与气速不自洽。

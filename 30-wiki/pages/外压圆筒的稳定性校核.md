# 外压圆筒的稳定性校核

外压容器的失效是**屈曲**（失稳），不是强度破坏，所以不用应力公式，走"应变系数 A → 应力系数 B → 许用外压 [p]"三步法。

## 计算长度 L（`#L5190-#L5214`）

取相邻两支撑线之间的距离：
- 带凸形封头时，**加封头曲面深度的 1/3**；
- 有加强圈时，取加强圈中心线间距；
- 带夹套时，取承受外压的筒体长度；
- 支撑线 = 截面惯性矩足够、能保证该处不失稳的位置（封头切线、加强圈、法兰等）。

## 第一步：求 A（应变系数）

$D_o/\delta_e\ge20$ 时（`#L5258-#L5295`）：由 $L/D_o$ 与 $D_o/\delta_e$ 查图6-2（或表6-2 数值表）得 A；$L/D_o>50$ 按 50 取，$<0.05$ 按 0.05 取，中间内插。

$D_o/\delta_e<20$ 时（6.3.3）：$D_o/\delta_e\ge4.0$ 用同一图，$D_o/\delta_e<4.0$ 用式6-3：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=\dfrac{1.1}{(D_o/\delta_e)^2}$，且 $A>0.1$ 时取 0.1 | （6-3） |
| **文字式** | $\text{应变系数}=\dfrac{1.1}{(\text{外径}/\text{有效厚度})^2}$ |  |

## 第二步：求 B（应力系数）

按材料查表6-1 确定对应的 B 曲线图（图6-3~6-14），由 A 查 B；A 超曲线右端取端点纵坐标；A 小于曲线最小值时用式6-1：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $B=\dfrac{2AE^t}{3}$ | （6-1） |
| **文字式** | $\text{应力系数}_{\text{【MPa】}}=\dfrac{2\times\text{应变系数}\times\text{设计温度弹性模量}_{\text{【MPa】}}}{3}$ |  |

表6-1 共 107 行材料条目（碳钢、低合金、不锈钢、镍基），每条给 $R_{eL}$、设计温度上限与适用曲线图号；高温时 B 曲线不得超出 GB/T 150.2 表C.1~C.6 粗实线温度（防蠕变屈曲）。

## 第三步：求许用外压力

$D_o/\delta_e\ge20$（式6-2）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[p]=\dfrac{B}{D_o/\delta_e}$ | （6-2） |
| **文字式** | $\text{许用外压力}_{\text{【MPa】}}=\dfrac{\text{应力系数}}{\text{外径}/\text{有效厚度}}$ |  |

$D_o/\delta_e<20$（式6-4）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[p]=\min\left\{\left(\dfrac{2.25}{D_o/\delta_e}-0.0625\right)B,\ \dfrac{2\sigma_0}{D_o/\delta_e}\left(1-\dfrac{1}{D_o/\delta_e}\right)\right\}$ | （6-4） |
| **文字式** | $\text{许用外压力}=\min\{\text{厚壁修正项},\ \text{屈服控制项}\}$，$\sigma_0=\min(2[\sigma]^t,\ 0.9R_{eL}^t)$ |  |

要求 $[p]\ge p_c$，否则调参数重算。

## 判断

- 三段体（A→B→[p]）本质是**把弹性屈曲曲线离散成图**：A 无量纲、B 是应力，交点落在比例段就用 $B=2AE^t/3$，落在塑性段就查曲线；
- $D_o/\delta_e<20$ 是"厚壁/小直径"区，屈曲前先屈服，所以式6-4 第二项用屈服上限封顶；
- $L/D_o$ 的上下限截断（0.05、50）是为了覆盖常用范围，超出即按边界处理——**不等于**外推；
- 与 150.1 的 5.4.5 轴向压缩公式分工：外压（侧向）用 6.3，轴向压缩用 5.4.5。

# 局部阻力损失

## 来源（`#L2285`）

流体流过阀门、弯头、三通、异径管时，流动方向与流速大小突变、产生涡流，湍动加剧，阻力显著增大。这类由管件、阀门造成的损失称局部摩擦阻力损失。

## 两种算法（`#L2291`）

局部阻力损失都折算成动能倍数：**阻力系数法**与**当量长度法**。

### 阻力系数法（`#L2293-#L2299`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_f=\zeta\dfrac{u^2}{2}$ | （1-56） |
| **文字式** | $\text{局部阻力损失}_{\text{【J/kg】}}=\text{局部阻力系数}\times\dfrac{\text{流速}_{\text{【m/s】}}^2}{2}$ |  |

$\zeta$ 无量纲，由实验测定，查表 1-2。

### 当量长度法（`#L2343-#L2349`）

把管件损失折算成同直径直管的长度 $l_e$（当量长度）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_f=\lambda\dfrac{l_e}{d}\dfrac{u^2}{2}$ | （1-58） |
| **文字式** | $\text{局部阻力损失}_{\text{【J/kg】}}=\text{摩擦系数}\times\dfrac{\text{当量长度}_{\text{【m】}}}{\text{管内径}_{\text{【m】}}}\times\dfrac{\text{流速}_{\text{【m/s】}}^2}{2}$ |  |

两法可互换：$\zeta$ 乘以 50 即得 $l_e/d$（书内经验换算）。

### 表 1-2 摘录（湍流）

| 管件 | $\zeta$ | $l_e/d$ |
|:---|:---|:---|
| 45° 弯头 | 0.35 | 17 |
| 90° 弯头 | 0.75 | 35 |
| 三通 | 1 | 50 |
| 回弯头 | 1.5 | 75 |
| 管接头/活接头 | 0.04 | 2 |
| 闸阀全开/半开 | 0.17 / 4.5 | 9 / 225 |
| 截止阀全开/半开 | 6.0 / 9.5 | 300 / 475 |
| 角阀全开 | 2 | 100 |
| 摇板式止逆阀 | 2 | 100 |
| 盘式水表 | 7 | 350 |

## 突然扩大与突然缩小（`#L2315-#L2341`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\zeta=\left(1-\dfrac{A_1}{A_2}\right)^{2}$ | （1-57a） |
| **文字式** | $\text{突然扩大阻力系数}=\left(1-\dfrac{\text{小管截面积}}{\text{大管截面积}}\right)^{2}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\zeta=0.5\left(1-\dfrac{A_2}{A_1}\right)^{2}$ | （1-57b） |
| **文字式** | $\text{突然缩小阻力系数}=0.5\times\left(1-\dfrac{\text{大管截面积}}{\text{小管截面积}}\right)^{2}$ |  |

- 1-56 中 $u$ 一律取**小管**流速；
- $A_1=A_2$ 时 $\zeta=0$，等径直管没有这项损失；
- 流入大容器/排入大气（$A_1/A_2\to0$）：扩大 $\zeta=1$；
- 自大容器进入管道（$A_2/A_1\to0$）：缩小 $\zeta=0.5$。

## 判断

- "ζ×50=l_e/d"只是量级换算，不精确；但工程估算足够，且能让直管与管件合并成"总长度"。
- 突然扩大 ζ=1 意味着出口动能全部损失，这就是为什么排入大气的管口要按损失项计而不是回收。

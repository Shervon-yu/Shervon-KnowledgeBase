# 放大时的传热能力变化

## 出发点

夹套釜釜壁对物料的表面传热系数（`#L4034`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\alpha_{1}D}{k}=C\,Re^{\varepsilon}Pr^{0.33}V_{is}^{0.14}$ | （4-14） |
| **文字式** | $\dfrac{\text{表面传热系数}_{\text{【W/(m²·K)】}}\times\text{釜径}_{\text{【m】}}}{\text{导热系数}_{\text{【W/(m·K)】}}}=C\times\text{雷诺数}^{\text{放大指数}}\times\text{普朗特数}^{0.33}\times\text{黏度比}^{0.14}$ |  |

忽略 $V_{is}$ 项、物性不变，得 $\alpha_1=C d^{2\varepsilon-1}N^{\varepsilon}$（4-15）；要 $\alpha_1$ 不变则 $d^{2\varepsilon-1}N^{\varepsilon}=\text{const}$（4-16）（`#L4040-#L4044`）。

## 三种准则下 N 与 d 的关系

| 准则 | 关系 | 指数 |
|:---|:---|:---|
| $N^3d^2$ 恒定 | $N\propto d^{-0.667}$ | （4-17） |
| $Nd$ 恒定 | $N\propto d^{-1.0}$ | （4-18） |
| $N^{0.81}d^{0.32}$ 恒定 | $N\propto d^{-0.495}$ | （4-19） |

（`#L4046-#L4052`）

## 单位体积传热量

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q/V=K\,A/V\approx\alpha\,A/V$ | （4-22）（4-23） |
| **文字式** | $\text{单位体积传热量}_{\text{【W/m³】}}=\text{总传热系数}_{\text{【W/(m²·K)】}}\times\dfrac{\text{传热面积}_{\text{【m²】}}}{\text{体积}_{\text{【m³】}}}$ |  |

因 $A/V\propto 1/D$，几何相似放大后 $A/V$ 必降，$Q/V$ 随之下降（`#L4060-#L4068`）。

## 表 4-3 的定量结果（湍流，$\varepsilon=0.667$）

| 内径放大 | $N^3d^2$ 恒：$\alpha$ / $Q/V$ | $Nd$ 恒：$\alpha$ / $Q/V$ | $N^{0.81}d^{0.32}$ 恒：$\alpha$ / $Q/V$ |
|:---:|:---:|:---:|:---:|
| 3 倍 | 0.885 / 0.295 | 0.693 / 0.231 | 1.086 / 0.361 |
| 5 倍 | 0.836 / 0.167 | 0.585 / 0.117 | 1.128 / 0.226 |
| 10 倍 | 0.774 / 0.077 | 0.464 / 0.046 | 1.189 / 0.119 |

（`#L4072-#L4082`；原表第三列标题 OCR 作 $N^{0.31}d^{0.42}$，正文式 4-19 为 $N^{0.81}d^{0.32}$，此处从正文）

## 结论

1. 放大后 $Q/V$ 一律大幅下降，10 倍内径时只剩 5%~12%；
2. $N^3d^2$ 恒定与 $Nd$ 恒定两种准则的 $Q/V$ 降幅几乎相等，**仅看传热时 $Nd$ 恒定更省能**；
3. 热负荷 $\propto D^3$、传热面 $\propto D^2$，几何相似放大无法解决，必须**非几何相似**：加内盘管、加回流冷凝器、改夹套形式（见 [[非几何相似放大]]、[[搅拌釜传热元件]]）。

# 新增一本书的入库清单

**一句话**：一本书 = 一个文件夹放 `00-inbox` + 一次 ingest 八步 + 一次 commit；验收看 `touch` 落在 10~15 页。

## 0 前置（放书前）

1. `00-inbox` **清空**：一本书一个文件夹，文件夹名 = 书名（之后 `20-md` 目录名与之一致）。
2. `30-index\todo.md` 无该书未决项；`check-links.ps1` 对已有三本书全绿。
3. 原件入库后从 `00-inbox` 移到 `10-source`（`10-source` 不进 git：版权材料）。

## 1 解析（机做，¥0）

| 步 | 命令 | 产出 |
|:---|:---|:---|
| 解析 | `90-tool\scripts\ingest.ps1`（内部调 MinerU → `20-md\<书>\<书>.md` + `图片\`） | md + 图 |
| 图整理 | `python 90-tool\scripts\figures.py --mineru --book <书> --dedupe --apply` | 图名规范、重复图合并 |
| 死链自检 | `powershell -NoProfile -ExecutionPolicy Bypass -File '90-tool\scripts\check-links.ps1' -Md '<md路径>'` | `SELFCHECK refs=N ok=N unresolved=0` |
| 书目 | `catalog.ps1` | `30-index\catalog.md` / `todo.md` 重算 |

- 路径含空格照写，**不要写成 %20**（rules v3.1；check-links 见 `%` 直接判 bad）。
- 解析完先看 `todo.md` 有没有「假标题」「缺图」两类未决项，有就当场处理，别带进 wiki 层。

## 2 编译（我做，八步）

| 步 | 动作 | 验收 |
|:---|:---|:---|
| 0 | 查 `glossary.md` + `concepts\` 有无同义页 | 命中即改旧页，不新建 |
| 1 | 列标题树（`^#{1,3} ` + 行号），假标题降级 | 章节地图 |
| 2 | 写 `sources\<书>.md` | 元信息表 + 章节行号表 + 能答/不能答 |
| 3 | 列 10~20 个候选概念 → 查重 → 建/改 | 8~15 页 |
| 4 | 每页：定义 / 判据·计算（符号式+文字式成对）/ 边界 / 相关 | 断言逐条挂 `§节号 #L行号` |
| 5 | 回改受影响页：冲突开 `openq`，换代标 `superseded` | 不删旧断言 |
| 6 | `wiki-index.ps1` 重生成 `index.md` | 页数与磁盘一致 |
| 7 | `log.md` 追加一条：目标页 / 依据 / `touch=N` / token | 只追加不改旧行 |
| 8 | `wiki-lint.ps1` → 0 问题 → `git commit -m "ingest: 《书名》 touch=N"` | commit 带 touch |

## 3 验收线

- `touch` 10~15：低于 10 说明在抄书，高于 20 说明拆太碎。
- `check-links` unresolved=0；`wiki-lint` 问题 0；`index.md` 页数 = 磁盘页数。
- 每页入链 ≥2（否则 lint 报孤儿页）。

## 4 常见坑

- **PowerShell 默认禁止执行 .ps1**：必须 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ...`。
- **scan 版 PDF 无文本层**（化工原理 398 页实测）：无法按图题坐标裁图，缺图只能整页重解析后按 `page_N_chart_M` 命名补回。
- **图名与图题分两行**：MinerU 先输出一行图片链接（指向 图片/page_39_chart_9.jpg）与图题行之间空一行，再接「图1-20 …」，归一改名要同时改 md 与文件名。
- **文件名差异比缺料更危险**：`40-new\_pageidx-*\` 里 json 名曾出现「汽液」「全角－」与目录名不符，插页码前必须先核对映射。

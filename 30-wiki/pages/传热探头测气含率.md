# 传热探头测气含率

## 结构与原理（`#L324`）

热膜探头是镀在细长石英柱上的金属薄膜，温度系数很高。用**反馈控制电路**使热膜平衡稳定、电阻恒定，从而测气液两相流速度与气含率。

气泡通过探头时**导热明显下降** → 输出信号出现明显峰值。

## 概率密度法（`#L338-#L342`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=\dfrac{t_g}{\sum t}=\dfrac{\sum_{E_1}^{E_2}N+\sum_{E_2}^{E_3}N_0}{N}$ | （1.4） |
| **文字式** | $\text{气含率}=\dfrac{\text{气相接触时间}}{\text{总接触时间}}=\dfrac{\text{气相区概率密度计数}+\text{分界区计数}}{\text{总计数}}$ |  |

## 能测三个量（`#L324`）

对输出信号分析处理可得：局部气含率、局部液速、湍动量。

## 优缺点（`#L344`）

- 优点：准确性高、价格适中；
- 缺点：**机械强度差**，流速大或气含率高时容易损坏。

应用：大型塔板鼓泡态局部气含率、环流反应器（子波分析）等；气液搅拌釜内报道甚少。

## 判断

- 热膜的根本约束是"靠导热差分辨气液"：探头上只要挂一层液膜或气泡紧贴，导热差就消失，信号失真——这是它在高气含率体系易失效的物理原因，也解释了"机械强度差"之外的另一重限制。
- （1.4）把分界区 $E_2\sim E_3$ 的计数也计入气相，是一种**阈值判定**；阈值取法直接决定气含率偏大还是偏小。
- 与电导/光纤相比，热膜是唯一能同时给出液速与湍动量的探头，这是它在流场研究中的价值所在。

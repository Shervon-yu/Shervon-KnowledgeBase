# 傅里叶定律与温度梯度

## 温度场与温度梯度（`#L5792-#L5808`）

- **温度场**：某一瞬时空间各点温度的分布；
- **等温面**：同一时刻温度相同的点连成的面；等温面与平面的交线叫等温线；
- 温度不同的等温面不能相交（一点不能同时有两个温度）；等温面上无温差，只有穿越等温面才有温度变化；
- **温度梯度**：自等温面上某点沿不同方向温度变化率不同，其中沿等温面**法线方向**的变化率最大，即为温度梯度。

它是一个向量：方向与等温面法线一致，**以温度增加的方向为正**。

一维稳态时温度只沿 $x$ 变，梯度写作 $\mathrm{d}t/\mathrm{d}x$；当 $x$ 轴与梯度方向（指向温度升高）一致时为正、反之为负。

## 傅里叶定律（`#L5810-#L5818`）

质地均匀的物体内，若等温面上各点温度梯度相同，则单位时间传导的热量 $Q$ 与温度梯度及垂直于热流方向的面积 $A$ 成正比：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=-\lambda A\dfrac{\mathrm{d}t}{\mathrm{d}x}$ | （4-2） |
| **文字式** | $\text{传热速率}_{\text{【W】}}=-\text{热导率}_{\text{【W/(m·K)】}}\times\text{传热面积}_{\text{【m²】}}\times\text{温度梯度}_{\text{【K/m】}}$ |  |

符号说明：$\lambda$ 为热导率，W/(m·K)；$\mathrm{d}t/\mathrm{d}x$ 为沿 $x$ 的温度梯度。

## 负号的来源（`#L5816`）

$x$ 方向取为**热流方向，即温度降低的方向**，于是 $\mathrm{d}t/\mathrm{d}x<0$；而传热速率 $Q$ 必须为正，故式中加负号。

## 判断

- 负号不是物理定律的内容，而是"坐标正方向与热流方向相反"的记账约定；若把 $x$ 轴改取温度升高方向，符号随之改变，定律本身不变。
- 温度梯度取"温度增加方向为正"这一点很关键：它使导热、对流、辐射三套公式的符号体系一致，后续多层壁串联时不必逐个改号。

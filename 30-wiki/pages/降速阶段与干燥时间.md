# 降速阶段与干燥时间

## 降速段速率的求法（`#L14539-#L14571`）

降速段 $u$ 随 $X$ 下降，直接解析式很少，一般两种处理：

**1. 图解积分**

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\tau_2=\dfrac{L_c}{A}\displaystyle\int_{X_2}^{X_c}\dfrac{\mathrm{d}X}{u}$ | （7-36） |
| **文字式** | $\text{降速段时间}=\dfrac{\text{绝干料质量}}{\text{干燥面积}}\times\text{自产品干基至临界干基对 }\dfrac{1}{\text{速率}}\text{ 的积分}$ |  |

把实验的 $u$–$X$ 曲线换成 $1/u$–$X$ 曲线，曲线下面积即积分值。

**2. 线性近似**（降速段 $u$ 与自由含水量成正比）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $u=K_X(X-X^{*})$，$K_X=\dfrac{u_c}{X_c-X^{*}}$ | （7-37a）（7-37b） |
| **文字式** | $\text{速率}=\text{降速系数}\times(\text{干基含水量}-\text{平衡含水量})$；$\text{降速系数}=\dfrac{\text{恒速速率}}{\text{临界干基}-\text{平衡干基}}$ |  |

代入积分得：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\tau_2=\dfrac{L_c}{A K_X}\ln\dfrac{X_c-X^{*}}{X_2-X^{*}}$ | （7-38） |
| **文字式** | $\text{降速段时间}=\dfrac{\text{绝干料质量}}{\text{干燥面积}\times\text{降速系数}}\ln\dfrac{\text{临界干基}-\text{平衡干基}}{\text{产品干基}-\text{平衡干基}}$ |  |

总时间 $\tau=\tau_1+\tau_2$。

## 例7-7（`#L14613-#L14637`）

$L_1$=200 kg、$w_1$=27%、$w_2$=5%；盘 0.3×0.5 m 共 25 个 → $A$=3.65 m²；$X_1$=0.37、$X_2$=0.053、$X_c$=0.20、$X^{*}$=0.05、$u_c$=1.5 kg/(m²·h)。

- $L_c$=146 kg；$\tau_1$=4.53 h；$K_X$=10 kg/(m²·h)；
- $\tau_2$=15.7 h；加装卸 1 h → 每批周期 21.2 h。

**结论**：降速段占了 78% 的时间——降速段才是干燥设备放大的控制环节。

## 降速段的曲线类型（`#L14523-#L14535`）

- (a) 大孔粒状、分散粉粒、液滴、薄片：线性；
- (b) 非亲水细粉、纤维：毛细管型；
- (c) 纤维性亲水物料（木材、纺织、皮革、纸张）与细粉（黏土、淀粉）：第一降速段毛细管、第二段扩散；
- (d) 肥皂胶类无孔吸湿性物料：**无恒速段**，从一开始就降速。

## 判断

- 线性近似（7-37a）的物理含义是"干燥速率只取决于剩余自由水量"，对 (a) 类成立，对 (c)(d) 类只是分段近似。
- (d) 类无恒速段的原因是表面没有自由水膜，一开始就是内部扩散控制。
- 实际设计一般按 $X_2$ 留余量：$\tau_2$ 对 $X_2$ 是对数敏感，产品要求越干，时间增长越快。
- 降速段提高温度的效果远小于恒速段——因为控制步骤已从"表面汽化"变成"内部传递"，此时减小料层厚度比升温有效得多。

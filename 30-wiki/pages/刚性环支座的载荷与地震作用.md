# 刚性环支座的载荷与地震作用

## 定义

刚性环支座用于高耸立式设备的支承。设计时除设备自重与介质重量外，还须考虑水平风力、水平地震力、竖向地震作用、偏心载荷与管道载荷；刚性环支座的允许载荷用 [W]（竖向）与 [M0]（力矩）两项给出，选型条件为 W < [W] 且 M0 < [M0]（#L8291）。

## 判据与计算

### 载荷取值（§6，#L7922-#L8001）

设计温度（#L7923）、腐蚀裕量（#L7927）、载荷（#L7935）、许用应力（#L7963）、元件尺寸（#L7993）与支座载荷计算（#L7999）见标准第 6 章。

### 2.1 外力构成（#L8299-#L8301）

支座承受的外力包括：设备重量、水平风力、水平地震力、竖向地震作用、设备附件偏心载荷、管道载荷。**向上的管道载荷在计算中不计入**（偏安全）。

### 2.2 水平力取值（#L8305-#L8307）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{\mathrm{H}}=\max\left\{F_{\mathrm{w}},\ F_{\mathrm{e}}+0.25F_{\mathrm{w}}\right\}$ | （2-1） |
| **文字式** | $\text{计算水平力}=\max(\text{水平风力},\ \text{水平地震力}+0.25\times\text{水平风力})$ |  |

### 2.3 竖向力取值（#L8309-#L8311）

竖向力取设备操作重量与附件偏心载荷、向下管道载荷的组合；**8 度、9 度设防区且设备总高 H0 > 20 m 的高耸设备**，还应计入竖向地震作用。

### 2.4 自振周期（式(B.2)，#L8313-#L8315）

- 自振周期按附录 B 式(B.2) 计算，适用范围 hc/Di ≤ 10；
- K2 为容器形状系数、K3 为支承位置系数，按附录 B 图 B.1、B.2 查取；
- 自振周期计算结果经修正后误差小于 5%（个别达 6%~8%），可满足工程设计精度。

### 2.5 水平地震力（底部剪力法，#L8317）

高径比 hc/Di ≤ 11.6 时结构以剪切震动为主，按底部剪力法计算水平地震力；地震影响系数 αmax 按设防地震取值；计算地震作用时取 RE = 0.45。

### 2.6 竖向地震作用（#L8319-#L8321）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{\mathrm{v}}=R_{\mathrm{E}}\cdot\alpha_{\mathrm{vmax}}\cdot m_{\mathrm{eqv}}\cdot g$ | （2-2） |
| **文字式** | $\text{竖向地震力}=\text{地震作用系数}\times\text{竖向地震影响系数最大值}\times\text{等效质量}\times\text{重力加速度}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{\mathrm{v}}=0.49R_{\mathrm{E}}\cdot\alpha_{\mathrm{max}}\cdot m_{\mathrm{eq}}\cdot g$ | （2-3） |
| **文字式** | $\text{竖向地震力}=0.49\times\text{地震作用系数}\times\text{水平地震影响系数最大值}\times\text{等效质量}\times\text{重力加速度}$ |  |

- 折算关系：竖向地震影响系数最大值 αvmax = 0.65αmax；竖向地震等效质量 meqv = 0.75meq（#L8319）。

## 适用范围与边界

- 适用于刚性环支座支承的高耸立式钢制容器；选表法以 W < [W] 且 M0 < [M0] 为前提（见 [[容器支座型式与选型]]）。
- 自振周期式(B.2) 只适用 hc/Di ≤ 10；超出时须按其他方法（如更精确的动力分析）确定。
- 本页只给出载荷组合与地震作用取值口径；[W]、[M0] 表与结构尺寸见标准第 4、5 章，焊缝与底板螺栓校核见标准其他章节。

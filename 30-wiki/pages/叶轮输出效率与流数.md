# 叶轮输出效率与流数

## 三个流数

湍流区容积流率 ∝ $nd^{3}$，故统一无量纲化（`#L3855`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $N_{qd}=\dfrac{q_{d}}{nd^{3}},\qquad N_{qi}=\dfrac{q_{i}}{nd^{3}},\qquad N_{qc}=\dfrac{q_{c}}{nd^{3}}$ | （3.4） |
| **文字式** | $\text{输出流数}=\dfrac{\text{叶轮输出流率}}{\text{转速}\times\text{叶轮直径}^{3}}；\ \text{感应流数}、\text{二次循环流数同构}$ |  |

其中 $q_d$ 输出流、$q_i$ 感应流（从叶轮上下被吸入输出流的量）、$q_c=q_d+q_i$ 二次循环流总量。

## 判据：$N_{p}/N_{qd}$

「单位功率换多少流量」，比值越小越省（`#L3859`、`#L3863`）：

- $N_{p}/N_{qd}$ 大 → **剪切型**（把功率砸在叶端附近）
- $N_{p}/N_{qd}$ 小 → **循环型**（把功率换成全釜流量）

表3.1（$Re\sim10^{5}$，$D=60$、$d=30$、$b=6$ cm）给的区间是 **1.3（8叶 Brumagin，无挡板）到 3.3（16叶涡轮）**，即工业叶轮之间只差 2.5 倍；**桨式与涡轮式的输出效率差别不大**（2.7~2.8）。

几个值得记住的数字（`#L3877`、`#L3890`、`#L3895`）：

| 叶轮 | $d/D$ | $b/D$ | $n_p$ | $N_p$ | $N_{qd}$ | $N_p/N_{qd}$ |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| 8叶平桨 | 0.5 | 0.1 | 8 | 0.95 | 0.34 | 2.8 |
| 16叶涡轮 | 0.5 | 0.1 | 16 | 1.08 | 0.33 | 3.3 |
| 8叶弯桨（$\alpha=80°$） | 0.5 | 0.1 | 8 | 0.55 | 0.37 | **1.5** |
| 8叶 Brumagin | 0.5 | 0.1 | 8 | 0.44 | 0.34 | **1.3** |
| 带导流筒推进式 | 0.5 | 0.1 | 3 | 0.42 | 0.78 | **0.54** |

## 选型四条

为提高输出效率，优先（`#L3865`）：① 弯叶；② 宽大叶片；③ 斜叶片（$\theta=45°$）；④ **相对容器直径较小的 $d/D$**。

反例同样重要（`#L3887`、`#L3907`）：

- 弯叶**反转**（$\alpha=-80°$）时 $N_{qd}$ 掉到 0.17、$N_p/N_{qd}$ 涨到 36.4——输出效率崩掉 20 倍，功率全变成湍动。
- 挡板会把 $N_{p}/N_{qd}$ 抬高很多（功率涨得比流量快），但 $q_c/q_d=1.8\sim1.9$、有无挡板差别不大——所以**无挡板时输出效率高的叶轮，加挡板后仍然高**（`#L3869`、`#L3871`）。
- 导流筒截面 = 筒外环隙截面时，轴向循环最均匀（`#L3905`）。

## 两个估算式

|  |  |  |
|:---|:---:|---|
| **符号式** | $N_{qd}\propto\left(\dfrac{d}{D}\right)^{-2.5}\left(\dfrac{b}{D}\right)n_{p}^{0.7}$ | （3.5） |
| **文字式** | 输出流数 ∝ 相对直径的 $-2.5$ 次方 × 相对叶宽 × 叶片数的 $0.7$ 次方 |  |

|  |  |  |
|:---|:---:|---|
| **符号式** | $N_{qc}\propto N_{qd}\left[1+0.16\left\{\left(\dfrac{D}{d}\right)^{2}-1\right\}\right]$ | （3.6） |
| **文字式** | 循环流数 = 输出流数 × 一个随 $(D/d)^2$ 增长的感应流修正 |  |

式(3.6) 的含义：$D/d$ 越大，感应流 $q_i$ 占比越高，总循环流越大；$d/D$ 小的叶轮"输出少但吸得多"。

# 传热速率方程与总传热系数

## 五环节

搅拌釜传热与普通换热器机理相同，热量从被搅物料到热载体要经过（`#L7332`）：

1. 被搅物料对传热面的对流传热；
2. 被搅物料侧壁面污垢热阻；
3. 筒体或盘管壁的热传导；
4. 热载体侧污垢热阻；
5. 传热面对热载体的对流传热。

## 传热速率方程

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=KA\Delta T$ | （7-46） |
| **文字式** | $\text{传热量}_{\text{【W】}}=\text{总传热系数}_{\text{【W/(m²·K)】}}\times\text{传热面积}_{\text{【m²】}}\times\text{温差}_{\text{【K】}}$ |  |

（`#L7334-#L7342`）

## 总传热系数

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{1}{K}=\dfrac{1}{\alpha_1}+\sum_{i=1}^{n}\dfrac{\delta_i}{\lambda_i}+\dfrac{1}{\alpha_2}+R_{s1}+R_{s2}$ | （7-47） |
| **文字式** | $\dfrac{1}{\text{总传热系数}}=\dfrac{1}{\text{物料侧膜系数}}+\sum\dfrac{\text{壁厚}}{\text{热导率}}+\dfrac{1}{\text{热载体侧膜系数}}+\text{物料侧污垢热阻}+\text{热载体侧污垢热阻}$ |  |

（`#L7346-#L7360`；$\delta_i$ 单位 m，$\lambda_i$ 单位 W/(m·K)，$R_s$ 单位 (m²·K)/W）

## 污垢热阻（表7-7）

| 流体 | $R_s$ /(m²·K)/kW | 流体 | $R_s$ /(m²·K)/kW |
|:---|:---:|:---|:---:|
| 蒸馏水 | 0.09 | 水蒸气·优质（不含油） | 0.052 |
| 海水 | 0.09 | 水蒸气·劣质 | 0.09 |
| 清净河水 | 0.21 | 往复机排出 | 0.176 |
| 未处理凉水塔水 | 0.58 | 处理过的盐水 | 0.264 |
| 已处理凉水塔水 | 0.26 | 有机物 | 0.176 |
| 已处理锅炉水 | 0.26 | 燃料油 | 1.056 |
| 硬水、井水 | 0.58 | 焦油 | 1.76 |
| 空气 | 0.26~0.53 | 溶剂蒸气 | 0.14 |

（`#L7370-#L7382`）

## 要不要计污垢热阻

| 情形 | $R_{s1}$ |
|:---|:---|
| 间歇操作、每次清洗干净 | 可不计 |
| 连续操作且不带刮壁结构 | 必须计 |
| 夹套/盘管侧 $R_{s2}$ | 一般都应计入 |

（`#L7368`）

## 判断

表7-7 的单位是 (m²·K)/kW，换算成 (m²·K)/W 要除以 1000——焦油 1.76 即 0.00176 (m²·K)/W，相当于膜系数只有约 570 W/(m²·K)；而未处理的凉水塔水 0.58（=0.00058）已经能让 $K$ 掉近三分之一。工程上"水冷夹套算不准"十有八九是漏了 $R_{s2}$。

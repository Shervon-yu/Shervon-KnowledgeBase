# 旋风分离器

## 构造与操作（`#L4889-#L4915`）

优点：结构简单、制造方便、分离效率高、可处理高温含尘气体。

气流路线：含尘气体由圆筒上部**长方形切线进口**进入（进口速度约 **15~20 m/s**）→ 沿内壁旋转向下 → 圆锥部分旋转半径缩小、切向速度增大 → 底部附近转为上升气流 → 由上部出口管排出。

颗粒在离心力作用下向外沉降到内壁，沿壁落入灰斗。工业上常用两种型式（图3-9）。

## 临界粒径（`#L4923-#L4953`）

定义：理论上能 100% 除去的最小粒径。三条假设：

① 气流在器内按入口宽度 $b$ 旋转 $n$ 圈，颗粒从 $r=0.5D-b$ 沉降到 $D/2$；
② 颗粒与气流流速相同、平均切向速度等于进口气速 $u_i$；
③ 沉降服从斯托克斯定律。

斯托克斯区沉降速度（半径 $r=0.5D-b$ 处）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{d}r}{\mathrm{d}\tau}=\dfrac{d_p^2(\rho_p-\rho)}{18\mu}\cdot\dfrac{u_i^2}{r}$ | （3-22） |
| **文字式** | $\text{沉降速度}=\dfrac{\text{粒径}^2\times\text{密度差}}{18\times\text{黏度}}\times\dfrac{\text{进口速度}^2}{\text{半径}}$ |  |

积分得沉降时间：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau_t=\dfrac{9\mu b(D-b)}{(\rho_p-\rho)d_p^2u_i^2}$ | （3-23） |
| **文字式** | $\text{沉降时间}=\dfrac{9\times\text{黏度}\times\text{进口宽}\times(D-b)}{(\text{密度差})\times\text{粒径}^2\times\text{进口速度}^2}$ |  |

平均旋转半径 $r_m=(D-b)/2$，旋转 $n$ 圈的停留时间：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=\dfrac{2\pi r_m n}{u_i}$ | （3-24） |
| **文字式** | $\text{停留时间}=\dfrac{2\pi\times\text{平均半径}\times\text{圈数}}{\text{进口速度}}$ |  |

令 $\tau_t=\tau$ 得临界粒径：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{pc}=3\sqrt{\dfrac{\mu b}{\pi n(\rho_p-\rho)u_i}}$ | （3-25） |
| **文字式** | $\text{临界粒径}_{\text{【m】}}=3\sqrt{\dfrac{\text{黏度}\times\text{进口宽}}{\pi\times\text{圈数}\times(\text{密度差})\times\text{进口速度}}}$ |  |

计算时通常取 **$n$=5**。

## 压力损失（`#L4955-#L4965`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=\dfrac{\zeta\rho u_i^2}{2},\qquad \zeta=\dfrac{30bh\sqrt{D}}{d^2\sqrt{L+H}}$ | （3-26）（3-27） |
| **文字式** | $\text{压损}_{\text{【Pa】}}=\dfrac{\text{阻力系数}\times\text{气体密度}\times\text{进口速度}^2}{2}$；$\text{阻力系数}=\dfrac{30\times\text{进口宽}\times\text{进口高}\times\sqrt{D}}{\text{出口管径}^2\times\sqrt{L+H}}$ |  |

一般 $\Delta p$ 约 **1~2 kPa**。

**关键推论（`#L4965`）**：各尺寸都是 $D$ 的倍数，故**进口速度相同则压损相同，与分离器大小无关**。压损相同时小型分离器的 $b=D/5$ 更小、由 3-25 知 $d_{pc}$ 更小 → **用若干小型分离器并联替代一台大分离器可提高分离效率**。

## 例3-3（`#L4967-#L4995`）

20 ℃、0.101 MPa 含尘空气、$q_V$=2.5 m³/s、$\rho_p$=2500 kg/m³、$\Delta p$ 允许 2.0 kPa：

- $\zeta$=8.3 → $u_i$=20 m/s；
- $q_V=bhu_i=2.4D^2$ → $D$=1.02 m；
- 其他尺寸：$L$=1.02、$H$=2.04、$b$=0.204、$h$=0.612、$d$=0.51 m；
- $d_{pc}$=6.5 μm。

## 适用粒径与系统（`#L4997`）

旋风分离器可分离 **5~200 μm**。典型除尘系统：重力降尘室（除大颗粒）→ 旋风分离器（除大部分）→ 袋滤器（除细小）；可按粒度分布与要求省去某一级。

## 判断

- 3-25 中 $b$ 在分子、$u_i$ 在分母：缩小进口宽度或提高进口速度都能降临界粒径，但提高 $u_i$ 会增大压损与磨损——实践中更常用"小直径并联"。
- "n=5 圈"是经验取值，不是理论推导结果，故 3-25 属半经验式。

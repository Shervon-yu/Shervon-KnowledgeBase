# 机械密封的分类与结构型式

## 按工作参数分类（表10-33，`#L13313-#L13329`）

| 维度 | 分档与阈值 | 名称 |
|:---|:---|:---|
| 密封腔温度 $t$ | $t>150\ ℃$ | 高温机械密封 |
| | $80<t\le150\ ℃$ | 中温机械密封 |
| | $-20\le t\le80\ ℃$ | 普温机械密封 |
| | $t<-20\ ℃$ | 低温机械密封 |
| 密封端面速度 $v$ | $v>100\ \mathrm{m/s}$ | 超高速机械密封 |
| | $25\le v\le100\ \mathrm{m/s}$ | 高速机械密封 |
| | $v<25\ \mathrm{m/s}$ | 一般速度机械密封 |
| 密封腔压力 $p$ | $p>15\ \mathrm{MPa}$ | 超高压机械密封 |
| | $3<p\le15\ \mathrm{MPa}$ | 高压机械密封 |
| | $1<p\le3\ \mathrm{MPa}$ | 中压机械密封 |
| | 常压 $\le p\le1\ \mathrm{MPa}$ | 低压机械密封 |
| | 负压 | 真空机械密封 |
| 轴径 $d$ | $d>120\ \mathrm{mm}$ | 大轴径机械密封 |
| | $25\le d\le120\ \mathrm{mm}$ | 一般轴径机械密封 |
| | $d<25\ \mathrm{mm}$ | 小轴径机械密封 |

> OCR 说明：原文 13319、13323、13325 行的「中温 80~150 ℃」「高压 3~15 MPa」「中压 1~3 MPa」被合并单元格压成首行；13325 行「真空机械密封」被压在「常压≤p≤1 MPa」行上、13326 行「负压」独行，上表按阈值与该节体例补全，属合理推断。

按综合工况再分三型（`#L13327-#L13329`）：

- **重型**：满足 $p>3\ \mathrm{MPa}$、$t<-20\ ℃$ 或 $t>150\ ℃$、$v\ge25\ \mathrm{m/s}$、$d>120\ \mathrm{mm}$ 之一；
- **轻型**：$p<0.5\ \mathrm{MPa}$ 且介质为油、水、有机溶剂等弱腐蚀；
- **中型**：其余。

## 按结构型式分类（七组，`#L13331-#L13427`）

| 组 | 分法 | 判据与取舍 |
|:---|:---|:---|
| 1 | **平衡式 / 非平衡式** | 能卸载端面介质压力为平衡式（又分部分平衡、过平衡）；非平衡式端面受力随压力变化大，仅用于 $p<0.7\ \mathrm{MPa}$；平衡式端面摩擦磨损小、承载能力大，但需在轴或轴套上车台阶，成本高 |
| 2 | **内置式 / 外置式** | 弹簧与动环在密封箱内、与介质接触为内置式，端面受力与冷却润滑好，常用；外置式零件不接触介质、便于观察维修，但介质压力与弹簧力反向，压力波动易失稳，仅用于强腐蚀、高黏、易结晶、低压场合 |
| 3 | **内流式 / 外流式** | 泄漏方向与离心力相反为内流式，泄漏量小、密封可靠，用于高压；外流式用于极高速（加强端面润滑），但 $p$ 不宜高，一般 $1\sim2\ \mathrm{MPa}$ |
| 4 | **静止式 / 旋转式** | 弹簧不随轴转为静止式，不受离心力影响，用于高速；旋转式结构简单、径向尺寸小，常用，但线速度 $>30\ \mathrm{m/s}$ 时宜改静止式 |
| 5 | **单弹簧式 / 多弹簧式** | 单弹簧（大弹簧）端面压力分布不均，用于 $d\lesssim80\sim150\ \mathrm{mm}$；多弹簧（小弹簧）压力均匀，用于高速、大轴径，但弹簧丝细，介质腐蚀或含结晶颗粒时易失效，此时须用单弹簧 |
| 6 | **单端面 / 双端面** | 单端面结构简单、制造安装容易，用于介质润滑性好、允许微量泄漏的场合；双端面用于润滑性差、有毒、易燃易爆、易挥发、含磨粒及含气体的场合。轴向双端面分面对面与背靠背，两对端面间引入高于介质压力 $0.05\sim0.15\ \mathrm{MPa}$ 的封液，可改善润滑冷却并把介质与外界隔离，**有可能实现零泄漏** |
| 7 | **单级 / 多级** | 介质处于一种压力状态为单级；两级串联、压力依次递减为双级，可耐更高压力；更高压力可多级串联 |

此外还有接触式/非接触式、波纹管型等（`#L13427`）。

## 选用顺序

1. 先按 $p$、$v$、$t$、$d$ 定位表10-33 的档位（决定是否属重型）；
2. 按 $p$ 定平衡程度 → 按 $v$ 定弹簧旋转/静止 → 按 $t$ 定辅助密封圈材料（见 [[机械密封的选型原则]]）；
3. 最后按介质危险性与泄漏要求定单/双端面与级数。

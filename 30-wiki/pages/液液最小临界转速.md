# 液液最小临界转速

## 定义

通过搅拌使一个液相完全分散于另一不相溶液相中所需的最低转速称临界转速 $N_c$（`#L2457`）。

## 永田进治式（无挡板平底、四直叶涡轮）

适用 $d/D=1/3$、$b/D=0.06$（`#L2463`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{c}=Kd^{-2.3}\left(\dfrac{\mu_{c}}{\rho_{c}}\right)^{1.9}\left(\dfrac{\rho_{c}-\rho_{d}}{\rho_{c}}\right)^{0.26}$ | （2-107） |
| **文字式** | $\text{临界转速}_{\text{【1/s】}}=K\times\left(\text{搅拌器直径}_{\text{【m】}}\right)^{-2.3}\times\left(\dfrac{\text{连续相黏度}_{\text{【Pa·s】}}}{\text{连续相密度}_{\text{【kg/m³】}}}\right)^{1.9}\times\left(\dfrac{\text{两相密度差}_{\text{【kg/m³】}}}{\text{连续相密度}_{\text{【kg/m³】}}}\right)^{0.26}$ |  |

叶轮居中 $K=6.01$；偏心安装 $K=4.88$。

## Skelland 式（带挡板、$H=D$、相比 0.5）

无量纲形式（`#L2471`，式2-108）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{d^{1.2}N_{c}}{g^{1.2}}=C_{1}\left(\dfrac{D}{d}\right)^{\alpha_{1}}\left(\dfrac{\mu_{c}}{\mu_{d}}\right)^{1.9}\left(\dfrac{\Delta\rho}{\rho_{c}}\right)^{0.25}\left(\dfrac{\sigma}{d^{2}\rho_{c}g}\right)^{0.3}$ | （2-108） |
| **文字式** | $\dfrac{\left(\text{搅拌器直径}_{\text{【m】}}\right)^{1.2}\times\text{临界转速}_{\text{【1/s】}}}{g^{1.2}}=C_{1}\left(\dfrac{\text{釜内径}}{\text{搅拌器直径}}\right)^{\alpha_{1}}\left(\dfrac{\text{连续相黏度}}{\text{分散相黏度}}\right)^{1.9}\times\left(\dfrac{\text{密度差}}{\text{连续相密度}}\right)^{0.25}\times\left(\dfrac{\text{表面张力}_{\text{【N/m】}}}{\left(\text{搅拌器直径}_{\text{【m】}}\right)^{2}\times\text{连续相密度}_{\text{【kg/m³】}}\times g}\right)^{0.3}$ |  |

预测平均偏差 <10.62%（`#L2476`）。$C_1$、$\alpha_1$ 与桨型、桨径、安装位置有关，见表2-20（摘要，`#L2486-#L2509`）：

| 桨型 | 安装方式号 | $C_0$ | $\alpha_0$ | $C_1$ | $\alpha_1$ |
|:---|:---:|:---:|:---:|:---:|:---:|
| 推进式 | 1（H/4） | 0.3481 | −1.383 | 15.32 | 0.2827 |
| 推进式 | 2（3H/4） | 0.1519 | −1.654 | 9.968 | 0.5536 |
| 推进式 | 3（H/2） | 0.2934 | −1.493 | 15.31 | 0.3933 |
| 推进式 | 4（双层） | 0.0447 | −2.023 | 5.241 | 0.9232 |
| 45° 折叶涡轮 | 5 | 0.04738 | −2.151 | 6.823 | 1.0512 |
| 45° 折叶涡轮 | 7 | 0.00915 | −2.690 | 2.987 | 1.5901 |
| 直叶涡轮 | 9 | 0.00910 | −2.725 | 3.178 | 1.6247 |
| 直叶涡轮 | 11 | 0.03665 | −1.981 | 3.996 | 0.8810 |
| 曲叶涡轮 | 13 | 0.01329 | −2.562 | 3.611 | 1.4624 |
| 曲叶涡轮 | 15 | 0.04823 | −1.901 | 4.715 | 0.8006 |
| 曲叶涡轮 | 16 | 0.06675 | −1.640 | 4.293 | 0.5401 |

安装方式号含义（`#L2478-#L2484`）：1/5/9/13 = 单层桨在重相中部 H/4；2/6/10/14 = 单层桨在轻相中部 3H/4；3/7/11/15 = 单层桨在两相界面 H/2；4/8/12/16 = 双层桨分别装在 H/4 与 3H/4。表中 `*` 表示尚未达到临界转速液体就大量飞溅，无法求得 $N_c$（`#L2511`）。

## Van Heuven 式（六叶标准涡轮、桨径不变、挡板平底）

$N_c=8d^{-0.3}\gamma^{0.3}\sigma^{0.06}\rho^{-0.18}\Delta\rho^{0.38}(1+2.5\varphi_d)^{0.9}$（式2-109，`#L2472`）。式中 $\gamma$ 为该式自定义参数，原文未展开，引用需查原书。

## 单位与口径

$N_c$ 单位 r/s，$d$、$D$ 为 m，$\mu_c$、$\mu_d$ 为 Pa·s，$\rho_c$、$\rho_d$ 为 kg/m³，$\Delta\rho$ 为密度差（`#L2474`）。

# 原书 §7.1.2：分散的临界搅拌速度

## 式子本身

原书给出的条件很具体（`#L8102`）：桨式叶轮 $d=D/3$、$b=0.06D$、$\theta=90^\circ$、$n_p=4$、$C=D/2$，平底圆筒容器 $H=D$：

|  |  |  |
|:---|:---:|---|
| **符号式** | $N_c=KD^{-2/3}\left(\dfrac{\mu_c}{\rho_c}\right)^{1/9}\left(\dfrac{\rho_c-\rho_d}{\rho_c}\right)^{0.26}$ | （7.9） |
| **文字式** | $\text{临界转速}=\text{比例系数}\times\text{容器直径}^{-2/3}\times\left(\dfrac{\text{连续相运动黏度}\times\text{密度}}{\text{密度}}\right)^{1/9}\times\text{无因次密度差}^{0.26}$ |  |

- $K=750$（叶轮在**中心**，$\varepsilon=0$）；$K=610$（偏心 $\varepsilon=d/4$）。
- **分散相的黏度与界面张力影响可忽略**（`#L8106`）——与滴径关联式里 $\sigma$ 是主导因素形成鲜明对照：能不能"分散开"只看密度差与连续相黏度，滴"多细"才看界面张力。
- 放大时给出的是同一液体所需的最小转速（`#L8108`、`#L8110`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $N_c=KD^{-2/3}$，即 $N_c^3D^2=\text{常数}$ | （7.9'） |
| **文字式** | 临界转速与容器直径的 $-2/3$ 次方成正比；等价于**单位体积功率相等则分散状态相同** |  |

推导（`#L8112`、`#L8116`）：由 $P=c'\rho N^3D^5$（7.10）与 $P_v=c''\rho n^3D^2$（7.11）可见 $N^3D^2\propto P/V$，式(7.9') 即"等 $P/V$ 准则"。

## 例7.1 硝化混合酸

条件（`#L8124`）：混合酸比重 1.55（连续相）、苯比重 0.88、混合酸黏度 30 cP，釜 $D=H=80$ cm，桨 $d=D/3$、$b=0.06D$、$\theta=90^\circ$、$n_p=4$，叶轮置于液高一半。

- 居中（$\varepsilon=0$）：$N_c=750(0.8)^{-2/3}(0.03/1550)^{1/9}(670/1550)^{0.26}=210$ r/min；
- 偏心 $\varepsilon=d/4$：$N_c=172$ r/min（`#L8130`、`#L8132`）。

**偏心省 18% 转速**——这就是式(7.3) 偏心安装的实用价值。

## 与手册式的差异（引用前必看）

| 写法 | 出处 | 表达式 | 指数 |
|:---|:---|:---|:---|
| 本书原式 | 《混合原理与应用》§7.1.2 | $KD^{-2/3}(\mu_c/\rho_c)^{1/9}(\Delta\rho/\rho_c)^{0.26}$ | $D^{-2/3}$、黏度 $1/9$ |
| 手册转录 | 《搅拌与混合设备设计选用手册》式2-107 | $Kd^{-2.3}(\mu_c/\rho_c)^{1.9}(\Delta\rho/\rho_c)^{0.26}$ | $d^{-2.3}$、黏度 $1.9$ |

两处的 $\Delta\rho$ 指数（0.26）一致；差别集中在**特征长度（$D$ 还是 $d$，指数 $-2/3$ 还是 $-2.3$）**与**黏度指数（$1/9$ 还是 $1.9$）**。粘度量纲上 $\mu/\rho$ 必须开 9 次方才得 r/s 量级，故**手册式的 1.9 很可能是 1/9 的排版丢失**；长度项 $2.3$ 与 $2/3$ 同理。工程计算以原书(7.9) 为准，手册式需回查原书核对。

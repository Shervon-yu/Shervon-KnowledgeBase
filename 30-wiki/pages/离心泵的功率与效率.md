# 离心泵的功率与效率

## 有效功率（`#L3425-#L3433`）

单位时间内液体从叶轮获得的有效能量：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_e=q_V\rho gH$ | （2-3） |
| **文字式** | $\text{有效功率}_{\text{【W】}}=\text{流量}_{\text{【m³/s】}}\times\text{密度}_{\text{【kg/m³】}}\times\text{重力加速度}\times\text{扬程}_{\text{【m】}}$ |  |

## 轴功率与效率（`#L3435-#L3441`）

轴功率 $P$ = 电动机传给泵轴的功率（输入）；有效功率 $P_e$ = 泵给液体的功率（输出）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\eta=\dfrac{P_e}{P}$ | （2-4） |
| **文字式** | $\text{泵效率}=\dfrac{\text{有效功率}}{\text{轴功率}}$ |  |

$\eta$ 一般为 0.6~0.85，大型泵可达 0.90。

## 三类功率损失（`#L3443`）

| 损失 | 机理 | 后果 |
|:---|:---|:---|
| 水力损失 | 泵内流体流动摩擦 | 叶轮给的能量不能全被液体获得，只得到有效扬程 $H$ |
| 容积损失（流量损失） | 部分高压液体漏回低压区 | 排出流量小于流经叶轮的流量 |
| 机械损失 | 轴承摩擦、轴封摩擦 | 轴功率有一部分不传给液体 |

## 电动机功率（`#L3445`）

泵启动或运转时可能超负荷，所配电机功率应比轴功率大；具体按泵样本选取。

## 判断

- $\eta=P_e/P$ 是"整泵效率"，把水力、容积、机械三种损失合并了；样本上给的效率通常就是它。
- 计算顺序固定：$q_V$、$H$（含密度）→ $P_e$ → 除以 $\eta$ 得 $P$。若已知电机功率求流量，则要反推，属于试差类问题。

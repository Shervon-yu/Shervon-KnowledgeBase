# 过滤-恒压过滤与过滤常数

## 定义

过滤以**过滤介质**截留颗粒，滤液穿过多孔层；**过滤速度**是单位时间单位过滤面积得到的滤液体积，其基本关系为「过滤速度 = 过滤推动力 / 过滤阻力」（#L5186）。推动力是滤饼与介质两侧的压差，阻力来自**滤饼阻力**（滤饼比阻 $r$ 与滤饼体积 $V_{c}$）和**过滤介质阻力**（用虚拟滤液体积 $V_{e}$ 折算，#L5244）。

**恒压过滤**指过滤过程中压差不变的操作：随滤饼增厚，速度下降（#L5262、#L5296）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=\dfrac{\Delta p_{\mathrm{c}}}{r\mu\dfrac{V_{\mathrm{c}}}{A}}$ | （3.4-1） |
| **文字式** | $\text{过滤速度}_{\text{【m/s】}}=\dfrac{\text{滤饼两侧压差}_{\text{【Pa】}}}{\text{滤饼比阻}_{\text{【1/m²】}}\times\text{滤液黏度}_{\text{【Pa·s】}}\times\dfrac{\text{滤饼体积}_{\text{【m³】}}}{\text{过滤面积}_{\text{【m²】}}}}$ |  |

（式 3-32 变形后的形式，#L5192、#L5218；$V_{\mathrm{c}}=vV$，$v$ 为单位滤液体积生成的滤饼体积，#L5232。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{d}V}{A\,\mathrm{d}\tau}=\dfrac{\Delta p}{r\mu v\dfrac{V+V_{\mathrm{e}}}{A}}$ | （3.4-2） |
| **文字式** | $\text{过滤速度}_{\text{【m/s】}}=\dfrac{\text{总压差}_{\text{【Pa】}}}{\text{比阻}\times\text{黏度}\times\text{单位滤液滤饼体积}\times\dfrac{\text{累计滤液体积}+\text{虚拟滤液体积}_{\text{【m³】}}}{\text{过滤面积}_{\text{【m²】}}}}$ |  |

（式 3-37、3-38，合并滤饼阻力 $R_{c}=r\mu vV/A$ 与介质阻力 $R_{m}=r\mu vV_{e}/A$，#L5238、#L5244、#L5258。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $V^{2}+2VV_{\mathrm{e}}=KA^{2}\tau$ | （3.4-3） |
| **文字式** | $\left(\text{累计滤液体积}_{\text{【m³】}}\right)^{2}+2\times\text{累计滤液体积}_{\text{【m³】}}\times\text{虚拟滤液体积}_{\text{【m³】}}=\text{过滤常数}_{\text{【m²/s】}}\times\left(\text{过滤面积}_{\text{【m²】}}\right)^{2}\times\text{过滤时间}_{\text{【s】}}$ |  |

（式 3-40，恒压过滤方程，#L5300；$K=2\Delta p/(\mu r v)$，#L5296。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\tau}{q}=\dfrac{1}{K}q+\dfrac{2}{K}q_{\mathrm{e}}$ | （3.4-4） |
| **文字式** | $\dfrac{\text{过滤时间}_{\text{【s】}}}{\text{单位面积滤液量}_{\text{【m³/m²】}}}=\dfrac{1}{\text{过滤常数}}\times\text{单位面积滤液量}_{\text{【m³/m²】}}+\dfrac{2}{\text{过滤常数}}\times\text{单位面积虚拟滤液量}_{\text{【m³/m²】}}$ |  |

（式 3-41、3-42，$q=V/A$、$q_{e}=V_{e}/A$；这是**恒压过滤实验求 $K$、$q_{e}$** 的直线式，#L5310、#L5326。）

**转筒真空过滤机**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=A\sqrt{K\psi N}$ | （3.4-5） |
| **文字式** | $\text{生产能力}_{\text{【m³/s】}}=\text{过滤面积}_{\text{【m²】}}\times\sqrt{\text{过滤常数}\times\text{浸液分数}\times\text{转速}_{\text{【1/s】}}}$ |  |

（式 3-49，$q_{e}$ 可忽略时的近似式，#L5524；完整式 3-48 为 $Q=AN\left(\sqrt{q_{e}^{2}+K\psi/N}-q_{e}\right)$，#L5520；$\psi$=浸液面积/转筒总表面积=浸液角度/360°，$\tau=\psi/N$，#L5494、#L5500。）

## 适用范围与边界

- 式 3-32 由「滤饼内毛细管束」的层流假定推出（#L5192）；滤饼不可压缩时 $r$ 为常数，可压缩滤饼 $r$ 随 $\Delta p$ 变，本页不展开。
- 式 3-40 仅对**恒压**过滤成立；恒速过滤、变压过滤须用微分式（3-37）积分（#L5262）。
- 若滤布阻力可忽略（$V_{e}\approx0$），式 3-40 退化为 $V^{2}=KA^{2}\tau$（#L5300 的说明）。
- 洗涤段、板框压滤机的生产能力另按洗涤速率计算，本页未收（#L5330 一带为洗涤计算起始）。

# 锥形封头

仅适用于半顶角 $\alpha\le60°$ 的轴对称锥壳（`#L6447`）。四种形式：单一厚度锥壳、多段等角组合、端部带折边+直边段、端部带加强段。

## 折边设置（表7-4，`#L6471-#L6479`）

| 半顶角 α | 大端 | 小端 |
|:--|:--|:--|
| ≤30° | 允许无折边 | 允许无折边 |
| ≤45° | 允许无折边，但须全截面焊透、内外打磨 $r_0\ge\delta_r$、100% RT/UT | 应有折边 $r_s\ge5\%D_{is}$ 且 $\ge3\delta_r$ |
| ≤60° | 应有折边 $r\ge10\%D_{iL}$ 且 $\ge3\delta_r$ | 同左 |
| >60° | 按平盖（或应力分析） | — |

## 锥壳厚度（式7-14）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_c=\dfrac{p_cD_c}{2[\sigma]_c^t\varphi-p_c}\cdot\dfrac{1}{\cos\alpha}$ | （7-14） |
| **文字式** | $\text{锥壳计算厚度}_{\text{【mm】}}=\dfrac{\text{计算压力}\times\text{计算内直径}}{2\times\text{许用应力}\times\text{焊接接头系数}-\text{计算压力}}\times\dfrac{1}{\cos(\text{半顶角})}$ |  |

$1/\cos\alpha$ 是锥壳的几何放大：$\alpha=60°$ 时为 2 倍，$\alpha=45°$ 时 1.414 倍。多段锥壳按各段大端内直径分别计算，取各段最大厚度。

## 无折边大端／小端（7.6.4.1／7.6.4.2）

- **判别**：大端按图7-13、小端按图7-15，以 $p_c/([\sigma]^t\varphi)$ 与 $\alpha$ 查交点；交点落在曲线上方或 $\alpha>31.5°$ → 需加强；落在下方 → 不需加强。
- **需要加强时**（式7-15／7-16）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_r=Q_1\delta$（$\delta/R_L\ge0.001$）；$\quad \delta_r=0.001Q_1R_L$（$\delta/R_L<0.001$） | （7-15） |
| **文字式** | $\text{加强段厚度}=Q_1\times\text{锥壳计算厚度}$；极薄时改为 $0.001\times Q_1\times\text{中面半径}$ |  |

- $Q_1$ 由图7-14（大端）、$Q_2$ 由图7-16（小端）按 $p_c/([\sigma]_s^t\varphi)$ 查取；小端极薄时用 $0.001Q_2R_s$。
- **加强段长度**：锥壳侧 $L_1\ge\sqrt{2D_{iL}\delta_r/\cos\alpha}$（大端）或 $\sqrt{2D_{is}\delta_r/\cos\alpha}$（小端）；圆筒侧 $L\ge\sqrt{2D_{iL}\delta_r}$ 或 $\sqrt{2D_{is}\delta_r}$。

## 内压 + 轴向载荷（7.6.4.3）

适用 $\alpha\le45°$；$30°<\alpha\le45°$ 须全截面焊透、打磨 $r_0\ge\delta_r$、100% RT/UT。

|  |  |  |
|:---|:---:|---|
| **符号式** | $k=\begin{cases}1 & \text{无加强圈}\\ \max\left(\dfrac{[\sigma]_s^tE_s}{[\sigma]_r^tE_r},1\right) & \text{加强圈在圆筒}\\ \max\left(\dfrac{[\sigma]_c^tE_c}{[\sigma]_r^tE_r},1\right) & \text{加强圈在锥壳}\end{cases}$ | （7-17） |
| **文字式** | 材料影响系数 k 取 1 或按加强圈所在位置取刚度比，不小于 1 |  |

仅适用于 $Q_L,Q_s$ 为**拉伸**（正值）；$f_1,f_2$ 拉伸取正、压缩取负。$Q_L=\frac14p_cD_{iL}+f_1$、$Q_s=\frac14p_cD_{is}+f_2$（外压时换 $D_L/D_s$）。

## 通用规则（7.6.1.3）

- 分段计算取各段厚度的**最大值**；
- 过渡段/加强段有效厚度 ≥ 所连锥壳计算厚度，且 ≥ $0.15\%D_i$；
- 外压锥封头**先满足内压强度**，再按第6章校核稳定性；
- 锥壳与圆筒连接一律全焊透。

## 判断

- 表7-4 的折边要求本质是在"几何突变处的边缘应力"与"制造难度"之间划线：α 越大，锥壳与圆筒的经线转角越大，无折边时边缘弯矩越大，所以先要求全焊透+打磨、再要求折边；
- 加强段的作用是承担边缘剪力与弯矩，$Q_1,Q_2$ 随 $p_c/([\sigma]^t\varphi)$ 增大而增大——即**薄壁高压**时加强段更厚；
- $\alpha>60°$ 归入平盖是合理的：此时锥壳已接近平板，薄膜假设失效。

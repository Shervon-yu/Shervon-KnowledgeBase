# 喷射式混合器（文丘里）

## 用途与组成（`#L17891-#L17897`）

主要用于**液-液、气-液**混合；炼油厂油品精制的酸碱洗涤与酸碱液配制中最常见；近年也用于气-气（如液化石油气与空气混合）。

组成：喷嘴 + 接受室 + 混合室 + 扩散器。

## 两种流程（图15-17，`#L17899-#L17909`）

| 流程 | 动力来源 | 次流 | 优缺点 |
|:---|:---|:---|:---|
| 循环流程 | 主流经喷嘴产生压降，动能增加 | 被抽入接受室，无需泵，循环使用 | 省药剂；但循环药剂浓度在变、影响精制效果，酸碱渣易带入混合器造成堵塞 |
| 一次通过 | 主流与次流靠自身压力进入 | 不循环 | 流程简单、浓度稳定；药剂消耗大 |

循环流程中扩散器出口压力**高于次流入口压力、低于主流入口压力**，正是这一压差实现自吸。

## 压力降要求（`#L17921-#L17923`）

| 过程 | 混合器压力降 $\Delta p$ |
|:---|:---|
| 碱洗、水洗 | 0.05~0.10 MPa |
| 酸洗 | 0.10~0.15 MPa |

压降大表示混合室内流速大、混合激烈。

## 压力平衡（式15-20~15-23，`#L17925-#L17961`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_s=p_d-\Delta p_1$ | （15-20） |
| **文字式** | $\text{次流入口压力}_{\text{【MPa】}}=\text{沉降罐操作压力}_{\text{【MPa】}}-\text{沉降罐底至混合器次流入口管系压降}_{\text{【MPa】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_m=p_d+\Delta p_2+\dfrac{H\rho_m}{100}$ | （15-21） |
| **文字式** | $\text{混合器出口压力}_{\text{【MPa】}}=\text{沉降罐操作压力}_{\text{【MPa】}}+\text{混合器出口至沉降罐入口管系压降}_{\text{【MPa】}}+\dfrac{\text{标高差}_{\text{【m】}}\times\text{混合液密度}_{\text{【t/m³】}}}{100}$ |  |

混合液密度（式15-22）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho_m=\dfrac{(1+u)\rho_s\rho_p}{\rho_s+u\rho_p}$，$u=\dfrac{Q_{ms}}{Q_{mp}}$ | （15-22） |
| **文字式** | $\text{混合液密度}_{\text{【t/m³】}}=\dfrac{(1+\text{主次流混合比})\times\text{次流密度}_{\text{【t/m³】}}\times\text{主流密度}_{\text{【t/m³】}}}{\text{次流密度}_{\text{【t/m³】}}+\text{主次流混合比}\times\text{主流密度}_{\text{【t/m³】}}}$，$\text{主次流混合比}=\dfrac{\text{次流质量流量}_{\text{【kg/s】}}}{\text{主流质量流量}_{\text{【kg/s】}}}$ |  |

主流入口压力（式15-23）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_p=p_m+\Delta p$ | （15-23） |
| **文字式** | $\text{主流入口压力}_{\text{【MPa】}}=\text{混合器出口压力}_{\text{【MPa】}}+\text{混合器压力降}_{\text{【MPa】}}$ |  |

## 喷嘴（式15-24~15-26，`#L17967-#L17989`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_n=\dfrac{Q_{mp}}{\varphi_1}\sqrt{\dfrac{1}{0.204g\rho_p\Delta p_p}}$ | （15-24） |
| **文字式** | $\text{喷嘴出口面积}_{\text{【m²】}}=\dfrac{\text{主流质量流量}_{\text{【kg/s】}}}{\text{喷嘴流量系数}}\times\sqrt{\dfrac{1}{0.204\times\text{重力加速度}_{\text{【m/s²】}}\times\text{主流密度}_{\text{【kg/m³】}}\times\text{主次流压差}_{\text{【Pa】}}}}$ |  |

$\varphi_1$ 取 **0.95**。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_n=1.13\sqrt{A_n}$；合并简化 $d_n=30.6\sqrt{\dfrac{Q_{mp}}{\sqrt{\rho_p\Delta p_p}}}$ | （15-25）（15-26） |
| **文字式** | $\text{喷嘴直径}_{\text{【m】}}=1.13\times\sqrt{\text{喷嘴出口面积}_{\text{【m²】}}}$；或 $=30.6\times\sqrt{\dfrac{\text{主流质量流量}_{\text{【kg/s】}}}{\sqrt{\text{主流密度}_{\text{【kg/m³】}}\times\text{主次流压差}_{\text{【Pa】}}}}}$ |  |

## 混合室（式15-27~15-30，`#L17993-#L18015`）

最佳面积比由式15-27、15-28 联立给出：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{A_t}{A_n}=\dfrac{-a+\sqrt{a^2-3.9b}}{1.95}$ | （15-29） |
| **文字式** | $\text{混合室与喷嘴面积比}=\dfrac{-a+\sqrt{a^2-3.9\times b}}{1.95}$ |  |

其中 $a=-\left[0.975+1.19\dfrac{\rho_p}{\rho_m}(1+u)^2-0.78\dfrac{\rho_p}{\rho_s}u^2\right]$，$b=1.19\dfrac{\rho_p}{\rho_m}(1+u)^2$；流量系数 $\varphi_2=0.975$、$\varphi_3=0.9$、$\varphi_4=0.925$（制造良好时）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_t=1.13\sqrt{A_t}$ | （15-30） |
| **文字式** | $\text{混合室直径}_{\text{【m】}}=1.13\times\sqrt{\text{混合室截面积}_{\text{【m²】}}}$ |  |

## 关键尺寸与其余尺寸

关键尺寸只有两个：**喷嘴直径**与**圆柱形混合室直径**；其余长度（接受室锥体起始直径、喷嘴出口至混合室入口距离、混合室长度、扩散器扩散角与长度、喷嘴锥体长度与收敛角）按这两个直径定，细部参考文献 [11]（`#L18017`）。

## 判断

- 喷射式混合器是「泵 + 混合器」二合一：设计时必须同时满足**抽吸比**（次流流量）和**出口压力**两个目标，任何一个不达标都算失败。
- 循环流程省药剂但药剂浓度漂移，精制精度要求高的场合应选一次通过流程。
- 式15-29 的解只在「给定混合比、出口压力最高」的意义上最优，实际制造偏差会让最佳面积比偏移，工程上按其 ±10% 取整即可。

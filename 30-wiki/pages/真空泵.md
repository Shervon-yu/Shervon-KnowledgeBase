# 真空泵

## 共同点（`#L4375`）

把设备内气体抽出排至大气（或略高于大气），使设备内形成真空。真空度用"低于大气的压差"表示。

## 往复真空泵（`#L4377-#L4381`）

结构与原理同往复压缩机。差别：

- 低压下操作，缸内外压差很小，阀门必须更**轻巧、启闭方便**；
- 真空度高时压比很大（如 95 kPa 真空度 ≈ 压比 20），余隙残余气体膨胀严重影响抽气速率；
- 对策：缸两端之间设**平衡气道**，排气终了时短时连通，让余隙残余气体从一侧流向另一侧，降低其压力，减小余隙影响。

## 水环真空泵（`#L4383-#L4391`）

结构：圆形外壳、偏心安装的带叶片转子、泵内充一定量水。转子旋转形成**水环**，偏心使叶片间小室容积周期性变化：右半部扩大吸气、左半部缩小压气。

| 项目 | 内容 |
|:---|:---|
| 最高真空度 | 85 kPa |
| 优点 | 结构简单紧凑、无阀门、经久耐用 |
| 运行要求 | 需不断充水以维持液封并冷却泵体 |
| 限制 | 真空度受泵内水温限制 |
| 变体 | 被抽气体不宜与水接触时换其他液体 → 液环真空泵 |

## 喷射泵（`#L4393-#L4405`）

属流体动力作用式：利用流体流动时动能与静压能相互转换来吸送流体，可吸送液体或气体；用于抽真空时称喷射式真空泵。

工作过程（单级水蒸气喷射泵）：高压水蒸气经喷嘴高速喷出 → 静压能转动能、产生低压吸入气体 → 混合气进扩散管减速 → 压力升高 → 排出。

| 项目 | 内容 |
|:---|:---|
| 工作流体 | 水蒸气（水蒸气喷射泵）或高压水（水喷射泵） |
| 单级真空度 | 仅 90 kPa；更高需多级水蒸气喷射泵 |
| 优点 | 结构简单、制造方便、可用耐腐蚀材料、无传动装置 |
| 缺点 | 效率低，仅 10%~25% |
| 其他用途 | 小型锅炉注水器（利用锅炉自身蒸汽注水并回收热能） |

## 判断

- 三种泵的能力梯度：水环 85 kPa < 单级蒸汽喷射 90 kPa < 多级喷射/往复更高；选型时真空度与抽气量要一起看。
- 水环泵的真空度上限由**水温**决定（水温高则水的饱和蒸气压高），这是它不能用热水或高温工况的物理原因。

# 分子扩散与费克定律

## 吸收过程的三步（`#L9002-#L9010`）

1. 溶质从气相主体传到**气液界面的气相侧**；
2. 在界面上溶解，进入**液相侧**；
3. 从界面液相侧传到**液相主体**。

界面与主体之间的传质称**对流传质**，其中同时存在分子扩散与湍流扩散。先研究纯分子扩散。

## 分子扩散的定义（`#L9018`）

流体内部存在浓度差时，分子热运动使组分从高浓度向低浓度迁移——分子扩散。工业上一般为**稳态**过程，故只讨论稳态双组分扩散。

## 扩散速率（`#L9028`）

单位时间通过单位面积扩散的物质量：

$$J\ \left[\mathrm{kmol/(m^2\cdot s)}\right]$$

## 费克定律（`#L9030-#L9042`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $J_A=-D_{AB}\dfrac{\mathrm{d}c_A}{\mathrm{d}Z}$ | （5-12a） |
| **文字式** | $\text{组分A扩散速率}_{\text{【kmol/(m}^2\cdot\text{s)】}}=-\text{扩散系数}_{\text{【m}^2\text{/s】}}\times\text{浓度梯度}_{\text{【kmol/m}^4\text{】}}$ |  |

理想气体用分压表示（$c_A=p_A/RT$）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $J_A=-\dfrac{D_{AB}}{RT}\dfrac{\mathrm{d}p_A}{\mathrm{d}Z}$ | （5-12b） |
| **文字式** | $\text{扩散速率}=-(\text{扩散系数}/\text{气体常数}\times\text{温度})\times\text{分压梯度}$ |  |

要点：
- 负号表示扩散方向与浓度梯度方向**相反**（由高到低）；
- 只适用于**双组分**混合物；
- 形式上与牛顿黏性定律、傅里叶定律同类——都是"通量 = 系数 × 梯度"。

## 扩散速率 vs 传质速率（`#L9098-#L9100`）

- 扩散速率 $J$：单纯分子扩散造成的传递；
- 传质速率 $N$：单位时间单位面积实际传递的物质量，含分子扩散与**整体流动**两部分。

只有在等摩尔逆向扩散中二者才相等：$N_A=J_A$。这正是下一节要展开的分界点。

## 判断

- 费克定律是"分子级"的，工程设备里主体流动湍流剧烈，单靠它是算不出总传质速率的；它的价值是给出**膜内**的传递规律，再与双膜理论拼成总速率方程。
- 记负号的最好方式：梯度是"从低到高"的导数方向，扩散是"从高到低"，两者天然反号。写代码或做题时若把 $c_{A1}-c_{A2}$ 直接当梯度代入，就不要再加负号。

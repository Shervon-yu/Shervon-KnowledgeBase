# 吸收剂用量与最小液气比

## 已知与待求（`#L9710-#L9712`）

已知：惰性气体量 $G$、进塔组成 $Y_1$、吸收剂进塔组成 $X_2$、分离要求。待求：吸收剂用量 $L$（等价于液气比 $L/G$）。

## 分离要求怎么给（`#L9714-#L9722`）

- 回收有用物质：给**回收率（吸收率）** $\eta$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\eta=\dfrac{G(Y_1-Y_2)}{GY_1}=1-\dfrac{Y_2}{Y_1}$ | （5-54） |
| **文字式** | $\text{回收率}=\dfrac{\text{被吸收的溶质量}}{\text{进塔气体溶质量}}=1-\dfrac{\text{出塔气相组成}}{\text{进塔气相组成}}$ |  |

- 除去有害物质：直接给出尾气残留组成 $Y_2$。

## 最小液气比的几何意义（`#L9724-#L9738`）

操作线斜率 $L/G$ 减小 → 操作线向平衡线靠近 → 出塔液组成 $X_1$ 增大、塔底推动力 $\Delta Y$ 减小 → 为达同一 $Y_2$ 所需填料层增高。

减到某一值，操作线与平衡线在塔底相交于 $B^{*}(Y_1,X_1^{*})$：该处推动力为零，**所需填料层高度趋于无穷**。这就是液气比的下限——**最小液气比** $(L/G)_{\min}$，对应 $L_{\min}$ 与吸收液组成上限 $X_1^{*}$（与进塔气 $Y_1$ 平衡的液相组成）。

## 三式计算（`#L9740-#L9756`）

| 情形 | 式 |
|:--|:--|
| 一般平衡线（图5-19a） | $\left(\dfrac{L}{G}\right)_{\min}=\dfrac{Y_1-Y_2}{X_1^{*}-X_2}$（5-55） |
| 平衡线呈凸形（图5-19b）：从 $T$ 作平衡线的切线 | $\left(\dfrac{L}{G}\right)_{\min}=\dfrac{Y_1-Y_2}{X_1'-X_2}$（5-56） |
| 亨利定律 $Y^{*}=mX$：$X_1^{*}=Y_1/m$ | $\left(\dfrac{L}{G}\right)_{\min}=\dfrac{Y_1-Y_2}{Y_1/m-X_2}$（5-57） |

$Y_1$、$X_2$ 已定时，$(L/G)_{\min}$ 只随分离要求 $Y_2$ 变化：要求尾气越干净（$Y_2$ 越小），最小液气比越大。

## 适宜液气比（`#L9758-#L9764`）

实际液气比必须大于最小值。取多大由经济核算定：液气比小 → 吸收剂省、操作费低，但塔高、设备费高；反之亦然。总费用曲线有最低点，工程经验取

$$\frac{L}{G}=(1.1\sim2.0)\left(\frac{L}{G}\right)_{\min}$$

## 例5-6（`#L9766-#L9826`）

炉气 1000 m³/h、20 ℃、含 SO₂ 9%（体积）、其余按空气；回收率 90%；用水吸收，$L=1.3L_{\min}$、$p=101.33$ kPa。

- $Y_1=0.09/(1-0.09)=0.099$；$Y_2=Y_1(1-\eta)=0.0099$；
- $G=\frac{1000}{22.4}\cdot\frac{273}{293}\cdot(1-0.09)=37.9$ kmol/h $=0.0105$ kmol/s；
- 查图5-20：与 $Y_1$ 平衡的 $X_1^{*}=0.0032$。

(1) $X_2=0.0003$：$(L/G)_{\min}=(0.099-0.0099)/(0.0032-0.0003)=30.7$；$L/G=1.3\times30.7=39.9$；$L=37.9\times39.9\times18=2.72\times10^4$ kg/h；$X_1=0.00253$。

(2) 清水 $X_2=0$：$(L/G)_{\min}=27.8$、$L/G=36.1$、$L=2.46\times10^4$ kg/h、$X_1=0.00247$。

结论：同样的回收率下，吸收剂越纯（$X_2$ 越低），所需用量越小；但再生越彻底成本越高，需两者兼顾。

## 判断

- "最小液气比对应无穷高塔"是理解整章的关键：它把热力学（平衡）与设备尺寸（塔高）绑在一起。实际取 1.1~2.0 倍，本质上是拿操作费（吸收剂+再生）换设备费（塔高）。
- 平衡线为凸形时必须作切线而非取 $X_1^{*}=Y_1/m$——因为最低推动力点可能不在塔底。这一条最容易被忽略。

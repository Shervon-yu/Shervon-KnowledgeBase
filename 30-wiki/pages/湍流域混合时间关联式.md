# 湍流域混合时间关联式

低黏液体的混合一般在湍流域进行，此时 $C_1$（混合准数 $N_{\theta M}$）为常数（`#L3041`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_1=N_{\theta M}=N\theta_M=K\left(\dfrac{D}{d}\right)^{\alpha}$ | （3-6） |
| **文字式** | $\text{混合准数}=\text{转速}_{\text{【1/s】}}\times\text{混合时间}_{\text{【s】}}=K\times\left(\dfrac{\text{搅拌设备内径}_{\text{【m】}}}{\text{搅拌器直径}_{\text{【m】}}}\right)^{\alpha}$ |  |

式中 $\alpha$ 为常数，通常在 1.5～2.5 之间；$K$ 为衰减常数（`#L3045-#L3047`，OCR 原文 $\alpha$ 上标残损、单位缺失，按上下文补）。

## 两条结论

1. **同一设备里 $d$ 越大 $C_1$ 越小**，混合性能越好——“大搅拌器的混合作用比小桨明显有效”（`#L3049`）。
2. 经验范围：设计得当的普通混合过程，$C_1=20\sim80$ 即可获得良好混合效果（`#L3051`）。

## 用法

给定设备几何与转速，先用 （3-6） 估 $C_1$，再用 $\theta_M=C_1/N$ 得混合时间；反过来由允许的 $\theta_M$ 反算所需转速。

- $K$ 与 $\alpha$ 需按桨型取值或标定，书中未给全表，实际用时应以同类桨型实测数据回归；
- 该式只适用于湍流域；层流与过渡流见 [[层流域搅拌器混合效率对比]]、[[过渡流域混合特性]]；
- 体积很大时混合时间的体积效应不可忽略，见 [[混合过程的混合时间与循环时间]]。

# 泄漏与密封判据

## 定义

**泄漏**：介质（气体、液体、固体或其混合物）从一个空间进入另一个人们不希望的空间的现象。单位时间内泄漏的介质量称为**泄漏率**。《机械密封结构图例及应用》§1.1.1 #L275

**密封**：机器、设备的连接处没有泄漏的现象；起密封作用的零部件称密封件，较复杂的密封连接称密封系统或密封装置。§1.1.1 #L277

**泄漏的物理根源**：机械加工必然留下表面缺陷与形状、尺寸偏差，零件接触处因此存在微小间隙；当存在压差或浓度差时，介质经间隙泄漏。§1.1.1 #L277

**紧密性**：不存在绝对的紧密性，只能定量衡量。文献定义为——在某一特定操作条件下，采用指定的、具有相应测试分辨率的检漏方法测得的泄漏率低于某一规定的指标泄漏率，则该连接是紧密的。§1.1.1 #L279

## 判据 / 计算

泄漏率的定义式（书中只给文字定义，本条公式为按其定义改写，非原书公式）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{v}=\dfrac{V}{t}$ | （1-1） |
| **文字式** | $\text{体积泄漏率}_{\text{【cm³/s】}}=\dfrac{\text{泄漏体积}_{\text{【cm³】}}}{\text{时间}_{\text{【s】}}}$ |  |

泄漏率的三种表示与常用单位（§1.1.1 #L283）：体积流率 `cm³/s`、质量流率 `g/s`、pV 流率 `Pa·m³/s`。三者不可直接互比，换算式本书未给出。

指标泄漏率（判据值）由行业标准规定，不是物理常数：

| 场合 | 指标泄漏率 | 出处 |
|:---|:---|:---|
| 一般工业与部分石化装置 | 四级，由 `1.0×10⁻⁴`、`1.0×10⁻³`、`1.0×10⁻² cm³/s` 与最高一级组成（最高一级原书 OCR 为 `1.?×10⁻⁵`，数值待核） | GB/T 4622.3—2007，§1.1.1 #L281 |
| 核能与重要化工设备 | 控制在 `10⁻⁷ cm³/s` 以下 | §1.1.1 #L281 |
| 心脏起搏器同位素电池 | 约 `10⁻¹² Pa·m³/s` 量级 | §1.1.1 #L281 |

## 适用范围与边界

- 紧密性判据必须连同**检漏方法与其分辨率**一起给出，脱离方法谈"漏/不漏"无意义；同一连接换检漏手段，结论可以不同。§1.1.1 #L279
- 判据值是工程约定（标准分级的产物），不是"零泄漏"；`10⁻⁷ cm³/s` 与 `10⁻¹² Pa·m³/s` 相差多个数量级，说明指标随行业风险等级变化。
- 本书只给指标数量级，**不给**泄漏率与间隙、压差、黏度的定量关系式；需要设计计算时须另找手册，不要在本库内插值外推。
- 四种表示（体积/质量/pV 流率）之间的换算依赖介质密度与压力，本库暂无出处，标为待补。

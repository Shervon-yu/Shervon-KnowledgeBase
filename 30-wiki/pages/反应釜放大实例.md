# 反应釜放大实例

## 设计目标（原文）

反应釜设计要消除传递界限、提供良好混合与接触，使过程尽量在**动力学或平衡控制**下进行；反应釜行为应**与加料方式、加料位置、物性变化无关**，并防止过热/过冷点与死区（`#L4301-#L4305`）。

原文提示：相当数量反应釜效果不佳，源于缺乏对过程的理解与简单设计错误，例如把进料管设在釜壁与冷却管之间（`#L4309`）。

## 原始釜（14 m³）

$D=2440$ mm、$d=1270$ mm、$b=165$ mm、$N=130$ r/min、$N_p=0.45$、$N_{qd}=0.225$、$\rho$ 按水（`#L4315-#L4317`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{qc}=N_{qd}\left\{1+0.16\left[(D/d)^{2}-1\right]\right\}$ | — |
| **文字式** | $\text{循环流量准数}=\text{排出流量准数}\times\left\{1+0.16\left[\left(\dfrac{\text{釜径}}{\text{桨径}}\right)^{2}-1\right]\right\}$ |  |

$N_{qc}=0.32$；$Q_c=0.32\times130\times1.27^{3}=85.2$ m³/min；循环次数 $85/14\approx6.07$ 次/min；$P=0.45\times\dfrac{1000}{9.8\times102}\times(130/60)^{3}\times1.27^{5}=15$ kW；$P_V=1.07$ kW/m³（`#L4323-#L4339`）。

## 几何相似放大到 45 m³

放大比 $\alpha=(45/14)^{1/3}\approx1.48$；$D_L=3611\to$ 实取 **3600 mm**；$d_L=1880$ mm；$b_L=244$ mm（`#L4347-#L4359`）。

按 $P_V$ 恒等求转速：$N_L=100$ r/min → $Q_c=213$ m³/min → 循环次数 **4.73 次/min**（`#L4363-#L4369`）。

**问题**：完全几何相似 + $P_V$ 恒等时，循环次数明显下降，反应效果可能变差。

## 补救：改叶宽（非几何相似）

功率与 $b$ 的一次方（或小于一次方）、与 $N^3$、与 $d^5$ 成正比，故**在功率增幅不大的前提下加宽叶片最划算**；把三叶改四叶会给叶片与轴的连接带来困难（`#L4373`）。

取 $b=300$ mm、$d=1850$ mm：

- $N_p=0.45\times\dfrac{300/3600}{165/2440}=0.55$；
- $\dfrac{N_p}{N_{qd}}=\dfrac{0.45}{0.225}\times\dfrac{244}{300}=1.63$ → $N_{qd}=0.34$；
- $N_{qc}=0.49$；$Q_c=0.49\times100\times1.85^{3}=310$ m³/min；
- 循环次数 $310/45=6.88$ 次/min（略高于原釜）；
- $P=55$ kW，$P_V=1.22$ kW/m³。

（`#L4377-#L4395`）

## 结论

1. 放大时不必要求大釜循环次数与小釜**相等**，只需**超过某一低限值**（`#L4397`）；
2. 调叶宽是"用几何换循环"的典型手段，代价是 $P_V$ 略升（1.07→1.22）。

# 两股进料的精馏塔

## 为什么不混料（`#L12689-#L12695`）

两种组成不同的原料若混合后进塔，所需理论板数增多；若要板数相同，则单股进料时的 R 要更大、再沸器热负荷更高。因此按组成**分别加入不同位置**。

塔分三段：精馏段（上）、中间段、提馏段（下）。

## 中间段操作线（`#L12697-#L12711`）

对中间段至塔顶作物料衡算：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $V''+F_1=L''+D$，$V''y+F_1x_{F1}=L''x+Dx_D$ | （6-58）（6-59） |
| **文字式** | 进料 1 以上至塔顶的总物料与组分衡算 |  |

整理得：

$$y=\frac{L''}{V''}x+\frac{Dx_D-F_1x_{F1}}{V''}\tag{6-60}$$

段间流量关系：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $L''=L+q_1F_1$，$V''=V+(q_1-1)F_1$；$L'=L''+q_2F_2$，$V'=V''+(q_2-1)F_2$ | （6-61）（6-62） |
| **文字式** | 每股进料按自身 q 值改变液量与汽量 |  |

两条 q 线：

$$y=\frac{q_1}{q_1-1}x-\frac{x_{F1}}{q_1-1}\quad(6-63),\qquad y=\frac{q_2}{q_2-1}x-\frac{x_{F2}}{q_2-1}\quad(6-64)$$

## 作图（`#L12733-#L12735`）

1. 精馏段线（截距 $x_D/(R+1)$）与 $q_1$ 线交于 $f_1$；
2. 从 $f_1$ 作斜率 $L''/V''$ 的中间段线，与 $q_2$ 线交于 $f_2$；
3. 连 $f_2$ 与 $W(x_W,x_W)$ 得提馏段线。

三段斜率必须满足：

$$\frac{L}{V}<\frac{L''}{V''}<\frac{L'}{V'}$$

（自上而下液汽比递增——因为每加一股进料，下降液量相对增加。）

## 例6-20（`#L12737`）

苯-甲苯：$F_1$=100、$x_{F1}$=0.6；$F_2$=200、$x_{F2}$=0.3；均饱和液体；$x_D\ge0.9$、$x_W\le0.02$、$R$=2。按上述作图法求中间段操作线方程。

## 判断

- 两股进料的价值在于"把高质量原料放在塔顶附近、低质量原料放在下部"，避免高质量组分在塔内被反复稀释——本质是**减少返混损失**。
- 三段斜率的有序性是必然的：每进一股料，$L$ 增加而 $V$ 减少（q>0 时），$L/V$ 必增大。
- 多股进料的图解与单股相同，只是多了一个"分段点"；实际塔的进料板位置优化比单股更敏感。

# 管路阻力-局部阻力与当量长度

## 定义

流体流经管件、阀门及设备进出口时产生的摩擦阻力损失称**局部摩擦阻力损失**（#L1941）。计算有两种方法：**局部阻力系数法**与**当量长度法**（#L2274）。

- **局部阻力系数 $\zeta$**：由实验测定，反映某管件/阀件的阻力特性，常用值列于表 1-2（#L2282-#L2295）。
- **当量长度 $l_{\mathrm e}$**：把局部损失折算成"同直径直管需要多长才产生同样的阻力"，便于并入直管项一次算完（#L2328）。

## 判据 / 计算

局部阻力系数法：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{\mathrm f}=\zeta\dfrac{u^{2}}{2}$ | （5-1） |
| **文字式** | $\text{局部阻力损失}_{\text{【J/kg】}}=\text{局部阻力系数}\times\dfrac{\left(\text{流速}_{\text{【m/s】}}\right)^{2}}{2}$ |  |

当量长度法（把 $l_{\mathrm e}$ 并入直管项）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{\mathrm f}=\lambda\left(\dfrac{l}{d}+\dfrac{l_{\mathrm e}}{d}\right)\dfrac{u^{2}}{2}$ | （5-2） |
| **文字式** | $\text{摩擦阻力损失}_{\text{【J/kg】}}=\text{摩擦系数}\times\left(\dfrac{\text{直管长}_{\text{【m】}}}{\text{内径}_{\text{【m】}}}+\text{当量长度与内径之比}\right)\times\dfrac{\left(\text{流速}_{\text{【m/s】}}\right)^{2}}{2}$ |  |

原书编号：式(1-56)（#L2280）；当量长度法见 #L2328 起，$l_{\mathrm e}/d$ 值并列于表 1-2。

突然扩大 / 突然缩小（流速取**小管**中的流速）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\zeta=\left(1-\dfrac{A_1}{A_2}\right)^{2}$ | （5-3） |
| **文字式** | $\text{局部阻力系数}=\left(1-\dfrac{\text{小截面面积}_{\text{【m²】}}}{\text{大截面面积}_{\text{【m²】}}}\right)^{2}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\zeta=0.5\left(1-\dfrac{A_2}{A_1}\right)^{2}$ | （5-4） |
| **文字式** | $\text{局部阻力系数}=0.5\times\left(1-\dfrac{\text{小截面面积}_{\text{【m²】}}}{\text{大截面面积}_{\text{【m²】}}}\right)^{2}$ |  |

原书编号：式(1-57a)、(1-57b)，见 #L2302、#L2320。

表 1-2 摘录（#L2286-#L2295，用于湍流）：

| 管件 | $\zeta$ | $l_{\mathrm e}/d$ |
|:---|---:|---:|
| 弯头 90° | 0.75 | 35 |
| 弯头 45° | 0.35 | 17 |
| 三通 | 1 | 50 |
| 闸阀（全开） | 0.17 | 9 |
| 闸阀（半开） | 4.5 | 225 |
| 截止阀（全开） | 6.0 | 300 |
| 球式止逆阀 | 70 | 3500 |

两个极限（#L2324）：管路流入大容器（$A_1/A_2\approx0$）→ $\zeta=1$；大容器进入管口（$A_2/A_1\approx0$）→ $\zeta=0.5$。

## 适用范围与边界

- 表 1-2 的 $\zeta$ 与 $l_{\mathrm e}/d$ 值**只用于湍流**（#L2284 表题）。
- $\zeta$ 是实验值，随管件规格、口径、开启度变化；表中是常见规格的代表值，精确计算应查具体管件资料。
- 当 $A_1=A_2$（等直径直管）时两式均给 $\zeta=0$，即无此项局部损失（#L2322）。
- 局部损失与直管损失相加得总摩擦损失（#L1943），再代入伯努利方程（[[流体流动-伯努利方程]]）。

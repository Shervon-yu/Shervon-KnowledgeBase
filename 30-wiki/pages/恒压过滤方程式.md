# 恒压过滤方程式

## 恒压过滤（`#L5281-#L5299`）

$\Delta p$ 恒定，$\mu$、$r$、$v$、$V_e$ 均为常数，对式(3-38)积分：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{V^2}{2}+VV_e=\dfrac{A^2\Delta p}{\mu r v}\tau$ | （积分式，书内未编号） |
| **文字式** | $\dfrac{\text{滤液体积}^2}{2}+\text{滤液体积}\times\text{当量滤液体积}=\dfrac{\text{过滤面积}^2\times\text{压降}\times\text{时间}}{\text{黏度}\times\text{比阻}\times\dfrac{\text{滤饼体积}}{\text{滤液体积}}}$ |  |

令过滤常数 $K=\dfrac{2\Delta p}{\mu r v}$（3-39），得恒压过滤方程式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $V^2+2VV_e=KA^2\tau$ | （3-40） |
| **文字式** | $\text{滤液体积}^2+2\times\text{滤液体积}\times\text{当量滤液体积}=\text{过滤常数}\times\text{过滤面积}^2\times\text{过滤时间}$ |  |

除以 $A^2$，令 $q=V/A$、$q_e=V_e/A$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $q^2+2qq_e=K\tau$ | （3-41） |
| **文字式** | $\text{单位面积滤液量}^2+2\times\text{单位面积滤液量}\times\text{单位面积当量滤液量}=\text{过滤常数}\times\text{过滤时间}$ |  |

- $q$：单位过滤面积获得的滤液体积，m³/m²；
- $q_e$：单位面积当量滤液体积，m³/m²；
- $K$：过滤常数，m²/s，由 $K=2\Delta p/(\mu rv)$ 知它与压差、悬浮液性质、温度（$\mu$、$r$、$v$）有关。

## 过滤常数的测定（`#L5321-#L5329`）

无可靠预测方法，工业设计须用小试测定。把式(3-41)改写成线性式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{\tau}{q}=\dfrac{1}{K}q+\dfrac{2q_e}{K}$ | （3-42） |
| **文字式** | $\dfrac{\text{过滤时间}}{\text{单位面积滤液量}}=\dfrac{1}{\text{过滤常数}}\times\text{单位面积滤液量}+\dfrac{2\times\text{单位面积当量滤液量}}{\text{过滤常数}}$ |  |

实测不同 $\tau$ 下的 $q$，以 $\tau/q$ 对 $q$ 作图：斜率 $=1/K$、截距 $=2q_e/K$，由此得 $K$ 与 $q_e$。

**限制**：只有工业生产条件与实验条件完全相同时，才能直接搬用实验的 $K$、$q_e$（原文强调）。

## 判断

- $K$ 把压差、黏度、比阻、$v$ 四个量打包成一个可测参数，这是恒压过滤方程能用于设计的根本原因；代价是换料、换压差、换温度都必须重测。
- 式(3-42)的形式意味着：即使 $K$ 与 $q_e$ 未知，只要做一组 $\tau$–$q$ 数据，两者可同时解出；这也解释了为什么过滤实验通常只需记录时间与滤液量。

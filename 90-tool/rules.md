## 1. 总则

**一个会话 = 一本书 = `00-inbox` 下一个文件夹 = 一个入库夹。** 不并行、不批量、不跳步。文件夹缺失时按第 2 节自动建，不停下询问。
下文「入库夹」= 因一次入库而生成的那个文件夹，形如 `书名_作者_版次_年份`。

## 2. 输入

- `00-inbox` 顶层只认一个入库单元：**恰好一个文件夹 → 用它**；**只有散文件 → 自动建入库夹、把顶层散文件全部移入，继续，不询问**；**2 个以上文件夹 → 停，问处理哪一个**（不许自己挑）；**空 → 停，告诉用户放书**。
- 自动建夹的命名：取文件名里的书名与作者，缺项写 `NA`，形如 `书名_作者_NA_NA`；文件名带 `(作者编著)`/`（作者主编）` 的，去掉括号与「编著/主编/著/编」；书名内全角 `－` 归一为半角 `-`。**这只是初值**：解析完必须用正文版权页/CIP 校准书名、版次、年份（例：文件名「汽液」而版权页是「气液」），不符就改名——入库夹、md 文件名、`10-source` 目录、frontmatter 的 `title/src` 同步改，改完重跑 `catalog.ps1`。
- 文件夹名：`书名_作者_版次_年份`，缺项写 `NA`，例：`机械设计手册_成大先_第5版_2008`。
- 一个文件夹内可有多个文件（分册、扫描页、补充图），按文件名排序依次解析，合并成一份正文。
- 支持：`.pdf .png .jpg .jpeg .webp .bmp .tif .tiff`（走 MinerU）、`.md .txt`、`.docx .pptx .xlsx`（直接读 OOXML，不需要 Office）、`.html`（粗提取）。
- **入库成功后，`00-inbox` 里这个文件夹若已空则删除**（原件此时已移进 `10-source`，inbox 只作传送带，不作仓库）。解析失败或走第 9 节手工回退时**保留原文件**，并在 `todo.md` 留痕。
- 不支持：`.doc .ppt .xls`（97-2003）——要求另存为新格式。

## 3. 输出

- 原件 → `10-source\<层级>\<入库夹>\`（移动，保持原文件名）
- 正文与其他文档 → `20-md\<层级>\<入库夹>\`（入库夹根：`<入库夹>.md`，将来也可能是 txt/csv 等）
- 图示 → `20-md\<层级>\<入库夹>\图片\`（**所有插图集中放 `图片\`**，文件名见第 5 节）
- 隔离 → `20-md\_quarantine\Q-<入库夹>.md`
- 索引 → `30-index\manifest.csv`、`catalog.md`、`todo.md`（由 `catalog.ps1` 重建）
- 新建物（脚本/日志/笔记/临时目录）→ `40-new\`，一律不许落到根目录或 `20-md`、`10-source` 里

`<层级>` 默认为空（即直接放 `20-md\<入库夹>`），只有第 4 节阈值触发时才出现分类夹；`10-source` 与 `20-md` 的层级必须完全镜像。

frontmatter 字段：

```
id / title / authors / edition / year / kind / topic / pages / ocr /
quality / sha256 / src / files / added / missing
```

`kind` 取值：`book spec paper project web other note`（`spec` = 标准/规范，避免与解析档位 `standard` 混淆）。`topic` 填分类夹名；扁平时填 `NA`；分组后手工补或由 `catalog.ps1` 回写。

## 4. 分层（v2.0 核心）

### 4.1 硬上限

任一文件夹的直接子项（子文件夹数）**不得超过 40 个**。超过即为违规，必须先分组再入库。

### 4.2 阈值

令 **N** = `20-md` 下现有的入库夹总数（不含 `_quarantine`，含已被分组的）。

| N | 规则 |
|:---|:---|
| N < 20 | **只许扁平**：`20-md` 下只有入库夹，不建任何分类夹 |
| 20 ≤ N ≤ 40 | **可选分组**：能一眼看出某一主题 **≥ 3 个**入库夹同类时，可建一个分类夹把它们移进去；看不出就继续扁平 |
| N > 40 | **必须分组**：直到层数 x 满足 `40^(x-1) < N ≤ 40^x`，且每个文件夹直接子项 ≤ 40 |

- 例：N=41 → 至少 1 层分类夹、`20-md` 下 ≤40 个子项；N=1601 → 至少 2 层。
- 允许**分类夹与入库夹同层混放**（例如 `20-md\机械\` 与 `20-md\化工原理_…\` 并列）。
- 「明显同类」指同一学科、同一项目或同一来源的成套资料，不是硬性分类学。

### 4.3 分类夹命名

- 用主题词：`机械`、`流体`、`仪表`、`公司项目`、`奇门遁甲`……中英文皆可，不带序号前缀。
- 已存在同名或同义分类夹就**复用它**，不许建 `机械2`、`mechanical` 两个并列夹。
- 分类夹名不写进 `taxonomy.md` 也可以建；`taxonomy.md` 只是**建议清单**，不再是白名单。

### 4.4 重排时机（每进一本就重排）

**每次新增一个入库夹时，先判定它归哪个分类夹，再决定放哪一层**，不要等到硬阈值才动。

1. 先看现有一级/各级分类夹里**已经装着什么入库夹**——判断依据是夹内实际内容，不是夹名。
2. 有一看就合适的 → 直接放进去（需要时先建该分类夹）。
3. 没有合适的，但存在若干个能凑成一类的入库夹 → 新建分类夹，**只把本次这一本放进去；别人的入库夹不动**（批量归并见 4.5）。
4. 夹名不再贴合内容时**允许改名**（`仪表` → `测量与控制`）；改名后必须重跑 `catalog.ps1`。
5. 每次重排后自检：任一文件夹直接子项 ≤ 40；`20-md` 与 `10-source` 层级完全镜像。

### 4.5 谁负责重排

- 外部 agent：只决定**自己这一本**应放哪一层（复用已有分类夹或按 4.2 新建一个），**不移动别人的入库夹**。
- 全局重排（把散落入库夹归并、拆超限夹）由 **DSH** 负责；外部 agent 建分类夹时可移动本次入库的夹，归并既有夹只有 DSH 能做；`catalog.ps1` 会在 `todo.md` 里报「层级体检」（当前 N、是否超限、建议动作）。
- 任何移动之后必须重跑 `catalog.ps1`，否则索引路径失效。

## 5. 图示规则（强制）

原文出现"图X.X 说明"（含"如图所示（图 3-1 …）"）时：

- **正文**：文字照常转换，图号与说明原样保留（`图3-1 结构示意图`），不改写法、不删图号。
- **图片**：由 MinerU 导出（`--format zip` 的 `images/`），脚本读 `middle_json.json` 定位图题，改名后放入入库夹的 `图片\` 子目录。
- **文件名**：`图1.1 问题描述.jpg` = 图号 + 一个空格 + 说明；图号归一为 `图X.Y`；说明超 60 字截断。
- **禁用字符**：`( ) [ ] { } * ? : " < > | / \ # %` 一律换成空格或下划线——括号/方括号会截断 markdown 的 `![](...)` 链接，是硬错误；图题里的引用号（`[31]`、`[31-33]`）在命名前先剥掉。
- **多子图**：`图7.3 104型机械密封_a.jpg`、`_b`、`_c`（不用 `(a)`）。
- **无图号**：`未命名图1.jpg`、`未命名图2.jpg`……
- **md 链接**：`![](图片/图1.1 问题描述.jpg)`——带 `图片/` 前缀，不出现绝对路径；**目标写真实文件名，含空格照写，不加 `%20`**（`check-links.ps1` 按原文判：含 `%` 一律记 bad，即使解码后文件存在）。
- **同号重复**：第二次起加 `_2`、`_3`，再与子图后缀组合为 `_a_2`。

## 6. 命名

`书名_作者_版次_年份.ext`；正文 md 与入库夹同名。入库夹名与 md 名必须一致。

## 7. 质检（自动，`ingest.ps1` 内）

| 指标 | 阈值 | 处置 |
|---|---|---|
| 有效字符（去空白） | < 200 | `quarantine` → `20-md\_quarantine\Q-*.md` |
| 有效字符 | 200 ~ 2000 | `warn`，照常入库，记 `todo.md` |
| U+FFFD 占比 | > 2% | `quarantine` |
| 单个 md/txt | > 5 MiB | 记 `todo.md`，不拦 |
| PDF 解析失败 | — | 原件归档，正文记 `pending`，进 `todo.md` |
| 图题存在但 MinerU 未导出图 | — | `figures.py`/`check-links.ps1` 报缺图数 + 清单，进 `todo.md`（可选：按页重解析补齐） |

隔离不等于删除：原件照样进 `10-source`，md 进 `_quarantine`，`manifest.csv` 与 `todo.md` 都留痕。

## 8. 禁止（九条）

1. 不删任何文件（原件、md、图片）；例外三条：`figures.py --dedupe` 删**同字节副本**（第 11 节）；`00-inbox` 里已成功入库且已清空的文件夹（第 2 节）；`check-links.ps1` 只删**指向不存在文件的链接标记**，不删图。
2. 不改 `10-source` 里的文件内容。
3. 不覆盖已有 md。
4. 不移动、不改名别人已入库的入库夹（全局重排是 DSH 的活）。
5. 不联网（不上传、不下载模型）。
6. 不安装软件。
7. 不新增分类夹以外的目录层级；层数超出第 4 节公式即违规。
8. 不跳过 MinerU 解析直接手写正文（预览可跳过，解析不可跳过）。
9. 不直接写 DSH 检索索引（插件私有 JSON，只能由 DSH 写）。

## 9. 手工回退（执行者不能跑命令时）

1. 能直接读的（`.md/.txt`）→ 按第 3、5、6 节写 md + frontmatter，放进对应目录。
2. PDF / 图片 → 用本机任何工具转文字（**不许上传到任何网站**）；转不出就整本留在 `00-inbox`，记进 `todo.md` 的"待解析"。
3. 原件**复制**（不是移动）到 `10-source` 对应目录，`00-inbox` 里的原文件夹保留。
4. 不生成 `manifest.csv`，交给 DSH 跑 `catalog.ps1` 重建。
5. 汇报里注明"手工完成，未跑脚本"。
6. 留在 `00-inbox` 的文件夹里放一个空的 `_done` 标记文件；下次会话按第 2 节跳过它，并在 `todo.md` 里记一笔。

## 10. 汇报格式

```
书名：
入库夹：机械密封结构图例及应用_孙开元、郝振洁_第1版_2017
层级：20-md\<入库夹>            （或 20-md\机械\<入库夹>）
正文：20-md\<层级>\<入库夹>\<入库夹>.md
文件：3 个（2 PDF + 1 图）
图示：12 张（图片\ 内，图3.1 … 图3.12）
inbox：已清空
质检：ok / warn / quarantine
图链：SELFCHECK refs=N ok=N unresolved=0
缺图：N 张（清单见 todo.md）
元数据缺失：edition, year
20-md 当前入库夹数：N（<20 扁平 / 20~40 可分组 / >40 必须分组）
未完成：无 / 具体清单
```

## 11. 图名归一工序（DSH 专用，入库后跑）

`90-tool\scripts\figures.py`：读 MinerU 产物 → 按 bbox 把图题配回图片 → 按 SHA256 去重 → 改名为 `图X.Y 说明[_a].jpg` 并放进 `图片\` → 改写 md 引用为 `图片/...` → 报告写 `40-new\figures-report-<入库夹>.json`。**它由 `ingest.ps1` 内部调用，MinerU 原始产物随后即被删除**——只有另外保留了产物时才可手工重跑（`--mineru` 指向那份产物）。

```
python -X utf8 "D:\Shervon_KnowledgeBase\90-tool\scripts\figures.py" `
  --mineru "<mineru 输出目录>" --book "20-md\<层级>\<入库夹>" --dedupe [--apply]
```

- 默认 dry-run；`--apply` 才动文件和 md。
- `--dedupe` 只删**同字节副本**，且把引用重指向保留件；删前已核对唯一性。
- 同一本书重复跑是安全的（幂等）。
- 跑完必须重新检查：`broken` 应为 0。用 `check-links.ps1 -Md <md>`（默认 dry-run，`-Fix` 才修），输出 `unresolved=0` 才算过。

## 12. 50-wiki 层（LLM Wiki）

三层结构：raw（`10-source` + `20-md`）→ wiki（`50-wiki`）→ schema（`90-tool\AGENTS.wiki.md` + 本文件）。

- `50-wiki` 固定六个子目录：`concepts` / `entities` / `sources` / `comparisons` / `howto` / `openq`，外加 `index.md`（索引）、`log.md`（变更日志）、`glossary.md`（唯一译名表）。
- 写者边界：**只有 LLM 写 `50-wiki`**；人在 Obsidian 中只读，改动靠 git 审计；脚本不写 `50-wiki`。
- 一次提交只含一本书的 ingest，不混两本。
- 页面级编辑契约全文见 `90-tool\AGENTS.wiki.md`；与本文件冲突时以更严的一条为准。
- 新增子目录前必须先改 `AGENTS.wiki.md` 第 0 节，不得擅自开新层级。

## 13. 页面契约（frontmatter 与硬约束）

字段顺序固定，不得增删或调序：

```
---
type: concept
title: 端面比压
aliases: [端面比载荷]
domain: 机械密封
status: draft
confidence: high
sources:
  - book: 机械密封结构图例及应用
    section: §1.2
    lines: "#L120-#L148"
related: ["[[泄漏与密封判据]]"]
supersedes: []
updated: 2026-11-16
---
```

- `type` 六选一：`concept` / `entity` / `source` / `comparison` / `howto` / `openq`，必须与所在目录一致。
- `status` 四选一：`draft` / `stable` / `superseded` / `open`。
- `confidence` 三选一：`high` / `medium` / `low`；`low` 需在正文首段说明为何低。
- 单页 ≤150 行；超了拆页，原页留「→ 已拆至 [[新页]]」。
- 每页入链 ≥2，否则合并或删除。
- 图引用必须附 ≥1 句文字转述；转述不出则走视觉模型并在 `log.md` 记一条。
- 文件名 = `title` = 正名；禁用字符 `\ / : * ? " < > |`。

## 14. 引用格式（书名 + 节号 + 行号双轨）

正文引用一律写成：`《书名》§节号（#L行号）`，例：

```
《机械密封结构图例及应用》§1.2（#L120-#L148）
```

- 节号用书中真实章节号，不自行编号、不猜。
- 行号指 `20-md\<入库夹>\<入库夹>.md` 的绝对行号。
- 行号随重解析漂移：重解析后由 `md-anchor.ps1` 重算锚点，并在 `log.md` 记一条 `reanchor`。
- 只写书名不写节号 = 无来源，按 `AGENTS.wiki.md` §2 处理（进 `openq`）。
- 同一断言跨书时逐条列全，不合并成一条。

## 15. SOP（ingest / query / lint）

**ingest 八步**：0 查重（`glossary.md` + `concepts\`）→ 1 章节地图（`(n)` 假标题降级为粗体）→ 2 写 `sources\` 页 → 3 建/改概念页 → 4 转述图 → 5 回改受影响页（冲突开 `openq`）→ 6 更新 `index.md` → 7 追加 `log.md`（记 token 与成本）→ 8 `wiki-lint.ps1` + `git commit`。

**query 四步**：grep `index.md` 与 `50-wiki` → 读 ≤10 候选页 → 回答带 §节号与 `#L` 行号 → 判断回填（crystallize）并登记 `index.md`。

**lint 八项**：死链 / 孤儿页 / 无来源 / 超长页 / 同义重复 / 过期断言 / index 漂移 / 图无转述。命令：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\Shervon_KnowledgeBase\90-tool\scripts\wiki-lint.ps1"
```

报告写 `50-wiki\_lint.md`（生成物，不进版本库）。

**提交信息格式**：`wiki(ingest): <书名> touch=N`；`crystallize` 与 `lint` 分别用 `wiki(crystallize):` / `wiki(lint):` 前缀。

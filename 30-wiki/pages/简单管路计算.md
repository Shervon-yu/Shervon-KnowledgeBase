# 简单管路计算

## 计算基础（`#L2431-#L2462`）

简单管路=单根管子+管件组成的输送系统。计算本质是四个式子联立：

$$u=\dfrac{4q_V}{\pi d^2},\quad \sum h_f=\lambda\dfrac{l}{d}\dfrac{u^2}{2},\quad Re=\dfrac{du\rho}{\mu},\quad \lambda=f\left(Re,\dfrac{\varepsilon}{d}\right)$$

管路两端常接液面恒定的容器，两液面间列机械能衡算式：$\sum h_f=gH$（位头全用于克服阻力）。

## 三类问题（`#L2464-#L2616`）

| 类型 | 已知 | 求 | 方法 |
|:---|:---|:---|:---|
| 第一类 | $d$、$l$、$q_V$、物性 | $\sum h_f$ 或 $H$ | 直接算 |
| 第二类 | $d$、$l$、$\sum h_f$（或 $H$）、物性 | $u$、$q_V$ | 用 1-60 直接算 |
| 第三类 | $q_V$、$\sum h_f$、$l$ | $d$ | 用 1-61~1-63 试差 |

### 第一类：例 1-19（`#L2472-#L2492`）

输水 35 m³/h、φ89×3.5（$d$=0.082 m）、$l$=138 m（含当量长度）、$\varepsilon/d=0.0001$：

$u=1.84$ m/s、$Re=1.51\times10^5$（湍流）、$\lambda=0.017$，

$H=\lambda\dfrac{l}{d}\dfrac{u^2}{2g}=0.017\times\dfrac{138}{0.082}\times\dfrac{1.84^2}{2\times9.81}=4.94$ m。

### 第一类：例 1-20 求泵轴功率（`#L2494-#L2522`）

36 m³/h、φ108×4（$d$=0.1 m）、$\varepsilon$=0.2 mm、$l$=80 m、闸阀全开 $\zeta\approx0.17$、位差 20 m、泵效率 60%：

- $u=1.27$ m/s、$Re=1.26\times10^5$、$\lambda=0.025$；
- $\sum W_f=\left(0.17+0.025\times\dfrac{80}{0.1}\right)\dfrac{1.27^2}{2}=16.3$ J/kg；
- $W_e=20\times9.81+16.3=212.5$ J/kg；
- 有效功率 $N_e=W_e q_V\rho=212.5\times\dfrac{36}{3600}\times998.2=2.12$ kW；
- 轴功率 $N=\dfrac{N_e}{\eta}=\dfrac{2.12}{0.6}=3.53$ kW。

### 第二类：1-60 与例 1-21（`#L2524-#L2550`）

把 $\lambda$ 换成考莱布鲁克式并消去 $\lambda$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=-2\sqrt{\dfrac{2d\sum h_f}{l}}\lg\left(\dfrac{\varepsilon/d}{3.7}+\dfrac{2.51\mu}{d\rho}\sqrt{\dfrac{l}{2d\sum h_f}}\right)$ | （1-60） |
| **文字式** | $\text{流速}_{\text{【m/s】}}=-2\sqrt{\dfrac{2\times\text{管内径}\times\text{总阻力损失}}{\text{管长}}}\lg\left(\dfrac{\text{相对粗糙度}}{3.7}+\dfrac{2.51\times\text{黏度}}{\text{管内径}\times\text{密度}}\sqrt{\dfrac{\text{管长}}{2\times\text{管内径}\times\text{总阻力损失}}}\right)$ |  |

例 1-21：$H=5$ m → $\sum h_f=49.1$ J/kg，代入得 $u=1.84$ m/s、$Re=1.51\times10^5$、$q_V=9.72\times10^{-3}$ m³/s=35 m³/h，与例 1-19 互为反算。

### 第三类：1-61~1-63 与例 1-22（`#L2552-#L2616`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d=\lambda^{1/5}\left(\dfrac{8lq_V^2}{\pi^2\sum h_f}\right)^{1/5}=\lambda^{1/5}K^{1/5}$ | （1-61） |
| **文字式** | $\text{管内径}_{\text{【m】}}=\text{摩擦系数}^{1/5}\times\left(\dfrac{8\times\text{管长}\times\text{流量}^2}{\pi^2\times\text{总阻力损失}}\right)^{1/5}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K=\dfrac{8lq_V^2}{\pi^2\sum h_f}$ | （1-62） |
| **文字式** | $\text{管径常数}_{\text{【m⁵】}}=\dfrac{8\times\text{管长}\times\text{流量}_{\text{【m³/s】}}^2}{\pi^2\times\text{总阻力损失}_{\text{【J/kg】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re=\dfrac{4\rho q_V}{\pi\mu d}$ | （1-63） |
| **文字式** | $\text{雷诺数}=\dfrac{4\times\text{密度}\times\text{流量}}{\pi\times\text{黏度}\times\text{管内径}}$ |  |

例 1-22：$H=5$ m → $K=215\times10^{-6}$ m⁵、$K^{1/5}=0.815$ m；先设 $\lambda=0.03$ → $d=0.0917$ m → $Re=1.35\times10^5$、$\varepsilon/d=0.0109$ → 重算 $\lambda=0.0388$ → $d=0.0966$ m，迭代收敛。

**第三类的特点**：$d$ 同时出现在 $Re$、$\varepsilon/d$、1-61 三处，必须试差；收敛判据是两次 $d$ 接近。

## 最适宜管径（`#L2618-#L2651`）

$q_V$ 一定时：$d$ 增大 → $u$ 减小 → 阻力与泵功率下降，但设备费上升。**最适宜管径=设备费与动力费之和最小处**（图 1-36）。

工程上按经验流速选管径，表 1-3 常用范围：

| 流体 | $u$/(m/s) |
|:---|:---|
| 自来水（0.3 MPa 左右） | 1~1.5 |
| 水及低黏液体（0.1~1.0 MPa） | 1.5~3.0 |
| 高黏液体 | 0.5~1.0 |
| 工业供水、锅炉供水 | 1.5~3.0 / >3.0 |
| 饱和蒸汽 | 20~40；过热蒸汽 30~50 |
| 低压空气 / 高压空气 | 12~15 / 15~25 |
| 一般气体（常压） | 10~20；真空 <10 |

## 判断

- 三类问题的差别不在公式，而在"未知量是否同时出现在 λ 里"：只有第三类必然试差，第一、二类可直算。
- 表 1-3 是经验值，选完后仍要用 1-59 复核阻力与泵功率，不能只凭流速定案。

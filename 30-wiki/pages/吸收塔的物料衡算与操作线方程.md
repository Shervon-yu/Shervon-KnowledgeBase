# 吸收塔的物料衡算与操作线方程

## 为什么用摩尔比（`#L9666`）

塔内惰性气体流量 $G$ 与吸收剂流量 $L$ 沿塔高基本不变（惰性组分不被吸收、溶剂不挥发），所以按"每 kmol 惰性气体/每 kmol 溶剂"计量的摩尔比 $Y$、$X$ 最方便——它们与 $G$、$L$ 一起构成常数。

## 塔顶与塔底的命名（`#L9668`）

逆流塔塔顶气、液组成都低 → 称**稀端**；塔底组成高 → 称**浓端**。

## 操作线方程（`#L9670-#L9692`）

在塔内任取截面 O-O，对塔顶至该截面作溶质衡算：$LX+GY_2=LX_2+GY$，整理得

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{L}{G}=\dfrac{Y-Y_2}{X-X_2}$ | （5-51） |
| **文字式** | $\text{液气比}=\dfrac{\text{该截面气相组成}-\text{塔顶气相组成}}{\text{该截面液相组成}-\text{塔顶液相组成}}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Y=\dfrac{L}{G}X+\left(Y_2-\dfrac{L}{G}X_2\right)$ | （5-52） |
| **文字式** | $\text{气相组成}=\text{液气比}\times\text{液相组成}+(\text{塔顶气相组成}-\text{液气比}\times\text{塔顶液相组成})$ |  |

稳定操作时 $L$、$G$、$X_2$、$Y_2$ 均定值 ⇒ 操作线是**直线**，斜率 $L/G$（液气比），截距 $Y_2-(L/G)X_2$。

## 全塔衡算（`#L9694-#L9698`）

把 $X$、$Y$ 换成塔底的 $X_1$、$Y_1$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{L}{G}=\dfrac{Y_1-Y_2}{X_1-X_2}$ | （5-53） |
| **文字式** | $\text{液气比}=\dfrac{\text{塔底与塔顶气相组成差}}{\text{塔底与塔顶液相组成差}}$ |  |

图5-18 上操作线通过 $T(X_2,Y_2)$（塔顶）与 $B(X_1,Y_1)$（塔底）两点，线上任一点代表塔内某一截面的气液组成。

## 操作线与平衡线的关系（`#L9704-#L9706`）

吸收中气相 $Y$ 总大于与其接触液相的平衡值 $Y^{*}$，故**操作线在平衡线上方**。两线之间的：

- 垂直距离 $Y-Y^{*}$：气相总推动力；
- 水平距离 $X^{*}-X$：液相总推动力。

两线越远，推动力越大，达到同样分离所需填料层越矮。这条几何关系是全章计算的主线。

## 判断

- 操作线只由物料衡算决定，与传质速率无关——所以它先于填料高度计算而确定。平衡线由热力学决定，两者一叠加，推动力沿塔高的分布就定了。
- 液气比 $L/G$ 是唯一可自由调的斜率：调大 → 操作线远离平衡线 → 推动力大、塔矮，但吸收剂用量与再生费用高；调小则相反。

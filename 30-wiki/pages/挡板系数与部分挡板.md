# 挡板系数与部分挡板

## 定义

全挡板条件可以用"挡板系数" $K_b$ 定量判定（`#L1526-#L1532`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{W_{b}}{D}\right)^{1.2}n_{b}=K_{b}=0.35$ | （2-27） |
| **文字式** | $\left(\dfrac{\text{挡板宽}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}\right)^{1.2}\times\text{挡板块数}=K_{b}=0.35$ |  |

- $K_b=0.35$：**全挡板条件**，功率达到最大值，再加挡板功耗不再增；
- $0<K_b<0.35$：**部分挡板条件**，功率介于无挡板与全挡板之间；
- $K_b=0.06\sim0.12$：可使混合能耗最小（`#L1532`）。

## 部分挡板的功率插值

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{N_{p\max}-N_{p}}{N_{p\max}-N_{p\infty}}=\left[1-2.9\left(\dfrac{W_{b}}{D}\right)^{1/2}n_{b}\right]^{2}$ | （2-29） |
| **文字式** | $\dfrac{\text{全挡板功率准数}-\text{实际功率准数}}{\text{全挡板功率准数}-\text{无挡板功率准数}}=\left[1-2.9\times\left(\dfrac{\text{挡板宽}}{\text{釜内径}}\right)^{1/2}\times\text{挡板块数}\right]^{2}$ |  |

## 圆管当挡板的折算

釜式反应器常用直立内冷管，兼作挡板。计算时把圆管外径乘校正系数 $K_r$ 作为有效挡板宽度（`#L1556`）。表2-5（`#L1558-#L1562`）：

| $\Delta C/D$ | 0 | 0.025 | 0.050 | 0.075 | 0.10 | 0.131 |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| $K_r$ | 0.78 | 0.70 | 0.57 | 0.48 | 0.50 | 0.63 |

$\Delta C$ 是挡板与釜壁的间隙。间隙为零时 $K_r=0.78$，即圆管的挡板效果比等宽平板弱约两成。

## 用法与坑

- 先算 $K_b$ 判是否全挡板；未到 0.35 就用式（2-29）插值，不要直接取 $N_{p\max}$。
- 同一釜内既有挡板又有内冷管时，把冷管按 $K_r$ 折算后并入 $n_b$ 与 $W_b$ 再算。
- 能耗最小的 $K_b=0.06\sim0.12$ 与全挡板 $K_b=0.35$ 是两个不同的设计目标：前者省能、后者保证流型；选择取决于更在意混合效果还是能耗（`#L1532`）。
- 定性结论与参数范围见 [[挡板与全挡板条件]]；带挡板后的功率变化也可从 [[Rushton功率曲线]] 有/无挡板两条曲线的差别看出。

# 几何相似放大与转速关系

## 前提

几何相似要求大、小釜所有对应线性尺寸成比例。大釜体积确定后，$D$、$H$、$d$、$b$、安装位置、挡板尺寸随之确定，**放大的问题就归结为确定转速**（`#L3929`）。

## 转速关系

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{L}=N_{s}\left(\dfrac{D_{s}}{D_{L}}\right)^{X}$ | （4-5） |
| **文字式** | $\text{大釜转速}_{\text{【1/s】}}=\text{小釜转速}_{\text{【1/s】}}\times\left(\dfrac{\text{小釜内径}_{\text{【m】}}}{\text{大釜内径}_{\text{【m】}}}\right)^{\text{放大指数}}$ |  |

$X$ 一般在 $2/3\sim1$ 之间，按过程类别选取（`#L3935`）。

## X 的物理含义

| $X$ | 保持恒定的量 | 判据 |
|:---:|:---|:---|
| 1 | 叶端线速度 $Nd$、或单位体积扭矩 | 剪切主导 |
| 2/3 | 单位体积功率 $P_V$ | 湍流混合主导（最常用） |
| 0 | 混合时间 $\theta_M$（湍流） | 循环/均匀性主导 |

（`#L3941-#L3945`）

## 单位体积功率关系

|  |  |  |
|:---|:---:|---:|
| **符号式** | $(P_{V})_{L}=(P_{V})_{s}\left(\dfrac{D_{s}}{D_{L}}\right)^{Y}$ | （4-6） |
| **文字式** | $\text{大釜单位体积功率}_{\text{【W/m³】}}=\text{小釜单位体积功率}_{\text{【W/m³】}}\times\left(\dfrac{\text{小釜内径}_{\text{【m】}}}{\text{大釜内径}_{\text{【m】}}}\right)^{\text{功率放大指数}}$ |  |

$Y$ 与 $X$ 不独立：湍流下 $P_V\propto N^3d^2$，若 $N\propto D^{-X}$ 且 $d\propto D$，则 $P_V\propto D^{-3X+2}$，即 $Y=3X-2$。

## 用表

- $X=2/3$（$P_V$ 恒定）时，$d$ 放大 $\gamma$ 倍，$N$ 变为 $\gamma^{-2/3}$，$P$ 变为 $\gamma^{3}\cdot\gamma^{-2}=\gamma$（单位体积功率不变，总功率按体积增长）；
- $X=1$（$Nd$ 恒定）时，$N$ 变为 $\gamma^{-1}$，$P_V$ 变为 $\gamma^{-1}$ —— 越大越"温柔"，易出现混合不足。

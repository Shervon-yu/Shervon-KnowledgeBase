# 锚式框式搅拌器功率

## 等效替代

锚式可看作"直径相同、叶宽等于锚高"的平桨式搅拌器，因此可用平桨的功率关联式估算（`#L1622`）。这是所有锚式算法的基础近似。

## 北京化工大学关联式（层流到过渡流都适用）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}^{*}=\dfrac{27\left(\dfrac{D}{c}\right)^{0.405}}{Re}+0.217\,\alpha\left(\dfrac{D}{d}\right)^{2.21}\left(\dfrac{Re^{0.171}}{Re^{0.171}+0.275}\right)^{11.27(D/d)-12.93}$ | （2-34） |
| **文字式** | $\text{修正功率准数}=\dfrac{27\left(\dfrac{\text{釜内径}}{\text{间隙}}\right)^{0.405}}{\text{雷诺数}}+0.217\,\alpha\left(\dfrac{\text{釜内径}}{\text{叶轮直径}}\right)^{2.21}\left(\dfrac{\text{雷诺数}^{0.171}}{\text{雷诺数}^{0.171}+0.275}\right)^{11.27\times\frac{\text{釜内径}}{\text{叶轮直径}}-12.93}$ |  |

式中 $N_p^{*}=N_p/(L/d)$ 为修正功率准数，$L$ 是锚的有效边缘总长（两垂直边长与底边长之和），$c$ 是锚与釜壁间隙，$\alpha$ 为系数（`#L1643-#L1649`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha=\dfrac{1.15(d/D)}{1+0.00025Re^{0.87}}$ | （2-34 参数 α） |
| **文字式** | $\alpha=\dfrac{1.15\times\text{叶轮直径}/\text{釜内径}}{1+0.00025\times\text{雷诺数}^{0.87}}$ |  |

适用范围 $d/D=0.78\sim0.94$，叶片断面为 HG 标准等边角钢（`#L1651`）。简化：$Re<30$ 第二项很小可略；$Re=30\sim500$ 时 $\alpha\approx1$；$Re>1000$ 时 $c$ 几乎无影响；圆形/板形断面 $N_p^{*}$ 低 5%~10%（$Re<200$）；水平或垂直拉杆不影响总功率（`#L1653`）。

## 王凯、王嘉骏关联式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re^{*}\cdot N_{\mathrm{p}}=109\left(\dfrac{d}{c}\right)^{0.317}\left(\dfrac{w}{d}\right)^{0.1}\left(\dfrac{L}{d}\right)^{0.705}$ | （2-35） |
| **文字式** | $\text{表观雷诺数}\times\text{功率准数}=109\times\left(\dfrac{\text{叶轮直径}}{\text{间隙}}\right)^{0.317}\times\left(\dfrac{\text{桨宽}}{\text{叶轮直径}}\right)^{0.1}\times\left(\dfrac{\text{有效边缘长}}{\text{叶轮直径}}\right)^{0.705}$ |  |

预测平均标准偏差 5.47%，适用 $d/D=0.683\sim0.99$、$w/d=0.062\sim0.16$、$L/d=0.5\sim1.33$（`#L1655`）。式中 $Re^{*}$ 是表观雷诺数，按式（2-44）计算（`#L1659`）。

## 框式与偏框式

王嘉骏等对 2 种框式、5 种偏框式实测回归（`#L1693-#L1697`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}\cdot Re^{*}=255.36\left(\dfrac{d}{D}\right)^{3.63}\left(\dfrac{d_{f}}{d}\right)^{0.72}\left(\dfrac{w}{d}\right)^{-0.139}\left(\dfrac{L}{d}\right)$ | （2-39） |
| **文字式** | $\text{功率准数}\times\text{表观雷诺数}=255.36\left(\dfrac{\text{叶轮直径}}{\text{釜内径}}\right)^{3.63}\left(\dfrac{\text{框高}}{\text{叶轮直径}}\right)^{0.72}\left(\dfrac{\text{桨宽}}{\text{叶轮直径}}\right)^{-0.139}\left(\dfrac{\text{有效边缘长}}{\text{叶轮直径}}\right)$ |  |

平均标准偏差 2.59%，也可用于锚式的功率估算（`#L1697`）。

## 层流功率常数 $K_p$

层流区 $N_p\cdot Re=K_p$ 为常数，可直接查表2-7（`#L1731-#L1746`）：锚（$d/D=0.87$、$h/D=0.6$、$w/D=0.1$）$K_p=245$；锚（$d/D=0.89$）$K_s=21.5$；双螺带-锚（$d/D=0.95$）$K_p=424$；四螺带-锚 478；内外单螺带-锚 307。

## 坑

- 式（2-34）用的是 $N_p^{*}$，算完必须乘回 $L/d$ 才是 $N_p$；漏乘会低估一个量级。
- 框式式（2-39）与锚式式（2-35）的雷诺数口径不同（一个用 $Re^{*}$、一个也是 $Re^{*}$），但拟合样本不同，外推要谨慎。

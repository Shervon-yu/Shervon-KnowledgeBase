# 悬臂搅拌轴的支承条件与中间轴承取舍

## 优先做悬臂

一般情况搅拌轴应尽量设计成**悬臂式**：便于安装维护、减少介质腐蚀（`#L12180`）。只有悬臂过长且较细、会被扭弯、离心力递增甚至损坏轴时，才考虑加中间轴承/底轴承（`#L12182`）。

## 悬臂支承条件的粗算判据（式9-69）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left.\begin{array}{l}\dfrac{L_{1}}{a}\le 4\sim5\\[6pt]\dfrac{L_{1}}{d}\le 40\sim50\end{array}\right\}$ | （9-69） |
| **文字式** | $\left.\begin{array}{l}\dfrac{\text{第一层搅拌器悬臂长度}_{\text{【mm】}}}{\text{轴两支点间距}_{\text{【mm】}}}\le 4\sim5\\[6pt]\dfrac{\text{第一层搅拌器悬臂长度}_{\text{【mm】}}}{\text{搅拌轴直径}_{\text{【mm】}}}\le 40\sim50\end{array}\right\}$ |  |

- $L_{1}$ 为第一层搅拌器的悬臂长度（自下支点算起），$a$ 为两支承间距离，$d$ 为轴径（`#L12186-#L12190`）。
- **放宽条件**：$d$ 裕量大、搅拌器做过平衡试验、转速低时，$L_{1}/a$ 与 $L_{1}/d$ 可取大值；反之取小值（`#L12192`）。
- **调整顺序**：先调 $L_{1}$、$d$、$a$（缩短悬臂、加粗轴、加大支距）；调不动或运转时径向摆动量超过轴封允许值，才装中间轴承或底轴承（`#L12194`）。

## 轴封处允许的径向摆动量（`#L12198-#L12200`）

| 轴封型式 | 允许摆动量/mm |
|:---|:---|
| 填料箱密封 | 0.08~0.13 |
| 机械密封 | 0.04~0.08 |

机械密封的要求比填料密封严一倍左右——这是机械密封轴系容易振动的根本原因（见 [[轴封处径向位移的验算]]）。

## 中间轴承的代价（`#L12204`）

中间轴承通常装在轴封下方或轴中部，位置取决于轴的稳定性与安装检修方便。**浸没在介质中时有四重代价**：

1. 轴承与器壁固定的**拉杆起横挡板作用**，增加搅拌功率消耗；
2. 强化液体分子间的剪切；
3. 必须考虑介质**腐蚀**与**磨损**；
4. 磨损性颗粒会进入轴承，造成磨损、堵住甚至咬死（`#L12317`）。

**结论**：能不用就不用（`#L12204`、`#L12317`）。

## 底轴承与中间轴承共同的负面效应（`#L12317`）

- 改变支承条件、减小挠度的收益，被**结构复杂化、安装检修困难**抵消；
- **多支点对中困难**，装不好产生偏心，反而加剧轴承磨损与振动；
- 釜内轴承靠容器内液体润滑，含固体颗粒时寿命骤降。

因此设计顺序永远是：**先改悬臂长/轴径/支距**（第九章第九节的减挠四措施），最后才加支点（见 [[搅拌轴的支点类型与减挠措施]]）。

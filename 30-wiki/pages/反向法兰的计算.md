# 反向法兰的计算

反向法兰（图 9-9）把法兰环放在筒体端部内侧，螺栓从内往外穿、垫片反压在环上。适用条件是 $K_r\le2$（`#L9270`）。除 9.6.2 单列的符号外，其余全部沿用 9.3；垫片设计按 9.5.1、螺栓设计按 9.5.2，只把**力矩与应力**换成下面这套。

$K_r$：反向整体法兰取 $D_o/D_f$，反向松式法兰取 $D_i/D_f$——分母都是法兰环内直径。

## 一、力臂与力矩（9.6.3，`#L9338-#L9364`）

预紧力矩仍按式 9-11，只是垫片力臂换算式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $L_G=\dfrac{D_b-D_G}{2}$ | （9-26） |
| **文字式** | $\text{垫片力臂}=\dfrac{\text{螺栓中心圆直径}-\text{垫片压紧力作用中心圆直径}}{2}$ |  |

三个力按 9.5 的老公式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_D=\dfrac{\pi}{4}D_i^2p_c$；$\quad F_G=F_p=2b\pi D_Gmp_c$；$\quad F_T=\dfrac{\pi}{4}\left(D_i^2-D_G^2\right)p_c$ |  |
| **文字式** | $\text{孔盖区轴向力}=\dfrac{\pi}{4}\times\text{内直径}^2\times\text{计算压力}$；$\quad\text{垫片压紧力}=2\times\text{垫片有效宽度}\times\pi\times\text{垫片中心圆直径}\times\text{垫片比压力}\times\text{计算压力}$；$\quad\text{环形区轴向力}=\dfrac{\pi}{4}\times(\text{内直径}^2-\text{垫片中心圆直径}^2)\times\text{计算压力}$ |  |

操作力矩**取绝对值、垫片项为负**，这是反向法兰与 9.5 最大的分歧：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_p=\left|F_DL_D+F_TL_T-F_GL_G\right|$ | （9-27） |
| **文字式** | $\text{操作力矩}=\left|\text{孔盖区作用力}\times\text{力臂}+\text{环形区作用力}\times\text{力臂}-\text{垫片压紧力}\times\text{垫片力臂}\right|$ |  |

$L_D$：反向整体法兰 $(D_o-D_b-\delta_1)/2$，反向松式法兰 $(D_i-D_b)/2$；$L_T=\left(D_b-\dfrac{D_i+D_G}{2}\right)/2$。**$L_T$ 允许为负**——负值表示 $F_T$ 的作用圆比螺栓中心圆还大，此时 $F_TL_T$ 项反向（`#L9360`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_o=\max\left\{M_p,\ M_a\dfrac{[\sigma]_f^t}{[\sigma]_f}\right\}$ | （9-28） |
| **文字式** | $\text{设计力矩}=\max\left\{\text{操作力矩},\ \text{预紧力矩}\times\dfrac{\text{设计温度许用应力}}{\text{室温许用应力}}\right\}$ |  |

## 二、反向整体法兰的应力（9.6.4.1，`#L9368-#L9412`）

先把整套法兰系数"改造"成带下标 r 的版本：$h_{or}=\sqrt{D_o\delta_0}$ 代替 $h_o$，$K_r$ 代替 $K$。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{or}=\sqrt{D_o\delta_0}$；$\quad e_r=\dfrac{F_r}{h_{or}}$；$\quad \psi_r=\left[1+\dfrac{0.668(K_r+1)}{Y}\right]\dfrac{1}{K_r^2}$ |  |
| **文字式** | $\text{参数}h_{or}=\sqrt{\text{筒体外直径}\times\text{筒体厚度}}$；$\quad\text{参数}e_r=\dfrac{\text{系数}F_r}{\text{参数}h_{or}}$；$\quad\text{系数}\psi_r=\left[1+\dfrac{0.668\times(\text{系数}K_r+1)}{\text{系数}Y}\right]\times\dfrac{1}{\text{系数}K_r^2}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $U_r=\psi_rU$；$\quad d_r=\dfrac{U_rh_{or}\delta_0^2}{V_r}$；$\quad T_r=\left(\dfrac{Z+0.3}{Z-0.3}\right)\psi_rT$ |  |
| **文字式** | $\text{系数}U_r=\text{系数}\psi_r\times\text{系数}U$；$\quad\text{参数}d_r=\dfrac{\text{系数}U_r\times\text{参数}h_{or}\times\text{筒体厚度}^2}{\text{系数}V_r}$；$\quad\text{系数}T_r=\left(\dfrac{\text{系数}Z+0.3}{\text{系数}Z-0.3}\right)\times\text{系数}\psi_r\times\text{系数}T$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda_r=\dfrac{\delta_fe_r+1}{T_r}+\dfrac{\delta_f^3}{d_r}$ |  |
| **文字式** | $\text{力矩系数}\lambda_r=\dfrac{\text{法兰厚度}\times\text{参数}e_r+1}{\text{系数}T_r}+\dfrac{\text{法兰厚度}^3}{\text{参数}d_r}$ |  |

三个应力：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{Hr}=\dfrac{f_rM_o}{\lambda_r\delta_1^2D_f}$ | （9-29） |
| **文字式** | $\text{颈部轴向应力}=\dfrac{\text{系数}f_r\times\text{设计力矩}}{\text{力矩系数}\lambda_r\times\text{颈部厚度}^2\times\text{法兰环内直径}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{Rr}=\dfrac{(1.33\delta_fe_r+1)M_o}{\lambda_r\delta_f^2D_f}$ | （9-30） |
| **文字式** | $\text{外径处径向应力}=\dfrac{(1.33\times\text{法兰厚度}\times\text{参数}e_r+1)\times\text{设计力矩}}{\text{力矩系数}\lambda_r\times\text{法兰厚度}^2\times\text{法兰环内直径}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{Tr}=\dfrac{Y_rM_o}{\delta_f^2D_f}-Z\sigma_{Rr}\dfrac{0.67\delta_fe_r+1}{1.33\delta_fe_r+1}$；$\quad Y_r=\psi_rY$ | （9-31） |
| **文字式** | $\text{外径处环向应力}=\dfrac{\text{系数}Y_r\times\text{设计力矩}}{\text{法兰厚度}^2\times\text{法兰环内直径}}-\text{系数}Z\times\text{外径处径向应力}\times\dfrac{0.67\times\text{法兰厚度}\times\text{参数}e_r+1}{1.33\times\text{法兰厚度}\times\text{参数}e_r+1}$ |  |

反向整体法兰**多算一项**内径处环向应力（普通法兰没有）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{Tr}'=\dfrac{M_o}{\delta_f^2D_f}\left[Y-\dfrac{2K_r^2\left(\dfrac{2\delta_fe_r}{3}+1\right)}{\left(K_r^2-1\right)\lambda_r}\right]$ | （9-32） |
| **文字式** | $\text{内径处环向应力}=\dfrac{\text{设计力矩}}{\text{法兰厚度}^2\times\text{法兰环内直径}}\times\left[\text{系数}Y-\dfrac{2\times\text{系数}K_r^2\times\left(\dfrac{2\times\text{法兰厚度}\times\text{参数}e_r}{3}+1\right)}{(\text{系数}K_r^2-1)\times\text{力矩系数}\lambda_r}\right]$ |  |

系数取法：$F_r$、$V_r$、$f_r$ 都是用 $h_{or}$ 代替 $h_o$ 后查图 9-3、9-4、9-7（或表 9-7/9-8）；$f_r<1$ 时**取 1**（`#L9396`）；$T$、$U$、$Y$、$Z$ 用 $K_r$ 代替 $K$ 查图 9-8（或按图注公式算、或表 9-9）。

## 三、反向松式法兰的应力（9.6.4.2，`#L9416-#L9424`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{Hr}=0$；$\quad\sigma_{Rr}=0$；$\quad\sigma_{Tr}=\dfrac{YM_o}{\delta_f^2D_f}$ | （9-33） |
| **文字式** | 松式法兰无颈部约束，轴向应力与径向应力为 0，只剩环向应力 |  |

## 四、校核（9.6.5、9.6.6）

$\sigma_{Hr}$、$\sigma_{Rr}$、$\sigma_{Tr}$ 分别按 9.5.3.4 对 $\sigma_H$、$\sigma_R$、$\sigma_T$ 的规定；**另外** $\sigma_{Tr}'\le[\sigma]_t$（`#L9428`，$[\sigma]_t$ 的定义见 9.3 符号表）。刚度校核按 9.5.3.5，用 $h_{or}$ 与 $\lambda_r$ 代替式 9-23 的 $h_o$、$\lambda$，用 $K_r$ 代替式 9-24 的 $K$（`#L9432`）。

## 判断

- 反向法兰不是"另一种法兰"，而是**同一套法兰方法的坐标反演**：力臂改符号（$L_D$ 从外径量起），垫片力反向（9-27 里 $F_G$ 取负），$K$ 换成 $K_r$，其余 $F$、$V$、$f$、$T$、$U$、$Y$、$Z$ 全部沿用。所以标准把 9.5.1/9.5.2/9.5.3.5 直接引用过来，只重写力矩与应力。
- $M_p$ 取**绝对值**是必须的：$L_T$ 可能为负，$F_TL_T$ 与 $F_DL_D$ 可能相互抵消，力矩的符号只表示方向，不影响厚度选择。
- 内径处环向应力 $\sigma_{Tr}'$ 是反向法兰独有的危险点：法兰环内侧被垫片和筒体夹着，环向受拉，而普通法兰内径处被筒体壁"撑住"，没有这一项。
- 松式法兰的 $\sigma_{Hr}=\sigma_{Rr}=0$ 不是忽略，是结构上没有传弯路径：松式法兰不约束筒体，弯不到颈部。
- $K_r\le2$ 与 $f_r\ge1$ 两道夹子同一个目的——把计算限制在图表覆盖并验证过的几何与刚度范围内；$K_r$ 更大时法兰环过薄，图表曲线不再适用，标准不给外推。

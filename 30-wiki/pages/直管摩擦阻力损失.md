# 直管摩擦阻力损失

## 阻力损失的含义（`#L1962-#L1976`）

1 kg 流体经等直径水平直管，能量衡算（1-32）中 $z$、$u$ 均不变，只剩静压能与损失：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_f=\dfrac{p_1-p_2}{\rho}=\dfrac{\Delta p_f}{\rho}$ | （1-43） |
| **文字式** | $\text{直管阻力损失}_{\text{【J/kg】}}=\dfrac{\text{两截面压力差}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}}$ |  |

注意：**垂直管也有同样阻力，但垂直时静压差还包含位能**，只有水平管才满足 $h_f=\Delta p/\rho$。

## 范宁（Fanning）公式（`#L1980-#L1990`）

均匀直管阻力与管长成正比、与动能 $u^2/2$ 成正比、与管径成反比，比例系数即摩擦系数 $\lambda$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_f=\lambda\dfrac{l}{d}\dfrac{u^2}{2}$ | （1-44） |
| **文字式** | $\text{直管阻力损失}_{\text{【J/kg】}}=\text{摩擦系数}\times\dfrac{\text{管长}_{\text{【m】}}}{\text{管内径}_{\text{【m】}}}\times\dfrac{\text{流速}_{\text{【m/s】}}^2}{2}$ |  |

$\lambda$ 无量纲，是**流型与管壁粗糙度的函数**：层流时只与 $Re$ 有关，湍流时与 $Re$、$\varepsilon/d$ 都有关。1-44 对层流湍流都成立，区别只在 $\lambda$ 的算法。

## 层流：λ=64/Re（`#L1994-#L2004`）

把层流的哈根-泊谡叶方程（1-41）$\Delta p=32\mu lu/d^2$ 代入 1-43、1-44 联立：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\dfrac{64}{Re}$ | （1-45） |
| **文字式** | $\text{摩擦系数}=\dfrac{64}{\text{雷诺数}}$ |  |

- 该式由理论推导得到，与实验**完全相符**；
- 层流 $h_f\propto u$ 的一次方；
- 湍流也用 1-44，仅 $\lambda$ 换成 1-50~1-53 的关联式。

## 例 1-15：乌氏黏度计（`#L2010-#L2040`）

毛细管 $d=1$ mm、液体密度 1040 kg/m³、体积 4.0 cm³、流完用 120 s、$\Delta p=\rho g h$：

- $\mu=\dfrac{\pi \rho g d^4 t}{128V}=7.51\times10^{-3}$ Pa·s $=7.51$ cP；
- 校核：$u=\dfrac{4V}{\pi d^2 t}=0.0425$ m/s，$Re=\dfrac{du\rho}{\mu}=5.88<2000$，层流假设成立。

**先假设层流→用 1-45 求 μ→再用 Re 校核**，这个"假设—求解—校核"的顺序是黏度计测定的标准套路。

## 判断

- 层流 $\lambda\propto1/Re$、$h_f\propto u$；完全湍流 $\lambda$ 与 $Re$ 无关、$h_f\propto u^2$。两种极限之间是过渡区，工程上常按湍流保守取。
- 1-43 的 $h_f=\Delta p/\rho$ 只在水平管成立，这是最常见的误用点。

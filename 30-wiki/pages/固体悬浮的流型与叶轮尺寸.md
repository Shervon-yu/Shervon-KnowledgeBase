# 固体悬浮的流型与叶轮尺寸

## 两个判据，别混

液体里固体颗粒的悬浮状态一般**不均匀**（`#L6746`），因此要分开看两件事：

1. **临界搅拌速度 $N_f$**：所有颗粒都离开底部（全部流化）的最小转速；
2. **局部浓度的均匀性**：流化之后各点浓度是否一致。

White 和 Sumerford 在无挡板桨式釜中测水中沙子，**不同取样位置的浓度差高达 20 倍**（`#L6748`）——所以"看到颗粒都在动"完全不代表混合均匀。

## 混合指数 MI

Hixson 等在 4 叶斜叶涡轮、$D=18$ cm 无挡板釜中提出（`#L6750`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\mathrm{MI}=\dfrac{100-L}{100-L_0}\times100$ | （6.1） |
| **文字式** | $\text{混合指数}=\dfrac{100-\text{样品中水的质量分数}}{100-\text{全釜平均水的质量分数}}\times100$ |  |

沙过量时把"水"换成"沙"：$\mathrm{MI}=\dfrac{100-s}{100-s_0}\times100$（6.1'）。

判据与两个反直觉结论（`#L6762`）：

- **MI 达到 90% 后，再提高转速不再改变 MI**——强化搅拌有饱和点；
- **同一转速下增大液体黏度，MI 反而增大**：黏度高使颗粒沉降被抑制，分布更均匀。

Hirsekorn 等把固悬研究推到 $5\times10^{4}$ cP 的高黏体系，在 $Re\approx10$ 的三个几何相似釜（$D=6,12,18$ in）中建议：**以单位容积功率 $P/V$ 作为固悬的放大判据**（`#L6766`）。

## 两种流化流型

见图6.1（`#L6770`、`#L6772`）：

| 流型 | 判据 | 特征 | 何时 $N_f$ 更小 |
|:---|:---|:---|:---|
| 型1 | $C>3$（叶轮高于液高的 30%） | 颗粒被卷到上部再沉降 | 固体**密度小**时 |
| 型2 | $C<1$（叶轮近底） | 底部扫掠为主 | 固体**密度大、粒径小**时 |

即"叶轮放高还是放低"要按颗粒的密度与粒径来选，没有通用答案。

## 最佳叶轮直径

叶轮太小 → 中央不积料但**器壁残留**；太大 → 器壁干净但**底部中央积料**（`#L6776`）。最佳直径是"同一转速下中央与器壁同时流化"的那个尺寸：图6.2 中实线为边缘流化速度 $sN_f$、虚线为中心流化速度 $cN_f$，**两线交点即 $d_{\text{最佳}}$**。

$d_{\text{最佳}}$ 随叶宽、叶片角、叶片数与颗粒密度稍有变化，**与叶轮高度和液面高度无关**；最显著的影响因素是**容器底形状**（`#L6776`、`#L6792`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | 平底：$d_{\text{最佳}}=0.45\sim0.5D$；碟底：$0.4D$；球底：$0.35D$ | （6.2）（6.3）（6.4） |
| **文字式** | $\text{最佳叶轮直径}=0.35\sim0.5\times\text{容器直径}$，底越尖取越小 |  |

叶宽标准（`#L6800`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $b=0.1\sim0.2D$ | （6.5） |
| **文字式** | $\text{双叶桨叶宽}=0.1\sim0.2\times\text{容器直径}$ |  |

## 其他几何约束（经验条目）

- Rushton 标准涡轮（`#L6846`）：$d=D/2$、$b=D/5$、$l=D/4$、$n_p=6$、$H=D$、$C=H/6\sim H/3$、$B_w=0.1D$、$n_B=4$。美国叶宽偏窄、德国偏宽（`#L6802`）。
- 黏度升高，叶径与叶宽都要加大：Hirsekorn 在 3800~9200 cP 液体中建议 $d>0.6D$（`#L6802`）。
- $H/D>1.0$ 一般得不到均匀悬浮，**建议 $H<D$**（`#L6804`）。
- 叶轮高度取距底液高的 $1/6$（Rushton，`#L6806`）。
- 均匀悬浮**建议用挡板**；但大而重的颗粒会堆在**挡板后的死角**里（`#L6808`）。

## 专门的悬浮结构

图6.5 三种设计（`#L6810`、`#L6834`）：

1. **碟形底圆筒**：把圆周流引导向上；
2. **底部小挡板**（把圆周流变向上流的"底挡板"）：对**最低浮游速度**有效，但不保证全釜均匀。参数：

|  |  |  |
|:---|:---:|---|
| **符号式** | $(\varepsilon_B)_{\text{最佳}}=d/2$，$\qquad B_w\times B_H=0.1D\times0.05D$（4 块） | （6.6）（6.7） |
| **文字式** | 底挡板外沿半径 $=\text{叶轮半径}$；挡板宽 $\times$ 高 $=0.1D\times0.05D$ |  |

3. **导流筒推进式**：能获得轴向流，但**叶轮端与导流筒的间隙里会卡颗粒，磨损严重**。作者的替代方案是**往复叶轮**——带锥形边缘、底部穿孔的圆盘在导流筒里上下运动（图6.5c）。间隙不必像推进式那样小，**低功率就能把颗粒悬浮起来**（`#L6848`）。这是本书少见地给出"换机构而不是加功率"的思路。

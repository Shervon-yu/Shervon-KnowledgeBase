# 离心泵的最大安装高度

## 临界条件（`#L3777-#L3787`）

把 $\Delta h_a=\Delta h_r$ 代入 2-12，得临界安装高度：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H_{g\max}=\dfrac{p_0}{\rho g}-\dfrac{p_v}{\rho g}-\Delta h_r-\sum H_f$ | （2-15） |
| **文字式** | $\text{最大安装高度}_{\text{【m】}}=\dfrac{\text{槽面绝对压力}}{\text{密度}\times\text{重力加速度}}-\dfrac{\text{饱和蒸气压}}{\text{密度}\times\text{重力加速度}}-\text{必需汽蚀余量}_{\text{【m】}}-\text{吸入管压头损失}_{\text{【m】}}$ |  |

## 工程式（`#L3791-#L3799`）

用允许汽蚀余量 $\Delta h=\Delta h_r+0.3$ 替换：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H_{g\text{允许}}=\dfrac{p_0}{\rho g}-\dfrac{p_v}{\rho g}-\Delta h-\sum H_f$ | （2-16） |
| **文字式** | $\text{最大允许安装高度}_{\text{【m】}}=\dfrac{\text{槽面绝对压力}}{\text{密度}\times\text{重力加速度}}-\dfrac{\text{饱和蒸气压}}{\text{密度}\times\text{重力加速度}}-\text{允许汽蚀余量}_{\text{【m】}}-\text{吸入管压头损失}_{\text{【m】}}$ |  |

符号口径：
- $p_0$：贮槽液面上方**绝对压力**（敞口槽即当地大气压）；
- $p_v$：液体在工作温度下的饱和蒸气压；
- $\Delta h$：泵样本给的允许汽蚀余量，m 液柱；
- $\sum H_f$：**吸入管路**压头损失，m 液柱。

要求：实际安装高度 $H_g<H_{g\text{允许}}$。

## 例2-4（`#L3805-#L3815`）

敞口水槽、40 ℃ 清水，$\Delta h=2$ m、吸入损失 1 m、$p_0=100$ kPa、$p_v=7.377$ kPa、$\rho=992.2$ kg/m³：

$$H_{g\text{允许}}=\frac{(100-7.377)\times10^3}{992.2\times9.81}-2-1=6.51\ \text{m}$$

实际 4 m < 6.51 m → 合适。

## 例2-5（`#L3817-#L3833`）

塔釜液体**处于沸腾状态** → 液面压力即饱和蒸气压，$p_0=p_v$，第一项为零：

$$H_{g\text{允许}}=-2.0-0.6=-2.6\ \text{m}$$

实际装在液面下 2.0 m（即 $H_g=-2.0$ m）> −2.6 m → 不合格，应至少再下移 1.0 m，装到液面下 3.0 m 以下。

## 判断

- 例2-5 是本主题最重要的工程结论：**沸腾液体必须倒灌安装**，因为 $p_0=p_v$，允许安装高度只能是负值（液面以下）。
- 同理，高温接近沸点的液体、低沸点液体（液化气）、真空系统下的泵，都要按 $p_0-p_v$ 大幅缩水来核算，往往需要倒灌。

# 塔径的计算

## 计算式（`#L13201-#L13209`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $D_T=\sqrt{\dfrac{V_s}{(\pi/4)\,u}}$ | （6-72） |
| **文字式** | $\text{塔径}=\sqrt{\dfrac{\text{气相体积流量}}{\dfrac{\pi}{4}\times\text{空塔气速}}}$ |  |

关键是定空塔气速 $u$。气速大 → 塔径小、造价低，但液沫夹带大、板效率低，气速过大即液泛。

## 泛点气速（`#L13211-#L13217`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $u_{\max}=C\sqrt{\dfrac{\rho_L-\rho_V}{\rho_V}}$ | （6-73） |
| **文字式** | $\text{泛点气速}=\text{负荷系数}\times\sqrt{\dfrac{\text{液相密度}-\text{气相密度}}{\text{气相密度}}}$ |  |

负荷系数 $C$ 查图6-59（史密斯关联图）：横坐标为 $(L/V)\sqrt{\rho_L/\rho_V}$（液气动能比），纵坐标为 $C_{20}$（对应表面张力 $\sigma$=20 mN/m）。

表面张力不同时校正：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $C=C_{20}\left(\dfrac{\sigma}{20}\right)^{0.2}$ | （6-74） |
| **文字式** | $\text{负荷系数}=\text{查图值}\times\left(\dfrac{\text{表面张力}_{\text{【mN/m】}}}{20}\right)^{0.2}$ |  |

## 设计气速（`#L13219-#L13221`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $u=(0.6\sim0.8)u_{\max}$ | （6-75） |
| **文字式** | $\text{设计气速}=(0.6\sim0.8)\times\text{泛点气速}$ |  |

取 0.6~0.8 是留出操作弹性：上限保证不液泛，下限保证不漏液。

## 例6-22（`#L13223-#L13281`）

苯-甲苯精馏：$D$=24.6 kmol/h、$R$=2.3、$M$=78.3、$\rho_L$=815 kg/m³、$\rho_V$=2.70 kg/m³、$L$=5.44 m³/h、$V$=2350 m³/h、初选 $H_T$=0.35 m。

1. 动能参数 $(L/V)\sqrt{\rho_L/\rho_V}=0.0402$；
2. 查图6-59 → $C_{20}$=0.07；$\sigma$=21.2 mN/m → $C$=0.0708；
3. $u_{\max}$=1.23 m/s，取 $u$=0.923 m/s；
4. $D_T$=0.949 m → 圆整 1.0 m。

## 判断

- "先定气速、再算塔径"是唯一可行顺序：气速由液泛（上限）与漏液（下限）夹出窗口，塔径只是它的换算结果。
- 史密斯图的横坐标是"液气动能比"，本质是"液体负荷相对气体负荷的大小"；液体越大越易液泛，$C$ 越小。
- 表面张力校正指数 0.2 意味着 $\sigma$ 从 20 增到 60 mN/m 时 $C$ 只增约 25%——泡沫体系（低 σ）不是靠 $\sigma$ 就能救，要靠降低气速。
- 圆整塔径后必须回算实际气速与液泛率，不能直接采用算出的 $u$。

# 过滤方式与物料衡算

## 基本术语（`#L5069-#L5073`）

过滤=使含固体颗粒的非均相物系通过多孔材料、分离出固体颗粒的操作；通常指悬浮液过滤。

- 滤浆（料浆，slurry）：待过滤的悬浮液；
- 过滤介质（filtering medium）：多孔材料；
- 滤饼（滤渣，filter cake）：留在介质上的固体颗粒层；
- 滤液（filtrate）：透过介质与滤饼的清液。

## 关键矛盾（`#L5123`）

过滤所得滤液量 **不等于** 悬浮液中的液体量——因为湿滤渣里含有一部分液体。故必须先建立"悬浮液量、固体量、滤液量、滤渣量"四者的换算关系。

## 三个换算式（`#L5129-#L5155`）

设 $C$ = 湿滤渣与其所含干渣的质量比（kg 湿渣/kg 干渣）；$X$ = 悬浮液中固体的质量分数（kg 固体/kg 悬浮液）；$\rho$、$\rho_p$、$\rho_c$ 分别为滤液、干渣、湿滤渣密度。

湿滤渣密度：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{C}{\rho_c}=\dfrac{1}{\rho_p}+\dfrac{C-1}{\rho}$ | （3-28） |
| **文字式** | $\dfrac{\text{湿渣与干渣质量比}}{\text{湿滤渣密度}_{\text{【kg/m³】}}}=\dfrac{1}{\text{干渣密度}_{\text{【kg/m³】}}}+\dfrac{\text{湿渣与干渣质量比}-1}{\text{滤液密度}_{\text{【kg/m³】}}}$ |  |

单位体积滤液对应的干渣质量：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $w=\dfrac{X\rho}{1-CX}$ | （3-29） |
| **文字式** | $\text{干渣质量与滤液体积之比}_{\text{【kg/m³】}}=\dfrac{\text{固体质量分数}\times\text{滤液密度}_{\text{【kg/m³】}}}{1-\text{湿干质量比}\times\text{固体质量分数}}$ |  |

单位体积滤液对应的湿滤渣体积：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $v=\dfrac{wC}{\rho_c}$ | （3-30） |
| **文字式** | $\text{湿渣体积与滤液体积之比}=\dfrac{\text{干渣与滤液比}_{\text{【kg/m³】}}\times\text{湿干质量比}}{\text{湿滤渣密度}_{\text{【kg/m³】}}}$ |  |

另两个中间量：湿滤渣质量与滤液体积之比 $=wC$（kg 湿渣/m³ 滤液）。

## 例3-4（`#L5157-#L5173`）

1 kg 悬浮液含 0.04 kg 固体；$\rho_c=1400$、$\rho_p=2600$、$\rho=1000$ kg/m³：
- 由(3-28)解得 $C=2.15$ kg 湿渣/kg 干渣；
- $w=0.04\times1000/(1-2.15\times0.04)=43.8$ kg 干渣/m³ 滤液；
- $v=43.8\times2.15/1400=0.0673$ m³ 湿渣/m³ 滤液。

## 判断

- $v$ 是连接"物料衡算"与"过滤速率方程"的桥梁：速率方程中的滤饼厚度 $V_c/A$ 正是靠 $v$ 换成滤液体积 $V$ 的。
- $C$ 与 $X$ 的关系决定了 $w$ 与 $v$ 的量级：$CX$ 接近 1 时分母趋零，说明该料浆几乎全是固体、滤液极少——这在实际操作中对应"无法过滤"的极限。

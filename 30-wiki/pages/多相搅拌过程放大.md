# 多相搅拌过程放大

## 共同逻辑

多相过程影响因素多且互相矛盾，只能针对具体过程**找出最有影响的场变量（放大因子）**，把复杂问题化为单一问题，再尽量照顾其他变量（`#L4197`）。

## 一、气液分散

基准：**比界面积 $a$ 恒定**（`#L4201`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $ad\propto\left(\dfrac{d^{3}N^{2}\rho}{\sigma}\right)\left(\dfrac{d^{2}N\rho}{\mu}\right)^{-0.6}$ | （4-27） |
| **文字式** | $\text{比界面积}\times\text{桨径}\propto\text{韦伯数}\times\text{雷诺数}^{-0.6}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $a\propto\left(N^{3}d^{2}\right)^{0.5}$ | （4-28） |
| **文字式** | $\text{比界面积}\propto\left(\text{转速}^{3}\times\text{桨径}^{2}\right)^{0.5}$ |  |

几何相似 + $a$ 恒定 ⇒ $N^3d^2=\text{const}$，进而

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{N_{2}}{N_{1}}=\left(\dfrac{d_{1}}{d_{2}}\right)^{2.4}$；$\ \dfrac{P_{V2}}{P_{V1}}=1$ | （4-30）（4-31） |
| **文字式** | $\text{大釜转速}/\text{小釜转速}=\left(\text{小釜桨径}/\text{大釜桨径}\right)^{2.4}$；$\text{单位体积功率不变}$ |  |

（`#L4205-#L4225`）

补充：$P_V$ 恒等时若同时保持**表观气速**相同，大小釜传质速率可近似相等（`#L4227`）；混合时间与循环时间的方差也影响液滴尺寸分布。

## 二、液液分散

同样以 $a$ 恒定、$P_V$ 恒等为放大因子（`#L4233`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $ad\propto\left(\dfrac{N^{2}d^{2}\rho}{\sigma}\right)^{0.6}$ | （4-32） |
| **文字式** | $\text{比界面积}\times\text{桨径}\propto\text{韦伯数}^{0.6}$ |  |

- 由式（2-97），$P_V$ 恒等时 $d_{32}$ 也相等；
- 若还要求**粒径分布方差**相同，则因方差随釜径增大而增大，必须改 $d/D$ 做非几何相似放大。例：15 m³ 淤浆聚合釜放大到 50 m³，需增大大釜桨径以增大排量，才能保持分布一致（`#L4239-#L4241`）。

## 三、固液悬浮

无挡板下临界悬浮转速（`#L4249`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{c}=KD^{-2/3}d_{p}^{1/3}\left(\dfrac{\Delta\rho}{\rho}\right)^{2/3}\left(\dfrac{\mu}{\rho}\right)^{1/9}\left(\dfrac{V_{p}^{\prime}}{V_{p}}\right)^{0.7}$ | （4-33） |
| **文字式** | $\text{临界转速}_{\text{【1/s】}}=\text{结构常数}\times\text{釜径}_{\text{【m】}}^{-2/3}\times\text{粒径}_{\text{【m】}}^{1/3}\times\left(\dfrac{\text{密度差}}{\text{液体密度}}\right)^{2/3}\times\left(\dfrac{\text{黏度}}{\text{密度}}\right)^{1/9}\times\left(\dfrac{\text{视体积}}{\text{真体积}}\right)^{0.7}$ |  |

$K\approx200\sim250$，与槽结构、桨型与尺寸有关（`#L4255`）。由此 $N_c\propto D^{-2/3}$（4-34），对应放大指数 $X=2/3$，即**$P_V$ 恒定**（`#L4273-#L4279`）。

### 争议：Y 有十种取值

Einenkel 归纳出以 $P_V\propto D^{Y}$ 表示时 $Y$ 有 $+0.5$、$+0.2$、$0$、$-0.1$、$-0.13$、$-0.3$、$-0.55$、$-0.7$、$-0.75$、$-1$ 十种（图 4-2）；转换关系 $Y=2+3Z$（$N_c\propto D^{Z}$）（`#L4287`）：

| 来源 | $Z$ | $Y$ |
|:---|---:|---:|
| Zwietering（2-117） | −0.85 | −0.55 |
| 王凯推荐（均匀悬浮） | −0.775 | −0.325 |
| 王凯推荐（完全离底） | −0.85 | −0.55 |

**大釜上 $Y$、$Z$ 的细微差别会让所需功率相差极大**（`#L4289`）。

溶解过程：首要仍是固体悬浮，故也取 $P_V$ 恒等（`#L4291`）。

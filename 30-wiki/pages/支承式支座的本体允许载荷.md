# 支承式支座的本体允许载荷

## 定义

支承式支座分 A 型（钢板焊制）与 B 型（钢管制作）。本体允许载荷 [Q] 指筋板/钢管与底板本身强度允许的垂直载荷，按筋板（或钢管）受压和底板弯曲两种模式分别导出允许值后取小（#L7307）。

## 判据与计算

### 计算模型（编制说明 4.1/5.1，#L7310、#L7354）

A 型与 B 型支座本体强度的计算模型分别见第4部分编制说明 4.1（#L7310）与 5.1（#L7354）：筋板/钢管按受压（或受压稳定）计，底板按弯曲计，取两者小值。

### 2.1 A 型 A1~A4 号（式(1)~(3)，#L7317-#L7327）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{1}]=2\delta_{2}(b_{1}-10)k[\sigma]$ | （2-1） |
| **文字式** | $\text{按筋板确定的允许载荷}=2\times\text{筋板厚度}\times(\text{筋板宽度}-10)\times\text{折减系数}\times\text{材料许用应力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{2}]=\dfrac{4b_{1}l_{1}\delta_{1}^{2}}{3b_{2}^{2}}[\sigma]$ | （2-2） |
| **文字式** | $\text{按底板确定的允许载荷}=\dfrac{4\times\text{底板宽度}\times\text{底板长度}\times\text{底板厚度}^{2}}{3\times\text{筋板外侧长度}^{2}}\times\text{材料许用应力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q]=\min\left\{[Q_{1}],[Q_{2}]\right\}$ | （2-3） |
| **文字式** | $\text{支座允许载荷}=\min(\text{筋板允许载荷},\ \text{底板允许载荷})$ |  |

### 2.2 A 型 A5~A6 号（槽型杆+一边固支板，式(4)~(6)，#L7331-#L7341）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{1}]=\delta_{2}(2b_{1}-20+l_{1})k[\sigma]$ | （2-4） |
| **文字式** | $\text{按筋板确定的允许载荷}=\text{筋板厚度}\times(2\times\text{筋板宽度}-20+\text{底板长度})\times\text{折减系数}\times\text{材料许用应力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{2}]=\dfrac{2.17b_{1}l_{1}\delta_{1}^{2}}{(b_{2}-\delta_{2})^{2}}[\sigma]$ | （2-5） |
| **文字式** | $\text{按底板确定的允许载荷}=\dfrac{2.17\times\text{底板宽度}\times\text{底板长度}\times\text{底板厚度}^{2}}{(\text{筋板外侧长度}-\text{筋板厚度})^{2}}\times\text{材料许用应力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q]=\min\left\{[Q_{1}],[Q_{2}]\right\}$ | （2-6） |
| **文字式** | $\text{支座允许载荷}=\min(\text{筋板允许载荷},\ \text{底板允许载荷})$ |  |

### 2.3 B 型（钢管+四边自由中部支承板，式(7)~(9)，#L7363-#L7373）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{1}]=\dfrac{\pi}{4}(d_{\mathrm{o}}^{2}-d_{\mathrm{i}}^{2})k[\sigma]$ | （2-7） |
| **文字式** | $\text{按钢管确定的允许载荷}=\dfrac{\pi}{4}\times(\text{钢管外径}^{2}-\text{钢管内径}^{2})\times\text{折减系数}\times\text{材料许用应力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{2}]=\dfrac{4\delta_{1}^{2}b_{2}}{3(b^{2}-0.5d_{2}^{2})}[\sigma]$ | （2-8） |
| **文字式** | $\text{按底板确定的允许载荷}=\dfrac{4\times\text{底板厚度}^{2}\times\text{底板长度}}{3\times(\text{底板宽度}^{2}-0.5\times\text{开孔直径}^{2})}\times\text{材料许用应力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q]=\min\left\{[Q_{1}],[Q_{2}]\right\}$ | （2-9） |
| **文字式** | $\text{支座允许载荷}=\min(\text{钢管允许载荷},\ \text{底板允许载荷})$ |  |

## 适用范围与边界

- 适用于标准 A/B 型支承式支座（DN 800~4000）按标准尺寸安装的工况；材料 Q235B、S30408（系列参数见表 3、表 4，#L6836）。
- 本页只管支座本体；封头局部应力按 [[支承式支座的封头许用垂直载荷]] 另行校核，实际允许垂直载荷取两者小值。
- B 型支座高度可以改变但不应大于 hmax（#L6846-#L6848）。
- 公式中几何尺寸（b1/b2/l1/δ1/δ2/do/di/b/d2）取自标准系列参数表；A5~A6 的结构与其他 A 型不同，公式不通用。

# 光纤探头测气含率

## 原理（`#L294`）

利用气液两相**光学折射率**不同，探测某点气液两相的交替存在；用交替存在的相对时间比（或采样时间 $t$ 内气泡包围探头的时间与 $t$ 之比）求局部气含率。

## 波形为什么是梯形（`#L294`）

气液界面张力的影响使探头**完全刺破界面需要时间**——这就是信号上升段；下降段表示探头从气到液的探测过程。界面张力越大，时间延迟越大。故输出近似**梯形波**，须转成矩形波才能确定气泡经过时间。

## Bankoff 指数分布（`#L294-#L297`）

S. G. Bankoff 在管道变密度模型中提出气液分散充分发展段的截面气含率指数分布：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{\alpha(r)}{\alpha_c}=\left(1-\dfrac{r}{R}\right)^{1/n}$，$n=\dfrac{2}{\sqrt{1+8\alpha_c/\langle\alpha\rangle}-3}$ | （1.3） |
| **文字式** | $\dfrac{\text{径向位置气含率}}{\text{中心气含率}}=\left(1-\dfrac{\text{径向位置}}{\text{半径}}\right)^{\text{分布指数}}$ |  |

## 误差来源（`#L304`）

1. 探头表面状况对刺穿气泡能力的影响；
2. 探头在两相流中的放置方向；
3. 气泡形状。

## 应用情况（`#L304`）

在垂直上升管、液压泵两相流局部气含率测量中报道较多；测**气液搅拌釜**的报道较少。

## 判断

- 梯形波与电导探头的成因不同：电导靠电导率跳变（理论上近阶跃），光纤靠界面张力决定的刺破过程（物理延迟），所以光纤的时间偏差更依赖体系表面张力。
- （1.3）中 $n$ 依赖 $\alpha_c/\langle\alpha\rangle$，意味着分布形状随平均气含率变化：平均气含率越高，$n$ 越大，分布越平坦——与鼓泡塔实测趋势一致。
- 三项误差里"放置方向"最容易被忽略：探头与流向不平行时，气泡可能沿探针表面滑过而不被刺穿，气泡频率被低估。

# 圆管内流体的速度分布

## 层流：抛物线（`#L1786-#L1858`）

水平管半径 $R$、取长 $l$ 半径 $r$ 的流柱，两端总压力与周围内摩擦力平衡，用牛顿黏性定律（负号表示流速随半径增大而减小），得微分方程：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{d}u_r}{\mathrm{d}r}=-\dfrac{\Delta p}{2\mu l}r$ | （1-36） |
| **文字式** | $\dfrac{\text{半径}r\text{处流速对半径的导数}}{\ }=-\dfrac{\text{两端压差}_{\text{【Pa】}}}{2\times\text{黏度}_{\text{【Pa·s】}}\times\text{管长}_{\text{【m】}}}\times\text{半径}_{\text{【m】}}$ |  |

积分并用壁面边界条件（$r=R$ 时 $u_r=0$）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_r=\dfrac{\Delta p}{4\mu l}(R^2-r^2)$ | （1-37） |
| **文字式** | $\text{半径}r\text{处流速}_{\text{【m/s】}}=\dfrac{\text{压差}_{\text{【Pa】}}}{4\times\text{黏度}_{\text{【Pa·s】}}\times\text{管长}_{\text{【m】}}}\times\left(\text{管内半径}^2-\text{半径}r^2\right)$ |  |

**速度分布为抛物线**：管中心最大、壁面为零。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_{\max}=\dfrac{\Delta p}{4\mu l}R^2$ | （1-38） |
| **文字式** | $\text{最大流速}_{\text{【m/s】}}=\dfrac{\text{压差}_{\text{【Pa】}}}{4\times\text{黏度}_{\text{【Pa·s】}}\times\text{管长}_{\text{【m】}}}\times\text{管内半径}_{\text{【m】}}^2$ |  |

## 层流的流量与平均流速（`#L1866-#L1904`）

对环形微元积分得流量 $q_V=\dfrac{\pi R^4\Delta p}{8\mu l}$（书内未编号），故平均流速：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=\dfrac{\Delta p}{8\mu l}R^2$ | （1-39） |
| **文字式** | $\text{平均流速}_{\text{【m/s】}}=\dfrac{\text{压差}_{\text{【Pa】}}}{8\times\text{黏度}_{\text{【Pa·s】}}\times\text{管长}_{\text{【m】}}}\times\text{管内半径}_{\text{【m】}}^2$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=\dfrac{1}{2}u_{\max}$ | （1-40） |
| **文字式** | $\text{平均流速}=\dfrac{1}{2}\times\text{最大流速}$ |  |

**哈根-泊谡叶方程**（层流压差与流速一次方成正比）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=32\dfrac{\mu lu}{d^2}$ | （1-41） |
| **文字式** | $\text{压差}_{\text{【Pa】}}=32\times\dfrac{\text{黏度}_{\text{【Pa·s】}}\times\text{管长}_{\text{【m】}}\times\text{平均流速}_{\text{【m/s】}}}{\text{管内径}_{\text{【m】}}^2}$ |  |

## 湍流（`#L1908-#L1930`）

湍流速度分布无法理论推导，只能实测：中心湍流主体动量交换强、速度分布**平坦**；$Re$ 越大顶部越平。平均速度约为最大速度的 **0.82 倍**（$u\approx0.82u_{\max}$）。

光滑管、$Re\le10^5$ 时可用 **1/7 次方定律**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_r=u_{\max}\left(1-\dfrac{r}{R}\right)^{1/7}$ | （1-42） |
| **文字式** | $\text{半径}r\text{处流速}_{\text{【m/s】}}=\text{最大流速}_{\text{【m/s】}}\times\left(1-\dfrac{\text{半径}r}{\text{管内半径}}\right)^{1/7}$ |  |

## 层流底层、过渡层与进口起始段（`#L1798-#L1804`、`#L1930-#L1940`）

- 紧贴管壁、速度梯度大、仍作层流流动的薄层称**层流底层**，厚度随 $Re$ 增大而减小；
- 湍流核心与层流底层之间有**过渡层**；
- 湍流起始段约 $(40\sim50)d$；
- 层流起始段：入口速度均匀，壁面处降为零，深入一段后中心速度达到平均速度 2 倍，抛物线才完全形成；**$X_0=0.05dRe$**。

## 判断

- 1-40 与"湍流 0.82"是同一件事的两种流型版本：层流剖面尖、湍流剖面平，所以平均/最大之比从 0.5 升到 0.82。
- 层流起始段长度与 $Re$ 成正比：小管低速时入口段很长，实验测速度分布必须避开它。

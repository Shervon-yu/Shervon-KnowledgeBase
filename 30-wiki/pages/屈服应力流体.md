# 屈服应力流体

## 定义

宾汉塑性流体在流动曲线上存在屈服应力 $\tau_0$：应力小于 $\tau_0$ 时呈固体行为，大于 $\tau_0$ 时三维刚性结构被破坏，才出现流动（`#L1259`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=\tau_{0}+\mu_{\mathrm{p}}\dot{\gamma}\quad(\tau>\tau_{0});\qquad\dot{\gamma}=0\quad(\left|\tau\right|\leqslant\tau_{0})$ | （2-3） |
| **文字式** | $\text{切应力}_{\text{【Pa】}}=\text{屈服应力}_{\text{【Pa】}}+\text{塑性黏度}_{\text{【Pa·s】}}\times\text{切应变速率}_{\text{【1/s】}}$；当切应力不大于屈服应力时切应变速率为零 |  |

$\mu_{\mathrm{p}}$ 为塑性黏度，即流动曲线（图2-1 曲线 4）的斜率（`#L1273`）。

## 常见物料

污水泥浆、油脂、油漆、牙膏、淤泥、蛋黄酱、含固体颗粒的白垩；把大量二氧化钛、碳酸钙、氧化铁微粉混入水中也可得宾汉塑性流体（`#L1275`）。

## 与幂律的组合形式

表2-3 收了几种带屈服应力的模型（`#L1303-#L1305`）：

- Bingham：$\tau=\tau_0+\mu_B\dot{\gamma}$；
- Casson：$\sqrt{\tau}=\sqrt{\tau_0}+\sqrt{\mu_C\dot{\gamma}}$（$\tau>\tau_0$），涂料/油墨常用；
- Herschel-Bulkley：$\tau=\tau_0+K_{\mathrm{psn}}\left|\dot{\gamma}\right|^{n-1}\dot{\gamma}$，即"屈服应力 + 幂律"，覆盖剪切变稀的膏体。

## 搅拌时的后果

- 釜内存在 $\tau<\tau_0$ 的区域即为**滞留区（死区）**：叶轮附近流动、远离叶轮处不动，表观"混合均匀"但实际未交换。
- 启动时叶轮必须先提供超过 $\tau_0$ 的剪切才能让全釜流动，所需启动扭矩高于稳态值。
- 因此对这类物料，"混合时间"与"功率准数"关联式都建立在**全釜已屈服**的前提下；选型要先确认叶轮能覆盖全部容积，而不是只看功率。
- 定量计算（$Re_b$、$He$、屈服项）见 [[宾汉塑性流体搅拌功率]]。

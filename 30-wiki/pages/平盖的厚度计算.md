# 平盖的厚度计算

适用受内压或外压、无孔或有孔但已加强的平盖，形状含圆形、椭圆形、长圆形、矩形、正方形（`#L7118`）。平盖与圆筒的连接结构分两类：表7-9（弹性/经验法）与表7-10（**基于塑性分析**，仅适用于封头与筒体全焊透结构）。

中心开孔直径超过 $0.5D_o$ 的平盖不适用本节，走 8.5 → [[平盖中心大开孔的计算]]。

## 一、圆形平盖（式7-40）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_p=D_c\sqrt{\dfrac{Kp_c}{[\sigma]^t\varphi}}$ | （7-40） |
| **文字式** | $\text{平盖计算厚度}_{\text{【mm】}}=\text{平盖计算直径}\times\sqrt{\dfrac{\text{结构特征系数}\times\text{计算压力}}{\text{许用应力}\times\text{焊接接头系数}}}$ |  |

## 二、结构特征系数 K（表7-9，`#L7170-#L7191`）

| 连接方式 | K |
|:--|:--|
| 与圆筒一体或对焊（序号1） | 0.145，仅适用圆形平盖、$p_c\le0.6$ MPa、$L_1\ge1.1\sqrt{D_c\delta_{ep}}$、$r\ge3\delta_{ep}$ |
| 角焊缝或组合焊缝（序号2~5） | 圆形：$0.4m$（$m=\delta/\delta_e$），且不小于 0.3；非圆形：0.4（个别 0.44） |
| 锁底对接焊缝（序号6、7） | 0.4m 或 0.4（序号7 的 b 为 0.5）；须 $\delta_1\ge\delta_e+3$ mm |
| 螺栓连接（序号8） | 0.25 |
| 螺栓连接（序号9、10） | 操作：$0.3+\dfrac{1.78WL_G}{p_cD_c^3}$；预紧：$\dfrac{1.78WL_G}{p_cD_c^3}$；非圆形用 $Z$ 与 $L$ 替换 |

- 表7-9 序号2~7 的结构，焊接接头表面须 100% 表面检测；
- 序号9、10 须分别取操作状态与预紧状态的 K 计算，**取较大值**；预紧状态 $[\sigma]^t$ 用常温许用应力。

表7-10 的 K 查图7-23/图7-24（结构参数要求如 $r\ge10$ mm 或 $0.25\delta_e$、$L\ge2\sqrt{D_c\delta_e}$、$\delta_f\ge2\delta_e$、全截面熔透 $f\ge\delta_e$ 等）。

## 三、非圆形平盖（式7-41、7-42）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_p=a\sqrt{\dfrac{KZp_c}{[\sigma]^t\varphi}}$，$Z=3.4-2.4\dfrac{a}{b}\le2.5$ | （7-41） |
| **文字式** | $\text{厚度}=\text{短轴长度}\times\sqrt{\dfrac{K\times Z\times p_c}{[\sigma]^t\varphi}}$，$Z$ 按长短轴比取，上限 2.5 |  |

表7-9 序号9、10（螺栓连接带垫片）的非圆形平盖改用式7-42（无 Z）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_p=a\sqrt{\dfrac{Kp_c}{[\sigma]^t\varphi}}$ | （7-42） |
| **文字式** | 同式7-41，但去掉形状系数 Z |  |

带拉撑的平封头不走本节的结构特征系数 K，按 7.12 的式（7-58）算板厚 → [[拉撑结构]]。

## 判断

- 式7-40 与内压圆筒式5-1 形式相似，但平盖的应力是**弯曲**而不是薄膜：所以是 $\sqrt{}$ 开方、且 K 在 0.15~0.5 量级——一体对焊（0.145）比螺栓连接（0.25~0.5）省近一半厚度，这是"边缘固支 vs 简支"的差别；
- 螺栓连接平盖的 K 里含 $WL_G/(p_cD_c^3)$ 项：**螺栓预紧力**会产生附加弯矩，小直径、高预紧时这一项可能远超 0.3，是小釜平盖常被忽略的破坏源；
- 表7-10 是塑性分析结果，用它的前提是全焊透 + 满足结构参数，不能只抄 K 值。

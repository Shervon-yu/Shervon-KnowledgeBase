# 旋转蛇管式叶轮

## 结构

把螺带换成**内部通冷却水的螺旋蛇管**，蛇管随轴一起转，冷却水经两个旋转轴封进出（`#L3089`、`#L3113`）：

| 型号 | 形式 | 螺距 $s/d$ | 实验釜 |
|:---|:---|:---:|:---|
| RC1 | 两圈对称螺旋蛇管 | 1.0 | $D=300$、$d=285$、$H=400$ mm，管外径 $d_{co}=28$ mm |
| RC2 | 单圈螺旋蛇管 | 0.33 | 同上 |

## 为什么"转的蛇管"比"固定的夹套"强

两个面积相等的平面面对面时剪切率相同；但蛇管表面积比釜壁小，**剪应力集中在蛇管表面**，该处剪切率更高，拟塑性/宾汉流体的表观黏度被拉得更低，传热系数反而更大（`#L3129`，图2.16）。

两种对照实验（`#L3131`、`#L3139`）：

| 情况 | 加热侧 | 冷却侧 | 结果 |
|:---|:---|:---|:---|
| （1） | 夹套蒸汽 | 蛇管内水冷 | $h_{c}>h_{j}$（尽管夹套壁温更高、$\mu_{a}$ 更小，本应 $h_{j}$ 更大） |
| （2） | 蛇管蒸汽 | 夹套冰水 | $h_{c}$ 是 $h_{j}$ 的 **6.5 倍** |

所以冷却能力排序不是"传热面积 × 温度差"，而是 **$\dot{\gamma}$ 决定 $\mu_{a}$，$\mu_{a}$ 决定 $h$**。

## 表观黏度

沿用双层螺带的平均剪切率（`#L3123`，与 §1.6 的 $K=30.0$ 一致）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dot{\gamma}_{\mathrm{av}}=30.3n$ | （2.26） |
| **文字式** | $\text{平均剪切率}_{\text{【1/s】}}=30.3\times\text{转速}_{\text{【1/s】}}$ |  |

由 $\mu_{a}=\tau/\dot{\gamma}_{\mathrm{av}}$ 在流动曲线（图2.14b）上读表观黏度，再算 $Re$、$Pr$、$Vis$。

## 关联式

层流区 $1<Re<200$（`#L3170`、`#L3176`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mathrm{RC1}:\ Nu_{j}=2.2Re^{1/3}Pr^{1/3}Vis^{0.2},\ N_{c}=6.2Re^{1/3}Pr^{1/3}Vis^{0.2}$ | （2.27）（2.28） |
| **文字式** | $\text{夹套侧努塞尔数}=2.2\times\text{雷诺数}^{1/3}\times\text{普朗特数}^{1/3}\times\text{黏度比}^{0.2}；\ \text{蛇管侧}=6.2\times\text{同上各项}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mathrm{RC2}:\ Nu_{j}=1.6Re^{1/3}Pr^{1/3}Vis^{0.2},\ Nu_{c}=2.9Re^{1/3}Pr^{1/3}Vis^{0.2}$ | （2.29）（2.30） |
| **文字式** | 同 RC1，两系数由 2.2/6.2 降为 1.6/2.9 |  |

湍流侧 $Re>200$ 两者等价，且与锚式一致（`#L3214`、`#L3216`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Nu_{j}=0.36Re^{2/3}Pr^{1/3}Vis^{0.14}$；$\mathrm{RC1}:Nu_{c}=3.3Re^{1/2}Pr^{1/3}Vis^{0.14}$；$\mathrm{RC2}:Nu_{c}=1.8Re^{1/2}Pr^{1/3}Vis^{0.14}$ | （2.31）（2.32）（2.33） |
| **文字式** | 夹套侧回到 2/3 次方；**蛇管侧仍是 1/2 次方**，因为管面绕流与壁面边界层不同 |  |

**$Nu_{c}\approx3Nu_{j}$**（6.2/2.2），这是 RC 叶轮的核心数字（`#L3168`）。

RC1 与 RC2 的**功率几乎相等**，但 RC1 的 $h_{c}$ 是 RC2 的两倍，故 RC1 更有效（`#L3184`）。

## 例2.2：夹套 vs 旋转蛇管（`#L3234`）

$D=300$ mm、RC1、40 r/min、反应热 3000 kcal/h、$k=0.5$ kcal/(m·h·℃)、$C_{p}=1.0$、$\rho=950$ kg/m³，冷却面 $A_{j}=0.2309$ m²、$A_{c}=0.1932$ m²。

| 量 | 值 |
|:---|:---|
| $\dot{\gamma}_{\mathrm{av}}=30.3\times(40/60)$ | 20.2 s⁻¹ |
| $\mu_{a}=2400/20.2$ | 118.5 P |
| $Re'=d^{2}n\rho/\mu_{a}$ | 4.35 |
| $Pr=C_{p}\mu_{a}/k$ | $8.52\times10^{4}$ |
| 机械能转化热（式1.66′） | 4.27 kg·m/s = 36 kcal/h（总 3036） |

| 冷却方式 | 试差得壁温 | $h$ [kcal/(m²·h·℃)] | 系数式 |
|:---|:---:|:---:|:---|
| 夹套 | $t_{w}=0$ ℃ | 190 | $h_{j}=264(\mu_{a}/\mu_{w})^{0.2}$ |
| 旋转蛇管 | $t_{w}=46$ ℃ | 660 | $h_{c}=745(\mu_{a}/\mu_{w})^{0.2}$ |

**要点**：旋转蛇管不只把 $h$ 提高 3.5 倍，还因壁温从 0 ℃ 升到 46 ℃、壁面黏度从 615 P 降到 213 P，使 $Vis$ 项（0.719→0.885）也变好；两者叠加才是完整的收益（`#L3356`、`#L3360`）。反应热到 4000 kcal/(m³·h) 时壁温压低、$\mu_{w}$ 暴涨，**夹套根本冷不下来**（`#L3364`）。

## 冷却能力 $Q_{c}$

叶轮机械能会变成热，净冷却能力要扣掉这一项（`#L3370`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q_{c}=q_{c}-q_{p}=K\dfrac{k}{D}Re^{\alpha}Pr^{\beta}Vis^{\gamma}A\Delta T-N_{p}\rho n^{3}d^{5}/g_{c}\cdot j$ | （2.34）（2.34′） |
| **文字式** | $\text{净冷却能力}_{\text{【W】}}=\text{传热除去的热}-\text{搅拌机械能转化的热}$ |  |

代入 $\alpha=\beta=1/3$、$\gamma=0.2$ 得 $Q_{c}=K'n^{1/3}Vis^{0.2}(t-t_{w})-K''\mu n^{2}$（2.35，`#L3378`）：**黏度越大、转速越高，净冷却能力越小**。数值代入本例题得 $Q_{c}=318n^{1/3}(t-t_{w})Vis^{0.2}-0.586\mu n^{2}$（2.35′，`#L3390`）。

工程结论（`#L3392`）：$D\leq2$ m、$\mu=100$ P 时，反应热必须控制在 **$7\times10^{3}$ kcal/(m³·h)** 以内；容器越大冷却能力越小。

## 附注

- 宾汉塑性流体：关联式中用塑性黏度 $\eta$ 代替 $\mu$，且曲线上**没有转折点**——因为旋转蛇管表面附近剪应力足够大（`#L3206`、`#L3220`）。

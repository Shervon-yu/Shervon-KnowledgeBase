# 孔板混合器的界面面积关联式

## 为什么不用搅拌桨

流动混合器用于石油洗涤、脂肪油氢化的连续液-液与气-液接触（`#L8826`）：目的是**提高液体速度、产生湍动分散**，从而强化传质或反应，而不需要转动部件。三类装置（`#L8826`–`#L8834`）：

| 类型 | 结构 | 特点 |
|:---|:---|:---|
| 射流接触器 | 两液并流，经一只孔板或喷嘴产生湍动 | 被处理液强制通过，另一液体在紧靠障碍物**前部**泵入 |
| 塔式接触器 | 串联孔板/弯头/障碍物的管或塔 | 最简单的为挡板塔，可再循环；最常用为筛板塔 |
| 管线混合器 | 管道内装一串孔板 | 开孔太小则液滴喷得太小、几乎无法分离 |

**最后这条是设计红线**：孔板孔径不是越小越好，太小会造成"乳化过度、分不掉"（`#L8834`）。

## 已有的实测规律

Scott 与 McDonough 等用光透射法测分散相单位体积界面面积（`#L8840`）：以孔板直径为基础的雷诺数 $Re_0=10^4\sim4.5\times10^4$ 时，

- 比界面积随**两相流量比**增大而增大；
- 比界面积随**孔板处动能**增大而增大；
- Scott 还测了孔板下游凝并与再分散的速率。

## 关联式的推导骨架

### 第一步：面积与滴径

|  |  |  |
|:---|:---:|---|
| **符号式** | $a=6\phi/d_{SM}$ | （7.65） |
| **文字式** | $\text{比界面积}_{\text{【ft²/ft³】}}=6\times\text{分散相体积分率}/\text{索特平均直径}_{\text{【ft】}}$ |  |

### 第二步：造表面要耗能

造出面 $a$ 所需的能量由 $a\sigma$ 给出（$\sigma$ 为界面张力），它应是通过孔板的动能变化 $\Delta K.E.$ 与混合物密度的某种函数（`#L8850`、`#L8852`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a\sigma=f_1\left[(\Delta K.E.)\rho_m\right]$;\qquad $\rho_m=(1-\phi)\rho_c+\phi\rho_d$ | （7.66）（7.67） |
| **文字式** | 界面能密度 = 孔板动能变化 × 混合物平均密度 的函数 |  |

### 第三步：分裂液滴还要克服黏滞力

在过液滴几何中心的平面上把它分开，只考虑黏滞力（`#L8866`–`#L8874`）：剪切力 $\tau\times\pi d_{SM}^2/4$，乘位移 $d_{SM}$、乘单位质量液滴数 $Z$，得

|  |  |  |
|:---|:---:|---|
| **符号式** | $a\sigma\propto\dfrac{3\tau\phi}{2}$;\qquad $Z=\dfrac{\phi}{\rho_m\left(\pi d_{SM}^3/6\right)}$ | （7.70）（7.69） |
| **文字式** | 界面能密度正比于剪切应力 × 体积分率；$Z$ 为单位质量液体中的液滴数 |  |

### 第四步：三项指数式

综合（7.66）（7.70）与"面积正比于 $f(\phi)$"（`#L8862`、`#L8878`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a\sigma=K_0\left(\Delta K.E.\cdot\rho_m\right)^{a}\tau^{b}\phi^{c}$ | （7.72） |
| **文字式** | 界面能密度是「孔板动能×密度」「剪切应力」「体积分率」三项的幂函数 |  |

剪切应力与剪切速度（`#L8886`、`#L8904`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\tau=\dfrac{C_D\rho\bar u^{2}}{2g_c}$;\qquad $\bar u=k_1u_p\left[\left(\dfrac{d_t}{d_0}\right)^{4}-1\right]^{e}$ | （7.73）（7.75） |
| **文字式** | 剪切应力 = 阻力系数 × 密度 × 剪切速度² / 2；剪切速度正比于管速 × (管径/孔径)⁴−1 的幂 |  |

$C_D$ 与以滴径、密度、速度算的雷诺数成反比（`#L8892`）：$C_D=k_0/(d_{SM}\rho\bar u/\mu)$。$d_t$、$d_0$ 为管道与孔板直径。

## 拟合结果

把（7.73）（7.75）代入（7.72），方程式两端都出现 $a$，可解出（`#L8910`、`#L8912`）；系数与指数由最小二乘定（`#L8916`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a\sigma=0.189\left(\Delta K.E.\cdot\rho_m\right)^{0.829}\left(\dfrac{\mu u_p}{\sigma g_c}\right)^{-0.158}\left[\left(\dfrac{d_t}{d_0}\right)^{4}-1\right]^{0.0378}\phi^{0.878}$ | （7.77） |
| **文字式** | 界面能密度 ∝ 孔板动能密度的 0.83 次方、黏性/毛细比值的 −0.16 次方、开孔面积比的 0.04 次方、相比的 0.88 次方 |  |

### 换成压降的工程版

孔板前后压降 $\Delta P$ 往往比动能更好测（`#L8918`、`#L8920`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a\sigma=0.179\left(c_0^{2}\Delta P\right)^{0.750}\left(\dfrac{\mu}{\sigma\sqrt{g_c\rho_m}}\right)^{-0.158}\left[\left(\dfrac{d_t}{d_0}\right)^{4}-1\right]^{0.117}\phi^{0.878}$ | （7.78） |
| **文字式** | 同一式换成压降口径，注意动能项指数由 0.829 降到 0.750、开孔项由 0.038 升到 0.117 |  |

孔板流量系数 $c_0$ 的定义（`#L8928`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{u_0^{2}-u_p^{2}}{2g_c}=\dfrac{c_0^{2}\Delta P}{\rho_m}$ | （7.79） |
| **文字式** | 孔板前后动能变化 = 流量系数² × 压降 / 混合物密度 |  |

## 指数说明了什么

1. **$\phi^{0.878}$ 接近 1 次方**：界面面积几乎与分散相含量成正比，说明液滴尺寸主要由孔板决定、不因相比而变——这与搅拌釜里 $a\propto\phi$ 的结论一致。
2. **动能项指数 0.83（<1）**：加倍动能只能得到约 1.8 倍面积，存在饱和趋势；靠加压差硬提面积不划算。
3. **黏性项 −0.158**：黏度越高界面面积越小，但很弱。
4. **开孔面积比的指数极小（0.04 / 0.12）**：$(d_t/d_0)^4-1$ 本身从 15（$d_0=d_t/2$）变化到 9999（$d_0=d_t/10$）跨三个数量级，指数小正说明**孔径的作用已体现在动能项里**，不能靠孔径单独调面积。

## 凝并发生在哪里

水在煤油中分散的实测（`#L8930`，图7.17，$d_0=0.4375$ in、$\phi=0.10$）：孔板下游沿轴向几个位置测界面面积，**几乎全部凝并都发生在孔板下游 220 in 内**。这就是孔板混合器"必须紧接分离器、不能长管输送"的原因——超出这段距离，前面打出来的界面面积已经白白凝并掉了。

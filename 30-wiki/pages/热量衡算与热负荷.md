# 热量衡算与热负荷

## 基本式（`#L6674-#L6690`）

保温良好、无热损失时，热流体放热=冷流体吸热。以焓差表示：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=q_{m1}(H_1-H_2)=q_{m2}(h_2-h_1)$ | （4-35） |
| **文字式** | $\text{热负荷}_{\text{【W】}}=\text{热流体质量流量}\times\text{进出口焓差}=\text{冷流体质量流量}\times\text{进出口焓差}$ |  |

两流体均无相变、$c_p$ 取平均温度下的值：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=q_{m1}c_{p1}(T_1-T_2)=q_{m2}c_{p2}(t_2-t_1)$ | （4-36） |
| **文字式** | $\text{热负荷}=\text{热流体流量}\times\text{比热容}\times\text{温降}=\text{冷流体流量}\times\text{比热容}\times\text{温升}$ |  |

一侧为饱和蒸气冷凝、另一侧无相变：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=q_{m1}r=q_{m2}c_{p2}(t_2-t_1)$ | （4-37） |
| **文字式** | $\text{热负荷}=\text{蒸气流量}\times\text{比汽化热}=\text{冷流体流量}\times\text{比热容}\times\text{温升}$ |  |

冷凝液出口低于饱和温度（过冷）时：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=q_{m1}\left[r+c_{p1}(T_s-T_2)\right]=q_{m2}c_{p2}(t_2-t_1)$ | （4-38） |
| **文字式** | $\text{热负荷}=\text{蒸气流量}\times\left[\text{比汽化热}+\text{冷凝液比热容}\times(\text{饱和温度}-\text{出口温度})\right]$ |  |

## 例4-11（`#L6702-#L6706`）

150 kPa（饱和温度 111 ℃、$r=2.229\times10^6$ J/kg）饱和水蒸气 1500 kg/h，冷凝后降至 50 ℃；冷凝水平均 80.5 ℃、$c_{p1}=4.196\times10^3$：

$Q=\frac{1500}{3600}[2.229\times10^6+4.196\times10^3\times(111-50)]=1.035\times10^6$ W。

## 判断

- 热量衡算的作用是给出 $Q$，它是后续三项（$K$、$\Delta t_m$、$A$）计算中唯一由工艺条件直接确定的量，必须先算、且要区分"有无相变""冷凝液是否过冷"三种情形。
- 工程上常忽略热损失（保温良好）；若热损失不可忽略，应对热流体侧乘散热系数或对冷流体侧除热效率，原文按理想情况处理。

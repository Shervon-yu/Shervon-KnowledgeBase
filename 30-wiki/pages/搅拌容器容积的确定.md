# 搅拌容器容积的确定

## 口径

工艺给定的容积：直立式为**内筒体 + 下封头**容积之和；卧式为**筒体 + 左右两封头**容积之和（`#L5885`）。

## 间歇式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $V=\dfrac{V_{s}\,t\,(1+\eta)}{24\,\phi\,m}$ | （6-1） |
| **文字式** | $\text{容器容积}_{\text{【m³】}}=\dfrac{\text{每昼夜处理物料体积}_{\text{【m³/24h】}}\times\text{每批处理时间}_{\text{【h】}}\times(1+\text{备用系数})}{24\times\text{装料系数}\times\text{台数}}$ |  |

（`#L5891-#L5905`）

## 连续式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $V=\dfrac{V_{s}^{\prime}\,t\,(1+\eta)}{\phi\,m}$ | （6-2） |
| **文字式** | $\text{容器容积}_{\text{【m³】}}=\dfrac{\text{每小时处理物料体积}_{\text{【m³/h】}}\times\text{停留时间}_{\text{【h】}}\times(1+\text{备用系数})}{\text{装料系数}\times\text{台数}}$ |  |

（`#L5909-#L5911`）

## 两个系数的取法

| 系数 | 取值 | 说明 |
|:---|:---|:---|
| 备用系数 $\eta$ | 0.1~0.15 | 一般取 0.1~0.15 |
| 装料系数 $\phi$ | 0.6~0.85 | 起泡或沸腾状态取低值 0.6~0.7；平稳或高黏物料取 0.8~0.85 |

（`#L5899-#L5901`）

## 台数与容积的权衡

一定产量下 $V$ 与台数 $m$ 有多种组合；应先从**设备投资与日常生产费用**综合经济性出发确定 $V$，再定 $m$（`#L5913`）。

## 判断

装料系数是"安全裕量"与"有效容积"的折中：取高值省设备费但易溢料、传热面积偏紧；取低值稳妥但体积利用率低。原文把"是否起泡/沸腾"作为分档依据，这比按物料黏度分档更接近实际——泡沫体积能轻易占去 30% 以上。

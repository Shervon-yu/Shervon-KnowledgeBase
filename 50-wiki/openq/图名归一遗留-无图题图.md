# 图名归一遗留-无图题图

**本页记录的问题已于 2026-11-17 清零**，保留页面是为了记住命名口径与走过弯路。

## 结论（2026-11-17）

- 化工原理 426 图、机械密封 319 图，全部为可读名，**0 张**页码式名（`图_第NN页_n.jpg` 已绝迹）。其中 5 张原是二维码（书中补充材料扫码入口，153x153 的方形图），命名 `二维码-第NN页.jpg`。
- check-links：化工原理 426/426、机械密封 319/319，unresolved=0。

## 四轮做法与结果

1. 新解析重建后，281（化工原理）/ 232（机械密封）张有图题，直接命名 `图X.Y 说明.jpg`。
2. 余 231 张（化工原理 145、机械密封 86）只拿到页码式名 `图_第NN页_n.jpg`。
3. 曾试「按正文图号配对」：231 张里 121 张可配，但抽查发现图号常指向同页另一张图（图2-1 与图2-2 混挂）——会编造，废弃。
4. 改「挂同页图题」：一个图被拆成多块时，无图题块挂到同页图题名下加 `-a/-b/-c`（160 张）。剩 71 张再按上下文人工定名：
   - 习题图 → `习题X-Y附图`（如 `习题1-6附图.jpg`）；
   - 附录共线图 → `液体黏度共线图`、`气体热导率共线图` 等；
   - 子图 → `图3-28 套筒密封结构-a`、`图3-29 迷宫密封结构-b`；
   - 页图 → `封面`、`封底`；
   - OCR 残片（挡圈尺寸表）→ `表5-28 孔用YX形密封圈挡圈-1`；
   - 方形小图（153×153）多为书中二维码 → `二维码-第NN页`（不冒充图题）。

## 命名口径（后续新书沿用）

- 有图号：`图X.Y 说明.jpg`；同图多块依次 `-a`、`-b`。
- 无图号但有上下文可判：用上下文名（`习题X-Y附图`、`附录 见标题名`）。
- 完全无依据：仍按 `图_第NN页_n.jpg`，并在本页登记——宁可页码式，不编造图号。

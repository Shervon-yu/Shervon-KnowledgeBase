# 内压圆筒的计算

适用范围：$K\le1.5$ 或 $p_c\le0.4[\sigma]^t\varphi$（`#L5110`），$K=D_o/D_i$。

## 计算厚度（式5-1、5-2）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta=\dfrac{p_cD_i}{2[\sigma]^t\varphi-p_c}$；$\quad \delta=\dfrac{p_cD_o}{2[\sigma]^t\varphi+p_c}$ | （5-1）（5-2） |
| **文字式** | $\text{计算厚度}_{\text{【mm】}}=\dfrac{\text{计算压力}_{\text{【MPa】}}\times\text{内直径}_{\text{【mm】}}}{2\times\text{许用应力}_{\text{【MPa】}}\times\text{焊接接头系数}-\text{计算压力}}$；以外径为基准时分母改加 |  |

两式等价（$D_o=D_i+2\delta_n$），以内径为准更常用。

## 环向应力校核（式5-3~5-5）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_\theta^t=\dfrac{p_c(D_i+\delta_e)}{2\delta_e}$；$\quad \sigma^t\le[\sigma]^t\varphi$ | （5-3）（5-5） |
| **文字式** | $\text{环向应力}_{\text{【MPa】}}=\dfrac{\text{计算压力}\times(\text{内直径}+\text{有效厚度})}{2\times\text{有效厚度}}$，且不大于许用应力乘焊接接头系数 |  |

## 多层包扎与套合圆筒（式5-6）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[\sigma]^t\varphi=\dfrac{\delta_i}{\delta_n}[\sigma_i]^t\varphi_i+\dfrac{\delta_o}{\delta_n}[\sigma_o]^t\varphi_o$，$\varphi_i=1.0$、$\varphi_o=0.95$ | （5-6） |
| **文字式** | $\text{折算许用应力}=\dfrac{\text{内筒名义厚度}\times\text{内筒许用应力}\times1.0+\text{层板总厚度}\times\text{层板许用应力}\times0.95}{\text{总名义厚度}}$ |  |

## 最大允许工作压力（式5-7、5-8）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[p_w]=\dfrac{2\delta_e[\sigma]^t\varphi}{D_i+\delta_e}$；$\quad [p_w]=\dfrac{2\delta_e[\sigma]^t\varphi}{D_o-\delta_e}$ | （5-7）（5-8） |
| **文字式** | $\text{最大允许工作压力}_{\text{【MPa】}}=\dfrac{2\times\text{有效厚度}\times\text{许用应力}\times\text{焊接接头系数}}{\text{内直径}+\text{有效厚度}}$ |  |

## 判断

- 分母的 $-p_c$（或 $+p_c$）项是厚壁修正：$p_c$ 相对 $[\sigma]^t\varphi$ 很小时可忽略，但 $p_c\approx0.4[\sigma]^t\varphi$ 时误差已不可忽略，故标准把适用范围卡在 $K\le1.5$；
- 有效厚度 $\delta_e=\delta_n-C$（$C$ 为腐蚀裕量与厚度负偏差之和），**代入公式用的是 $\delta$（计算厚度）与 $\delta_e$（有效厚度），不要混**；
- 式5-5 中 $\sigma_\theta^t$ 是环向应力，圆筒的轴向应力只有一半，强度由环向控制——这就是为什么纵缝是 A 类、最危险。

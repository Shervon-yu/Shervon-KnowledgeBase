# 沉降速度

## 自由沉降（`#L4631-#L4633`）

单个颗粒在流体中沉降，或颗粒群分散良好、互不接触碰撞地沉降，称**自由沉降**（free settling）。

## 两段过程（`#L4635-#L4657`）

颗粒密度 $\rho_p>\rho$ 时受三力：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_g=\dfrac{\pi}{6}d_p^3\rho_pg,\qquad F_b=\dfrac{\pi}{6}d_p^3\rho g,\qquad F_d=\zeta\dfrac{\pi d_p^2}{4}\dfrac{\rho u^2}{2}$ | （3-6）（3-7）（3-8） |
| **文字式** | $\text{重力}=\dfrac{\pi}{6}\times\text{粒径}^3\times\text{颗粒密度}\times g$；$\text{浮力}$ 同形但用流体密度；$\text{阻力}=\text{阻力系数}\times\text{投影面积}\times\dfrac{\text{密度}\times\text{速度}^2}{2}$ |  |

牛顿第二定律：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_g-F_b-F_d=m\dfrac{\mathrm{d}u}{\mathrm{d}\tau}$ | （3-9） |
| **文字式** | $\text{重力}-\text{浮力}-\text{阻力}=\text{质量}\times\text{加速度}$ |  |

代入三力并整理：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{d}u}{\mathrm{d}\tau}=\left(\dfrac{\rho_p-\rho}{\rho_p}\right)g-\dfrac{3\zeta\rho}{4d_p\rho_p}u^2$ | （3-10） |
| **文字式** | $\text{加速度}=(\text{密度差项})\times g-\dfrac{3\times\text{阻力系数}\times\text{流体密度}}{4\times\text{粒径}\times\text{颗粒密度}}\times\text{速度}^2$ |  |

右边第一项与 $u$ 无关，第二项随 $u$ 增大而增大 → $u$ 增大、加速度减小 → 到 $u_t$ 时加速度为零、转为**匀速沉降**。

两阶段：**加速段**（小颗粒极短，可忽略）+ **匀速段**，匀速段速度即沉降速度/终端速度 $u_t$。

## 通用式（`#L4659-#L4665`）

令 $\mathrm{d}u/\mathrm{d}\tau=0$、$u=u_t$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\sqrt{\dfrac{4gd_p(\rho_p-\rho)}{3\zeta\rho}}$ | （3-11） |
| **文字式** | $\text{沉降速度}_{\text{【m/s】}}=\sqrt{\dfrac{4\times g\times\text{粒径}\times(\text{颗粒密度}-\text{流体密度})}{3\times\text{阻力系数}\times\text{流体密度}}}$ |  |

## 三分区公式（`#L4667-#L4679`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\dfrac{gd_p^2(\rho_p-\rho)}{18\mu}$ | （3-12） |
| **文字式** | $\text{沉降速度}=\dfrac{g\times\text{粒径}^2\times(\text{颗粒密度}-\text{流体密度})}{18\times\text{流体黏度}}$ |  |

（3-12）即**斯托克斯式/斯托克斯定律**，适用 $Re<2$。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\left[\dfrac{4g^2(\rho_p-\rho)^2}{225\mu\rho}\right]^{1/3}d_p$ | （3-13） |
| **文字式** | $\text{过渡区沉降速度}=\left[\dfrac{4\times g^2\times(\text{密度差})^2}{225\times\text{黏度}\times\text{密度}}\right]^{1/3}\times\text{粒径}$ |  |

适用 $2<Re<500$，$u_t\propto d_p$。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_t=\sqrt{3.03g(\rho_p-\rho)d_p/\rho}$ | （3-14） |
| **文字式** | $\text{湍流区沉降速度}=\sqrt{\dfrac{3.03\times g\times(\text{密度差})\times\text{粒径}}{\text{流体密度}}}$ |  |

适用 $500<Re<2\times10^5$，$u_t\propto\sqrt{d_p}$。

## 规律与推论（`#L4679`）

- $d_p$、$\rho_p$ 越大 → $u_t$ 越大；
- 层流区与过渡区 $u_t$ 还受黏度影响：液体黏度约为气体的 50 倍，故**同粒径颗粒在液体中的沉降速度远小于在气体中**。

## 判断

- 三个区对 $d_p$ 的依赖不同（$d_p^2$／$d_p$／$\sqrt{d_p}$），这正是"大颗粒在气体中容易沉降、微细颗粒极难沉降"的定量来源。
- 实际计算必须先假定区、算出 $u_t$ 再算 Re 校核，不符则重设——这是本章第一个"试差"环节。

# 湿空气的比体积与比热容

## 湿比体积（`#L13803-#L13819`）

定义：湿空气体积 / 干气质量，单位 m³ 湿气/kg 干气。

1 kg 干气对应的总物质的量：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $n_g+n_v=\dfrac{1}{M_g}+\dfrac{H}{M_v}$ | （7-9） |
| **文字式** | $\text{总物质的量}=\dfrac{1}{\text{干气摩尔质量}}+\dfrac{\text{湿度}}{\text{水汽摩尔质量}}$ |  |

理想气体、总压 $p$（kPa）、温度 $T$（K）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $v_H=22.41\left(\dfrac{1}{M_g}+\dfrac{H}{M_v}\right)\dfrac{T}{273}\cdot\dfrac{101.33}{p}$ | （7-10） |
| **文字式** | $\text{湿比体积}=22.41\times\left(\dfrac{1}{\text{干气摩尔质量}}+\dfrac{\text{湿度}}{\text{水汽摩尔质量}}\right)\times\dfrac{\text{温度}_{\text{【K】}}}{273}\times\dfrac{101.33}{\text{总压}_{\text{【kPa】}}}$ |  |

代入常数得：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $v_H=(0.774+1.244H)\dfrac{T}{273}\cdot\dfrac{101.33}{p}$ | （7-11） |
| **文字式** | $\text{湿比体积}=(0.774+1.244\times\text{湿度})\times\dfrac{\text{温度}_{\text{【K】}}}{273}\times\dfrac{101.33}{\text{总压}_{\text{【kPa】}}}$ |  |

## 湿比热容（`#L13821-#L13831`）

定义：湿度 $H$ 的湿空气升温 1 K 所需热量（以 1 kg 干气为基准），kJ/(kg 干气·K)。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $c_H=c_g+c_vH$ | （7-12） |
| **文字式** | $\text{湿比热容}=\text{干气比热容}+\text{水汽比热容}\times\text{湿度}$ |  |

273~393 K 取 $c_g$=1.01、$c_v$=1.88：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $c_H=1.01+1.88H$ | （7-13） |
| **文字式** | $\text{湿比热容}=1.01+1.88\times\text{湿度}$ |  |

湿比热容**只随湿度变化**，与温度无关（在给定温度区间内）。

## 判断

- 0.774 与 1.244 是"1 kg 干气 + H kg 水汽"在标准状况下的体积系数；0.774=22.41/28.95，1.244=22.41/18.02。
- $c_H$ 与 $t$ 无关这一条很关键：它让干燥器的热量衡算可以写成线性式，否则必须积分。
- 高压下 $v_H$ 必须带 $101.33/p$ 修正；常压干燥可省略。

# 蒸气冷凝与沸腾传热

## 一、蒸气冷凝（`#L6432-#L6572`）

### 两种冷凝方式

- **膜状冷凝**：冷凝液润湿壁面，形成连续液膜，靠重力下流，越往下越厚；蒸气在液膜表面冷凝，热量经液膜导热+对流到壁面。附着力 > 表面张力时形成。
- **滴状冷凝**：冷凝液聚成液滴滚落，露出壁面，热阻小，$\alpha$ 可比膜状高 **5~10 倍**。

原文明确：持久滴状冷凝难以实现，工业冷凝器按膜状冷凝计算更安全可靠。

### 水平管外（`#L6444-#L6454`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=0.725\left(\dfrac{\rho^2g\lambda^3r}{n^{2/3}\mu d_o\Delta t}\right)^{1/4}$ | （4-27） |
| **文字式** | $\text{冷凝传热系数}=0.725\times\left(\dfrac{\text{液密度}^2\times g\times\text{热导率}^3\times\text{比汽化热}}{\text{垂直列管数}^{2/3}\times\text{黏度}\times\text{管外径}\times\text{温差}}\right)^{1/4}$ |  |

- $r$ 取饱和温度 $t_s$ 下的比汽化热；$n$ 为垂直列上的管数，单根管 $n=1$；
- 定性温度取膜温 $(t_s+t_w)/2$，特征尺寸取管外径 $d_o$。

### 垂直管外/板（`#L6456-#L6478`）

液膜层流（$Re<1800$）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=1.13\left(\dfrac{\rho^2g\lambda^3r}{\mu l\Delta t}\right)^{1/4}$ | （4-28） |
| **文字式** | $\text{冷凝传热系数}=1.13\times\left(\dfrac{\text{液密度}^2\times g\times\text{热导率}^3\times\text{比汽化热}}{\text{黏度}\times\text{壁面高度}\times\text{温差}}\right)^{1/4}$ |  |

液膜湍流（$Re>1800$）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=0.0077\left(\dfrac{\rho^2g\lambda^3}{\mu^2}\right)^{1/3}Re^{0.4}$ | （4-29） |
| **文字式** | $\text{冷凝传热系数}=0.0077\times\left(\dfrac{\text{液密度}^2\times g\times\text{热导率}^3}{\text{黏度}^2}\right)^{1/3}\times\text{雷诺数}^{0.4}$ |  |

特征尺寸 $l$ 取垂直管长或板高；式(4-29)的 $\alpha$ 是含层流段在内的全高平均值。计算时先假设流型、算完再验 $Re$。

### 液膜 Re（`#L6480-#L6512`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Re=\dfrac{4\alpha l\Delta t}{r\mu}$ | （4-32） |
| **文字式** | $\text{液膜雷诺数}=\dfrac{4\times\text{冷凝传热系数}\times\text{壁面高度}\times\text{温差}}{\text{比汽化热}\times\text{黏度}}$ |  |

推导链：$Re=4(q_m/\Pi)/\mu$（4-30）→ $q_m/\Pi=\alpha l\Delta t/r$（4-31）→ 代入得(4-32)。

### 例4-10（`#L6514-#L6554`）

120 ℃ 饱和水蒸气、管外径 60 mm、长 1 m、壁温 100 ℃：$r=2205$ kJ/kg，膜温 110 ℃，$\rho=951$、$\lambda=0.685$、$\mu=25.9\times10^{-5}$，$\Delta t=20$。

1. 垂直放置（假设层流）：$\alpha=1.13(\rho^2g\lambda^3r/(\mu l\Delta t))^{1/4}=6670$ W/(m²·K)；验 $Re=4\alpha l\Delta t/(r\mu)=934<1800$ 层流成立；
2. 临界高度：$Re=1800$ → $l_c=(1800/(1.13\times4))^{4/3}\times\frac{r}{\Delta t\lambda}(\mu^5/(\rho^2g))^{1/3}=2.397$ m，$\alpha_c=5360$（也可用 $\alpha_c=\alpha(l/l_c)^{1/4}$ 直接缩放）；
3. 水平放置：$\alpha'/\alpha=(0.725/1.13)(l/d_o)^{1/4}=1.3$ → $\alpha'=8671$ W/(m²·K)。

**结论：水平放置的冷凝传热系数高于垂直放置**（长 1 m 的管约为 1.3 倍）。

### 影响冷凝的因素（`#L6556-#L6572`）

1. **不凝性气体**：在液膜表面形成气膜，热阻大——含量 1% 时 $\alpha$ 可降低约 **60%**，故冷凝侧必须设排气口；
2. **蒸气流速与流向**：水蒸气 $u>10$ m/s 时黏滞摩擦力显著；向下流加速液膜、减薄膜厚、$\alpha$ 增大；速度很大时液膜被吹离壁面、传热进一步增强；
3. **过热**：冷凝温差仍为 $t_s-t_w$；误差约 3% 可忽略，但 $r$ 应改为 $r'=r+c_p(t_v-t_s)$；
4. **传热面形状**：纵槽面（凝液顺槽流下）$\alpha$ 可提高约 4 倍；水平管束减少垂直列数、改错列可提高 $\alpha$。

## 二、液体沸腾（`#L6572-#L6628`）

### 现象与汽化核心

$\Delta t=t_w-t_s$ 为壁面过热度，是气泡生成与成长的条件；壁面粗糙小坑残留气体成为**汽化核心**，过热度越大气泡越多。气泡长大到浮力大于附着力即脱离上浮——沸腾时液体被剧烈扰动，故同一液体沸腾 $\alpha$ 远大于无相变时。

### 沸腾曲线（`#L6586-#L6602`）

常压水 $q$–$\Delta t$ 关系分段：

| 段 | 区间 | 现象 | $\alpha$ 趋势 |
|:---|:---|:---|:---|
| AB 自然对流区 | $\Delta t\le5$ K | 少量气泡不脱离，靠自然对流，蒸发表面进行 | 略增 |
| BC 核状沸腾区 | 5 K < $\Delta t$ < $\Delta t_c$ | 汽化核心增多，气泡剧烈搅拌液体 | 迅速增大 |
| CD 过渡段 | — | 气泡连成气膜覆盖壁面，气膜热阻大 | 急剧下降 |
| D 以后 膜状沸腾 | — | 壁面全被气膜覆盖，辐射传热比重增大 | 又回升，但低于核状 |

**临界点 C**：核状→膜状的转变点。$\Delta t_c\approx25$ K（常压水）、$q_c\approx1.25\times10^6$ W/m²。工业操作必须控制在核状沸腾区、$\Delta t\le\Delta t_c$；超过则 $\alpha$ 骤降且壁温过高可能**烧毁**，故 C 点又称**烧毁点**。

### 影响因素（`#L6604-#L6628`）

- **物性**：$\lambda$、$\rho$ 增大，$\mu$、表面张力减小 → 有利于沸腾；
- **温差**：核状区 $\alpha=C\Delta t^m$；
- **操作压力**：提高压力（提高饱和温度）使黏度与表面张力下降，同样 $\Delta t$ 下 $\alpha$ 增大；水在 $10^5\sim4\times10^6$ Pa 有经验式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=0.123\Delta t^{2.33}p^{0.5}$ | （4-33） |
| **文字式** | $\text{沸腾传热系数}=0.123\times\text{过热度}^{2.33}\times\text{绝对压力}^{0.5}$ |  |

- **加热面状况**：清洁无油 $\alpha$ 高；粗糙面汽化核心多、可强化。

原文说明：核状沸腾关联式虽多但结果相差很大，**无可靠通用式**，重要场合应实测。

## 三、选用关联式的五条注意（`#L6630-#L6658`）

1. 按传热问题类型选式；
2. 注意适用范围、特征尺寸、定性温度；
3. 注意单位（纯经验式必须按公式要求单位）；
4. 用指数大小判断各量对 $\alpha$ 的影响强弱；
5. $\alpha$ 的大致量级（表4-5，W/(m²·K)）：空气自然 5~25、空气强制 30~300、水自然 200~1000、水强制 1000~8000、有机液体强制 500~1500、水蒸气冷凝 5000~15000、有机蒸气冷凝 500~3000、水沸腾 1500~30000、有机物沸腾 500~15000。

规律：液体 > 空气；水 > 有机液体；有相变 > 无相变。

## 判断

- 例4-10 的"水平优于垂直"是设计冷凝器时优先横管的定量依据；但水平管束越往下液膜越厚、$n^{1/4}$ 会抵消一部分收益，这正是"减少垂直列数、改错列"的动机。
- 烧毁点的工程含义是：沸腾传热不能靠"加大温差"无限强化，越过 C 点后系统进入负反馈区（$\alpha$ 下降→壁温更高→膜更厚），这是换热器设计必须设 $\Delta t$ 上限的原因。

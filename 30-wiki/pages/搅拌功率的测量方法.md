# 搅拌功率的测量方法

搅拌功率只能靠实测校准：文献关联式的常数都来自实验，几何或物料一变就要重测。

## 反扭矩法（小规模）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=2\pi NmgR$ | （3-42） |
| **文字式** | $\text{搅拌功率}_{\text{【W】}}=2\pi\times\text{转速}_{\text{【1/s】}}\times\text{砝码质量}_{\text{【kg】}}\times9.81\times\text{力臂}_{\text{【m】}}$ |  |

（`#L3537`；$m$ kg、$R$ 力臂 m、$g=9.81$ m/s²）

原理：电机定子与转子所受电磁力矩大小相等、方向相反（`#L3535`）。把釜体（或定子）用轴承浮动支撑、以力臂砝码平衡反扭矩，即可由砝码读出扭矩，再乘 $2\pi N$ 得功率。

适用：实验室小规模、几十升至几百升；优点是直接、无需标定电机效率。缺点：需浮动安装、摩擦与密封干扰要扣除；大功率时力臂与砝码笨重。

## 应变法（大功率）

在搅拌轴（或联轴器）上贴 4 片 45° 应变片组成电桥，测轴受扭时的应变量，标定后换算扭矩与功率（`#L3559-#L3565`）。

要点：

1. 应变片布置须对称于轴线、45° 方向，抵消弯扭分离；
2. 必须**扣除空载摩擦功率**（填料函/机械密封、轴承）——空载值随转速与介质压力变（`#L3565`）；
3. 适合工业规模，信号可滑环或遥测引出。

## 功率计谱系

文献功率数据互相不符，首要原因是各家自制的功率计不同、静摩擦量级不同（`#L712`、`#L714`）。按测点分三类（`#L716`）：

| 类别 | 测什么 | 代表 | 主要缺陷 |
|:---|:---|:---|:---|
| 电机输入功率法 | 电机有效输入（扣铜损/铁损/空载） | 换向器电机（`#L718`） | 难以精确扣除各项损失 |
| 转矩法 | 釜体或定子上的反扭矩 | 浮动转台+砝码（`#L724`）、电机反馈转矩（`#L728`） | 支撑轴承摩擦混入 |
| 转矩功率计法 | 轴上的扭矩（弹簧/应变片） | 螺旋弹簧、涡卷弹簧、应变片、差动齿轮（`#L736`~`#L746`） | 读数受静摩擦锁定 |

永田自制的三种：1号（反馈转矩式）、2A号（电感仪测两盘角位移，$T_{s}=10\sim20$ g·cm，均值 15）、2B号（滑线电阻式，$T_{s}=150\sim200$ g·cm，均值 175，专为比较静摩擦误差而做）、3号（钻石轴承支承 + 频闪读数，$T_{s}\approx1$ g·cm，量程小，用于推进式小功率）（`#L762`~`#L796`）。

## 静摩擦误差：核心判据

搅拌启动时转矩很大、随涡旋建立而下降，指针因静摩擦停在偏高位置（读数 $T_{h}$）；稳态时人为短暂加速再放手，指针会停在偏低位置（读数 $T_{1}$）；真值取平均 $T_{0}$（`#L836`、`#L861`）。把 $\left(T_{h}-T_{0}\right)/T_{0}\times100$ 对 $T_{0}/T_{s}$ 标绘得到误差曲线（原书图1.11），结论：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $T_{0}\ge20\,T_{s}$ | （§1.2.4 判据） |
| **文字式** | $\text{真值转矩}_{\text{【g·cm】}}\ge20\times\text{静摩擦转矩}_{\text{【g·cm】}}$ |  |

- 电感仪式（$T_{s}=15$ g·cm）：测得转矩 > $300$ g·cm 即准（`#L867`）。
- 滑线电阻式（$T_{s}=175$ g·cm）：须大于 $T_{s}$ 的 100~150 倍，即 $1.75\times10^{4}\sim2.63\times10^{4}$ g·cm 才可靠（`#L869`）。
- 实测转折点（表1.2）$T_{f}=2500\sim4700$ g·cm，约为 $T_{s}$ 的 20 倍，与判据自洽（`#L832`）。

工程含义：低转速、小桨、低黏工况的转矩本就只有几百 g·cm，用静摩擦大的功率计必然系统性偏高——这正是早期文献 $N_{p}$ 曲线在低 $Re$ 段分散的主因。另一个误差源是空载动摩擦（填料、轴承、滑环），必须在观测值中扣除空载值（`#L802`、`#L808`）。

## 弗鲁德数要不要修正

Rushton 等用 $\left(dn^{2}/g\right)\left(a-\log Re\right)/b$ 解释 Fr 对 $N_{p}$ 的影响（`#L935`）。永田用静摩擦极小的功率计重测各类叶轮，$N_{p}$–$Re$ 基本落在一条曲线上，**工程精度下可略去 Fr 修正**（`#L937`、`#L973`）。

例外：容器内存在自由表面变形时 Fr 不能忽略。用 $d=0.9D$ 的大桨高速搅拌，液面变陡、液体对壁摩擦耗能显著，$N_{p}$ 偏离曲线（`#L943`、`#L945`）。故"要不要修 Fr"取决于液面变形程度，而非一律修正。

## 选型口径

| 场合 | 首选 |
|:---|:---|
| 实验室、<几百 L、需快速换桨 | 反扭矩法 |
| 工业釜、>几十 kW、轴系已定 | 应变法 |
| 现场无拆轴条件 | 电功率法（量电机输入、乘效率），误差大，只作量级核对 |

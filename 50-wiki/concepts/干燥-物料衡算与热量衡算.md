# 干燥-物料衡算与热量衡算

## 定义

干燥的**物料衡算**以绝干物料为基准：湿物料中水分质量与绝干物料质量之比称**干基含水量** $X$，与**湿基含水量** $w$ 可互换（式 7-23~7-25，#L14131、#L14135、#L14143）。**空气用量**由水分蒸发量与空气湿度增量决定（式 7-27、7-28，#L14165、#L14171）。**热量衡算**把预热器加入的热量与干燥器内各项热支出配平（式 7-32、7-32a，#L14243、#L14247）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $X=\dfrac{w}{1-w}$，$w=\dfrac{X}{1+X}$ | （7.3-1） |
| **文字式** | $\text{干基含水量}_{\text{【kg水/kg干料】}}=\dfrac{\text{湿基含水量}}{1-\text{湿基含水量}}$ |  |

（式 7-25，#L14143。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W=L_{\mathrm{c}}\left(X_{1}-X_{2}\right)=G\left(H_{2}-H_{1}\right)$ | （7.3-2） |
| **文字式** | $\text{水分蒸发量}_{\text{【kg/s】}}=\text{绝干物料流量}_{\text{【kg/s】}}\times\left(\text{初含水量}-\text{终含水量}\right)_{\text{【kg水/kg干料】}}$ |  |

（式 7-27，#L14165；$L_{\mathrm{c}}$ 为绝干物料流量，$G$ 为绝干空气流量，$H$ 为空气湿度。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $G=\dfrac{W}{H_{2}-H_{1}}$ | （7.3-3） |
| **文字式** | $\text{绝干空气用量}_{\text{【kg/s】}}=\dfrac{\text{水分蒸发量}_{\text{【kg/s】}}}{\text{出干燥器空气湿度}-\text{进干燥器空气湿度}}$ |  |

（式 7-28，#L14171；单位空气用量 $G/W=1/(H_{2}-H_{1})$，式 7-29，#L14175。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q_{\mathrm{P}}=G\left(I_{1}-I_{0}\right)$ | （7.3-4） |
| **文字式** | $\text{预热器热负荷}_{\text{【kW】}}=\text{绝干空气流量}_{\text{【kg/s】}}\times\left(\text{预热后焓}-\text{预热前焓}\right)_{\text{【kJ/kg干空气】}}$ |  |

（式 7-30，#L14219；空气焓 $I=(1.01+1.88H)t+2490H$ 见 [[干燥-湿空气性质]]。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $G\left(I_{1}-I_{2}\right)=L_{\mathrm{c}}\left(I_{2}^{\prime}-I_{1}^{\prime}\right)+Q_{\mathrm{D}}$ | （7.3-5） |
| **文字式** | $\text{空气放出焓}=\text{物料带走焓}+\text{干燥器补充热}_{\text{【kW】}}$ |  |

（式 7-32a，干燥器本身的热衡算，#L14247；湿物料焓 $I^{\prime}=c_{s}\theta+Xc_{w}\theta$，式 7-31，#L14237。）

## 适用范围与边界

- 式 7-27、7-28 的前提是**绝干物料流量守恒**（$L_{c}$ 不变，只失去水）（#L14153 的式 7-26）。
- 式 7-32a 里 $Q_{D}$ 为干燥器内补充热量（如内置换热器），绝热干燥时 $Q_{D}=0$，等焓过程 $I_{1}=I_{2}$（#L14247 后文）。
- 计算水分蒸发量、空气用量只需物料/空气衡算，与干燥速率无关；干燥时间另算（#L14485 起）。
- 本书未给干燥器热损失的通用系数，实际设计需给定散热损失率。

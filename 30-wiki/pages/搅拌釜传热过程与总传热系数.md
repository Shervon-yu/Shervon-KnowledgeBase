# 搅拌釜传热过程与总传热系数

## 传热方式与元件

搅拌设备传热最常用整体夹套；在此基础上发展了型钢夹套、半管夹套、蜂窝夹套、激光焊接式蜂窝夹套。几何相似放大时，单位体积对应的传热面与釜内径成比例减小；夹套面积不够时可在釜内设盘管（横向或纵向，也可替代挡板）（`#L3197`）。具体结构见第七章 §7.1。

## 五个串联环节

热量从被搅液传到热载体，依次经过（`#L3199`）：

1. 被搅液对传热面的对流传热；
2. 多层固体（釜壁、垢层）的热传导；
3. 传热面对热载体的对流传热；
4. 被搅液侧污垢热阻；
5. 热载体侧污垢热阻。

## 总传热方程

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=KA\Delta T$ | （3-8） |
| **文字式** | $\text{热流量}_{\text{【W】}}=\text{总传热系数}_{\text{【W/(m²·K)】}}\times\text{传热面积}_{\text{【m²】}}\times\text{被搅液与热载体温差}_{\text{【K】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{1}{K}=\dfrac{1}{\alpha_1}+\sum_{i=1}^{n}\dfrac{\delta_i}{\lambda_i}+\dfrac{1}{\alpha_2}\dfrac{A}{A_2}+R_{S1}+R_{S2}$ | （3-9） |
| **文字式** | $\dfrac{1}{\text{总传热系数}}=\dfrac{1}{\text{被搅液侧表面传热系数}}+\sum_{i=1}^{n}\dfrac{\text{第 i 层壁厚}_{\text{【m】}}}{\text{第 i 层热导率}_{\text{【W/(m·K)】}}}+\dfrac{1}{\text{热载体侧表面传热系数}}\times\dfrac{\text{传热面积}_{\text{【m²】}}}{\text{热载体侧传热面积}_{\text{【m²】}}}+\text{被搅物料侧污垢热阻}_{\text{【(m²·K)/W】}}+\text{热载体侧污垢热阻}_{\text{【(m²·K)/W】}}$ |  |

釜壁作传热面时，釜壁厚度相对釜径很小，两侧面积相差不大，$A/A_2\approx1$（`#L3231`）。

## 控制项

通常**表面传热系数是传热阻力的控制项**，而混合搅拌对釜内侧表面传热系数影响较大，所以选一个合适的搅拌器非常重要（`#L3233`）。

## 原书 §10.5.3：同一功率下三类传热元件的实测排序

《混合原理与应用》§10.5.3 给出一张横向比较表（表10.7，`#L11488`），把**恒功率**下三种传热元件的搅拌侧系数、可用面积、热载体侧内膜系数统一成相对值：

| 元件 | 搅拌侧系数 | 可用面积 | 冷却水内膜系数 | 蒸汽内膜系数 |
|:---|:---:|:---:|:---:|:---:|
| 蛇管 | 1.0 | 1.0 | 1.0 | 1.0 |
| 垂直管（插管） | 1.0 | 0.5 | 0.1 | 0.1 |
| 夹套 | 0.65 | 0.5 | 0.5 | 1.0 |

读法与推论（`#L11495`–`#L11517`）：

- 搅拌侧系数蛇管与垂直管相当、夹套只有 65%——因为夹套离叶轮远、贴壁流速低；
- 夹套的优势在**面积大、结构简单**，劣势在系数低；垂直管两头不占优，只在特殊布置（插管式换热）时用；
- 一旦进入强制对流区，**再加大功率对系数影响很小**——这条结论与关联式里 $Re$ 指数在水冷时变平是一致的；
- 多放蛇管前必须先加功率与流量，否则新增面积上的流速不足，系数达不到表值（`#L11503`）；
- 加热系数普遍高于冷却（蒸汽冷凝侧热阻低），夹套系数约为蛇管的 70%（`#L11511`）；
- **叶轮位置对传热影响甚微**（`#L11513`）——与"叶轮位置对混合时间影响大"形成对照；
- 黏滞流按 Coyle 法：薄膜厚度取间隙的 $1/2$，用液体热学性质即可估系数；刮板使功率翻倍，系数也约翻倍（`#L11515`）；
- 同样传热能力下，螺带的功率约为涡轮的 $1/3$，且搅拌输入的热量显著减少（`#L11517`）——这正是高黏体系用螺带的经济理由。

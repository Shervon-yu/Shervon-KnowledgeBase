# 过渡区与层流对流传热

## 过渡区（`#L6280-#L6286`）

$Re=2300\sim10000$ 时，先按湍流式(4-19)、(4-20)算 $\alpha$，再乘校正系数：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $f=1-\dfrac{6\times10^5}{Re^{1.8}}$ | （4-21） |
| **文字式** | $\text{过渡区校正系数}=1-\dfrac{6\times10^5}{\text{雷诺数}^{1.8}}$ |  |

**例4-7**：φ89×3.5 套管、内管 φ25×2.5、长 2 m，水 15→35 ℃、$u=0.4$ m/s：定性 25 ℃，$Re=8836$（过渡区）、$Pr=6.2$、$l/d=100$；$f=1-6\times10^5/8836^{1.8}=0.953$，$\alpha=0.023\times0.608/0.02\times8836^{0.8}\times6.2^{0.4}\times0.953=1981$ W/(m²·K)。

## 层流（`#L6304-#L6314`）

只有小管径、水平管、温差小、流速低时才是严格层流；其他情况常伴自然对流。

当 $Gr<2.5\times10^4$，自然对流可忽略：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Nu=1.86\left(Re\,Pr\dfrac{d}{l}\right)^{1/3}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}$ | （4-22） |
| **文字式** | $\text{努塞尔数}=1.86\times\left(\text{雷诺数}\times\text{普朗特数}\times\dfrac{\text{管内径}}{\text{管长}}\right)^{1/3}\times\left(\dfrac{\text{主体黏度}}{\text{壁温黏度}}\right)^{0.14}$ |  |

条件：$Re<2300$、$Re\,Pr\,d/l>10$；特征尺寸取内径；定性温度除 $\mu_w$ 取壁温外均取进出口平均。

当 $Gr>2.5\times10^4$，自然对流不可忽略，乘：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $f=0.8\left(1+0.015\,Gr^{1/3}\right)$ | （4-23） |
| **文字式** | $\text{自然对流校正系数}=0.8\times\left(1+0.015\times\text{格拉晓夫数}^{1/3}\right)$ |  |

**例4-8**：14 号机油在 $d=10$ mm、$l=7.7$ m 管内 0.31 m/s、90→70 ℃、壁温 20 ℃：定性 80 ℃，$Re=126$、$RePr\,d/l=52.9>10$、$Gr=632<2.5\times10^4$ 可忽略自然对流，$\alpha=1.86\times0.1431/0.01\times52.9^{1/3}\times(0.0211/0.367)^{0.14}=66.9$ W/(m²·℃)。

## 非圆形管（`#L6334-#L6340`）

仍可用上述各式，只把特征尺寸换成当量直径：

$$d_e=4\times\dfrac{\text{流体流动截面积}}{\text{润湿周边}}$$

原文说明：当量直径法简便但结果欠准确；更准的做法是用该非圆形管路专门由实验得到的关联式。

## 判断

- 过渡区用"湍流式×校正系数"而不是另建一套关联式，是因为过渡区物理上介于两者之间、数据分散大，乘一个随 $Re$ 变化的系数已足够工程使用。
- 层流式的 $(d/l)^{1/3}$ 项说明：层流传热沿程不断"发展"，管越长平均 $\alpha$ 越低——这与湍流入口段效应方向相反，是层流与湍流最重要的定性差别之一。

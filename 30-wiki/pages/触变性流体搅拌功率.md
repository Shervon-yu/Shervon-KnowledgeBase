# 触变性流体搅拌功率

## 难点

触变性流体的表观黏度既随切变速率变化、又随时间变化（`#L2000`），所以搅拌功率是时间的函数。**必须先固定计算时刻 $t_0$**——搅拌启动后经过的时间；脱离 $t_0$ 谈功率没有意义。

## Edwards 七步法

Edwards 等用番茄沙司、奶油色拉、酸乳酪、非自流性涂料等实验总结，方法本质是"冻结时刻的表观黏度 + 牛顿曲线"（`#L2002-#L2016`）：

1. 用牛顿流体的 $N_p$–$Re$ 曲线作为依据；
2. 用假塑性实验测得的 Metzner 常数 $k_s$ 算平均切变速率 $\dot{\gamma}_{\mathrm{av}}=k_sN$（式2-42）；
3. 在流变仪上测表观黏度随切变速率与时间的变化关系；
4. 由 $t_0$ 与 $\dot{\gamma}_{\mathrm{av}}$ 查出该时刻的表观黏度 $\mu_a$；
5. 算表观雷诺数（`#L2010`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re^{*}=\dfrac{d^{2}N\rho}{\mu_{a}}$ | （2-57 雷诺数） |
| **文字式** | $\text{表观雷诺数}=\dfrac{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}\times\text{密度}_{\text{【kg/m³】}}}{\text{该时刻表观黏度}_{\text{【Pa·s】}}}$ |  |

6. 在牛顿曲线上由 $Re^{*}$ 读出 $N_p$；
7. 该时刻的搅拌功率：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=N_{\mathrm{p}}\rho N^{3}d^{5}$ | （2-57） |
| **文字式** | $\text{搅拌功率}_{\text{【W】}}=\text{功率准数}\times\text{密度}_{\text{【kg/m³】}}\times\left(\text{转速}_{\text{【1/s】}}\right)^{3}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{5}$ |  |

## 前提条件

Edwards 等强调：必须选**能使全釜液体都被搅动**的搅拌器，如锚式、螺带式等 $d/D$ 较大的型式；在全釜运动的前提下，上述方法的误差在工程精度范围内（`#L2018`）。

推论：若选小直径叶轮，釜壁附近可能静止，则第 5 步的"单一表观黏度"假设失效，算出的功率偏低——这类工况不能直接用本方法。

## 与假塑性算法的差别

| 项 | 假塑性（稳态） | 触变（依时） |
|:---|:---|:---|
| 表观黏度来源 | 只随 $\dot{\gamma}$ 变 | 随 $\dot{\gamma}$ **与 $t$** 同时变 |
| 时刻 | 无需指定 | 必须指定 $t_0$ |
| 流变测量 | 一条流变曲线 | 一族随时间变化的曲线 |

触变的微观机理（等温结构可逆变化）见 [[依时性流体-触变与震凝]]。

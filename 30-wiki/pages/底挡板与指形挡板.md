# 底挡板与指形挡板

## 底挡板

装在釜底，**促进固体悬浮**、避免搅拌器下方形成颗粒堆积，一般用于固体悬浮液（`#L7807`）。

### 底部小挡板（湍流操作推荐）

| 参数 | 取值 |
|:---|:---|
| 桨径 $d$ | $0.5D$ |
| 挡板宽 $b$ | $0.1D$ |
| 高 $h_1$ | $0.05D$ |
| 宽 $w$ | $0.1D$ |
| 离底 $C$ | $0.25D$ |
| 间距 $\varepsilon$ | $0.5d$ |

（`#L7817`）

### 轻液挡板（液-液分散、分散相轻于连续相，如油分散于水）

问题：桨径太小，釜壁产生浮油；桨径太大，釜中部产生浮油。用轻液挡板可改善（`#L7817-#L7823`）。

| 参数 | 取值 |
|:---|:---|
| $d$ | $0.4D$ |
| $b$ | $0.05\sim0.1D$ |
| $B_w$ | $0.07\sim0.1D$ |
| $S_B$ | $0.5d$ |
| $e_B$ | $0.5d$ |

（`#L7823`）

## 指形挡板

形似手指，多用于**三叶后掠式搅拌器的搪玻璃釜**。优点是比板式挡板**省功率**，同时增加上下循环流；内可通冷却水兼作换热（`#L7827`）。

| 参数 | 取值 |
|:---|:---|
| 管外径 $d_0$ | $D/20$ |
| 宽度 $W_f$ | $0.1D$ |
| 厚度 $X_f$ | $0.04D$ |
| 间距 $S_f$ | $0.2D$ |
| 长度 $L_f$ | $0.17D$ |
| 与内壁间距 $S_b$ | $0.1D$ |
| 离底距离 $C$ | $0.44D$ |
| 管下端突出长度 $L$ | $0.06D$ |

（`#L7829`）

## 判断

指形挡板"省功率"的原因与它为什么常用于搪玻璃釜是同一个：搪玻璃釜的桨多为三叶后掠、转速不低，板式挡板会把功率推高；指形挡板迎流面积小、又能通冷却水，换热面积不够时它一物两用。但它的挡板效率也低，只适合本就湍动足够的体系。

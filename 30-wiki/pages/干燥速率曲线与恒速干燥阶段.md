# 干燥速率曲线与恒速干燥阶段

## 干燥速率的定义（`#L14477-#L14481`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $u=\dfrac{\mathrm{d}W}{A\,\mathrm{d}\tau}$ | （7-33） |
| **文字式** | $\text{干燥速率}=\dfrac{\text{汽化水分量}}{\text{干燥面积}\times\text{时间}}$ |  |

用绝干料表示：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $u=-\dfrac{L_c\,\mathrm{d}X}{A\,\mathrm{d}\tau}$ | （7-34） |
| **文字式** | $\text{干燥速率}=-\dfrac{\text{绝干料质量}\times\text{干基含水量变化}}{\text{干燥面积}\times\text{时间}}$ |  |

单位 kg/(m²·s)。负号因 $X$ 随时间减小。

## 曲线形状（`#L14507`）

恒速段 $u$ 为水平线；到 $X_c$ 后折向下，降速段呈凹曲线（受结构/形状/尺寸影响）；到 $X^{*}$ 时 $u\to0$。

## 恒速阶段为什么恒速（`#L14499-#L14505`）

表面有连续水膜 → 表面温度 = 空气湿球温度 $t_w$ → 传热推动力 $(t-t_w)$ 与传质推动力 $(H_w-H)$ 恒定 → 速率恒定。属于**表面汽化控制**：速率与物料性质关系小。

## 影响恒速段的三个因素（`#L14501-#L14505`）

1. **空气状态**：提温、降湿增大两个推动力；
2. **气流速度**：提高流速可增大对流传热系数 $\alpha$ 与对流传质系数 $k_H$（$u_c\propto \sqrt{u}$ 量级）；
3. **接触方式**：物料分散悬浮于气流中最佳，气流穿过物料层次之，掠过料面最差——因为后者有效传热传质面积只是料面。

## 恒速阶段干燥时间（`#L14513`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\tau_1=\dfrac{L_c}{A u_c}\,(X_1-X_c)$ | （7-35） |
| **文字式** | $\text{恒速段时间}=\dfrac{\text{绝干料质量}}{\text{干燥面积}\times\text{恒速干燥速率}}\times(\text{进料干基}-\text{临界干基})$ |  |

## 判断

- 恒速段"与物料无关"只对**非结合水**成立；一旦表面水膜消失，速率立即转入内部扩散控制（降速段）。
- 实验中 $u$ 按干燥面积计，而干燥面积在干燥中会因收缩而变，故 $A$ 取初始还是瞬时值必须说明，否则算出的 $\tau_1$ 不可比。
- 三个因素里最容易忽略的是接触方式：把同样风速用"掠过料面"改成"穿透料层"，有效面积可增大一个数量级以上。
- 提高气速对 $u_c$ 的增益小于线性（约平方根），而能耗按 $u^{1.8}$ 增长，故气速不是越大越好。

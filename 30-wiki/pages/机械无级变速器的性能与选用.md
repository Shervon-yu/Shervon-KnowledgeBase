# 机械无级变速器的性能与选用

## 一、型式与行星摩擦式的优点

机械无级变速器靠主从动件接触处的摩擦力传动，改变接触处工作半径实现无级变速（`#L9820`）。按运动形式分普通式、行星式、复合行星式；行星摩擦式的中间滚动体既自转又公转，称"行星锥（盘）"（`#L9824`）。

行星摩擦式五特点（`#L9826-#L9836`）：

| # | 特点 |
|:--:|:---|
| ① | 结构简单：6~8 个关键传动元件，紧凑、制造较易 |
| ② | 变速范围较大，传动平稳、噪声极低 |
| ③ | 驱动功率较大、承载能力较强 |
| ④ | 机械特性优越：低速恒扭矩强、高速可恒功率 |
| ⑤ | 效率 75%~94%，正常寿命 10 年以上 |

|  |  |  |

| **符号式** | $k=-\dfrac{\mathrm{d}T_2}{\mathrm{d}n_2}=\tan\alpha_A$ | （9-9） |
| **文字式** | $\text{传动刚度}=-\dfrac{\text{输出扭矩}_{\text{【N·m】}}\text{的增量}}{\text{输出转速}_{\text{【r/min】}}\text{的增量}}$ |  |

（`#L9846-#L9870`）

- **滑动率 $\varepsilon$**：几何滑动＋弹性滑动＋打滑；打滑是过载效应，弹性滑动布满全接触区即打滑（`#L9850`）。
- **传动刚度 $k$**：$k$ 大→特性"硬"，负载变化对转速影响小；$k$ 小→"软"（`#L9872`）。

### 三类机械特性（图9-19）

a. 恒功率：$P_2$ 水平、$T_2$ 与 $n_2$ 双曲线，低速时特性硬，能充分利用原动机功率；
b. 恒扭矩：$T_2$ 恒定、$k=0$，负载扭矩一旦超过就掉速甚至打滑；
c. 变功率变扭矩：规律复杂，靠试验确定（`#L9876-#L9880`）。

## 三、选用四步（`#L9886-#L9950`）

1. **类型**：按机械特性（恒功率/恒扭矩）、转速特性、安装场地（链式与宽 V 带式不宜立式安装）、操作要求（能否停车调速）选；
2. **输入转速**：多数按 1500~1800 r/min 设计；低于额定转速则传递功率减小且润滑不足，高于则搅油损失、温升、噪声增大；
3. **输出转速**：按各自功率/扭矩特性曲线确定可用区；
4. **负荷容量**：按需传功率（扭矩）选，再乘工况系数 $k_g$。

## 保护与注意（`#L9990-#L10008`）

- 启动扭矩大→电机与变速器间加电磁粉末联轴器；启动频繁→加离合器；负载变动/冲击→加飞轮或粉末联轴器；急刹车→加刹车离合器；
- 轴端悬伸量不得超限（否则损轴承、改相对位置）；变速器应放在传动链**高速段**；限制启动时间（启动扭矩常为额定 2~3 倍）；不要急剧调速；高温下油膜牵引力下降，需降容。

## 判断

式9-9 的"刚度"是这套选型里最容易被忽略的量：恒扭矩型（$k=0$）听起来简单，但它意味着负载扭矩一超额定就掉速打滑，对黏度随反应变化的聚合釜是隐患；反过来恒功率型低速段很硬，适合启动扭矩大的场合。

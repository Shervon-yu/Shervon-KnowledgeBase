# 宽面法兰的计算

宽面法兰专指用**厚度不小于 1.5 mm 非金属软垫片**、且垫片一直铺到螺栓中心圆以外的那种（图 9-13，`#L9614`）。它不能套 9.5：窄面法兰的垫片在螺栓圆以内，螺栓力全部压在垫片上；宽面法兰的垫片外伸到螺栓圆外，螺栓拉紧时**必须先在外侧把垫片压住**，否则外侧翘起、密封失效。9.8 就是为这一条额外需求写的算法。

符号除 9.8.2 单列的（$b_0'$、$b'$、$2b''$、$D_G'$、$D$、$F'$、$F_a'$、$F_T'$、$F_p'$、$F_R$）外同 9.3。$D$ = 垫片外径与法兰外径的**较小值**；$d_b$ 螺栓孔直径；$D_b$ 螺栓中心圆直径。

## 一、垫片（9.8.3，`#L9648-#L9682`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $b_0'=D-D_b$；$\quad b'=4\sqrt{b_0'}$ | （9-45）（9-46） |
| **文字式** | $\text{预紧状态垫片基本密封宽度}=\text{垫片外径与法兰外径的较小值}-\text{螺栓中心圆直径}$；$\quad\text{预紧状态垫片有效密封宽度}=4\times\sqrt{\text{预紧状态垫片基本密封宽度}}$ |  |

操作状态垫片有效宽度**取定值**：$2b''=5$ mm（`#L9664`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $D_G'=D_b-(d_b+2b'')$ | （9-47） |
| **文字式** | $\text{垫片压紧力作用中心圆直径}=\text{螺栓中心圆直径}-(\text{螺栓孔直径}+2\times\text{操作状态垫片有效密封宽度})$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_a'=\pi D_bb'y$；$\quad F_p'=2b''\pi D_G'mp_c$ | （9-48）（9-49） |
| **文字式** | $\text{预紧状态需要的垫片压紧力}=\pi\times\text{螺栓中心圆直径}\times\text{预紧状态有效密封宽度}\times\text{垫片比压力}$；$\quad\text{操作状态需要的垫片压紧力}=2\times\text{操作状态有效密封宽度}\times\pi\times\text{垫片压紧力作用中心圆直径}\times\text{垫片系数}\times\text{计算压力}$ |  |

$m$、$y$ 查表 9-2。

## 二、螺栓（9.8.4，`#L9684-#L9726`）

间距上限：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\hat{L}_{\max}=3d_B+2\delta_f$ | （9-50） |
| **文字式** | $\text{螺栓最大间距}=3\times\text{螺栓公称直径}+2\times\text{法兰厚度}$ |  |

螺栓载荷两条：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W_a=F_a'$ | （9-51） |
| **文字式** | $\text{预紧状态需要的螺栓载荷}=\text{预紧状态需要的垫片压紧力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W_p=F'+F_p'+F_R$ | （9-52） |
| **文字式** | $\text{操作状态需要的螺栓载荷}=\text{内压引起的总轴向力}+\text{操作状态需要的垫片压紧力}+\text{平衡力矩所需的轴向力}$ |  |

这里 $F_R$ 是宽面法兰的**独有项**——作用在螺栓中心圆外侧、用来平衡 $F_D$、$F_p'$、$F_T'$ 产生的力矩：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F'=\dfrac{\pi}{4}\left(D_b-d_b\right)^2p_c$；$\quad F_T'=F'-F_D$；$\quad F_R=\dfrac{F_DL_D+F_p'L_p'+F_T'L_T'}{L_R}$ |  |
| **文字式** | $\text{内压引起的总轴向力}=\dfrac{\pi}{4}\times(\text{螺栓中心圆直径}-\text{螺栓孔直径})^2\times\text{计算压力}$；$\quad\text{环形区轴向力}=\text{内压引起的总轴向力}-\text{孔盖区轴向力}$；$\quad\text{平衡力矩所需轴向力}=\dfrac{\text{孔盖区作用力}\times\text{力臂}+\text{垫片压紧力}\times\text{力臂}+\text{环形区作用力}\times\text{力臂}}{\text{外侧力臂}}$ |  |

三个力臂：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $L_T'=\dfrac{(D_b+d_b+2b'')-D_i}{4}$；$\quad L_p'=\dfrac{d_b+2b''}{2}$；$\quad L_R=\dfrac{D-(D_b+d_b)}{4}+\dfrac{d_b}{2}$ |  |
| **文字式** | 环形区力臂、垫片压紧力力臂、外侧力臂——均由螺栓中心圆、螺栓孔直径与操作状态垫片有效密封宽度组合而成 |  |

需要的螺栓面积与实际螺栓面积按 9.5.2.3（`#L9726`）。

## 三、法兰（9.8.5，`#L9728-#L9740`）

宽面法兰**不校核 $\sigma_H$、$\sigma_R$、$\sigma_T$**，直接把力矩换成厚度：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_o=F_RL_R$ | （9-53） |
| **文字式** | $\text{法兰设计力矩}=\text{平衡力矩所需轴向力}\times\text{外侧力臂}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_f=\sqrt{\dfrac{6M_o}{[\sigma]_f^t\left(\pi D_b-nd_b\right)}}$ | （9-54） |
| **文字式** | $\text{法兰厚度}=\sqrt{\dfrac{6\times\text{法兰设计力矩}}{\text{设计温度下法兰材料许用应力}\times(\pi\times\text{螺栓中心圆直径}-\text{螺栓数量}\times\text{螺栓孔直径})}}$ |  |

分母 $(\pi D_b-nd_b)$ 是"螺栓孔削弱后的环带周长"，即环形板受弯的有效宽度；$n$ 为螺栓数量。

## 判断

- 宽面法兰的一切差异都从 $F_R$ 长出来：垫片越过螺栓圆之后，螺栓力必须分一份去压外侧，于是 $W_p=F'+F_p'+F_R$ 比 9.5 多一项，设计力矩也从"三个力乘力臂求和"简化成 $M_o=F_RL_R$——因为 $F_R$ 本身就是按平衡其余力矩反算出来的，回代后 $M_o$ 只剩这一项。
- $M_o=F_RL_R$ 是个巧妙的等价式：$F_R=(F_DL_D+F_p'L_p'+F_T'L_T')/L_R$，两边乘 $L_R$ 就回到传统力矩和。标准写成前一种形式，是因为宽面法兰真正要算的是"外侧要压多大力"，$F_R$ 是设计者直接要用的量。
- 厚度公式用了 $(\pi D_b-nd_b)$ 而不是整圈周长，等于把螺栓孔当"缺口"从受弯截面里扣掉——孔越多、孔越大，法兰越厚，这与工程直觉一致。
- 宽面法兰不给 $\sigma_H$、$\sigma_R$、$\sigma_T$，是因为它的法兰环很薄、锥颈几乎没有，三个应力分量失去物理意义；标准改用一个平板弯曲的净截面弯曲应力（式 9-54 的开方形式），把 $[\sigma]_f^t$ 直接当允许弯曲应力用。
- 适用范围卡在"非金属软垫片且厚度 $\ge1.5$ mm"：软垫片才需要外侧额外压紧，金属垫片（缠绕式、金属环）自紧性强，走 9.5 的窄面算法。

# 气液相平衡在吸收中的应用

## 判断传质方向与推动力（`#L8910-#L8940`）

拿到一对接触中的气液组成 $(y,x)$，先由平衡关系算出对应值，再比较：

| 判据 | 结论 | 推动力 |
|:--|:--|:--|
| $y>y^{*}$（$y^{*}=mx$） | 吸收（气→液） | $y-y^{*}$ |
| $y<y^{*}$ | 解吸（液→气） | $y^{*}-y$ |
| $x^{*}>x$（$x^{*}=y/m$） | 吸收 | $x^{*}-x$ |
| $x^{*}<x$ | 解吸 | $x-x^{*}$ |

两种表示等价：用气相组成差或液相组成差量度同一推动力，数值不同、结论一致。相平衡曲线图上：平衡线以上的操作点 → 吸收；以下 → 解吸；落在线上 → 平衡（图5-6）。

## 两个极限浓度（`#L8942-#L8954`）

**吸收液的最大组成** $x_{1\max}$：一定量混合气（入口 $y_1$）进塔，塔无限高、吸收剂用量趋于极小，塔底吸收液组成也不会超过与 $y_1$ 平衡的液相组成：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $x_{1\max}=x_{1}^{*}$ | （5-10） |
| **文字式** | $\text{吸收液最大组成}=\text{与塔底入口气相组成平衡的液相组成}$ |  |

**尾气的最小组成** $y_{2\min}$：吸收剂用量极大、塔无限高时，塔顶尾气组成也不会低于与入口吸收剂 $x_2$ 平衡的气相组成：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y_{2\min}=y_{2}^{*}$ | （5-11） |
| **文字式** | $\text{尾气最小组成}=\text{与塔顶吸收剂入口组成平衡的气相组成}$ |  |

这两条是吸收塔设计的**天花板与地板**：液气比再大也降不到 $y_{2\min}$ 以下，液气比再小也超不过 $x_{1\max}$。

## 例5-2（`#L8956-#L8998`）

20 ℃、0.1 MPa，CO₂-空气 $y=0.1$；水溶液 $x=2\times10^{-5}$。查表5-1 得 $E=144$ MPa，故 $m=E/p=144/0.1=1440$（注意 E 用 MPa、p 用 MPa 同口径）。

- $x=2\times10^{-5}$：$y^{*}=1440\times2\times10^{-5}=0.0288<0.1$ → **吸收**，推动力 $y-y^{*}=0.0712$；液相口径 $x^{*}=0.1/1440=6.94\times10^{-5}>x$ → 吸收，推动力 $4.94\times10^{-5}$。
- $x=2\times10^{-4}$：$y^{*}=0.288>0.1$ → **解吸**，推动力 $0.188$；$x^{*}=6.94\times10^{-5}<x$ → 解吸，推动力 $1.306\times10^{-4}$。

同一股气，只因吸收液浓度从 $2\times10^{-5}$ 升到 $2\times10^{-4}$，过程就从吸收翻成解吸。

## 判断

- 判断方向只有一步：把一侧组成代进平衡式算"应有的另一侧"，再与实测比较。不要凭直觉，尤其在 m 很大（难溶气体）时，浓度差几个数量级。
- "极限浓度"不是操作值，而是平衡值：实际设计中尾气组成必须比 $y_{2\min}$ 高出一段推动力，否则所需塔高趋于无穷。这条约束会直接进入最小液气比的推导。

# 物料流变分类

## 牛顿流体的判据

切应力正比于切应变速率（或反之）即为牛顿流体（`#L1209`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=\mu\dot{\gamma}$ | （2-1） |
| **文字式** | $\text{切应力}_{\text{【Pa】}}=\text{黏度}_{\text{【Pa·s】}}\times\text{切应变速率}_{\text{【1/s】}}$ |  |

牛顿流体的黏度不随搅拌转速变化、不随位置变化（`#L1219`）。水、各种盐水溶液、甘油、饴糖在通常切变速率范围内属牛顿流体。

## 分类树

《搅拌与混合设备设计选用手册》表2-1（`#L1198-#L1205`）：

- **牛顿流体**
- **非牛顿流体**
  - 纯黏性非牛顿流体（广义牛顿流体）
    - 非依时性：宾汉塑性流体、假塑性流体、胀塑性流体
    - 依时性：触变性流体、震凝性流体
  - 黏弹性流体

## 关键性质

- 非牛顿流体的黏度是切变速率 $\dot{\gamma}$ 的函数，不同 $\dot{\gamma}$ 下黏度差异可达**三个数量级以上**（`#L1229`）。因此"某物料黏度多少"这句话，不给出对应切变速率就没有意义，见 [[搅拌剪切速率量级]]。
- 流变行为由物料结构与受力状况共同决定：同为水，通常牛顿，高速运动时可呈明显弹性（`#L1196`）。
- 理论上非牛顿流体都有黏弹性，工程上把弹性不明显的按纯黏性处理（`#L1196`）——这是"纯黏性"分类的来源，也是简化误差的来源。

## 边界

分类只描述稳态剪切下的 $\tau$–$\dot{\gamma}$ 关系；依时性与黏弹性行为需要额外的时间/法向应力数据，见 [[依时性流体-触变与震凝]] 与 [[黏弹性流体的反常流动]]。

# 支承式支座的封头许用垂直载荷

## 定义

支承式支座直接作用在容器封头上时，除支座本体强度外，还要校核封头在支座反力 F 作用下的局部应力。方法按 AD 规范 S3/3（标准椭圆封头）计算各应力分量，用应力分类法限制组合应力，迭代求出封头允许承受的最大垂直载荷 [F]（#L7383）。

## 判据与计算

### 2.1 压力引起的薄膜应力（#L7391-#7393）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{mp}}=\dfrac{pR_{\mathrm{m}}}{2\delta_{\mathrm{e}}}$ | （2-1） |
| **文字式** | $\text{封头薄膜应力}=\dfrac{\text{设计压力}\times\text{封头平均半径}}{2\times\text{封头有效厚度}}$ |  |

### 2.2 支座反力引起的平均薄膜应力（#L7395-#7399）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\bar{\sigma}_{\mathrm{mx}}=\dfrac{f_{\mathrm{mx}}F}{\delta_{\mathrm{e}}^{2}}$ | （2-2） |
| **文字式** | $\text{反力引起的 x 向平均薄膜应力}=\dfrac{\text{x 向系数}\times\text{支座反力}}{\text{封头有效厚度}^{2}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\bar{\sigma}_{\mathrm{my}}=\dfrac{f_{\mathrm{my}}F}{\delta_{\mathrm{e}}^{2}}$ | （2-3） |
| **文字式** | $\text{反力引起的 y 向平均薄膜应力}=\dfrac{\text{y 向系数}\times\text{支座反力}}{\text{封头有效厚度}^{2}}$ |  |

### 2.3 支座反力引起的弯曲应力（#L7401-#7405）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{bx}}=\dfrac{f_{\mathrm{bx}}\cdot 6F}{\delta_{\mathrm{e}}^{2}}$ | （2-4） |
| **文字式** | $\text{反力引起的 x 向弯曲应力}=\dfrac{\text{x 向弯曲系数}\times 6\times\text{支座反力}}{\text{封头有效厚度}^{2}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{by}}=\dfrac{f_{\mathrm{by}}\cdot 6F}{\delta_{\mathrm{e}}^{2}}$ | （2-5） |
| **文字式** | $\text{反力引起的 y 向弯曲应力}=\dfrac{\text{y 向弯曲系数}\times 6\times\text{支座反力}}{\text{封头有效厚度}^{2}}$ |  |

### 2.4 应力限制与 [F] 的确定（#L7409-#L7423）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_{\mathrm{L}}\leqslant 1.0[\sigma]$；$p_{\mathrm{L}}+p_{\mathrm{b}}\leqslant 1.5[\sigma]$ | （2-6） |
| **文字式** | $\text{一次局部薄膜应力}\leqslant 1.0\times\text{许用应力}$；$\text{一次局部薄膜应力}+\text{弯曲应力}\leqslant 1.5\times\text{许用应力}$ |  |

- 迭代求解使各限制式取等号的最大 F 即为封头许用垂直载荷 [F]；
- 标准附录 B 给出 B1~B8 支座号、两种封头厚度档的 [F] 表；
- 带衬里的容器，[F] 取表值的 1/1.5（#L7421-#L7423）。

## 适用范围与边界

- 适用于支承式支座（B 型为主）直接焊在标准椭圆封头上的立式容器；正锥、球冠等其他封头不在本方法范围（#L7385）。
- 系数 fmx/fmy/fbx/fby 按 AD 规范 S3/3 线图查取（随封头曲率、支座位置变化，#L7395-#L7405），本页不展开查图过程。
- 封头有开孔、接管且距支座近时，本方法未覆盖，需另行分析。
- 实际允许垂直载荷取 [[支承式支座的本体允许载荷]] 中 [Q] 与本页 [F] 的小值。

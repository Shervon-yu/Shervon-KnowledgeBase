# 总传热系数与污垢热阻

## 串联热阻（`#L6924-#L6958`）

三过程串联：热流体对流 → 壁导热 → 冷流体对流，稳态下速率相等。对微元 $\mathrm{d}A$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{1}{K\mathrm{d}A}=\dfrac{1}{\alpha_1\mathrm{d}A_1}+\dfrac{b}{\lambda\mathrm{d}A_m}+\dfrac{1}{\alpha_2\mathrm{d}A_2}$ | （4-42） |
| **文字式** | $\dfrac{1}{\text{总系数}\times\text{面积}}=\dfrac{1}{\text{热侧系数}\times\text{热侧面积}}+\dfrac{\text{壁厚}}{\text{热导率}\times\text{平均面积}}+\dfrac{1}{\text{冷侧系数}\times\text{冷侧面积}}$ |  |

圆筒壁 $\mathrm{d}A_1\ne\mathrm{d}A_2\ne\mathrm{d}A_m$，但 $K\mathrm{d}A=K_1\mathrm{d}A_1=K_2\mathrm{d}A_2=K_m\mathrm{d}A_m$，故可任选基准面。

$d_m=\dfrac{d_2-d_1}{\ln(d_2/d_1)}=\dfrac{2b}{\ln(d_2/d_1)}$。

以内表面 $A_1$ 为基准：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{1}{K_1}=\dfrac{1}{\alpha_1}+\dfrac{d_1}{2\lambda}\ln\dfrac{d_2}{d_1}+\dfrac{d_1}{\alpha_2d_2}$ | （4-42b） |
| **文字式** | $\dfrac{1}{\text{内表面总系数}}=\dfrac{1}{\text{热侧系数}}+\dfrac{\text{内径}}{2\times\text{热导率}}\ln\dfrac{\text{外径}}{\text{内径}}+\dfrac{\text{内径}}{\text{冷侧系数}\times\text{外径}}$ |  |

以外表面 $A_2$ 为基准：$\dfrac{1}{K_2}=\dfrac{d_2}{\alpha_1d_1}+\dfrac{d_2}{2\lambda}\ln\dfrac{d_2}{d_1}+\dfrac{1}{\alpha_2}$（4-42d）；以平均面 $A_m$ 为基准：$\dfrac{1}{K_m}=\dfrac{d_m}{\alpha_1d_1}+\dfrac{b}{\lambda}+\dfrac{d_m}{\alpha_2d_2}$（4-42e）。

原文说明：$\alpha$ 用的是全管长平均，故由此得 $K$ 也是全管长平均值。

## 污垢热阻（`#L6992-#L7014`）

$R_d$ 的倒数称**污垢系数** $\alpha_d=1/R_d$。以内表面为基准：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{1}{K_1}=\dfrac{1}{\alpha_1}+R_{d1}+\dfrac{bd_1}{\lambda d_m}+R_{d2}\dfrac{d_1}{d_2}+\dfrac{d_1}{\alpha_2d_2}$ | （4-43） |
| **文字式** | $\dfrac{1}{K_1}=\dfrac{1}{\alpha_1}+\text{热侧污垢热阻}+\text{壁热阻}+\text{冷侧污垢热阻}\times\dfrac{d_1}{d_2}+\dfrac{d_1}{\alpha_2d_2}$ |  |

表4-6 常用污垢热阻（m²·K/kW）：蒸馏水 0.09、海水 0.09、清净河水 0.21、未处理凉水塔水 0.58、已处理凉水塔水 0.26、已处理锅炉水 0.26、硬水/井水 0.58、优质蒸气 0.052、不含油劣质 0.09、往复机排出 0.176、处理过盐水 0.264、有机物 0.176、燃料油 1.056、焦油 1.76、空气 0.26~0.53、溶剂蒸汽 0.14。

原文提醒：污垢层虽薄但热阻大，不可忽视；易结垢或使用过久须定期清洗。

## 例4-14（`#L7015-#L7037`）

φ25×2.5 钢管，管内 CO₂ $\alpha_1=40$、管外水 $\alpha_2=3000$，$\lambda=45$，$R_{d1}=0.53\times10^{-3}$、$R_{d2}=0.21\times10^{-3}$：

$1/K_1=0.025+5.3\times10^{-4}+4.94\times10^{-5}+1.68\times10^{-4}+2.67\times10^{-4}=2.6\times10^{-2}$ → $K_1=38.5$ W/(m²·K)；$K_2=30.7$，但 $K_1A_1=K_2A_2=2.41$ W/K 相等。

- CO₂ 侧热阻占 **96%**，壁热阻仅 0.19%；
- 把 $\alpha_1$ 加倍：$K_1'=74$（+92.2%）；把 $\alpha_2$ 加倍：$K_1'=38.6$（+0.26%）。

**结论：$K$ 由最差一侧（$\alpha$ 最小、热阻最大）的膜控制。**

## 平壁与薄壁管（`#L7081-#L7093`）

$A_1\approx A_2\approx A_m$ 时：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{1}{K}=\dfrac{1}{\alpha_1}+R_{d1}+\dfrac{b}{\lambda}+R_{d2}+\dfrac{1}{\alpha_2}$ | （4-44） |
| **文字式** | $\dfrac{1}{\text{总系数}}=\dfrac{1}{\alpha_1}+\text{热侧污垢}+\dfrac{\text{壁厚}}{\text{热导率}}+\text{冷侧污垢}+\dfrac{1}{\alpha_2}$ |  |

壁热阻与污垢均可忽略时 $\dfrac{1}{K}=\dfrac{1}{\alpha_1}+\dfrac{1}{\alpha_2}$（4-45），$K$ 必小于 $\alpha_1$、$\alpha_2$ 中较小者。

## 经验 K 值与实测（`#L7095-#L7127`）

表4-7 列管式换热器 $K$ 大致范围（W/(m²·K)）：水-水 700~1800；有机物-水（$\mu<0.5$ mPa·s）300~800、（0.5~1.0）200~500、（>1.0）50~300；有机物-有机物 100~350 / 50~250；液体-气体 10~60；气体-气体 10~40；蒸气冷凝-气体 20~250；水蒸气冷凝-水 1500~4700；有机物冷凝-水 500~1200；液体沸腾-液体 100~800。

无可靠数据时可实测：已知 $A$、测流量与进出口温度 → 求 $Q$、$\Delta t_m$ → $K=Q/(A\Delta t_m)$。例4-16：$A=2$ m²、热水 1500 kg/h 80→50 ℃、冷水逆流 15→30 ℃ → $Q=5.23\times10^4$ W、$\Delta t_m=42.5$ ℃、$K=615$ W/(m²·K)。

## 保温层的临界直径（例4-15，`#L7039-#L7079`）

管外保温层：$d_2$ 增大时导热热阻增大、但外表面散热面积也增大，总热损失先增后减，最大值处：

$$d_c=\dfrac{2\lambda}{\alpha}$$

$\lambda$ 为保温材料热导率、$\alpha$ 为外表面与环境的对流+辐射系数。例4-15 中 $d_c\approx$ 图4-28 峰值处，$d_2=0.05$ m 时热损失与裸管（12.6 W/m）相同，故保温层外径须大于 0.05 m 才真正减少热损失。

## 判断

- 例4-14 的"96% 热阻在气侧"是换热器改造的第一原则：强化传热要打在最差的一侧，在好的一侧（水侧）加倍几乎没用（+0.26%）。
- 临界直径说明"加保温层不一定减少热损失"——对小管径、低 $\alpha$ 的场合，保温层反而可能先增大散热；工程上要么选更厚越过 $d_c$，要么换 $\lambda$ 更小的材料。

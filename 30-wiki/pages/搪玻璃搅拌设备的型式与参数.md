# 搪玻璃搅拌设备的型式与参数

## 为什么用搪玻璃

以 $\mathrm{SiO_2}$ 为主体加多种元素的玻璃质瓷釉，经 **920~960 ℃ 多次高温烧结**牢固密着于金属铁胎表面：兼具玻璃的化学稳定性与金属的强度（`#L6168`）。

五项性能（`#L6170-#L6178`）：

| 性能 | 内容 |
|:---|:---|
| 耐腐蚀 | 耐无机酸、有机酸、有机溶剂及 pH ≤12 的碱；**不耐**强碱、氢氟酸、>180 ℃ 且 >30% 的磷酸 |
| 不粘 | 光滑玻璃面不粘、易清洗 |
| 绝缘 | 适合易产生静电的介质 |
| 隔离 | 玻璃层隔绝铁离子溶入介质 |
| 保鲜 | 对介质有优良保鲜性 |

## 开式搅拌设备（HG/T 2371）技术参数

| 参数 | 范围 |
|:---|:---|
| 筒体内公称压力 | ≤1.0 MPa |
| 公称容积 | 50~5000 L |
| 夹套内公称压力 | ≤0.6 MPa |
| 筒体及夹套介质温度 | −20~200 ℃ |

（`#L6184`）

## 两个系列

同一公称容积有 **L 系列（瘦长型）** 与 **S 系列（矮胖型）** 两种公称直径，由用户按使用条件选（`#L6190`）。

| VN/L | L 系列 DN | S 系列 DN |
|:---:|:---:|:---:|
| 50 | 400 | 500 |
| 100 | 500 | 600 |
| 200 | 600 | 700 |
| 300 | 700 | 800 |
| 400 | 800 | — |
| 500 | 900 | 1000 |
| 1000 | 1100 | 1200 |
| 2000 | 1300 | 1450 |
| 3000 | 1450 | 1600 |
| 5000 | 1750 | — |

（`#L6201-#L6232`；容积系数 $V_N/V_J$ 0.71~0.95，夹套换热面积 0.54~13.4 m²）

| 部件 | 标准 / 选型 |
|:---|:---|
| 传动装置 | HG/T 2052；I 型适用 VN 50~5000 L，II、III 型适用 VN 50~4000 L |
| 搅拌器 | HG/T 2051；锚式、框式、叶轮式、桨式 4 种 |
| 温度计套 | HG/T 2058.1（普通）/ 2058.2（翅片式）；DN ≤500 不宜用翅片式 |
| 轴封 | 搪玻璃填料箱（含冷却水夹套）PN ≤0.25 MPa；机械密封单端面 PN ≤0.6 MPa、双端面 PN ≤1.0 MPa |
| 放料阀 | 搪玻璃上展式或下展式 |

（`#L6190`、`#L6213-#L6221`）

## 与钢制容器的差异

搪玻璃设备的"公称容积"是**公称值**，计算容积普遍大于公称容积（容积系数 0.71~0.95），且随规格减小而降低；选型时必须用计算容积核装料系数，否则会低估装料量。

## 判断

L 与 S 的选择本质是"传热与混合"对"占地与造价"的权衡：同一容积下 S 系列直径大、液层浅，夹套面积与单位体积功率都更高；L 系列细长，适合高径比要求大的反应（如聚合）但传热面积小。表6-6 里同 VN 的两种 DN 容积系数接近，说明差异主要在形状而非容量。

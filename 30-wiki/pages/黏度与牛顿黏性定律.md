# 黏度与牛顿黏性定律

## 黏性的来源（`#L1600-#L1604`）

流体流动时产生内摩擦力的性质称黏性。两平行平板间液体：贴板面的一层随板走、贴底板的一层静止，中间形成上大下小的速度分布；速度不同的相邻液层间产生大小相等方向相反的**内摩擦力（黏滞力）**。

## 牛顿黏性定律（`#L1608-#L1622`）

速度梯度 $\mathrm{d}u/\mathrm{d}y$ 与剪应力 $\tau$ 成正比：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=\mu\dfrac{\mathrm{d}u}{\mathrm{d}y}$ | （1-33） |
| **文字式** | $\text{剪应力}_{\text{【Pa】}}=\text{黏度}_{\text{【Pa·s】}}\times\dfrac{\text{速度增量}_{\text{【m/s】}}}{\text{法向距离增量}_{\text{【m】}}}$ |  |

- $\mu$ 称黏性系数/动力黏度，简称黏度；
- **物理意义**：$\mathrm{d}u/\mathrm{d}y=1$ 时，单位面积上的内摩擦力即为 $\mu$；
- 单位：$\mathrm{Pa\cdot s}$（即 $\mathrm{N\cdot s/m^2}$）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\nu=\dfrac{\mu}{\rho}$ | （1-34） |
| **文字式** | $\text{运动黏度}_{\text{【m²/s】}}=\dfrac{\text{动力黏度}_{\text{【Pa·s】}}}{\text{密度}_{\text{【kg/m³】}}}$ |  |

## 温度与压力的影响（`#L1630-#L1632`）

- 同温下气体黏度远小于液体；
- **温度升高：液体黏度减小、气体黏度增大**；
- 压力影响：液体可忽略；气体在压力不过高过低时也与压力无关。

## 动量传递的解释（`#L1668-#L1684`）

分子随机运动使快层分子进入慢层、慢层分子进入快层，动量由速度大处向速度小处传递。把 1-33 改写：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=\nu\dfrac{\mathrm{d}(\rho u)}{\mathrm{d}y}$ | （1-35） |
| **文字式** | $\text{剪应力}_{\text{【Pa】}}=\text{运动黏度}_{\text{【m²/s】}}\times\dfrac{\text{动量浓度梯度}_{\text{【(kg·m/s)/m³/m】}}}{\ }$ |  |

$\rho u$ 为单位体积流体的动量；$\tau$ 可看作单位时间单位面积的动量，即**动量传递速率**——1-35 表明分子动量传递速率与动量梯度成正比。这与热传导（温度梯度）同构。

## 非牛顿型流体（`#L1688-#L1690`）

服从 1-33 的称牛顿型流体（水、空气）；不服从的称非牛顿型流体（泥浆、某些高分子溶液、悬浮液），属流变学范畴，本节不展开。

## 例 1-11（`#L1634-#L1666`）

汽缸 $D=12$ cm、活塞 $d=11.96$ cm、厚 $l=14$ cm、油 $\mu=0.1$ Pa·s、速度 1 m/s：

- 间隙 $n=\tfrac12(12-11.96)=0.02$ cm，$\mathrm{d}u/\mathrm{d}y=100/0.02=5\times10^3$ s⁻¹；
- $\tau=0.1\times5\times10^3=500$ N/m²；
- 面积 $A=\pi\times0.1196\times0.14=0.053$ m²；
- $F=\tau A=26.5$ N。

## 判断

- 例 1-11 的算法前提是"间隙很小、速度分布按直线"——间隙比直径小两个数量级时这个近似才成立。
- 液体与气体的黏度随温度反向变化，是分子机理不同（液体靠分子引力、气体靠分子碰撞）的直接结果；查表时务必确认温度。

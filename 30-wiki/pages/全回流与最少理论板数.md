# 全回流与最少理论板数

## 全回流（`#L12204-#L12214`）

塔顶蒸气冷凝后**全部**回流，不采出产品：$F=D=W=0$、$R=L/D\to\infty$。

此时：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{R}{R+1}\to1$，$\dfrac{x_D}{R+1}\to0$，$y_n=x_{n-1}$ | （无编号） |
| **文字式** | 操作线斜率 →1、截距 →0，即操作线与对角线重合 |  |

在图解法上，操作线就是对角线：从 $D(x_D,x_D)$ 在对角线与平衡线之间画梯级，到 $x_N\le x_W$ 为止，梯级数 = 指定分离要求下的**最少理论板数** $N_{\min}$（含蒸馏釜）。

全回流只用于开工、调试、实验，不作正常生产——没有产品。

## 芬斯克方程（`#L12220-#L12266`）

对理想溶液，逐板把相平衡 $y_n/(1-y_n)=\alpha_n x_n/(1-x_n)$ 与全回流操作线 $y_{n+1}=x_n$ 连乘，取平均相对挥发度：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=\sqrt[N]{\alpha_1\alpha_2\cdots\alpha_N}\approx\sqrt{\alpha_1\alpha_N}$ | （6-48）（6-49） |
| **文字式** | 全塔平均相对挥发度 = 各板相对挥发度的几何平均；常用塔顶与塔底值的几何平均 |  |

$$N_{\min}=\frac{\lg\left[\left(\dfrac{x_D}{1-x_D}\right)\left(\dfrac{1-x_W}{x_W}\right)\right]}{\lg\alpha}\tag{6-50}$$

$N_{\min}$ **包括蒸馏釜**；$\alpha$ 取全塔平均相对挥发度。

## 例6-13（`#L12270-#L12306`）

正庚烷-正辛烷，$x_D$=0.95、$x_W$=0.05、101.3 kPa：

- 图解法：8 块理论板（含釜）；
- 芬斯克：$\alpha_D=101.3/44.4=2.28$、$\alpha_W=205.3/101.3=2.03$ → $\alpha=2.15$；
$N_{\min}=\frac{\lg(19\times19)}{\lg2.15}=7.69$ → 取整 **8**，与图解法一致。

## 判断

- 全回流是"用无穷多回流换最少板数"，物理上对应操作线离平衡线最远——每一步梯级都是最大分离能力。
- 芬斯克方程只依赖两端组成与平均 $\alpha$，与进料状态、q、R 都无关——这也是它能当"理论下限"工具的原因。
- $N_{\min}$ 含釜，实际塔板数 $N_T=N_{\min}-1$（釜单独算）——工程上换算时经常出错。
- $\alpha$ 变化大（非理想）时芬斯克误差大，宜用图解法。

# 搅拌功率的测量方法

搅拌功率只能靠实测校准：文献关联式的常数都来自实验，几何或物料一变就要重测。

## 反扭矩法（小规模）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=2\pi NmgR$ | （3-42） |
| **文字式** | $\text{搅拌功率}_{\text{【W】}}=2\pi\times\text{转速}_{\text{【1/s】}}\times\text{砝码质量}_{\text{【kg】}}\times9.81\times\text{力臂}_{\text{【m】}}$ |  |

（`#L3537`；$m$ kg、$R$ 力臂 m、$g=9.81$ m/s²）

原理：电机定子与转子所受电磁力矩大小相等、方向相反（`#L3535`）。把釜体（或定子）用轴承浮动支撑、以力臂砝码平衡反扭矩，即可由砝码读出扭矩，再乘 $2\pi N$ 得功率。

适用：实验室小规模、几十升至几百升；优点是直接、无需标定电机效率。缺点：需浮动安装、摩擦与密封干扰要扣除；大功率时力臂与砝码笨重。

## 应变法（大功率）

在搅拌轴（或联轴器）上贴 4 片 45° 应变片组成电桥，测轴受扭时的应变量，标定后换算扭矩与功率（`#L3559-#L3565`）。

要点：

1. 应变片布置须对称于轴线、45° 方向，抵消弯扭分离；
2. 必须**扣除空载摩擦功率**（填料函/机械密封、轴承）——空载值随转速与介质压力变（`#L3565`）；
3. 适合工业规模，信号可滑环或遥测引出。

## 选型口径

| 场合 | 首选 |
|:---|:---|
| 实验室、<几百 L、需快速换桨 | 反扭矩法 |
| 工业釜、>几十 kW、轴系已定 | 应变法 |
| 现场无拆轴条件 | 电功率法（量电机输入、乘效率），误差大，只作量级核对 |

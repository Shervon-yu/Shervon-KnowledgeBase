# 釜用立式减速机的选用原则

## 十条（`#L8659-#L8677`）

| # | 原则 | 要点 |
|:--:|:---|:---|
| ① | 优先标准机 | 选标准减速机与专业厂产品 |
| ② | 平稳连续 | 考虑振动与载荷变化下的平稳性，一般选效率较高的齿轮或行星摆线针轮 |
| ③ | 双向传动 | 出轴要正反双向的，**不宜选蜗轮蜗杆** |
| ④ | 防爆环境 | 一般不采用带传动；必须用时要有防静电措施 |
| ⑤ | 轴向力 | 搅拌轴向力**原则上不由减速机轴承承受**；必须承受时须验算核定 |
| ⑥ | 功率余量 | 额定功率 ≥ 输出轴传动功率（搅拌轴功率＋轴封摩擦＋机架轴承损耗之和），并满足启动功率增大 |
| ⑦ | 转速匹配 | 输入轴转速与电动机匹配，输出轴转速与工艺搅拌转速一致；不一致时可在工艺允许下改搅拌转速 |
| ⑧ | 轴位置 | 输入输出轴相对位置适合釜顶或釜底布置 |
| ⑨ | 外形 | 满足安装与检修；釜顶一般用单台立式传动 |
| ⑩ | 综合 | 环境、制造水平、检修能力、造价、噪声等一起权衡 |

## 判断

十条里最容易被忽略的是 ③ 与 ⑤：蜗轮蜗杆的自锁性在需要反转时会成为隐患；而把搅拌轴向力直接压在减速机轴承上，短期看不出问题，长期是轴承与齿轮啮合精度的双重损失。

# 伯努利方程式

伯努利方程是管内流体流动的**机械能衡算式**（`#L1418`）。

## 推导（`#L1420-#L1456`）

假定流体无黏性（无摩擦损失）、稳态流动、截面上速度分布均匀、压力与密度取截面平均值。取微管段 $\mathrm{d}x$，作用力两项：两端总压力 $pA$ 与 $-(p+\mathrm{d}p)A$；重力沿流向分力 $g\rho A\mathrm{d}z$。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $pA-(p+\mathrm{d}p)A-g\rho A\mathrm{d}z=-A\mathrm{d}p-g\rho A\mathrm{d}z$ | （1-24） |
| **文字式** | $\text{两端压力差}-\text{重力沿流向分力}=-\text{截面积}\times\text{压力增量}-\text{重力加速度}\times\text{密度}\times\text{截面积}\times\text{高度增量}$ |  |

动量变化速率：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_m\mathrm{d}u=\rho Au\,\mathrm{d}u$ | （1-25） |
| **文字式** | $\text{质量流量}\times\text{流速增量}=\text{密度}\times\text{截面积}\times\text{流速}\times\text{流速增量}$ |  |

由动量原理（合力=动量变化速率）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho Au\,\mathrm{d}u=-A\mathrm{d}p-g\rho A\mathrm{d}z$ | （1-26） |
| **文字式** | $\text{密度}\times\text{截面积}\times\text{流速}\times\text{流速增量}=-\text{截面积}\times\text{压力增量}-\text{重力加速度}\times\text{密度}\times\text{截面积}\times\text{高度增量}$ |  |

化简：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $g\mathrm{d}z+\dfrac{\mathrm{d}p}{\rho}+u\mathrm{d}u=0$ | （1-27） |
| **文字式** | $\text{重力加速度}\times\text{高度增量}+\dfrac{\text{压力增量}}{\text{密度}}+\text{流速}\times\text{流速增量}=0$ |  |

不可压缩流体 $\rho$ 为常数，积分：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $gz+\dfrac{p}{\rho}+\dfrac{u^2}{2}=\text{常数}$ | （1-28） |
| **文字式** | $\text{重力加速度}\times\text{高度}+\dfrac{\text{压力}}{\text{密度}}+\dfrac{\text{流速}^2}{2}=\text{常数}$ |  |

式(1-28)称**理想流体伯努利方程式**。

## 物理意义（`#L1464-#L1490`）

| 项 | 含义 | 单位 |
|:---|:---|:---|
| $gz$ | 单位质量流体的位能 | J/kg |
| $p/\rho$ | 单位质量流体的静压能（压力称静压） | J/kg |
| $u^2/2$ | 单位质量流体的动能 | J/kg |

三项均属机械能，可相互转换、总和不变——1-28 即**单位质量流体的能量守恒式**。

各项除以 $g$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $z+\dfrac{p}{\rho g}+\dfrac{u^2}{2g}=\text{常数}$ | （1-29） |
| **文字式** | $\text{高度}+\dfrac{\text{压力}}{\text{密度}\times\text{重力加速度}}+\dfrac{\text{流速}^2}{2\times\text{重力加速度}}=\text{常数}$ |  |

各项单位为 m（J/N），即**单位重量流体的能量**。此时称压头：$z$ 位压头、$p/\rho g$ 静压头、$u^2/2g$ 动压头（速度压头），三者之和为总压头。

## 气体适用条件（`#L1460-#L1462`）

两截面压差小（$p_1-p_2\le0.2p_1$）、密度变化小时仍可用，$\rho$ 取两截面平均值；压差大时须按热力学过程（等温/绝热）另行处理。

## 判断

- 1-24~1-27 的推导只用"力=动量变化率"，没有引入任何经验系数——这是它能成为理论基准的原因，也是它必须先假设无黏性的原因。
- J/kg 与 m 两套写法（1-28 与 1-29）只是除以 $g$ 的差别，工程上泵的扬程用 m、管路损失常用 J/kg，换算靠 $g$。

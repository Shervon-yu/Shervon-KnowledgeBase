# 热负荷与空气消耗量

## 预热器加热量（`#L14215-#L14219`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q_P=G(I_1-I_0)$ | （7-30） |
| **文字式** | $\text{预热器负荷}=\text{干空气流量}\times(\text{出预热器焓}-\text{进预热器焓})$ |  |

预热只升温不增湿，故 $H_1=H_0$；$I_1-I_0=(c_H)(t_1-t_0)$。

## 干燥器热量衡算（`#L14225-#L14255`）

物料焓（基准 0 ℃）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $I'=(c_s+Xc_w)\theta$ | （7-31） |
| **文字式** | $\text{物料焓}=(\text{绝干料比热}+\text{干基含水量}\times\text{水比热})\times\text{物料温度}$ |  |

$c_w\approx4.187$ kJ/(kg 水·℃)。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $GI_1+L_cI_1'+Q_D=GI_2+L_cI_2'+Q_L$ | （7-32） |
| **文字式** | $\text{空气带入焓}+\text{物料带入焓}+\text{补充热}=\text{空气带出焓}+\text{物料带出焓}+\text{热损失}$ |  |

改写：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $G(I_1-I_2)=L_c(I_2'-I_1')+Q_L-Q_D$ | （7-32a） |
| **文字式** | $\text{空气放热}=\text{物料吸热}+\text{热损失}-\text{补充热}$ |  |

## 等焓干燥（`#L14251-#L14253`）

若 $Q_L=0$、$Q_D=0$ 且物料进出焓相等，则右侧为零 → $I_1=I_2$：空气在干燥器内沿 I-H 图**等焓线**降温增湿。已知 $t_2$ 即可定 $H_2$。多数干燥器接近此情形。

## 热量去向（`#L14255`）

总热量 $Q=Q_P+Q_D$ 用于：①加热空气；②蒸发水分；③加热物料；④补偿热损失。

## 例7-6（`#L14257-#L14385`）

年产 2×10⁶ kg 晶体、$w_1$=20%→$w_2$=2%、物料 15→45 ℃、$c_s$=1.25；空气 15 ℃/70% → 预热 90 ℃ → 出 65 ℃；不计损失、无补充热。

- $L_2$=278 kg/h、$L_c$=272、$X_1$=0.25、$X_2$=0.0204 → $W$=62.5 kg/h；
- $I_1$=110、$I_2=65.7+2610H_2$；$I_1'$=34.5、$I_2'$=60.1；
- 联立热量衡算与 $G=W/(H_2-H_1)$ → $G$=6760 kg 干气/h、$H_2$=0.0166、$I_2$=109≈$I_1$（近等焓）；
- $Q_P$=143 kW；200 kPa 饱和蒸汽 $r$=2205 → $D$=0.0649 kg/s=233 kg/h；
- 分配：空气加热 96.1 kW（67.1%）、水分蒸发 44.3 kW（30.8%）、物料加热 3.03 kW（2.1%）；
- 热空气在干燥器内放热 $Q_D'$=48 kW；
- 若预热到 100 ℃：$G$=4820、$H_2$=0.0203、$Q_P$=117 kW、$D$=191 kg/h、$Q_g/Q_P$=59%。

## 判断

- "近等焓"不是假设，而是 $Q_L$、$Q_D$、物料焓差三项都小到可忽略的结果；有补充加热或热损失大时必须用（7-32a）解。
- 提高预热温度的作用是"以更少空气带走同样水分"：例7-6 中 90 ℃→100 ℃ 使 $G$ 降 29%、$Q_P$ 降 18%。代价是废气温度与产品受热。
- 热效率的短板通常是废气带走显热（67% 用于加热空气本身），所以废热回收是干燥节能的主战场。

# 管路总阻力损失

## 叠加式（`#L2351-#L2357`）

等直径管路中，总阻力=直管阻力+全部局部阻力：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sum h_f=\left[\lambda\left(\dfrac{l+\sum l_e}{d}\right)+\sum\zeta\right]\dfrac{u^2}{2}$ | （1-59） |
| **文字式** | $\text{总阻力损失}_{\text{【J/kg】}}=\left[\text{摩擦系数}\times\dfrac{\text{管长}+\sum\text{当量长度}}{\text{管内径}}+\sum\text{局部阻力系数}\right]\times\dfrac{\text{流速}^2}{2}$ |  |

注意：**变径管路要分段算**，每段用自己的 $d$、$u$、$\lambda$，不能直接套 1-59。

## 例 1-17：分段计算（`#L2359-#L2401`）

常温水泵送 20 m³/h 到塔，塔内表压 196 kPa，升扬 15 m。吸入管 φ108×4（$d$=0.1 m、$l$=5 m）；出口管 φ57×3.5（$d$=0.05 m、$l$=20 m），塔进口前截止阀半开，$\varepsilon/d=0.001$。

**吸入管**：$u=0.708$ m/s、$Re=7.08\times10^4$、查图 $\lambda=0.0235$；入口 $\zeta=0.5$、90° 弯头 $l_e/d=35$：

$\sum h_{f1}=\left[0.0235\left(\dfrac{5}{0.1}+35\right)+0.5\right]\dfrac{0.708^2}{2}=0.626$ J/kg

**出口管**：$u=2.83$ m/s、$Re=1.42\times10^5$、$\lambda=0.0215$；两个弯头 $l_e/d=70$、截止阀半开 475、入塔 $\zeta=1.0$：

$\sum h_{f2}=\left[0.0215\left(\dfrac{20}{0.05}+70+475\right)+1\right]\dfrac{2.83^2}{2}=85.4$ J/kg

**总损失** 86 J/kg，外加机械能：

$W=15\times9.81+\dfrac{196\times10^3}{1000}+86=429$ J/kg

**要点**：出口管的 $u$ 是吸入管的 4 倍（面积比 4:1），阻力与 $u^2$ 成正比，所以 99% 的损失发生在细管——变径管路里"细管主导"是普遍规律。

## 例 1-18：拆一个阀流量增多少（`#L2403-#L2429`）

垂直管 $d=0.1$ m、$l=16$ m、$\lambda=0.025$，两个截止阀（一全开 $\zeta=6.0$、一半开 9.5），入口 0.5、出口 1.0。位头 $Hg$ 全部用于克服阻力：

- 拆除前：$\sum h_{f1}=\left(0.025\times\dfrac{16}{0.1}+0.5+6.0+9.5+1\right)\dfrac{u_1^2}{2}=21\dfrac{u_1^2}{2}$；
- 拆除后：$\sum h_{f2}=15\dfrac{u_2^2}{2}$；
- 位头不变 → $21u_1^2=15u_2^2$ → $\dfrac{q_{V2}}{q_{V1}}=\sqrt{\dfrac{21}{15}}=1.18$，流量增 18%。

**要点**：全开截止阀的 $\zeta=6$ 相当于 300 倍管径的直管，拆掉它比缩短 3 m 管子更有效。这类"阻力构成分析"是管路改造的常用手段。

## 判断

- 两个例子的方法不同：例 1-17 是"正向算损失→求外功"，例 1-18 是"阻力比例→流量比例"。后者只在位头驱动、且 λ 不变的条件下成立。
- 1-59 把 $l_e$ 与 $\zeta$ 并入一个式子，便于 Excel 一次算完；但两法混用时要注意同一管件的当量长度按哪个流速折算。

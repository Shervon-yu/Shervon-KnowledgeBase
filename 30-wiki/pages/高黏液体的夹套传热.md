# 高黏液体的夹套传热

## 为什么指数是 1/3 而不是 2/3

高黏体系里，叶轮与釜壁的间隙（约几毫米到几厘米）本身就成了传热层的厚度：**边界层比间隙更厚，其厚度由几何固定、与黏度无关**（`#L3025`）。于是传热层导热为主，$h\propto Re^{1/3}$——比湍流区的 $2/3$ 平缓得多，也解释了为什么这一类式子除了 $Vis$ 项外能把黏度消掉。

推进式、桨式、涡轮式不适合高黏体系；锚式能做但近壁温度不均，故推荐螺带式或螺杆+导流筒（`#L2995`）。

## 螺带式

实验釜：$90^{\circ}$ 间隔交替装冷却水夹套与加热蒸汽夹套，稳态测传热（`#L3011`）。拟塑性流体的 $\mu_{a}$ 按 §1.6 估算后算 $Re$、$Pr$、$Vis$（`#L3015`）。

层流区（$1<Re<1000$，$Re$ 用表观黏度 $\mu_{a}$）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{h_{j}D}{k}=4.2\left(\dfrac{d^{2}n\rho}{\mu_{a}}\right)^{1/3}\left(\dfrac{C_{p}\mu_{a}}{k}\right)^{1/3}\left(\dfrac{\mu_{a}}{\mu_{aw}}\right)^{0.2}=4.2\left(\dfrac{d^{2}n\rho C_{p}}{k}\right)^{1/3}\left(\dfrac{\mu_{a}}{\mu_{aw}}\right)^{0.2}$ | （2.21）（2.21′） |
| **文字式** | $\text{夹套侧努塞尔数}=4.2\times\left(\dfrac{\left(\text{桨径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}\times\text{密度}_{\text{【kg/m³】}}\times\text{比热}_{\text{【J/(kg·K)】}}}{\text{热导率}_{\text{【W/(m·K)】}}}\right)^{1/3}\times\left(\dfrac{\text{表观黏度}}{\text{壁温下表观黏度}}\right)^{0.2}$ |  |

湍流区（$Re>10^{3}$）$Re$ 指数升到 2/3，$Vis$ 指数改 0.14（`#L3031`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{h_{j}D}{k}=0.42\left(\dfrac{d^{2}n\rho}{\mu}\right)^{2/3}\left(\dfrac{C_{p}\mu_{a}}{k}\right)^{1/3}\left(\dfrac{\mu_{a}}{\mu_{aw}}\right)^{0.14}$ | （2.22） |
| **文字式** | 同上，只是雷诺数指数由 1/3 改为 2/3，黏度比指数由 0.2 改为 0.14 |  |

$Vis$ 指数的选取：层流区试过 0.14、0.18、0.24，用 0.14 偏差大，**用 0.20 基本符合**（`#L3017`）。

## 锚式

锚式结构简单、工业用得多，但近壁液温明显分层、同一位置温度还随时间波动（图2.9、图2.10），**温差取不准**，关联曲线也对不上（`#L3035`、`#L3047`）。只能给近似式（`#L3053`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{h_{j}D}{k}=1.5\left(\dfrac{d^{2}n\rho}{\mu_{a}}\right)^{1/2}\left(\dfrac{C_{p}\mu_{a}}{k}\right)^{1/3}\left(\dfrac{\mu_{a}}{\mu_{w}}\right)^{0.14}$ | （2.23） |
| **文字式** | $\text{夹套侧努塞尔数}=1.5\times\text{表观雷诺数}^{1/2}\times\text{普朗特数}^{1/3}\times\text{黏度比}^{0.14}$ |  |

锚式 $Re$ 指数是 **1/2**，与螺带的 1/3 不同——锚式靠刮削更新边界层，流动介于层流与湍流之间。

## 间隙的影响

若传热层厚度≈间隙，缩短间隙就应有利；在螺带尖端加刮板更新传热层更好（`#L3063`）。计入间隙比（`#L3065`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{h_{j}D}{k}=1.75\left(\dfrac{d^{2}n\rho}{\mu_{a}}\right)^{1/3}\left(\dfrac{C_{p}\mu_{a}}{k}\right)^{1/3}\left(\dfrac{\mu_{a}}{\mu_{w}}\right)^{0.2}\left(\dfrac{D-d}{D}\right)^{-1/3}$ | （2.24） |
| **文字式** | 同式(2.21) 乘 $\left(\dfrac{\text{釜内径}-\text{桨径}}{\text{釜内径}}\right)^{-1/3}$，间隙越小系数越大 |  |

带两个橡皮刮板的带状叶轮（$d=264$ mm、$D=300$ mm，即间隙 18 mm）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{h_{j}D}{k}=5.4\left(\dfrac{d^{2}n\rho}{\mu}\right)^{1/3}\left(\dfrac{C_{p}\mu_{a}}{k}\right)^{1/3}\left(\dfrac{\mu_{a}}{\mu_{w}}\right)^{0.2}$ | （2.25） |
| **文字式** | 系数由 4.2 升到 5.4，即表面传热系数提高约 28.6% |  |

## 一个没被解释清楚的矛盾

若刮板对传热面的更新是**理想**的（每转一次把边界层完全换掉），$Re$ 指数应为 **1/2**；实测仍是 **1/3**（`#L3073`）。作者自己承认这与理论不符。实践含义：刮板的收益（4.2→5.4）远小于"理想更新"应有的量级，真正让高黏釜传热变好的是避免黏釜物（见 [[高黏流体黏釜物与刮壁式传热]]，黏釜 0.1 mm 即可让总系数掉 35%），而不是单纯加刮板。

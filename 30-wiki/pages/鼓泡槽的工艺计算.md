# 鼓泡槽的工艺计算

## 一、气泡上升速度（式15-8，`#L17558`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $v_t=\sqrt{\dfrac{2\sigma}{D_1\rho_L}+\dfrac{gD_1}{2}}$ | （15-8） |
| **文字式** | $\text{气泡上升速度}_{\text{【m/s】}}=\sqrt{\dfrac{2\times\text{表面张力}_{\text{【N/m】}}}{\text{气泡当量直径}_{\text{【m】}}\times\text{液相密度}_{\text{【kg/m³】}}}+\dfrac{\text{重力加速度}_{\text{【m/s²】}}\times\text{气泡当量直径}_{\text{【m】}}}{2}}$ |  |

原文符号说明中 $D_1$ 单位为 mm，公式量纲要统一为 m（`#L17562`）。

## 二、上升气泡床直径（式15-9，`#L17570-#L17586`）

当气量大于生成气泡链的最小流量时适用：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{BO}=\left(\dfrac{6Q}{\pi n}\right)^{0.4}\left(\dfrac{3\lambda}{4g}\right)^{0.2}$ | （15-9） |
| **文字式** | $\text{气泡床直径}_{\text{【m】}}=\left(\dfrac{6\times\text{气体体积流量}_{\text{【m³/s】}}}{\pi\times\text{鼓泡器小孔数}}\right)^{0.4}\times\left(\dfrac{3\times\text{摩擦系数}}{4\times\text{重力加速度}_{\text{【m/s²】}}}\right)^{0.2}$ |  |

其中 $\lambda=\dfrac{8}{3}\dfrac{E\ddot O}{4+E\ddot O}$，$E\ddot O=\dfrac{g\rho_L D_1^2}{4\sigma}$（Eötvös 准数）。

## 三、输气压力（式15-10，`#L17588-#L17606`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p=\left(p_1+\rho_L gH\times10^{-6}\right)+\Delta p_1+\Delta p_0$ | （15-10） |
| **文字式** | $\text{输气压力}_{\text{【MPa】}}=\left(\text{槽内气压}_{\text{【MPa】}}+\text{液体密度}_{\text{【kg/m³】}}\times\text{重力加速度}_{\text{【m/s²】}}\times\text{液高}_{\text{【m】}}\times10^{-6}\right)+\text{输气压力降}_{\text{【MPa】}}+\text{鼓泡孔口压降}_{\text{【MPa】}}$ |  |

物理含义：输气压力须足以克服**速度压头 + 液柱静压 + 管路与孔口阻力**。

## 四、喷气流量（式15-11、15-12，`#L17608-#L17622`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{Q}{d_0\nu}=10.5\left(\dfrac{\sigma d_0}{\rho_L\nu^2}\right)^{0.48}\left(\dfrac{\Delta p_0 d_0}{\sigma}\right)^{0.75}$ | （15-11） |
| **文字式** | $\dfrac{\text{喷气流量}_{\text{【m³/s】}}}{\text{孔口直径}_{\text{【m】}}\times\text{运动黏度}_{\text{【m²/s】}}}=10.5\times\left(\dfrac{\text{表面张力}_{\text{【N/m】}}\times\text{孔口直径}_{\text{【m】}}}{\text{液体密度}_{\text{【kg/m³】}}\times\text{运动黏度}^2_{\text{【m²/s】}}}\right)^{0.48}\times\left(\dfrac{\text{鼓泡孔口压降}_{\text{【Pa】}}\times\text{孔口直径}_{\text{【m】}}}{\text{表面张力}_{\text{【N/m】}}}\right)^{0.75}$ |  |

低黏液体改用式15-12（前系数 21，末指数 0.65）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{Q}{d_0\nu}=21\left(\dfrac{\sigma d_0}{\rho_L\nu^2}\right)^{0.48}\left(\dfrac{\Delta p_0 d_0}{\sigma}\right)^{0.65}$ | （15-12） |
| **文字式** | $\dfrac{\text{喷气流量}_{\text{【m³/s】}}}{\text{孔口直径}_{\text{【m】}}\times\text{运动黏度}_{\text{【m²/s】}}}=21\times\left(\dfrac{\text{表面张力}_{\text{【N/m】}}\times\text{孔口直径}_{\text{【m】}}}{\text{液体密度}_{\text{【kg/m³】}}\times\text{运动黏度}^2_{\text{【m²/s】}}}\right)^{0.48}\times\left(\dfrac{\text{鼓泡孔口压降}_{\text{【Pa】}}\times\text{孔口直径}_{\text{【m】}}}{\text{表面张力}_{\text{【N/m】}}}\right)^{0.65}$ |  |

黏稠/低黏的判据原文未给数值，只按「黏稠液体」与「低黏液体」文字区分（`#L17610`、`#L17614`），选式时以实测黏度与已有工程经验类比。

## 五、鼓泡器孔口最大直径（式15-13，`#L17632`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_0=\sqrt{\dfrac{6\sigma}{g\rho_L}}$ | （15-13） |
| **文字式** | $\text{孔口最大直径}_{\text{【m】}}=\sqrt{\dfrac{6\times\text{表面张力}_{\text{【N/m】}}}{\text{重力加速度}_{\text{【m/s²】}}\times\text{液体密度}_{\text{【kg/m³】}}}}$ |  |

这是「稳定操作」的上限，与结构推荐的 3~6 mm 孔径互为校核（`#L17650`）。

## 六、气体滞留量（式15-14，`#L17638`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\varphi=\dfrac{Q}{Av_t}\Big/\left(\dfrac{Q}{Av_t}+1\right)$ | （15-14） |
| **文字式** | $\text{气体滞留量}=\dfrac{\text{气体体积流量}_{\text{【m³/s】}}}{\text{鼓泡槽截面积}_{\text{【m²】}}\times\text{气泡上升速度}_{\text{【m/s】}}}\div\left(\dfrac{\text{气体体积流量}_{\text{【m³/s】}}}{\text{鼓泡槽截面积}_{\text{【m²】}}\times\text{气泡上升速度}_{\text{【m/s】}}}+1\right)$ |  |

形式上是 $\varphi=x/(x+1)$，$x=Q/(Av_t)$ 为表观气速与气泡速度之比，恒小于 1。

## 计算顺序

1. 由工艺定 $Q$ 与槽截面 $A$ → 2. 式15-8 算 $v_t$ → 3. 式15-14 校核滞留量 → 4. 式15-13 定孔径上限、结合 3~6 mm 经验定 $d_0$ → 5. 式15-11 或 15-12 反算所需孔口压降（校核气源压力）→ 6. 式15-10 定输气压力 → 7. 式15-9 估算气泡床直径，校核是否覆盖槽截面。

## 判断

- 式15-14 隐含「气泡速度均匀、无返混」的假设；实际大气泡破碎会抬高滞留量，工程上按计算值 +20% 估气量更稳。
- 式15-13 给的是「孔口最大直径」，不是最佳直径：孔越大越难形成细泡，实际取 3~6 mm 是在「不堵」与「气泡不过大」之间折中。

# 热辐射的基本概念与斯蒂芬-玻尔兹曼定律

## 物理本质（`#L7403-#L7409`）

一切绝对温度大于零的物体都以电磁波形式向外发射热辐射。波长范围：紫外线 0.1~0.38 μm、可见光 0.38~0.76 μm、红外线 0.76~1000 μm；大部分能量集中在 **0.76~20 μm** 的红外区。传播不需要介质，真空中照常传播。

## 吸收率、反射率、透过率（`#L7413-#L7421`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha+\rho+\tau=1$ | （4-48） |
| **文字式** | $\text{吸收率}+\text{反射率}+\text{透过率}=1$ |  |

- $\alpha=1$：黑体；$\rho=1$：白体；$\tau=1$：透热体（如 O₂、N₂、H₂ 等对称双原子气体；CO、CO₂、SO₂、水蒸气辐射与吸收能力大）。
- 固体、液体 $\tau=0$ → $\alpha+\rho=1$（4-49），辐射与吸收都在表面进行；
- 气体的辐射与吸收在整个容积内进行。

## 黑体辐射：四次方定律（`#L7465-#L7485`）

辐射能力 $E=Q/A$（4-50）。黑体：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $E_b=\sigma T^4$ | （4-51） |
| **文字式** | $\text{黑体辐射能力}_{\text{【W/m²】}}=\text{斯蒂芬-玻尔兹曼常数}\times(\text{热力学温度}_{\text{【K】}})^4$ |  |

$\sigma=5.67\times10^{-8}$ W/(m²·K⁴)。工程式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $E_b=C_b\left(\dfrac{T}{100}\right)^4$ | （4-52） |
| **文字式** | $\text{黑体辐射能力}=5.67\times\left(\dfrac{\text{绝对温度}}{100}\right)^4$ |  |

$C_b=5.67$ W/(m²·K⁴)。因 $E\propto T^4$，称**四次方定律**。

**例4-23**：20 ℃ 时 $E_{b1}=418$ W/m²；600 ℃ 时 $E_{b2}=3.29\times10^4$ W/m²，比值 78.8——温度只变 30 倍，辐射能力变约 79 倍。低温时辐射可忽略，高温时成为主要传热方式。

## 黑度与灰体（`#L7499-#L7570`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\varepsilon=\dfrac{E}{E_b}$ | （4-53） |
| **文字式** | $\text{黑度}=\dfrac{\text{实际物体辐射能力}}{\text{同温度黑体辐射能力}}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $E=\varepsilon C_b\left(\dfrac{T}{100}\right)^4$ | （4-54） |
| **文字式** | $\text{实际物体辐射能力}=\text{黑度}\times5.67\times\left(\dfrac{\text{绝对温度}}{100}\right)^4$ |  |

也可写 $E=C(T/100)^4$（4-55），$C=5.67\varepsilon$。

- $\varepsilon<1$，只与材料、温度、表面状况有关；金属磨光面小、粗糙面大，氧化面较大；金属 $\varepsilon$ 随温度升高略增；非金属 0.85~0.95。
- 表4-8：钢板磨光 0.55~0.61、钢板氧化 0.8、铸铁磨光 0.21、铸铁氧化 0.64~0.78、紫铜磨光 0.03、紫铜氧化 0.78、铝磨光 0.039~0.057、铝氧化 0.11~0.19、红砖 0.93、耐火砖 0.8~0.9、玻璃 0.9~0.94。
- **灰体**：单色辐射能力随波长分布与黑体相似、黑度不随波长变的理想物体；工程上把实际物体当灰体处理。

## 克希霍夫定律（`#L7570-#L7616`）

两块无限大平行壁（一黑体一灰体）处于热平衡时，灰体净损失为零，得：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{E}{\alpha}=E_b,\qquad \alpha=\varepsilon$ | （4-56）（4-57） |
| **文字式** | $\dfrac{\text{辐射能力}}{\text{吸收率}}=\text{同温度黑体辐射能力}$，且 $\text{吸收率}=\text{黑度}$ |  |

物理含义：**善于吸收者必善于辐射**。吸收率与黑度相等，使实际物体的吸收率可用可测的黑度代替——这是把实际物体当灰体计算的理论依据。

## 判断

- 四次方定律解释了"为什么高温炉、火焰辐射不能用对流思维估算"：温差不大时辐射仍可能主导，因为 $T^4$ 对高温极敏感。
- 黑度同时承担"辐射能力"和"吸收率"两个角色（克希霍夫定律），这是灰体假设的全部价值；对波长选择性强的气体（CO₂、水蒸气）该假设不成立，需按气体辐射单独处理。

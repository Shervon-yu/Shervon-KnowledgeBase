# 各型搅拌器的传热膜系数

## 推进式（7-52）

$d/D=0.4\sim0.53$、$C/H=0.125\sim0.5$、$Re>100$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha=0.33\dfrac{\lambda}{D}Re^{2/3}Pr^{1/3}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}\left(\dfrac{d}{D}\right)^{-0.25}\left(\dfrac{C}{H}\right)^{0.15}$ | （7-52） |
| **文字式** | 与 7-49 同形，区别是几何修正项用离底高与**液面高**之比 $C/H$ |  |

（`#L7497`）

## 六叶后弯式（7-53）

$d/D=0.3\sim0.5$、$b/D=0.03\sim0.05$、$C/H=0.125\sim0.5$、$Re>100$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha=0.48\dfrac{\lambda}{D}Re^{2/3}Pr^{1/3}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}\left(\dfrac{d}{D}\right)^{-0.25}\left(\dfrac{b}{D}\right)^{0.15}\left(\dfrac{C}{H}\right)^{0.12}$ | （7-53） |
| **文字式** | 比推进式多一项叶宽修正 $(b/D)^{0.15}$ |  |

（`#L7511`）

## 锚式（7-54~7-56）

锚式混合效果不理想、釜内上下温度分布不均，α 只是近似值；**叶端与器壁间隙 e < 25 mm** 时：

| Re 范围 | 式 | 形式 |
|:---|:---:|:---|
| 30~300 | （7-54） | $1.0\,\lambda/D\cdot Re^{0.67}Pr^{0.33}(\mu/\mu_w)^{0.18}$ |
| 300~4000 | （7-55） | $0.38\,\lambda/D\cdot Re^{0.67}Pr^{0.33}(\mu/\mu_w)^{0.18}$ |
| 4000~37000（e 为 25~127 mm） | （7-56） | $0.55\,\lambda/D\cdot Re^{0.67}Pr^{0.25}(\mu/\mu_w)^{0.14}$ |

（`#L7515-#L7527`）

**α 随间隙 e 减小而增大**——锚式靠"刮"而非"搅"，e 越小边界层越薄。

## 螺带式（7-57/7-58）

$d/D\approx0.95$，边界层薄，利于槽壁传热；物料有轴向循环、上下温度均匀（`#L7531`）。

|  |  |  |
|:---|:---:|---:|
| **符号式**（$Re<130$） | $\alpha=0.248\dfrac{\lambda}{L}Re^{0.5}Pr^{0.33}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}\left(\dfrac{e}{D}\right)^{-0.22}\left(\dfrac{p}{d}\right)^{-0.26}$ | （7-57） |
| **文字式** | 层流区对间隙比与螺距比都敏感（负指数） |  |

|  |  |  |
|:---|:---:|---:|
| **符号式**（$Re>130$） | $\alpha=0.238\dfrac{\lambda}{D}Re^{0.67}Pr^{0.34}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}\left(\dfrac{p}{d}\right)^{-0.25}$ | （7-58） |
| **文字式** | 湍流区只对螺距比敏感 |  |

（`#L7535-#L7543`）

## 螺带-锚组合

| 组合 | 几何 | 层流区 | 过渡区 |
|:---|:---|:---|:---|
| 双螺带-锚 | $d/D=0.95$、$p/D=1.0$、$w/D=0.1$ | （7-59）$Re<100$：$0.752Re^{0.50}$ | （7-60）$Re<290$：$0.483Re^{0.60}$ |
| 内外螺带-锚 | $d/D=0.95$、$D_1/D=0.55$、$p/D=1.0$（内螺带反向）、$w/D=0.1$、$w_1/D=0.183$ | （7-61）$Re<100$：$0.682Re^{0.50}Pr^{1.33}$ | （7-62）$100<Re<317$：$0.358Re^{0.64}$ |

（`#L7545-#L7563`；7-61 的 Pr 指数 1.33 原文如此，与前几式差异明显，**待核**）

## MIG 大桨径多层

| 层数 | Re 范围 | 式 |
|:---|:---|:---|
| 四层 | 2.4~100 | （7-63）$0.65Re^{0.535}Pr^{0.33}(\mu/\mu_w)^{0.2}$ |
| 七层 | 3.8~100 | （7-64）$0.681Re^{0.593}Pr^{0.33}(\mu/\mu_w)^{0.2}$ |

（`#L7565-#L7575`）

## 判断

锚式与螺带的式子都带着 $e$（间隙）的负指数，这不是笔误：高黏流体里传热几乎全靠壁面附近的"刮擦更新"，间隙每大一档，边界层就厚一层。因此**高黏釜的传热能力主要由制造精度（间隙）决定，而不是转速**——这与低黏体系"靠湍流强度"完全不同。

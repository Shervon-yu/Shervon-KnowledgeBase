# 平盖中心大开孔的计算

等面积法管不到中心大孔：孔一大，平盖的承载机理就从"被孔削弱的平板"变成"法兰+孔"的耦合结构，标准把界限划在 $d_{op}=0.5D_o$。超过这条线，8.5 给两套算法，按连接方式分：

- **螺栓连接的平盖**：按第 9 章**当法兰结构**算（8.5.1，`#L8140-#L8142`）——因为它本来就是靠螺栓压紧的法兰板；
- **焊接的平盖**（与圆筒对接焊、须全焊透，`#L8148`）：走 8.5.2.2~8.5.2.5，本页讲的就是这条。适用对象是表 7-9 序号 2~7、表 7-10 所列平盖，带不带接管都算；带接管时平盖与接管连接处须整体结构或全焊透（图 8-11）。

符号沿用 9.3；$\delta_p$ 平盖厚度、$\delta_0$ 圆筒厚度、$\delta_1$ 接管处厚度（图 8-11）。

## 一、计算力矩（8.5.2.2，`#L8154-#L8196`）

思路：略去与平盖连接的圆筒，按法兰原理把压力分成"孔盖区"和"环形区"两块，各自乘力臂。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_D=0.785d_{op}^2p_c$；$\quad S_D=\dfrac{D_i-(d_{op}+\delta_1)}{2}$ | （8-16）（8-17） |
| **文字式** | $\text{孔盖区作用力}=0.785\times\text{开孔直径}^2\times\text{计算压力}$；$\quad\text{力臂}=\dfrac{\text{平盖内直径}-(\text{开孔直径}+\text{接管处厚度})}{2}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_T=0.785p_c\left(D_i^2-d_{op}^2\right)$；$\quad S_T=\dfrac{D_i-d_{op}}{4}$ | （8-18）（8-19） |
| **文字式** | $\text{环形区作用力}=0.785\times\text{计算压力}\times(\text{平盖内直径}^2-\text{开孔直径}^2)$；$\quad\text{力臂}=\dfrac{\text{平盖内直径}-\text{开孔直径}}{4}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_o=F_DS_D+F_TS_T$ | （8-15） |
| **文字式** | $\text{计算力矩}=\text{孔盖区作用力}\times\text{力臂}+\text{环形区作用力}\times\text{力臂}$ |  |

## 二、平盖自身的三个应力（式8-20~8-22）

取 $K=D_o/d_{op}$，$f$、$\lambda$、$e$ 按**开孔处接管参数**从 9.3 取；$Y$、$Z$ 查相应图表。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_H=\dfrac{fM_o}{\lambda\delta_1^2d_{op}}$ | （8-20） |
| **文字式** | $\text{颈部轴向应力}=\dfrac{\text{颈部系数}\times\text{计算力矩}}{\text{力矩系数}\times\text{接管处厚度}^2\times\text{开孔直径}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_R=\dfrac{(1.33\delta_pe+1)M_o}{\lambda\delta_p^2d_{op}}$ | （8-21） |
| **文字式** | $\text{径向应力}=\dfrac{(1.33\times\text{平盖厚度}\times\text{系数}e+1)\times\text{计算力矩}}{\text{力矩系数}\times\text{平盖厚度}^2\times\text{开孔直径}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_T=\dfrac{YM_o}{\delta_p^2d_{op}}-Z\sigma_R$ | （8-22） |
| **文字式** | $\text{环向应力}=\dfrac{\text{系数}Y\times\text{计算力矩}}{\text{平盖厚度}^2\times\text{开孔直径}}-\text{系数}Z\times\text{径向应力}$ |  |

**不带接管**的开孔平盖，其 $\sigma_H=\sigma_R=0$，只算 $\sigma_T$（`#L8196`）。

## 三、平盖与圆筒连接处的应力（8.5.2.3，`#L8198-#L8266`）

这一步才算"平盖与筒体互相拉扯"：先求相容参数 $(E\theta)$，再求连接力矩 $M_H$，再求三个应力。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(E\theta\right)=\dfrac{0.91\left(\delta_1/\delta_0\right)^2D_{i1}V_1}{fh_o}\sigma_H$（带接管）；$\quad\left(E\theta\right)=\dfrac{d_{op}}{\delta_p}\sigma_T$（无接管） | （8-23）（8-24） |
| **文字式** | $\text{相容参数}=\dfrac{0.91\times(\text{接管处厚度}/\text{圆筒厚度})^2\times\text{计算直径}\times\text{系数}V_1}{\text{颈部系数}\times\text{系数}h_o}\times\text{颈部轴向应力}$；无接管时用开孔直径与平盖厚度之比乘环向应力 |  |

式中 $D_{i1}=D_i+\delta_1$（$f<1.0$）或 $D_i+\delta_0$（$f\ge1.0$），$V_1$、$f$、$h_o$ 按开孔处接管参数取。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_H=\dfrac{(E\theta)}{\dfrac{1.74h_oV_1}{\delta_0^3D_{i1}}+\dfrac{(E\theta)}{M_o}\left(1+\dfrac{F_1\delta_p}{h_o}\right)}$ | （8-25） |
| **文字式** | $\text{连接处力矩}=\dfrac{\text{相容参数}}{\dfrac{1.74\times\text{系数}h_o\times\text{系数}V_1}{\text{圆筒厚度}^3\times\text{计算直径}}+\dfrac{\text{相容参数}}{\text{计算力矩}}\times\left(1+\dfrac{\text{系数}F_1\times\text{平盖厚度}}{\text{系数}h_o}\right)}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $x_1=\dfrac{M_o-M_H\left(1+\dfrac{F_1\delta_p}{h_o}\right)}{M_o}$ | （8-26） |
| **文字式** | $\text{力矩分配系数}=\dfrac{\text{计算力矩}-\text{连接处力矩}\times\left(1+\dfrac{\text{系数}F_1\times\text{平盖厚度}}{\text{系数}h_o}\right)}{\text{计算力矩}}$ |  |

$x_1$ 的含义：$M_o$ 分给筒体连接处多少、留在平盖上多少。$F_1$、$h_o$ 按**平盖外径处圆筒**参数取。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{Hs}=x_1(E\theta)\dfrac{1.1h_of}{\left(\delta_1/\delta_0\right)^2D_iV_1}$；$\quad\sigma_{Rs}=\dfrac{1.91M_H\left(1+\dfrac{F_1\delta_p}{h_o}\right)}{D_i\delta_p^2}+\dfrac{0.64F_1M_H}{D_ih_o\delta_p}$；$\quad\sigma_{Ts}=\dfrac{x_1(E\theta)\delta_p}{D_i}-\dfrac{0.57\left(1+\dfrac{F_1\delta_p}{h_o}\right)M_H}{D_i\delta_p^2}+\dfrac{0.64F_1Z_1M_H}{D_ih_o\delta_p}$ | （8-27）～（8-29） |
| **文字式** | 连接处圆筒颈部轴向应力、平盖外径处径向应力、平盖外径处环向应力，三者均由 $\text{力矩分配系数}\times\text{相容参数}$ 与连接处力矩 $M_H$ 组合而成 |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Z_1=\dfrac{K^2+1}{K^2-1}$；$\quad K=D_o/d_{op}$ | （8-30）（8-31） |
| **文字式** | $\text{系数}Z_1=\dfrac{\text{系数}K^2+1}{\text{系数}K^2-1}$；$\quad\text{系数}K=\text{平盖外直径}/\text{开孔直径}$ |  |

## 四、开孔处的应力（8.5.2.4，`#L8268-#L8284`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{Ho}=x_1\sigma_H$；$\quad\sigma_{Ro}=x_1\sigma_R$；$\quad\sigma_{To}=x_1\sigma_T+\dfrac{0.64F_1Z_2M_H}{D_ih_o\delta_p}$ | （8-32）～（8-34） |
| **文字式** | 开孔处接管颈部轴向应力、平盖径向应力、平盖环向应力：前两者按力矩分配系数折减，第三项再叠加连接处力矩的贡献 |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Z_2=\dfrac{2K^2}{K^2-1}$ | （8-35） |
| **文字式** | $\text{系数}Z_2=\dfrac{2\times\text{系数}K^2}{\text{系数}K^2-1}$ |  |

## 五、校核（8.5.2.5，`#L8288-#L8290`）

连接处的 $\sigma_{Hs}$、$\sigma_{Rs}$、$\sigma_{Ts}$ 与开孔处的 $\sigma_{Ho}$、$\sigma_{Ro}$、$\sigma_{To}$ **分别**满足 9.5.3.4 对 $\sigma_H$、$\sigma_R$、$\sigma_T$ 的相应要求，即：

- $\sigma_R\le[\sigma]_f^t$；$\sigma_T\le[\sigma]_f^t$；
- $\sigma_H\le\min\{1.5[\sigma]_f^t,\ 2.5[\sigma]_n^t\}$（一般整体法兰）或更严的 1.5/1.5 或 1.5$[\sigma]_f^t$（按法兰型式，见 9.5.3.4）；
- 组合应力 $(\sigma_H+\sigma_R)/2$ 与 $(\sigma_H+\sigma_T)/2$ 均 $\le[\sigma]_f^t$。

## 判断

- 大开孔平盖的本质**不是"带孔的板"，是"法兰"**：$M_o$ 由两块压力区力矩合成，$M_H$ 由平盖与筒体的边缘相容条件解出，$x_1$ 把力矩在两者之间分配——这套完全是 9.5 法兰方法的移植。所以 8.5 反复说"符号见 9.3"、"满足 9.5.3.4"，它没有独立的许用值。
- $x_1$ 是关键中间量：$x_1\to1$ 表示力矩基本留在平盖上（筒体刚、约束弱），$x_1\to0$ 表示力矩被筒体吸收。它同时缩放 $\sigma_H$、$\sigma_R$、$\sigma_T$ 并出现在连接处三个应力里，所以算错 $x_1$ 会同时错六项。
- 要算**两处**六个应力而不是一处三项：连接处控制筒体颈部，开孔处控制孔边——平盖大开孔的两个危险点就在这里，$Z_2$ 项只出现在开孔处环向应力，正是孔边的额外放大。
- 无接管情形 $(\sigma_H=\sigma_R=0)$ 是公式的结构性退化，不是简化假设：没有接管就没有颈部，$f$、$\lambda$ 等系数失去意义，只剩 $\sigma_T$ 与 $(\mathrm{E}\theta)=d_{op}\sigma_T/\delta_p$ 一条链。
- 边界 $d_{op}=0.5D_o$ 由等面积法一侧的适用上限（8.1.2）与本节的起点对齐；$d_{op}$ 再大就要考虑平盖是否还属"平板"范畴，标准未再放宽。

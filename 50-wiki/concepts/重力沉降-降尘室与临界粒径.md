# 重力沉降-降尘室与临界粒径

## 定义

**重力沉降**：由地球引力作用发生的颗粒沉降（#L4628）。颗粒互不接触、互不碰撞条件下的沉降称**自由沉降**（#L4634）；颗粒密集、相互影响时称**干扰沉降**，速度比自由沉降小（#L4710）；靠近器壁时受**壁效应**影响，速度也偏小（#L4708）。

**降尘室**（dust-settling chamber）是最典型的重力降尘设备：含尘气体进入后流道扩大、流速下降，只要气体在室内的**停留时间**不小于尘粒自顶部沉到底部所需的**沉降时间**，尘粒即可分离；通常用于分离 $50\ \mu m$ 以上的粗颗粒（#L4716、#L4720）。能 100% 除去的最小粒径称**临界粒径** $d_{pc}$（#L4746）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{L}{u}\geqslant\dfrac{H}{u_{\mathrm{t}}}$ | （3.2-1） |
| **文字式** | $\dfrac{\text{降尘室长度}_{\text{【m】}}}{\text{气体水平流速}_{\text{【m/s】}}}\geqslant\dfrac{\text{降尘室高度}_{\text{【m】}}}{\text{颗粒沉降速度}_{\text{【m/s】}}}$ |  |

（式 3-15，停留时间 ≥ 沉降时间，#L4726。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_{\mathrm{t}}\geqslant\dfrac{q_{V\mathrm{s}}}{WL}$ | （3.2-2） |
| **文字式** | $\text{颗粒沉降速度}_{\text{【m/s】}}\geqslant\dfrac{\text{含尘气体体积流量}_{\text{【m³/s】}}}{\text{降尘室宽度}_{\text{【m】}}\times\text{降尘室长度}_{\text{【m】}}}$ |  |

（式 3-16，由 $u=q_{V\mathrm{s}}/(HW)$ 代入式 3-15 得，#L4732、#L4736。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{\mathrm{pc}}=\sqrt{\dfrac{18\mu}{\left(\rho_{\mathrm{p}}-\rho\right)g}\,u_{\mathrm{tc}}}=\sqrt{\dfrac{18\mu\,q_{V\mathrm{s}}}{\left(\rho_{\mathrm{p}}-\rho\right)g\,WL}}$ | （3.2-3） |
| **文字式** | $\text{临界粒径}_{\text{【m】}}=\sqrt{\dfrac{18\times\text{流体黏度}_{\text{【Pa·s】}}}{\left(\text{颗粒密度}_{\text{【kg/m³】}}-\text{流体密度}_{\text{【kg/m³】}}\right)\times\text{重力加速度}_{\text{【m/s²】}}}\times\text{临界沉降速度}_{\text{【m/s】}}}$ |  |

（式 3-18，层流区/斯托克斯区，#L4754；$u_{\mathrm{tc}}=q_{V\mathrm{s}}/(WL)$ 见式 3-17 #L4744。）

**设备含义（书中明说）**：$q_{V\mathrm{s}}$ 一定时，$d_{pc}$ 与 $u_{\mathrm{tc}}$ 与降尘室**底面积 $WL$ 成反比，与高度 $H$ 无关**（#L4758）——所以降尘室做成扁平多层比加高更有效。

## 适用范围与边界

- 式 3-18 只在**层流区（斯托克斯区）**成立（#L4752）；湍流区须用式 3-13、3-14 的 $u_{t}$ 反解（#L4750 指明「代入式(3-12)至式(3-14)」）。
- 降尘室只适合粗颗粒（≈50 μm 以上，#L4720）；更细颗粒须走离心沉降（#L4836）。
- 自由沉降是理想假定；实际粉尘浓度高时为干扰沉降，式 3-16 会低估所需底面积（#L4710）。
- 沉聚、澄清器、增稠器（底流/溢流）属同一节的设备分支，其计算未在本书展开（#L4816、#L4828）。

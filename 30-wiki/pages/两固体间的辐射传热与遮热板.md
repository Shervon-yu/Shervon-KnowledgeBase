# 两固体间的辐射传热与遮热板

## 基本式（`#L7620-#L7636`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q_{1-2}=C_{1-2}\,\varphi\,A\left[\left(\dfrac{T_1}{100}\right)^4-\left(\dfrac{T_2}{100}\right)^4\right]$ | （4-58） |
| **文字式** | $\text{辐射传热速率}_{\text{【W】}}=\text{总辐射系数}\times\text{角系数}\times\text{面积}\times\left[\left(\dfrac{\text{热面温度}}{100}\right)^4-\left(\dfrac{\text{冷面温度}}{100}\right)^4\right]$ |  |

- $\varphi$：角系数，表面 1 发射的总辐射能中到达表面 2 的分数，取决于形状、尺寸、相对位置与距离；
- $C_{1-2}$：总辐射系数，取决于两表面黑度 $\varepsilon_1$、$\varepsilon_2$；
- $A$：两表面不等时取**较小**者。

## 三种典型几何（`#L7640-#L7676`）

| 情况 | $A$ | $\varphi$ | $C_{1-2}$ |
|:--|:--|:--|:--|
| 无限大平行平壁 | $A_1=A_2$ | 1 | $\dfrac{C_b}{\dfrac{1}{\varepsilon_1}+\dfrac{1}{\varepsilon_2}-1}$（4-59） |
| 有限大平行壁 | $A_1=A_2$ | <1，查图4-33 | $\varepsilon_1\varepsilon_2C_b$（4-60） |
| 物体 1 被物体 2 包围 | $A_1$ | 1 | $\dfrac{C_b}{\dfrac{1}{\varepsilon_1}+\dfrac{A_1}{A_2}\left(\dfrac{1}{\varepsilon_2}-1\right)}$（4-61） |

包围情形的两种简化：
- $A_1/A_2\approx1$ → 退化为 4-59（按平行平壁）；
- $A_1\ll A_2$ → $C_{1-2}=\varepsilon_1C_b$（4-62），此时与 $A_2$、$\varepsilon_2$ 无关。

结论：$\varepsilon_1$、$\varepsilon_2$ 越大 → $C_{1-2}$ 越大 → 辐射越强。

## 例4-24（`#L7682-#L7694`）

φ100 mm 氧化铸铁管（$\varepsilon_1$=0.71）插入 0.2 m 见方耐火砖烟道（$\varepsilon_2$=0.9），管 400 ℃、烟道壁 1000 ℃：

$A_1=\pi\times0.1\times1=0.314$ m²、$A_2=4\times0.2\times1=0.8$ m²、$\varphi=1$、$A=A_1$；

$C_{1-2}=5.67/\left[\frac{1}{0.71}+\frac{0.314}{0.8}\left(\frac{1}{0.9}-1\right)\right]=3.9$ W/(m²·K⁴)；

$Q_{1-2}=3.9\times1\times0.314\times[(6.73)^4-(12.73)^4]=-2.96\times10^4$ W——**负号表示铸铁管从烟道吸热**。

## 例4-25 热电偶测温误差（`#L7696-#L7718`）

管道内壁 200 ℃、热电偶指示 400 ℃、$\alpha=50$、$\varepsilon=0.4$。稳态下：气体对热电偶的对流热 = 热电偶向管壁的辐射热：

$$50(t-400)=0.4\times5.67\times1\times\left[\left(\frac{400+273}{100}\right)^4-\left(\frac{200+273}{100}\right)^4\right]\Rightarrow t=470\ \text{℃}$$

- 指示温度偏低 70 ℃，原因是热电偶向低温管壁辐射散热；
- 对策：管道保温（提高壁温）、热电偶周围加遮热板。

## 遮热板（`#L7732-#L7782`）

插入薄板后，串起两段辐射：$Q_{1-3}=Q_{3-2}$。

**例4-26**：0.5×0.5 m 铸铁炉门 600 ℃、室温 30 ℃、$\varepsilon_1$=0.78：

- 无遮热板：$C_{1-2}=\varepsilon_1C_b=4.42$ → $Q=6330$ W；
- 加同尺寸氧化铝板（$\varepsilon_3$=0.15）：$C_{1-3}=\frac{5.67}{1/0.78+1/0.15-1}=0.816$、$C_{3-2}=0.851$，由 $Q_{1-3}=Q_{3-2}$ 解得 $T_3=460$ ℃；
- 有遮热板时 $Q_{1-3}=596$ W，仅为无板时的 **9.4%**。

## 辐射与对流的联合传热（`#L7784-#L7812`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=(\alpha_c+\alpha_r)A_1(T_1-T_2)$ | （4-65） |
| **文字式** | $\text{总散热}=(\text{对流传热系数}+\text{辐射传热系数})\times\text{表面积}\times\text{表面与环境温差}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha_r=\dfrac{C_{1-2}\left[(T_1/100)^4-(T_2/100)^4\right]}{T_1-T_2}$ | （4-66） |
| **文字式** | $\text{辐射传热系数}=\dfrac{\text{总辐射系数}\times\left[\left(\dfrac{T_1}{100}\right)^4-\left(\dfrac{T_2}{100}\right)^4\right]}{\text{两表面温差}}$ |  |

注意：高温下即使温差小，辐射仍可能很大；空气温度与包围物温度不同时不能合并成 4-65，须分开算。

## 判断

- 遮热板把辐射"一分为二"后总热阻加倍，且低黑度板把每段热阻进一步放大——9.4% 的结果说明**低黑度＋多层**是削弱辐射最有效的手段，这也是保温瓶镀银、真空夹层的原理。
- 角系数与总辐射系数的取值是辐射计算最容易出错的地方：几何上"谁被谁包围"决定用 4-59 还是 4-61，工程上宁可保守取 $\varphi=1$、按被包围物体面积算。

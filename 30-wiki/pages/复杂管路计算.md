# 复杂管路计算

## 两类复杂管路（`#L2659-#L2661`）

- **并联管路**：主管分出两支或多支，之后又重新汇合；
- **分支管路**：在主管处分出，之后不再汇合。

## 并联管路的两条基本关系（`#L2661-#L2681`）

**流量守恒**（节点）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_V=q_{V1}+q_{V2}$ | （1-64） |
| **文字式** | $\text{总管流量}=\text{支管1流量}+\text{支管2流量}$ |  |

**阻力相等**（共同起点 A、共同终点 B，各支管两端压差相同）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{f1}=h_{f2}=h_{fAB}$ | （1-65） |
| **文字式** | $\text{支管1阻力损失}=\text{支管2阻力损失}=\text{并联段总阻力损失}$ |  |

要点：**并联各支管的阻力损失相同，但流量一般不同**——流量按"谁阻力小谁多流"分配。

## 流量分配比（`#L2683-#L2697`）

把 $h_f=\lambda\dfrac{l}{d}\dfrac{u^2}{2}$ 用 $u=\dfrac{q_V}{\pi d^2/4}$ 换掉，得 $h_f=\dfrac{8\lambda lq_V^2}{\pi^2d^5}$，代入 1-65：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{V1}:q_{V2}=\sqrt{\dfrac{d_1^5}{\lambda_1l_1}}:\sqrt{\dfrac{d_2^5}{\lambda_2l_2}}$ | （1-66） |
| **文字式** | $\text{支管1流量}:\text{支管2流量}=\sqrt{\dfrac{\text{支管1内径}^5}{\text{支管1摩擦系数}\times\text{支管1长度}}}:\sqrt{\dfrac{\text{支管2内径}^5}{\text{支管2摩擦系数}\times\text{支管2长度}}}$ |  |

管径的 5 次方最敏感：**管径差一倍，流量差约 5.7 倍**。

单个支管流量：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{q_{V1}}{q_V}=\dfrac{\sqrt{d_1^5/(\lambda_1l_1)}}{\sqrt{d_1^5/(\lambda_1l_1)}+\sqrt{d_2^5/(\lambda_2l_2)}}$ | （1-67） |
| **文字式** | $\dfrac{\text{支管1流量}}{\text{总管流量}}=\dfrac{\text{支管1的}\sqrt{d^5/(\lambda l)}}{\text{支管1的}\sqrt{d^5/(\lambda l)}+\text{支管2的}\sqrt{d^5/(\lambda l)}}$ |  |

## 为什么要试差（`#L2703-#L2709`）

1-67 里有 $\lambda_1$、$\lambda_2$，而 $\lambda$ 取决于各支管自己的 $Re$，$Re$ 又取决于待求的 $q_{V1}$、$q_{V2}$——**循环依赖**。

标准做法：
1. 在完全湍流区（阻力平方区）$\lambda$ 只与 $\varepsilon/d$ 有关，先按 $\varepsilon_1/d_1$、$\varepsilon_2/d_2$ 查图定 $\lambda_1$、$\lambda_2$；
2. 用 1-67 算出 $q_{V1}$、$q_{V2}$；
3. 由流量算 $Re_1$、$Re_2$，查图得新 $\lambda$；
4. 与假设值比较，迭代到接近为止。

若流动不在阻力平方区，第 1 步的初值只能凭经验或先估 $Re$。

## 分支管路（`#L2711-#L2718`）

主管分出后不再汇合。此时各分支的**总机械能头相同**（从同一分叉点算起），但各分支的位头、压力不同，故不能用 1-65 的"阻力相等"直接套；原文只给出定性说明，具体计算需按各支路分别列机械能衡算式逐段求解。

## 判断

- 并联管路的"阻力相等"是结果不是假设：它来自两端点相同这一几何事实。
- 工程上常把并联流量分配当作"自动平衡"：阻力大的支管流量小到几乎不走，这就是换热器并联时偏流的根源。

# 传质单元高度与传质单元数

## 乘积形式（`#L9872-#L9896`）

把积分式改写为"层高×层数"的形式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Z=H_G N_G=H_L N_L=H_{OG}N_{OG}=H_{OL}N_{OL}$ | （5-61） |
| **文字式** | $\text{填料层高度}=\text{传质单元高度}\times\text{传质单元数}$ |  |

四种口径：

| 口径 | 高度 | 单元数 |
|:--|:--|:--|
| 气膜 | $H_G=\dfrac{G}{k_Ya\Omega}$（5-62） | $N_G=\int_{Y_2}^{Y_1}\dfrac{\mathrm{d}Y}{Y-Y_i}$ |
| 液膜 | $H_L=\dfrac{L}{k_Xa\Omega}$（5-63） | $N_L=\int_{X_2}^{X_1}\dfrac{\mathrm{d}X}{X_i-X}$ |
| 气相总 | $H_{OG}=\dfrac{G}{K_Ya\Omega}$（5-64） | $N_{OG}=\int_{Y_2}^{Y_1}\dfrac{\mathrm{d}Y}{Y-Y^{*}}$ |
| 液相总 | $H_{OL}=\dfrac{L}{K_Xa\Omega}$（5-65） | $N_{OL}=\int_{X_2}^{X_1}\dfrac{\mathrm{d}X}{X^{*}-X}$ |

比喻（原文）：像楼房高度 = 每层高 × 层数。

## 两个量的物理含义（`#L9898-#L9910`）

- **传质单元数** $N_{OG}$：由积分中值定理

  |  |  |  |
  |:---|:---:|--:|
  | **符号式** | $N_{OG}=\dfrac{Y_1-Y_2}{(Y-Y^{*})_{\mathrm{m}}}=\dfrac{\text{气相组成变化}}{\text{平均传质推动力}}$ | （5-66） |
  | **文字式** | $\text{传质单元数}=\dfrac{\text{气相组成变化}}{\text{平均传质推动力}}$ |  |

  它反映**分离任务的难易**：推动力越大，$N_{OG}$ 越小，塔越矮。

- **传质单元高度** $H_{OG}$：$N_{OG}=1$ 时所需的填料层高度，是 $G/\Omega$ 与 $1/(K_Ya)$ 的乘积——前者是单位截面积的气体流量，后者反映传质阻力。阻力小 → $H_{OG}$ 小 → 塔矮。常用填料塔 $H_{OG}$ 量级 **0.1~1.0 m**。

## 三条比例关系（`#L9910-#L9930`）

- $K_Ya\propto G^{0.8}$，而 $H_{OG}=G/(K_Ya\Omega)$ → $H_{OG}\propto G^{0.2}$：气速变化对 $H_{OG}$ 影响很弱（这也是填料塔操作弹性小的原因之一）。
- $K_Y=pK_G$ → $H_{OG}=\dfrac{G}{pK_Ga\Omega}$：$H_{OG}$ **与总压成反比**——加压吸收既提高溶解度（$m$ 减小），又降低 $H_{OG}$，双重有利。
- $K_X=cK_L$ → $H_{OL}=\dfrac{L}{cK_La\Omega}$：$H_{OL}$ 与溶液总浓度 $c$ 成反比。

## 吸收因数与高度换算（`#L9932-#L9956`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H_{OG}=H_G+\dfrac{mG}{L}H_L$，$H_{OL}=\dfrac{L}{mG}H_G+H_L$，$H_{OG}=\dfrac{mG}{L}H_{OL}$ | （5-67）~（5-69） |
| **文字式** | $\text{气相总单元高度}=\text{气膜单元高度}+\text{吸收因数倒数}\times\text{液膜单元高度}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_{OG}=\dfrac{L}{mG}N_{OL}$ | （5-71） |
| **文字式** | $\text{气相总单元数}=\text{吸收因数}\times\text{液相总单元数}$ |  |

**吸收因数** $A=L/(mG)$：操作线斜率与平衡线斜率之比。$A$ 越大，操作线越远离平衡线、推动力越大、对吸收越有利。工程上常取 $L/(mG)=1.0\sim2.0$。

## 判断

- $H_{OG}$ 与 $N_{OG}$ 的分工非常清晰：前者是"设备行不行"（填料性能、气液分布），后者是"任务难不难"（平衡、液气比、分离要求）。设计时改填料/气速动 $H_{OG}$，改液气比/温度/压力动 $N_{OG}$。
- $H_{OG}\propto G^{0.2}$ 说明"加大气速提高处理量"几乎不增加塔高，但气速上限受液泛与压降限制——真正的约束在流体力学，不在传质。

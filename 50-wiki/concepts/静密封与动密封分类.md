# 静密封与动密封分类

## 定义

密封分两大类：**静密封**——密封部位相对静止（管道法兰、螺纹连接、压力容器与盖）；**动密封**——密封部位有相对运动。动密封再按运动形式分旋转密封与往复密封，按密封件与运动件是否接触分接触式、非接触式、无轴封三类，另有把两类组合起来的组合式密封。《机械密封结构图例及应用》§1.2.1 #L372、#L402

## 分类树

```
密封
├─ 静密封 ── 按压力：中低压 / 高压
│           └ 按原理：法兰垫片 · 自紧 · 研合面 · O形环 · 胶圈 · 填料
│                    · 螺纹连接垫片 · 螺纹连接 · 承插连接 · 密封胶
└─ 动密封 ─ 按运动：旋转 / 往复
            ├ 接触式 ── 圆周(径向) / 端面(轴向,即机械密封)
            │           填料 · 油封 · 涨圈 · 机械密封
            ├ 非接触式 ─ 迷宫 + 动力密封(离心 · 浮环 · 螺旋 · 气压 · 喷射 · 水力 · 磁流体)
            └ 无轴封 ── 隔膜式 · 屏蔽式 · 磁力传动式
```

## 静密封：按原理十类及边界

| 型式 | 关键工况上限 | 行号 |
|:---|:---|:---|
| 法兰连接垫片 | −70~600 ℃，>1.333 kPa(绝压) 且 ≤35 MPa；特殊垫片可更高 | #L380 |
| 自紧密封 | ≤100 MPa、≤350 ℃（平垫式；自紧环用于高压容器法兰） | #L382 |
| 研合面 | Ra 2~5 μm、自由态间隙 ≤0.05 mm、≤100 MPa、≤550 ℃ | #L384 |
| O 形环（非金属） | 压缩 15%~30%，≤100 MPa，适用于气缸/油缸 | #L386 |
| O 形环（金属空心） | 直径至 6000 mm、280 MPa、−250~600 ℃；壁厚 0.25~0.5 mm（最大 1 mm） | #L386 |
| 胶圈 | ≤200 ℃、0.4 MPa，快速装拆场合 | #L388 |
| 填料（盘根） | 随填料材质定，用于可拆式内伸接管 | #L390 |
| 螺纹连接垫片 | 金属平垫（活接头）32 MPa、DN ≤32 mm | #L392 |
| 螺纹连接 | ≤1.6 MPa、DN ≤50 mm，须加密封材料 | #L394 |
| 承插连接 | 常压、非重要管道 | #L396 |
| 密封胶 | ≤150 ℃，平面法兰/螺纹/承插均可用 | #L398 |

静密封建压逻辑：中低压用软而宽的垫片，高压用硬而窄的金属垫片。#L376

## 动密封：三类及边界

**接触式**——密封面靠紧甚至嵌入，密封性好，受摩擦磨损限制，用于线速度较低场合。#L402

| 型式 | 工况上限 | 行号 |
|:---|:---|:---|
| 毛毡 | ≤90 ℃；粗毛毡 v ≤3 m/s，优质细毛毡经抛光轴 ≤10 m/s | #L408 |
| 软填料 | ≤35 MPa、≤600 ℃、≤20 m/s；泄漏率 10~1000 mL/h | #L410 |
| 硬填料 | 350 MPa、12 m/s、−45~400 ℃，需冷却或加热 | #L412 |
| 挤压型（O 形等） | 真空 1.33×10⁻⁵ Pa~40 MPa、−60~200 ℃、≤3.5 m/s | #L414 |
| 唇型 | 结构复杂、自紧显著，主要往复运动；选材得当可达 100 MPa | #L416 |
| 油封 | 自紧式唇型，不能承受高压；封油、封气、防尘 | #L418 |
| 涨圈 | ≤200 ℃、≤10 m/s；往复 ≤70 MPa，旋转 ≤1.5 MPa | #L420 |
| 机械密封 | 轴径 5~2000 mm、真空 10⁻⁶ MPa~45 MPa、−200~450 ℃、线速度 150 m/s；寿命 8000~25000 h | #L422 |

**非接触式**——预留固定间隙，无摩擦磨损、启动功率小、寿命长，但密封性较差，适用较高速度；泄漏量随运转条件波动大，市场上买不到成品，基本由用户自行设计。#L424

- 迷宫（梳齿）：靠节流与膨胀腔耗能；圆周速度 >5 m/s 时润滑脂可能被甩出；不受转速温度限制，用于级间与轴端。#L426
- 浮环：>10 MPa、10000~20000 r/min、线速度 >100 m/s，需复杂自动供油系统。#L430
- 离心、螺旋、气压、喷射、水力、磁流体各有专限（离心仅液体；螺旋不适用气体；气压需高于介质 0.03~0.05 MPa 气源；水力切向速度不宜超 50 m/s；磁流体不耐高温）。#L428–#L440

**无轴封**——目标为完全无泄漏，用于剧毒、易燃易爆、贵重介质：隔膜式（<50 MPa）、屏蔽式、磁力传动式（传递功率目前 ≤75 kW）。#L442–#L448

## 适用范围与边界

- 上述数值是**本书给出的适用上限**，不是设计准则；选型时同一工况往往有多种型式可选，本书要求先做分析比较再定（§1.2.2 #L450）。
- 机械密封同时存在接触式与非接触式两种形态（§1.2.1 #L404），归入哪一支取决于具体结构，不能一概而论。
- 组合式密封（填料-迷宫、螺旋-填料、迷宫-浮环等）不属上述任一单类，本书列在密封方法组合中（§1.1.2 #L330）。

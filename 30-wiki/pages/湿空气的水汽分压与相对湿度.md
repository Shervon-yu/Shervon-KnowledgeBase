# 湿空气的水汽分压与相对湿度

## 基准（`#L13739`）

湿空气 = 干空气 + 水汽，可视为理想气体。干燥中水汽量不断增加而**干空气质量不变**，故湿空气性质一律以 **1 kg 干空气**为基准。

## 水汽分压（`#L13745-#L13753`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p=p_v+p_g$ | （7-1） |
| **文字式** | $\text{总压}=\text{水汽分压}+\text{干空气分压}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p_v=py$ | （7-2） |
| **文字式** | $\text{水汽分压}=\text{总压}\times\text{水汽摩尔分数}$ |  |

总压一定时 $p_v$ 越大，水汽含量（摩尔分数 $y$）越高；$p_v$ 达到该温度下水的饱和蒸气压 $p_s$ 时，空气被水汽饱和。

## 相对湿度（`#L13757-#L13765`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\varphi=\dfrac{p_v}{p_s}\times100\%$ | （7-3） |
| **文字式** | $\text{相对湿度}=\dfrac{\text{水汽分压}}{\text{同温度下水的饱和蒸气压}}\times100\%$ |  |

$p_s=f(t)$，所以 $\varphi$ 由 $p_v$ 与 $t$ **共同**决定：

| $p_v$ | $\varphi$ | 状态 |
|:--|:--|:--|
| 0 | 0 | 干空气 |
| $p_v<p_s$ | <1 | 未饱和湿空气 |
| $p_v=p_s$ | 1 | 饱和湿空气 |

## 判断

- "相对"二字的关键：同一个 $p_v$，温度不同则 $p_s$ 不同、$\varphi$ 不同。升温使 $p_s$ 增大、$\varphi$ 下降——这正是预热能增强干燥能力的原因。
- 干燥介质永远是未饱和空气（$\varphi<100\%$），否则不能吸湿。
- 相对湿度不是含水量指标；绝对含水量看湿度 $H$（下一个断言簇）。

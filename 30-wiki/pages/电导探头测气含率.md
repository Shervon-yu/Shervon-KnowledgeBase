# 电导探头测气含率

## 针数与功能（`#L260`）

| 系统 | 可测参数 |
|:--|:--|
| 单针 | 气泡频率 |
| 双针 | 气泡速度、局部时均相界面、局部气含率 |
| 多针 | 气泡形状 |

## 双针工作原理（`#L260`）

上升气泡被两针先后穿过，气液两相电导率差异使电路产生**两个有时间间隔的脉冲**；每个脉冲代表 1 个气泡经过针尖。采集脉冲序列即可算局部气含率。

## 时均气含率（`#L276-#L279`）

设采样时间 $t$，第 $i$ 个气泡的停留时间间隔为 $\Delta t_i$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\varepsilon_g=\dfrac{\sum \Delta t_i}{t}$ | （1.1） |
| **文字式** | $\text{时均气含率}=\dfrac{\text{各气泡在探针处的停留时间之和}}{\text{总采样时间}}$ |  |

## 径向分布经验式（`#L282-#L288`）

吕术森修正 T. Miyauchi 的鼓泡塔径向分布经验式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\varepsilon_g=\left[1.312+0.1856\dfrac{h}{H}\right]\left\{\varepsilon_0\left[1-\dfrac{4}{5}\left(\dfrac{r}{R}\right)^2\right]\right\}$，$\varepsilon_0=0.0156V_g^{0.855}$ | （1.2） |
| **文字式** | $\text{局部气含率}=\left[1.312+0.1856\dfrac{\text{测点高度}}{\text{总高度}}\right]\times\text{中心气含率}\times\left[1-\dfrac{4}{5}\left(\dfrac{\text{径向位置}}{\text{半径}}\right)^2\right]$ |  |

## 优缺点（`#L290`）

优势：气液电导率差异大 → 测量敏感、响应快、可直接给出电信号；国内应用较多。

局限：测量气液**搅拌釜**气含率的报道较少（多用于鼓泡塔、管道）。

## 判断

- （1.1）是"时间份额 = 体积份额"的遍历性假设：只有测点足够长、流态稳定时，气泡停留时间占比才等于该点气含率。
- 双针的间隔用于算气泡**速度**（$\Delta t_i$ 与针距），单针只能算频率——这是针数决定功能的根本原因。
- （1.2）在 $r/R=1$ 时括号内为 0.2，即壁面仍有约 20% 中心值，与鼓泡塔"壁面气含率不为零但明显偏低"的实测一致；它不能直接搬到搅拌釜（有桨叶强制循环）。

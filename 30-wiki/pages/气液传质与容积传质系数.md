# 气液传质与容积传质系数

## 两个速率式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r=K_{L}a\,\Delta C$ | （3-27） |
| **文字式** | $\text{传质速率}_{\text{【kmol/(s·m³)】}}=\text{液相容积传质系数}_{\text{【1/s】}}\times\text{液相浓度推动力}_{\text{【kmol/m³】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r=K_{G}a\,\Delta p$ | （3-28） |
| **文字式** | $\text{传质速率}_{\text{【kmol/(s·m³)】}}=\text{气相容积传质系数}_{\text{【kmol/(s·m³·MPa)】}}\times\text{分压推动力}_{\text{【MPa】}}$ |  |

（`#L3475-#L3485`）

## 推动力怎么取

1. 气液两相全混：出口推动力代表全过程；
2. 气体不混合、平推流通过：釜底与釜顶各一个推动力，取**对数平均值**。工业规模实践表明对数平均最符合实际、最实用（`#L3487`）。

## K_L 与 a 谁在变

实验证明 $K_La$ 的变化主要来自操作条件改变比界面积 $a$；$K_L$ 几乎不随操作条件变，只与体系性质有关（`#L3493`）：

| 体系 | $K_L$ 量级 |
|:---|:---|
| 聚并体系 | $1\sim6\times10^{-4}$ m/s |
| 非聚并体系 | $1\sim4\times10^{-4}$ m/s |
| 常取设计值 | $4\times10^{-4}$ m/s |

因此**比界面积直接决定传质速率**，它与气泡直径 $d_B$ 和气含率 $\Phi$ 的关系见式（2-86）及 [[持气率与气泡直径]]。

## 再回归式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{L}a=0.023(P/V_{L})^{0.49}V_{G}^{0.58}$ | （3-40） |
| **文字式** | $\text{液相容积传质系数}_{\text{【1/s】}}=0.023\times\left(\dfrac{\text{功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.49}\times\left(\text{空塔气速}_{\text{【m/s】}}\right)^{0.58}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{L}a=0.0016(P/V_{L})^{0.82}V_{G}^{0.3}$ | （3-41） |
| **文字式** | $\text{液相容积传质系数}_{\text{【1/s】}}=0.0016\times\left(\dfrac{\text{功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.82}\times\left(\text{空塔气速}_{\text{【m/s】}}\right)^{0.3}$ |  |

（3-40）对低黏体系，（3-41）对高黏流体与电解质溶液（`#L3513-#L3521`）。

## 用法

1. 先按体系选式（黏度、是否电解质、是否聚并），再代入 $P/V_L$ 与 $V_G$；
2. 通气功率 $P_G$ 与不通风功率差别很大，见 [[通气搅拌功率]]；
3. 测得 $K_La$ 后乘推动力得速率；推动力取法见上。

# 原书 §8.5：$k_La$ 为什么呈 S 形

## 曲线形状的机理

转速低于临界值（由式8.10~8.13 算）时气泡直接穿液上升、不被叶轮击碎；转速很高时气泡分裂成细泡、不再进一步变小。So $k_{Ga}$–$n$ 曲线呈 **S 形**，很难用一个简单公式统一关联（`#L9514`）。

## Cooper 式（亚硫酸钠溶液吸氧）

|  |  |  |
|:---|:---:|---|
| **符号式** | $k_{G}a=0.0635P_v^{0.95}v_s^{0.67}$（盘下直叶涡轮） | （8.42） |
| **文字式** | 容积系数 ∝ 单位体积功率^0.95 × 表观气速^0.67；功率指数近 1，说明气液体系对功率极敏感 |  |
| **符号式** | $k_{G}a=0.038P_v^{0.38}v_s^{0.67}$（桨叶式） | （8.43） |
| **文字式** | 桨式的功率指数只有 0.38——桨打不碎气泡，加功率没用 |  |

适用条件（`#L9524`、`#L9530`）：盘下直叶涡轮 $d/D=0.4$、$b/D=0.04$、$n_p=12$、$C/H=0.3$、$l/d=0.35$、$B_w/D=0.08\sim0.10$、$n_B=4$；单层时 $v_s<90$ m/h，双层时可到 150 m/h 以内。桨式式适用于 $d/D=1/4$、$b/D=0.04$、$n_p=2$、$C/H=0.3$。

**两个式子功率指数的巨大差别（0.95 vs 0.38）是叶轮型式的本质差异**，不是实验误差——选错叶轮，再大的功率也换不来传质。

## Yoshida 与 Hikita 式

十六叶盘下直叶涡轮吸氧（`#L9534`、`#L9536`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $k_La=11.8\left(N^{3}D^{2}\right)^{2/3}v_s^{2/3}$（十二叶平板涡轮） | （8.44） |
| **文字式** | $N^3D^2$ 正比于 $P_v$；容积系数 ∝ $P_v^{2/3}$×气速$^{2/3}$ |  |

Hikita 重整理（`#L9542`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $k_La=1000\left(\dfrac{N^{3}D^{2}}{5.57\times10^{8}}\right)^{0.75}v_s^{-0.175}$ | （8.45） |
| **文字式** | $k_La$ 单位为 1/h，$N$ 为 r/min、$D$ 为 m、$v_s$ 为 m/h；**气速指数竟是负的 −0.175** |  |

气速指数为负是个反常结果：气速增大反而 $k_La$ 略降。与式(8.39) 的"气速换接触时间"一致——气速过大时气泡停留时间缩短的损失超过了界面面积的增益。

## 各类设备的 $k_La$ 量级

表8.1（`#L9550`–`#L9561`）：

| 混合过程 | $k_La$【1/h】 |
|:---|:---|
| 鼓泡通气（Holroyd） | 5 |
| 摇瓶（Wise） | 24 |
| 摇瓶（Olson） | 200 |
| 涡轮 500 r/min（Maxon） | 350 |
| 涡轮 750 r/min | 1000 |
| 涡轮 1680 r/min | 2650 |
| 盘下直叶涡轮（Cooper） | 30~450 |
| 涡轮 2700 r/min（Overton） | 2500 |

**摇瓶能到 200 而鼓泡只有 5**——这一百倍差距全靠"把气泡打碎"。也说明摇瓶放大到釜不能按体积放大，必须按 $k_La$ 匹配。

## 41.6 倍是怎么来的

气泡直径缩到 1/4 时 $k_La$ 约增大四十倍，分解（表8.2，`#L9565`–`#L9572`）：

| 贡献项 | 倍数 |
|:---|:---|
| 吸收系数的增加 | 1.3 |
| 烟囱效应使停留时间增加 | 2.0 |
| 减小气泡直径使停留时间增加 | 4.0 |
| 单位体积气体界面面积（$a$）的增加 | 4.0 |
| **总增益** | $1.3\times2.0\times4.0\times4.0=41.6$ |

"烟囱效应"指后来的气泡沿前驱气泡的尾迹加速上升（`#L9563`）——**加剧搅拌能防止它**。Timson 的同心圆筒实验：气泡终端速度随剪切率增加而降低，**剪切率 50 s⁻¹ 以上时终端速度降到正常值的一半**（`#L9563`）。

## 与"$k_L$ 是常数"的分工

§8.7 将说明：气液体系传质速率的增加**主要来自界面面积 $a$ 的增加**，$k_L$ 相对视为常数（`#L9546`）。所以 $k_La$ 的关联式本质上是 $a$ 的关联式乘一个近似恒定的 $k_L$——这也是为什么所有 $k_La$ 式都长得像 $a$ 的式子。

凸形封头与法兰做成一体（锻制或整体成形），法兰不再是独立零件，法兰厚度的公式随封头形式与螺栓孔型式（圆形孔/槽形孔）、垫片宽度（窄面/宽面）分叉。

## 一、四种形式（图7-28，`#L7406-#L7416`）

| 形式 | 结构 | 计算路径 |
|:--|:--|:--|
| a） | 法兰与封头分体（凹面受压） | 封头厚度按 7.3.2 或 7.4.2；法兰按第 9 章（7.11.3.2） |
| b） | 无折边球面封头 + 法兰环，窄面/宽面 | 封头式（7-50）；法兰式（7-51）或（7-52） |
| c） | 带折边，法兰与封头一体 | 封头式（7-50）；法兰按螺栓孔型式走（7-53）~（7-57） |
| d） | 整体锻制，法兰应力按表 7-12 校核 | 封头式（7-50）；表 7-12 |

## 二、封头计算厚度（式7-50，`#L7434-#L7438`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_h=\dfrac{5p_cR_i}{6[\sigma]^t}$ | （7-50） |
| **文字式** | $\text{封头计算厚度}_{\text{【mm】}}=\dfrac{5\times\text{计算压力}_{\text{【MPa】}}\times\text{球面部分内半径}_{\text{【mm】}}}{6\times\text{设计温度下封头许用应力}_{\text{【MPa】}}}$ |  |

## 三、法兰计算厚度

**窄面法兰（形式 b，式7-51，`#L7440-#L7446`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_f=\sqrt{\dfrac{M_o}{[\sigma]_f^tD_i}\left(\dfrac{D_o+D_i}{D_o-D_i}\right)}$ | （7-51） |
| **文字式** | $\text{法兰计算厚度}_{\text{【mm】}}=\sqrt{\dfrac{\text{法兰设计力矩}_{\text{【N·mm】}}}{\text{法兰许用应力}_{\text{【MPa】}}\times\text{法兰内直径}_{\text{【mm】}}}\times\dfrac{\text{法兰外直径}+\text{法兰内直径}}{\text{法兰外直径}-\text{法兰内直径}}}$ |  |

$M_o$ 按 9.5.3 计算。

**宽面法兰（形式 b，式7-52，`#L7448-#L7454`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_f=0.6\sqrt{\dfrac{p_c}{[\sigma]_f^t}\left[\dfrac{D_i\left(D_o+D_i\right)\left(D_b-D_i\right)}{D_o-D_i}\right]}$ | （7-52） |
| **文字式** | $\text{法兰计算厚度}_{\text{【mm】}}=0.6\sqrt{\dfrac{\text{计算压力}_{\text{【MPa】}}}{\text{法兰许用应力}_{\text{【MPa】}}}\times\dfrac{\text{法兰内直径}\times\left(\text{法兰外直径}+\text{法兰内直径}\right)\times\left(\text{螺栓中心圆直径}-\text{法兰内直径}\right)}{\text{法兰外直径}-\text{法兰内直径}}}$ |  |

**圆形螺栓孔窄面法兰（形式 c，式7-53 与 7-54，`#L7456-#L7470`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_f=Q+\sqrt{\dfrac{1.875M_o\left(D_b+D_i\right)}{[\sigma]_f^tD_i\left(7D_b-5D_i\right)}}$；$Q=\dfrac{p_cR_i}{4[\sigma]_f^t}\left(\dfrac{D_b+D_i}{7D_b-5D_i}\right)$ | （7-53）（7-54） |
| **文字式** | $\text{法兰计算厚度}_{\text{【mm】}}=\text{操作状态系数}+\sqrt{\dfrac{1.875\times\text{法兰设计力矩}_{\text{【N·mm】}}\times\left(\text{螺栓中心圆直径}+\text{法兰内直径}\right)}{\text{法兰许用应力}\times\text{法兰内直径}\times\left(7\times\text{螺栓中心圆直径}-5\times\text{法兰内直径}\right)}}$ |  |

操作状态 $M_o$ 取 $M_p$（按 9-14）；预紧状态 $Q=0$，$M_o$ 取 $M_a[\sigma]_f^t/[\sigma]_f$（$M_a$ 按 9-11）。**两状态各算，取较大值。**

**槽形螺栓孔窄面法兰（式7-55 与 7-56，`#L7472-#L7486`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_f=Q+\sqrt{\dfrac{1.875M_o\left(D_b+D_i\right)}{[\sigma]_f^tD_i\left(3D_b-D_i\right)}}$；$Q=\dfrac{p_cR_i}{4[\sigma]_f^t}\left(\dfrac{D_b+D_i}{3D_b-D_i}\right)$ | （7-55）（7-56） |
| **文字式** | 与圆形孔同构，仅分母由 $7D_b-5D_i$ 换成 $3D_b-D_i$ |  |

**宽面法兰（形式 c，式7-57，`#L7490-#L7500`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_f=Q+\sqrt{Q^2+\dfrac{3D_iQ\left(D_b-D_i\right)}{R_i}}$ | （7-57） |
| **文字式** | $\text{法兰计算厚度}_{\text{【mm】}}=\text{状态系数}+\sqrt{\text{状态系数}^2+\dfrac{3\times\text{法兰内直径}\times\text{状态系数}\times\left(\text{螺栓中心圆直径}-\text{法兰内直径}\right)}{\text{球面部分内半径}_{\text{【mm】}}}}$ |  |

圆形孔 $Q$ 用式（7-54），槽形孔 $Q$ 用式（7-56）。

## 四、两条构造约束

- **任何情况下法兰厚度不应小于封头厚度**（$\delta_f\ge\delta_h$，7.11.3.4 f，`#L7500`）；
- 表 7-12 的迭代条件：假设的法兰有效厚度须 $\delta_{ef}\ge\max\{\delta_{fa},\delta_{fp}\}$ **且** $\delta_{ef}\ge2\delta_{eh}$，否则重设（`#L7578`）。

## 五、受外压（凸面受压，7.11.4，`#L7504-#L7514`）

1. 封头厚度按 6.4（外压球壳）算；
2. 总力矩 $M_o$ 按 9.5.3；形式 d 的法兰力矩 $M_p=F_D(L_D-L_G)+F_T(L_T-L_G)-F_rL_r$；
3. 形式 a 的法兰按第 9 章，其余按（7-51）、（7-52）、（7-53）、（7-55）、（7-57）。

## 判断

- 封头厚度只有一条式（7-50），法兰厚度有五条——**分叉点在「螺栓孔型式」与「垫片宽度」**，不是封头形状。圆形孔用 $7D_b-5D_i$，槽形孔用 $3D_b-D_i$，选错分母法兰厚度会偏小。
- 圆形/槽形孔窄面法兰必须**分操作与预紧两状态算并取大**；只算操作态会漏掉预紧力矩控制的工况。
- 两条硬约束容易漏：$\delta_f\ge\delta_h$ 是构造下限；表 7-12 还要求 $\delta_{ef}\ge2\delta_{eh}$——即法兰有效厚度至少是封头有效厚度的两倍。
- 形式 a 不是本条的公式体系，封头按 7.3/7.4、法兰按第 9 章；把它当形式 c 套（7-53）会算错。

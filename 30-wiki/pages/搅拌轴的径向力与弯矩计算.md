# 搅拌轴的径向力与弯矩计算

## 径向力弯矩 $M_{R}$

**悬臂轴**（受力模型见图9-54）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_{R}=\left(\sum F_{hi}L_{i}+9.81m_{W1}L_{e}\sin\alpha+F_{e}L_{e}\right)\times10^{-3}$ | （9-39） |
| **文字式** | $\text{径向力弯矩}_{\text{【N}\cdot\text{m】}}=\left(\sum\text{第}i\text{层流体径向力}_{\text{【N】}}\times\text{悬臂长度}_{\text{【mm】}}+9.81\times\text{组合质量}_{\text{【kg】}}\times\text{重心距}_{\text{【mm】}}\times\sin\text{轴线倾角}+\text{离心力}_{\text{【N】}}\times\text{重心距}_{\text{【mm】}}\right)\times10^{-3}$ |  |

**单跨轴**（图9-55），近似取：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_{R}=\dfrac{\sum F_{hi}(L-L_{i})L_{i}}{1000L}+\dfrac{F_{e}(L-L_{e})L_{e}}{1000L}$ | （9-40） |
| **文字式** | $\text{径向力弯矩}_{\text{【N}\cdot\text{m】}}=\dfrac{\sum\text{流体径向力}_{\text{【N】}}\times(\text{跨长}-\text{至传动侧距离})\times\text{至传动侧距离}}{1000\times\text{跨长}}+\dfrac{\text{离心力}_{\text{【N】}}\times(\text{跨长}-\text{重心距})\times\text{重心距}}{1000\times\text{跨长}}$ |  |

## 流体径向力 $F_{hi}$

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{hi}=K_{1}\dfrac{M_{nqi}\times10^{3}}{(3/8)D_{ji}}$ | （9-41） |
| **文字式** | $\text{第}i\text{层流体径向力}_{\text{【N】}}=\text{流体径向力系数}\times\dfrac{\text{该层扭矩}_{\text{【N}\cdot\text{m】}}\times10^{3}}{(3/8)\times\text{该层搅拌器直径}_{\text{【mm】}}}$ |  |

该层扭矩 $M_{nqi}=9553\,P_{qi}/n$，$P_{qi}$ 为该层搅拌器的设计功率（由工艺过程确定）。

**为什么除以 $(3/8)D_{j}$**：把叶轮功率按等效作用半径 $3D_{j}/8$ 折算成切向力，再乘径向力系数 $K_{1}$ 得径向分量。

## 系数 $K_{1}$ 的取法

### 推进式、三叶后掠式（表9-97）

| 挡板及内件数＼介质黏度 | $\le20$ mPa·s | $\ge1000$ mPa·s |
|:---|:---:|:---:|
| 无挡板 | 0.40 | 0.04 |
| 1~3 块挡板或 1~2 个插入内件（指形挡板、扁管、内插管） | 0.25 | 0.04 |
| 4 块挡板 | 0.16 | 0.04 |

### 其他型式（式9-42）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{1}=K_{1}'K_{1u}K_{1b}K_{1e}K_{1t}$ | （9-42） |
| **文字式** | $\text{流体径向力系数}=\text{基本系数}\times\text{黏度修正}\times\text{挡板数修正}\times\text{偏心安装修正}\times\text{内件修正}$ |  |

**基本系数 $K_{1}'$（表9-98）**，按 $Z_{j}(n/n_{cr})$ 取值：

| 搅拌器形式 | ≤0.5 | 1.0（峰值） | 1.2 | 1.5 | ≥2.0 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 锚式、框式 | 0.08 | (0.10) | — | — | — |
| 直叶桨式 | 0.15 | (0.20) | — | — | — |
| 斜叶桨式 | 0.20 | (0.25) | — | — | — |
| 直叶涡轮（4叶） | 0.15 | (0.45) | 0.18 | 0.13 | 0.11 |
| 直叶涡轮（6叶） | 0.10 | (0.30) | 0.11 | 0.10 | 0.09 |
| 斜叶涡轮（4叶） | 0.16 | (0.50) | 0.20 | 0.15 | 0.12 |
| 斜叶涡轮（6叶） | 0.11 | (0.35) | 0.12 | 0.11 | 0.10 |

**挡板数修正 $K_{1b}$（表9-99）**：双桨式 4 块 1.0、2 块 3.0、0 块 10.0；4 叶涡轮 4 块 1.0、2 块 1.6、0 块 1.8（$Z_{j}=1.0$ 时）/2.0（其他）；6 叶涡轮 4 块 1.0、3 块 1.3/1.4、2 块 1.2/1.3、0 块 2.2/4.4。

**偏心修正 $K_{1e}$（表9-100）**：偏心距离 $D_{i}/96$ 时直叶 1.0、斜叶 1.4；$D_{i}/12$ 时 1.35/2.45；$D_{i}/4$ 时直叶 4.0。

**内件修正 $K_{1t}$（表9-101，摘录）**：4 个三角形内件 1.0；1 个螺旋盘管 0.8~0.9；1 个指形内件 1.8/3.6；2 个指形 1.1/1.7；1 个扁管 2.3/4.0；内插管在 $D_{i}/2$ 处 2.0、$D_{i}/3$ 处 0.7~1.0；1 个小圈盘管 $D_{i}/2$ 处 2.0、$D_{i}/3$ 处 0.9~1.2；小圈盘管+内插管 1.9/1.3；2 个小圈盘管 1.4/1.2。

**黏度修正 $K_{1u}$**：查图9-61（`#L11842`）。

## 使用要点

1. 表9-98 括号内为**共振峰值**（$n/n_{cr}=1.0$），正常设计应避开该点（见表9-95）。
2. $K_{1}$ 的**数值方向反直觉**：黏度越高径向力越小（液体被带转、相对冲角减小），无挡板时最危险。
3. $M_{R}$ 是 $M=M_{A}+M_{R}$ 的主体项，直接决定轴径（见 [[按强度计算搅拌轴的轴径]]）。

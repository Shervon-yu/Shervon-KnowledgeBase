# 混合效率指标

## 低黏流体的混合能

衡量低黏互溶液体搅拌效果的第二指标是混合能 $E$，与黏度、叶轮直径、转速的关系（`#L1464`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $E\propto\left(\mu N^{2}d^{3}\right)\left(\dfrac{1}{N}\right)=\mu Nd^{3}$ | （2-25） |
| **文字式** | $\text{混合能}\propto\text{黏度}_{\text{【Pa·s】}}\times\text{转速}_{\text{【1/s】}}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{3}$ |  |

物理含义：把黏性耗散功率乘以时间尺度，得到"混匀一次付出的能量代价"。

## 高黏流体的四个指标

高黏搅拌器用以下指标综合评价（`#L1596-#L1616`）：

1. **混合准数** $N_{\theta\mathrm{M}}$：螺带式、螺杆式等适合高黏流体的搅拌器在层流下 $N_{\theta\mathrm{M}}$ 仍为常数；不适合的（如 $d/D\approx0.5$ 盘式涡轮层流混合）因有死角求不出 $\theta_M$（`#L1598`）。
2. **单位体积混合能** $W_v=P_v\theta_M$，即单位体积功率与混合时间之积（`#L1600`）。
3. **剪切性能数** $C_3$：搅拌器转一圈流体所受的剪切量（`#L1602`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_{3}=\dfrac{1}{N}\sqrt{\dfrac{P_{v}}{\mu}}$ | （2-31） |
| **文字式** | $\text{剪切性能数}=\dfrac{1}{\text{转速}_{\text{【1/s】}}}\sqrt{\dfrac{\text{单位体积功率}_{\text{【W/m³】}}}{\text{黏度}_{\text{【Pa·s】}}}}$ |  |

4. **混合效率数** $C_4$ 与比混合能 $C_4^{*}$（`#L1610-#L1616`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_{4}=P_{v}\theta_{\mathrm{M}}^{2}/\mu=W_{v}\,\theta_{\mathrm{M}}/\mu$ | （2-32） |
| **文字式** | $\text{混合效率数}=\dfrac{\text{单位体积功率}_{\text{【W/m³】}}\times\left(\text{混合时间}_{\text{【s】}}\right)^{2}}{\text{黏度}_{\text{【Pa·s】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_{4}^{*}=C_{4}/10^{5}$ | （2-33） |
| **文字式** | $\text{比混合能}=\text{混合效率数}/10^{5}$ |  |

$C_4$ 常在 $10^5$ 量级，直接用不便，故除以 $10^5$ 得 $C_4^{*}$；**$C_4^{*}$ 越小，混合效率越高**（`#L1614`）。

## 表2-6 的读法

表2-6 给出常用高黏搅拌器的 $N_{\theta\mathrm{M}}$、$C_3$、$C_4^{*}$（`#L1626-#L1637`，牛顿流体与 $n=0.53\sim0.63$ 假塑性流体两栏）：

- 复动式（$d/D=0.947$）：$N_{\theta\mathrm{M}}=22.7$、$C_3=11.2$、$C_4^{*}=0.645$——取样数值最低，即单位混合时间的能量最省；
- 双螺带-锚（$d/D=0.95$）：$N_{\theta\mathrm{M}}=34$、$C_3=19.4$、$C_4^{*}=4.36$；
- 框（$d/D=0.790$）：$C_4^{*}$ 达 10.1，效率最低；
- 螺杆-导流筒（$d/D=0.574$）：假塑性下 $C_4^{*}=0.80$。

## 边界

$C_4^{*}$ 只在"流体相同、混合时间相同"的前提下比较搅拌器（`#L1614`）；跨流体或跨混合标准比较无意义。$C_3$ 反映剪切强弱，与混合快慢不是同一件事。

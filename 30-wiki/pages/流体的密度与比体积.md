# 流体的密度与比体积

## 密度（`#L982-#L992`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho=\dfrac{m}{V}$ | （1-1） |
| **文字式** | $\text{密度}_{\text{【kg/m³】}}=\dfrac{\text{质量}_{\text{【kg】}}}{\text{体积}_{\text{【m³】}}}$ |  |

**液体**：压力影响可忽略（极高压力除外），密度随温度稍有改变，工程上按不可压缩处理；常用值查附录四，附录五给相对密度（与 4 ℃ 水密度之比，4 ℃ 水为 1000 kg/m³）。

## 气体密度（`#L994-#L1010`）

压力不太高、温度不太低时按理想气体：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $pV=nRT=\dfrac{m}{M}RT$ | （1-2） |
| **文字式** | $\text{压力}_{\text{【kPa】}}\times\text{体积}_{\text{【m³】}}=\dfrac{\text{质量}_{\text{【kg】}}}{\text{摩尔质量}_{\text{【kg/kmol】}}}\times\text{气体常数}_{\text{【kJ/(kmol·K)】}}\times\text{温度}_{\text{【K】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho=\dfrac{pM}{RT}$ | （1-3） |
| **文字式** | $\text{密度}_{\text{【kg/m³】}}=\dfrac{\text{压力}_{\text{【kPa】}}\times\text{摩尔质量}_{\text{【kg/kmol】}}}{\text{气体常数}\times\text{温度}_{\text{【K】}}}$ |  |

$R=8.314$ kJ/(kmol·K)；$p$ 必须用**绝对压力**。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho^{\ominus}=\dfrac{M}{22.4}$ | （1-4） |
| **文字式** | $\text{标准状况密度}_{\text{【kg/m³】}}=\dfrac{\text{摩尔质量}_{\text{【kg/kmol】}}}{22.4}$ |  |

标准状况 $T^{\ominus}=273.15$ K、$p^{\ominus}=101.325$ kPa，摩尔体积 $22.4$ m³/kmol。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho=\rho^{\ominus}\dfrac{T^{\ominus}p}{Tp^{\ominus}}$ | （1-5） |
| **文字式** | $\text{密度}_{\text{【kg/m³】}}=\text{标准状况密度}_{\text{【kg/m³】}}\times\dfrac{\text{标准温度}_{\text{【K】}}\times\text{操作压力}_{\text{【kPa】}}}{\text{操作温度}_{\text{【K】}}\times\text{标准压力}_{\text{【kPa】}}}$ |  |

## 混合物密度（`#L1012-#L1024`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho_{\mathrm{m}}=\sum_{i=1}^{n}\rho_i y_i$ | （1-6） |
| **文字式** | $\text{混合气体密度}_{\text{【kg/m³】}}=\sum_{i=1}^{n}\text{组分密度}_{i,\text{【kg/m³】}}\times\text{组分摩尔分数}_i$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{1}{\rho_{\mathrm{m}}}=\sum_{i=1}^{n}\dfrac{w_i}{\rho_i}$ | （1-7） |
| **文字式** | $\dfrac{1}{\text{混合液密度}_{\text{【kg/m³】}}}=\sum_{i=1}^{n}\dfrac{\text{组分质量分数}_i}{\text{组分密度}_{i,\text{【kg/m³】}}}$ |  |

液体混合按**质量分数**加权取倒数和（以 1 kg 混合液为基准）；气体混合按**摩尔分数**加权取和。

## 比体积（`#L1026-#L1034`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $v=\dfrac{V}{m}=\dfrac{1}{\rho}$ | （1-8） |
| **文字式** | $\text{比体积}_{\text{【m³/kg】}}=\dfrac{\text{体积}_{\text{【m³】}}}{\text{质量}_{\text{【kg】}}}=\dfrac{1}{\text{密度}_{\text{【kg/m³】}}}$ |  |

## 两个算例

- 例 1-2（`#L1036-#L1046`）：N₂:H₂ 体积比 1:3（摩尔分数 0.25/0.75），$M_m=28.02\times0.25+2.016\times0.75=8.52$ kg/kmol；$p=100$ kPa、$T=298$ K 时 $\rho=100\times8.52/(8.314\times298)=0.344$ kg/m³。
- 例 1-3（`#L1048-#L1054`）：苯质量分数 0.6、20 ℃ 下苯 879、甲苯 867 kg/m³，$1/\rho_m=0.6/879+0.4/867$ → $\rho_m=874$ kg/m³。

## 判断

- 气体密度随压力线性、随温度反比变化，所以"标况密度 + 1-5"是工程上最省事的换算法。
- 混合液用倒数和而不是算术平均：体积不可加、质量可加，这是 1-7 的来源。

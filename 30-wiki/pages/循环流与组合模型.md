# 循环流与组合模型

## 一、循环流模型（§5.7）

模型假设（`#L6338`）：活塞流管中的流体以 $v'$ 循环回进口，总流量 $v+v'$，进料 $v$。

|  |  |  |
|:---|:---:|---|
| **符号式** | $C_{x\to0+}=\dfrac{vC_i+v'C_e}{v+v'}$ | （5.43） |
| **文字式** | $\text{进口浓度}=\dfrac{\text{进料量}\times\text{进料浓度}+\text{回流量}\times\text{出口浓度}}{\text{总流量}}$ |  |

沿轴向积分（`#L6340`、`#L6346`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $-\int_{C_{x\to0+}}^{C_e}\dfrac{\mathrm{d}C}{\psi(C)}=\dfrac{V}{v+v'}$ | （5.44） |
| **文字式** | $\int-\dfrac{\text{浓度微元}}{\text{反应速率}}=-\dfrac{\text{容积}}{\text{总流量}}=\text{沿程时间}$ |  |

用途（`#L6344`）：**只要一个参数 $v'$ 就能估反应器性能**，在分析复杂反应的选择性（并列/串联副反应）时最方便——因为循环使局部浓度维持在出口浓度附近。

## 二、并联组合模型（§5.8.1）

把反应器看成两条并联的支路（`#L6354`）：

- $\Phi v$ 的流量走活塞流、占 $\Phi V$ 容积；
- $(1-\Phi)v$ 走完全混合、占 $(1-\Phi)V$。

结果按两支路加权混合（`#L6420`、`#L6422`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $C=\Phi C_p+(1-\Phi)C_m$，$\quad C_e=\Phi C_{pe}+(1-\Phi)C_{me}$ | （5.50）（5.51） |
| **文字式** | $\text{出口浓度}=\text{活塞流份额}\times\text{其出口浓度}+\text{完全混合份额}\times\text{其出口浓度}$ |  |

两支路各自的解（一级反应为解析式，`#L6372`、`#L6400`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $C_p=C_ie^{-k_1t}$，$\qquad C_m=\dfrac{C_i}{1+k_1t}$ | （5.47）（5.49） |
| **文字式** | 活塞流支路指数衰减；完全混合支路按 $1/(1+\cdot)$ 衰减 |  |

$1-\Phi$（并联的"完全混合当量"）与 $M$ 的关系见原书图5.21，$M=1$ 时 $\Phi=0.5$（`#L6434`）。

## 三、串联组合模型（§5.8.2）

先活塞流 $\Phi V$、再完全混合 $(1-\Phi)V$（`#L6440`）。其逐步响应曲线在半对数图上**大 $t/\theta$ 区近直线**（图5.22），Gilliland 用折线近似（`#L6444`、`#L6448`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $0\le\dfrac{t}{\theta}<\phi:\ \dfrac{C}{C_i}=1;\qquad \dfrac{t}{\theta}>\phi:\ \dfrac{C}{C_i}=e^{-S\left[\frac{t}{\theta}-\phi\right]}$ | （5.52）（5.53） |
| **文字式** | 在 $\phi$ 之前浓度不变（活塞流段的纯延迟），之后按斜率 $-S$ 指数衰减 |  |

两个参数 $\phi$（活塞流容积分数）与 $S$（斜率的负倒数）由**面积归一**约束（`#L6452`、`#L6466`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi+\dfrac{1}{S}=1\ \Longrightarrow\ \phi=1-\dfrac{1}{S}$ | （5.54）（5.55） |
| **文字式** | $\text{活塞流分数}+\text{衰减曲线下的面积}=1$ |  |

两个极端：完全混合 $\phi=0,\ S=1$（代入即 $e^{-t/\theta}$）；活塞流 $\phi=1,\ S=\infty$（`#L6460`）。

### φ、S 与 M 的解析关系

由年龄分布的级数展开，大 $t/\theta$ 时只保留首项（`#L6490`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $S=\dfrac{M^{2}+\mu_1^{2}}{2M}$ | （5.60） |
| **文字式** | 由混合强度参数与级数首根算出衰减斜率 |  |

$M<0.7$、$\phi<0.2$ 时 $\phi$ 有解析式（5.61）。工程上更常用拟合曲线反读（图5.21，`#L6506`、`#L6508`、`#L6512`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi<0.12:\ \Phi=1.40\phi^{0.824};\qquad 0.12<\phi<0.40:\ \Phi=1.21\phi^{0.760}$ | （5.62）（5.63） |
| **文字式** | 由串联活塞流分数 $\phi$ 换算出并联当量完全混合分数 $1-\Phi$ |  |

## 用哪一步、怎么用

1. 实测 RTD → 半对数图上画出曲线；
2. 读大 $t/\theta$ 段斜率得 $S$，再由 (5.55) 得 $\phi$；
3. 由 $\phi$ 经 (5.62)/(5.63) 得 $\Phi$（或直接查图5.21 得 $M$）；
4. 拆成两支路分别算，最后按 (5.50) 加权。

**适用边界**（`#L6516`）：**只对不可逆单一反应有效**；有并列/串联副反应时两支路的选择性不同，加权会掩盖真实过程。

# 固液悬浮判据与搅拌级别

## 判据一：釜底未悬浮固体量

固体粒子在釜底停留时间不超过 **1~2 s**，即认为达到完全离底悬浮；满足此条件的最低转速称**完全离底悬浮临界转速** $N_c$。注意：此时釜内各处固体含量并不均一（`#L2587`）。

## 判据二：悬浮均匀度

大多数体系达不到真正均一，故取样测浓度，用浓度方差定义（`#L2589-#L2599`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma^{2}=\dfrac{1}{n}\sum_{1}^{n}\left(\dfrac{\varphi_{V}}{\varphi_{av}}-1\right)^{2}$ | （2-115） |
| **文字式** | $\text{浓度方差}=\dfrac{1}{\text{样品个数}}\sum\left(\dfrac{\text{样品固相分体积}}{\text{全釜平均固相分体积}}-1\right)^{2}$ |  |

$\sigma^2$ 越小越均匀。

另用悬浮百分数表示（`#L2601-#L2605`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $100\times\dfrac{\text{取样点固体质量分数}}{\text{全釜平均固体质量分数}}=\text{悬浮百分数}$ | （2-116） |
| **文字式** | $100\times\dfrac{\text{取样点固体质量分数}}{\text{全釜平均固体质量分数}}=\text{悬浮百分数}$ |  |

悬浮百分数可大于 100%；完全均匀悬浮意味着各点都是 100%，但最上层液体很难达到均一。

## 判据三：十个搅拌级别（设计用）

从设计角度把悬浮程度分十级，虽不严密但实用（`#L2607-#L2616`）：

| 级别 | 效果 |
|:---|:---|
| 1~2 | 最低程度悬浮：颗粒在容器中运动，釜底边缘的颗粒周期性悬浮 |
| 3~5 | 多数化工过程要求：3 级使全部颗粒离开釜底、浆液易从釜底放出 |
| 6~8 | 接近均匀悬浮：6 级使 95% 料层高度的浆料均匀悬浮，料液可从 80% 料层高度排出 |
| 9~10 | 最均匀：9 级使 98% 料层高度的浆液均匀悬浮，可用溢出方式出料 |

## 怎么选判据

- 只要催化/溶解接触、不要浓度均一 → 用完全离底悬浮（省能）；
- 要出料稳定、防分层 → 用 6 级以上；
- 要"全釜浓度一致"（分析、精密反应）→ 需 9~10 级，代价是功耗成倍上升。

浓度沿釜深的实测分布与 $\bar{\sigma}$ 判据见 [[均匀悬浮与浓度分布]]。

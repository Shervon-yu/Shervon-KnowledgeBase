# 气泡破裂模型

## 破裂的两个阶段与三种机制（`#L3215`）

气泡破裂分两阶段：**先变形**（受周围液体的作用），**后破裂**（变形到一定程度裂成两个或更多子气泡）。

三种机制：

- **湍流脉动**（湍流涡体碰撞）——主要机制；
- 液体黏性剪切；
- 气泡表面不稳定。

## 五类破裂标准（`#L3215`）

| 序号 | 标准 | 含义 |
|:--|:--|:--|
| ① | 气泡的湍流动能 ≥ 表面能 | 能量判据 |
| ② | 液相脉动速度 ≥ 等尺寸破裂所需表面能增量对应的速度 | 速度判据 |
| ③ | 碰撞涡的湍动动能 ≥ 临界值（如破裂前后表面能增量） | 涡动能判据（Luo-Svendsen 用） |
| ④ | 碰撞涡的动压力（惯性力）≥ 最小子气泡的附加压力（界面力） | 力平衡判据（Lehr-Mewes 用） |
| ⑤ | ③与④结合 | 复合判据 |

破裂速率模型多与 ③~⑤ 相关。

## Luo-Svendsen 模型（7.17~7.23，`#L3217-#L3261`）

三条假定：气泡**二元破裂**；破裂由抵达湍流涡的能级决定；**只有尺寸 ≤ 气泡的涡才能引起破裂**（大涡只起输运作用）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $b(V_0:V_0f_v)=\displaystyle\int_{\lambda_{\min}}^{d_0}P_B(V_0:V_0f_v,\lambda)\,\omega_B(d_0,\lambda)\,\mathrm{d}\lambda$ | （7.17） |
| **文字式** | $\text{以破裂比}f_v\text{破裂的速率}=\displaystyle\int_{\lambda\min}^{d_0}\text{破裂概率}\times\text{与尺度}\lambda\text{湍流涡的碰撞频率}\,\mathrm{d}\lambda$ |  |

碰撞频率（7.18）：$\omega_B=c_4(1-\alpha)n(\varepsilon d_0)^{1/3}\frac{(1+\xi)^2}{d_0^2\xi^{11/3}}$，$\xi=\lambda/d_0$。

破裂判据（7.19）：$e(\lambda)\ge c_f\pi d_0^2\sigma$，其中 $c_f=f_v^{2/3}+(1-f_v)^{2/3}-1$ 为**表面积增量系数**。

破裂概率（7.20）：$P_B=\exp(-\chi_c)$，$\chi_c$ 为无量纲临界能量（7.21）：

$$\chi_c=\frac{c_f\pi d_0^2\sigma}{\bar e(\lambda)}=\frac{12c_f\sigma}{\beta_1\rho_c\varepsilon^{2/3}d_0^{5/3}\xi^{11/3}}$$

总破裂速率（7.23）：$b(V_0)=\frac12\int_0^1b(V_0:V_0f_v)\mathrm{d}f_v$。

**特点（`#L3261`）**：除积分上下限（上限 $d_0$、下限 $\lambda_{\min}$ 需估算）外**不含其他未知或可调参数**；且子尺寸分布可直接从破裂速率得到。近年应用最广。

## 子尺寸分布（7.41~7.45，`#L3355` 前后）

破裂后子气泡按体积比 $f_v$ 分布的密度函数 $\beta(f_v,d)$ 有五种形态：

- Luo："U"型（两端多、中间少）；
- Martínez-Bazán："bell"型；
- Lehr：双峰，随直径增大转单峰；
- Wang："M"型；
- Zhao-Ge：见原文。

## 判断

- 五类标准不是"谁更准"，而是**判据的物理量不同**（能量/速度/力），在 $d_0$ 接近临界直径时结果趋同、远离时差异大；
- Luo-Svendsen 的"无参数"是相对的：$\lambda_{\min}$ 与积分上限仍是估算值，且 $\beta_1$、$c_4$ 是模型常数；
- 本书选它，正是看中它**自带子尺寸分布**——否则还要再为 $\beta$ 编一个模型，多一层不确定性。

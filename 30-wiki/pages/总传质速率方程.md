# 总传质速率方程

## 为什么要把界面组成消掉（`#L9430-#L9438`）

界面组成 $(Y_i,X_i)$ 要先知道 $k_X$、$k_Y$ 才能求，而这两个系数实验测定困难。于是用相平衡关系把界面浓度换成**主体浓度与平衡浓度**，得到只含主体组成的"总系数"表达式。

推导前提：操作范围内平衡关系可用直线 $Y^{*}=mX+b$ 表示（亨利定律 $Y^{*}=mX$ 是它的特例，结果形式相同）。

## 以 $(Y-Y^{*})$ 为推动力（`#L9446-#L9482`）

由 $X_i=(Y_i-b)/m$、$X=(Y^{*}-b)/m$，代入液相速率式并写成推动力/阻力，与气相速率式相加（稳态时 $N_A$ 相等），消去 $Y_i$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=\dfrac{Y-Y^{*}}{\dfrac{1}{k_Y}+\dfrac{m}{k_X}}$，$K_Y=\dfrac{1}{\dfrac{1}{k_Y}+\dfrac{m}{k_X}}$ | （5-32）、（5-33） |
| **文字式** | $\text{传质速率}=\dfrac{\text{气相总推动力}}{\text{气膜阻力}+\text{液膜折算阻力}}$，$\text{气相总传质系数}=1/(\text{两项阻力之和})$ |  |

即

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=K_Y(Y-Y^{*})$，$\dfrac{1}{K_Y}=\dfrac{1}{k_Y}+\dfrac{m}{k_X}$ | （5-34）、（5-35） |
| **文字式** | $\text{传质速率}=\text{气相总传质系数}\times(\text{气相主体组成}-\text{与液相平衡的气相组成})$；$\text{总阻力}=\text{气膜阻力}+\text{液膜阻力（乘 }m\text{ 折算）}$ |  |

## 以 $(X^{*}-X)$ 为推动力（`#L9484-#L9522`）

同理（用 $Y_i=mX_i+b$、$Y=mX^{*}+b$）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $K_X=\dfrac{1}{\dfrac{1}{mk_Y}+\dfrac{1}{k_X}}$，$N_A=K_X(X^{*}-X)$ | （5-37）、（5-38） |
| **文字式** | $\text{液相总传质系数}=1/(\text{气膜阻力}/m+\text{液膜阻力})$；$\text{传质速率}=\text{液相总传质系数}\times(\text{与气相平衡的液相组成}-\text{液相主体组成})$ |  |

总阻力式与两系数的关系：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{1}{K_X}=\dfrac{1}{mk_Y}+\dfrac{1}{k_X}$，$K_X=mK_Y$ | （5-39）、（5-40） |
| **文字式** | $\text{液相总阻力}=\text{气膜阻力除以}m+\text{液膜阻力}$；$\text{液相总系数}=m\times\text{气相总系数}$ |  |

## 图上的含义（图5-15，`#L9520`）

$Y-Y^{*}$ 是操作点与平衡线的垂直距离（气相总推动力）；$Y-Y_i$ 是气膜推动力；$Y_i-Y^{*}$ 是液膜推动力。斜率 $-k_X/k_Y$ 把总推动力按两膜阻力分成两段。

## 例5-5（`#L9614-#L9652`）

含微量氨的空气-水系统，101.33 kPa、20 ℃：$k_G=3.15\times10^{-6}$ kmol/(m²·s·kPa)、$k_L=1.81\times10^{-4}$ kmol/(m²·s·kmol/m³)、$H=0.72$ kmol/(m³·kPa)。

- $1/K_G=1/k_G+1/(Hk_L)=3.17\times10^5+7.67\times10^3=3.25\times10^5$ → $K_G=3.08\times10^{-6}$；
- 气膜阻力占总阻力 3.17/3.25=**97.5%** → $K_G\approx k_G$，典型气膜控制；
- 低浓度：$K_Y=pK_G=101.33\times3.08\times10^{-6}=3.12\times10^{-4}$ kmol/(m²·s)；
- $1/K_L=H/k_G+1/k_L=2.34\times10^5$ → $K_L=4.27\times10^{-6}$；
- $c=\rho_s/M_s=998.2/18=55.5$ kmol/m³ → $K_X=cK_L=2.37\times10^{-4}$ kmol/(m²·s)。

## 判断

- 别把 $K_Y$ 当成"两个膜系数相加"：液膜项要乘 $m$ 才能折到气相推动力口径。$m$ 大（难溶）→ 液膜项权重高；$m$ 小（易溶）→ 气膜项主导。这正是"气膜/液膜控制"的来源。
- $K$ 与 $k$ 的比较只能在同一推动力口径下进行；跨口径比较（如 $K_G$ 与 $k_L$）没有物理意义。

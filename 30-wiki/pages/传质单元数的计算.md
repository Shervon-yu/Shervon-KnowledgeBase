# 传质单元数的计算

## 三种方法的分工（`#L9960-#L9962`）

填料层高度 $Z=H_{OG}N_{OG}$，$H_{OG}$ 可测可查，关键在 $N_{OG}=\int_{Y_2}^{Y_1}\frac{\mathrm{d}Y}{Y-Y^{*}}$。求积分三种办法：对数平均推动力法、吸收因数法、图解积分（前两种最常用）。

## 一、对数平均推动力法（`#L9964-#L10004`）

前提：平衡线与操作线**都是直线**（亨利定律 $Y^{*}=mX$ 或局部线性化 $Y^{*}=mX+b$）。此时 $\Delta Y=Y-Y^{*}$ 与 $Y$ 成直线关系，可直接积分：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\Delta Y_{\mathrm{m}}=\dfrac{\Delta Y_1-\Delta Y_2}{\ln(\Delta Y_1/\Delta Y_2)}=\dfrac{(Y_1-Y_1^{*})-(Y_2-Y_2^{*})}{\ln\dfrac{Y_1-Y_1^{*}}{Y_2-Y_2^{*}}}$ | （5-72） |
| **文字式** | $\text{气相对数平均推动力}=\dfrac{\text{塔底推动力}-\text{塔顶推动力}}{\ln(\text{塔底推动力}/\text{塔顶推动力})}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_{OG}=\dfrac{Y_1-Y_2}{\Delta Y_{\mathrm{m}}}$ | （5-73） |
| **文字式** | $\text{气相总传质单元数}=\dfrac{\text{气相组成变化}}{\text{对数平均推动力}}$ |  |

两个特例：
- $\Delta Y_1/\Delta Y_2<2$ 时，对数平均可用算术平均代替（误差 ≤4%）；
- 操作线与平衡线平行（$L/(mG)=1$）时，$\Delta Y_{\mathrm{m}}=\Delta Y_1=\Delta Y_2$（5-74），于是

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_{OG}=\dfrac{Y_1-Y_2}{Y_2-mX_2}$ | （5-75） |
| **文字式** | $\text{传质单元数}=\dfrac{\text{气相组成变化}}{\text{塔顶推动力}}$ |  |

## 二、吸收因数法（`#L10006-#L10024`）

把操作线 $X=\frac{G}{L}(Y-Y_2)+X_2$ 代入 $Y^{*}=mX$，得到 $Y^{*}$ 随 $Y$ 的线性式，代入积分：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_{OG}=\dfrac{1}{1-\dfrac{mG}{L}}\ln\left[\left(1-\dfrac{mG}{L}\right)\dfrac{Y_1-mX_2}{Y_2-mX_2}+\dfrac{mG}{L}\right]$ | （5-76） |
| **文字式** | $\text{传质单元数}=\dfrac{1}{1-\text{解吸因数}}\ln\left[(1-\text{解吸因数})\times\dfrac{\text{塔底气相推动力}}{\text{塔顶气相推动力}}+\text{解吸因数}\right]$ |  |

等价形式：$\dfrac{Y_2-mX_2}{Y_1-mX_2}=\dfrac{1-\frac{mG}{L}}{\exp[(1-\frac{mG}{L})N_{OG}]-\frac{mG}{L}}$。

为了省算，把 $N_{OG}$ 与 $\frac{Y_2-mX_2}{Y_1-mX_2}$ 的关系按吸收因数 $L/(mG)$ 为参变量绘成图5-23。读数在 $\frac{Y_2-mX_2}{Y_1-mX_2}<0.05$ 且 $L/(mG)>1$ 时较准，否则误差大，需回代公式。

平衡线为 $Y^{*}=mX+b$ 时公式与图仍可用，只需 $Y_2^{*}=mX_2+b$。

## 三、各因素的影响（`#L10026-#L10054`）

$N_{OG}$ 由 $L$、$G$、$m$、$X_2$、$Y_1$、$Y_2$ 决定：

- $L$ 增大、$G$ 减小、$m$ 减小 → 吸收因数 $L/(mG)$ 增大 → $N_{OG}$ 减小（操作线远离平衡线，推动力大）；
- $m$ 减小靠**降温**（$E$ 减小）或**加压**（$p$ 增大），因 $m=E/p$；
- $Y_1$ 减小或 $Y_2$ 增大（分离要求放宽）→ $N_{OG}$ 减小；
- $X_2$ 减小（吸收剂更纯）→ $N_{OG}$ 减小，见式（5-77）：$\dfrac{Y_1-mX_2}{Y_2-mX_2}=\dfrac{1}{1-\eta/(1-mX_2/Y_1)}$。

经济上常取 $L/(mG)=1.0\sim2.0$。

## 例5-7（`#L10056-#L10100`）

直径 0.8 m 填料塔，清水吸氨：空气 1390 kg/h（$G=47.9$ kmol/h）、$y_1=0.0131$、回收率 99.5%、$Y^{*}=0.75X$、$L=52$ kmol/h、$K_Ya=314$ kmol/(m³·h)。

- $Y_1=0.0133$、$Y_2=6.65\times10^{-5}$、$X_1=0.0122$；
- $Y_1^{*}=0.0092$、$Y_2^{*}=0$；$\Delta Y_1=0.0041$、$\Delta Y_2=6.65\times10^{-5}$；
- $\Delta Y_{\mathrm{m}}=0.000979$ → $N_{OG}=13.5$；
- $H_{OG}=\dfrac{47.9}{314\times0.785\times0.8^2}=0.304$ m；
- $Z=0.304\times13.5=4.1$ m。

吸收因数法复核：$mG/L=0.691$、$\frac{Y_1-mX_2}{Y_2-mX_2}=200$ → $N_{OG}=13.4$，$Z=4.07$ m；查图5-23（$L/mG=1.45$、$0.005$）得 13.5。三法一致。

## 判断

- 两法数学上等价于"平衡线为直线"这一前提下；差别只在计算路径：平均推动力法要算两端推动力，吸收因数法要算 $L/(mG)$ 与比值。手算时代数法更省事，查图更快。
- 若平衡线明显弯曲，两者都不能直接用——必须图解积分或分段线性化。这是工业吸收（尤其高浓度、放热显著）最常见的失真来源。

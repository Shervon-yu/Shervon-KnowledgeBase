# 液液分散的均匀度与滴径

## 两个分散程度概念

- **完全分散**：设备顶部和底部都看不到清液块。但靠近内壁仍可能残留清液块，需再提转速；只能粗略反映分散程度（`#L2404`）。
- **均匀分散**：设备各部位液滴浓度都相等。靠取样分析，用分散指标判定（`#L2406`）。

## 分散指标

取样点（`#L2408-#L2412`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $i_{D}=\dfrac{R}{S}$ | （2-95） |
| **文字式** | $\text{取样点分散指标}=\dfrac{\text{样品中含量少的相的实测体积百分数}}{\text{该相在全釜的平均体积百分数}}$ |  |

全釜（`#L2416-#L2420`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $I_{D}=\dfrac{1}{n}\sum i_{D}$ | （2-96） |
| **文字式** | $\text{全釜分散指标}=\dfrac{1}{\text{取样点数}}\times\sum\text{各取样点分散指标}$ |  |

$n$ 越大越能反映真实情况；$I_D=0.98$ 即认为达到均匀分散（`#L2420`）。

## 滴径与比界面积

滴径用体表面积平均直径 $d_{32}$（`#L2424-#L2428`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{32}=\dfrac{6\varphi_{d}}{a}$ | （2-97） |
| **文字式** | $\text{索特平均直径}_{\text{【m】}}=\dfrac{6\times\text{分散相体积分数}}{\text{比界面积}_{\text{【1/m】}}}$ |  |

$\varphi_d$ 为分散相体积分数（相比）。注意方向：$a$ 是未知量时用其他关联式先算 $d_{32}$，再用本式反算 $a$。

## $d_{32}$ 关联式（表2-18 摘要）

主流形式是 $\dfrac{d_{32}}{d}=C\,We^{-0.6}\left(1+k\varphi_{d}\right)$，$We$ 按 $We=\dfrac{\rho N^{2}d^{3}}{\sigma}$ 理解（`#L2432-#L2451`）：

| 研究者 | 系数 | 相比修正 | 条件 |
|:---|:---|:---|:---|
| Sprow（2-98） | 0.052 | 无 | 六叶涡轮，$\varphi_d=0.005$ |
| Chen（2-99） | 0.053 | 无 | 光散射法 |
| Calderbank（2-100） | 0.06 | $(1+9\varphi_d)$ | 四叶桨，$\varphi_d=0\sim0.2$ |
| Brown（2-101） | 0.051 | $(1+3.14\varphi_d)$ | 六叶盘式涡轮 |
| Van Heuven（2-102） | 0.047 | $(1+2.5\varphi_d)$ | $\varphi_d=0.04\sim0.33$ |
| Mlyneck（2-103） | 0.058 | $(1+5.4\varphi_d)$ | 六叶盘式涡轮 |
| Gnanasundaram（2-104） | 0.052 | $e^{4\varphi_d}$；$We>10^4$ 取 0.039 | — |

两个非 We 形式（`#L2450-#L2451`）：

- 韩杰（2-105）：$d_{32}=0.132e^{1.79\varphi_d}(n^{3}d^{2})^{0.33}(d/D)^{-0.35}$，六直叶涡轮；
- 张燕敏（2-106）：$d_{32}=0.156e^{0.66\varphi_d}(n^{3}d^{2})^{0.38}(d/D)^{-0.21}$，框板式搅拌器。

## 用法

1. 定操作条件（$N$、$d$、物性）→ 算 $We$；
2. 按搅拌器型式与相比选表2-18 某式 → 得 $d_{32}/d$；
3. 用式（2-97）反算比界面积 $a$，再乘传质系数；
4. 需判断是否"均匀分散"时，另按式（2-95）（2-96）取样计算 $I_D$，目标 0.98。

各式的系数差异（0.047~0.06）来自测量方法（光散射/照相/电子计数）与体系，选同类型式并在结论里注明出处。

最小临界转速见 [[液液最小临界转速]]。

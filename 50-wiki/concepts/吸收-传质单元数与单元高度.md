# 吸收-传质单元数与单元高度

## 定义

低浓度气体稳态吸收塔的填料层高度，可写成"传质单元高度 × 传质单元数"（#L9855-#L9879）：

- **传质单元高度 $H_{OG}$**：传质单元数 $N_{OG}=1$ 时所需的填料层高度，反映**设备传质能力**（$G/\Omega$ 与 $1/K_Ya$ 的乘积，#L9891）。
- **传质单元数 $N_{OG}$**：反映**传质难易程度**——推动力越大，$N_{OG}$ 越小，所需填料越矮（#L9885）。

## 判据 / 计算

通用式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Z=H_{OG}\times N_{OG}=H_{OL}\times N_{OL}$ | （10-1） |
| **文字式** | $\text{填料层高度}_{\text{【m】}}=\text{气相总传质单元高度}_{\text{【m】}}\times\text{气相总传质单元数}=\text{液相总传质单元高度}_{\text{【m】}}\times\text{液相总传质单元数}$ |  |

原书编号：式(5-61)（#L9857）。

气相总传质单元数（推动力 $(Y-Y^*)$）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{OG}=\displaystyle\int_{Y_2}^{Y_1}\dfrac{\mathrm dY}{Y-Y^{*}}$ | （10-2） |
| **文字式** | $\text{气相总传质单元数}=\displaystyle\int_{\text{出口组成}}^{\text{入口组成}}\dfrac{\mathrm d\text{气相组成}}{\text{气相组成}-\text{平衡气相组成}}$ |  |

气相总传质单元高度：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H_{OG}=\dfrac{G}{K_{Y}a\,\Omega}$ | （10-3） |
| **文字式** | $\text{气相总传质单元高度}_{\text{【m】}}=\dfrac{\text{惰性气体摩尔流量}_{\text{【kmol/s】}}}{\text{气相总传质系数}_{\text{【kmol/(m²·s)】}}\times\text{比表面积}_{\text{【m²/m³】}}\times\text{塔截面积}_{\text{【m²】}}}$ |  |

原书编号：式(5-64)（#L9867）。液相总传质单元数、单元高度见式(5-65)（#L9871），气/液分传质单元见式(5-62)、(5-63)（#L9859、#L9863）。

积分式改写为平均值形式（积分中值定理）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{OG}=\dfrac{Y_1-Y_2}{\left(Y-Y^{*}\right)_m}$ | （10-4） |
| **文字式** | $\text{气相总传质单元数}=\dfrac{\text{气相组成变化}}{\text{平均传质推动力}}$ |  |

原书编号：式(5-64) 的等价写法（#L9883）。

## 适用范围与边界

- 推导前提：**低浓度气体**、**稳态**吸收，气液流量沿塔高近似不变（#L9851-#L9855）。
- 使用式(10-4) 需先算平均推动力 $(Y-Y^*)_m$；平衡线为直线时用对数平均，弯曲时须数值积分（#L9885）。
- $K_Ya$（体积总传质系数）随气液流量变化大，而 $H_{OG}$ 变化小：$K_Ya\propto G^{0.8}$ 时 $H_{OG}\propto G^{0.2}$，故工程上更常用 $H_{OG}$ 换算（#L9893）。
- 填料层高度不含塔顶分布器、塔底持液等附件高度。

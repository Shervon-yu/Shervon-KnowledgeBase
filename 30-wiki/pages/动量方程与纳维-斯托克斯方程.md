# 动量方程与纳维-斯托克斯方程

## 从牛顿第二定律到动量方程（§2.6）

对运动的无穷小流体微团取 $x$ 方向：$F_x=ma_x$（式 2-44，＃L1372）。作用力分体积力（式 2-45，＃L1390）与表面力（压力 + 三个面上的切应力/正应力，式 2-46～2-47，＃L1410-1414）；微团质量 $\rho\,\mathrm{d}x\mathrm{d}y\mathrm{d}z$（式 2-48），加速度是速度的物质导数 $a_x=\mathrm{D}u/\mathrm{D}t$（式 2-49，＃L1430）。合并得（式 2-50a，＃L1434）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho\dfrac{\mathrm{D}u}{\mathrm{D}t}=-\dfrac{\partial p}{\partial x}+\dfrac{\partial\tau_{xx}}{\partial x}+\dfrac{\partial\tau_{yx}}{\partial y}+\dfrac{\partial\tau_{zx}}{\partial z}+\rho f_x$ | （2-50a） |
| **文字式** | $\text{密度}\times\dfrac{\text{物质导数}_{\text{【速度}}_x\text{】}}{\text{时间}}=-\dfrac{\partial\text{压力}}{\partial x}+\dfrac{\partial\text{正应力}_{xx}}{\partial x}+\dfrac{\partial\text{切应力}_{yx}}{\partial y}+\dfrac{\partial\text{切应力}_{zx}}{\partial z}+\text{密度}\times\text{体积力}_x$ |  |

$y$、$z$ 方向同形（2-50b,c，＃L1440-1442）。三个方程都是运动微团上直接导出的，故为**非守恒形式**（＃L1444）。书里明确把这三个标量方程统称纳维-斯托克斯方程，纪念 19 世纪上半叶独立得到它们的 Navier 与 Stokes（＃L1444）。

## 改写成守恒形式

用物质导数展开（2-51）、乘积求导（2-52）、向量恒等式（2-53），把（2-51）变成（2-54）；方括号内恰是连续性方程（2-25）的左端，为零，于是（式 2-55，＃L1472）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho\dfrac{\mathrm{D}u}{\mathrm{D}t}=\dfrac{\partial(\rho u)}{\partial t}+\nabla\cdot(\rho u\boldsymbol{V})$ | （2-55） |
| **文字式** | $\text{密度}\times\dfrac{\text{物质导数}_{\text{【速度}}_x\text{】}}{\text{时间}}=\dfrac{\partial(\text{密度}\times\text{速度}_x)}{\partial\text{时间}}+\nabla\cdot(\text{密度}\times\text{速度}_x\times\text{速度})$ |  |

代回（2-50a）得守恒形式（2-56a～c，＃L1476-1486）。注意：守恒与非守恒的差别只在左端，右端（压力梯度、粘性力、体积力）相同（＃L1842）。

## 应力与粘性（牛顿流体）

牛顿流体假设切应力与速度梯度成正比；Stokes 在 1845 年给出六个应力分量（式 2-57a～f，＃L1490-1500）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau_{xx}=\lambda(\nabla\cdot\boldsymbol{V})+2\mu\dfrac{\partial u}{\partial x},\quad \tau_{xy}=\tau_{yx}=\mu\left(\dfrac{\partial v}{\partial x}+\dfrac{\partial u}{\partial y}\right)$ | （2-57a,d） |
| **文字式** | $\text{正应力}_{xx}=\text{第二粘性系数}\times(\nabla\cdot\text{速度})+2\times\text{分子粘性系数}\times\dfrac{\partial\text{速度}_x}{\partial x},\quad \text{切应力}_{xy}=\text{分子粘性系数}\times\left(\dfrac{\partial\text{速度}_y}{\partial x}+\dfrac{\partial\text{速度}_x}{\partial y}\right)$ |  |

并采用 Stokes 假设 $\lambda=-\tfrac{2}{3}\mu$（＃L1502-1506，书里注明"至今仍没有被严格证明"）。把这六个关系代入（2-56）即得完整 N-S 方程（式 2-58a～c，＃L1508-1516），左端是动量通量的散度，右端是压力梯度加粘性项。

## §2.8 的两条要点

1. 五个方程、六个未知量 $p,\rho,u,v,w,e$；需热状态方程 $p=\rho RT$ 与量热状态方程 $e=e(T,p)$ 才能封闭（＃L1850-1858）。
2. 现代 CFD 文献把"纳维-斯托克斯方程"扩展为**整个方程组**（连续性 + 动量 + 能量），书里遵从这一命名（＃L1866）。无粘极限删去摩擦与热传导项，得欧拉方程（式 2-82～2-86，＃L1780-1834）。

## 适用边界

- 控制方程是非线性耦合偏微分方程组，至今没有封闭形式的通解（＃L1840）；CFD 的全部工作就是数值求解它。
- 式（2-57）只对牛顿流体成立；血液等非牛顿流体不适用（＃L1488）。
- 上述方程不含质量扩散与化学反应（＃L1726），也不含湍流模型——雷诺平均或大涡模拟要在动量方程里另加湍流应力项。
- 求解前必须配物理边界条件（§2.9），见 [[CFD边界条件与守恒控制方程]]。

## 判断

N-S 方程的"守恒形式"不是数学装饰：有限体积法离散的是（2-56）左端的通量，守恒性由面通量成对相消保证；而差分离散（2-93）的强守恒形式时，守恒性取决于格式能否写成通量差分形式。书里第 6 章反复用这两个形式对照，正是为了让读者看清"方程守恒"与"格式守恒"是两回事。

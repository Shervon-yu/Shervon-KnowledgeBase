# 静态混合器的长度与压力降计算

## 一、长度 $L/D$ 的确定（`#L17212-#L17228`）

长度由**混合质量要求 + 混合难易**共同定，再靠实验与经验修正：

| 流型/过程 | 推荐 $L/D$ | 说明 |
|:---|:---|:---|
| 湍流 | 7~10 | 湍流下混合效果与长度基本无关，加长无明显收益 |
| 过渡流 | 10~15 | — |
| 层流 | 10~30 | 层流下混合效果随长度单调改善 |
| 萃取（要混匀又想快分层） | 7~10 | 控制流型 |
| 乳化、传质、传热 | 按工艺另定 | — |

SK 型例外：湍流下 $L/D=10\sim15$（`#L17218`）。

Sulzer 经验数据（表15-9，`#L17232-#L17238`）：气体混合 $L/D=1\sim3$；低黏液体 3~5；两种 5000 mPa·s 液体 5~10；主流 1000 mPa·s 加 1 mPa·s 流体 10；黏度差很大的两种流体 15。

## 二、$d_h$ 的定义（式15-4，`#L17299`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_h=4\left(\dfrac{\pi}{4}D^2L-\Delta A\,\delta\right)\big/(2\Delta A+\pi DL)$ | （15-4） |
| **文字式** | $\text{水力直径}_{\text{【m】}}=4\times\left(\dfrac{\pi}{4}\text{管内径}^2_{\text{【m】}}\times\text{混合器长度}_{\text{【m】}}-\text{混合单元单面总面积}_{\text{【m²】}}\times\text{单元材料厚度}_{\text{【m】}}\right)\div(2\times\text{混合单元单面总面积}_{\text{【m²】}}+\pi\times\text{管内径}_{\text{【m】}}\times\text{混合器长度}_{\text{【m】}})$ |  |

材料厚度 $\delta$ 一般 0.2 mm（`#L17284`）。单位体积单面面积 $A$ 与 $d_h$ 对应：$d_h$ 2.3/3.5/5/7/15/20 mm → $A$ 700/475/350/260/125/90 m²/m³（`#L17278-#L17282`）。

## 三、SV/SX/SL 型压降（式15-2、15-3，`#L17246`、`#L17248`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=\lambda\dfrac{\rho_c}{2\varepsilon^2}u^2\dfrac{L}{d_h}$ | （15-2） |
| **文字式** | $\text{压力降}_{\text{【Pa】}}=\text{摩擦系数}\times\dfrac{\text{连续相密度}_{\text{【kg/m³】}}}{2\times\text{空隙率}^2}\times\text{空管流速}^2_{\text{【m/s】}}\times\dfrac{\text{混合器长度}_{\text{【m】}}}{\text{水力直径}_{\text{【m】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re_\varepsilon=\dfrac{d_h\rho_c u}{\mu\varepsilon}$ | （15-3） |
| **文字式** | $\text{修正雷诺数}=\dfrac{\text{水力直径}_{\text{【m】}}\times\text{连续相密度}_{\text{【kg/m³】}}\times\text{空管流速}_{\text{【m/s】}}}{\text{连续相黏度}_{\text{【Pa·s】}}\times\text{空隙率}}$ |  |

摩擦系数 $\lambda$ 与 $Re_\varepsilon$ 的分段关系见表15-10（`#L17288-#L17295`），核心分段：

| 型号 | 层流 | 过渡区 | 湍流 | 完全湍流 |
|:---|:---|:---|:---|:---|
| SV 2.3/D、3.5/D | $Re<23$，$\lambda=139/Re$ | $23<Re<150$，$\lambda=23.1Re^{-0.429}$（3.5/D 为 $43.7Re^{-0.681}$） | $150<Re<2400$，$\lambda=14.1Re^{-0.329}$（3.5/D 为 $10.7Re^{-0.751}$） | $Re>2400$，$\lambda\approx1.09$（3.5/D 为 0.702） |
| SV (5~15)/D | $Re<150$，$\lambda=150/Re$ | — | $Re>150$，$\lambda\approx1.0$ | — |
| SX | $Re<13$，$\lambda=235/Re$ | $13<Re<70$，$\lambda=74.7Re^{-0.475}$ | $70<Re<2000$，$\lambda=22.3Re^{-0.194}$ | $Re>2000$，$\lambda\approx5.11$ |
| SL | $Re<10$，$\lambda=156/Re$ | $10<Re<100$，$\lambda=57.7Re^{-0.566}$ | $100<Re<3000$，$\lambda=10.8Re^{-0.205}$ | $Re>3000$，$\lambda\approx2.10$ |

## 四、SH/SK 型压降（式15-5、15-6，`#L17303`、`#L17305`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=\lambda\dfrac{\rho_c}{2}u^2\dfrac{L}{D}$ | （15-5） |
| **文字式** | $\text{压力降}_{\text{【Pa】}}=\text{摩擦系数}\times\dfrac{\text{连续相密度}_{\text{【kg/m³】}}}{2}\times\text{空管流速}^2_{\text{【m/s】}}\times\dfrac{\text{混合器长度}_{\text{【m】}}}{\text{管内径}_{\text{【m】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re_D=\dfrac{D\rho_c u}{\mu}$ | （15-6） |
| **文字式** | $\text{雷诺数}=\dfrac{\text{管内径}_{\text{【m】}}\times\text{连续相密度}_{\text{【kg/m³】}}\times\text{空管流速}_{\text{【m/s】}}}{\text{连续相黏度}_{\text{【Pa·s】}}}$ |  |

表15-11（`#L17313-#L17320`）：SH 层流 $Re_D<30$、$\lambda=3500/Re_D$；过渡 $30<Re_D<320$、$\lambda=646Re_D^{-0.503}$；湍流 $Re_D>320$、$\lambda=80.1Re_D^{-0.141}$。SK 层流 $Re_D<23$、$\lambda=430/Re_D$；过渡 $23<Re_D<300$、$\lambda=87.2Re_D^{-0.191}$；湍流 $300<Re_D$、$\lambda=17.0Re_D^{-0.206}$；$Re_D>11000$ 时 $\lambda\approx2.53$。

压力降计算值允许偏差 **±30%**，适用于液-液、气-液、液-固混合（`#L17311`）。

## 五、气-气混合压降（式15-7，`#L17334`）

气-气一般用 SV 型，上化院回归式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=0.0502\left(u\sqrt{\rho_c}\right)^{1.5339}\dfrac{L}{d_h}$ | （15-7） |
| **文字式** | $\text{压力降}_{\text{【Pa】}}=0.0502\times\left(\text{气体流速}_{\text{【m/s】}}\times\sqrt{\text{混合气密度}_{\text{【kg/m³】}}}\right)^{1.5339}\times\dfrac{\text{混合器长度}_{\text{【m】}}}{\text{水力直径}_{\text{【m】}}}$ |  |

## 六、计算简化（`#L17328`）

SH/SK 压降式中的空隙率简化为：$D\le50$ mm 取 $\varepsilon\approx0.9$；$D>50$ mm 取 $\varepsilon=1.0$。

## 判断

- 压降式是「几何 + 物性 + 流速」的显式式，没有隐含迭代，手算即可；真正的误差来源是 $\lambda$ 的分段边界（$Re$ 落在 23/150 或 320 附近时，摩擦系数跳变，压降可差一倍）。
- 原文允许 ±30% 偏差，工程设计应按上限配管，不要按平均值选泵。

# 流量测定-孔板与测速管

## 定义

**测速管（皮托管）**：两根弯成直角的同心套管，内管测**冲压**（静压＋动能），外管壁小孔与流动方向平行测**静压**，压差即动能项，因此测出的是**点速度**（《化工原理》§1.6 #L2728、#L2738）。

**孔板流量计**：在管路中插入开孔圆板，流体收缩到最小截面处称**缩脉**（vena contracta），缩脉处流速最大、压力最低；用孔板前后压差换算流量（#L2786、#L2794）。压差与流量的关系式称**流量方程式**（#L2798）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_{1}=\sqrt{\dfrac{2gR(\rho_{0}-\rho)}{\rho}}$ | （1.6-1） |
| **文字式** | $\text{测速管点速度}_{\text{【m/s】}}=\sqrt{\dfrac{2\times\text{重力加速度}_{\text{【m/s²】}}\times\text{压差计读数}_{\text{【m】}}\times\left(\text{指示液密度}_{\text{【kg/m³】}}-\text{流体密度}_{\text{【kg/m³】}}\right)}{\text{流体密度}_{\text{【kg/m³】}}}}$ |  |

（式 1-69a，测速管，#L2750；当指示液为水而流体为气体时用 1-69b 近似，省去 $\rho$，#L2754。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{m}=\alpha A_{0}\sqrt{2\rho\Delta p}$ | （1.6-2） |
| **文字式** | $\text{质量流量}_{\text{【kg/s】}}=\text{流量系数}\times\text{孔口面积}_{\text{【m²】}}\times\sqrt{2\times\text{流体密度}_{\text{【kg/m³】}}\times\text{孔板前后压差}_{\text{【Pa】}}}$ |  |

（式 1-74，#L2828；$\alpha=C/\sqrt{1-\beta^{4}}$ 称流量系数，$\beta=d_{0}/D$，#L2830。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{m}=\varepsilon\alpha A_{0}\sqrt{2\rho\Delta p}$ | （1.6-3） |
| **文字式** | $\text{气体质量流量}_{\text{【kg/s】}}=\text{气体膨胀系数}\times\text{流量系数}\times\text{孔口面积}_{\text{【m²】}}\times\sqrt{2\times\text{气体密度}_{\text{【kg/m³】}}\times\text{孔板前后压差}_{\text{【Pa】}}}$ |  |

（式 1-75，气体/蒸气，#L2836；$\varepsilon$ 是 $p_{2}/p_{1}$、绝热指数 $\kappa$、$\beta$ 的函数，#L2838。）

**求 $\alpha$ 要试差**：$\alpha$ 随 $Re$ 变，而 $Re$ 里的流速又未知，故先假定 $\alpha$，算出 $q_{m}$、$u$、$Re$，再查图核对（#L2840、#L2848）。

## 适用范围与边界

- 测速管测点速度；求平均速度须测管中心最大速度 $u_{max}$，算 $Re_{max}$ 后查图 1-40 得 $u/u_{max}$（#L2756）。
- 孔板流量计结构简单、造价低，但压损大（缩脉后截面突然扩大形成旋涡，#L2794）。
- 气体必须用带 $\varepsilon$ 的式(1-75)，液体用式(1-74)。
- 本书未给孔板 $\alpha$ 的解析式，只给查图/查表路径（#L2840）；本库未收转子流量计（恒压差、变截面）的正文行，故本页不展开。

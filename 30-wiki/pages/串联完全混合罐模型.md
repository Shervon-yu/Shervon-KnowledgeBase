# 串联完全混合罐模型

## 为什么还要它

扩散模型只适用 $D_t$ 均匀的场合；工程上还要"给定出口浓度、估反应器容积"这种反算。串联 CSTR 的方程更简单，特别在稳态下能逐级解析（`#L6282`、`#L6302`）。

## 逐级物料平衡

单釜（`#L6288`、`#L6296`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{\mathrm{d}C_1}{\mathrm{d}t}=\dfrac{C_i-C_1}{\theta_1}+\psi(C_1)$ | （5.37'） |
| **文字式** | 第 1 釜内浓度变化 = 进出口浓度差 ÷ 单釜停留时间 + 反应项 |  |

第 $j$ 釜同构（5.38）；稳态时（`#L6308`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{C_{j-1}-C_j}{\theta_j}+\psi(C_j)=0$ | （5.39） |
| **文字式** | 稳态：上一级来量减本级去量 + 反应消耗 = 0 |  |

**只要 $C_{j-1}$ 与 $\theta_j$ 已知，逐级就能算下去**——即使 $\psi(C)$ 形式复杂也可用解析或图解法（`#L6310`）。

## 等容积分配

|  |  |  |
|:---|:---:|---|
| **符号式** | $V_1=V_2=\cdots=V_n=V/n,\qquad \theta_1=\theta_2=\cdots=\theta_n=\theta/n$ | （5.40）（5.40'） |
| **文字式** | 总容积与总停留时间平均分给 n 个罐 |  |

## 与扩散模型的换算

Kramers 的经验关系（`#L6320`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $M=\dfrac{Lu}{2D_t}=n-1$ | （5.41） |
| **文字式** | 混合强度参数 ≈ 串联罐数 − 1 |  |

出口年龄分布（`#L6326`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $E\!\left(\dfrac{t}{\theta}\right)=\dfrac{n^{n}}{(n-1)!}\left(\dfrac{nt}{\theta}\right)^{n-1}e^{-nt/\theta}$ | （5.42） |
| **文字式** | n 级串联的年龄分布是 Gamma 分布 |  |

> OCR：原书该式印作 $\dfrac{n}{(n-1)!}$，按其自身归一化 $\int E\,\mathrm{d}(t/\theta)=1$ 校核应为 $n^{n}/(n-1)!$。

## 适用边界（关键）

- $n$ 不必是整数：$n=5\sim6$ 之间可按比例内插得到 $n=5.3$ 的出口浓度（`#L6322`）。
- **$n>10$ 足够精确**；**$n<5$（返混激烈）不适用**——这是本模型的硬边界，别外推。
- 需要更贴近实际时可加"回流量"修正（图5.18，返混型串联罐）。

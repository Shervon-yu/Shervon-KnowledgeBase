# 齿轮泵与旋涡泵

## 齿轮泵（`#L4017-#L4035`）

结构：椭圆形泵壳 + 两个齿轮（主动轮 + 从动轮，啮合反向旋转）。

工作过程：
- 两齿相互**分开**的一侧形成低压 → 吸液；
- 液体沿壳壁被推到排出腔；
- 两齿相互**合拢**的一侧挤压液体形成高压 → 排出。

特点：

| 项目 | 内容 |
|:---|:---|
| 类型 | 正位移泵（与往复泵同类，故流量与压头解耦、关阀不能调流量） |
| 扬程 | 能产生较高扬程 |
| 流量 | 较均匀 |
| 适用 | 流量小、**无固体颗粒**、高黏度液体（各种油类） |
| 优点 | 构造简单、维修方便、价格低廉、运转可靠 |

## 旋涡泵（`#L4037-#L4047`）

结构：泵壳内壁为圆形，吸入口与排出口都在泵壳顶部、由**间壁**隔开（间隙极小，防漏回）；圆盘形叶轮两侧边缘沿半径方向铣出许多长条形凹槽作叶片、辐射状排列；叶轮两侧平面紧靠泵壳，叶片周围与泵壳之间形成液体流道。

工作原理：
1. 叶轮旋转，叶片推液体向前运动；
2. 叶片槽内液体在离心力作用下甩向流道，流道内压力增大；
3. 流道与叶片槽之间形成**旋涡流**；
4. 液体从吸入口到排出口经过多次旋涡流作用，压力逐级增大，最终排出。

关键性能：

| 项目 | 数据/说明 |
|:---|:---|
| 流量—扬程特性 | 流量小时旋涡作用次数多、扬程与功率均**大**；流量增大扬程急剧降低 → 只适合小流量 |
| 启动 | 流量小时功率大，**启动时不要关闭出口阀** |
| 流量调节 | **旁路回流调节法**（不能用关阀，因为关阀=小流量=大功率） |
| 扬程量级 | 同叶轮直径与转速下约为离心泵的 **2~4 倍** |
| 效率 | 低，一般 **30%~40%**（旋涡流摩擦损失大） |
| 适用 | 小流量、高扬程、低黏度液体；可作耐腐蚀泵（不锈钢/塑料叶轮与泵壳） |

## 判断

- 旋涡泵"小流量大功率"与离心泵"零流量最小功率"完全相反，所以两者的启动规程也相反：离心泵关阀启动，旋涡泵开阀启动。
- 齿轮泵与旋涡泵的调节方式都指向同一个结论：**凡流量不随扬程自由变化的泵（正位移型或准正位移型），都靠旁路而非节流调节**。

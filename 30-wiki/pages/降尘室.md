# 降尘室

## 用途与能力（`#L4713-#L4717`）

最原始的重力除尘设备，一般作**预分离**，除去 50 μm 以上粗颗粒。典型为水平流动型。

## 分离条件（`#L4717-#L4725`）

气流进降尘室后流道扩大、流速降低。设室长 L、高 H，颗粒水平分速与气速相同为 $u$：

- 停留时间 = $L/u$；沉降时间 = $H/u_t$；
- 分离条件：停留时间 ≥ 沉降时间。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $L/u\ge H/u_t$ | （3-15） |
| **文字式** | $\dfrac{\text{室长}}{\text{气流速度}}\ge\dfrac{\text{室高}}{\text{沉降速度}}$ |  |

## 临界粒径（`#L4727-#L4757`）

由 $q_{Vs}=uHW$ 代入上式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_{tc}=\dfrac{q_{Vs}}{WL}$ | （3-17） |
| **文字式** | $\text{临界沉降速度}=\dfrac{\text{含尘气体体积流量}_{\text{【m³/s】}}}{\text{室宽}\times\text{室长}}$ |  |

满足该式的粒径称**临界粒径 $d_{pc}$**——能 100% 除去的最小粒径；比它大的颗粒都能沉下来。

层流区（斯托克斯区）时，代入 3-12：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{pc}=\sqrt{\dfrac{18\mu}{(\rho_p-\rho)g}\cdot\dfrac{q_{Vs}}{WL}}$ | （3-18） |
| **文字式** | $\text{临界粒径}_{\text{【m】}}=\sqrt{\dfrac{18\times\text{黏度}}{(\text{颗粒密度}-\text{流体密度})\times g}\times\dfrac{\text{气体流量}}{\text{底面积}}}$ |  |

**关键结论（`#L4757`）**：$q_{Vs}$ 一定时，$d_{pc}$ 与 $u_{tc}$ 只与**底面积 $WL$** 成反比，**与高度 H 无关**。

## 为什么宜扁平（`#L4759-#L4765`）

- 气体流速 $u$ 不能太大（一般 ≤3 m/s），否则干扰尘粒沉降或把已沉尘粒重新卷起；
- 由"与 H 无关"可知，减小 H 不影响临界粒径，但可提高相同底面积下的处理量、使设备扁平；
- 若设 H 减半，则气速加倍、停留时间减半、沉降时间也减半，$u_{tc}$ 不变——分离能力不变。

## 多层隔板（`#L4767-#L4781`）

用水平隔板分成 N 层，每层高 H/N，气速 $u$ 不变、停留时间不变：

- 沉降高度降为 1/N → 所需 $u_{tc}$ 降为 1/N；
- 临界粒径降为原来的 $\sqrt{1/N}$，可分离 **20 μm 以上**；
- 缺点：排灰不方便。

## 计算三类问题（`#L4783-#L4791`）

① 已知 $q_{Vs}$、物性、$d_{pc}$ → 求底面积 $WL$；
② 已知底面积、物性、$d_{pc}$ → 求处理量 $q_{Vs}$；
③ 已知底面积、物性、$q_{Vs}$ → 求临界粒径 $d_{pc}$。

## 例3-2（`#L4793-#L4809`）

高 2 m、宽 2.5 m、长 5 m；空气 $\rho$=0.779 kg/m³、$\mu$=2.53×10⁻⁵ Pa·s、$q_{Vs}$=1.25×10⁴ m³/h；粉尘 $\rho_p$=2000 kg/m³：

- $u_{tc}$=0.278 m/s；
- 设层流区，$d_{pc}$=80.3 μm；
- 校核 $Re$=0.687<2 → 层流成立。

## 判断

- "只与底面积有关"是降尘室设计的核心：加宽加长有效、加高无效。这解释了为什么工业降尘室都是矮而宽的大房间。
- 多层隔板把"高度"用到了极致，但代价是清灰困难——这是结构与操作性的权衡。

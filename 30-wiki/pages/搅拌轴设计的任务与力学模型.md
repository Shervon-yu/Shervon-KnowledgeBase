# 搅拌轴设计的任务与力学模型

## 设计任务

搅拌轴的设计主要是确定**危险截面处轴的最小尺寸**，进行强度、刚度计算或校核，验算轴的临界转速和挠度，保证搅拌轴能安全平稳地运转（`#L11433`）。

轴径 $d$ 的先后关系（`#L11435`）：

1. 一般情况：$d$ **必须满足强度和临界转速**要求；
2. 有特殊要求时：还应满足**扭转**（单位长度扭转角）或**径向位移**要求；
3. 最后考虑材料的**腐蚀裕量**，把直径**圆整为标准轴径**。

## 力学模型的基本假设（十条）

为方便计算，对搅拌轴作下列简化（`#L11443-#L11461`）：

1. 搅拌器浸入的液体为**连续相**介质；
2. 进出口处介质流动对作用在轴上的**流体径向力无显著干扰**；
3. 用**刚性联轴器**连接的可拆轴按**整体轴**计算；
4. **不考虑**密封部件作用在轴上的力和轴承的柔度；
5. 搅拌器及轴上其他零件的重力、惯性力、流体作用力均作用在**零件轴套的中部**；几个轴套（如框式）时近似均分，各作用于每一轴套中部；
6. 轴承以外轴外伸部分长度不超过单跨跨长（或悬臂长度）的 **30%**，且外伸部分零件质量不大于跨中或悬臂部分单个零件质量时，**外伸段不予考虑**；
7. 计算临界转速时，深度小于 $0.1d$ 的键槽、直径大于 $0.9d$ 的局部环形沟槽**可不计**；
8. 悬臂轴：悬臂段与跨间段**各自等直径**，两段直径可等可不等；单跨轴：跨间段等直径；
9. 等直径轴段内允许存在直径差 $\le 5\%d$ 的区段，取**最长部分**直径作为该段设计轴径；
10. 轴为**同一材料**、不考虑沿轴温度变化；扭转变形计算中**最大扭矩发生在传动侧轴承处**。

## 按柔性轴设计时的附加条件（八条）

除上述十条外，柔性轴还必须满足（`#L11465-#L11479`）：

1. 悬臂轴的跨间段与悬臂段**直径必须相等**（单跨轴仅要求跨间段等直径）；
2. 轴的计算长度范围内**不得装可拆联轴器**；
3. 只允许装三叶后掠式、开启涡轮、圆盘涡轮、推进式等**高转速搅拌器**；
4. 无折流挡板的容器中**不允许安装其他内件**；
5. **不得**在气体介质和气-液介质中使用；
6. 充液高度**不低于** $1/2$ 容器直径；
7. 漏斗状漩涡液面凹下深度不超过 $1/2$ 充液高度，且漩涡最低液面**不得低于搅拌器**；
8. 搅拌器产生轴向流时，应保证搅拌轴**仅受拉力**。

## 受力模型与惯性矩比

简化后的模型见**图9-54（悬臂式）**与**图9-55（单跨式）**（`#L11481`）。悬臂段与跨间段惯性矩之比：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\dfrac{I_{L1}}{I_{0}}=\dfrac{d_{L1}^{4}(1-N_{0}^{4})}{d_{0}^{4}(1-N_{0}^{4})}$ |  |
| **文字式** | $\text{惯性矩比}=\dfrac{\text{悬臂段惯性矩}_{\text{【mm}^{4}\text{】}}}{\text{跨间段惯性矩}_{\text{【mm}^{4}\text{】}}}=\dfrac{\text{悬臂段外径}_{\text{【mm】}}^{4}(1-\text{空心比}^{4})}{\text{跨间段外径}_{\text{【mm】}}^{4}(1-\text{空心比}^{4})}$ |  |

式中 $N_{0}$ 为空心轴内径与外径之比；实心轴 $N_{0}=0$，此时 $\lambda=(d_{L1}/d_{0})^{4}$。

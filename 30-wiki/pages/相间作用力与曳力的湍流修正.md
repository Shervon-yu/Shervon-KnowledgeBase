# 相间作用力与曳力的湍流修正

## 为什么要修正（`#L3123`）

单气泡在静止液体中的曳力系数（Schiller-Naumann 等）不能直接用于搅拌釜：釜内液体处于**强湍流**，气泡周围被湍流涡包裹，气泡形状、尾涡、相对速度都在变。

原文只考虑**曳力**与**附加质量力**两项（升力、壁面润滑力未计）。

## 曳力系数的修正（7.6，`#L3125`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{C_D-C_{D0}}{C_{D0}}=K\left(\dfrac{d_b}{\lambda}\right)^{3}$ | （7.6） |
| **文字式** | $\dfrac{\text{曳力系数}-\text{静止液体曳力系数}}{\text{静止液体曳力系数}}=\text{经验系数}\times\left(\dfrac{\text{气泡直径}}{\text{Kolmogorov 微尺度}}\right)^{3}$ |  |

- $C_{D0}$ 单气泡静止液体曳力系数；$d_b$ 气泡直径；$\lambda$ 湍流微尺度；
- $K$ 经验值：**本书取 $8.76\times10^{-4}$**；Khopkar 等取 $6.5\times10^{-6}$（差两个量级，说明该系数对流场敏感）。

## 相对雷诺数与有效黏度（7.7~7.10，`#L3131-#L3153`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re=\dfrac{\rho_l d_b|\mathbf{u}_l-\mathbf{u}_b|}{\mu}$ | （7.7） |
| **文字式** | $\text{相对雷诺数}=\dfrac{\text{液相密度}\times\text{气泡直径}\times\text{气液相对速度}}{\text{有效黏度}}$ |  |

有效黏度有两条常用写法（择一）：

$$\mu=\mu_L+C_1\rho_l\frac{k^2}{\varepsilon}\tag{7.8}$$

$$\mu=\mu_L+C_7\rho_l\varepsilon^{1/3}d_b^{4/3}\tag{7.10}$$

- 7.8：用湍动能 $k$ 与耗散率 $\varepsilon$；$C_1$ 取值 **Bakker 0.02、Kerdouss 0.3**（差一个量级）；
- 7.10：$C_7$ 取 0.02，直接把 $d_b$ 与 $\varepsilon$ 引入，**对气泡尺度更敏感**；
- 二者中间桥梁是 7.9：$k=0.5\overline{u'^2}=\varepsilon^{2/3}d_b^{2/3}$。

## 判断

- 7.6 的 $(d_b/\lambda)^3$ 是**湍流对曳力的放大**：小气泡跟随涡运动、相对速度降低，大气泡穿越涡、相对速度大，故修正量随 $d_b/\lambda$ 三次方增长；
- $K$ 从 $10^{-6}$ 到 $10^{-4}$ 的差异说明：这类经验系数**不能跨釜型套用**，必须用自己的实验标定；
- 本书只计曳力+附加质量力，省略升力与壁面润滑力，是模拟结果"比 CT 更均匀"的原因之一（少了对气泡的横向聚集与贴壁排斥）。

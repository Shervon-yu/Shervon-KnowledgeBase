# 固体混合设备的功率计算

## 功率的四个组成部分（`#L15431-#L15441`）

① 使容器内粉粒体运动消耗的功率；
② 轴承、减速装置和传动装置摩擦消耗的功率；
③ 连续驱动容器本身或搅拌桨叶回转消耗的功率；
④ 其他附属装置（如控制器）消耗的功率。

其中①受装置结构、尺寸、粉粒体物性和操作条件影响，其余为机械损失与辅机，选电机时按效率折算（参见 [[搅拌用电动机的选用原则]]）。

## 总关系式（式12-5，`#L15443-#L15451`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=2\pi nT$ | （12-5） |
| **文字式** | $\text{功率}_{\text{【W】}}=2\pi\times\text{回转速}_{\text{【r/s】}}\times\text{轴力矩}_{\text{【N·m】}}$ |  |

## 容器回转型：式12-6（`#L15455-#L15469`）

卧式滚筒的三个回转力矩来源：①使容器回转、作用于粉粒体层重心的重力矩；②使粉粒体层以一定速度做圆周运动的力矩；③回转离心力引起的粉粒体层与容器内壁间的摩擦力矩。整理后：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{T}{R^{3}L\rho g}=A+B\dfrac{n^{2}R}{g}$ | （12-6） |
| **文字式** | $\dfrac{\text{轴力矩}_{\text{【N·m】}}}{\text{回转半径}^{3}_{\text{【m】}}\times\text{筒体长度}_{\text{【m】}}\times\text{表观密度}_{\text{【kg/m³】}}\times9.81}=\text{系数}A+\text{系数}B\times\dfrac{\text{回转速}^{2}_{\text{【r/s】}}\times\text{回转半径}_{\text{【m】}}}{9.81}$ |  |

系数 $A$、$B$ 与装料系数 $f$、安息角 $\alpha$、粉粒体与容器内壁的摩擦系数 $\mu_N$ 有关，由图12-9 查取（`#L15469`）。

V 型与双重圆锥型：随容器回转，粉粒体连续往复从一端到另一端，轴力矩按周期 $\pi$ 在 $T_{max}$ 与 $T_{min}$ 之间变动；用最大回转半径 $R_{max}$ 代入，$T_{max}$、$T_{min}$ 的基本形式仍同式12-6，但系数 $A$、$B$ 由试验确定（`#L15471-#L15481`）。这意味着电机选型须按 $T_{max}$ 计，均方根值只用于发热校核。

## 容器固定型：式12-7（`#L15483-#L15505`）

螺带叶片或搅拌桨回转时，对流动良好的粉粒体，轴力矩由实验关联：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $T=K\,D_{\mathrm{p}}^{\alpha_1}\rho^{\alpha_2}\mu_{\mathrm{S}}^{\alpha_3}Z^{\alpha_4}d^{\alpha_5}\left(\dfrac{s}{d}\right)^{\alpha_6}b^{\alpha_7}f^{\alpha_8}$ | （12-7） |
| **文字式** | $\text{轴力矩}_{\text{【N·m】}}=\text{实验系数}\times\text{粒子直径}^{\alpha_1}_{\text{【m】}}\times\text{表观密度}^{\alpha_2}_{\text{【kg/m³】}}\times\text{内摩擦系数}^{\alpha_3}\times\text{粉粒体层高度}^{\alpha_4}_{\text{【m】}}\times\text{叶片外径}^{\alpha_5}_{\text{【m】}}\times\left(\dfrac{\text{螺带节距}_{\text{【m】}}}{\text{叶片外径}_{\text{【m】}}}\right)^{\alpha_6}\times\text{叶片宽度}^{\alpha_7}_{\text{【m】}}\times\text{装料系数}^{\alpha_8}$ |  |

## 指数表12-4（`#L15509-#L15515`）

| 机型 | α₁(D_p) | α₂(ρ) | α₃(μ_S) | α₄(Z) | α₅(d) | α₆(s/d) | α₇(b) | α₈(f) |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 立式螺带 | 0 | 1.0 | 0.7 | 1.5 | 3.0 | 1.2 | −0.8 | — |
| 卧式螺带 | 0 | 1.0 | 1.2 | 1.0 | 3.3 | −0.3 | 0.7 | 1.2 |
| 桨叶式 | 0 | 1.0 | 1.0 | 1.0 | 2.0 | — | 1.0 | — |

读表要点：

- 三种机型的 $D_p$ 指数全为 0——**粒子直径不影响轴力矩**，力矩由料层整体阻力决定；
- $\rho$ 指数全为 1.0，与式12-6 的重力项一致；
- 对 $d$ 的指数最大（2.0~3.3），说明**叶片外径是功率最敏感的几何参数**；
- 立式螺带的 $b$ 指数为负（−0.8）、卧式螺带的 $s/d$ 指数为负（−0.3）——加宽叶片或加大节距反而降力矩，属排料能力增强、料层被带动的份额下降。

## 使用限制（`#L15517`）

以上是典型粉粒体实验得到的一般关系式与指数。粉粒体物性（表观密度、流动性、含水率等）对混合功率影响很大，**设计大型设备时应先用小型实验样机测定实际功率，再换算大设备功率**，不要直接套指数外推。

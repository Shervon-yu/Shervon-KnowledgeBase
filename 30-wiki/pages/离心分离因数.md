# 离心分离因数

## 离心力的量级（`#L4839-#L4849`）

以角速度 $\omega$ 旋转的圆筒内，忽略重力沉降，颗粒受离心力：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_c=mr\omega^2$ | （3-19 前式） |
| **文字式** | $\text{离心力}_{\text{【N】}}=\text{颗粒质量}\times\text{旋转半径}\times\text{角速度}^2$ |  |

$\omega=2\pi N/60$（$N$ 为 r/min）代入后工程近似式：

$$F_c\approx \frac{mrN^2}{100}$$

## 定义（`#L4849-#L4859`）

同一颗粒所受离心力与重力之比：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_c=\dfrac{r\omega^2}{g}\approx\dfrac{rN^2}{900}$ | （3-19） |
| **文字式** | $\text{离心分离因数}=\dfrac{\text{半径}\times\text{角速度}^2}{g}\approx\dfrac{\text{半径}_{\text{【m】}}\times\text{转速}_{\text{【r/min】}}^2}{900}$ |  |

$K_c$ 表示离心力场相当于重力场的倍数，是衡量离心分离能力的核心指标。

## 提高 $K_c$ 的两条路（`#L4843`）

| 手段 | 影响 | 限制 |
|:---|:---|:---|
| 提高 $\omega$（转速） | $K_c\propto N^2$，**更有效** | 转速高则轴承、密封、动平衡要求高 |
| 增大 $r$（半径） | $K_c\propto r$，线性 | 受转筒机械强度限制，$r$ 不宜太大 |

结论：**提高转速比增大半径更有效**（平方 vs 一次方），但机械强度约束使大直径设备不能高速旋转。

## 算例（`#L4917-#L4921`）

旋风分离器切向速度 $u_i$=20 m/s、旋转半径 $r$=0.3 m：

$$K_c=\frac{u_i^2}{gr}=\frac{20^2}{9.81\times0.3}=136$$

即该条件下颗粒的离心沉降速度是重力沉降速度的 **136 倍**。

## 判断

- $K_c$ 的量级解释了离心设备为何能处理重力沉降搞不定的微细颗粒：不是改变颗粒，而是把"驱动加速度"放大两个数量级。
- 旋风分离器用 $u_i^2/r$ 代替 $r\omega^2$，说明其分离能力由进口速度主导，这也是进口速度 15~20 m/s 的由来。

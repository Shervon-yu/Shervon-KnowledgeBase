# 回流比与进料热状态对精馏过程的影响

## 热负荷的定义（`#L12072-#L12092`）

塔顶蒸气全部冷凝为泡点液体：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q_C=r_cV$，$Q_B=r_bV'$ | （无编号） |
| **文字式** | $\text{冷凝器热负荷}=\text{馏出液汽化热}\times\text{塔顶蒸气量}$；$\text{再沸器热负荷}=\text{釜液汽化热}\times\text{提馏段蒸气量}$ |  |

全塔热量衡算：$Q_F+Q_B=Q_C+Q_D+Q_W$。

## 三种情况（`#L12094-#L12108`）

| 固定量 | 结论 |
|:--|:--|
| q 一定、R 增大 | R'、V、V'、L、L' 全增大 → Q_C、Q_B 都增大（塔内循环量增大） |
| R 一定 | $V=(R+1)D$ 定 → $Q_C$ 定；$Q_F+Q_B$ 定：q 减小（进料热）→ $Q_B$ 减小 |
| R' 一定 | $Q_B$ 定：q 减小 → R 增大 → $Q_C$ 增大 |

**工程取向**：应在再沸器输入热量（让 V' 在**全塔**起传质作用），进料通常预热到泡点附近；若原料本身是蒸气就不必冷凝——虽板数增多，但操作费降低可补偿设备费。

## 例6-12（`#L12110-#L12152`）

乙醇-水，$F$=100 kmol/h、$x_F$=0.3、$x_D$=0.8、$x_W$=0.005、$R$=1.6：

- $D=100\times\frac{0.3-0.005}{0.8-0.005}=37.1$ kmol/h；$V=(R+1)D=96.5$ kmol/h；
- $r_c=39600\times0.8+43200\times0.2=40300$ kJ/kmol → $Q_C=40300\times96.5=3.89\times10^6$ kJ/h；
- 饱和液体进料：$V'=V=96.5$，釜液近纯水 $r_b=2260\times18=40700$ → $Q_B=3.93\times10^6$ kJ/h（与 $Q_C$ 基本相等）；
- 汽液比 1 的混合物进料：$q$=0.5 → $V'=96.5-0.5\times100=46.5$ → $Q_B=1.89\times10^6$ kJ/h（**进料预热后再沸器负荷减半**）。

## R、q 对板数的影响（`#L12154-#L12193`）

**（1）q 一定、R 增大**：精馏段线斜率 $R/(R+1)$ 增大、两线都远离平衡线 → 所需板数减少；对既定塔则 $x_D$ 增大、$x_W$ 减小，但 $Q_C$、$Q_B$ 都增大。

**（2）R 一定、q 增大**（进料变冷）：精馏段线位置不变，提馏段线远离平衡线 → 板数减少；代价是 $Q_B$ 增大（$Q_F$ 减少）。

**（3）R' 一定、q 减小**（进料变热）：提馏段线不变，精馏段线远离平衡线 → 板数减少；代价是 R 增大、$Q_C$ 增大。

## 判断

- 三条"板数减少"结论看似矛盾，实质是**同一个约束在变**：R 固定时变化的是提馏段，R' 固定时变化的是精馏段——先看哪个量被固定。
- 热负荷与板数是"操作费 vs 设备费"的对偶：增大回流永远能减板，但再沸器/冷凝器要跟着变大，经济最优点在二者之间（见选回流比）。
- 例6-12 的量化结论值得记：饱和液→汽液比 1，$Q_B$ 从 3.93 降到 1.89（约 −52%），这正是"预热进料省能"的账。

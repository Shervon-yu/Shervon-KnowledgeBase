# 刮壁式搅拌釜的传热系数与功率关联式

## 传热系数（表 3-4）

| 搅拌器型式 | 关联式 | 公式号 | 适用 |
|:---|:---|:---|:---|
| 螺带+橡胶刮板 | $N_u=5.4Re^{1/3}Pr^{1/3}V_{is}^{0.2}$ | （3-11） | — |
| 螺带+刮板 | $\alpha_s=0.8(c_p\rho\lambda Nn_B)^{0.5}$ | （3-12） | — |
| 交叉桨+刮板（复动式） | $N_u=0.67Re^{0.5}Pr^{1/4}V_{is}^{0.14}$；或 $N_u=0.28(\varepsilon D^{4}/\nu^{3})^{0.25}Pr^{1/3}$ | （3-13）（3-14） | — |
| 框+刮板 | $N_u=15.31Re^{0.653}Pr^{0.294}(w/d)^{0.945}\sin^{0.384}\theta$ | （3-15） | $Re=10\sim80$ |
| 内外单螺带+刮板 | $N_u=34.8Re^{0.434}Pr^{0.294}(w/d)^{0.945}\sin^{0.764}\theta$ | （3-16） | $Re=10\sim80$ |

符号（`#L3326`）：$N_u$ 努塞尔数（OCR 作 $N_u$/Nu，按惯例为 Nu）；$Re$ 雷诺数；$Pr$ 普朗特数；$V_{is}=\mu/\mu_w$（本体黏度/壁温黏度）；$c_p$ 比定压热容 J/(kg·K)；$\lambda$ 热导率 W/(m·K)；$\rho$ 密度 kg/m³；$N$ 转速 1/s；$n_B$ 单层叶轮上的刮板数；$w$ 刮板宽度 m；$\nu$ 环隙轴向流速 m/s；$\theta$ 刮壁角；$\varepsilon$ 单位质量被搅液消耗的搅拌功率 W/kg；$D$、$d$ 设备内径与搅拌器直径 m。

注意：式（3-15）（3-16）的指数项 $(\sin\theta)^{0.384}$ 与 $(\sin\theta)^{0.764}$ 依 OCR 原样抄录，$\theta$ 取弧度还是角度书中未注明，代入前须核对原书；$N_u$ 与 $Nu$ 记法混用同此。

## 原书 §2.3.6：刮刀表面的不稳态传热模型

刮壁传热的物理图像是**周期性的边界层更新**，不是稳态对流：刮板每转一次把壁面液体刮走、露出新液体，热流率随时间衰减（`#L3414`）。

|  |  |  |
|:---|:---:|---|
| **符号式** | $Q_{x}=2\dfrac{k\Delta\theta}{\sqrt{\pi a}}\sqrt{T},\qquad Q=\dfrac{Q_{T}}{T}=\dfrac{2k\Delta\theta}{\sqrt{\pi a}}\cdot\dfrac{1}{\sqrt{T}}$ | （2.36）（2.37） |
| **文字式** | $\text{单位面积传热量}=2\times\dfrac{\text{热导率}\times\text{温差}}{\sqrt{\pi\times\text{热扩散系数}}}\sqrt{\text{更新周期}}$ |  |

更新周期 $T=1/(NZ)$（$N$ 转/秒、$Z$ 刮板数；原书 OCR 作 $T=1/60NZ$，与下一式的 $\sqrt{60NZ}$ 只有把 $N$ 取 r/min 才自洽——**原书此处量纲有笔误**）。代入得平均传热系数（`#L3426`、`#L3432`、`#L3440`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{s}=\dfrac{2k}{\sqrt{\pi a}}\sqrt{60NZ}=8.75\left(C_{p}\rho kNZ\right)^{1/2}$ | （2.39）（2.40） |
| **文字式** | $\text{刮壁侧膜系数}=8.75\times\left(\text{比热}\times\text{密度}\times\text{热导率}\times\text{转速}\times\text{刮板数}\right)^{1/2}$ |  |

**关键结论**（`#L3442`）：$h_{s}$ 只由 $C_{p}\rho k$ 决定，**与液体黏度无关**；且正比于"刮除频率 $(NZ)$ 的平方根"，**与刮板叶端速度无关**。这是刮壁式在极高黏度下仍然有效的理论根据。

黏度升高后刮下的液体混入主体的速度变慢、有效温差下降，Öhara 加经验修正（`#L3446`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{s}=87.5\left(C_{p}\rho kNZ\right)^{1/2}\left(\dfrac{\mu}{10}\right)^{-0.1}$ | （2.41） |
| **文字式** | 系数由 8.75 改为 87.5、再乘 $\left(\mu_{\text{【cP】}}/10\right)^{-0.1}$；$\mu>20000$ cP 时指数改 $-0.14$ |  |

单位换算坑：式(2.40) 的 8.75 与式(2.41) 的 87.5 差 10 倍，是同一条式子在两套单位（kcal/m²·h·℃ 与 W/m²·K）下的系数；手册表 3-4 的式（3-12）$\alpha_{s}=0.8(c_{p}\rho\lambda Nn_{B})^{0.5}$ 又是第三种写法——**三者代入前必须先统一单位并核对系数**（`#L3328`）。

## 用法与坑

1. 先按 [[刮板形状与固定方式]] 定型，再按桨型选式；
2. 式（3-17）~（3-22）全部是层流/低 $Re$ 段，超出适用区一律外推不可信；
3. 刮壁釜的 $N_p$ 已含刮板摩擦，不要再叠加刮板功率；
4. 传热与功率的耦合：刮板使 $\alpha$ 上升的同时增加摩擦功率，选型时两头都要算。

全套传热框架见 [[搅拌釜传热过程与总传热系数]]；黏釜物的危害量级见 [[高黏流体黏釜物与刮壁式传热]]。

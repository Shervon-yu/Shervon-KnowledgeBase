# 流量与流速

## 四个量（`#L1260-#L1292`）

| 量 | 定义 | 单位 |
|:---|:---|:---|
| 体积流量 $q_V$ | 单位时间流经任一截面的体积 | m³/s |
| 质量流量 $q_m$ | 单位时间流经任一截面的质量 | kg/s |
| 平均流速 $u$ | 体积流量除以截面积（工程上的"流速"） | m/s |
| 质量流速 $w$ | 单位时间流经单位截面的质量 | kg/(m²·s) |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_m=\rho q_V$ | （1-14） |
| **文字式** | $\text{质量流量}_{\text{【kg/s】}}=\text{密度}_{\text{【kg/m³】}}\times\text{体积流量}_{\text{【m³/s】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=\dfrac{q_V}{A}$ | （1-15） |
| **文字式** | $\text{流速}_{\text{【m/s】}}=\dfrac{\text{体积流量}_{\text{【m³/s】}}}{\text{截面积}_{\text{【m²】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_m=\rho q_V=\rho Au$ | （1-16） |
| **文字式** | $\text{质量流量}_{\text{【kg/s】}}=\text{密度}_{\text{【kg/m³】}}\times\text{截面积}_{\text{【m²】}}\times\text{流速}_{\text{【m/s】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $w=\dfrac{q_m}{A}=\rho u$ | （1-17） |
| **文字式** | $\text{质量流速}_{\text{【kg/(m²·s)】}}=\dfrac{\text{质量流量}_{\text{【kg/s】}}}{\text{截面积}_{\text{【m²】}}}=\text{密度}_{\text{【kg/m³】}}\times\text{流速}_{\text{【m/s】}}$ |  |

**为什么要有质量流速**：气体体积随温度压力变，体积流量与流速随之变，而质量流量不变——变工况下用 $w$ 方便（`#L1292`）。

## 管径估算（`#L1296-#L1306`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d=\sqrt{\dfrac{q_V}{0.785u}}$ | （1-18） |
| **文字式** | $\text{管内径}_{\text{【m】}}=\sqrt{\dfrac{\text{体积流量}_{\text{【m³/s】}}}{0.785\times\text{流速}_{\text{【m/s】}}}}$ |  |

**流速取值**：一般液体 0.5~3 m/s、气体 10~30 m/s；更细的常用流速范围见本章表1-3。流量由生产任务定，管径由流速定，而流速要经济权衡。

## 两个算例

- 例 1-6（`#L1308-#L1324`）：φ105 mm 钢管输 202.6 kPa、120 ℃ 空气，标况流量 630 m³/h → 操作态 $q_V=630\times(393/273.15)\times(101.325/202.6)=453$ m³/h；$u=453/3600/(0.785\times0.105^2)=14.5$ m/s；$\rho=1.8$ kg/m³；$w=26.1$ kg/(m²·s)。（原文按 φ105 代入，未扣壁厚。）
- 例 1-7（`#L1326-#L1338`）：输水 30 m³/h、取 $u=1.8$ m/s → $d=77$ mm，选 φ89×4（内径 81 mm），实际 $u=1.62$ m/s。

## 判断

- 例 1-6 与例 1-7 是同一套公式的两种用法：前者"已知管径求流速"，后者"已知流量选管径再回算流速"。
- 管径估算的关键不是公式而是流速取值：取值区间宽一倍，管径只差 √2 倍，但阻力差 4 倍（阻力 ∝ u²）。

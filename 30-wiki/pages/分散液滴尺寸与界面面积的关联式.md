# 分散液滴尺寸与界面面积的关联式

## 先要知道滴径怎么测

- **直接摄影**：分散相分率小时可行；分率大时会凝并，故要用两种"锁住液滴"的技巧——① 界面缩聚反应生成**聚合薄膜**把液滴隔离（Madden–McCoy：二氯癸二酰溶在有机相，再向连续相加十二烷基硫酸钠饱和的己二胺溶液）；② 向样品中混入**发泡/表面活性溶液**（十二烷基硫酸钠）稳定液滴（`#L8152`）。缺点是要预先往分散相里加化合物，会改变界面张力与凝并频率。
- **光透射间接法**：由透光率反算比表面积（Rodger、Vermeulen、Calderbank 等用过，`#L8156`）。

## 转速的影响：界面面积 ∝ n^1.9

甲苯-水体系（`#L8180`）：转速升高，滴径分布从**正态**（300 r/min）逐渐变成**对数分布**（675 r/min）；界面张力小时这种偏斜更明显（异戊醇-水 $\sigma=4.31$ dyn/cm 在低转速就有大量小滴；正己烷-水 $\sigma=51.1$ dyn/cm 即使高转速仍对称）。

界面张力大的体系，界面面积–转速关系（`#L8212`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{AD}{Uf_\phi}\propto n^{1.9}$ | （7.12） |
| **文字式** | $\dfrac{\text{界面面积}\times\text{容器直径}}{\text{分散相体积}\times\text{体积分率校正因子}}\propto\text{转速}^{1.9}$ |  |

$f_\phi$ 由体积分率 $\phi$ 查图7.4（$\phi$ 与 $\phi=0.01$ 时 $A/U$ 之比）。**偏离**：$\sigma$ 小、$\mu_d$ 大、$\mu_c$ 小时 $n$ 的影响变小，高转速区实测点掉到式(7.12) 下方（图7.5）——因为存在**极限滴径**（Taylor），再打不碎（`#L8221`）。

修正后（`#L8229`、`#L8231`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{AD}{U}f_\phi f\propto n^{1.90};\qquad \log(2-f)=10^{-3}(5.14-0.073\sigma)(0.447nD^{0.35}-5)\mu_c^{-0.4}$ | （7.13）（7.14） |
| **文字式** | 用校正因子 $f$（1 附近）压低高转速区的偏差，$f$ 由界面张力、转速、黏度决定 |  |

一般关联式（`#L8237`、`#L8247`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{AD}{Uf_\phi}=20.6\,f\left(\dfrac{d^3n^2\rho_e}{\sigma}\right)^{0.75}\left(\dfrac{dn^2}{g}\right)^{0.2}\left(\dfrac{\mu_c}{\mu_d}\right)^{0.13}$ | （7.15） |
| **文字式** | 无因次界面面积 $=20.6\times\text{校正因子}\times\text{韦伯数}^{0.75}\times\text{弗鲁德数}^{0.2}\times\text{黏度比}^{0.13}$ |  |

$\rho_e$ 是 Lamb 的乳化液有效平均密度（`#L8249`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\rho_e=0.6\rho_d+0.4\rho_c$ | （7.16） |
| **文字式** | 有效平均密度按分散相 0.6、连续相 0.4 加权 |  |

> OCR：式(7.16) 原书两处写成 $\rho_c=0.6\rho_d+0.4\rho_c$，左端应为 $\rho_e$（书后符号表亦定义为 $\rho_I$/"乳化液有效平均密度"）。

## Vermeulen 的比接触面积式

由 10 in 与 20 in 两个几何相似挡板釜（4 叶平桨、$d=(2/3)D$、$b=D/4$、$C=H/2$）导出（`#L8253`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a=\dfrac{6\phi}{d_{SM}}=72\dfrac{n^{1.2}d^{0.8}\rho_e^{0.6}\phi}{\sigma^{0.6}\bar f_\phi}$ | （7.17） |
| **文字式** | 比接触面积 $=72\times\dfrac{\text{转速}^{1.2}\times\text{桨径}^{0.8}\times\text{密度}^{0.6}\times\text{体积分率}}{\text{界面张力}^{0.6}\times\text{分率校正因子}}$ |  |

$\bar f_\phi$ 是任意 $\phi$ 与 $\phi=0.1$ 时的滴径之比，**随 $\phi$ 增大而增大**（图7.6，与 $f_\phi$ 基准不同、趋势相反）。稀分散相时简化为（`#L8265`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $aD\propto\left(\dfrac{D^3n^2\rho_c}{\sigma}\right)^{0.6}$ | （7.18） |
| **文字式** | 比界面面积 $\propto$ 韦伯数的 0.6 次方 |  |

Chen 等、以及"等功率"推论（`#L8271`、`#L8275`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{d_{SM}}{d}=0.053\left(\dfrac{d^3n^2\rho}{\sigma}\right)^{-0.6};\qquad a\propto(n^3D^2)^{0.4}$ | （7.18'）（7.19） |
| **文字式** | 滴径与韦伯数 −0.6 次方；比界面面积与单位体积功率 0.4 次方 —— **等 $P/V$ 即等分散** |  |

**注意**：$a\propto(n^3D^2)^{0.4}$ 正是"等 $P/V$ 放大"的依据，但只在**低分散相分率、凝并可忽略**时成立。

## 分率大时凝并接管

Rodger 等在**两相等体积**（$\phi=1/2$）下测得（`#L8281`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{d_{SM}}{d}=C\left(\dfrac{d^3n^2\rho}{\sigma}\right)^{-0.36}\left(\dfrac{d}{D}\right)^{-k}$ | （7.20） |
| **文字式** | 凝并控制时韦伯数指数从 −0.6 退到 −0.36，并额外依赖桨径比（$k=0.75\sim1.4$） |  |

Shinnar–Church 把它无量纲化为含凝并参数 $A(s)$ 的形式（`#L8291`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{d_{SM}}{d}=C'\left(\dfrac{d^3n^2\rho}{\sigma}\right)^{-0.375}\left(\dfrac{A(s)}{\sigma d}\right)^{0.375}$ | （7.21） |
| **文字式** | 与式(7.20) 一致；$A(s)$ 是两滴相距 $s$ 的粘附能 |  |

## 从湍流理论推：韦伯数恒定

Hinze 的判据：液滴破裂时最小韦伯数为常数（`#L8341`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $We=\dfrac{\rho_c\overline{u^2}d_{SM}}{\sigma g_c}=\text{常数}$ | （7.22） |
| **文字式** | $\text{韦伯数}=\dfrac{\text{连续相密度}\times\text{均方波动速度}\times\text{滴径}}{\text{界面张力}}$，破裂时恒为常数 |  |

湍流中 $\overline{u^2}=k_1\varepsilon^{2/3}d_{SM}^{2/3}$（7.23），$\varepsilon=Kn^3D^2=K'n^3d^2$（7.24、7.24'）。代入得 Sauter 平均直径（`#L8357`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{SM}=k_2\varepsilon^{-2/5}\left(\dfrac{\sigma g_c}{\rho_c}\right)^{3/5}$ | （7.25） |
| **文字式** | 平衡滴径由单位质量能耗的 −2/5 次方与 $(\sigma/\rho)^{3/5}$ 决定 |  |

以及（`#L8361`、`#L8365`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $We=\dfrac{\rho_cn^2d^{4/3}d_{SM}^{5/3}}{\sigma}=\text{常数}$ | （7.26）（7.26'） |
| **文字式** | 用桨径与转速改写后的韦伯数（$d_{SM}$ 为最大滴径时称 7.26'） |  |

实测常数（`#L8369`）：Van Heuven–Hoevenaar $We=11.0\times10^{-3}$；Sprow $7.4\times10^{-3}$；Chen 等 $7.5\times10^{-3}$。由(7.26') 与 (7.18) 得比界面面积（`#L8379`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a=\dfrac{b}{d_{SM}}\propto n^{6/5}$ | （7.27） |
| **文字式** | 比界面面积 $\propto$ 转速的 1.2 次方（$=P/V$ 的 0.4 次方） |  |

已用 1.56、14.4、71.5 l 三种容器核实（`#L8381`）。

## 最大滴径 vs 最小滴径：两套机理

**最大滴径**由破裂控制，两种机理（Sprow，`#L8383`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{p\max}=k_3\sigma^{3/5}\rho_c^{-3/5}n^{-6/5}d^{-4/5}$（惯性） | （7.28） |
| **文字式** | 惯性效应破裂：最大滴径随 $n^{-6/5}$、$\sigma^{3/5}$ |  |

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{p\max}=k_4\sigma\nu_c^{1/2}\mu_c^{-1}n^{-3/2}d^{-1}f(\mu_d/\mu_c)$（粘性剪切） | （7.29） |
| **文字式** | 粘滞剪切破裂：指数变成 $n^{-3/2}$，且依赖黏度比 |  |

判据是**与 Kolmogorov 尺度 $\eta$ 比较**（`#L8393`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\eta\equiv\left(\dfrac{\nu_c^{3}}{\varepsilon}\right)^{1/4}$ | （7.30） |
| **文字式** | 耗散尺度 $=(\text{运动黏度}^{3}/\text{单位质量能耗})^{1/4}$ |  |

$d>\eta$ 用(7.28)、$d<\eta$ 用(7.29)。**气泡比 $\eta$ 大，却也符合 (7.29)**（Vermeulen 数据，`#L8397`）——作者未解释，属经验事实。Sprow 的 MIBK-水（$\phi=0.25$）实测在叶轮端部符合(7.29)（图7.7 曲线1）。

**最小滴径**由凝并控制。设两滴间粘附能 $F$、分离它们的湍动力与之平衡（`#L8403`、`#L8411`）：$\rho_c\overline{u^2}d_{p\min}^2=F$（7.31），配 $\overline{u^2}=k_5\varepsilon^{2/3}d_{p\min}^{2/3}$（7.23'）得（`#L8419`、`#L8425`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{p\min}=k_6F^{3/8}\rho_c^{-3/8}\varepsilon^{-1/4};\qquad d_{p\min}=k_7F^{3/8}\rho_c^{-3/8}n^{-3/4}d^{-1/2}$ | （7.32）（7.33） |
| **文字式** | 最小滴径由粘附能的 $3/8$、能耗的 $-1/4$ 决定；挡板涡轮中换成 $n^{-3/4}d^{-1/2}$ |  |

粘滞剪切区内（`#L8429`、`#L8435`、`#L8437`）$\mu_c\overline{\nabla u}d_{p\min}^2=F$（7.34）、$\overline{\nabla u}=k_8\varepsilon^{1/2}\nu_c^{-1/2}$（7.35）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{p\min}=k_9F^{1/2}\nu_c^{1/4}\mu_c^{-1/2}n^{-3/4}d^{-1/2}$ | （7.36） |
| **文字式** | 粘滞区内最小滴径 $\propto F^{1/2}$，与转速的 $-3/4$ 次方 |  |

**两套斜率在实验上可见**（`#L8721`、`#L8723`）：叶轮端部 $d_{SM}\propto n^{-3/2}$（破裂控制，式7.29），容器底部 $d_{SM}\propto n^{-3/4}$（凝并控制，式7.33）。

## 特征尺度：涡旋有多大

`#L8445`、`#L8451`：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\lambda=\dfrac{1}{k_e}=0.08D$（含能涡）;\qquad $\eta=\dfrac{1}{k_d}=(\nu_c^3/\varepsilon)^{1/4}$（耗散涡） | （7.37）（7.38） |
| **文字式** | 含能涡尺度约 0.08 倍容器直径；耗散涡由黏度与能耗决定 |  |

Weinstein 等测得 $\lambda=6.1\sim10.2$ mm、$\eta=0.036\sim0.32$ mm 时 $d_{SM}=0.221\sim0.844$ mm——**滴径与"惯性子域到耗散域之间"的涡尺度相当**（`#L8453`）。作者怀疑其实测 $\lambda$、$\eta$ 偏大（示踪粒子跟不上快速波动）。

用 Heisenberg 谱在近耗散区积分得 $\overline{u^2}=k_{10}\nu_c^{-4}\varepsilon^{-2}d_{SM}^{6}$（7.39），代入 (7.22) 得（`#L8463`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{SM}=k_{11}\nu_c^{1/7}\varepsilon^{-2/7}\left(\dfrac{\sigma g_c}{\rho_c}\right)^{1/7}$ | （7.40） |
| **文字式** | 落在耗散区的滴径指数变成 $1/7$（而非 $3/5$） |  |

Weinstein–Treybal 用经验式 $\overline{u^2}=k_{12}\nu_c^ae^bd_{SM}^c$（7.41）覆盖两种极限，得通用形式（`#L8471`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{SM}=k_{13}\nu_c^{a'}\varepsilon^{b'}(\sigma g_c/\rho_c)^{c'}$ | （7.42） |
| **文字式** | 滴径由黏度、能耗、界面张力三者幂次组合 |  |

**液滴浓度（持液率）的影响**（`#L8473`）：$\phi<0.01$ 时滴与滴几乎不碰，$d_{SM}$ 反映叶轮处能耗；$\phi=0.08\sim0.60$ 时碰撞凝并频繁。修正函数取（`#L8475`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $f(\phi)=10^{\alpha+\beta\phi};\qquad d_{SM}=10^{\alpha+\beta\phi}\nu_c^a\varepsilon^b(\sigma g_c/\rho_c)^e$ | （7.43）（7.44） |
| **文字式** | 持液率的影响折成指数上的线性项 |  |

一组实测系数（`#L8485`）：$d_{SM}=10^{-2.316+0.672\phi}\nu_c^{0.0722}\varepsilon^{-0.194}(\sigma g_c/\rho_c)^{0.196}$（7.44'）。

## 分布：Erlang（γ）分布

Van Heuven 等发现实测面积分布符合 Erlang 分布（图7.8，`#L8491`、`#L8493`）：

$$\frac{F^{*}\Delta d_{SM}}{a}=\frac{m}{b(m-1)!}\left[\frac{md_{SM}}{b}\right]^{m-1}\exp\left[-\frac{md_{SM}}{b}\right]\Delta d_{SM}$$

（7.45）$F^*\Delta d_{SM}/a$ 是半径落在 $d_{SM}\pm\Delta d_{SM}/2$ 内的液滴所占总表面积的分数。两参数（`#L8497`、`#L8501`、`#L8503`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $b=\dfrac{\sigma}{a}=d_{SM};\qquad m=\dfrac{d^{*}}{d^{*}-a^{2}}$ | （7.46）（7.47） |
| **文字式** | 尺度参数取 Sauter 平均直径；形状参数 $m$ 由比直径与比面积决定 |  |

$d^{*}=36\sum n_id_i/\sum n_id_i^3$（7.48，比直径，m/m³）。**$m$ 大 = 分布窄**；实验显示低转速时 $m$ 较大（更均匀），高转速反而变宽（图7.9：1561 cm³、820 r/min 时 $m=11$；1320 r/min 时 $m=7$）。

Chen–Middleman 用正态分布关联；$m$ 大时两者无差别，但**分布的两端**仍以 Erlang 吻合更好（概率纸上呈曲线而非直线，`#L8517`）。

## 例7.2：同一体系两个公式差 4 倍

条件（`#L8295`）：10%（体积）甲苯分散于 25℃ 水，六叶标准涡轮 $d=D/2=15$ cm、$C=D/3$、300 r/min；$\sigma=36.1$ dyn/cm、$\rho_c=0.997$、$\rho_d=0.866$。

- **按 Vermeulen (7.17)**：$n=5$ r/s、$\phi=0.1$、$\bar f_\phi=1$ → $a=47.9$ cm²/cm³（`#L8309`）。
- **按 (7.14)+(7.15)**：$We=d^3n^2\rho_e/\sigma=2150$、$Fr=dn^2/g=0.383$、$f=0.903$ → $AD/(Uf_\phi)=5380$、$A/U=112$ → $a=A/V=11.3$ cm²/cm³（`#L8323`、`#L8333`）。

**两法差 4 倍**（`#L8335`）——原书直说"不一致"，没给裁决。工程用法：两式都算，取区间；要知道哪个更可信，必须用同一装置实测一次做锚点。

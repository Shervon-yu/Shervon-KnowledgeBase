# 相分率的测量

## 定义与约束

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\varepsilon_{p}+\varepsilon_{L}+\varepsilon_{G}=1$ | （3-43） |
| **文字式** | $\text{固相分率}+\text{液相分率}+\text{气相分率}=1$ |  |

（`#L3669`）

三相之和恒为 1，测其中两相即可推第三相。注意**进料体积比不等于釜内相分率**——各相停留时间不同（`#L3667`）。

## 固相分率

固相分率的测量方法有体积法、电容法、压力法、光学法和伽马射线法（`#L3671`），工程常用前三种（`#L3673-#L3689`）：

1. **体积法**：停搅拌沉降后量固相层高度，最简单但只适合可完全沉降体系；
2. **局部分离法**：从釜内定点取样、过滤干燥称重，得局部固含率；须多点平均；
3. **压力法**（最通用）：测釜内垂直压差，由混合密度反算固含率：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta P=H\rho_{m}g$ | （3-44） |
| **文字式** | $\text{压差}_{\text{【Pa】}}=\text{取压点高差}_{\text{【m】}}\times\text{混合密度}_{\text{【kg/m³】}}\times9.81$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho_{m}=\rho_{p}\varepsilon_{p}+\rho_{F}(1-\varepsilon_{p})$ | （3-45） |
| **文字式** | $\text{混合密度}_{\text{【kg/m³】}}=\text{颗粒密度}_{\text{【kg/m³】}}\times\text{固相分率}+\text{流体密度}_{\text{【kg/m³】}}\times\left(1-\text{固相分率}\right)$ |  |

由（3-44）得 $\rho_m$，代入（3-45）解出 $\varepsilon_p$。

## 气相分率

- **液位法**：通气前后液位差 / 静止液位，即平均气含率；简单，但忽略气泡膨胀与泡沫层；
- **压差法**：同固相压力法，两取压点间平均密度反算；
- **流动法**：测局部流速与空隙率；
- **光电法**：光纤探头测局部气含率与气泡频率。

Pan、Kehl、Rempel（2002）用**压力平衡室**测气含率，可减小取压管堵塞与动态误差（`#L3699`）。

## 液相分率

由（3-43）反算：$\varepsilon_L=1-\varepsilon_p-\varepsilon_G$。

## 坑

1. 取压点须避开桨叶排出流与死区，否则测得的是局部而非平均值；
2. 含固体系取压管易堵，压力平衡室是工程对策；
3. 气含率随通气量、功率、液高变化，同一釜不同 $H/D$ 不可外推。

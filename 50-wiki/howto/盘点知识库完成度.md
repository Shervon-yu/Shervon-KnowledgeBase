# 盘点知识库完成度

**一句话**：不看图谱点数，看四组硬指标——页面数、lint 八项、三书图链、阶段验收表（P0~P4）。

## 1 四条命令（一条都别省）

```powershell
cd D:\Shervon_KnowledgeBase
# 书目与未决项
powershell -NoProfile -ExecutionPolicy Bypass -File '90-tool\scripts\catalog.ps1'
# 索引页数与磁盘是否一致
powershell -NoProfile -ExecutionPolicy Bypass -File '90-tool\scripts\wiki-index.ps1'
# 八项体检
powershell -NoProfile -ExecutionPolicy Bypass -File '90-tool\scripts\wiki-lint.ps1'
# 图链（每本书一次）
powershell -NoProfile -ExecutionPolicy Bypass -File '90-tool\scripts\check-links.ps1' -Md '<20-md\<书>\<书>.md>'
```

2026-11-17 实测输出（对照基线）：

| 命令 | 输出 | 判据 |
|:---|:---|:---|
| catalog.ps1 | 书目已更新：3 本 · 笔记 0 篇 · 待确认 1 项 | 待确认项 = 缺字段的书，不是错误 |
| wiki-index.ps1 | index.md 已写：页面 20 个，55 行 | 页数 = 磁盘页数；>120 行才拆 domain 子索引 |
| wiki-lint.ps1 | lint 完成：页面 20，问题 0 条 | 八项全 0 才算闭环 |
| check-links.ps1 | 化工原理 refs=426 ok=426；机械密封 320/320；气液搅拌釜 137/137 | unresolved=0 |

## 2 页面密度（判断「内容够不够」的唯一硬口径）

| 口径 | 数值 |
|:---|:---|
| 现有一本书产出 | 机械密封 5 页、化工原理 5 页、气液搅拌釜 4 页 |
| 满编口径 | 20~25 页/本 → 3 本 60~75 页 |
| 当前 | 20 页 ≈ 满编 1/3 |
| 结论 | 页面数不到满编一半，就是「内容密度不够」，与 Obsidian 图谱无关 |

## 4 没做完的三件事（别混进「完成度」）

1. 机械密封只有 `#L行号`，无 PDF 页码锚点（三本书里只有气液搅拌釜有附录 A 页码对照）。
2. 82 张图仍叫 `page_*`，图名归一未做（见 [[图名归一遗留-无图题图]]）。
3. GitHub push 未成功（网络），本地 commit 已在。

## 5 判定口诀

- **页数看满编比、闭环看 lint 0、引用看 check-links 0、规模看 P4 触发条件**。
- 四项任一不达标，「完成度」就打折，不许用「已经能用了」代替。

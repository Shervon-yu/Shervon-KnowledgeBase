# 气泡尺寸与比界面积的关联式

## 气泡受两种力

剪应力 $\tau$ 与表面张力 $\sigma/d_p$ 相等时气泡尺寸达平衡（`#L9315`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{\tau d_p}{\sigma}=We$;\qquad $We=\dfrac{d_p^{2}\Delta\rho g}{6\sigma}$ | （8.15）（8.16） |
| **文字式** | 韦伯数 = 剪应力 × 泡径 / 表面张力；另一种写法用浮力与表面张力之比 |  |

## 用 Kolmogoroff 理论接上湍流

最小涡尺度（`#L9333`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\eta=\dfrac{\mu_c^{3/4}}{\rho_c^{1/2}}P_v^{-1/4}$ | （8.17） |
| **文字式** | Kolmogoroff 尺度 = 黏度^0.75 / 密度^0.5 × 单位体积功率^-0.25 |  |

在 $L\gg s\gg\eta$ 范围内均方脉动速度（`#L9341`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\overline{u^{2}}\propto P_v^{2/3}\left(\dfrac{s}{\rho_c}\right)^{2/3}$ | （8.18） |
| **文字式** | 脉动速度平方 ∝ 单位体积功率的 2/3 次方 × 尺度（密度折算）的 2/3 次方 |  |

由此得湍流剪应力（`#L9345`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\tau=C_1\rho_c\left(P_v\dfrac{d_p}{\rho_c}\right)^{2/3}$ | （8.19） |
| **文字式** | 剪应力 ∝ 连续相密度 × (单位体积功率 × 泡径 / 密度)^{2/3} |  |

把（8.19）代入（8.15）取 $We$=常数（`#L9351`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_p\propto\dfrac{\sigma^{0.5}}{P_v^{0.4}\rho_c^{0.2}}$ | （8.20） |
| **文字式** | 气泡直径 ∝ 表面张力^0.5 /（单位体积功率^0.4 × 密度^0.2） |  |

**这就是气体分散的核心标度关系**：功率翻一倍（$2^{0.4}=1.32$），泡径只降 24%。要高气液面积，靠功率很贵。

## 换成无因次

代 $N_p$ 与 $We_1=dn^{2}\rho_c/\sigma$（`#L9355`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{d_p}{d}\propto We_1^{-3/5}N_p^{-2/5}\left(\dfrac{d^{3}}{V}\right)^{-2/5}$ | （8.21） |
| **文字式** | 泡径/叶径 ∝ 韦伯数^-0.6 × 功率准数^-0.4 × 单位体积占比^-0.4 |  |

几何相似容器（$d^3/V$ 一定）、全挡板（$N_p$ 一定）时简化为（`#L9361`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{d_p}{d}\propto We_1^{-3/5}$ | （8.23） |
| **文字式** | 几何相似下泡径/叶径只取决于叶轮韦伯数 |  |

Vermeulen 的实测修正（含持气量影响，`#L9365`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{d_p}{d}\propto(2.5\phi+0.75)We_1^{-3/5}$ | （8.24） |
| **文字式** | 持气量越大泡径越大（气泡互相靠得近、更易凝并） |  |

## Calderbank 的索特平均直径式

六叶涡轮搅拌电解质溶液（`#L9371`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{SM}=2.25\left[\dfrac{\sigma^{0.6}}{P_v^{0.4}\rho_c^{0.2}}\right]\phi^{0.4}\left(\dfrac{\mu_d}{\mu_c}\right)^{0.25}$ | （8.25） |
| **文字式** | 索特平均直径 ∝ 表面张力^0.6/功率^0.4 × 持气量^0.4 × (分散相/连续相黏度)^0.25 |  |

$d_{SM}$ 的定义与 $a$ 的关系（`#L9377`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{SM}=\dfrac{\sum n_id_i^{3}}{\sum n_id_i^{2}}=\dfrac{6\phi}{a}$ | （8.26） |
| **文字式** | 索特平均直径 = 体积总和/面积总和；与比界面积互算 |  |

Hinze 对湍流中最大气泡直径的形式完全一致（`#L9383`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{\max}=K\dfrac{\sigma^{0.6}}{P_v^{0.4}\rho_c^{0.2}}$ | （8.27） |
| **文字式** | 最大稳定泡径同一标度（与液液系统的式7.25 同构，只是 $\sigma/\rho$ 幂次配比不同） |  |

**电解质或醇类溶液中气泡更小**，因为这些添加剂妨碍气泡凝并（`#L9385`）——这就是"纯水通气气泡大、盐水通气气泡细"的原因。

## 直接关联比界面积

Vermeulen 用光透射数据重整理（`#L9387`、`#L9391`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{d_p\,dn^{1.5}\rho_c^{0.5}\mu_d^{0.75}}{\sigma\bar f_\phi\mu_c^{0.25}}=4.3\times10^{-3}$ | （8.28） |
| **文字式** | 含 $n^{1.5}$ 的经验无因次群等于常数；$\bar f_\phi$ 为持气量校正系数（同式7.17） |  |

变换成 $a=6\phi/d_{SM}$ 的形式（`#L9391`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a=\dfrac{1400\,n^{1.5}d\rho_c^{0.5}\mu_d^{0.75}\phi}{\sigma\mu_c^{0.25}\bar f_\phi}$ | （8.29） |
| **文字式** | 比界面积 ∝ $n^{1.5}$×叶径×持气量；黏度项为分散相 0.75 次、连续相 −0.25 次 |  |

**注意 $a\propto n^{1.5}$**：与液液系统的 $a\propto n^{1.2}$（式7.17）和 $n^{6/5}$（式7.27）同量级但不同，气液对转速更敏感。

无因次形式（`#L9395`，原文该式排版残缺，只保留结构）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $aD\sigma\left(\dfrac{D^{3}n^{2}\rho_c}{\sigma}\right)^{?}\left(\dfrac{D^{2}n\rho_c}{\mu_c}\right)^{-0.5}\left(\dfrac{\mu_d}{\mu_c}\right)^{0.75}$ | （8.30） |
| **文字式** | 比界面积的无因次群：雷诺数项 −0.5 次、黏度比 0.75 次（原文残缺，引用需回查原书） |  |

### Calderbank 的工程式（最常用）

$d=D/3$ 六叶涡轮，容器 50.8 cm 与 18.4 cm（`#L9399`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $a=1.44\left(\dfrac{P_v^{0.4}\rho_c^{0.2}}{\sigma^{0.6}}\right)\left(\dfrac{v_s}{v_t}\right)^{0.5}$ | （8.31） |
| **文字式** | 比界面积 = 1.44 × 功率-表面张力群 × (表观气速/终端气速)^0.5 |  |

**适用上限**（`#L9405`）：

$$\left(\frac{d^{2}n\rho_c}{\mu_c}\right)^{0.7}\left(\frac{dn}{v_s}\right)^{0.3}<20000$$

超过 20000 时，液面开始吸气，界面面积按（8.32）估算（`#L9413`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\log\dfrac{2.3a'}{a}=1.95\times10^{-5}\left(\dfrac{d^{2}n\rho_c}{\mu_c}\right)^{0.7}\left(\dfrac{dn}{v_s}\right)^{0.3}$ | （8.32） |
| **文字式** | 吸气后面积的对数增量 ∝ 上述判据；$a'$ 为吸气工况的界面面积 |  |

## Reith–Beek：一个参数就够

18.45 与 120 cm 两套几何相似釜，同一表观气速 $v_s=4.7$ cm/s（`#L9419`）：以 **$n^{3}d^{2}$**（即单位体积功率的量纲）作单一参数，纵轴取 $a/(1-\phi)$，得到合理关联（`#L9419`）。

**偏离出现在低转速端**（`#L9429`）：$\pi nd<2.25$ m/s 时三个釜的曲线明显分离，容器越大 $a/(1-\phi)$ 越低——**低转速不能按功率放大**，因为大容器需要更高的叶端速度才能把气泡打散。

## Van Dierendonck：Eötvös 数式

`#L9433`，适用 $0<(n-n_0)d<1.5$ m/s：

|  |  |  |
|:---|:---:|---|
| **符号式** | $E\ddot{o}=\dfrac{d_{SM}^{2}\rho g}{\sigma}=\left[1.2+260\dfrac{\mu(n-n_{0})d}{\sigma}\right]^{-2}$ | （8.33） |
| **文字式** | Eötvös 数 = (1.2 + 260×黏性剪切项)^{-2}；用**超过临界转速的超额转速** $n-n_0$ 而不是转速本身 |  |

纯液体、$n>2n_0$ 时（`#L9439`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $E\ddot{o}=\dfrac{d_{SM}^{2}\rho g}{\sigma}=0.45$ | （8.34） |
| **文字式** | 超过两倍临界转速后泡径与转速无关，Eötvös 数固定 |  |

**这是最实用的判据**：两倍临界转速以上，继续加转速不再减小泡径，只能靠增加持气量提面积——与 §8.1"死泡"的结论一致。

## §8.4 气泡凝并

釜内气泡尺寸随位置变化，凝并是一个原因，但**理论分析困难**（`#L9506`、`#L9508`）。Calderbank–Moo-Young 用直径 4 in、高 10 ft 的水塔测了 ${CO}_2$ 上升气泡的凝并速度并给出理论分析（`#L9510`）。

工程上可行的替代：用"添加剂抑制凝并"的思路控制泡径——电解质、醇类都有效（见式8.25 讨论）。

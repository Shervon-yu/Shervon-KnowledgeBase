# 吸收操作的应用与分类

## 定义与术语（`#L8614-#L8616`）

吸收（absorption）：气体混合物与适当液体接触，其中**一个或几个组分溶解于液体**，不溶组分留在气相，从而分离气体混合物——依据是各组分在液体中的**溶解度差异**。

| 术语 | 含义 |
|:--|:--|
| 吸收剂（溶剂） | 用于吸收的液体 |
| 溶质（吸收质） | 混合气中被溶解的组分 |
| 惰性气体（载体） | 不被溶解的组分 |
| 吸收液 | 溶剂 + 溶质 |
| 吸收尾气 | 塔顶排出气，主要为惰性气体与残留溶质 |

## 四类应用（`#L8620-#L8630`）

1. **制取液体产品**：水吸收 NO₂ 制硝酸；硫酸吸收 SO₃ 制发烟硫酸；
2. **回收有用组分**：液态烃吸收裂解气中的乙烯、丙烯；硫酸吸收焦炉气中的氨；
3. **净化工艺气体**：水或乙醇胺脱除合成氨原料气中的 CO₂；
4. **脱除尾气有害组分**：脱 H₂S、SO₂，防止污染。

## 设备（`#L8632-#L8646`）

- 填料塔：塔内装瓷环等填料，气液在填料表面接触；
- 板式塔：筛孔塔板上气液鼓泡接触；
- 流程一律**逆流**：气体自下而上、吸收剂自上而下，吸收液从塔底、尾气从塔顶引出；
- 本章只讲填料塔计算，板式塔在蒸馏章讲。

## 三类分类（`#L8648-#L8666`）

### ① 物理吸收 vs 化学吸收（关键差别在平衡分压）

- 物理吸收：溶质只靠物理溶解，无化学反应；液相上方溶质分压较大，吸收**只能进行到气相分压略高于平衡分压**为止；
- 化学吸收：溶质与吸收剂反应。
  - 不可逆反应：溶液上方溶质平衡分压极小 → 可**充分吸收**；
  - 可逆反应：仍有明显平衡分压，但比物理吸收小得多；
- 工业上**化学吸收比物理吸收用得多**（净化度要求高时尤其如此）。

### ② 单组分 vs 多组分吸收

混合气中只有一个组分被吸收 → 单组分；两个及以上 → 多组分。

### ③ 等温 vs 非等温吸收

溶解热（化学吸收还有反应热）使温度升高：温度变化明显 → 非等温；溶质含量低、吸收剂用量大、温度变化不大 → 按等温处理。

## 本章范围（`#L8666`）

**单组分、等温、物理吸收**：气液相平衡 → 传质速率方程 → 物料衡算与吸收剂用量 → 填料层高度与塔径 → 填料塔结构。

## 判断

- 判断一个吸收过程"能不能吸收干净"，先看化学还是物理：物理吸收受平衡分压封顶，尾气浓度不可能低于与入口吸收液平衡的气相分压；要深度净化必须用化学吸收（不可逆反应）或加大液气比、降低温度。
- 分类不是并列的标签，而是**选择计算方法的前提**：多组分要联立各组分的平衡与速率；非等温要联立热量衡算；本课程只解单组分等温，遇到别的先判断能否近似。

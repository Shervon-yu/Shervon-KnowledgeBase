# 搅拌容器中的湍动与能耗分布

## 层流域：能耗全堆在叶轮周围

层流的能耗可由耗散函数严格写出（`#L3935`、`#L3937`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\varepsilon\rho=P_{v}g_{c}=\mu\left\{2\left(\dfrac{\partial v_{x}}{\partial x}\right)^{2}+\cdots+\left(\dfrac{\partial v_{y}}{\partial x}+\dfrac{\partial v_{x}}{\partial y}\right)^{2}\right\}=\mu\phi$ | （3.7） |
| **文字式** | $\text{单位体积能耗率}=\text{黏度}\times\text{耗散函数}$（应变率张量的二次型） |  |

代表应变速度取 $\sqrt{\varepsilon/\nu}=\sqrt{P_v g_c/\mu}$（3.8），配合 $P\propto\mu n^2 d^3$ 推出（`#L3967`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $n=C_{3}\sqrt{\dfrac{P_{v}g_{c}}{\mu}}$ | （3.11） |
| **文字式** | $\text{转速}=常数\times\sqrt{\dfrac{\text{单位体积功率}}{\text{黏度}}}$ |  |

**这解释了为什么平均剪切率 ∝ 叶轮速度**（与式1.79 一致）——剪切率直接由"功率/黏度"决定。

图3.12（$Re=14$，小米糊）显示剪应变 $\dot\gamma$ 与 $P_v$ 在叶轮附近都大，故高黏液体**必须用伸展到整个容器的叶片**（螺带、锚式），桨式/涡轮式在叶轮周围剪得狠、远处几乎不动（`#L3953`、`#L3957`）；拟塑性液体因叶轮周围 $\dot\gamma$ 大、$\mu_a$ 小，不均匀性更甚。

## 湍动强度：40~50%

有挡板、$Re\sim10^{4}$ 量级时（`#L4301`、`#L4450`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{\sqrt{\overline{u^{2}}}}{\overline{U}}\approx0.4\sim0.5$（有挡板）；无挡板 $0.25\to0.10$ |  |
| **文字式** | 湍动强度 = R.M.S. 波动速度 / 时间平均速度 |  |

要点：

- R.M.S. 速度与叶轮速度**成正比**（图3.21），且是全频段成立的；若滤掉低频，高转速下的高频分量下降得更快（图3.22），**放大时大小涡的分布会变**（`#L4321`）。
- 环流中心（涡旋眼）处 $\overline{U}$ 与 R.M.S. 都极小，是**停滞区**（`#L4284`）。
- 叶轮高度处 $\sqrt{\bar{u}_r^2}=2\sqrt{\bar{u}_n^2}$，输出流是**强非各向同性**；离开叶轮后两者趋于相等（`#L4299`）。
- 挡板前后：紧贴挡板前的壁面湍动被抑制，轴与壁之间最大；挡板**背后**湍动区更宽且更靠近轴（`#L4286`、`#L4288`）。

## 雷诺应力只发生在两处

实测雷诺应力峰在 $R_1$（叶轮高度处器壁附近，输出流撞壁后转向）与 $R_2$（挡板背后，沿挡板液流与输出流相撞处）；叶轮之外急降（`#L4325`、`#L4335`）。

**结论**：只有环绕叶轮约 **10%** 的区域处于非各向同性湍动、是湍动的"产地"，其余 90% 近似各向同性。这解释了为什么"局部"加挡板/加导流筒能改全局，也解释了为什么按平均能耗率算的 $\eta$ 只能当量级估计。

## 能耗的空间分布

$\varepsilon$ 最大点 $M$ 位于**叶轮高度的挡板前面、叶轮顶端与器壁的中央**，恰好对应雷诺应力两峰之间的谷值；$D_1$、$D_2$ 还有两个峰，但只有 $M$ 的 $1/2\sim1/3$（`#L4386`、`#L4390`）。

- $\varepsilon$ 沿高度方向变化比径向显著（`#L4400`）。
- 转速超过约 300 r/min 后 $\varepsilon$ 趋于极值：被吸入叶轮的液体本身带强湍动，回流的湍动能占比变大（`#L4402`、`#L4404`）。
- 耗散尺度 $\lambda$ 与转速**无关**、与位置关系极大，分布形状与时间平均速度相同，环流中心处有极小值（`#L4369`、`#L4384`）。
- 最小涡 $\eta$ 的分布与 $\varepsilon$ 相反（峰谷互换）；转速超 300 r/min 后 $\eta$ 偏离斜率 $-4/3$ 的直线，因为高频分量再增加、能耗随之增加，$\eta$ 不再变小（`#L4434`）。

## 无挡板的情形

叶轮高度处湍动比有挡板小，但**离开叶轮高度后反而更大**；横向 R.M.S. 只有纵向的 1/3~1/4，全釜非各向同性；能耗低，故最小涡略大于有挡板（`#L4448`、`#L4450`、`#L4464`）。

## 湍动扩散：传热传质靠大涡

对热量/质量输送起作用的是**低频大涡**（初级涡旋），它们含大量动能、受容器几何支配（`#L4470`）。实测湍动扩散系数 $D_{\text{湍}}$、湍动黏度 $\nu_{\text{湍}}$ 都在叶轮周围最大、离开叶轮迅速下降（`#L4472`、`#L4474`）。

**这条是放大与选型的核心**：化学反应、溶解、传热的速率由 $D_{\text{湍}}$ 与局部 $\varepsilon$ 决定，而这两者都高度集中于叶轮区——用全釜平均值会高估远离叶轮处的传递能力。

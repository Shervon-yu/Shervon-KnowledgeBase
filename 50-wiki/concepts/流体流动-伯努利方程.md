# 流体流动-伯努利方程

## 定义

对不可压缩、非黏性（理想）流体，在稳态流动、管截面速度分布均匀、压力与密度取截面平均值的条件下，沿流线有：位能、静压能、动能三项的「单位质量」能量之和为常数——这就是伯努利方程式（式 1-28）。§1.2 四 #L1524 #L1574

三项均为单位质量流体的机械能，单位 J/kg：gz 为位能，p/ρ 为静压能，u²/2 为动能；三者之和称总机械能。式 (1-28) 实质是单位质量流体的能量守恒方程式：三种机械能可相互转换，总和不变。§1.2 四 #L1598

## 计算式

|:---|:---:|---:|

| **文字式** | $\text{位能}_{gz}+\dfrac{\text{静压}_{p}}{\text{密度}_{\rho}}+\dfrac{\text{流速}_{u}^{2}}{2}=\text{常数}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $z_{1}g+\dfrac{p_{1}}{\rho}+\dfrac{u_{1}^{2}}{2}+W=z_{2}g+\dfrac{p_{2}}{\rho}+\dfrac{u_{2}^{2}}{2}+\sum h_{\mathrm{f}}$ | （1-2） |
| **文字式** | $\text{截面1高度}_{z_{1}}\times\text{重力加速度}_{g}+\dfrac{\text{截面1压力}_{p_{1}}}{\text{密度}_{\rho}}+\dfrac{\text{截面1流速}_{u_{1}}^{2}}{2}+\text{外加机械能}_{W}=\text{截面2高度}_{z_{2}}\times\text{重力加速度}_{g}+\dfrac{\text{截面2压力}_{p_{2}}}{\text{密度}_{\rho}}+\dfrac{\text{截面2流速}_{u_{2}}^{2}}{2}+\text{总机械能损失}_{\sum h_{\mathrm{f}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $z_{1}+\dfrac{p_{1}}{\rho g}+\dfrac{u_{1}^{2}}{2g}+H=z_{2}+\dfrac{p_{2}}{\rho g}+\dfrac{u_{2}^{2}}{2g}+\sum H_{\mathrm{f}}$ | （1-3） |
| **文字式** | $\text{截面1位压头}_{z_{1}}+\dfrac{\text{截面1静压头}_{p_{1}}}{\text{密度}_{\rho}\times\text{重力加速度}_{g}}+\dfrac{\text{截面1动压头}_{u_{1}^{2}}}{\text{2}\times\text{重力加速度}_{g}}+\text{外加压头}_{H}=\text{截面2位压头}_{z_{2}}+\dfrac{\text{截面2静压头}_{p_{2}}}{\text{密度}_{\rho}\times\text{重力加速度}_{g}}+\dfrac{\text{截面2动压头}_{u_{2}^{2}}}{\text{2}\times\text{重力加速度}_{g}}+\text{压头损失}_{\sum H_{\mathrm{f}}}$ |  |

### 三条式的来路与差别

- 式（1-1）= 原书式 (1-28)，由微管段动量衡算 d(p/ρ+u²/2+gz)=0 积分得，仅适用于不可压缩非黏性流体（理想流体）。#L1565 #L1571
- 式（1-2）= 原书式 (1-32)，实际流体机械能衡算式（单位质量，J/kg）：加入压头损失 Σh_f 与外加机械能 W。#L1649 #L1652
- 式（1-3）= 原书式 (1-31)，同一衡算除以 g 得「压头」形式（m 液柱）：ΣH_f=Σh_f/g，H=W/g。#L1629 #L1636-#L1652 原书称式 (1-31)(1-32)「习惯上也称之为伯努利方程式」。#L1654
- 气体的适用性：若两截面压差 p₁−p₂ ≤ 0.2p₁，密度变化小，可按不可压缩处理，ρ 取两截面平均值；压差大时须按等温/绝热过程的热力学方法处理。#L1576 #L1578

## 判据 / 用法

1. **取截面**：选两截面（常取液面、管口），两截面间流体须连续、稳态；基准面取其中一截面最方便（例 1-9 取贮槽液面为基准面）。#L1662
2. **单位制一致**：三式分别以 J/kg（式 1-1、1-2）与 m 液柱（式 1-3）为单位，不可混用；ΣH_f 与 Σh_f 差一个 g。#L1652
3. **阻力项**：直管摩擦 + 局部阻力（局部阻力系数法 ζ、当量长度法 l_e），见 §1.4 五 #L2533 #L2599。
4. **泵的扬程**：外加压头 H（或 W=gH）即泵提供的机械能，例 1-9 由 W=(z₂−z₁)g+(p₂−p₁)/ρ+(u₂²−u₁²)/2+Σh_f 求。#L1675
5. **连续性方程配套**：变径管先用 u₁A₁=u₂A₂ 求另一截面流速，再列伯努利式。#L1678

## 典型数据（例 1-9）

泵送稀碱液：进口管 φ89×3.5 mm、u=1.5 m/s；出口管 φ76×3 mm；贮槽液面至蒸发器入口垂直距离 7 m。由连续性方程求出口流速，再由式 (a) 求 W。#L1660 #L1662 #L1678

## 开放问题

- 本书伯努利式未讨论可压缩气体的大压差解法（原文明确「不再作进一步讨论」）#L1578，工程上需另查可压缩流公式。
- 未纳入非稳态流动与非牛顿流体的推广形式（§1.2 二 仅给稳态/非稳态定义 #L1428）。

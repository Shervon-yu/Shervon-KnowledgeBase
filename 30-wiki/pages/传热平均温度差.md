# 传热平均温度差

## 三类传热（`#L6710-#L6758`）

- **恒温传热**：两侧均相变且温度恒定（饱和蒸气冷凝 / 液体沸腾），$\Delta t_m=T-t$；
- **一侧变温**：一侧相变恒温、另一侧升温或降温；
- **两侧变温**：逆流（流向相反）、并流（流向相同）；另有错流（垂直交叉）与折流（一侧反复换向）。

## 对数平均温度差（`#L6760-#L6812`）

假设：$q_{m1}$、$q_{m2}$ 恒定，$c_{p1}$、$c_{p2}$、$K$ 沿传热面不变，忽略热损失。取微元 $\mathrm{d}A$，热流体降 $\mathrm{d}T$、冷流体升 $\mathrm{d}t$：

$$\mathrm{d}Q=q_{m1}c_{p1}\mathrm{d}T=q_{m2}c_{p2}\mathrm{d}t$$

由此 $Q$–$T$、$Q$–$t$ 均为直线，故 $Q$–$\Delta t$ 也是直线，$\mathrm{d}\Delta t/\mathrm{d}Q=(\Delta t_1-\Delta t_2)/Q$；又 $\mathrm{d}Q=K\Delta t\,\mathrm{d}A$，积分得：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\Delta t_m=\dfrac{\Delta t_1-\Delta t_2}{\ln\dfrac{\Delta t_1}{\Delta t_2}}$ | （4-40） |
| **文字式** | $\text{对数平均温度差}=\dfrac{\text{两端温差之差}}{\ln\dfrac{\text{较大端温差}}{\text{较小端温差}}}$ |  |

- 逆流、并流、一侧变温均适用；
- 习惯取较大者为 $\Delta t_1$、较小者为 $\Delta t_2$，保证分子分母为正；
- $\Delta t_1/\Delta t_2<2$ 时可用算术平均代替，误差不超过 4%。

## 例4-12（`#L6814-#L6870`）

原油 100→150 ℃，加热剂 250→180 ℃。

- 并流：$\Delta t_1=150$、$\Delta t_2=30$ → $\Delta t_{m并}=74.6$ ℃；
- 逆流：$\Delta t_1=100$、$\Delta t_2=80$（比值 1.25<2，取算术平均）→ $\Delta t_{m逆}=90$ ℃；
- $Q=5\times10^4$ W、$K=100$ → $A_并=6.7$ m²、$A_逆=5.56$ m²。

若要求加热剂出口降至 150 ℃：并流时 $\Delta t_2=150-150=0$ → $\Delta t_m=0$、$A=\infty$（并流不可能实现）；逆流 $\Delta t_m=72$ ℃、$A_逆=6.94$ m²，加热剂用量降为 0.7 倍（省 30%），面积增 24.8%。

**两条结论**：
1. 同样进出口温度下 $\Delta t_{m逆}>\Delta t_{m并}$，故 $A_逆<A_并$；
2. 并流时热流体出口 $T_2$ 必大于冷流体出口 $t_2$（极限 $T_2=t_2$ 时 $\Delta t_m=0$、$A=\infty$）；逆流时 $T_2$ 可低于 $t_2$，故加热剂/冷却剂用量更省。

工程上多用逆流；但需要"出口温度不超限"时用并流。

## 折流与错流（`#L6872-#L6918`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\Delta t_m=\psi\,\Delta t_{m逆}$ | （4-41） |
| **文字式** | $\text{实际平均温度差}=\text{温差校正系数}\times\text{逆流对数平均温度差}$ |  |

$\psi=f(R,P)$，其中

$$R=\dfrac{T_1-T_2}{t_2-t_1}=\dfrac{\text{热流体温降}}{\text{冷流体温升}},\qquad P=\dfrac{t_2-t_1}{T_1-t_1}=\dfrac{\text{冷流体温升}}{\text{两流体最初温差}}$$

$\psi<1$，故折流/错流的 $\Delta t_m$ 总小于逆流。要求 $\psi>0.9$；$\psi\le0.8$ 时应增加壳程数，至少不小于 0.8。

**例4-13**：$T_1=120$、$T_2=75$、$t_1=20$、$t_2=50$ → $\Delta t_{m逆}=62.2$ ℃，$R=1.5$、$P=0.3$，查图 $\psi=0.935$ → $\Delta t_m=58.2$ ℃。

## 判断

- 对数平均的根源是"温差沿程按指数衰减"，而算术平均只在两端温差接近（比值<2）时才够用；这与圆筒壁对数平均面积是同一数学结构。
- 逆流省加热剂的本质是"逆流能把热流体出口压到冷流体出口以下"，即多榨出一段可用温位；代价是同样换热量下面积略增，工程上是否划算要看加热剂价格与面积造价的比较。

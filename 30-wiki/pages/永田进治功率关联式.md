# 永田进治功率关联式

## 无挡板时的功率准数

二叶平桨、二叶斜桨可查图2-5，也可用永田进治的解析式（`#L1516-#L1520`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}=\dfrac{A}{Re}+B\left(\dfrac{10^{3}+1.2Re^{0.66}}{10^{3}+3.2Re^{0.66}}\right)^{p}\left(\dfrac{H}{D}\right)^{0.35+\frac{b}{D}}\left(\sin\theta\right)^{1.2}$ | （2-26） |
| **文字式** | $\text{功率准数}=\dfrac{A}{\text{雷诺数}}+\text{系数}B\times\left(\dfrac{1000+1.2\times\text{雷诺数}^{0.66}}{1000+3.2\times\text{雷诺数}^{0.66}}\right)^{指数p}\times\left(\dfrac{\text{液面高}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}\right)^{0.35+\frac{\text{桨宽}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}}\times\left(\sin\text{桨叶倾角}_{\text{【°】}}\right)^{1.2}$ |  |

式中（`#L1520`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=14+\left(\dfrac{b}{D}\right)\left[670\left(\dfrac{d}{D}-0.6\right)^{2}+185\right]$ | （2-26 参数 A） |
| **文字式** | $\text{系数}A=14+\dfrac{\text{桨宽}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}\times\left[670\left(\dfrac{\text{叶轮直径}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}-0.6\right)^{2}+185\right]$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $B=10^{\left[1.3-4\left(\frac{b}{D}-0.5\right)^{2}-1.14\frac{d}{D}\right]}$ | （2-26 参数 B） |
| **文字式** | $\text{系数}B=10^{\left[1.3-4\left(\frac{\text{桨宽}}{\text{釜内径}}-0.5\right)^{2}-1.14\frac{\text{叶轮直径}}{\text{釜内径}}\right]}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p=1.1+4\left(\dfrac{b}{D}\right)-2.5\left(\dfrac{d}{D}-0.5\right)^{2}-7\left(\dfrac{b}{D}\right)^{4}$ | （2-26 参数 p） |
| **文字式** | $\text{指数}p=1.1+4\dfrac{\text{桨宽}}{\text{釜内径}}-2.5\left(\dfrac{\text{叶轮直径}}{\text{釜内径}}-0.5\right)^{2}-7\left(\dfrac{\text{桨宽}}{\text{釜内径}}\right)^{4}$ |  |

$b/D\le0.3$ 时 $p$ 中四次方项可忽略（`#L1522`）。

## 推导链：为什么只三个参数

永田式的骨架不是拟合出来的，而是从双叶桨的微元阻力积分推出来的（`#L1001`、`#L1069`）：

1. 叶面上微元所受阻力按平板阻力写，相对速度取桨叶与液体之差：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mathrm{d}F=K\rho u_{r}^{2}b\,\mathrm{d}l,\qquad u_{r}=cn\left(l_{c}-l\right)$ | （1.30）（1.31） |
| **文字式** | $\text{微元阻力}_{\text{【N】}}=\text{阻力系数}\times\text{密度}_{\text{【kg/m³】}}\times\text{相对速度}_{\text{【m/s】}}^{2}\times\text{桨宽}_{\text{【m】}}\times\text{微元长度}_{\text{【m】}},\qquad \text{相对速度}_{\text{【m/s】}}=\text{常数}\times\text{转速}_{\text{【1/s】}}\times\left(\text{有效半径}_{\text{【m】}}-\text{半径}_{\text{【m】}}\right)$ |  |

2. 微元功率 $\mathrm{d}P=4\pi n r\,\mathrm{d}F$（1.32），在 $l=0\sim l_{c}$ 上积分得解析式（`#L1029`、`#L1037`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=\dfrac{1}{3}\pi bc^{2}K\rho n^{3}l_{c}^{3}\left(4r_{1}-l_{c}\right)$ | （1.34） |
| **文字式** | $\text{功率}_{\text{【W】}}=\dfrac{1}{3}\pi\times\text{桨宽}_{\text{【m】}}\times\text{常数}^{2}\times\text{阻力系数}\times\text{密度}_{\text{【kg/m³】}}\times\text{转速}_{\text{【1/s】}}^{3}\times\text{有效半径}_{\text{【m】}}^{3}\times\left(4\times\text{叶轮半径}_{\text{【m】}}-\text{有效半径}_{\text{【m】}}\right)$ |  |

3. 有效半径由 CRZ 半径截断：$l_{c}=r_{1}-r_{c}$，代 $r_{c}/r_{1}=Re/(1000+1.6Re)$ 得（`#L1041`、`#L1045`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $l_{c}=\left(\dfrac{10^{3}+0.6Re}{10^{3}+1.6Re}\right)\dfrac{d}{2},\qquad N_{\mathrm{p}}\propto\left(\dfrac{10^{3}+0.6Re}{10^{3}+1.6Re}\right)^{3}$ | （1.37）（1.38） |
| **文字式** | $\text{有效半径}_{\text{【m】}}=\left(\dfrac{1000+0.6\times\text{雷诺数}}{1000+1.6\times\text{雷诺数}}\right)\dfrac{\text{叶轮直径}_{\text{【m】}}}{2},\qquad \text{功率准数}\propto\left(\dfrac{1000+0.6\times\text{雷诺数}}{1000+1.6\times\text{雷诺数}}\right)^{3}$ |  |

4. 式(1.38) 是近似式（假设 C.R.Z. 与桨同角速度、$K$ 与 $c$ 为常数），故加经验常数 $f$、$\alpha$、$p$ 得式(1.39)，补上层流项 A/Re 得通式(1.41)（`#L1059`、`#L1063`、`#L1071`）。
5. 直接置 $f=1$、$\alpha=1$ 的式(1.48) 在过渡区与实测不符；取同 $N_{\mathrm{p}}$ 下实测 $Re$ 与计算 $Re'$ 作双对数图得直线 $Re'=2Re^{0.66}$（1.49），代回即终式(1.50)（`#L1162`、`#L1179`、`#L1183`）。
6. 再乘液面高与倾角两个几何修正得式(1.53)（`#L1263`、`#L1265`）。

一句话：**$Re$ 管流态、$d/D$ 管桨的绝对尺寸、$b/D$ 管桨的推水面积**，其余几何量（$H/D$、$\theta$）都作为乘性修正挂在外面；多层、多叶则按 $b\,n_{p}$ 折算（`#L1271`）。

## 三个参数怎么随几何变

- $A$（层流项）：$b/D$ 线性、$(d/D-0.6)^{2}$ 平方放大，故 $b/D$ 大、$d/D$ 远离 0.6 时层流功率高（`#L1107`、表1.4 `#L1143`）。
- $B$（湍流渐近段系数）：$b/D=0.5$ 附近最大，偏离按 $10^{-4(b/D-0.5)^{2}}$ 衰减；$d/D$ 增大使 $B$ 略降（`#L1113`）。
- $p$（过渡段陡度）：$b/D$ 增大使 $p$ 增大、曲线变陡；$d/D$ 偏离 0.5 使 $p$ 减小（`#L1139`）。
- 三个参数并不独立：$N_{\mathrm{p}\infty}=B(0.6/1.6)^{p}$ 反解出 $p=2.35\log\left(B/N_{\mathrm{p}\infty}\right)$（1.46），故由 $A$、$B$、$N_{\mathrm{p}\infty}$ 即可定 $p$（`#L1135`）。
- 表1.4 的 $A$ 实测矩阵（选摘，`#L1143`）：

| $b/D$ \ $d/D$ | 0.2 | 0.4 | 0.5 | 0.8 | 0.9 |
|---|---|---|---|---|---|
| 0.05 | — | — | 22.3 | 24.0 | — |
| 0.2 | — | 54.6 | 51.7 | 52.0 | 59.0 |
| 0.5 | 200 | 122 | 107 | 122 | 134 |
| 0.9 | — | 228 | 190 | 212 | 260 |

## 工程算例

例1.2（`#L1273`）：$D=2.4$ m、$\rho=1200$ kg/m³、$\mu=200$ cP、$H/D=0.7$、$d=1.2$ m、$b=0.48$ m、$n_{\mathrm{p}}=2$、$n=60$ r/min、$\theta=90^{\circ}$。

1. $Re=\rho nd^{2}/\mu=1200\times1\times1.44/0.2=8650$；
2. $Re^{0.66}=396$，比值 $Z=(1000+1.2\times396)/(1000+3.2\times396)=0.65$；
3. $A=14+0.2\left[670(0.5-0.6)^{2}+185\right]=52.3$；$B=10^{[1.3-4(0.5-0.5)^{2}-1.14\times0.5]}=2.34$；$p=1.1+0.8-0-0.011=1.9$；
4. $N_{\mathrm{p}}=52.3/8650+2.34\times0.65^{1.9}\times0.7^{0.55}=0.006+0.85=0.859$；
5. $P=N_{\mathrm{p}}\rho n^{3}d^{5}=0.859\times1200\times1\times2.49=2.57$ kW $=265$ kg·m/s $=3.5$ PS。

同条件改倾角：$45^{\circ}\to2.31$ PS、$30^{\circ}\to1.53$ PS，倾角影响全由 $(\sin\theta)^{1.2}$ 承担（`#L1273`，$R_{\theta}$ 换算法见 `#L1439`）。例1.3 加全挡板：$R_{c}=12.86$、$Z=0.99$、$N_{p\max}=52.3/12.86+2.34\times0.99^{1.9}\times0.822=5.99$，$P_{\max}=1827$ kg·m/s $=24$ PS，**是同样转速下无挡板功率（3.5 PS）的近 7 倍**——加速与启动必须按这个值选电机（`#L1443`、`#L1459`）。

## 多叶与多层的换算技巧

无挡板湍流下，式（2-26）可近似用于多层叶轮或单叶轮多叶片，前提：叶片非曲面、各层倾角与直径一致、**桨宽 $b$ 与叶片总数 $n_{p}$ 之积相等**（`#L1317`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $b\,n_{\mathrm{p}}=\text{常数}$ | （1.54） |
| **文字式** | $\text{桨宽}_{\text{【m】}}\times\text{叶片数}=\text{常数}$ |  |

例：六平直叶开启式涡轮（叶宽 $b$）≈ 叶宽 $3b$ 的二叶桨；两层四叶开启式涡轮 ≈ 叶宽 $4b$ 的二叶桨（`#L1315`）。**挡板容器里这条不成立**：挡板把切向流改成轴向/径向流，层间与叶数不再等价（`#L1321`）。另有：桨的安装高度 $H_{p}$ 从 0.1D 到 0.9D 对功率影响甚微（高黏液体除外，`#L1311`）。

## 全挡板时的功率准数

1. 由式（2-28）算临界雷诺数 $R_{c}$（`#L1415`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R_{c}=\dfrac{25}{b/D}\left(\dfrac{d}{D}-0.4\right)^{2}+\dfrac{b/D}{0.11(b/D)-0.0048}$ | （1.57） |
| **文字式** | $\text{临界雷诺数}=\dfrac{25}{\text{桨宽}/\text{釜内径}}\left(\dfrac{\text{叶轮直径}}{\text{釜内径}}-0.4\right)^{2}+\dfrac{\text{桨宽}/\text{釜内径}}{0.11\times(\text{桨宽}/\text{釜内径})-0.0048}$ |  |

2. 把 $R_{c}$ 代回式(1.50) 得全挡板 $N_{p\max}$；带液面修正的完整形式为（`#L1421`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}\max}=\dfrac{A}{R_{c}}+B\left(\dfrac{H}{D}\right)^{0.35+\frac{b}{D}}$ | （1.58） |
| **文字式** | $\text{最大功率准数}=\dfrac{\text{系数}A}{\text{临界雷诺数}}+\text{系数}B\times\left(\dfrac{\text{液面高}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}\right)^{0.35+\frac{\text{桨宽}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}}}$ |  |

3. 倾角 $\theta$ 的折叶桨：$R_{\theta}=10^{4(1-\sin\theta)}R_{c}$（1.59），再代入式(1.58) 得该倾角下的 $N_{p\max}$（`#L1439`）。
4. 挡板充分的条件：$\left(B_{w}/D\right)n_{b}=0.5$（平桨）、$\left(B_{w}/D\right)^{1.2}n_{B}=0.35$（折叶桨），$B_{w}$ 为挡板宽、$n_{b}$ 为挡板数（`#L1363`）。
5. 启动功率按 $N_{p\max}$ 算，约为稳态功率的 1.5 倍，是电机选型的控制工况（`#L1389`）。

## 推广到涡轮、锚式、带式

式(1.50)、(1.53) 本是双叶桨的式子，书中按 $b\,n_{\mathrm{p}}$ 等宽原则外推到开式涡轮、锚式与带式（`#L1729`、`#L1769`）：

- 六叶开式涡轮 ≈ 叶宽 $3b$ 的二叶桨（例1.8：60 cP、$b=0.2\times3=0.6$ m 代入式1.50）（`#L1771`）。
- 锚式、带式按叶片的展开面积折成等效 $b$（`#L1868` 一带）。
- 折叶桨的 $R_{c}$ 用 $R_{\theta}$ 换算（式1.59）。

## 适用边界

- **依据不一致处**：手册版说"多层叶轮不能用（未考虑层间距，有挡板时影响显著）"（《搅拌与混合设备设计选用手册》§2.2 `#L1554`）；本书则说无挡板下多层可按 $b\,n_{\mathrm{p}}$ 折算，仅挡板容器不适用（`#L1321`）。两者不冲突的读法是：**无挡板、叶片非曲面的多层可折算；有挡板必须分层实测**。
- 内径 <1200 mm、$d/D<0.5$、无挡板时计算值与实际相符；内径 >1200 mm 时最大偏差可达 100%；全挡板、$d/D=0.35\sim0.5$、$b/D=0.1\sim0.25$、$\theta=45^{\circ}$ 时折叶桨偏差 <20%（《搅拌与混合设备设计选用手册》§2.2 `#L1564`）。
- 部分挡板另按 [[挡板系数与部分挡板]] 的插值式计算。
- 非牛顿流体改用表观黏度法，见 [[表观黏度法与Metzner常数]]。

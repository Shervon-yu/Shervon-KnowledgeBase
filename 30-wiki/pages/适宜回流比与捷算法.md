# 适宜回流比与捷算法

## 适宜回流比（`#L12380-#L12400`）

设备费与操作费之和最低的 R 称**适宜回流比**。

- R→Rmin：板数→∞、设备费→∞；
- R 稍大于 Rmin：板数锐减、设备费骤降；
- R 继续增大：板数减少变缓，而塔径、再沸器、冷凝器增大 → 设备费回升；操作费（加热与冷却介质）单调上升。

工程经验：

$$R=(1.1\sim2.0)R_{\min}\tag{6-52}$$

难分离物系取上限。

## 吉兰关联图与式（`#L12402-#L12424`）

吉利兰（Gilliland）以 $X=\frac{R-R_{\min}}{R+1}$ 为横坐标、$Y=\frac{N-N_{\min}}{N+1}$ 为纵坐标，把 50 多种双组分/多组分精馏的逐板结果关联成一条曲线（图6-36），可近似为：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{N-N_{\min}}{N+1}=0.75-0.75\left(\dfrac{R-R_{\min}}{R+1}\right)^{0.5668}$ | （6-53） |
| **文字式** | $(理论板数−最少理论板数)/(理论板数+1)=0.75−0.75\times[(回流比−最小回流比)/(回流比+1)]^{0.5668}$ |  |

$N$、$N_{\min}$ 均**包括蒸馏釜**。

## 捷算法三步（`#L12418-#L12424`）

1. 由 $x_D$、$x_W$、$x_F$、q 求 $R_{\min}$，再按 1.1~2.0 倍选 R；
2. 求全回流最少理论板数 $N_{\min}$（芬斯克式或图解法）；
3. 算 $X=(R-R_{\min})/(R+1)$ → 查图/代式得 $Y=(N-N_{\min})/(N+1)$ → 解出 $N$。

## 例6-15（`#L12426-#L12442`）

正庚烷-正辛烷，饱和液体进料，$x_F$=0.45、$x_D$=0.95、$N_{\min}$=7.69、$R$=1.5Rmin：

- 夹点 $x_P$=0.45、$y_P$=0.636 → $R_{\min}=\frac{0.95-0.636}{0.636-0.45}=1.69$；$R$=2.54；
- $X=\frac{2.54-1.69}{3.54}=0.24$ → 查图 $Y$=0.415；
- $N=\frac{7.69+0.415}{1-0.415}=13.9$ → 取 **14**（含釜）。

## 判断

- 吉利兰法的价值是"**不用画梯级**就能估板数"，适合初步设计与方案比较；最终设计仍应逐板校核。
- $R=(1.1\sim2.0)R_{\min}$ 是统计经验，不是最优解本身：最优点取决于当地能源与设备价格，能耗贵时取下限、设备贵时取上限。
- 捷算法假设 $N$ 与 $R$ 的关系对物系不敏感（50 多种物系归纳），所以对强非理想物系误差较大，需用图解法复核。

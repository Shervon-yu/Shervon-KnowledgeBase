# 机械密封的选型原则

## 选型依据（`#L13431`）

主要依据：**工作参数 $p$、$v$、$t$**，**介质特性**，**泄漏量与寿命要求**，**安装密封的有效空间位置**；其次考虑安装维修难易与价格。

其中 $p$ 为密封腔处介质压力，$v$ 为密封面平均直径处的圆周速度，$t$ 为密封腔内介质温度（`#L13435`）。

## 一、按 $p$、$v$、$t$ 选型（`#L13433-#L13443`）

### 按压力 $p$ 定平衡程度

| 条件 | 结构 |
|:---|:---|
| 高黏度、润滑性好，$p\le0.8\ \mathrm{MPa}$ | 非平衡式 |
| 低黏度、润滑性差，$p\le0.5\ \mathrm{MPa}$ | 非平衡式 |
| 超过上述范围 | 平衡式 |
| $p>15\ \mathrm{MPa}$ | 单端面平衡式很难达标，改用**串联式多端面**密封 |

### 按速度 $v$ 定弹簧是否随轴旋转

- $v<20\sim30\ \mathrm{m/s}$：可用**弹簧旋转式**；
- 更高速度：旋转件不平衡质量易引起强烈振动，宜用**弹簧静止式**；
- $p$、$v$ 都高：可考虑流体动压式结构。

### 按温度 $t$ 定辅助密封圈与冷却

| 温度 | 辅助密封圈 | 备注 |
|:---|:---|:---|
| $0\sim80\ ℃$ | 丁腈橡胶 O 形圈 | 常用 |
| $-50\le t<150\ ℃$ | 按腐蚀性强弱选氟橡胶、硅橡胶或聚四氟乙烯成形填料（O/方形/V 形） | 覆盖普温与中温 |
| $t<-50\ ℃$ 或 $t\ge150\ ℃$ | 橡胶与聚四氟乙烯会低温脆裂或高温老化，改用**金属波纹管**结构 | — |

温度 $>80\ ℃$ 在密封领域即按**高温**处理，必须采取相应冷却措施（`#L13443`）。

## 二、按介质特性选型（`#L13445-#L13451`）

| 介质 | 结构 | 理由与限制 |
|:---|:---|:---|
| 弱腐蚀 | **内置式** | 端面受力状态与泄漏方向都比外置式合理 |
| 强腐蚀 | **外置式**或**聚四氟乙烯波纹管式** | 弹簧选材困难；一般只适用于 $p\le0.2\sim0.3\ \mathrm{MPa}$ |
| 易结晶、易凝固、高黏度 | **大弹簧旋转式** | 小弹簧易被固体物堵塞，高黏介质使小弹簧轴向补偿受阻 |
| 易燃、易爆、有毒 | **有封液（隔离液）的双端面** | 保证介质不外漏 |

## 三、按搅拌设备特点选型（`#L13453-#L13471`）

1. 优先选用现行**标准机械密封**；按腐蚀、安装检修条件尽可能用**外置式**。
2. 搅拌介质与密封装置直接接触且含固体颗粒（如底插式搅拌）时，宜用**内流式**。
3. 密封要求高（易燃、易爆、强腐蚀、带颗粒、低温、真空）时用**双端面**。
4. 密封液要求：漏入设备不影响物料工艺性能、不使物料变质；润滑性良好、不腐蚀密封零件、有较高汽化温度与比热；**压力一般高于设备内工作压力**。
5. 标准机械密封的密封箱上部轴承只用于控制搅拌轴径向摆动量，**在搅拌轴计算中不作为支承点**（见 [[搅拌轴的支点类型与减挠措施]]）。
6. 动、静环材料三条：满足耐腐蚀要求；实际 $pv$ 值小于允许 $[pv]$；一般用**硬质材料动环 + 软质材料静环**配对。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $pv=p_{c}\,v$ | （10-1′） |
| **文字式** | $\text{端面} pv\text{值}=\text{端面比压}_{\text{【MPa】}}\times\text{端面平均线速度}_{\text{【m/s】}}$ |  |

口径：$p_c$ 为密封端面比压（MPa），$v$ 为端面平均线速度（m/s）；[pv] 由所选端面材质、加工精度、工况经试验确定，**由制造厂提供**（`#L13471`）。原文未给此式号，本页按书内体例临时编为（10-1′），仅作记号。

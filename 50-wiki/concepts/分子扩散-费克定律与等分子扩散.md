# 分子扩散-费克定律与等分子扩散

## 定义

**分子扩散**是流体内部因浓度差引起的组分迁移，靠分子微观运动，速率慢（#L9004）。**费克定律**：扩散通量与浓度梯度成正比、方向相反（#L9032、#L9040）。比例系数 $D_{AB}$ 称**扩散系数**，量纲 m²/s（#L9020）。

**等分子反向扩散**：两组分以相等的摩尔通量相向扩散（如精馏中的 A、B 同向等量），条件 $J_{A}=-J_{B}$（#L9068）。**单向扩散**：A 通过不扩散的停滞组分 B 扩散（吸收中常见），总通量中额外含**总体流动**项（#L9124、#L9138）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $J_{\mathrm{A}}=-D_{\mathrm{AB}}\dfrac{\mathrm{d}c_{\mathrm{A}}}{\mathrm{d}Z}$ | （5.3-1） |
| **文字式** | $\text{扩散通量}_{\text{【mol/(m²·s)】}}=-\text{扩散系数}_{\text{【m²/s】}}\times\dfrac{\mathrm{d}\text{A的摩尔浓度}_{\text{【mol/m³】}}}{\mathrm{d}\text{扩散距离}_{\text{【m】}}}$ |  |

（式 5-12a，#L9032；以分压表示的等价式 5-12b，#L9040。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{A}}=\dfrac{D}{RTZ}\left(p_{\mathrm{A1}}-p_{\mathrm{A2}}\right)$ | （5.3-2） |
| **文字式** | $\text{A的传质通量}_{\text{【mol/(m²·s)】}}=\dfrac{\text{扩散系数}_{\text{【m²/s】}}\times\left(\text{截面1处A分压}_{\text{【Pa】}}-\text{截面2处A分压}_{\text{【Pa】}}\right)}{\text{气体常数}_{\text{【J/(mol·K)】}}\times\text{温度}_{\text{【K】}}\times\text{扩散距离}_{\text{【m】}}}$ |  |

（式 5-16a、5-16b，等分子反向扩散，$N_{A}=J_{A}$，#L9100、#L9104。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{A}}=\dfrac{D}{RTZ}\cdot\dfrac{p}{p_{\mathrm{Bm}}}\left(p_{\mathrm{A1}}-p_{\mathrm{A2}}\right)$ | （5.3-3） |
| **文字式** | $\text{A的传质通量}_{\text{【mol/(m²·s)】}}=\dfrac{\text{扩散系数}\times\text{总压}_{\text{【Pa】}}\times\left(\text{截面1A分压}-\text{截面2A分压}\right)_{\text{【Pa】}}}{\text{气体常数}\times\text{温度}\times\text{扩散距离}\times\text{惰性组分B的对数平均分压}_{\text{【Pa】}}}$ |  |

（式 5-17，单向扩散，「漂流因子」$p/p_{Bm}$，#L9168；液相形式 5-18 用 $c/c_{Bm}$，#L9176；$p_{Bm}$ 为 $p_{B1}$、$p_{B2}$ 的对数平均值。）

**实验测定 $D$（毛细管法）**：由式 5-19 反算 $D=\frac{RT\rho\left(Z^{2}-Z_{0}^{2}\right)}{2pM\theta\ln\frac{p}{p-p_{A0}}}$（#L9274）。

## 适用范围与边界

- 费克定律适用于**二元、稀溶液、恒温恒压、无化学反应的分子扩散**（#L9004 的前提）。
- 式 5-17 与 5-16 的差别只在漂流因子 $p/p_{Bm}$；B 不扩散时（吸收中惰性气体）必须用 5-17，用 5-16 会低估通量（#L9168 的推导来源）。
- 湍流主体内以涡流扩散为主，$D$ 不适用，须用对流传质系数（#L9328 起）。
- 本书未给 $D$ 的通用预测式（只给实验测定与查表路径）。

# 相对挥发度与汽液平衡比

## 定义

**挥发度**：某组分的平衡分压与其液相摩尔分数之比，$v_{A}=p_{A}^{\circ}$、$v_{B}=p_{B}^{\circ}$（理想溶液，式 6-11，#L11216）。**相对挥发度** $\alpha$ 是两组分挥发度之比（式 6-12，#L11222）：

$$\alpha=\frac{v_{A}}{v_{B}}=\frac{p_{A}^{\circ}}{p_{B}^{\circ}}$$

$\alpha>1$ 表示 A 比 B 易挥发，可用普通精馏分离；$\alpha=1$ 时不能用普通精馏分离（需萃取/恒沸精馏等特殊手段，本书未展开）。$\alpha$ 随温度变化缓慢，工程上常取塔顶塔底几何平均（式 6-48、6-49，#L12252、#L12256）。

**汽液平衡比**（相平衡常数）$K_{i}=y_{i}/x_{i}$；相对挥发度与平衡比的关系 $\alpha=K_{A}/K_{B}$，等价于式 6-13 的 $\frac{y}{1-y}=\alpha\frac{x}{1-x}$（#L11234）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $y=\dfrac{\alpha x}{1+\left(\alpha-1\right)x}$ | （6.1-1） |
| **文字式** | $\text{气相摩尔分数}=\dfrac{\text{相对挥发度}\times\text{液相摩尔分数}}{1+\left(\text{相对挥发度}-1\right)\times\text{液相摩尔分数}}$ |  |

（式 6-14，恒 $\alpha$ 下的平衡曲线，#L11240；反解为式 6-15 $x=\frac{y}{\alpha-(\alpha-1)y}$，#L11244。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha=\sqrt[N]{\alpha_{1}\alpha_{2}\cdots\alpha_{N}}$，近似 $\alpha=\sqrt{\alpha_{1}\alpha_{N}}$ | （6.1-2） |
| **文字式** | $\text{平均相对挥发度}=\sqrt[N]{\text{各板相对挥发度之积}}$ |  |

（式 6-48、6-49，#L12252、#L12256。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha=\dfrac{p_{A}^{\circ}}{p_{B}^{\circ}}$，$p_{i}^{\circ}$ 由 $\lg p^{\circ}=A-\dfrac{B}{t+C}$ 求 | （6.1-3） |
| **文字式** | $\text{相对挥发度}=\dfrac{\text{A的饱和蒸气压}_{\text{【Pa】}}}{\text{B的饱和蒸气压}_{\text{【Pa】}}}$，饱和蒸气压用安托因式由温度求 |  |

（式 6-12、6-1（安托因式），#L11222、#L10994。）

**泡点/露点与平衡组成的求法**：已知 $p$、$x$ 用式 6-7、6-8 求泡点温度与 $y$（#L11074、#L11086）；已知 $y$ 反求 $x$、温度用式 6-9、6-10（#L11100、#L11110）。三元以上用式 6-4 的杠杆规则读相图（#L11044）。

## 适用范围与边界

- 式 6-14 的前提是**理想溶液 + 恒 $\alpha$**（#L11240 的推导基于拉乌尔定律）；非理想体系（乙醇-水、共沸物）$\alpha$ 随组成剧变，不能用单点 $\alpha$ 的解析式。
- 安托因式 6-1 的常数只在给定温区内有效（#L10994）。
- 本书未给活度系数模型（NRTL/UNIQUAC），非理想体系须查实验相图。
- $\alpha=1$ 的恒沸点附近，$y=x$，操作线与平衡线相交，普通精馏无法越过（#L11234 的推论）。

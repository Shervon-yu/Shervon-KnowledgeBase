# 开孔补强的等面积法

开孔使承载截面减少，并在孔边产生应力集中。等面积法的思路：**开孔削掉多少承载面积，就在孔边有效范围内补回多少**。

## 一、适用范围（8.1.2，`#L7721-#L7761`）

| 壳体 | 允许开孔直径 |
|:--|:--|
| 圆筒/球壳/锥壳/凸形封头，$D_i\le1500$ mm | $d\le D_i/2$ 且 $d\le520$ mm |
| 同上，$D_i>1500$ mm | $d\le D_i/3$ 且 $d\le1000$ mm |
| 椭圆/碟形封头 | 须在 0.8 倍封头内直径范围内，$d\le D_i/2$ |

超出范围须按 8.5（平盖中心大孔 → [[平盖中心大开孔的计算]]）或 8.6（径向接管分析法 → [[圆筒径向接管补强的分析法]]）处理。

## 二、所需补强面积

### 内压容器（式8-1）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=d_{op}\delta+2\delta\delta_{et}(1-f_r)$ | （8-1） |
| **文字式** | $\text{需要补强面积}=\text{开孔直径}\times\text{壳体计算厚度}+2\times\text{计算厚度}\times\text{接管有效厚度}\times(1-\text{许用应力比})$ |  |

$f_r=[\sigma]_{nt}^t/[\sigma]^t$（接管与壳体许用应力之比）。第二项是"接管材料强度不如壳体"的补偿。

$d_{op}$：圆孔取接管内直径 + 2 倍厚度附加量；椭圆/长圆孔取所考虑截面弦长 + 2 倍厚度附加量（`#L7900`）。

$\delta$ 的取法：
- 圆筒、球壳：取开孔处壳体计算厚度；
- 锥壳：按式7-14，$D_c$ 取开孔中心处锥壳内直径；
- 椭圆封头且开孔在中心 80% 直径的球面区内 → 式8-2 $\delta=\dfrac{p_cK_1D_i}{2[\sigma]^t\varphi-0.5p_c}$（$K_1$ 查表7-2）；否则按式7-1/7-2；
- 碟形封头且在球面部分内 → 式8-3 $\delta=\dfrac{p_cR_i}{2[\sigma]^t\varphi-0.5p_c}$；否则按式7-7/7-8。

### 外压容器（式8-4）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=0.5\left[d_{op}\delta+2\delta\delta_{et}(1-f_r)\right]$ | （8-4） |
| **文字式** | 外压时所需补强面积取内压式的一半 |  |

内、外压两种工况都存在的容器，须同时满足式8-1 与式8-4（取大）。

### 平盖开孔（式8-5）

$d_{op}\le0.5D_o$（$D_o$ 取平盖计算直径，非圆形取短轴）时：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=0.5d_{op}\delta_p+\delta\delta_{et}(1-f_r)$ | （8-5） |
| **文字式** | 以平盖计算厚度 $\delta_p$ 代替壳体计算厚度，且首项系数为 0.5 |  |

圆形平盖中心单孔且 $d_{op}>0.5D$ 时按 8.5 处理（不再用等面积法）。

## 三、有效补强范围（8.3.5，式8-6~8-8）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $B=\max\left(2d_{op},\ d_{op}+2\delta_n+2\delta_{nt}\right)$ | （8-6） |
| **文字式** | $\text{有效宽度}$ 取 $2\times$开孔直径 与 开孔直径+2×壳壁名义厚度+2×接管名义厚度 的较大者 |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_1=\min\left(\sqrt{d_{op}\delta_{nt}},\ \text{接管实际外伸高度}\right)$；$\quad h_2=\min\left(\sqrt{d_{op}\delta_{nt}},\ \text{接管实际内伸高度}\right)$ | （8-7）（8-8） |
| **文字式** | 外伸/内伸有效高度取 $\sqrt{\text{开孔直径}\times\text{接管名义厚度}}$ 与实际伸出高度的小者 |  |

## 四、有效补强面积与判定（式8-9~8-12）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_e=A_1+A_2+A_3$ | （8-9） |
| **文字式** | $\text{有效补强面积}=\text{壳体多余面积}+\text{接管多余面积}+\text{焊缝截面积}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_1=(B-d_{op})(\delta_e-\delta)-2\delta_{et}(\delta_e-\delta)(1-f_r)$ | （8-10） |
| **文字式** | 壳体在有效宽度内、有效厚度超出计算厚度的部分，扣除接管占去的部分 |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_2=2h_1(\delta_{et}-\delta_t)f_r+2h_2(\delta_{et}-c_2)f_r$ | （8-11） |
| **文字式** | 接管外伸段与内伸段的多余厚度，按许用应力比折算 |  |

- $A_e\ge A$ → 不需另加补强；
- $A_e<A$ → 另加补强面积 $A_4\ge A-A_e$（式8-12）。

## 五、补强结构（8.3.2）

- **补强圈**（`#L7872-#L7882`）：低合金钢 $R_m<540$ MPa、补强圈厚度 $\le1.5\delta_n$、壳体名义厚度 $\delta_n\le38$ mm；接管与补强圈焊接按附录 D 与 NB/T 11025；
- **整体补强**：增加壳体厚度，或用全截面焊透的厚壁接管、整体补强锻件；
- 条件许可时**推荐厚壁接管代替补强圈**，$\delta_{nt}/\delta_n$ 宜 0.5~2.0。

## 判断

- 等面积法的隐含假定是"补强材料的承载能力与壳体等效"，所以引入 $f_r$ 折算——接管若比壳体强（$f_r>1$），第二项为负值，相当于"接管自身就能抵掉一部分削弱"；
- 有效宽度 $B$ 取 $2d_{op}$ 与 $d_{op}+2(\delta_n+\delta_{nt})$ 的较大者，是"应力集中影响范围"与"实际可补材料范围"的折中；
- $h_1,h_2$ 用 $\sqrt{d_{op}\delta_{nt}}$ 限制，是因为离孔边越远，补强材料对孔边的贡献按"有效宽度"衰减，超出部分不起作用；
- 补强圈便宜但有三个硬约束（材料抗拉强度、厚度、壳厚），本质是担心**补强圈与壳体之间的焊缝成为新的薄弱环节**，这也是标准推荐厚壁接管的原因。

# 固液悬浮功率与平均物性

## 思路

定了悬浮临界转速后，轴功率仍用均相液体的功率计算式，**物性取平均值**（`#L2702`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho_{sv}=\varphi_{x}\rho_{x}+\varphi_{y}\rho_{y}$ | （2-128） |
| **文字式** | $\text{悬浮液平均密度}_{\text{【kg/m³】}}=\text{组分}x\text{体积百分率}\times\text{组分}x\text{密度}_{\text{【kg/m³】}}+\text{组分}y\text{体积百分率}\times\text{组分}y\text{密度}_{\text{【kg/m³】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu_{m}=\dfrac{\mu_{L}}{\left(\dfrac{1-X_{v}}{X_{vb}}\right)^{1.8}}$ | （2-129） |
| **文字式** | $\text{悬浮液平均黏度}_{\text{【Pa·s】}}=\dfrac{\text{液体黏度}_{\text{【Pa·s】}}}{\left(\dfrac{1-\text{固液体积比}}{\text{沉积层固液体积比}}\right)^{1.8}}$ |  |

符号（`#L2710-#L2718`）：$\rho_x$、$\rho_y$ 两组分密度（原文单位写作 kg·s²/m⁴，属工程制，换算时注意）；$\varphi_x$、$\varphi_y$ 体积百分率；$X_v$ 固-液相体积比；$X_{vb}$ 沉降后沉积层中的固-液体积比。

## 为什么计算功率与实际不符

`#L2720-#L2724`：

- **低转速启动**：转速不足以把颗粒提到叶轮区，叶轮实际处于纯液体密度下 → 实际功耗**小于**计算值。
- **部分悬浮**：转速升高、颗粒部分悬浮，桨叶区料液密度提高 → 实际功耗**高于**该转速下的计算值。
- **达到均匀悬浮**：实际功率降回，且**略低于**用悬浮液平均密度算出的值——因为搅拌器不可能总处于平均密度下操作。

## 工程用法

1. 用式（2-128）（2-129）算 $\rho_{sv}$、$\mu_m$；
2. 按 $Re$、$N_p$ 曲线算功率；
3. 用上述三条偏差规律做校核：启动扭矩按纯液体校核（偏小风险）；部分悬浮段按上限留裕量；均匀悬浮段按计算值略打折；
4. 若固体含量很高（50%~80% 以上出现剪切增稠），平均物性法失真，须实测（见 [[固液搅拌设备设计]]）。

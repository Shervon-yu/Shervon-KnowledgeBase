# 机架型式与选用

## 机架做什么

通过机架把立式传动装置装到封头上；机架内要留够空间容纳联轴器与轴封，并保证安装操作空间；多数情况下中间还要装中间轴承改善轴的支承（`#L8011`）。

机架下端用螺柱与安装底盖连接，**机架公称直径一般等于或小于安装底盖公称直径**（`#L8023`）。

## 三大类与选用判据（§9.1）

### 单支点机架

具备下列条件**之一**即可（`#L8041-#L8049`）：

1. 电动机或变速器有一个支点，经核算可承受搅拌轴载荷；
2. 设底轴承作为一个支点；
3. 轴封本体设有可作支点的轴承；
4. 釜内搅拌轴中部设导向轴承作为一个支点。

### 无支点机架

同时满足下列条件之一（`#L8051-#L8055`）：

1. 电动机与变速器具备两个支点，经核算轴承能承受搅拌轴传来的径向与轴向载荷；
2. 同时具备单支点条件①和②~④中之一，上下组成一对轴支承。

### 双支点机架

不具备单支点或无支点条件时**必须**选双支点（`#L8057`）。

## 按支点数的型号系列（§9.5，HG/T 3139.1 附录 A）

| 支点数 | 型号 | 说明 |
|:---|:---|:---|
| 无支点 | **WJ、LWJ** | 机架内不设轴承，轴的支承全在减速机内 |
| 单支点 | **DJ、LDJ、DXJ** | 机架内设一个轴承 |
| 双支点 | **SJ、LSJ** | 机架内设两个轴承 |
| 单支点（另一体系） | **XD** | 同 HG 21699，配 DF 型联轴器 |
| 双支点（另一体系） | **XS** | 同 HG 21567，内用 DF 型联轴器 |
| 双支点 | **FZ** | 方底板机架 |

## 型号标记规则

标记由三段组成（`#L10541-#L10551`）：

1. **接板型式**：`A` 配摆线针轮减速机；`B` 配 LC、DC、LPJ、LPB、CW 齿轮减速机；
2. **轴径**：减速机输出轴直径；
3. **机架类型**：WJ、LWJ（无支点）/ DJ、LDJ、DXJ（单支点）/ SJ、LSJ（双支点）。

**底面型式**：WJ、LWJ、DJ、LDJ、DXJ 型的 30A、30B、35A、40B、45A 四种机架底面分 **I 型与 II 型**（I 型不标注，II 型在型号后注 II），其余均为 II 型（不标注）。

## 选用要点

1. **先定支点体系**：无支点→单支点→双支点，与 [[搅拌轴的支承型式]] 的型号对应；支点数直接影响轴系临界转速与挠度（见 [[搅拌轴临界转速的计算]]）。
2. **空间是否容得下轴封**：
   - `LDJ` 型下部空间可容纳 **205、206、207 型双端面机械密封**（`#L10623`）；
   - `L.WJ` 型内部空间可同时容纳 **207 型双端面机械密封与 SF 型三分式联轴器**（`#L10587`）；
   - `LSJ` 型下部空间可容纳 205、206、207 型双端面机械密封（`#L10751`）。
3. **XD/XS 体系的轴封兼容性**：A 型可配 2001、2003、2004、2006、2008 型机械密封；B 型可配 2002、2005、2007 型机械密封或 506、516、606、616 型填料箱（`#L10759`）。
4. **可拆性**：XD/XS 采用 DF 型联轴器与安装底盖的搁轴装置，**不拆减速机和机架**即可从侧面窗口拆出 DF 联轴器、轴承室及机械密封/填料箱（`#L10761`）。

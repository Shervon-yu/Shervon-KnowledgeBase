# 通气搅拌容器的设计准则

## 为什么无挡板容器不能通气

无挡板容器里自由表面是等压面，且存在与自由表面平行的等压面；底部吹入的气泡受垂直于等压面的浮力作用，**聚集到搅拌轴周围**（`#L9093`）。结果气液接触效率极低。

对策两条：① 抑制切向流、保持液面平直——器壁等距垂直挡板；② 用叶轮给气泡施加剪切（`#L9093`、`#L9095`）。

## 气泡分散的三个条件

`#L9099`–`#L9103`：

1. **气体进口管靠近桨叶安装**；
2. 气体从**钻许多小孔的环形分布器**吹出，而不是单个喷嘴——单孔造成大气泡串；
3. 分布器圈径取叶轮直径的 80%：$D_s=0.8d$（图8.1）。

第三条有个边界：**转速很高时剪切力成为控制因素，其他因素的影响看不出来**（`#L9103`）——此时分布器怎么装都差不多。

## 净功率效率：搅拌到底贡献了多少吸收

不通气只吹气也能吸收一部分，其容积系数（`#L9113`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $(k_La)_0=\dfrac{1}{t}\ln\dfrac{C^{*}-C_1}{C^{*}-C_0}$ | （8.1） |
| **文字式** | 不搅拌时的容积系数 = 单位时间 × ln[(平衡浓度−通气后浓度)/(平衡浓度−通气前浓度)] |  |

搅拌时（`#L9123`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $(k_La)=\dfrac{1}{t}\ln\dfrac{C^{*}-C_1}{C^{*}-C}$;\qquad $(k_La)_I=(k_La)-(k_La)_0$ | （8.2）（8.3） |
| **文字式** | 搅拌带来的容积系数增量 = 搅拌工况值 − 纯鼓泡值，即**搅拌的净效应** |  |

定义净功率效率（`#L9133`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $E_p=\dfrac{(k_La)_I}{P_v}$ | （8.4） |
| **文字式** | $\text{净功率效率}_{\text{【(l/m)/(kg·m/s·m³)】}}=\text{搅拌引起的容积系数增量}/\text{单位体积功率}$ |  |

图8.2 是 0.1 N KOH 中氧传递的实测（`#L9141`）：曲线（1）纯鼓泡的 $(k_La)_0$、（2）（3）搅拌的总 $k_La$、（2′）（3′）净增量。**低转速时高气速段净增量很小甚至为负**——此时吹气本身就够了，搅拌白耗功。这是"通气量足够时不必加大转速"的定量依据。

## 标准尺寸（实验室得来，工业要复核）

|  |  |  |
|:---|:---:|---|
| **符号式** | $(B_w/D)n_B=\dfrac{1}{12}\times4=\dfrac{1}{3}$（工业常规） | （8.5） |
| **文字式** | 挡板宽/容器直径 × 挡板数 = 1/3，即四块 1/12 D 宽的挡板 |  |
| **符号式** | $(B_w/D)n_B=0.125\times4=0.5$（全挡板，功率最大） | （8.6） |

挡板通常固定于器壁，有时留 0.5~1.5 in 间隙（`#L9153`）——留缝用于冲刷防积料。

叶轮选型（`#L9155`）：**气流分散用盘下直叶涡轮优于桨式**，圆盘阻止气体沿轴上窜。

改进涡轮（图8.3b，上半部叶片割掉加在下半部）的 $E_p$ 比标准涡轮高（`#L9177`）——原因正是标准涡轮有部分叶片在圆盘上方，对分散气体没用。

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{\text{最佳}}\cong D/3$ | （8.7） |
| **文字式** | 功率不变时 $k_La$ 最大的叶轮直径为容器直径的三分之一 |  |
| **符号式** | $(b/D)n_p=0.15\sim0.3$ | （8.8） |
| **文字式** | 总叶片宽与容器直径之比（叶片宽 × 叶数）取 0.15~0.3 |  |
| **符号式** | $C=H/3$ | （8.9） |
| **文字式** | 距器底的叶轮高度取液面高度的三分之一 |  |

**这四条都是实验室结论，工业上直接用可能有困难，且最佳条件会随通气速率与转速的相对关系改变**（`#L9195`、`#L9203`）。

## 泛点：气速有上限

增加气速使界面面积增加、$k_La$（或 $k_{Ga}$）上升；但到某一流速 $k_{Ga}$ 达最大，之后**下降**（`#L9205`）。原因是气速超过叶轮分散能力，气体走短路（"泛点" flooding）。

图8.4 的读数（`#L9207`）：气速 2.25 l/min 时转速至少需 600 r/min 以上；若转速只有 350 r/min，那么 2.25 l/min 的 $k_{Ga}$ 反而比 1.5 l/min 时更差。

**无量纲判据**：$N_A=Q/(nd^3)$ 相等时，$P_g/P_0$ 的下降速率反映叶轮的分散能力（`#L9209`，Oyama）。$P_g/P_0$ 急降的叶轮，其周围液体局部平均密度低——气穴堵塞了。

## 三条容易被忽略的结论

1. **吸收主要发生在气泡被分裂成新表面的瞬间**，气泡上升途中的吸收是次要的（`#L9217`）。故加深液层不一定有利，而**多层搅拌让气泡一再分散、凝并反而有效**；但 $k_{Ga}$ 并不正比于层数，层数多了传质系数还会变小（`#L9219`，见图8.12）。
2. **"死泡"**：稳定分散在液体里的极细气泡，其停留时间比完成吸收所需时间还长——里面溶质早已吸完，不再起作用（`#L9221`）。
3. 所以**大量细小气泡会造成"分散很有效"的错觉**（`#L9223`）。判断标准应是 $k_La$，不是目视气泡多少。

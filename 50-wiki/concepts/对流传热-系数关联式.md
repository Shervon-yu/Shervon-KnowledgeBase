# 对流传热-系数关联式

## 定义

对流传热速率方程由**有效层流膜**概念建立：把全部热阻集中于有效层流膜内，凡能减小有效膜热阻的因素就是增大 $\alpha$ 的因素（#L6615）。

$\alpha$ 的计算式有两类（#L6617）：

1. **量纲分析法**：把影响因素整理成无量纲特征数之间的幂函数关系，实验定系数与指数；
2. **纯经验式**：由实验直接拟合，**必须用公式规定的单位**。

## 判据 / 计算

强制湍流管内对流传热（原书例 4-19 所用式，水被加热）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha=0.023\dfrac{\lambda}{d}Re^{0.8}Pr^{0.4}$ | （8-1） |
| **文字式** | $\text{对流传热系数}_{\text{【W/(m²·K)】}}=0.023\times\dfrac{\text{导热系数}_{\text{【W/(m·K)】}}}{\text{管内径}_{\text{【m】}}}\times\left(\text{雷诺数}\right)^{0.8}\times\left(\text{普朗特数}\right)^{0.4}$ |  |

来源：原书 §4.4 例 4-19（#L7250-#L7254）。该例算得 $Re=7.71\times10^{4}$（湍流）、$\alpha_1=6.246\times10^{3}\ \mathrm{W/(m^2\cdot K)}$。

不同传热类型的 $\alpha$ 量级（表 4-5，#L6631-#L6641，单位 W/(m²·K)）：

| 传热类型 | $\alpha$ | 传热类型 | $\alpha$ |
|:---|---:|:---|---:|
| 空气自然对流 | 5~25 | 水蒸气冷凝 | 5000~15000 |
| 空气强制对流 | 30~300 | 有机蒸气冷凝 | 500~3000 |
| 水自然对流 | 200~1000 | 水沸腾 | 1500~30000 |
| 水强制对流 | 1000~8000 | 有机物沸腾 | 500~15000 |
| 有机液体强制对流 | 500~1500 |  |  |

规律（#L6641）：强制对流时液体 $\alpha$ 大于空气；水强制对流大于有机液体；同一液体有相变时 $\alpha$ 大于无相变。

## 使用关联式的五条注意事项（#L6619-#L6627）

1. 先按问题类型（强制/自然/冷凝/沸腾）选对关系式。
2. 注意关系式的**应用范围**、**特征尺寸**选择（管内径？管长？）与**定性温度**（膜温？主体温度？）。
3. 单位必须与公式要求一致；各特征数量纲为一，但纯经验式的系数带单位。
4. 用指数大小判断各物理量对 $\alpha$ 的影响强弱。
5. $\alpha$ 的量级可先用表 4-5 粗估，防数量级错。

## 适用范围与边界

- 式(8-1) 只对**管内强制湍流**且 $Re$、$Pr$ 在实验范围内成立；层流、过渡区、弯管、非圆截面均需另选关系式（#L6619）。
- 定性温度与特征尺寸取错会让 $\alpha$ 偏 20%~50%，这是工程估算的主要误差源（#L6621）。
- 有相变（冷凝、沸腾）的机理与单相对流不同，不能用同一关联式外推（#L6641）。
- 本页不给全部关联式：原书 §4.3 按类型分列，按需查原节。

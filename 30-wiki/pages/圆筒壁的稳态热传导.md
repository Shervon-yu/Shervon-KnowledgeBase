# 圆筒壁的稳态热传导

## 单层圆筒壁（`#L5995-#L6039`）

温度只沿半径变化，等温面为同心圆柱面；与平壁的根本差别是**传热面积随半径变化** $A=2\pi rl$。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=-\lambda\,2\pi rl\dfrac{\mathrm{d}t}{\mathrm{d}r}$ | （4-8） |
| **文字式** | $\text{传热速率}_{\text{【W】}}=-\text{热导率}\times2\pi\times\text{半径}\times\text{管长}\times\text{径向温度梯度}$ |  |

分离变量积分（$\lambda$ 为常数）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=2\pi l\lambda\dfrac{t_1-t_2}{\ln(r_2/r_1)}=\dfrac{\Delta t}{\dfrac{1}{2\pi l\lambda}\ln\dfrac{r_2}{r_1}}$ | （4-9） |
| **文字式** | $\text{传热速率}=\dfrac{2\pi\times\text{管长}\times\text{热导率}\times\text{温差}}{\ln\dfrac{\text{外半径}}{\text{内半径}}}$ |  |

**温度分布是对数曲线**，温度梯度随 $r$ 增大而减小。

单位管长传热速率（工程上常用，W/m）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $q_1=\dfrac{Q}{l}=2\pi\lambda\dfrac{t_1-t_2}{\ln(r_2/r_1)}$ | （4-10） |
| **文字式** | $\text{单位管长传热速率}_{\text{【W/m】}}=2\pi\times\text{热导率}\times\dfrac{\text{温差}}{\ln\dfrac{\text{外半径}}{\text{内半径}}}$ |  |

改写为平壁形式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=\dfrac{\lambda}{b}A_m(t_1-t_2),\quad A_m=\dfrac{A_2-A_1}{\ln(A_2/A_1)}$ | （4-11） |
| **文字式** | $\text{传热速率}=\dfrac{\text{热导率}}{\text{壁厚}}\times\text{对数平均面积}\times\text{温差}$ |  |

- 对数平均面积 $A_m=(A_2-A_1)/\ln(A_2/A_1)$；$A_2/A_1<2$ 时可用算术平均 $(A_1+A_2)/2$ 近似；
- 或用对数平均半径 $r_m=(r_2-r_1)/\ln(r_2/r_1)$，$A_m=2\pi r_m l$；$r_2/r_1<2$ 时 $r_m\approx(r_1+r_2)/2$。

**例4-3**：φ426 mm 管外 400 mm 保温层，$\lambda=0.5+0.0009t$，内表面 150 ℃、外表面 40 ℃ → $q_1=383$ W/m（积分时 $\lambda$ 随温度变化一并积进）。

## 多层圆筒壁（`#L6051-#L6079`）

以三层为例，$b_i=r_{i+1}-r_i$，稳态下 $Q=Q_1=Q_2=Q_3$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=\dfrac{2\pi l(t_1-t_4)}{\dfrac{1}{\lambda_1}\ln\dfrac{r_2}{r_1}+\dfrac{1}{\lambda_2}\ln\dfrac{r_3}{r_2}+\dfrac{1}{\lambda_3}\ln\dfrac{r_4}{r_3}}$ | （4-12） |
| **文字式** | $\text{传热速率}=\dfrac{2\pi\times\text{管长}\times\text{总温差}}{\text{各层}\dfrac{1}{\text{热导率}}\ln\dfrac{\text{外半径}}{\text{内半径}}\text{之和}}$ |  |

单位管长：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{Q}{l}=\dfrac{2\pi(t_1-t_4)}{\sum_{i}\dfrac{1}{\lambda_i}\ln\dfrac{r_{i+1}}{r_i}}$ | （4-13） |
| **文字式** | $\text{单位管长传热速率}=\dfrac{2\pi\times\text{总温差}}{\text{各层}\dfrac{1}{\text{热导率}}\ln\dfrac{\text{外半径}}{\text{内半径}}\text{之和}}$ |  |

也可写成 $Q=\Delta t/\left(\sum b_i/(\lambda_i A_{mi})\right)$，各层用各自的对数平均面积。

**例4-4**：φ60×3.5 钢管 + 40 mm 氧化镁粉（$\lambda=0.07$）+ 20 mm 石棉（$\lambda=0.15$），管内壁 500 ℃、最外层 80 ℃、管 $\lambda=45$ → $q_1=191$ W/m；界面温度 $t_3=132$ ℃。

## 判断

- 圆筒壁的"面积随半径变"使热阻不再是 $b/(\lambda A)$ 的单值，对数平均面积就是把变面积积分后的等效面积；$r_2/r_1<2$ 时退化为算术平均，是因为此时对数与算术平均的相对误差已小于工程精度。
- 保温层越厚、$r_2/r_1$ 越大，对数平均面积偏离算术平均越多——所以大口径薄壁管可以用算术平均，厚保温层则必须用对数平均，否则会高估散热。

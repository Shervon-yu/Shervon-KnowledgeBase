# 圆筒轴向压缩许用应力的计算

适用范围：$5\le R_o/\delta_e\le800$ 的圆筒（`#L794`）。

## 理想弹性临界应力（式3）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{cr}=\dfrac{1}{\sqrt{3(1-\nu^2)}}E^t\dfrac{\delta_e}{R_o}$ | （3） |
| **文字式** | $\text{理想弹性临界应力}_{\text{【MPa】}}=\dfrac{1}{\sqrt{3(1-\text{泊松比}^2)}}\times\text{设计温度弹性模量}_{\text{【MPa】}}\times\dfrac{\text{有效厚度}_{\text{【mm】}}}{\text{外半径}_{\text{【mm】}}}$ |  |

$\nu$ 取 0.3 时系数约 0.605。

## 三个无量纲参数

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\beta=\dfrac{R_{eL}^{t}}{\sigma_{cr}},\qquad \omega=\dfrac{L}{\sqrt{R_o\delta_e}}$ | （4）（5） |
| **文字式** | $\text{塑性影响系数}=\dfrac{\text{设计温度屈服强度}}{\text{理想弹性临界应力}},\qquad \text{结构特征参数}=\dfrac{\text{圆筒长度}}{\sqrt{\text{外半径}\times\text{有效厚度}}}$ |  |

$\omega_E$、$\omega_P$ 是第二/第三类屈曲、第一/第二类屈曲的分界（式6、式7，形式同式5 乘以 $\sqrt{1.2E^t/R_{eL}^t}$ 与 $\sqrt{0.2E^t/R_{eL}^t}$）。

## 临界应力 $\sigma_{acr}$（式8~10）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{acr}=R_{eL}^{t}\ (\beta\le0.2);\quad \sigma_{cr}(-0.020+1.124\beta-0.254\beta^2)\ (0.2<\beta\le1.2);\quad \sigma_{cr}(1.012+2.226e^{-\omega/2.220})\ (\beta>1.2)$ | （8）（9）（10） |
| **文字式** | $\text{临界应力}=\text{屈服强度};\quad \text{弹性临界应力}\times\text{塑性修正};\quad \text{弹性临界应力}\times\text{长圆筒修正}$ |  |

## 折减因子 ρ（式11~13）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho=0.9\ (\omega\le\omega_P);\quad (0.207+0.602e^{-0.067\omega_E})\dfrac{\omega-\omega_P}{\omega_E-\omega_P}+\dfrac{0.9(\omega_E-\omega)}{\omega_E-\omega_P}\ (\omega_P<\omega\le\omega_E);\quad 0.207+0.602e^{-0.067\omega}\ (\omega>\omega_E)$ | （11）（12）（13） |
| **文字式** | $\text{折减因子}=0.9;\quad \text{两点间线性插值};\quad \text{长筒指数衰减}$ |  |

## 许用压缩应力（式14）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[\sigma]_{cr}^{t}=\dfrac{\sigma_{acr}\rho}{n_{ab}},\quad n_{ab}=2.0$ | （14） |
| **文字式** | $\text{许用轴向压缩应力}_{\text{【MPa】}}=\dfrac{\text{临界应力}\times\text{折减因子}}{2.0}$ |  |

最终取 $[\sigma]_{cr}^t$ 与 $[\sigma]^t$ 的**较小者**（`#L956`）。

## 判断

- 这条路是"临界应力 × 折减因子 ÷ 2.0"，折减因子 ρ 已经把几何缺陷与屈曲类别差异折进去，**不要再另加安全系数**；
- $\beta$ 小 → 屈服控制（式8）；$\beta$ 大 → 弹性屈曲控制（式10）；中间是塑性修正段（式9）；
- $\omega$ 小（短粗筒）取 ρ=0.9，$\omega$ 大（细长筒）ρ 降到 0.2 附近——细长塔器是这条线的主战场；
- 与 150.3 外压稳定性校核分工：外压用 B 值/A 值曲线法，轴向压缩（如塔器自重、地震）用本节。

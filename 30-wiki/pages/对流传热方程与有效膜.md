# 对流传热方程与有效膜

## 壁面附近的温度分布（`#L6105-#L6109`）

两流体沿间壁两侧平行流动，传热方向垂直于流动方向。湍流时，从湍流主体到壁面依次为：湍流主体 → 过渡区 → **层流底层** → 壁面。

- 层流底层内热量靠**导热**传递；多数流体 $\lambda$ 小，故该层热阻大、温度梯度大；
- 过渡区内导热与对流共同作用；
- 湍流主体内质点剧烈混合，热阻很小、温度梯度小。

**结论：对流传热的热阻主要集中在层流底层。**

## 有效膜模型（`#L6115`）

湍流主体的最高/最低温度不易测定，工程上用流体平均温度（热流体 $T$、冷流体 $t$）代替。这一处理等价于：把过渡区与湍流主体的热阻全部叠加到层流底层上，在壁面附近构成一层厚度 $\delta$ 的**有效膜**，膜内层流、膜外湍流——即**膜理论模型**。

湍动程度越大，有效膜越薄，同样温差下对流传热速率越大。

## 对流传热速率方程（`#L6117-#L6127`）

用 $\alpha$ 代替 $\lambda/\delta$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=\alpha A\Delta t=\dfrac{\Delta t}{\dfrac{1}{\alpha A}}$ | （4-14） |
| **文字式** | $\text{对流传热速率}_{\text{【W】}}=\text{对流传热系数}\times\text{传热面积}\times\text{对流传热温差}$ |  |

- 又称**牛顿冷却公式**；
- $\Delta t$：热流体侧 $T-T_w$，冷流体侧 $t_w-t$；
- $\alpha$：对流传热系数（膜系数），W/(m²·K)。

方程把复杂的对流传热写成"推动力/热阻"的简单形式，但 $\alpha$ 本身仍需由具体条件求取——这是对流传热问题的核心。

**例4-5**：φ25×2.5 管、长 2 m、水 30→50 ℃、$\alpha=2000$ W/(m²·K)、$Q=2500$ W → $A=\pi\times0.02\times2=0.126$ m²，由 $2500=2000\times0.126\times(t_w-40)$ 得 $t_w=49.9$ ℃。

## 判断

- 有效膜不是真实存在的膜，而是把"分布热阻"折算成"集中热阻"的等效厚度；它的价值在于让 $\alpha$ 有了物理解释：$\alpha\approx\lambda/\delta$，于是"提高流速→减薄 $\delta$→提高 $\alpha$"这条工程直觉成立。
- 因为 $\alpha$ 随流动截面变化（进出口温度不同），换热器计算要用管长平均的 $\alpha$，这解释了为什么关联式都强调"平均"与"定性温度"。

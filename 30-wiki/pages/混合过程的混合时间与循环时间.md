# 混合过程的混合时间与循环时间

循环时间：流体质点在搅拌作用下循环回到原出发点所需的时间（`#L3121`）。

## 混合时间与循环时间的比例

| 场合 | 混合时间 / 循环时间 |
|:---|:---|
| 有挡板的湍流搅拌 | 3~4 倍 |
| 湍流喷射混合 | ≈1 倍 |
| 无挡板的层流混合 | 8~10 倍 |

（`#L3121`）

## 体积效应

混合时间通常是定性长度与体积的指数函数（`#L3123-#L3131`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\theta_{\mathrm{M}}=k_1 L^{a}\mathrm{e}^{k_2 V}$ | （3-7） |
| **文字式** | $\text{混合时间}_{\text{【s】}}=\text{常数}_1\times\left(\text{定性长度}_{\text{【m】}}\right)^{\text{指数}}\times\mathrm{e}^{\text{常数}_2\times\text{体积}_{\text{【m³】}}}$ |  |

给定设备 $k_1$、$k_2$ 为常数。$k_2$ 很小（多数体系）时体积效应可忽略，混合时间退化为湍流表达式（3-6）；$k_2$ 或 $V$ 较大时 $\theta_M\propto \mathrm{e}^{k_2V}$，体积一大混合时间急剧增加，设计变得困难（`#L3131-#L3133`）。

## 设计含义

- **设计得当**：混合行为不因加料方式、示踪剂加入量、流体性质改变而明显变化。
- **设计不当**：上述每个因素都会改变混合行为（`#L3133`）。
- 实验室小设备总是混得好且与加料位置无关，但这一效果与功耗很难在工业规模重现；工业设备里混合速率大为下降，且与加料位置有关（`#L3135`）。

## 工程结论

1. 放大时不能按几何相似直接放大混合时间，必须按（3-7）核对体积项；
2. 大釜要靠结构（多桨、导流筒、挡板、加料位置）压住体积效应，见 [[混合过程强化方法]]；
3. 混合时间的测量方法见 [[混合时间的测量方法]]。

# 压力修正法与SIMPLE算法

## ADI：二维隐式拆成两条三对角（§6.7）

二维隐式格式每步要解一个块三对角（或五对角）大方程组，直接解代价高。ADI（交替方向隐式）把时间步劈成两个半步（式 6-62～6-67，＃L5224-5268）：

- 前半步：$x$ 方向取隐式、$y$ 方向显式（式 6-64，＃L5234）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{T_{i,j}^{n+1/2}-T_{i,j}^{n}}{\Delta t/2}=\alpha\dfrac{T_{i+1,j}^{n+1/2}-2T_{i,j}^{n+1/2}+T_{i-1,j}^{n+1/2}}{(\Delta x)^2}+\alpha\dfrac{T_{i,j+1}^{n}-2T_{i,j}^{n}+T_{i,j-1}^{n}}{(\Delta y)^2}$ | （6-64） |
| **文字式** | 前半步只在 $x$ 方向隐式，$y$ 方向用旧层显式 |  |

- 后半步：$y$ 方向隐式、$x$ 方向用半步结果（式 6-66，＃L5264）。
- 每个半步只含一条网格线上的未知量，系数矩阵是三对角（式 6-65、6-67，＃L5240/5268），用[[托马斯算法]] 直接解（$O(N)$）。

ADI 对二维热传导是二阶精度、无条件稳定；代价是引入了中间步，边界条件的半步处理要小心。

## 不可压 N-S 的麻烦（§6.8）

不可压连续性方程 $\nabla\cdot\boldsymbol{V}=0$（式 6-68，＃L5308）里没有时间导数；动量方程（6-76～6-80，＃L5350-5368）里有 $\partial p/\partial x$，但压力没有自己的推进方程。于是不能像可压流那样把 $(\rho,\rho u,\rho v,e)$ 一起向前推——压力只能由"速度场必须满足连续性"这个约束反求（#L5296）。

## 交错网格（§6.8.2）

若压力和速度都放在同一套网格点上，中心差分的连续性方程会出现棋盘式压力振荡（#L5426）。交错网格把压力放在网格中心（实心点）、$u$ 放在 $x$ 方向面心、$v$ 放在 $y$ 方向面心（图 6-15，＃L5430），连续性方程变成（式 6-85，＃L5438）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{u_{i+1/2,j}-u_{i-1/2,j}}{\Delta x}+\dfrac{v_{i,j+1/2}-v_{i,j-1/2}}{\Delta y}=0$ | （6-85） |
| **文字式** | 面心速度的差商之和为零 |  |

这样压力梯度正好用相邻两个压力点的差分，棋盘振荡被消除（#L5436）。

## 压力修正与 SIMPLE（§6.8.3–6.8.5）

思路：猜一个压力场 $p^*$，代入动量方程解出 $u^*$、$v^*$；它们一般**不满足**连续性。把真压力写成（式 6-86，＃L5452）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p=p^{*}+p^{\prime}$ | （6-86） |
| **文字式** | $\text{压力}=\text{猜测压力}+\text{压力修正量}$ |  |

动量方程中压力梯度换成 $p^*+p'$（式 6-88，＃L5474），要求修正后的速度满足连续性，就得到 $p'$ 的泊松方程（式 6-104、6-105，＃L5641-5645）——**压力修正公式就是压力泊松方程的差分形式**（#L5641）。

SIMPLE（Semi-Implicit Method for Pressure-Linked Equations，Patankar & Spalding，＃L5296、＃L5649）五步：

1. 在交错网格上给定初始 $p^*$、$u^*$、$v^*$（＃L5651）；
2. 用 $p^*$ 解动量方程，得新的 $u^*$、$v^*$；
3. 由连续性导出并解 $p'$ 的泊松方程（式 6-104）；
4. 用 $p'$ 修正压力与速度：$p=p^*+p'$，速度按 $p'$ 的梯度修正；
5. 以修正后的场为新的猜测，回到第 2 步，直到连续性残差足够小。

"半隐式"指推导中令 $A'$、$B'$、$(\rho u')^n$、$(\rho v')^n$ 为零，使 $p'$ 方程只含五个网格点，不必全场联立（＃L5649）。

边界条件：入口给定速度、出口给定压力（或零梯度）、壁面速度为零（无滑移）、压力法向零梯度（＃L5683）。

## 适用边界

- SIMPLE 是迭代法，收敛速度依赖松弛因子；压力修正方程的求解本身又可用 ADI 或 SOR。
- 交错网格编程麻烦（三套下标），但避免了棋盘压力；同位网格要靠 Rhie-Chow 插值才能达到同样效果（书里未展开）。
- 压力修正法的思想只针对不可压（或低马赫）流动；可压流用密度、能量方程闭合，不需要压力泊松方程。
- 第 9 章库埃特流算例就是用它：Crank-Nicolson 推进 + 交错网格 + 压力修正，$\Delta t$ 可取到 $E=4000$ 仍稳定（＃L9548、＃L10071）。

## 判断

压力修正法的关键不是"迭代"，而是把连续性方程当成压力的方程：压力没有演化方程，它的值由"速度场必须无散"这一约束唯一确定。SIMPLE 之所以叫半隐式，是因为它把这个全局约束近似成局部的五点关系——这是它能实用的原因，也是它收敛慢的原因。

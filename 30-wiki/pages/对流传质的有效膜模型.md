# 对流传质的有效膜模型

## 湿壁塔中的浓度分布（`#L9304-#L9322`）

直立圆管，吸收剂自上而下呈液膜沿壁流下，混合气自下而上，逆流接触——湿壁塔（图5-11a）。取一小段看任意截面：

- 气相主体湍流 → 涡流混合使主体内分压几乎水平；
- 靠近界面有一层**层流膜**（厚度 $Z_G'$），溶质只能靠分子扩散通过 → 分压在此迅速下降；
- 把层流膜内的分压梯度线延长、与主体分压水平线交于 G 点，G 到界面的距离 $Z_G$ 即**有效层流膜（虚拟膜）**厚度。

这样做等于：把单相内的全部传质阻力都集中在一层虚拟膜里。这就是**膜模型**（film model）的基础。

## 气相传质速率方程（`#L9324-#L9342`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=\dfrac{D}{RTZ_G}\cdot\dfrac{p}{p_{Bm}}(p_{AG}-p_{Ai})$ | （5-20） |
| **文字式** | $\text{气相传质速率}=\dfrac{\text{扩散系数}}{\text{气体常数}\times\text{温度}\times\text{气膜厚度}}\times\dfrac{\text{总压}}{\text{B分压对数均值}}\times(\text{气相主体分压}-\text{界面分压})$ |  |

令

|  |  |  |
|:---|:---:|--:|
| **符号式** | $k_G=\dfrac{D}{RTZ_G}\cdot\dfrac{p}{p_{Bm}}$ | （5-21 内定义） |
| **文字式** | $\text{气膜传质系数}=\dfrac{\text{扩散系数}}{\text{气体常数}\times\text{温度}\times\text{气膜厚度}}\times\text{漂流因子}$ |  |

则

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=k_G(p_A-p_i)=\dfrac{p_A-p_i}{1/k_G}$ | （5-21） |
| **文字式** | $\text{传质速率}=\text{气膜传质系数}\times(\text{主体分压}-\text{界面分压})=\dfrac{\text{气膜传质推动力}}{\text{气膜传质阻力}}$ |  |

$k_G$ 单位 kmol/(m²·s·kPa)。溶质很稀时 $p/p_{Bm}\approx1$，$k_G$ 可视为与浓度无关。

## 液相传质速率方程（`#L9344-#L9366`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=\dfrac{D}{Z_L}\cdot\dfrac{c}{c_{Bm}}(c_{Ai}-c_{AL})=k_L(c_i-c_A)$ | （5-22）、（5-24） |
| **文字式** | $\text{传质速率}=\dfrac{\text{扩散系数}}{\text{液膜厚度}}\times\dfrac{\text{总浓度}}{\text{B浓度对数均值}}\times(\text{界面浓度}-\text{液相主体浓度})=\text{液膜传质系数}\times(\text{液膜推动力})$ |  |

令 $k_L=\dfrac{D}{Z_L}\cdot\dfrac{c}{c_{Bm}}$（5-23），单位 m/s 或 kmol/(m²·s·kmol/m³)。

## 六种写法（`#L9394-#L9414`）

同一速率可用不同推动力表示，系数随之换算：

| 气相 | 液相 |
|:--|:--|
| $N_A=k_G(p_A-p_i)$（5-25） | $N_A=k_L(c_i-c_A)$（5-28） |
| $N_A=k_y(y-y_i)$（5-26） | $N_A=k_x(x_i-x)$（5-29） |
| $N_A=k_Y(Y-Y_i)$（5-27） | $N_A=k_X(X_i-X)$（5-30） |

## 判断

- 膜模型的价值不在"膜真的那么薄"，而在把湍流折合成一个可测的系数 $k_G$、$k_L$——它和对流传热系数 α 完全同构（$q=\alpha(T-t_w)$ 对照 $N_A=k_G(p_A-p_i)$），因此传热与传质的实验关联式可以互相借鉴（$Nu\leftrightarrow Sh$、$Pr\leftrightarrow Sc$）。
- 膜厚 $Z_G$ 无法直接测，所以 $k_G$ 只能实验测定、整理成特征数关联式，不能从 $Z_G$ 算出来。

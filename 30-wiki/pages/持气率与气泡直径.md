# 持气率与气泡直径

## 为什么看这两个量

持气率与气泡大小决定体系的**相界面积**，而界面积是传质的基础（`#L2233`）。传质系数本身另有关联式，但界面积不够时其他都无从谈起。

## 气泡平均直径

气泡大小不一，常用体表面积平均直径 $d_B$ 表示；空气-水系统 $d_B$ 通常 2~5 mm（`#L2235`）。设 $n$ 种尺寸（`#L2237`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{B}=\dfrac{\sum n_{Bi}d_{i}^{3}}{\sum n_{Bi}d_{i}^{2}}$ | （2-85） |
| **文字式** | $\text{气泡平均直径}_{\text{【m】}}=\dfrac{\sum\text{第}i\text{种气泡数}\times\left(\text{第}i\text{种直径}_{\text{【m】}}\right)^{3}}{\sum\text{第}i\text{种气泡数}\times\left(\text{第}i\text{种直径}_{\text{【m】}}\right)^{2}}$ |  |

## 比界面积

|  |  |  |
|:---|:---:|---:|
| **符号式** | $a=\dfrac{6\Phi}{d_{B}}$ | （2-86） |
| **文字式** | $\text{比界面积}_{\text{【1/m】}}=\dfrac{6\times\text{持气率}}{\text{气泡平均直径}_{\text{【m】}}}$ |  |

## $d_B$ 的三个体系式

气体-纯液体（`#L2249`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{B}=4.15\left[\dfrac{\sigma^{0.6}}{\left(\dfrac{P_{G}}{V_{L}}\right)^{0.4}\rho_{c}^{0.2}}\right]\Phi^{0.5}+9\times10^{-4}$ | （2-87） |
| **文字式** | $\text{气泡直径}_{\text{【m】}}=4.15\times\left[\dfrac{\text{表面张力}_{\text{【N/m】}}^{0.6}}{\left(\dfrac{\text{通气功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.4}\times\text{连续相密度}_{\text{【kg/m³】}}^{0.2}}\right]\times\text{持气率}^{0.5}+9\times10^{-4}$ |  |

气体-电解质溶液（`#L2255`，式2-88）：同结构，$\Phi$ 的指数为 0.4，再乘 $\left(\mu_d/\mu_c\right)^{0.25}$；系数 2.25。
气体-醇溶液（`#L2259`，式2-89）：$\Phi$ 的指数 0.65，再乘 $\left(\mu_d/\mu_c\right)^{0.25}$；系数 1.90。

三者说明：**持气率越高、气泡越大**，但不同体系的敏感度不同（醇类最强）。

## 持气率

$\Phi$ 定义为通气后分散体系中气体容积与气-液分散体系容积之比（`#L2271`）。

发泡体系（`#L2275`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Phi=0.0051\left(\dfrac{P}{V_{L}}\right)^{0.57}V_{G}^{0.24}$ | （2-90） |
| **文字式** | $\text{持气率}=0.0051\times\left(\dfrac{\text{功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.57}\times\text{表观气速}_{\text{【m/s】}}^{0.24}$ |  |

不生成泡沫的体系用表2-15（`#L2277-#L2284`）：

| 研究者 | 式号 | 关联式结构 |
|:---|:---|:---|
| Loiseau | 2-91 | $\Phi\propto(V_G/\sigma)^{0.36}(P/V_L)^{0.27}\mu^{-0.056}$ |
| Yung | 2-92 | $\Phi=0.52N_A^{0.5}\left(\rho N^{2}d^{3}/\sigma\right)^{0.65}(d/D)^{1.4}$ |
| 高正明 | 2-93 | $\Phi=0.195(P/V_L)^{0.28}V_G^{0.56}D^{0.45}$ |
| 张志斌 | 2-94 | $\Phi=C(P_G/V_L)^{0.35}V_G^{0.55}$，$C=0.053\sim0.059$ |

## 用法链条

1. 由功率关联式（见 [[通气搅拌功率]]）得 $P_G/V_L$；
2. 选 $\Phi$ 关联式算持气率，注意是否发泡；
3. 选对应体系式算 $d_B$；
4. 由式（2-86）得比界面积 $a$，再乘液相传质系数得体积传质系数。

这几步均为经验关联，体系一变（电解质、醇、发泡）系数就变，不能跨体系套用。

# 原书 §8.3：持气量与接触时间

## Calderbank 的两项式

六叶涡轮通气容器（`#L9458`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi=\left(\dfrac{v_s\phi}{v_t}\right)^{1/2}+0.0216\left(\dfrac{P_v^{0.4}\rho_c^{0.2}}{\sigma^{0.6}}\right)\left(\dfrac{v_s}{v_t}\right)^{1/2}$ | （8.35） |
| **文字式** | 持气量 = 鼓泡项（气速/终端速度）+ 搅拌项（功率-表面张力群） |  |

适用区间与式(8.31) 相同：$(d^{2}n\rho_c/\mu_c)^{0.7}(dn/v_s)^{0.3}<20000$（`#L9462`）。

**极限校核**：$P_v\to0$ 时 $\phi$ 应等于 $v_s/v_t$（`#L9464`、`#L9466`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi=\dfrac{\theta v_s}{H'}=\dfrac{(H'/v_t)v_s}{H'}=\dfrac{v_s}{v_t}$ | （8.36） |
| **文字式** | 纯鼓泡时持气量 = 气速/气泡终端速度（等价于"气泡停留时间×气速/液层高度"） |  |

$P_v$ 增大时第一项可略（`#L9470`、`#L9474`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi\propto P_v^{0.4}v_s^{0.5}$;\qquad $\phi=KP_v^{0.47}v_s^{0.53}$ | （8.37）（8.38） |
| **文字式** | 搅拌主导时持气量 ∝ 功率^0.47 × 气速^0.53；指数几乎对半，说明**功率与气速对持气量的贡献接近等价** |  |

## 接触时间与持气量的关系

平均液高 $H'$、气泡平均停留时间 $\theta$、表观气速 $v_s$（`#L9478`）得 $\theta=(\phi/v_s)H'$，代入(8.38)得**单位液层高度的接触时间**（`#L9480`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\theta'=\dfrac{\theta}{H'}=\dfrac{\phi}{v_s}=K\left(\dfrac{P_v}{v_s}\right)^{0.47}$ | （8.39） |
| **文字式** | 单位液高的接触时间 ∝ (功率/气速)^0.47；$K=1.3\sim1.6$（随容器结构） |  |

**这条结论反直觉**：气速增加 50%，持气量只增 25%，而单位液高接触时间**减少 17%**（`#L9482`）——**加大气速是拿接触时间换界面面积**，净效果要看传质系数与推动力谁占优。

## Van Dierendonck 的分体系式

### a) 纯液体

条件 $\phi\le0.2$、$n\ge n_0^*$、$0<v_s<0.05$ m/s、$H/D=1$（`#L9490`、`#L9494`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi=0.31\left[\dfrac{\mu v_s}{\sigma}\right]^{2/3}\left[\dfrac{\rho\sigma^{3}}{g\mu^{4}}\right]^{1/6}+0.45\dfrac{(n-n_0^{*})d^{2}}{D(gD)^{1/2}}$ | （8.40） |
| **文字式** | 持气量 = 0.31×毛细数^2/3×物性群^1/6 + 0.45×超额转速的弗鲁德项 |  |

### b) 电解质溶液

条件 $\phi\le0.3$、$0.003<v_s<0.03$ m/s、$n\ge n_0$、$H/D=1$（`#L9498`、`#L9502`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\phi=0.075\left[\dfrac{\mu(n-n_0)d^{2}}{D\sigma}\right]\left[\dfrac{\rho\sigma^{3}}{g\mu^{4}}\right]^{1/4}$ | （8.41） |
| **文字式** | 电解质液中持气量与气速无关，只随超额转速线性增长 |  |

**电解质与纯液体的结构完全不同**：纯液体有独立的鼓泡项（气速项），电解质液没有——因为电解质抑制凝并、气泡更小更稳定，鼓泡本身就能带住气。

## 持气量沿轴向不均匀

图8.11（`#L9476`）：

- **叶轮与自由表面之间的中间高度上任一位置持气量最大**；
- 叶轮附近及叶轮以下的持气量与转速**基本无关、保持恒定**。

这与 §8.2.5 的界面面积双峰分布位置一致：下部区域靠鼓泡、上部区域靠叶轮分散，两者机理不同。

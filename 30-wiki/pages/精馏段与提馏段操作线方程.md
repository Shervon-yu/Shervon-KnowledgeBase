# 精馏段与提馏段操作线方程

## 精馏段（`#L11700-#L11730`）

对进料以上塔段作物料衡算：$V=L+D$、$Vy_n=Lx_{n-1}+Dx_D$。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y_n=\dfrac{L}{V}x_{n-1}+\dfrac{D}{V}x_D$ | （6-32） |
| **文字式** | $\text{上升蒸气组成}=\dfrac{\text{液量}}{\text{汽量}}\times\text{下降液体组成}+\dfrac{\text{馏出液量}}{\text{汽量}}\times\text{馏出液组成}$ |  |

回流比 $R=L/D$（6-34）代入后：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y_n=\dfrac{R}{R+1}x_{n-1}+\dfrac{x_D}{R+1}$，$\dfrac{L}{V}=\dfrac{R}{R+1}$ | （6-35）（6-36） |
| **文字式** | 精馏段液汽比 = 回流比/(回流比+1) |  |

R 增大 → L/V 增大 → 上升汽相纯度提高。

## 提馏段（`#L11736-#L11778`）

对进料板以下作物料衡算：$L'=V'+W$、$L'x_n=V'y_{n+1}+Wx_W$。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y_{n+1}=\dfrac{L'}{V'}x_n-\dfrac{W}{V'}x_W$ | （6-39） |
| **文字式** | $\text{上升蒸气组成}=\dfrac{\text{提馏段液量}}{\text{提馏段汽量}}\times\text{下降液体组成}-\dfrac{\text{釜液量}}{\text{提馏段汽量}}\times\text{釜液组成}$ |  |

汽相回流比 $R'=V'/W$（蒸出比）代入：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y_{n+1}=\dfrac{R'+1}{R'}x_n-\dfrac{x_W}{R'}$，$\dfrac{L'}{V'}=\dfrac{R'+1}{R'}$ | （6-40）（6-41） |
| **文字式** | 提馏段液汽比 = (汽相回流比+1)/汽相回流比 |  |

## R′ 与 R、q 的关系（`#L11840-#L11856`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $R'W=(R+1)D+(q-1)F$，$R'=(R+1)\dfrac{x_F-x_W}{x_D-x_F}+(q-1)\dfrac{x_D-x_W}{x_D-x_F}$ | （6-43a/b）（6-44） |
| **文字式** | 釜汽相回流比 = (回流比+1)×馏出液/釜液 + (热状态参数−1)×进料/釜液 |  |

## 例6-7（`#L11780-#L11838`）

苯-甲苯，$\alpha$=2.46、$F$=250、$x_F$=0.4、$D$=100、$x_D$=0.97、$L$=200、$q$=1.2：

- 第一板：$y_1=x_D=0.97$ → $x_1=0.929$；
- $R$=2 → $y_2=\frac{2}{3}\times0.929+\frac{0.97}{3}=0.943$；
- $V$=300、$V'=300+0.2\times250=350$、$W$=150 → $R'=2.33$、$x_W=\frac{250\times0.4-100\times0.97}{150}=0.02$；
- 提馏段操作线：$y=1.43x-0.00857$；
- 釜上一层板：$y_W=\frac{2.46\times0.02}{1+1.46\times0.02}=0.0478$ → $x=\frac{0.0478+0.00857}{1.43}=0.0394$。

## 例6-8（`#L11858-#L11868`）

正戊烷-正己烷，$R$=1.6、$x_F$=0.4、$x_D$=0.95、$x_W$=0.05、$q$=1.22：
$R'=(1.6+1)\frac{0.4-0.05}{0.95-0.4}+(1.22-1)\frac{0.95-0.05}{0.95-0.4}=2.01$ → $y=1.5x-0.0249$。

## 判断

- 两条操作线都是**直线**，因为恒摩尔流下 L/V、L'/V' 是常数；一旦 q 或 R 变，斜率才变。
- 精馏段线的截距 $x_D/(R+1)$ 是图解法作图的"抓手"；提馏段线则必须通过 $W$ 点 $(x_W,x_W)$。
- 提馏段线**在平衡线下方会更靠近**——它离开 W 点向上，与精馏段线交于 q 线；交点位置由进料热状态决定。
- 例6-8 说明：只要给了 q 和 R，不必知道 F、D、W 的具体值也能写出提馏段线（用 6-44）。

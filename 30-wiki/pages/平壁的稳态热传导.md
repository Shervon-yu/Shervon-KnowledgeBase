# 平壁的稳态热传导

## 单层平壁（`#L5885-#L5913`）

壁厚 $b$、面积 $A$、$\lambda$ 为常数，两侧温度 $t_1$、$t_2$ 恒定，一维稳态。由傅里叶定律积分：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=\dfrac{\lambda}{b}A(t_1-t_2)$ | （4-5） |
| **文字式** | $\text{传热速率}_{\text{【W】}}=\dfrac{\text{热导率}_{\text{【W/(m·K)】}}}{\text{壁厚}_{\text{【m】}}}\times\text{传热面积}_{\text{【m²】}}\times\text{温差}_{\text{【K】}}$ |  |

写成"推动力/热阻"形式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=\dfrac{t_1-t_2}{b/(\lambda A)}=\dfrac{\Delta t}{R}$ | （4-5a） |
| **文字式** | $\text{传热速率}=\dfrac{\text{传热推动力}}{\text{热阻}}$ |  |

热流密度：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $q=\dfrac{Q}{A}=\dfrac{\lambda}{b}(t_1-t_2)$ | （4-6） |
| **文字式** | $\text{热流密度}_{\text{【W/m²】}}=\dfrac{\text{热导率}}{\text{壁厚}}\times\text{温差}$ |  |

热阻 $R=b/(\lambda A)$：壁越厚、面积越小、$\lambda$ 越小，热阻越大。

**例4-1**：240 mm 砖壁、内 600 ℃、外 150 ℃、$\lambda=0.60$ → $q=0.60/0.24\times450=1125$ W/m²。

## 多层平壁（`#L5931-#L5945`）

三层平壁，各层厚度 $b_i$、$\lambda_i$ 为常数，层间接触良好、界面温度相等，面积均为 $A$。稳态下穿过各层热量相等：$Q=Q_1=Q_2=Q_3$。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=\dfrac{\Delta t}{\sum_{i=1}^{3}\dfrac{b_i}{\lambda_i A}}=\dfrac{\text{总推动力}}{\text{总热阻}}$ | （4-7） |
| **文字式** | $\text{传热速率}=\dfrac{\text{总温差}}{\text{各层}\dfrac{\text{壁厚}}{\text{热导率}\times\text{面积}}\text{之和}}$ |  |

要点：总推动力=各层温差之和；总热阻=各层热阻之和；各层 $\Delta t_i/R_i$ 相等且等于 $\Delta t/\sum R_i$；**热阻大的层分到的温差也大**。

## 例4-2（`#L5947-#L5989`）

燃烧炉三层壁：耐火砖 150 mm/1.06、保温砖 310 mm/0.15、建筑砖 240 mm/0.69；内壁 1000 ℃、耐火砖与保温砖界面 946 ℃。

- $q=\lambda_1/b_1\times(1000-946)=1.06/0.15\times54=381.6$ W/m²；
- 保温砖层：$381.6=0.15/0.31\times(946-t_3)$ → $t_3=157.3$ ℃；
- 建筑砖层：$381.6=0.69/0.24\times(157.3-t_4)$ → $t_4=24.6$ ℃。

温度差/热阻对照：耐火砖 Δt=54、R=0.142；保温砖 Δt=788.7、R=2.07；建筑砖 Δt=132.7、R=0.348 → 温差与热阻成正比。

## 判断

- 多层壁的"温差按热阻分配"是串联网状结构的必然结果，工程上可用它反推界面温度：测外壁温度+已知各层 $\lambda$、$b$，即可估内部温度，这是炉墙测温的常用手段。
- 保温砖承担了近 80% 的温差，说明多层壁设计的核心是"把热阻集中在最便宜、最耐温的那一层"，而不是平均分配。

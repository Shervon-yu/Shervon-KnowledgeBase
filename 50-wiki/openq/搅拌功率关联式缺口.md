# 搅拌功率关联式缺口

**问题**：三本书没有一条搅拌功率的定量关联式；要算 P（W）就得另找文献。

## 缺口清单

| 需要的式子 | 库里状态 |
|:---|:---|
| 功率准数定义 N_p=P/(ρN³D⁵) | 无（三本书都没出现） |
| N_p = f(Re, Fr, 桨型, 挡板) | 无 |
| 通气功率比 P_g/P₀ = f(Q_G, N, D) | 无 |
| 单位体积功率 P/V 与 k_La 关联 | 无 |
| 临界搅拌速度解析式 | 无（只有 3 个实验点，表 5.1） |

现有可用物（气液搅拌釜γ-CT 书）：
- F₁=Q_G/(ND_i³)、F_r=N²D_i/g 两个无量纲数定义 #L2557
- 表 5.1：9.44 / 18.88 / 28.32 L/min → 350 / 470 / 530 r/min（标准 200×240 mm Rushton 釜）#L2569

## 影响

1. 无法回答「这台釜配这桨要多少 kW」类问题——只能回答「这个通气量下临界转速约多少」。
2. 无法做放大（等 P/V、等桨尖速度）判断。
3. 与 [[搅拌功率关联式对比]] 的结论一致：这是覆盖缺口，不是口径矛盾。

## 要闭合需要

- 入一本带功率关联式的教材/手册（如搅拌反应器设计类专著），或 Rushton/Michel-Miller 类原始论文合集；入库后建 `concepts\搅拌功率` 页，把本页降级为 `supersedes`。
- 在此之前，凡涉及功率的答复必须回落到本页，不得凭常识写公式。

## 现状决定

保持 open。已写入 [[气液分散-搅拌功率]] 首段「诚实边界」。

# 液液分散操作与搅拌要求

## 四个目的

1. 通过液-液分散使相界面增加；
2. 使分散相液滴外部的扩散阻力减小；
3. 产生湍流促进浓度和温度均一化；
4. 使液滴反复破碎凝并，从而促进滴间传质（`#L2332-#L2338`）。

## 谁分散在谁里

密度大的称重相，另一相为轻相。绝大多数场合把**轻相分散在重相中**（油分散于水）；一定条件下也可重相分散于轻相，即逆分散（`#L2344`）。

## 搅拌器位置与尺寸（无挡板）

通常应把搅拌器置于**被分散相**内（`#L2346`）：

| 项目 | 推荐值 |
|:---|:---|
| 叶轮直径 | $d=D/3$ |
| 叶宽 | $b=(0.05\sim0.1)D$ |
| 最佳偏心距（平底/碟形底容器） | $E_A=d/4$ |
| 使液滴尺寸最小的偏心距 | $E_B=d/2$ |

尺寸太小则大量轻相停留在液面边缘；太大则轻相停留在搅拌轴周围难以分散——两头都不好（`#L2346`）。

## 加挡板时

永田进治建议的两种挡板布置（图2-18），最佳技术条件（`#L2348`）：

| 项目 | 推荐值 |
|:---|:---|
| 挡板距底/位置参数 | $S_B=d/2$ |
| 挡板与壁间隙 | $e_B=d/2$ |
| 挡板宽 | $w_b=(0.07\sim0.10)D$ |
| 最佳叶轮直径（有挡板） | $d=0.4D$ |

## 与气液分散的差别

气液靠圆盘+气穴，液液**不需要中间圆盘**、也不要求一定从底部进料；液液功率输入的重要性低于气液，因为两相密度差小，不会有一相大量聚在搅拌器周围（`#L2553`）。详见 [[液液搅拌设计要点]]。

逆分散见 [[液液逆分散操作]]；平均物性与功率见 [[液液体系平均物性与功率计算]]；放大要点见 [[液液搅拌设计要点]]。

# 原书 §7.1.1：为什么是这些尺寸

## 尺寸背后的两个失败模式

轻液分散于水时（`#L8050`、`#L8054`）：

- 叶轮**太小** → 大量轻液停留**液面边缘**；
- 叶轮**太大** → 轻液停留**搅拌轴周围**，反而分散不掉。

所以最佳直径是"中央与边缘同时能分散"的那个值：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{\text{最佳}}=D/3$（无挡板）;\qquad $b_{\text{最佳}}=(0.05\sim0.1)D$（四叶桨） | （7.1）（7.2） |
| **文字式** | 无挡板时最佳叶轮直径 = 容器直径的三分之一；叶宽 5%~10% 容器直径 |  |

## 偏心安装

平底圆筒容器中偏心轴的位置与叶径、叶高、叶片角**无关**（`#L8064`、`#L8068`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\varepsilon_{\text{最佳}}=d/4$;\qquad $\varepsilon_m=d/2$（滴径最小的偏心） | （7.3）（7.4） |
| **文字式** | 最佳偏心距 = 桨径的四分之一；要滴最细则取桨径的一半 |  |

**碟形底的偏心距与平底相近，但(7.3)(7.4) 对球形底不适用**（`#L8072`）——球底容器的流场没有等效的偏心规律，必须实测。

## C.R.Z. 里会积一坨轻液

圆柱形回转区（C.R.Z.）在轴心，混合效率很差；液液搅拌中**轻液聚集在中轴周围形成分离体**。提高转速只能**减少**这坨分离液，**不能让它消失**（`#L8074`）。这是"叶轮居中永远分不干净"的根本原因。

## 分散轻液的中间挡板

针对 C.R.Z.，作者提出图7.1(a) 的**中间挡板**（不是壁面挡板，而是插在液层中间的两块板，`#L8088`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $(s_B)_{\text{最佳}}=d/2$;\quad $(S_B)_{\text{最佳}}=d/2$;\quad $(B_w)_{\text{最佳}}=0.07\sim0.10D$ | （7.5）（7.6）（7.7） |
| **文字式** | 两挡板的间距与离轴距离都取桨径的一半，板宽 7%~10% 容器直径 |  |

加挡板后最佳叶径变大（`#L8096`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{\text{最佳}}=0.4D$（挡板容器） | （7.8） |
| **文字式** | 有挡板时最佳叶轮直径升到容器直径的四成 |  |

从 $D/3$（0.33）到 $0.4D$ 的变化就是挡板把切向流变成轴向/径向流后，需要更大的扫掠范围。

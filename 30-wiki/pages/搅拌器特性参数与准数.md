# 搅拌器特性参数与准数

## 四个准数

为描述搅拌特性，常用无因次准数关联（`#L4878`）：

| 准数 | 符号 | 代表的物理特性 |
|:---|:---|:---|
| 搅拌雷诺数 | $N_{Re}$ | 黏性力（最重要，其他准数常与它关联） |
| 功率准数 | $N_p$ | 流体动力特性、能耗 |
| 排出流量准数 | $N_{qd}$ | 流体循环特性（排量） |
| 混合准数 | $N_{\theta M}$ | 混合特性（达到规定均匀度所需的无因次时间） |

## 定义与判断标准

$N_{Re}$ 见 [[搅拌雷诺数与流态划分]]（式5-1）。湍流区（$N_{Re}>20000$）时三者基本恒定，可作为特征量：

**$N_p$ 越小、$N_{qd}$ 越大、$N_{\theta M}$ 越小 → 搅拌性能越好**（`#L4898`）。

## 功率与排量的常用形式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=N_{p}\rho N^{3}d^{5}$ | （1-1） |
| **文字式** | $\text{搅拌功率}_{\text{【W】}}=\text{功率准数}\times\text{密度}_{\text{【kg/m³】}}\times\text{转速}_{\text{【r/s】}}^{3}\times\text{桨径}_{\text{【m】}}^{5}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q_{d}=N_{qd}Nd^{3}$ | （4-2） |
| **文字式** | $\text{排量}_{\text{【m³/s】}}=\text{排出流量准数}\times\text{转速}_{\text{【r/s】}}\times\text{桨径}_{\text{【m】}}^{3}$ |  |

（式号见第一章与第四章，$N_{\theta M}=\theta_M N$）

## 用法

- 选型时查湍流区常数值即可比较不同桨型；
- 计算功率用 $N_p$，计算循环/混合时间用 $N_{qd}$、$N_{\theta M}$；
- $N_p/N_{qd}$ 是剪切型/循环型的判别指标（见 [[剪切型与循环型搅拌器]]）。

## 判断

四个准数里只有 $N_{Re}$ 是"状态量"，其余三个是"特性量"。同一台桨在层流区 $N_p\propto Re^{-1}$、湍流区 $N_p$ 恒定，所以**引用 $N_p$ 必须同时说明流态与几何**（$d/D$、$b/D$、挡板数）；不同书上的 $N_p$ 数值不可无条件互换。

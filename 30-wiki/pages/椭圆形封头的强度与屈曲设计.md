# 椭圆形封头的强度与屈曲设计

标准型：$D_i/(2h_i)=2.0$（`#L6184`）。设计走**强度 + 屈曲**两条线，取大值。

## 内压强度厚度（式7-1、7-2）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_c=\dfrac{Kp_cD_i}{2[\sigma]^t\varphi-0.5p_c}$；$\quad \delta_c=\dfrac{Kp_cD_o}{2[\sigma]^t\varphi+(2K-0.5)p_c}$ | （7-1）（7-2） |
| **文字式** | $\text{强度计算厚度}_{\text{【mm】}}=\dfrac{\text{形状系数}\times\text{计算压力}\times\text{内直径}}{2\times\text{许用应力}\times\text{焊接接头系数}-0.5\times\text{计算压力}}$ |  |

形状系数（`#L6210`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K=\dfrac{1}{6}\left[2+\left(\dfrac{D_i}{2h_i}\right)^2\right]$ |  |
| **文字式** | $\text{形状系数}=\dfrac{1}{6}\left[2+\left(\dfrac{\text{内直径}}{2\times\text{内曲面深度}}\right)^2\right]$ |  |

表7-1 关键值：$D_i/2h_i$=2.0 → K=1.00；1.8 → 0.87；2.2 → 1.14；2.4 → 1.29；2.6 → 1.46。比值越大（越扁）K 越大、壁厚越厚。

## 屈曲判别（7.3.2.2）

按 $D_i/(2h_i)$ 与 $D_i/\delta_c$ 查图7-4：落在曲线上或右上方 → **可能屈曲**；左下方 → 不可能屈曲。

## 防屈曲厚度（式7-3、7-4）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_b=D_i\left[\dfrac{p_c}{23R_{eL}^t}\left(\dfrac{D_i}{2h_i}\right)^{1.93}\right]^{0.77}$ | （7-3） |
| **文字式** | $\text{防屈曲厚度}_{\text{【mm】}}=\text{内直径}\times\left[\dfrac{\text{计算压力}}{23\times\text{屈服强度}}\times\left(\dfrac{\text{内直径}}{2\times\text{内曲面深度}}\right)^{1.93}\right]^{0.77}$ |  |

经验法（式7-4）：$D_i/2h_i\le2$ 时 $\delta_b\ge0.0015D_i$；$>2$ 时 $\delta_b\ge0.0030D_i$。

## 最终厚度与允许工作压力（式7-5、7-6）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_h=\max(\delta_c,\delta_b)$（仅当可能屈曲）；$\quad [p_w]=\dfrac{2[\sigma]^t\varphi\delta_{eh}}{KD_i+0.5\delta_{eh}}$；$\quad [p_w]=23R_{eL}^t\left(\dfrac{\delta_{eh}}{D_i}\right)^{1.29}\left(\dfrac{D_i}{2h_i}\right)^{-1.93}$ | （7-5）（7-6） |
| **文字式** | 取强度与防屈曲厚度的较大者；允许工作压力取强度式与屈曲式的**较小者** |  |

## 外压（凸面受压）

按第6章外压球壳法，当量球壳外半径 $R_o=K_1D_o$；表7-2：$D_o/2h_o$=2.0 → $K_1$=0.90（标准椭圆封头），1.0 → 0.50，2.6 → 1.18。

## 判断

- $K$ 的物理含义是"椭球与圆筒的应力放大"：椭球顶点曲率半径 $D_i^2/(2h_i)$ 小于 $D_i/2$，所以薄膜应力比同径圆筒大；
- 内压屈曲是薄壁扁封头的特有失效：内压作用下赤道区受压、过渡区受拉，薄而扁时赤道带先失稳（皱曲），所以有独立的判别图与 $\delta_b$；
- 工程简化：$D_i/2h_i=2.0$ 时 $K=1.0$，式7-1 退化为圆筒式只差 0.5 系数——所以标准椭圆封头壁厚≈圆筒壁厚（略小）；
- 一旦按 7-4 经验法取 $\delta_b$，记得同时用 7-6 校核 $[p_w]$，否则"厚度够了但允许压力不够"仍不合格。

# 热传导-傅里叶定律与平壁导热

## 定义

**热传导**靠分子、原子或自由电子的热运动传递热量，在固体内部、静止流体层内和管壁两侧的滞留底层中是主要方式（#L5786）。**傅里叶定律**：单位时间传导的热量与温度梯度、传热面积成正比，方向与温度梯度相反（#L5814）。比例系数 $\lambda$ 称**导热系数**（热导率），其定义即傅里叶定律的系数形式（#L5824）。

**热阻**：把导热式写成「热量 = 温度差 / 热阻」，分母即热阻，量纲 K/W（#L5905）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=-\lambda A\dfrac{\mathrm{d}t}{\mathrm{d}x}$ | （4.2-1） |
| **文字式** | $\text{导热速率}_{\text{【W】}}=-\text{导热系数}_{\text{【W/(m·K)】}}\times\text{导热面积}_{\text{【m²】}}\times\dfrac{\mathrm{d}\text{温度}}{\mathrm{d}\text{壁厚方向距离}}$ |  |

（式 4-2，傅里叶定律，#L5814；负号表示热流方向与温度梯度相反。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\lambda_{0}\left(1+\alpha t\right)$ | （4.2-2） |
| **文字式** | $\text{导热系数}_{\text{【W/(m·K)】}}=\text{0℃时导热系数}_{\text{【W/(m·K)】}}\times\left(1+\text{温度系数}\times\text{温度}_{\text{【℃】}}\right)$ |  |

（式 4-4，导热系数随温度近似线性变化，#L5877；工程上常取两侧温度的算术平均温度下的 $\lambda$。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=\dfrac{\lambda}{b}A\left(t_{1}-t_{2}\right)$ | （4.2-3） |
| **文字式** | $\text{导热速率}_{\text{【W】}}=\dfrac{\text{导热系数}_{\text{【W/(m·K)】}}}{\text{壁厚}_{\text{【m】}}}\times\text{导热面积}_{\text{【m²】}}\times\left(\text{高温面温度}_{\text{【℃】}}-\text{低温面温度}_{\text{【℃】}}\right)$ |  |

（式 4-5，单层平壁稳态导热，#L5901。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=\dfrac{\Delta t}{R}$，$R=\dfrac{b}{\lambda A}$ | （4.2-4） |
| **文字式** | $\text{导热速率}_{\text{【W】}}=\dfrac{\text{温差}_{\text{【K】}}}{\text{导热热阻}_{\text{【K/W】}}}$，$\text{导热热阻}_{\text{【K/W】}}=\dfrac{\text{壁厚}_{\text{【m】}}}{\text{导热系数}_{\text{【W/(m·K)】}}\times\text{面积}_{\text{【m²】}}}$ |  |

（式 4-5a，热阻串联的出发点，#L5905；热通量 $q=Q/A=\lambda(t_{1}-t_{2})/b$，#L5911。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q=\dfrac{\Delta t}{\dfrac{b_{1}}{\lambda_{1}A}+\dfrac{b_{2}}{\lambda_{2}A}+\dfrac{b_{3}}{\lambda_{3}A}}$ | （4.2-5） |
| **文字式** | $\text{导热速率}_{\text{【W】}}=\dfrac{\text{总温差}_{\text{【K】}}}{\dfrac{\text{第1层厚}_{\text{【m】}}}{\text{第1层}\lambda\times A}+\dfrac{\text{第2层厚}}{\text{第2层}\lambda\times A}+\dfrac{\text{第3层厚}}{\text{第3层}\lambda\times A}}$ |  |

（式 4-7，三层平壁串联，#L5943；各层热阻相加，总温差等于各层温差之和。）

## 适用范围与边界

- 稳态一维导热、$\lambda$ 为常数的前提；非稳态导热（如间歇操作壁温变化）不适用（#L5901 的推导前提）。
- 式 4-4 的 $\alpha$ 是温度系数，不是对流传热系数，别与 $h$（$\alpha$）混用（#L5877 用词为「温度系数 $\alpha$」）。
- 多层壁的接触热阻本书未计入（#L5943 只写串联热阻）。
- 圆筒壁的热阻不是 $b/(\lambda A)$ 形式，须用对数平均半径或 $\ln(r_{2}/r_{1})$ 式，见 [[热传导-圆筒壁与多层壁]]。

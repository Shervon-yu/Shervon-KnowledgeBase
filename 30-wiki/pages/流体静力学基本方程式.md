# 流体静力学基本方程式

## 推导（`#L1058-#L1080`）

从静止液体中划出垂直液柱：横截面积 $A$、密度 $\rho$，上下面与基准面距离 $z_1$、$z_2$，压力 $p_1$、$p_2$。三个力：下端面向上总压力 $p_2A$；上端面向下 $p_1A$；液柱重力 $G=\rho gA(z_1-z_2)$。合力为零：

$$p_2A-p_1A-\rho gA(z_1-z_2)=0$$

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_2=p_1+\rho g(z_1-z_2)$ | （1-9） |
| **文字式** | $\text{下截面压力}_{\text{【Pa】}}=\text{上截面压力}_{\text{【Pa】}}+\text{密度}_{\text{【kg/m³】}}\times\text{重力加速度}_{\text{【m/s²】}}\times\text{两截面高度差}_{\text{【m】}}$ |  |

把上端面取在液面、液面上方压力 $p_0$、下端面深度 $h$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p=p_0+\rho gh$ | （1-9a） |
| **文字式** | $\text{任一点压力}_{\text{【Pa】}}=\text{液面压力}_{\text{【Pa】}}+\text{密度}_{\text{【kg/m³】}}\times\text{重力加速度}_{\text{【m/s²】}}\times\text{深度}_{\text{【m】}}$ |  |

式(1-9)与(1-9a)合称静力学基本方程式。

## 三个推论（`#L1090-#L1100`）

1. **等压面**：液面压力一定时，静止、连续、同一液体内同一水平面上各点压力相等——压力相等的水平面称等压面。
2. **巴斯噶原理**：液面压力 $p_0$ 变化多少，液体内部各点压力**同样大小**变化。
3. **液柱高表示压力**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{p-p_0}{\rho g}=h$ | （1-9b） |
| **文字式** | $\dfrac{\text{压力差}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}\times\text{重力加速度}_{\text{【m/s²】}}}=\text{液柱高度}_{\text{【m】}}$ |  |

液柱高度与密度有关，故 mmHg、mH₂O 这类单位必须带介质。

## 适用性（`#L1102`）

方程由液体推出（密度视为常数）；气体密度随压力变化，但在容器高差范围内变化甚微，也可视为常数，故**对气体同样适用**。

## 判断

- 等压面有三个前提：静止、连续、同一种液体——压差计算错绝大多数是在"不连续"或"不同液"处仍按等压面处理。
- 1-9b 是后面所有液柱压差计公式的来源，记它比记每一个仪表公式更省。

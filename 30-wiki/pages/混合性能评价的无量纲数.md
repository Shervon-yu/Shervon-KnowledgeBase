# 混合性能评价的无量纲数

评价搅拌器混合性能的常用指标：流量准数 $N_q$ 与无量纲数 $C_1$、$C_2$、$C_3$、$C_4$（`#L2993`）。

## 流量准数

排出流量准数与循环流量准数（`#L2997-#L3009`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{qd}=\dfrac{Q_d}{Nd^{3}}$ | （3-1） |
| **文字式** | $\text{排出流量准数}=\dfrac{\text{搅拌器排液量}_{\text{【m³/s】}}}{\text{转速}_{\text{【1/s】}}\times\left(\text{搅拌器直径}_{\text{【m】}}\right)^{3}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{qc}=\dfrac{Q_c}{Nd^{3}}$ | （3-2） |
| **文字式** | $\text{循环流量准数}=\dfrac{\text{循环流量}_{\text{【m³/s】}}}{\text{转速}_{\text{【1/s】}}\times\left(\text{搅拌器直径}_{\text{【m】}}\right)^{3}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{qc}=N_{qd}\left\{1+0.16\left[\left(\dfrac{D}{d}\right)^{2}-1\right]\right\}$ | （3-3） |
| **文字式** | $\text{循环流量准数}=\text{排出流量准数}\times\left\{1+0.16\left[\left(\dfrac{\text{搅拌设备内径}_{\text{【m】}}}{\text{搅拌器直径}_{\text{【m】}}}\right)^{2}-1\right]\right\}$ |  |

## C₁：无因次混合时间

$C_1$ 即第二章的混合准数 $N_{\theta M}=N\theta_M$，物理意义是达到规定混匀标准所需的总转数，式（2-24）（`#L3013`）。$C_1$ 越小混合越快。

- 湍流域：涡轮、桨式、推进式 $C_1$ 为常数。
- 层流域：$d/D\to1$ 的螺带式、MIG 式、螺杆-导流筒式 $C_1$ 为常数；$d/D=0.3\sim0.5$ 的涡轮/桨式因停滞区太大测不出 $\theta_M$，$C_1$ 不能确定。
- 过渡流域：所有搅拌器 $C_1$ 随 $Re$ 增大而降低（`#L3015`）。

## C₂、C₃、C₄

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_2=\theta_M\sqrt{P_v/\mu}$ | （3-4） |
| **文字式** | $\text{规定混合程度时的剪切量}=\text{混合时间}_{\text{【s】}}\times\sqrt{\dfrac{\text{单位体积功率}_{\text{【W/m³】}}}{\text{黏度}_{\text{【Pa·s】}}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_3=\dfrac{1}{N}\sqrt{P_v/\mu}$ | （3-5） |
| **文字式** | $\text{每转剪切量}=\dfrac{1}{\text{转速}_{\text{【1/s】}}}\times\sqrt{\dfrac{\text{单位体积功率}_{\text{【W/m³】}}}{\text{黏度}_{\text{【Pa·s】}}}}$ |  |

- $C_2$：达到规定混合程度时流体受到的总剪切量；$C_3$：搅拌器转一圈的剪切量（`#L3019-#L3025`；原文式（3-5）左端 OCR 作 $C_s$，按上下文应为 $C_3$）。
- $C_4$：一定黏度与混合时间下所需单位体积混合能，见第二章高黏流体部分（`#L3033`）。

## 非牛顿流的替换

假塑性流体也可用 $C_1\sim C_4$ 评价，但算 $C_2$、$C_3$、$C_4$ 时黏度须用表观黏度 $\mu_a$ 代替 $\mu$（`#L3035`）。$\mu_a$ 的算法见 [[表观黏度法与Metzner常数]]。

## 用法

1. 先用 $N_q$ 比循环能力（大 $N_q$ 适合均质、悬浮）；
2. 用 $C_1$ 比混合快慢（小者快，经验上 $C_1=20\sim80$ 可满足一般混合，见 [[湍流域混合时间关联式]]）；
3. 用 $C_2/C_3$ 比剪切史（剪切敏感体系取小值）；
4. 用 $C_4$ 比能耗。

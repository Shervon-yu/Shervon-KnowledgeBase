# 磁力联轴器最大传递扭矩的计算

## 方法定位（`#L14635-#L14637`）

静磁场与最大传递扭矩的精确计算需修正系数、漏磁系数、磁阻系数、磁钢工作点等，过程繁琐。工程上采用**近似计算法**：按稀土永磁特点推导，简易、快速且较准确，可反复试算磁钢材料、极数、直径、长度、气隙，找出最佳方案。

## 气隙中心磁场强度（图11-11 静态磁路，`#L14645-#L14675`）

同轴式联轴器由内、外两个磁环组成，每环由 $m$ 个 N/S 交替的瓦形磁钢构成；气隙中心场强由相对的内、外两块磁钢叠加。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H_{\text{内}}=\dfrac{B_r}{\pi}\left[\arctan\dfrac{L_{s2}L_b}{L_g\sqrt{L_g^2+L_b^2+L_{s2}^2}}-\arctan\dfrac{L_{s1}L_b}{(4L_{m1}+L_g)\sqrt{(4L_{m1}+L_g)^2+L_b^2+L_{s1}^2}}\right]$ | （11-1） |
| **文字式** | $\text{气隙场强}_{\text{内}}=\dfrac{\text{剩磁}}{\pi}\left[\arctan\dfrac{\text{内磁钢外弧长}\times\text{磁钢纵向长度}}{\text{气隙长}\sqrt{\text{气隙长}^2+\text{纵向长}^2+\text{内磁钢外弧长}^2}}-\arctan\dfrac{\text{内磁钢内弧长}\times\text{磁钢纵向长度}}{(4\text{内磁钢厚}+\text{气隙长})\sqrt{(4\text{内磁钢厚}+\text{气隙长})^2+\text{纵向长}^2+\text{内磁钢内弧长}^2}}\right]$ |  |

外磁钢同理（式11-2，把 $L_{s1}$、$L_{s2}$、$L_{m1}$ 换成 $L_{s3}$、$L_{s4}$、$L_{m2}$），则：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H_g=H_{\text{内}}+H_{\text{外}}$ | （11-3） |
| **文字式** | $\text{气隙中心场强}=\text{内磁钢贡献}+\text{外磁钢贡献}$ |  |

符号：$B_r$ 剩磁（T）；$L_g$ 气隙长度（m）；$L_b$ 磁钢纵向长度（m）；$L_{s1}/L_{s2}$ 内磁钢内/外弧长（m）；$L_{s3}/L_{s4}$ 外磁钢内/外弧长（m）；$L_{m1}/L_{m2}$ 内/外磁钢厚度（m）。

## 最大传递扭矩（`#L14677-#L14690`）

外磁环旋转、内外同步时，相对磁钢片间产生位移角；当位移角为 $\alpha/2$ 时，内磁钢片受相邻两外磁钢片吸力 $\vec F_1$ 与斥力 $\vec F_2$ 联合作用，扭矩最大（图11-12）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_{\max}=6.332\times10^{4}B_rH_gS_mR_2$ | （11-4） |
| **文字式** | $\text{最大传递扭矩}_{\text{【N·m】}}=6.332\times10^{4}\times\text{剩磁}_{\text{【T】}}\times\text{气隙场强}_{\text{【T】}}\times\text{磁极总面积}_{\text{【m}^2\text{】}}\times\text{内磁钢外半径}_{\text{【m】}}$ |  |

$S_m=S_{\text{内}}+S_{\text{外}}$ 为内、外磁钢磁极总面积（m²）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_{\max}=2\pi n M_{\max}$ | （11-5） |
| **文字式** | $\text{最大传递功率}_{\text{【W】}}=2\pi\times\text{转速}_{\text{【r/s】}}\times\text{最大传递扭矩}_{\text{【N·m】}}$ |  |

## 算例（例11-1，`#L14725-#L14779`）

已知：$R_2=4.995\ \mathrm{cm}$、$R_3=5.245\ \mathrm{cm}$、$L_g=0.25\ \mathrm{cm}$、$L_{m1}=L_{m2}=0.5\ \mathrm{cm}$、磁钢片纵向长度 $W=1.7\ \mathrm{cm}$、两排共 $L_b=3.4\ \mathrm{cm}$、极数 18、$n=2910\ \mathrm{r/min}$、钕铁硼 $B_r=1.12\ \mathrm{T}$、$L_{s1}=0.0157$、$L_{s2}=0.0174$、$L_{s3}=0.0183$、$L_{s4}=0.02005\ \mathrm{m}$。

计算链：

| 步 | 结果 |
|:---|:---|
| $H_{\text{内}}$ | 0.3255 T |
| $H_{\text{外}}$ | 0.2953 T |
| $H_g$ | 0.6208 T |
| $S_{\text{内}}=\pi\cdot2R_2L_b$ | 0.01067 m² |
| $S_{\text{外}}=\pi\cdot2R_3L_b$ | 0.01120 m² |
| $S_m$ | 0.02187 m² |
| $M_{\max}$ | **48.1 N·m** |
| $P_{\max}=2\pi\times48.5\times48.1$ | **14 660 W ≈ 14.7 kW** |

## 精度（表11-12，`#L14697-#L14707`）

四组气隙对比：计算与实测最大传递扭矩误差依次 **0.9%、7.9%、0.1%、3.9%**，最大误差 **7.9%**，工程计算可接受。

## 结论与用法

1. 先按式（11-1）~（11-3）求 $H_g$，再按式（11-4）求 $M_{\max}$、式（11-5）求 $P_{\max}$；
2. 扭矩与 $B_r$、$H_g$、$S_m$、$R_2$ 成正比；$H_g$ 又与 $B_r$、几何形状、气隙长度密切相关——**减小气隙是最有效的增益手段**；
3. 反复试算可避免设计盲目性；更详细计算原文建议查专门资料。

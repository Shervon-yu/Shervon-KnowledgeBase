夹套容器 = 内容器 + 夹套。被夹套包围的内容器圆筒/封头叫**公用元件**，同时受两腔压力与腐蚀；夹套端部的环形或锥形件叫**封闭件**（G.1.3，`#L14542`）。

## 一、三类结构（G.1，`#L14538-#L14596`）

| 类别 | 说明 |
|:--|:--|
| 整体夹套 | 5 种类型（图G.1）：1 型包内筒一段；2 型包内筒一部分 + 一个封头；3 型包一个封头的一部分（横截面为圆形）；4 型包内筒 + 一个封头且有中间支撑；5 型再包另一个封头的一部分。1、2、4、5 型夹套在圆周方向须为连续圆环 |
| 蜂窝短管夹套 | 图G.2 |
| 半管夹套 | 图G.3，夹套由 DN50、DN80、DN100 半圆管制造 |

限制：夹套内介质应为水、水蒸气等**无毒、非易燃、非易爆**的简单介质（G.1.6）；夹套与内容器材料不同或内容器要热处理时，封闭件材料宜与内容器相同，或设同材质垫板（G.2.2）。

## 二、计算压力与腐蚀裕量（G.4.1）

内容器与夹套分别按两腔最大工作压力定设计压力（G.4.1.2.1）：夹套 $P_{c2}=P_2$，内容器非公用元件 $P_{c1}=P_1$。

公用元件的计算压力按表 G.1（`#L14720-#L14736`）：

| $P_1$、$P_2$ | 夹套 $P_{c2}$ | 公用元件：正压 | 公用元件：负压（设计） | 公用元件：负压（校核） | 内容器非公用 $P_{c1}$ |
|:--|:--|:--|:--|:--|:--|
| $P_1\ge0,\ P_2\ge0$ | $P_2$ | $P_1$ | $-P_2$ | $-P_{T2}$ | $P_1$ |
| $P_1<0,\ P_2\ge0$ | $P_2$ | — | $-(P_2-P_1)$ | $-P_{T2}$ | $P_1$ |
| $P_1\ge0,\ P_2\le0$ | $P_2$ | $P_1-P_2$ | — | $-P_{T2}$ | $P_1$ |
| $P_1<0,\ P_2<0$ | $P_2$ | $-P_2$ | $P_1$ | $-P_{T2}$ | $P_1$ |

两侧压力同步升降时，公用元件按压差设计；不能同步时须计算最不利组合。

**腐蚀裕量**（G.4.1.3）：非公用元件各取本腔；**公用元件须同时计入两腔腐蚀**，材料相同时取不小于「内容器侧 + 夹套侧」之和；内容器外壁导流板、加强圈宜考虑夹套介质腐蚀。

**最小厚度**（G.4.1.4，成形后不含腐蚀裕量）：非合金钢、低合金钢夹套 $\ge3$ mm；高合金钢 $\ge2$ mm。

## 三、整体夹套

- 结构：顶端设 $\le$DN50 排气孔、底部设 $\le$DN50 排净孔，工艺管口能起该作用时可不另设（G.4.2.1）；
- 导流板与筒体须双面焊（可双面交错），焊脚高度按式（G.2，`#L14788`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $a\ge\dfrac{2h_1b_1}{\psi_0D_i}$ | （G.2） |
| **文字式** | $\text{焊脚高度}_{\text{【mm】}}\ge\dfrac{2\times\text{导流板截面高度}_{\text{【mm】}}\times\text{宽度}_{\text{【mm】}}}{\text{单面焊缝总长与导流板总长之比值}\times\text{内容器内直径}_{\text{【mm】}}}$ |  |

间断焊缝间距不大于内容器壳体名义厚度的 **8 倍**，一整圈单面焊缝总长不小于导流板长度的一半。

- 内容器与夹套壳体厚度按第 5~7 章算；封闭件按表 G.2 设计（4 页表，按封闭件结构选型）；穿过夹套的接管按表 G.3。

## 四、蜂窝短管夹套（G.5，`#L14890-#L14930`）

拉撑区的夹套壳体厚度与蜂窝短管按 7.12（拉撑结构）设计；拉撑区内容器筒体计算厚度按式（G.3）、常数按式（G.4）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $t_{sc}=L\sqrt{\dfrac{p_{c2}}{[\sigma]^tK_1}+\left(\dfrac{p_{c1}D_i}{2[\sigma]^tL}\right)^2}$ | （G.3） |
| **文字式** | $\text{内容器筒体计算厚度}_{\text{【mm】}}=\text{短管间距}_{\text{【mm】}}\times\sqrt{\dfrac{\text{夹套计算压力}_{\text{【MPa】}}}{\text{许用应力}\times\text{拉撑常数}}+\left(\dfrac{\text{内容器计算压力}\times\text{内直径}}{2\times\text{许用应力}\times\text{短管间距}}\right)^2}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_1=\dfrac{\pi}{2}\left[1+1.3\dfrac{1.8+2.3\dfrac{d_o}{L}}{\ln\dfrac{L}{d_o}}\right]$ | （G.4） |
| **文字式** | $\text{拉撑常数}=\dfrac{\pi}{2}\left[1+1.3\times\dfrac{1.8+2.3\times\dfrac{\text{短管外直径}}{\text{短管间距}}}{\ln\dfrac{\text{短管间距}}{\text{短管外直径}}}\right]$ |  |

无拉撑区仍按第 5~7 章算；夹套壳体与短管厚度宜计腐蚀。端部压力已由短管承担时，封闭件可按 1 型整体夹套设计。

## 五、半管夹套（G.6，`#L14932-#L14976`）

- 适用：内容器受内压或外压、夹套受内压，夹套由 DN50/DN80/DN100 半圆管制造；截面小于半圆（$<180^{\circ}$）可参照；
- 角焊缝腰高不小于夹套与内容器壳体厚度中的较小值，带外坡口的填角焊缝须焊透夹套整个厚度；
- 材料屈强比 $R_{eL}/R_m\le0.625$ 且无压力循环；内容器内直径 $>4000$ mm 时选较小公称直径半管；
- 内容器壳体厚度按不带夹套的结构算（G.6.2）；
- 夹套厚度（当 $P_2\le0.4\phi[\sigma]$，`#L14956`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $t_{rj}=\dfrac{P_2r_j}{\phi[\sigma]_j^t-0.5P_2}$ | （G.5） |
| **文字式** | $\text{夹套厚度}_{\text{【mm】}}=\dfrac{\text{夹套设计压力}_{\text{【MPa】}}\times\text{半管内半径}_{\text{【mm】}}}{\text{焊接接头系数}\times\text{夹套许用应力}_{\text{【MPa】}}-0.5\times\text{夹套设计压力}}$ |  |

- 夹套最大允许压力（`#L14964-#L14976`）：$P_{2\max}=F_j/K_j$（G.6）、$F_j=\min\{(1.5[\sigma]^t-\sigma_z),\ 1.5[\sigma]^t\}$（G.7）、$K_j=\sum C_iD_i^{(\cdot)}$（G.8，共 10 项，指数 0~4.5；原文第 3 项写作 $D$ 而非 $D_i$，按原文照录），系数 $C_1\sim C_{10}$ 按半管公称直径与壳体厚度查表 G.4，**允许插值但不许外延**；
- 校核：$P_2\le P_{2\max}$（G.9）。

## 六、耐压试验（G.7，`#L14978-#L15020`）

- 公用元件按压差 $\Delta P$ 设计时：若 $\Delta P>\max\{P_1,P_2\}$，试验时公用元件承受压力不小于 $\Delta P[\sigma]_g/[\sigma]_g^t$；若 $\Delta P\le\max\{P_1,P_2\}$，不小于 $1.25\Delta P[\sigma]_g/[\sigma]_g^t$；
- 独立操作设计：内容器与夹套分别试压，试夹套时**内容器须同时保压**，使任一时刻公用元件压差不超过允许压差，图样注明该要求；试夹套前先校核公用元件稳定性，不满足则先做泄漏检查；
- 非独立操作设计：内容器试压完成后两者同时试压，压差始终不超过允许压差；
- 无法进入内容器检漏且 $P_{T2}>P_{T1}$ 时：先焊夹套与内容器筒体及下封头 → 夹套侧试压 → 焊上封头 → 内容器试压（1~4 型）；必要时可提高内容器试验压力但须按 GB/T 150.1 5.6.3 做应力校核；
- 半管夹套按 GB/T 150.1 5.6 与 GB/T 150.4 第 11 章分别试压。

## 判断

- 公用元件的计算压力不是「取两者的大值」：表 G.1 给出**正压、负压设计、负压校核**三工况，$P_{T2}$ 是夹套试验压力，漏掉校核工况会漏掉最不利外压。
- 公用元件的腐蚀裕量按两腔**相加**（材料相同时），这是与普通容器最大的差异，容易整页照抄内容器数据。
- 半管夹套的 $P_{2\max}$ 用多项式 $K_j$ 算，系数只能插值不许外延——超出表 G.4 厚度范围就没有依据。
- 耐压试验是夹套容器最容易出事的一步：公用元件在「只试一侧」时会承受未设计过的压差，所以必须保压或改变试验顺序。

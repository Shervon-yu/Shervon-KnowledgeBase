# 宾汉塑性流体搅拌功率

## 流变方程与两个无量纲数

宾汉塑性流体 $\tau-\tau_0=\mu_p\dot{\gamma}$。层流区的搅拌雷诺数用**塑性黏度**计算（`#L1965`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re_{\mathrm{b}}=\dfrac{d^{2}N\rho}{\mu_{p}}$ | （2-53 雷诺数） |
| **文字式** | $\text{宾汉雷诺数}=\dfrac{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}\times\text{密度}_{\text{【kg/m³】}}}{\text{塑性黏度}_{\text{【Pa·s】}}}$ |  |

Hedström 准数度量非牛顿行为的强弱（`#L1969`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $He=\dfrac{\tau_{0}\rho d^{2}}{\mu_{p}^{2}}$ | （2-54） |
| **文字式** | $\text{赫德斯特罗姆准数}=\dfrac{\text{屈服应力}_{\text{【Pa】}}\times\text{密度}_{\text{【kg/m³】}}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}}{\left(\text{塑性黏度}_{\text{【Pa·s】}}\right)^{2}}$ |  |

## 层流关联式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}=\beta Re_{\mathrm{b}}^{-1}+a\,He\,Re_{\mathrm{b}}^{-2}$ | （2-53） |
| **文字式** | $\text{功率准数}=\dfrac{\text{系数}\beta}{\text{宾汉雷诺数}}+\dfrac{\text{常数}a\times\text{赫德斯特罗姆准数}}{\left(\text{宾汉雷诺数}\right)^{2}}$ |  |

注：20-md 该行 OCR 把负指数识别成 `^1`、`^2`（`#L1963`），按式（2-56）的组成反推为 $-1$、$-2$；验证：$He/Re_b^{2}=\tau_0/(d^{2}N^{2}\rho)=N_0$，正是式（2-56）的屈服项。

$He=0$（牛顿流体）时 $\beta=K_p$；$He>0$ 时 $\beta$ 增大（`#L1971-#L1973`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\beta-K_{\mathrm{p}}=A\,He^{h}$ | （2-55） |
| **文字式** | $\text{系数}\beta-\text{牛顿流体功率常数}=A\times\left(\text{赫德斯特罗姆准数}\right)^{h}$ |  |

永田进治用 CaCO₃、MgCO₃、高岭土、TiO₂ 分散于水、甘油水溶液、色拉油，使 $He$ 从 0 变到 $10^{9}$，实测 $a$ 为常数、$\beta$ 随 $He$ 变（`#L1971`）。

## 全雷诺数范围式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}=\alpha N_{0}+\left(K_{\mathrm{p}}+A\,He^{h}\right)Re_{\mathrm{b}}^{-1}+I$ | （2-56） |
| **文字式** | $\text{功率准数}=\alpha\times\text{屈服应力功率准数}+\dfrac{\text{牛顿功率常数}+A\times\text{赫德斯特罗姆准数}^{h}}{\text{宾汉雷诺数}}+\text{惯性项}I$ |  |

三项依次对应（`#L1990-#L1994`）：破坏内部结构所需功（$\alpha N_0$）、克服黏性阻力所需功（$\beta Re_b^{-1}$）、克服惯性力所需功（$I$）。屈服应力功率准数（`#L1998`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{0}=\dfrac{\tau_{0}}{d^{2}N^{2}\rho}$ | （2-56 屈服项） |
| **文字式** | $\text{屈服应力功率准数}=\dfrac{\text{屈服应力}_{\text{【Pa】}}}{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\left(\text{转速}_{\text{【1/s】}}\right)^{2}\times\text{密度}_{\text{【kg/m³】}}}$ |  |

## 推导：表观黏度与平均剪切率

牛顿流体层流下转矩与功率只差角速度因子（`#L2093`、`#L2097`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}=\beta_{\mathrm{N}}Re^{-1},\qquad Tg_{c}=\dfrac{\beta_{\mathrm{N}}\mu d^{3}}{2\pi}$ | （1.75）（1.76） |
| **文字式** | $\text{功率准数}=\dfrac{\text{牛顿流体功率常数}}{\text{雷诺数}},\qquad \text{转矩}_{\text{【N·m】}}\times g_{c}=\dfrac{\text{牛顿流体功率常数}\times\text{黏度}_{\text{【Pa·s】}}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{3}}{2\pi}$ |  |

定义容器内平均剪切率 $\dot{\gamma}_{m}$ 后，转矩式给出 $\beta_{\mathrm{N}}=2\pi k\left(\dot{\gamma}_{m}/n\right)=\alpha\left(\dot{\gamma}_{m}/n\right)$；Metzner 指出 $\dot{\gamma}_{m}=Kn$，即**平均剪切率与转速成正比**，这一条对宾汉液沿用（`#L2101`、`#L2107`、`#L2111`）。

宾汉流体 $\tau-\tau_{y}=\eta\dot{\gamma}$（1.80），表观黏度定义为 $\mu_{a}=\tau/\dot{\gamma}$（1.81）；把 $\mu_{a}=\eta+\tau_{y}/\dot{\gamma}_{m}$ 代进层流功率式，整理出两项（`#L2135`、`#L2141`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{Pg_{c}}{\rho n^{3}d^{5}}=\beta\left\{\dfrac{\eta}{d^{2}n\rho}+\left(\dfrac{n}{\dot{\gamma}_{m}}\right)\left(\dfrac{\tau_{y}}{d^{2}n^{2}\rho}\right)\right\}$ | （1.83） |
| **文字式** | $\dfrac{\text{功率}_{\text{【W】}}\times g_{c}}{\text{密度}_{\text{【kg/m³】}}\times\text{转速}_{\text{【1/s】}}^{3}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{5}}=\text{系数}\beta\left\{\dfrac{\text{塑性黏度}_{\text{【Pa·s】}}}{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}\times\text{密度}_{\text{【kg/m³】}}}+\left(\dfrac{\text{转速}_{\text{【1/s】}}}{\text{平均剪切率}_{\text{【1/s】}}}\right)\left(\dfrac{\text{屈服应力}_{\text{【Pa】}}}{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}^{2}\times\text{密度}_{\text{【kg/m³】}}}\right)\right\}$ |  |

由此定义两个准数（1.84）（1.85），并取近似 $\beta\cong\beta_{\mathrm{N}}$（`#L2145`、`#L2153`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re''=\dfrac{d^{2}n\rho}{\eta},\quad N_{y}=\dfrac{\tau_{y}}{d^{2}n^{2}\rho},\quad N_{\mathrm{p}}=\beta\left(Re''\right)^{-1}+\alpha N_{y}=\beta\left(Re''\right)^{-1}+\alpha\,He\left(Re''\right)^{-2}$ | （1.84）（1.85）（1.86'） |
| **文字式** | $\text{塑性雷诺数}=\dfrac{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}\times\text{密度}_{\text{【kg/m³】}}}{\text{塑性黏度}_{\text{【Pa·s】}}},\quad \text{屈服应力功率准数}=\dfrac{\text{屈服应力}_{\text{【Pa】}}}{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}^{2}\times\text{密度}_{\text{【kg/m³】}}},\quad \text{功率准数}=\dfrac{\text{系数}\beta}{\text{塑性雷诺数}}+\dfrac{\text{常数}\alpha\times\text{赫德斯特罗姆准数}}{\left(\text{塑性雷诺数}\right)^{2}}$ |  |

故 $N_{y}=He\left(Re''\right)^{-2}$，这正是上面式（2-56）里 $\alpha He\,Re_{b}^{-2}$ 的来源。$\alpha$ 是常数，$\beta$ 随 $He$ 变：$\beta-\beta_{\mathrm{N}}=KHe^{h}$，$h=1/3$（1.88，`#L2175`）。把三项叠加即得全范围式（1.92）。

## 算例：两项谁主导

例1.10（`#L2226`）：双螺带（$d=0.95D$、$b=0.1D$、$h=s=d$）、$D=0.30$ m，$\rho=1.08$ g/cm³、$\eta=0.0373$ P、$\tau_{y}=62.2$ dyn/cm²，$He=3.925\times10^{7}$；$Re''=23520\,n$。

| $n$ [r/min] | $Re''$ | 屈服项 $\alpha He/Re''^{2}$ | 黏性项 $\left(\beta_{\mathrm{N}}+KHe^{h}\right)/Re''$ | $I$ | $N_{\mathrm{p}}$ 计算 | 观测 |
|---:|---:|---:|---:|---:|---:|---:|
| 4.58 | $1.79\times10^{3}$ | 74.8 | 3.02 | 0.20 | 78.0 | 75.7 |
| 10.3 | $4.04\times10^{3}$ | 14.8 | 1.34 | 0.20 | 16.3 | 16.0 |
| 28.4 | $1.13\times10^{4}$ | 1.88 | 0.479 | 0.20 | 2.56 | 2.43 |
| 62.0 | $2.43\times10^{4}$ | 0.408 | 0.223 | 0.20 | 0.831 | 0.76 |
| 133 | $5.21\times10^{4}$ | 0.0886 | 0.104 | 0.20 | 0.393 | 0.34 |

低速时屈服项压倒一切；$n\approx28$ r/min 时黏性项追上屈服项的量级；高速时两者都小于惯性项 $I$（`#L2260`）。例1.11（MgCO₃+色拉油 40.4%，$He=1.86\times10^{4}$）显示：**分散介质本身黏、$He$ 小，则黏性项主导的区段宽得多**（`#L2284`）。

## 过渡区的涡流与功率反常

涡轮式与桨式在宾汉液中，$N_{\mathrm{p}}$–$Re''$ 曲线不是单调下降，而是经过一个最小值 $c_{i}$ 再回升到一个最大值 $d_{i}$，随后才接上牛顿型曲线；无挡板时伴随涡流的周期性生成与消失，有挡板时无涡流但挡板前液面周期性升降（`#L2292`、`#L2300`、`#L2318`）。

机理（`#L2306`）：$N_{\mathrm{p,min}}$ 附近叶轮开始有输出流、流动区扩展、转矩上升；$N_{\mathrm{p,max}}$ 时输出流到达器壁、全釜剪应力超过屈服应力、生成涡流；再加速则表观黏度下降、功耗降、远处剪应力又低于屈服应力、涡流消失，随之叶轮周围表观黏度回升、转矩再升——**同一转速下转矩随时间周期变化**。

例外：叶片伸到全釜的螺带式看不到这种现象，宾汉液曲线与牛顿曲线平滑相接；桨径越大，效应越弱（`#L2322`）。

## 湍流区与固体悬浮的统一

完全悬浮以上，屈服项与黏性项都可忽略，$N_{\mathrm{p}}\cong I$（式1.93，`#L2326`）。全挡板下三类流体的湍流功率数几乎相同（表1.9，`#L2332`）：

| 叶轮 | $C/D$ | $I_{1}$ 均相 | $I_{2}$ 宾汉 | $I_{3}$ 固悬 |
|:---|:---:|:---:|:---:|:---:|
| 六叶涡轮 | 1/2 | 5.5 | 5.5 | 5.6 |
| 六叶涡轮 | 1/3 | 5.0 | 5.1 | 5.4 |
| 六叶涡轮 | 1/10 | 3.3 | — | 3.3 |
| 六叶桨 | 1/2 | 4.4 | 4.5 | — |

结论：除膨胀性液体外，式（1.92）可覆盖全部固体悬浮系统；宾汉液与易沉降悬浮液之间用内插（`#L2344`）。另：宾汉液里螺带与釜壁的间隙修正项 $\left(D-d\right)/d$ 可取 1.0（即指数 $-0.5$ 改 0），因为介质黏度低时颗粒吸收动量并在壁面滑移，间隙影响甚小（`#L2224`）。

## 用法

1. 由塑性黏度算 $Re_b$，由屈服应力算 $He$；
2. 按叶轮查表2-11 取 $a,K_p,A,h,I$；
3. 层流区用式（2-53）（式2-55 仅供参考 $\beta$），全范围用式（2-56）；
4. 式（2-56）不含 $He$ 上限，但表2-11 参数来自 $He\le10^{9}$ 的实验，外推需谨慎。

屈服应力的物理含义见 [[屈服应力流体]]；假塑性流体（无屈服应力）的算法见 [[表观黏度法与Metzner常数]]。

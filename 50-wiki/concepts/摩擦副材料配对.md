# 摩擦副材料配对

## 定义

**密封副材料**：指动环与静环的端面材料。根据统计，机械密封的泄漏有 80%~95% 是由于密封副造成的，除了要保证密封面平行之外，主要是密封副材料问题；因此正确选择密封副材料，可以保证机械密封长寿命、稳定地运转。§4.4.1 #L3433

**配对**（书内用「配合面 / 密封面」「组对」表达）：一对端面里通常一面是软材料（石墨类）、一面是硬材料（陶瓷/硬质合金/金属），「一般配合面比密封面硬」「对含磨粒介质的密封面硬度比密封流体中固体颗粒硬度大」。§4.4.1 #L3443

## 选材的性能口径（表 4-17，§4.4.1 #L3439~#L3454）

| 性能 | 原文要点 | 行号 |
|:---|:---|:---|
| 硬度配合好 | 比摩擦学性能和其他因素更重要，是配合密封面的抗磨粒磨损准则；密封面比压与硬度的比值说明相对膜厚（所处摩擦状态） | #L3443 |
| 刚度 | 弹性模量高→承载时保持几何形状；高模量材料较脆，低模量抗热冲击好 | #L3444 |
| 强度足够 | 抗拉强度对受流体静压、摩擦力、驱动力的密封环很重要；碳石墨往往以抗压强度为限制因素 | #L3445 |
| 高韧性 | 抵抗机械冲击与热冲击 | #L3446 |
| 自润滑性好 | 耐干运转和耐高负荷 | #L3447 |
| 热性能 | 热导率决定摩擦热导出（传给冷却流体），低线胀系数使热冲击最小 | #L3448 |
| 密度 | 旋转环密度小可减少惯性与平衡问题 | #L3449 |
| pv 值 | 密封副材料配合的相对性能，可表示所能承受的接触压力与摩擦速度乘积；碳化硅的 pv 值受烷烃影响而增大 | #L3454 |
| 渗透性 | 陶瓷与碳石墨多孔，未处理会被气液渗透，是材料潜在泄漏量的量度 | #L3454 |

**必要特性八条**：机械密封性能好、弹性模量高；自润滑、耐干运转耐高负荷；配对摩擦学相容、黏着倾向小；导热性/耐热性/抗热冲击好；线胀系数小；保持流体膜能力（非接触式）；化学与电化学相容；加工性好、价廉。§4.4.1 #L3458~#L3474

## 软材料（石墨族）

- 用量最大、应用最广的是石墨：自润滑、低摩擦系数、耐腐蚀、导热好、线胀系数低、易加工、成本低。§4.4.1 #L3478
- 分电化石墨（软质石墨，2400~2800 ℃ 石墨化，质软强度低，适用于清洁、润滑性差或易干摩擦工况如轻烃）与碳石墨（高强石墨，强度高、硬度大、耐磨损，是常用的软环材料）。#L3482 #L3484
- 碳石墨按肖氏硬度分档（表 4-18）：HS 50~70 软碳石墨（配合面较软时）；70~90 中硬（配合面较硬时）；>90 硬碳石墨（配合面较硬、介质含固体颗粒时）。#L3490~#L3492
- 烧结石墨气孔率 10%~30%，需浸渍处理成不透性石墨；常用浸渍剂：酚醛树脂（耐酸好）、环氧树脂（耐碱好）、呋喃树脂（耐酸耐碱均好，三者中浸呋喃树脂环最好）；密封环温度 ≤170 ℃ 可选用浸合成树脂。#L3494
- 碳石墨受化学侵蚀时改用加填充剂的聚四氟乙烯作软密封面材料：自润滑、耐腐蚀优异，常用于干摩擦、极低温、强碱与溶剂环境；但导热率低、耐热差，摩擦热下会热变形，故用于轻载荷并与高纯度氧化铝配对。#L3616

## 硬材料

- **金属**：铸铁、模具钢、轴承钢等特殊钢不耐腐蚀，不能用于水类液体和药液，通常用于低负荷、油类液体，一般工艺过程很少使用；斯太利特（钴铬钨合金）也属此类。#L3620
- **工程陶瓷**：化学稳定性极好、硬度高、耐磨损，但脆性大、抗冲击韧性低；常用氧化铝陶瓷（Al₂O₃）、碳化硅陶瓷（SiC）、氮化硅陶瓷（Si₃N₄），后两者称新型陶瓷。#L3622
- 氧化铝陶瓷：Al₂O₃ 占 88%~92%，加 Fe、Cr、Ni 等金属元素可提高热导率、降低脆性（但耐蚀性略降）；除氢氟酸、氟硅酸及浓碱外几乎耐各种介质，线胀系数小、导热好、耐高温与一定温度剧变。#L3624
- **配对禁忌**：一套机械密封的动、静环不能都使用氧化铝陶瓷制造，否则有诱发产生静电的危险。#L3640

## 判据 / 计算

选材判据只有一条成文规则：**比压或 pv 值超过允许值 → 减小面积比（采用平衡型密封）**，但可靠性随之下降（见 [[端面比压与pv值]]，§4.2.2 #L2714）。容许 pv 的具体数值表本书未给（见开放问题）。

## 开放问题

- 各材料组合的允许 pv 值（MPa·m/s）没有成表给出，只有「碳化硅的 pv 值受烷烃影响而增大」这一条定性结论（#L3454）。
- 「软环 / 硬环」谁装在动环侧（旋转环）没有统一结论，书中按结构与工况定（§4.2.2 #L2730 提到动环误差一般比静环大，高速下采用静止式）。
- 硬质合金（WC）牌号与性能在本书只提到斯太利特与陶瓷，未见 WC 专节；若需选型数据要另找标准或厂家样本。

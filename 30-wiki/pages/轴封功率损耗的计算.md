# 轴封功率损耗的计算

## 为什么要算

第九章确定驱动电机功率的式（9-1）中，有一项就是**轴封装置的功率损耗** $P_{s}$（`#L12425`）。粗估口径：

- **填料密封**：可取搅拌器功率的 **10%**，或**至少 0.368 kW**；
- **机械密封**：一般为填料密封的 **10%~50%**。

需要更准时可按下式估算。

## 一、填料密封

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_{s}=6.67\,d_{0}^{2}\,h\,n\times10^{-9}$ | （10-1） |
| **文字式** | $\text{填料密封功率}_{\text{【kW】}}=6.67\times\left(\text{密封处轴径}_{\text{【mm】}}\right)^{2}\times\text{填料总高度}_{\text{【mm】}}\times\text{转速}_{\text{【r/min】}}\times10^{-9}$ |  |

- $P_{s}$——填料密封功率消耗近似值，kW；
- $n$——轴转速，r/min；
- $d_{0}$——设计最终确定的密封部位**实心轴轴径或空心轴外径**，mm；
- $h$——**不考虑密封环**时填料密封圈的总高度，mm（`#L12433-#L12439`）。

**机理**：摩擦功耗取决于填料摩擦系数、填料高度、压盖初始压缩力、流体压力、轴径、轴速、表面粗糙度、泄漏率与润滑状态；当压盖初始压力不大且填料浸满油/脂/密封液时，填料实际不与轴接触，功耗是**黏滞阻力**的函数（`#L12429`）。式10-1 是工程简化。

## 二、机械密封

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_{s}=1.8\,d_{0}^{1.2}\times10^{-3}$ | （10-2a，双端面） |
| **文字式** | $\text{双端面机械密封功率}_{\text{【kW】}}=1.8\times\left(\text{密封处轴径}_{\text{【mm】}}\right)^{1.2}\times10^{-3}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_{s}=d_{0}^{1.2}\times10^{-3}$ | （10-2b，单端面） |
| **文字式** | $\text{单端面机械密封功率}_{\text{【kW】}}=\left(\text{密封处轴径}_{\text{【mm】}}\right)^{1.2}\times10^{-3}$ |  |

$d_{0}$ 同上，mm（`#L12445-#L12455`）。

**系数关系**：双端面的 1.8 与单端面的 1.0 之比 = 1.8，即**双端面功耗约为单端面的 1.8 倍**——这是双端面密封的两个摩擦副叠加的结果。

## 使用注意

1. **式10-2a 的 OCR 风险**：原文公式写作 $1.8d_{0}^{12}\times10^{-3}$，指数"12"是"1.2"的 OCR 丢小数点，**已按 1.2 修正**，引用时注明。
2. **$h$ 不含密封环**：填料箱里的油环（密封环）高度不计入，只算填料圈总高。
3. **空心轴用外径**：$d_{0}$ 取空心轴**外径**，不是内径。
4. **粗估优先**：方案阶段用"10% 或 ≥0.368 kW"即可；详细设计再用式10-1/10-2a/10-2b（见 [[搅拌用电动机的选用原则]]）。

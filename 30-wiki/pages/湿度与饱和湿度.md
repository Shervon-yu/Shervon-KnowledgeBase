# 湿度与饱和湿度

## 定义（`#L13769-#L13775`）

湿度 $H$ = 湿空气中水汽质量 / 干空气质量，单位 kg 水/kg 干气。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H=\dfrac{m_v}{m_g}=\dfrac{M_v n_v}{M_g n_g}$ | （7-4） |
| **文字式** | $\text{湿度}=\dfrac{\text{水汽摩尔质量}\times\text{水汽摩尔数}}{\text{干气摩尔质量}\times\text{干气摩尔数}}$ |  |

## 用分压表示（`#L13777-#L13781`）

$\dfrac{n_v}{n_g}=\dfrac{p_v}{p-p_v}$，代入得：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H=\dfrac{M_v}{M_g}\cdot\dfrac{p_v}{p-p_v}$ | （7-5） |
| **文字式** | $\text{湿度}=\dfrac{\text{水汽摩尔质量}}{\text{干气摩尔质量}}\times\dfrac{\text{水汽分压}}{\text{总压}-\text{水汽分压}}$ |  |

式（7-5）对任何不凝性干气中含可凝蒸气的物系都适用。

对空气-水（$M_v$=18.02、$M_g$=28.95）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H=0.622\dfrac{p_v}{p-p_v}$ | （7-6） |
| **文字式** | $\text{湿度}=0.622\times\dfrac{\text{水汽分压}}{\text{总压}-\text{水汽分压}}$ |  |

$p_v$ 增大或 $p$ 减小，则 $H$ 增大。

## 饱和湿度（`#L13789-#L13791`）

$p_v=p_s$ 时：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H_s=0.622\dfrac{p_s}{p-p_s}$ | （7-7） |
| **文字式** | $\text{饱和湿度}=0.622\times\dfrac{\text{饱和蒸气压}}{\text{总压}-\text{饱和蒸气压}}$ |  |

## 用相对湿度表示（`#L13793-#L13797`）

$p_v=\varphi p_s$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H=0.622\dfrac{\varphi p_s}{p-\varphi p_s}$ | （7-8） |
| **文字式** | $\text{湿度}=0.622\times\dfrac{\text{相对湿度}\times\text{饱和蒸气压}}{\text{总压}-\text{相对湿度}\times\text{饱和蒸气压}}$ |  |

总压一定时，$H$ 随 $\varphi$ 与 $t$（因 $p_s$ 依赖 $t$）而变。

## 露点法测湿度（`#L13871-#L13875`）

冷却到刚出现液滴时的温度即露点 $t_d$；此时 $H=H_s(t_d)$，由 $p_s(t_d)$ 代入（7-7）求 $H$。

## 判断

- 用"水/干气"而不是"水/湿气"作基准，是因为干燥过程中干空气质量守恒——以它为基准，$H$ 才能直接相加、物料衡算才简单。
- $H$ 只由 $p_v$ 与 $p$ 决定（与温度无直接关系）；$\varphi$ 则依赖温度。所以 $H$ 是"绝对量"，$\varphi$ 是"相对量"。
- 0.622 = 18.02/28.95，是物系常数，换物系要换这个数。

# 瞬间失重粒子混合设备

又称 **WZ 系列无重力粒子混合设备**，20 世纪 90 年代初研制开发的新型设备（`#L16485`）。

## 结构（`#L16487`）

筒体、搅拌轴、桨叶、传动装置、加料口、出料口组成。**ω 形**混合室内装**一对反向旋转的轴**，由电动机经减速机、链条（或齿轮）带动；每根轴上安装**一定角度、一定数量且呈重叠状**的桨叶（图14-21）。

容器上方可装喷液口作固液混合；出料装置可气动或手动。

## 工作原理：流动层与瞬间失重（`#L16487`）

1. 桨叶达到一定圆周速度时，因物料**上抛运动**在混合室内形成**流动层**；
2. 层内物料按对流混合原理混合，并产生**瞬间失重**，达到最佳混合状态；
3. 在流动层中，物料以一定圆周速度克服离心力，在特定角度桨叶作用下由 **A→B**，移动叶片把它送到 **C**，同样角度的桨叶再送到 **D**，由 D 回到 A；
4. 在特定的**重叠叶片**作用下，物料同时作**轴向移动**，实现全方位混合，形成随机最佳运动状态（图14-22~14-24）。

转速为**临界转速的 50%~80%**；叶片距离较小时可接近临界转速。叶片形状随物性与操作目的而异：**干料混合螺距较小、湿料螺距较大**（`#L16513`）。

## 七个特点（`#L16515-#L16535`）

| 项 | 内容 |
|:---|:---|
| ① 流动层混合 | 叶片反向旋转产生流动层；当**粒子重力与离心力相等**时物料处于瞬间失重，此时**混合效果与物料粒径、形状、表观密度无关**，极短时间内得到均匀混合物 |
| ② 混合精度高 | 1:1000 配比下测得相对偏差 **0.003%~0.008%**，含量波动误差（变异因子）**<2%**；WZ 产品说明介绍相对偏差 ≤3%~4%；一般 $C_v\le5\%$ 即视为均匀混合 |
| ③ 混合时间短 | 干燥粉粒体通常数十秒；一般粉粒体 1~2 min |
| ④ 能耗低 | 只有一般混合设备的 **1/4~1/10** |
| ⑤ 混合过程温和 | 剪切作用较小，对物料原始形状破坏甚小 |
| ⑥ 结构紧凑 | 占地小，安装使用维修方便 |
| ⑦ 密闭操作 | 粉尘少、改善劳动环境；运转平稳、噪声低 |

## 应用范围（`#L16537-#L16547`）

- 化工、农药、医药、染料、食品、饲料、饲料添加剂等行业粉体混合；
- 适用粒径 **20~400 目**左右的**干燥非黏性**粉粒体；
- 也可混密度、粒径差异较悬殊的物料，且**不易产生偏析**；
- 可固液混合，喷液量取决于物料吸湿性与流动性，**一般不超过 15%**；
- 混合性能好、速度快、装料系数大、占地小，但**清洗困难** → 适合品种少、产量大的生产；
- 除混合外还可进行**干燥、反应、造粒**。

## 判断

「瞬间失重」的物理含义是：桨叶给物料的离心力恰好抵消重力，粒子在流动层中**不再按密度分层**——这正是它「与粒径、形状、表观密度无关」和「不易偏析」的根据。因此它特别适合密度差大、配比悬殊的粉体，以及既想混合又想顺带干燥/造粒的场合。短板同样明确：清洗困难，换品种成本高。

# 耳式支座的允许外弯矩

## 定义

耳式支座的允许外弯矩 [ML] 是耳座筋板与底板本身能承受、且容器圆筒局部应力不超限的最大外弯矩。设计分两步：先按筋板、底板强度定允许载荷 [Q]，再按圆筒局部应力定允许外弯矩 [ML]，二者比较取可承受范围（#L6568）。

## 判据与计算

### 2.1 筋板强度（式(1)、(2)，#L6590-#6610）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma=\dfrac{Q/(n\cdot\sin\alpha)}{b\cdot\delta_{2}}\leqslant k[\sigma]_{\mathrm{c}}$ | （2-1） |
| **文字式** | $\text{筋板拉压应力}=\dfrac{\text{支座反力}/(\text{筋板数}\times\sin\alpha)}{\text{筋板宽度}\times\text{筋板厚度}}\leqslant\text{折减系数}\times\text{材料许用应力}_{\text{c}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{1}]=b\cdot\delta_{2}\cdot n\cdot\sin\alpha\cdot k[\sigma]_{\mathrm{c}}$ | （2-2） |
| **文字式** | $\text{按筋板确定的允许载荷}=\text{筋板宽度}\times\text{筋板厚度}\times\text{筋板数}\times\sin\alpha\times\text{折减系数}\times\text{材料许用应力}_{\text{c}}$ |  |

- k 为折减系数，按 GB 50017 由受压构件柔度 λ 确定（#L6602）。
- 材料许用应力（#L6572-#L6574）：Q235B 取 200 MPa；S30408 取 140 MPa；15CrMoR 取 200 MPa。

### 2.2 底板强度（式(3)~(5)，#L6624-#6638）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma=\dfrac{6M}{\delta_{1}^{2}}\leqslant[\sigma]$ | （2-3） |
| **文字式** | $\text{底板弯曲应力}=\dfrac{6\times\text{底板计算弯矩}}{\text{底板厚度}^{2}}\leqslant\text{材料许用应力}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M=\dfrac{Qb_{2}^{2}}{8b_{1}l_{1}}$ | （2-4） |
| **文字式** | $\text{底板计算弯矩}=\dfrac{\text{支座反力}\times\text{筋板外侧长度}^{2}}{8\times\text{底板宽度}\times\text{底板长度}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q_{2}]=\dfrac{4\delta_{1}^{2}b_{1}l_{1}}{3b_{2}^{2}}[\sigma]$ | （2-5） |
| **文字式** | $\text{按底板确定的允许载荷}=\dfrac{4\times\text{底板厚度}^{2}\times\text{底板宽度}\times\text{底板长度}}{3\times\text{筋板外侧长度}^{2}}\times\text{材料许用应力}$ |  |

### 2.3 支座允许载荷（式(6)，#L6644）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[Q]=\min\left\{[Q_{1}],[Q_{2}]\right\}$ | （2-6） |
| **文字式** | $\text{支座允许载荷}=\min(\text{筋板允许载荷},\ \text{底板允许载荷})$ |  |

### 2.4 圆筒局部应力（AD 规范 S3/4，式(7)~(12)，#L6662-#6696）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{mp}\varphi}=\dfrac{pR_{\mathrm{m}}}{\delta_{\mathrm{e}}}$ | （2-7） |
| **文字式** | $\text{圆筒环向薄膜应力}=\dfrac{\text{设计压力}\times\text{圆筒平均半径}}{\text{圆筒有效厚度}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{mpx}}=\dfrac{pR_{\mathrm{m}}}{2\delta_{\mathrm{e}}}$ | （2-8） |
| **文字式** | $\text{圆筒轴向薄膜应力}=\dfrac{\text{设计压力}\times\text{圆筒平均半径}}{2\times\text{圆筒有效厚度}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\bar{\sigma}_{\mathrm{m}\varphi}=\dfrac{f_{\mathrm{m}\varphi}\cdot M_{\mathrm{L}}\cdot C_{\mathrm{L}\varphi}}{R_{\mathrm{m}}^{2}\beta\delta_{\mathrm{e}}}$ | （2-9） |
| **文字式** | $\text{外弯矩引起的环向平均薄膜应力}=\dfrac{\text{环向系数}\times\text{外弯矩}\times\text{环向载荷因子}}{\text{平均半径}^{2}\times\beta\times\text{有效厚度}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\bar{\sigma}_{\mathrm{mx}}=\dfrac{f_{\mathrm{mx}}\cdot M_{\mathrm{L}}\cdot C_{\mathrm{Lx}}}{R_{\mathrm{m}}^{2}\beta\delta_{\mathrm{e}}}$ | （2-10） |
| **文字式** | $\text{外弯矩引起的轴向平均薄膜应力}=\dfrac{\text{轴向系数}\times\text{外弯矩}\times\text{轴向载荷因子}}{\text{平均半径}^{2}\times\beta\times\text{有效厚度}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{b}\varphi}=\dfrac{f_{\mathrm{b}\varphi}\cdot 6M_{\mathrm{L}}}{R_{\mathrm{m}}^{2}\beta_{\mathrm{m}\varphi}\delta_{\mathrm{e}}^{2}}$ | （2-11） |
| **文字式** | $\text{外弯矩引起的环向弯曲应力}=\dfrac{\text{环向弯曲系数}\times 6\times\text{外弯矩}}{\text{平均半径}^{2}\times\beta_{\mathrm{m}\varphi}\times\text{有效厚度}^{2}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_{\mathrm{bx}}=\dfrac{f_{\mathrm{bx}}\cdot 6M_{\mathrm{L}}}{R_{\mathrm{m}}\beta_{\mathrm{mx}}\delta_{\mathrm{e}}^{2}}$ | （2-12） |
| **文字式** | $\text{外弯矩引起的轴向弯曲应力}=\dfrac{\text{轴向弯曲系数}\times 6\times\text{外弯矩}}{\text{平均半径}\times\beta_{\mathrm{mx}}\times\text{有效厚度}^{2}}$ |  |

### 2.5 应力限制与 [ML] 的确定（#L6698-#L6714）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_{\mathrm{m}}\leqslant[\sigma]$；$p_{\mathrm{L}}\leqslant 1.5[\sigma]$；$p_{\mathrm{L}}+p_{\mathrm{b}}\leqslant 1.5[\sigma]$ | （2-13） |
| **文字式** | $\text{一次总体薄膜应力}\leqslant\text{许用应力}$；$\text{一次局部薄膜应力}\leqslant 1.5\times\text{许用应力}$；$\text{一次局部薄膜应力}+\text{弯曲应力}\leqslant 1.5\times\text{许用应力}$ |  |

- 迭代求解使各限制式取等号的最大 ML 即为允许外弯矩 [ML]；
- 标准附录 B 给出 8 个支座号、两组材料（Q235B、S30408）的 [ML] 表；
- 带衬里的容器，[ML] 取表值的 1/1.5（#L6712-#L6714）。

## 适用范围与边界

- 只适用于标准耳式支座（短臂 A、长臂 B、加长臂 C，支座号 1~8）按标准尺寸安装在钢制立式圆筒上的工况（#L2424）。
- 系数 fmφ/fmx/fbφ/fbx、载荷因子 CLφ/CLx、β/βmφ/βmx 查 AD 规范 S3/4 相应线图与计算表（#L6653-#L6696）

由容器圆筒限定的支座许用外弯矩的计算方法与限制条件见第3部分编制说明第 5 条（#L6652、#L6653、#L6658）。，本页不展开查图过程。
- 耳座与圆筒的焊缝强度、垫板设置（δe 与材料匹配）另见型式与选型页，本页只管 [Q] 与 [ML]。

# 碟形封头与球冠形封头

两者都是"球面 + 过渡"的凸形封头，区别在过渡形式与是否带折边。

## 碟形封头（7.4）

### 几何约束（`#L6273-#L6277`）

- 球面内半径 $R_i\le D_i$（工程常取 $R_i=0.9D_i$）；
- 过渡圆角 $r\ge0.1D_i$，且 $r\ge3\delta_{nh}$。

### 强度厚度（式7-7、7-8）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_c=\dfrac{Mp_cR_i}{2[\sigma]^t\varphi-0.5p_c}$；$\quad \delta_c=\dfrac{Mp_cR_o}{2[\sigma]^t\varphi+(2M-0.5)p_c}$ | （7-7）（7-8） |
| **文字式** | $\text{强度厚度}_{\text{【mm】}}=\dfrac{\text{形状系数}\times\text{计算压力}\times\text{球面内半径}}{2\times\text{许用应力}\times\text{焊接接头系数}-0.5\times\text{计算压力}}$ |  |

形状系数（`#L6281`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M=\dfrac{1}{4}\left(3+\sqrt{\dfrac{R_i}{r}}\right)$ |  |
| **文字式** | $\text{形状系数}=\dfrac{1}{4}\left(3+\sqrt{\dfrac{\text{球面内半径}}{\text{过渡圆角半径}}}\right)$ |  |

表7-3：$R_i/r$=1.0 → M=1.00；1.5 → 1.07；2.0 → 1.14；3.0 → 1.29；5.0 → 1.46；10 → 1.71。$R_i/r$ 越大（过渡越急）M 越大。

### 屈曲（7.4.2.2~7.4.2.4）

查图7-5（$R_i/r$ 与 $D_i/\delta_c$）判是否可能内压屈曲；可能时：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_b=D_i\left[\dfrac{p_c}{120R_{eL}^t}\cdot\dfrac{(R_i/D_i)^{1.32}}{(r/D_i)^{0.47}}\right]^{0.6}$ | （7-9） |
| **文字式** | $\text{防屈曲厚度}_{\text{【mm】}}=\text{内直径}\times\left[\dfrac{\text{计算压力}}{120\times\text{屈服强度}}\times\dfrac{(R_i/D_i)^{1.32}}{(r/D_i)^{0.47}}\right]^{0.6}$ |  |

经验法式7-10：$R_i/r\le5.5$ 取 $0.0015D_i$，$>5.5$ 取 $0.0030D_i$。

### 允许工作压力（式7-11、7-12）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[p_w]=\dfrac{2[\sigma]^t\varphi\delta_{eh}}{MR_i+0.5\delta_{eh}}$；$\quad [p_w]=120R_{eL}^t\left(\dfrac{\delta_{eh}}{D_i}\right)^{1.67}\left(\dfrac{R_i}{D_i}\right)^{-1.32}\left(\dfrac{r}{D_i}\right)^{0.47}$ | （7-11）（7-12） |
| **文字式** | 强度式与屈曲式取**较小值** |  |

外压（凸面受压）按第6章外压球壳，$R_o$ 取球面部分外半径。

## 球冠形封头（7.5）

### 结构与厚度

- 可作端封头，也可作两独立受压室之间的中间封头；与圆筒连接的 T 形接头**必须全焊透**（`#L6365`）；
- 封头本体厚度：内压按第5章球壳，外压按第6章外压球壳；中间封头取两侧最苛刻压力组合，若能保证两侧压力同时作用可按**压差**算（`#L6383`）。

### 加强段（式7-13）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta_r=Q\delta$ | （7-13） |
| **文字式** | $\text{加强段计算厚度}=Q\times\text{球壳计算厚度}$ |  |

- Q 由圆筒材料与参数查图7-7（端封头）、图7-8（中间封头凹面受压）、图7-9（凸面受压）；
- 凸面受压时加强段厚度还不得小于按 7.5.2 定的球壳厚度；
- 加强段长度（封头侧与圆筒侧）均 $\ge\sqrt{2D_i\delta_r}$；
- 与封头相连的圆筒端部厚度不得小于加强段厚度，否则设圆筒加强段过渡。

### 极薄情形（7.5.5）

当 $2\delta/D_i<0.002$：取 $\delta=0.001D_i$，按 $p_c/([\sigma]_s^t\varphi)=0.002$ 查 Q，再算 $\delta_r=Q\delta$。

## 判断

- 碟形的 M 比椭圆的 K 更敏感：$R_i/r$ 从 2 到 10，M 从 1.14 涨到 1.71（+50%），而椭圆 $D_i/2h_i$ 从 2 到 2.6 只涨 46%——所以碟形封头"过渡圆角"是控制参数，规范才规定 $r\ge0.1D_i$；
- 球冠形封头本体很薄（近似球壳），危险点在**与圆筒的接头**：球壳径向位移小、圆筒大，边缘弯矩集中，所以用 Q 把整段加强，且加强段长度按 $\sqrt{2D_i\delta_r}$ 取；
- 三者壁厚排序（同径同压）：半球 < 标准椭圆 ≈ 碟形 < 球冠加强段；选型时按制造难度与空间权衡，不是越薄越好。

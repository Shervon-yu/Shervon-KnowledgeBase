# 干燥-湿空气性质

## 定义

湿空气是**干空气与水汽的混合物**；对流干燥中水汽含量不断增加，而干空气作为载湿体、载热体，质量流量不变，故湿空气的各物性量值**以单位质量干空气为基准**表示（#L13722）。干燥操作总压较低，湿空气可视为**理想气体**（#L13722）。

- **水汽分压 $p_v$**：湿空气中水汽的分压力（#L13726）。
- **相对湿度 $\varphi$**：同温度下 $p_v$ 与该温度水的饱和蒸气压 $p_s$ 之比（#L13740）。

## 判据 / 计算

总压与水汽、干空气分压：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p=p_v+p_g$ | （13-1） |
| **文字式** | $\text{总压}_{\text{【kPa】}}=\text{水汽分压}_{\text{【kPa】}}+\text{干空气分压}_{\text{【kPa】}}$ |  |

原书编号：式(7-1)（#L13730）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_v=p\,y$ | （13-2） |
| **文字式** | $\text{水汽分压}_{\text{【kPa】}}=\text{总压}_{\text{【kPa】}}\times\text{水汽摩尔分数}$ |  |

原书编号：式(7-2)（#L13734）。

相对湿度：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\varphi=\dfrac{p_v}{p_s}\times100\%$ | （13-3） |
| **文字式** | $\text{相对湿度}_{\text{【\%】}}=\dfrac{\text{水汽分压}_{\text{【kPa】}}}{\text{同温度饱和蒸气压}_{\text{【kPa】}}}\times100$ |  |

原书编号：式(7-3)（#L13742）。

三种极限（#L13736-#L13744）：

- $p_v=p_s$：湿空气被水汽**饱和**，$\varphi=100\%$；
- $p_v<p_s$：未饱和湿空气，$\varphi<1$；
- $p_v=0$：干空气，$\varphi=0$。

## 适用范围与边界

- 干燥操作的**总压较低**，湿空气按理想气体处理；高压下须用真实气体修正（#L13722）。
- 饱和蒸气压 $p_s=f(t)$ 只与温度有关，故 $\varphi$ 随温度与 $p_v$ 两个量变化（#L13744）。
- "以单位质量干空气为基准"是干燥计算的关键口径：湿空气的焓、湿比容、湿比热都按 1 kg 干空气给出，与按湿空气总量给出的值不同（#L13722）。
- 湿度图（$H$-$t$ 图）由本节各物性式绘制，用于查湿空气状态点；读数精度受图幅限制，精确计算仍用公式（§7.2 后文）。

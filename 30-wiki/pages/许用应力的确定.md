# 许用应力的确定

## 非螺栓材料（表1，`#L739-#L750`）

取下列各值中的**最小值**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[\sigma]^t=\min\left\{\dfrac{R_m}{2.7},\ \dfrac{R_{eL}}{1.5},\ \dfrac{R_{eL}^{t}}{1.5},\ \dfrac{R_D^{t}}{1.5},\ \dfrac{R_n^{t}}{1.0}\right\}$ | （1） |
| **文字式** | $\text{许用应力}_{\text{【MPa】}}=\min\left\{\dfrac{\text{抗拉强度}}{2.7},\ \dfrac{\text{常温屈服强度}}{1.5},\ \dfrac{\text{设计温度屈服强度}}{1.5},\ \dfrac{\text{设计温度持久强度}}{1.5},\ \dfrac{\text{设计温度蠕变极限}}{1.0}\right\}$ |  |

- 非合金钢、低合金钢、高合金钢：五项全用；钛/镍及合金：$R_m/2.7$ 起五项（用 $R_{p0.2}$）；铝/铜/锆及合金：**$R_m/3.0$**、$R_{p0.2}/1.5$、$R_{p0.2}^t/1.5$ 三项（`#L745-#L749`）。
- 奥氏体高合金钢受压元件：设计温度低于蠕变范围且允许微量永久变形时，可提到 $0.9R_{p0.2}^t$，但不超过 $R_{p0.2}/1.5$；**法兰或其他微量变形即泄漏/故障的场合不适用**（`#L750`）。
- 持久强度按设计使用年限取 $1.0\times10^5$、$1.5\times10^5$、$2.0\times10^5$ h（表1 注2）。

## 钢制螺栓（表2，`#L754-#L764`）

| 材料 | 直径档 | 热处理 | 取值 |
|:--|:--|:--|:--|
| 非合金钢 | ≤M22 | 热轧、正火 | $\min\{R_{eL}^t/2.7,\ R_D^t/1.5\}$ |
| 非合金钢 | M24~M48 | — | $\min\{R_{eL}^t/2.5,\ R_D^t/1.5\}$ |
| 低合金钢、马氏体高合金钢 | ≤M22 | 调质 | $R_{eL}^t/3.5$ |
| 同上 | M24~M48 | 调质 | $R_{eL}^t/3.0$ |
| 同上 | ≥M52 | 调质 | $R_{eL}^t/2.7$ |
| 奥氏体高合金钢 | ≤M22 | 固溶 | $R_{eL}^t/1.6$ |
| 奥氏体高合金钢 | M24~M48 | 固溶 | $R_{eL}^t/1.5$ |

**螺栓的安全系数比母材大得多**（2.5~3.5 对 1.5）——因为螺栓无塑性储备、且预紧力叠加。

## 复合板（式2，`#L770-#L786`）

覆层与基层结合率达 NB/T 47002 二级板以上、且设计计算需计入覆层强度时：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[\sigma]^t=\dfrac{[\sigma]_1^t\delta_1+[\sigma]_2^t\delta_2}{\delta_1+\delta_2}$ | （2） |
| **文字式** | $\text{复合板许用应力}_{\text{【MPa】}}=\dfrac{\text{基层许用应力}\times\text{基层名义厚度}+\text{覆层许用应力}\times\text{覆层厚度}}{\text{基层名义厚度}+\text{覆层厚度}}$ |  |

覆层厚度 $\delta_2$ **不计腐蚀裕量**。

## 其他两条

- 设计温度 <20 ℃：取 20 ℃ 的许用应力（`#L768`）；
- 地震/风载荷与其他载荷组合：设计应力可到许用应力的 **1.2 倍**（`#L790`）。

## 判断

- 许用应力是"五选一的最小值"，所以**低温容器不会因为温度低就自动降许用应力**——降的是韧性判据，不是强度；
- 常温屈服与设计温度屈服都出现在式子里，$[\sigma]^t$ 与 $[\sigma]$ 的比值正是耐压试验公式(15)(16)里的修正项；
- 复合板公式只对"结合率达标"的复合板成立，松衬、堆焊层不适用。

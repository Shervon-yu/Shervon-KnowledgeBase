# 气泡分散的最低转速

## 先解决"界面面积怎么测"

两种方法（`#L9229`–`#L9236`）：

| 方法 | 原理 | 限制 |
|:---|:---|:---|
| 光散射/反射 | 与液-液界面面积测量相同（Calderbank） | **只适用于持气量小**（低气速、低转速）；只能做**局部**测量 |
| 氧化速率法 | 铜离子催化下空气氧化亚硫酸钠，由氧吸收速率反算界面面积（Reith–Beek） | 得到的是**全容器平均值/累计值** |

局部测量与平均测量的差别在这个体系里不是小事：同一釜内比界面面积分布差异很大（见后文 §8.2.5）。

## 持气量的定义

由**通气与不通气时的液面高度差**确定（`#L9239`）——最简单也最常用的方法，不需要任何仪器。

## 分散气泡的最低转速 $n_0$

持气量 $\phi$ 随转速 $n$ 增加而增加；在**低表观气速**下把 $\phi$–$n$ 曲线外推到 $\phi=0$ 即得 $n_0$（`#L9247`）。

### a) 纯液体

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{n_0d^{2}/D}{(gD)^{1/2}}=0.07$\quad（$D<1.0$ m） | （8.10） |
| **文字式** | 临界转速的弗鲁德型准数等于 0.07（容器小于 1 m 时） |  |

$D>1.0$ m 时改用（`#L9261`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\left[\dfrac{\mu n_0d^{2}}{D\sigma}\right]\left[\dfrac{\rho\sigma^{3}}{g\mu^{4}}\right]^{1/4}=2.0\left[\dfrac{H-C}{D}\right]^{1/2}$ | （8.11） |
| **文字式** | 黏性-毛细准数与"浸没深度/直径"的平方根成正比（$\delta$ 为原文符号，按量纲应为 $\sigma$） |  |

### b) 电解质溶液

$V_s<0.03$ m/s、$0.1<(H-C)/D<0.6$ 时 $n_0$ **与气速无关**（`#L9265`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\left[\dfrac{\mu n_0d^{2}}{D\sigma}\right]\left[\dfrac{\rho\sigma^{3}}{g\mu^{4}}\right]^{1/4}=A\left(\dfrac{d}{D}\right)+B$ | （8.12） |
| **文字式** | 同一准数写成叶径比的线性函数；实测多数情况 **$A$ 很小、$B$ 近于 1** |  |

Westerterp 的实用式（`#L9275`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{n_0d}{(\sigma g/\rho_c)^{1/4}}=A+B\dfrac{D}{d}$ | （8.13） |
| **文字式** | 临界转速 × 叶径 / 毛细-重力特征速度 = A + B×(容器/叶轮直径比) |  |

系数（`#L9277`、`#L9279`）：

| 叶轮 | A | B |
|:---|:---:|:---:|
| 涡轮式 | 1.22 | 1.25 |
| 桨式 | 2.25 | 0.68 |

**桨式的 A 大于涡轮、B 小于涡轮**：桨式本身打不散气泡（A 大），但容器放大时恶化得慢（B 小）；涡轮在小容器里更省转速，但放大时对 $D/d$ 更敏感。

## 不吹气时靠液面涡流吸气：$n_0^*$

$V_s=0$ 时，转速到 $n^*$ 后第一批气泡由**液面涡流**从轴与挡板之间吸入（`#L9283`）。同样外推 $\phi$–$n$ 曲线到 $\phi=0$ 得特征转速 $n_0^*$。

适用条件 $0.1\le(H-C)/D\le0.20+1.75d/D$（`#L9291`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\left[\dfrac{\mu n_0^{*}d^{2}}{D\sigma}\right]\left[\dfrac{\rho\sigma^{3}}{g\mu^{4}}\right]^{1/4}=2.0\left[\dfrac{H-C}{D}\right]^{1/2}$ | （8.14） |
| **文字式** | 与式(8.11) 同形，把 $n_0$ 换成吸气特征转速 $n_0^*$ |  |

## 关键工程结论

**在 $0\le n\le\{n_0,n^*,n_0^*\}$ 范围内，转速对气体吸收是次要的——界面面积很难增加**（`#L9301`）。

含义：低于这个转速区间，加转速几乎不增加界面面积，只是白耗功；转过去之后界面面积才开始随转速涨。**设计时要么选在区间之上，要么就别指望转速**。

## §8.2.5 气泡分布不均匀

Calderbank 光透射实测（`#L9305`、`#L9311`）：

- 垂直方向**两个界面面积极大值**：叶轮附近、叶轮与自由表面的中间高度；
- 径向分布也不均匀（$Q=10$ ft³/m、400 r/min）。

这是"单点取样不能代表全釜"的直接证据，也是 §8.2.1 中"平均测量法"的价值所在。

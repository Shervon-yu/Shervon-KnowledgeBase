# 管内强制湍流对流传热

## 低黏度流体（`#L6218-#L6238`）

强制湍流时自然对流可忽略，$Gr$ 略去：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Nu=0.023\,Re^{0.8}Pr^{n}$ | （4-18） |
| **文字式** | $\text{努塞尔数}=0.023\times\text{雷诺数}^{0.8}\times\text{普朗特数}^{n}$ |  |

展开形式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=0.023\dfrac{\lambda}{d}\left(\dfrac{du\rho}{\mu}\right)^{0.8}\left(\dfrac{c_p\mu}{\lambda}\right)^{n}$ | （4-19） |
| **文字式** | $\text{对流传热系数}=0.023\times\dfrac{\text{热导率}}{\text{管内径}}\times\text{雷诺数}^{0.8}\times\text{普朗特数}^{n}$ |  |

**应用条件**：
- 特征尺寸取管内径 $d$；
- 定性温度取进出口算术平均；
- $Re>10^4$，$0.7<Pr<120$，$l/d\ge60$，$\mu<2$ mPa·s；
- 加热 $n=0.4$、冷却 $n=0.3$；
- 注意 $Pr$ 中 $c_p$ 用 J/(kg·K)，不是 kJ/(kg·K)。

## 为什么 n 随加热/冷却变（`#L6232`）

层流底层内温度影响 $\mu$ 与 $\lambda$：
- 液体：加热时底层温度高于主体 → $\mu$ 减小 → 底层变薄，$\lambda$ 虽减小但不显著 → $\alpha$ 增大。液体 $Pr>1$，$Pr^{0.4}>Pr^{0.3}$，故加热取 0.4；
- 气体：加热时底层温度升高 → $\mu$ 增大 → 底层变厚，$\lambda$ 略增但总效果是 $\alpha$ 减小。气体 $Pr<1$，$Pr^{0.4}<Pr^{0.3}$，故加热仍取 0.4；
- 两者加热都取 0.4、冷却都取 0.3，但机理相反（液体靠黏度下降增 $\alpha$，气体靠黏度上升减 $\alpha$）。

## 高黏度液体（`#L6242-#L6258`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=0.027\dfrac{\lambda}{d}\left(\dfrac{du\rho}{\mu}\right)^{0.8}\left(\dfrac{c_p\mu}{\lambda}\right)^{0.33}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}$ | （4-20） |
| **文字式** | $\text{对流传热系数}=0.027\times\dfrac{\text{热导率}}{\text{管内径}}\times\text{雷诺数}^{0.8}\times\text{普朗特数}^{0.33}\times\left(\dfrac{\text{主体黏度}}{\text{壁温黏度}}\right)^{0.14}$ |  |

条件：$Re>10^4$、$0.6<Pr<16700$、$l/d>60$；定性温度除 $\mu_w$ 取壁温外均取进出口平均。壁温未知需试差，工程近似：加热取 $(\mu/\mu_w)^{0.14}=1.05$，冷却取 0.95。

## 两种几何校正（`#L6260-#L6266`）

- 短管 $l/d<60$：入口扰动使热阻小、$\alpha$ 大，乘 $\varepsilon_1=1+(d/l)^{0.7}$；
- 弯管：离心力产生二次环流，扰动增大，乘 $\varepsilon_R=1+1.77\,d/R$。

## 例4-6（`#L6268-#L6276`）

空气在 φ60×3.5 管（$d=0.053$ m）内 10 m/s、150→250 ℃：定性 200 ℃，$\lambda=0.0393$、$\mu=2.6\times10^{-5}$、$\rho=0.746$、$Pr=0.68$，$l/d=75.5>60$；$Re=1.52\times10^4>10^4$，$\alpha=0.023\times0.0393/0.053\times(1.52\times10^4)^{0.8}\times0.68^{0.4}=32.4$ W/(m²·℃)。

流速变 15 m/s 时 $\alpha'=\alpha(u'/u)^{0.8}=32.4\times1.5^{0.8}=44.8$ W/(m²·℃)。

## 判断

- 0.023 式只给到 $Re^{0.8}$：$u$ 增 50% 只换来 $\alpha$ 增约 38%，这是"靠提流速强化传热代价高"的定量依据（泵功耗按 $u^3$ 涨）。
- 例4-6 的第二问演示了关联式的真正用法：同一体系、同一物性，只需按 $u^{0.8}$ 缩放，不必重算全套特征数。

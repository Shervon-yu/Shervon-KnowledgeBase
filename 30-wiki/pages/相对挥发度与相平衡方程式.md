# 相对挥发度与相平衡方程式

## 挥发度与相对挥发度（`#L11212-#L11224`）

理想溶液中各组分的挥发能力不受其他组分影响，可直接用饱和蒸气压表示**挥发度**：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $v_A=p_A^{\circ}$，$v_B=p_B^{\circ}$ | （6-11） |
| **文字式** | $\text{组分}A\text{的挥发度}=\text{纯}A\text{的饱和蒸气压}$（$B$ 同理） |  |

**相对挥发度** = 两组分挥发度之比：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha=\dfrac{v_A}{v_B}=\dfrac{p_A^{\circ}}{p_B^{\circ}}$ | （6-12） |
| **文字式** | $\text{相对挥发度}=\dfrac{\text{组分}A\text{的挥发度}}{\text{组分}B\text{的挥发度}}=\dfrac{\text{纯}A\text{饱和蒸气压}}{\text{纯}B\text{饱和蒸气压}}$ |  |

因 $p^{\circ}$ 是 $t$ 的函数，$\alpha$ 也是 $t$ 的函数；同温下 $p_A^{\circ}>p_B^{\circ}$ 则 $\alpha>1$。

## 相平衡方程式（`#L11226-#L11248`）

由式6-8 与式6-9 消去 $p$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{y}{1-y}=\alpha\dfrac{x}{1-x}$ | （6-13） |
| **文字式** | $\dfrac{\text{汽相易挥发组分}}{\text{汽相难挥发组分}}=\text{相对挥发度}\times\dfrac{\text{液相易挥发组分}}{\text{液相难挥发组分}}$ |  |

解得 $y$ 与 $x$ 的显式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y=\dfrac{\alpha x}{1+(\alpha-1)x}$，$x=\dfrac{y}{\alpha-(\alpha-1)y}$ | （6-14）（6-15） |
| **文字式** | $\text{汽相组成}=\dfrac{\alpha\times\text{液相组成}}{1+(\alpha-1)\times\text{液相组成}}$ |  |

已知 $\alpha$ 与 $x$ 即可求平衡的 $y$，反之亦然。

## α 取常数与几何平均（`#L11250-#L11260`）

$y$-$x$ 曲线上每点温度不同 ⇒ 每点 $\alpha$ 不同。但理想溶液的 $\alpha=p_A^{\circ}/p_B^{\circ}$ **随温度变化不大**，工程上取操作温度范围内两端 $\alpha$ 的**几何平均值**当作常数：

$$\alpha=\sqrt{\alpha_1\alpha_2}$$

- $\alpha=1$：平衡曲线与对角线重合，无法用普通精馏分离；
- $\alpha$ 越大：曲线离对角线越远、同一 $x$ 对应 $y$ 越大、越易分离；
- 泡点越高 ⇒ $\alpha$ 越小；**总压增大 ⇒ 泡点升高 ⇒ $\alpha$ 减小**（`#L11260`）。

## 例6-3（`#L11262-#L11286`）

正戊烷-正己烷，$p$=101.33 kPa：36.1 ℃ 时 $\alpha_1=101.33/31.98=3.169$；68.7 ℃ 时 $\alpha_2=273.28/101.33=2.697$（高温 $\alpha$ 小）。

$$\alpha=\sqrt{3.169\times2.697}=2.923$$

$$y=\frac{2.923x}{1+1.923x}$$

用表6-2 的 $x$ 值代入，得表6-3：$x$=0.82/0.62/0.45/0.30/0.18/0.07 → $y$=0.93/0.83/0.71/0.56/0.39/0.18，与例6-1 逐点计算基本一致——说明式6-14 适用于理想溶液。

## 判断

- $\alpha$ 是整章最重要的单一参数：理论板数、最小回流比、芬斯克方程全都以它为输入。$\alpha$ 从 3 降到 1.5，同样分离要求下板数会成倍增加。
- 几何平均是"工程近似"，只在操作温度区间不宽时可靠；跨大温差（如深冷精馏）应分段取 $\alpha$ 或用逐板计算。
- 恒沸点处 $\alpha=1$，这条判据比"查相图"更本质——它说明恒沸是热力学约束，不是设备问题。

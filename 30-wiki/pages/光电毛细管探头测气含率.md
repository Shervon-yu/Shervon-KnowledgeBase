# 光电毛细管探头测气含率

## 原理（`#L348`）

测量一定时间内流过毛细管某一截面的气液流量来确定气含率：把喇叭口伸入流场抽吸，毛细管内用光电检测气液交替。

## 抽吸速率问题（`#L348`）

流过截面的气量≠喇叭口外来流中的气量：

- 抽吸速率低时，部分外来流气体**未被抽进**毛细管；
- 抽吸速率增大，管内气量逐渐增加；
- 达到**某一临界抽吸速率**时，喇叭口吸引区的外来流气体全部被抽进；此后管内气量不再随抽吸速率变化。

## Greaves 公式（`#L348-#L351`）

M. Greaves 假定"临界抽吸下喇叭口内外气含率相等"，得：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\Phi_i=\dfrac{1}{2}\left[1-\sqrt{1-\dfrac{16\Phi_{0c}Q_{1c}}{(1-\Phi_{0c})S_0}}\right]$ | （1.5） |
| **文字式** | $\text{取样微元气含率}=\dfrac{1}{2}\left[1-\sqrt{1-\dfrac{16\times\text{喇叭口气含率}\times\text{毛细管气量}}{(1-\text{喇叭口气含率})\times\text{喇叭口面积}}}\right]$ |  |

**偏大原因**：实际喇叭口内局部气含率 $\Phi_c>\Phi_i$，即"内外相等"的假定不成立。

## 张志斌改进式（`#L354-#L357`）

考虑喇叭口内外气液**轴向运动差异**，给出内外气含率的定量关系：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\Phi_i=\dfrac{1}{2}\left[1-\sqrt{1-16\left(\dfrac{\pi}{4}d_k^2\nu_b^*/1.19-Q_1\right)\dfrac{P^*}{P_0S_0}}\right]$ | （1.6） |
| **文字式** | $\text{取样微元气含率}=\dfrac{1}{2}\left[1-\sqrt{1-16\left(\text{毛细管截面气量}/1.19-\text{抽吸液量}\right)\dfrac{\text{检测处压力}}{\text{喇叭口压力}\times\text{喇叭口面积}}}\right]$ |  |

## 判断

- 毛细管法的核心矛盾是"取样必扰动"：抽吸本身改变了喇叭口附近的流场，所谓"临界抽吸"只是让**取样**充分，并不等于**无扰动**。
- Greaves 式偏大是系统性的（假定 $\Phi_c=\Phi_i$ 且忽略了气泡相对速度与变形），张志斌式的改进正是补上了轴向速度差这一项。
- （1.6）中出现常数 1.19 与压力比 $P^*/P_0$，说明标定必须在与实际工况相同的压力下做，否则换算失真。

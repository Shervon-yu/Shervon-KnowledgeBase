# 气液搅拌设备设计要点

## 设计参数与设备型式

功率输入、流动区、界面积、传质系数是核心参数；界面积是传递发生的基础，传质系数决定能否达标，而产生界面积需要足够功率输入（`#L2288`）。常见气-液接触器/反应器（表2-16，`#L2290-#L2296`）：喷射、气泡塔、鼓泡釜、导流筒搅拌釜、静态混合器、离心泵。

功率排序（`#L2300`）：喷射与气泡塔最小 → 鼓泡釜略高 → 导流筒搅拌釜较高 → 静态混合器与离心泵也需较高功率。鼓泡釜的气-液接触通常提供较高的界面积与传质系数。

## 搅拌器选型

- 防止气体短路：搅拌器通常采用**中间带水平圆盘**的结构（`#L2302`）。
- 搅拌产生的低压漩涡会吸气，但气量过大时也会气蚀，使搅拌作用大降（`#L2302`）。
- 气体处理能力随叶片数增加而增大；典型结构为六叶 Rushton 盘形涡轮（图2-17a），12/18 叶或凹面叶片的涡轮湍动更强、混合效率更高（`#L2304`）。
- 安装方式也影响传质：四氟乙烯聚合釜研究表明卧式搅拌可使传质系数提高一个数量级（`#L2318`）。
- 气-液-固三相时可用多个搅拌器分工：一个吸气、一个悬浮固体（`#L2320`）。

## 容器与内件（推荐值）

`#L2324`：

| 项目 | 推荐值 |
|:---|:---|
| 筒体 | 圆柱形 |
| 挡板 | 宽 $D/10$ 的全长挡板 |
| 挡板数 | $D<\phi3000$ mm 用 4 块；更大容器 6 或 8 块；有蛇管等构件时仍应保证该数量 |
| 气体分布环 | 置于搅拌器下方，距离近 $D/2$ |
| 分散物系高度 | $D$、$2D$ 或 $3D$ |
| 搅拌器层数 | $H=D$ 单层；$H=2D$ 或 $3D$ 时加装，层间距约 $D$ |

## 电机功率方案

通气时功率低、停气瞬间功率突增（`#L2322`）。两种选型：

1. 按不通气功率选——保险但能量利用率低；
2. 按通气功率选 + 多级/无级调速——利用率高，需在通气量与转速间联动。

# 蒸馏-拉乌尔定律与汽液平衡

## 定义

- **拉乌尔定律**：溶液中溶剂 A 的蒸气分压等于同温度纯溶剂饱和蒸气压与其液相摩尔分数的乘积（#L12225）。
- **理想溶液**：在**全部浓度范围**内符合拉乌尔定律的溶液；其宏观表现是两组分混合时**不产生热效应、不发生体积变化**（#L12233）。
- **泡点线**（液相线）：溶液开始沸腾起泡的温度-组成关系；**露点线**（汽相线）：过热蒸气开始冷凝析出液滴的关系（#L12257-#L12259）。

## 判据 / 计算

纯组分饱和蒸气压随温度变化（Antoine 方程）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lg p^{\circ}=A-\dfrac{B}{t+C}$ | （11-1） |
| **文字式** | $\lg\left(\text{饱和蒸气压}_{\text{【kPa】}}\right)=A-\dfrac{B}{\text{温度}_{\text{【℃】}}+C}$ |  |

原书编号：式(6-1)（#L12212），$A$、$B$、$C$ 为 Antoine 常数（附录十列若干液体）。

拉乌尔定律（组分 A）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_A=p_A^{\circ}\,x_A$ | （11-2） |
| **文字式** | $\text{蒸气分压}_{\text{【kPa】}}=\text{纯组分饱和蒸气压}_{\text{【kPa】}}\times\text{液相摩尔分数}$ |  |

原书编号：式(6-2)（#L12222）。

拉乌尔定律（组分 B，理想溶液两组分都适用）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_B=p_B^{\circ}\,x_B=p_B^{\circ}\left(1-x_A\right)$ | （11-3） |
| **文字式** | $\text{组分 B 蒸气分压}_{\text{【kPa】}}=\text{纯 B 饱和蒸气压}_{\text{【kPa】}}\times\left(1-\text{液相 A 摩尔分数}\right)$ |  |

原书编号：式(6-3)（#L12238）。

汽液平衡关系的用法（#L12261）：恒压下把组成 $x_s$ 的混合液加热到某一温度，必分成互成平衡的汽液两相，汽相组成 $y$、液相组成 $x$，且 **$y>x$**（易挥发组分在汽相中富集）——这是蒸馏原理的基础。

## 适用范围与边界

- 拉乌尔定律对**大多数溶液只在浓度很低时**适用：稀溶液中溶质分子少、溶剂处境接近纯态，故溶剂服从（#L12227）。
- 对**大多数浓溶液不适用**；只有性质极近似的物系（苯-甲苯、正己烷-正庚烷、甲醇-乙醇等）在全浓度范围适用（#L12229）。
- 理想溶液假定无热效应、无体积变化；实际溶液有偏差，需用活度系数修正（本书 §6.1 后文）。
- 温度升高，$p^{\circ}$ 增大（Antoine 式），故同一组成的平衡温度与压力耦合：恒压图（$t$-$y$-$x$）与恒温图不同（#L12249）。

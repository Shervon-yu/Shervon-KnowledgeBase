# 圆筒径向接管补强的分析法

等面积法是"几何补料"——削掉多少承载面积就补回多少。分析法走另一条路：按**弹性薄壳理论**算出开孔处的实际应力，直接与许用值比。标准明说两条路在设计可靠性上等价（8.6.1.1，`#L8296`），选哪条只看手续与工况：核能装置一类的特殊容器**只能用分析法**（8.6.1.4，`#L8306`）。

## 一、适用条件（8.6.2，`#L8308-#L8326`）

| 项 | 要求 |
|:--|:--|
| 结构 | 内压、单个径向接管；可带径向内伸接管 |
| 多开孔 | 相邻两孔边缘间距 $\ge 2\sqrt{D_i\delta_n}$ |
| 材料 | 圆筒/接管/补强件的 $R_{eL}/R_m\le0.8$ |
| 焊缝 | 接管或补强件与壳体**截面全熔透**；补强区内 A、B 类接头不得有超标缺陷 |
| 补强范围 | 自交线起 圆筒 $l>\sqrt{D_i\delta_n}$，接管 $l_t>\sqrt{d_o\delta_{nt}}$，或整体加厚圆筒 |
| 角焊缝 | 焊脚分别不小于 $\delta_n/2$ 与 $\delta_{nt}/2$；接管内壁与圆筒内壁交线圆角半径在 $\delta_n/8\sim\delta_n/2$ |
| 参数 | $0.1\le\rho\le0.9$；$d/\sqrt{D\delta_e}\le12$；$\max[0.5,\rho]\le\delta_{et}/\delta_e\le2$ |

出这个参数盒子就不能用分析法，退回等面积法或改结构。

## 二、等效应力校核（8.6.3.1，`#L8334-#L8372`）

中面直径先按有效厚度取：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $D=D_i+\delta_e+2C_s$；$\quad d=d_0-\delta_{et}$ | （8-36）（8-37） |
| **文字式** | $\text{圆筒中面直径}=\text{内直径}+\text{有效厚度}+2\times\text{厚度附加量}$；$\quad\text{接管中面直径}=\text{接管外直径}-\text{接管有效厚度}$ |  |

开孔参数与两族应力系数：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\rho\sqrt{D/\delta_e}=d/\sqrt{D\delta_e}$ |  |
| **文字式** | $\text{开孔参数}=\text{开孔率}\times\sqrt{\text{圆筒中面直径}/\text{圆筒有效厚度}}=\text{接管中面直径}/\sqrt{\text{圆筒中面直径}\times\text{圆筒有效厚度}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $S_{II}=K_m\dfrac{pD}{2\delta_e}$；$\quad S_{IV}=K\dfrac{pD}{2\delta_e}$ | （8-38）（8-39） |
| **文字式** | $\text{等效薄膜应力}=\text{薄膜应力系数}_m\times\dfrac{\text{设计压力}\times\text{圆筒中面直径}}{2\times\text{圆筒有效厚度}}$；$\quad\text{等效总应力}=\text{总应力系数}\times\dfrac{\text{设计压力}\times\text{圆筒中面直径}}{2\times\text{圆筒有效厚度}}$ |  |

$K_m$、$K$ 由 $\rho$、$\lambda$、$\delta_{et}/\delta_e$ 查图 8-13（共 14 张分图，按 $\rho=0.1\sim0.9$ 与 K/K_m 分族；横坐标 $\lambda$，纵坐标系数，族参数为厚度比 $\delta_{et}/\delta_e$，遇中间值内插）。

校核：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $S_{II}\le n_{II}[\sigma]^t$；$\quad S_{IV}\le n_{IV}[\sigma]^t$ | （8-40）（8-41） |
| **文字式** | $\text{等效薄膜应力}\le\text{薄膜校核系数}\times\text{许用应力}$；$\quad\text{等效总应力}\le\text{总应力校核系数}\times\text{许用应力}$ |  |

$n_{II}=2.2$（有特殊要求的容器可 1.5~2.2），$n_{IV}=2.6$；$[\sigma]^t$ 取圆筒、接管、补强件三者中的**较小值**。

## 三、不满足时怎么调厚度（8.6.3.2，`#L8374-#L8394`）

两条路：直接加厚圆筒重算；或先加厚接管、必要时再加圆筒。后者要算"目标系数"：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\delta=\dfrac{pD}{2[\sigma]_s^t}$ | （8-42） |
| **文字式** | $\text{圆筒计算厚度}=\dfrac{\text{设计压力}\times\text{圆筒中面直径}}{2\times\text{圆筒许用应力}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_m'=n_{II}\dfrac{\delta_e}{\delta}\cdot\dfrac{[\sigma]^t}{[\sigma]_s^t}$（或 $K'=2.6\dfrac{\delta_e}{\delta}\cdot\dfrac{[\sigma]^t}{[\sigma]_s^t}$） | （8-43） |
| **文字式** | $\text{目标薄膜系数}=\text{薄膜校核系数}\times\dfrac{\text{圆筒有效厚度}}{\text{圆筒计算厚度}}\times\dfrac{\text{取小许用应力}}{\text{圆筒许用应力}}$ |  |

在 $\rho=d/D$ 那张图上，从纵坐标 $K_m'$（或 $K'$）水平右移到对应 $\lambda$ 的竖线，交点所在的 $\delta_{et}/\delta_e$ 族就是所需厚度比，按该比例加厚接管。**交点若跑出曲线族范围，不许外延**，只能加厚圆筒重算（`#L8394`）。

## 四、另一条等效途径：直接求补强尺寸（8.6.4，`#L8521-#L8583`）

不算应力，改算"够不够厚"。先设初值 $\delta_e^{(0)}$、$\delta_{et}^{(0)}$，取中面半径 $R=(D_i+\delta_e^{(0)})/2+C_s$、$r=(d_0-\delta_{et}^{(0)})/2$、开孔率 $\rho=r/R$，再用同一个中间参数：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $U=\dfrac{[\sigma]^t}{p}\ \left(=\dfrac{R}{\delta}=\dfrac{r}{\delta_t}\right)$ |  |
| **文字式** | $\text{强度比}=\dfrac{\text{取小许用应力}}{\text{设计压力}}\ \left(=\dfrac{\text{圆筒中面半径}}{\text{圆筒计算厚度}}=\dfrac{\text{接管中面半径}}{\text{接管计算厚度}}\right)$ |  |

于是计算厚度 $\delta=R/U$、$\delta_t=r/U$，补强系数 $h^{(0)}=\delta_e^{(0)}/\delta$、$g^{(0)}=\delta_{et}^{(0)}/\delta_t$。然后二选一（表 8-3 方式一/方式二）：

- **方式一**：令 $h=h^{(0)}$，由 $\rho,U,h$ 查图 8-14 得 $g_{\min}$，校核 $(\delta_t)_{\min}=g_{\min}\delta_t\le\delta_{et}^{(0)}$；
- **方式二**：令 $g=g^{(0)}$，由 $\rho,U,g$ 查得 $h_{\min}$，校核 $\delta_{\min}=h_{\min}\delta\le\delta_e^{(0)}$。

图 8-14 是按 $\rho_0=0.1$ 起分族的 $g$ 曲线（横坐标 $U$，纵坐标 $g$，族参数 $h$，遇中间值按 $\rho$ 双向内插）。同样**不许外延**：某点落图外就改初值重算。

## 判断

- 分析法与等面积法的差别不在保守程度，而在**信息量**：等面积法只看几何（开了多大孔、补了多少料），分析法把 $\rho$、$\lambda$、$\delta_{et}/\delta_e$ 三个无量纲量一起算进 $K_m$、$K$——同一块补强板，接管越薄、开孔越大，$K$ 涨得越快，等面积法看不见这个趋势。
- $n_{II}=2.2$、$n_{IV}=2.6$ 是"等效薄膜/总应力"的许用倍数，不是安全系数：薄膜应力的极限取 2.2 倍许用应力，对应防止整体屈服；总应力取 2.6 倍，对应允许孔边局部塑性再安定。核电容器收紧到 1.5~2.2，是把安定性余量再加一层。
- $[\sigma]^t$ 取三者最小，是因为等效薄膜应力的分母只用一个厚度——补强件比壳体弱时，孔边实际承载按最弱材料走。
- 不许外延（`#L8394`、`#L8577`）这条硬规定的本质是：图表只覆盖标准验算过的参数域，外延插值等于自己造判据。
- 分析法的"两条等效途径"不是两种精度：等效应力校核回答"现有厚度行不行"，尺寸设计回答"最少要多厚"，两者用的是同一套 $\rho$、$U$、$K_m$ 关系，只是求解方向相反。

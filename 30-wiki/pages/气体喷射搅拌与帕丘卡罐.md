# 气体喷射搅拌与帕丘卡罐

## 什么时候不用桨

腐蚀性液体、高温高压操作、冶金浸取、含高固体量的泥浆——这些场合**气体喷射有时比机械搅拌更适宜**（`#L9735`）：没有转动部件、没有轴封、能承受腐蚀与高压。

## §8.8.1 单喷嘴的三阶段

Oyama 的实验（`#L9739`）：长方形容器 11.5×7.5×19 cm，喷嘴 0.57~2.60 mm，液体为甲醇、水、甘油。

增加排气速率的三个阶段（`#L9743`–`#L9753`）：

| 阶段 | 气泡形态 | 特征 |
|:---|:---|:---|
| 1 | 互不干涉的球形 | 形成时间约 0.6 s |
| 2 | 压扁的蘑菇形 | 上升到离喷嘴 7 cm 以上速度趋于定值 0.43 m/s，**约为单气泡终端速度的 4 倍** |
| 3 | 再碎裂、以湍动形式上升 | **压力微小变化就使 2→3 突然过渡** |

图8.15 的 $Q$–$P$ 关系（`#L9755`）：AB 段（阶段 1、2）气泡不破裂，BC 段为阶段 3。同样气量下小喷嘴要更高压力；但临界点 B 处**小喷嘴的临界流率 $Q_c$ 更小**。

**临界判据**（`#L9763`）：$Q_c$ 与密度、黏度关系不大，基本只由 $d_0$ 决定：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{Q_c}{d_0\nu_{\text{空气}}}=210\sim250$ | （8.8′） |
| **文字式** | 临界流率的雷诺数在 210~250 之间——超过它气泡才开始碎裂 |  |

### 气泡碎裂区的流量

高黏液体（`#L9769`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{Q}{d_0\nu}=10.5\left(\dfrac{\sigma g_c d_0}{\rho\nu^{2}}\right)^{0.48}\left(\dfrac{Pd_0}{\sigma}\right)^{0.75}$ | （8.51） |
| **文字式** | 无因次流率 = 10.5 × 毛细-重力参数^0.48 × 无因次压力^0.75 |  |

低黏液体（`#L9773`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{Q}{d_0\nu}=21\left(\dfrac{\sigma g_c d_0}{\rho\nu^{2}}\right)^{0.48}\left(\dfrac{Pd_0}{\sigma}\right)^{0.65}$ | （8.52） |
| **文字式** | 同形，系数由 10.5 变 21、压力指数由 0.75 降到 0.65 |  |

整理后（`#L9787`）：$Q\propto d_0^{0.2}P^{0.75\sim0.65}\rho^{-0.48}\nu^{0.04}/\sigma^{0.27\sim0.17}$——**表面张力与黏度对排气速率影响很小**，主要是孔径与压力的作用。

高黏与低黏之差来自气泡运动：高黏液体中气泡的螺旋形运动被抑制，流型不同，成泡阻力也不同（`#L9783`）。

## 例8.4 单喷嘴气量估算

`#L9789`–`#L9809`：器底 60 cm 深处、$d_0=3$ mm 单喷嘴，20°C 水，0.5 kg/cm² 表压。

1. 有效压差 $P=(0.5-0.6\times0.0999)$ kg/cm² $=4.4\times10^{3}$ kg/m²（扣液柱静压）；
2. 用低黏式(8.52)代 $d_0=0.003$、$\nu=1.01\times10^{-6}$、$\sigma=7.37\times10^{-3}$、$\rho=1000$；
3. 得 $Q=2.94\times10^{-3}$ m³/s $=2.94$ l/s；
4. 校核 $Q/(d_0\nu_{\text{空气}})=1.05\times10^{5}>250$ → 确在第三阶段。

## §8.8.2 气体搅拌的能量

Lamont 的分析（`#L9813`）：压力下给定体积空气含一定能量，气泡上升时膨胀并把能量传给液体。假设等温膨胀、忽略喷嘴与进入空气的动能（`#L9817`、`#L9821`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $W=144P_1Q_1\ln\dfrac{P_2}{P_1}$ | （8.53） |
| **文字式** | 等温膨胀功【lb·ft/min】= 144 × 顶部绝压 × 空气体积流率 × ln(底部/顶部压力) |  |
| **符号式** | $W=144P_1Q_1\ln\dfrac{P_1+(\rho/144)H}{P_1}$ | （8.54） |
| **文字式** | 同一功写成"顶部压力 + 液柱压力"的形式，$H$ 为通气深度【ft】 |  |

**量级**（`#L9835`）：比重 1.6 的泥浆、深 45 ft，每 100 ft³/min 自由空气的能量传递率 242,000 lb·ft/min $=7.34$ HP。

**与机械搅拌的关键差别**（`#L9837`）：机械能只在叶轮附近传递，而气体搅拌输入的能量**可扩散到整个罐深**。这是气体搅拌在深罐、大高径比场合的优势。

### 有多少能量变成湍流

气泡上升时相对液体滑动，损失一部分位能（`#L9841`–`#L9855`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\mathrm{d}\theta=\dfrac{\mathrm{d}h}{u_{\text{表观}}}=\dfrac{\mathrm{d}h}{u+v}$;\qquad $\mathrm{d}h'=u\,\mathrm{d}\theta=\dfrac{u}{u+v}\mathrm{d}h$ | （8.55）（8.56） |
| **文字式** | 上升 $dh$ 所需时间由气泡相对速度 $u$ 与液体速度 $v$ 之和决定；相对滑动距离按比例缩小 |  |
| **符号式** | $\dfrac{\mathrm{d}W_T}{\mathrm{d}h'}=\dfrac{\mathrm{d}W}{\mathrm{d}h}\left(\dfrac{u}{u+v}\right)$ | （8.57） |
| **文字式** | 湍动耗能 = 总能量 × $u/(u+v)$，即总传递能量的 $1/(1+v/u)$ 损失于小尺度湍动 |  |

- 无总体液流（$v=0$）时全部位能变湍流；
- **泥浆循环量越大，损失于滑动的比例越低**；
- 无中心导流柱的帕丘卡罐约损失 15%，气泡越细则损失越小（`#L9855`）。

### 需要多少气量

Kauffman 的推荐（表8.3，液深 9 ft，每 ft² 罐截面的自由空气量，`#L9859`–`#L9864`）：

| 搅拌程度 | 空气量【ft³/min per ft²】 |
|:---|:---|
| 中等 | 0.65 |
| 完全 | 1.3 |
| 剧烈 | 3.1 |

## §8.8.3 帕丘卡罐的循环

气泡柱上升带动液体上升、沿器壁下降再吸入柱内（`#L9868`）。三种工况（`#L9888`）：

1. 排气不多时，循环主要围绕气泡柱外侧；
2. 增加通气率后，**空气柱像喷嘴一样把液体吸入气泡群**，循环大大加强；
3. 再增气量则液面剧烈扰动直至飞溅。

低黏液体中还可能有气泡沿螺旋线上升引起的水平环流（`#L9890`）。

三种结构（图8.16，`#L9892`）：(a) 中心柱几乎与罐同高；(b) Von Bernewitz 改进型（氰化物生产）；(c) 自由气提式（南非铀厂）。

**标准帕丘卡罐**（`#L9894`）：$D=22.5$ ft、底锥角 60°、装 45 ft 深比重 1.6 的泥浆、通常 300 ft³/min 自由空气。

### 循环量的估算

假设能量传递在所有平面上相似、终端气泡速度在罐底瞬时建立，则任一轴线上泥浆上升速度均匀（`#L9906`）。取中心 $v_{\max}=8$ ft/s、边界 $v=0$ 的线性分布，平均上升速度 $v_{\max}/3=2.67$ ft/s（`#L9908`）。

相对鼓泡速度 $u=0.5$ ft/s（$d_p=2$ mm）→ 滑动损失比 $u/(u+v)=0.5/(0.5+2.67)=0.16$，即损失 16%；总能量与滑动损失之差用于提升泥浆（`#L9910`）。

$$q=\frac{W\left\{1-\frac{u}{u+v}\right\}}{\rho(v^{2}/2g)}=\frac{726000\times0.84}{1000\times(2.67^{2}/2g)}=6100\ \mathrm{ft^{3}/min}$$

于是罐顶上升流面积 $38$ ft²、直径 7 ft（`#L9916`）。

## §8.8.4 空气提升

当上升流速太低、器底鼓泡不足以流化固体时，用空气提升管（图8.16a/b）。能量消耗在三项水力头（`#L9922`–`#L9932`）：

| 项 | 数值 |
|:---|:---|
| 进口压头（Borda 型入口） | $0.83v^{2}/2g$ |
| 摩擦头（$f=0.03$、$L=45$ ft、$d=1.5$ ft） | $0.9v^{2}/2g$ |
| 速度头 | $1.0v^{2}/2g$ |
| **总水力头** | $2.76v^{2}/2g$ |

由此算得中心柱输送速率 1180 ft³/min（`#L9934`）。Cook 与 Waters 用实测建议总水力头系数取 **4.6** 而非 2.73，则预测流量为 960 ft³/min（`#L9936`）——**理论值高估 23%**，设计应取实测系数。

## §8.8.5 两个工业装置

- **Dorr 搅拌器**（图8.18a）：空气提升 + 桨式搅拌的结合，目的是增加翻动（`#L9946`）；
- **Denver 搅拌罐**（图8.18b）：边壁空气提升辅助桨叶作用。

**组合的逻辑**：气体提升负责大范围循环（能量能到全深度），桨叶负责局部高剪切（气体做不到），各取所长。

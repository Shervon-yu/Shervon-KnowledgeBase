# 往复泵

## 工作原理与部件（`#L3921-#L3937`）

部件：泵缸、活塞、活塞杆、吸入阀、排出阀（均为单向阀）。曲柄连杆把旋转变成往复：

- 活塞右移 → 缸容积增大、压力降低 → 排出阀被管内压力压关、吸入阀被压差顶开 → 吸液；
- 活塞左移 → 缸内压力升高 → 吸入阀关、排出阀开 → 排液。

活塞两端间移动距离称**行程**（stroke）。有蒸汽机直接驱动的型式。

## 自吸与转速限制（`#L3939`）

- 启动前**不用灌泵**，能自动吸液（自吸能力）；但希望缸内有液，避免干摩擦。
- 转速不能太高：$n$ 太大则吸入阻力大，缸内压力低于饱和蒸气压会抽空失去吸液能力。一般 **$n=80\sim200$ r/min**，吸入高度 **4~5 m**。

## 类型与流量（`#L3941-#L3987`）

| 类型 | 排液特点 |
|:---|:---|
| 单动泵 | 往复一次只吸、排各一次，排液周期性间断，瞬时流量呈半波形 |
| 双动泵 | 可不间断排液，但流量仍不均匀 |
| 三联泵 | 3 台单动泵同曲轴、相位差 $2\pi/3$，改善均匀度 |
| 柱塞泵 | 向高压系统输送液体 |

空气室：装在进、出口，利用气体压缩与膨胀缓冲，减小流量脉动。

理论平均流量：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{V\text{理}}=ASn$ | （2-17） |
| **文字式** | $\text{理论流量}_{\text{【m³/min】}}=\text{活塞截面积}_{\text{【m²】}}\times\text{行程}_{\text{【m】}}\times\text{往复频率}_{\text{【1/min】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{V\text{理}}=(2A-a)Sn$ | （2-18） |
| **文字式** | $\text{双动泵理论流量}=(\text{2}\times\text{活塞截面积}-\text{活塞杆截面积})\times\text{行程}\times\text{往复频率}$ |  |

实际流量：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_V=\eta_v q_{V\text{理}}$ | （2-19） |
| **文字式** | $\text{实际流量}=\text{容积效率}\times\text{理论流量}$ |  |

$\eta_v$ 一般 0.9~0.97；转速增大受汽蚀影响可降到 0.8 以下。

## 扬程与流量调节（`#L3989-#L4015`）

- 扬程（排出压力）与流量**几乎无关**（只是高压时容积效率降低、流量略减）；工作点仍由管路曲线与泵 $H-q_V$ 曲线交点定；工作扬程不得超过由机械强度、密封、电机功率决定的最大允许扬程。
- **关出口阀不能调流量**（容积式泵，关阀只会升压）——这是与离心泵最本质的区别。

三种调节方法：

| 方法 | 说明 | 代价 |
|:---|:---|:---|
| 旁路调节 | 改变旁路阀开度，让部分液体回流到进口；兼作安全阀保护 | 简便，但增加功率消耗 |
| 变转速 | 改往复频率 | 需变速原动机 |
| 变行程 | 偏心轮改偏心距（计量泵/比例泵） | 可精确调节、按比例输出 |

## 正位移特性（`#L4011-#L4015`）

靠"吸入后减小容积、挤压排出"的泵称**容积式泵/正位移泵**（positive displacement pump）。共同特性：

- **理论流量由几何尺寸与往复频率决定，与管路特性无关**；
- **泵提供的压头只由管路特性决定**。

## 判断

- 正位移特性解释了两件事：为什么关阀不能调节（流量与压头解耦），以及为什么必须设安全阀/旁路（管路堵死时压力会一直升到破坏）。
- 往复泵适合高压小流量、高黏度、需精确计量；结构复杂、流量脉动是它的固有缺点。

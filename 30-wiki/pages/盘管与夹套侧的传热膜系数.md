# 盘管与夹套侧的传热膜系数

## 盘管内（光滑圆管、充分湍流）

$Re>10000$、$0.7<Pr<160$、$L/d>30\sim40$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha_2=0.023\dfrac{\lambda}{d}\left(\dfrac{\rho du}{\mu}\right)^{0.8}\left(\dfrac{C_p\mu}{\lambda}\right)^{b}$ | （7-65） |
| **文字式** | $\text{管内膜系数}=0.023\times\dfrac{\text{热导率}}{\text{管内径}}\times Re^{0.8}\times Pr^{\,b}$，加热 $b=0.4$、冷却 $b=0.3$ |  |

（`#L7583-#L7597`）

## 四种修正

| 情形 | 修正 | 式 |
|:---|:---|:---:|
| 弯管（离心力加剧扰动） | $\alpha_2'=\alpha_2\left(1+1.77\dfrac{d_i}{R}\right)$ | （7-66） |
| 过渡流 $Re=2000\sim10000$ | 乘 $f=1-\dfrac{6\times10^{5}}{Re^{1.8}}$ | （7-67） |
| 层流 $Re<2100$（螺旋管） | $\alpha_2=1.86\dfrac{\lambda}{d}\left[Re\cdot Pr\cdot\dfrac{D_e}{L}\right]^{0.34}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}$ | （7-68） |
| 短管 $L/d<30\sim40$ | 乘 1.02~1.07 | — |

（`#L7603-#L7621`）

## 高黏液体（7-69，$Re>10000$、$Pr=0.5\sim100$）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\alpha_2=0.027\dfrac{\lambda}{d}Re^{0.8}Pr^{0.33}\left(\dfrac{\mu}{\mu_w}\right)^{0.14}$ | （7-69） |
| **文字式** | 系数由 0.023 改 0.027，Pr 指数改 0.33，并显式引入黏度比 |  |

工程上不必迭代壁温：液体被加热取 $(\mu/\mu_w)^{0.14}=1.05$，被冷却取 0.95（式7-70/7-71）（`#L7633-#L7639`）。

## 非圆管与环隙

- 简便法：仍用圆管式，定性尺寸换成当量直径 $d_e=4A_h/L_h$；
- 精确法：套管环隙在 $Re=1.2\times10^4\sim2.2\times10^4$、$d_2/d_1=1.65\sim17$ 时用式（7-72），多乘 $(d_2/d_1)^{0.53}$（`#L7643-#L7657`）。

## 夹套侧（表7-9）

| 夹套型式 | $d_e$ | 流通面积 $A_x$ | 备注 |
|:---|:---|:---|:---|
| 螺旋导流板夹套 | $4W$ | $PW$ | 流速取"夹套与外无泄漏时流速"的 60% |
| 半管螺旋夹套（中心角 180°） | $(\pi/2)d_i$ | $(\pi/8)d_i^2$ | $A$ = 半管下面积 + 0.6×半管间面积 |
| 半管螺旋（中心角 120°） | $0.708d_i$ | $0.154d_i^2$ | — |
| 整体夹套 | $(D_{jo}^2-D_{ji}^2)/D_{ji}$ | $\pi(D_{jo}^2-D_{ji}^2)/4$ | 蒸汽冷凝时取 $h=5670$ W/(m²·K) |

（`#L7669-#L7688`；W 环隙宽，P 螺距，$d_i$ 管内径，$D_{jo}$ 夹套外径，$D_{ji}$ 夹套内径）

环形夹套低 Re（层流）时自然对流起作用，通水时用式（7-74）（含 $Gr^{0.05}$、$(D_{jo}/D_{ji})^{0.8}$）（`#L7690-#L7704`）。

## 扰流喷嘴的实际效果

整体夹套环形流道流速低、α 小；搪玻璃釜常在进口装扰流喷嘴使水成湍流：

| 指标 | 数值 |
|:---|:---|
| 达到湍流的水流速 | 0.8~1.2 m/s |
| 所需功率 | 41~82 W/m² |
| 得到的 α | 2500~3000 W/(m²·K) |

（`#L7706`）

## 判断

式（7-73）把 7-65 拆开后得到 $\alpha\propto u^{0.8}/d^{0.2}$：流速提一倍，α 提高约 74%；管径改一半，α 只变 15%。所以**提高夹套/盘管侧传热几乎只能靠提速**，这解释了扰流喷嘴为什么有效、以及为什么小管径盘管的 α 并不比大管径高多少。

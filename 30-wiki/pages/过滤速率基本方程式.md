# 过滤速率基本方程式

## 定义（`#L5179`）

- 过滤速率：单位时间滤过的滤液体积，m³/s，即 $dV/d\tau$；
- 过滤速度：单位过滤面积的过滤速率，m/s，即 $dV/(A\,d\tau)$。

## 速率=推动力/阻力（`#L5185-#L5187`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{dV}{A\,d\tau}=\dfrac{\Delta p}{\text{阻力}}$ | （3-31） |
| **文字式** | $\dfrac{\text{过滤速度}}{\text{}} = \dfrac{\text{过滤推动力}}{\text{过滤阻力}}$ |  |

推动力=总压差 $\Delta p=\Delta p_c+\Delta p_m$（滤饼压降+介质压降）；阻力=滤饼阻力+介质阻力。

## 从哈根-泊谡叶式借来（`#L5189-#L5221`）

滤饼内毛细孔道极细、流速很小，流动为层流，故用式(1-41)描述：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $u=\dfrac{d^2\Delta p_c}{32\mu l}$ | （3-32） |
| **文字式** | $\text{流速}_{\text{【m/s】}}=\dfrac{\text{孔径}^2\times\text{滤饼压降}_{\text{【Pa】}}}{32\times\text{黏度}_{\text{【Pa·s】}}\times\text{孔道长}_{\text{【m】}}}$ |  |

取 $l=\alpha V_c/A$、$u=\beta\,dV/(A\,d\tau)$，并把不可测的 $d$ 并入常数，令 $r=32\alpha\beta/d^2$，得

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{dV}{A\,d\tau}=\dfrac{\Delta p_c}{r\mu V_c/A}$ | （式 c，书内未编号） |
| **文字式** | $\dfrac{\text{过滤速度}}{\text{}}=\dfrac{\text{滤饼压降}}{\text{比阻}\times\text{黏度}\times\dfrac{\text{滤饼体积}}{\text{过滤面积}}}$ |  |

结论：任一瞬间过滤速度与 $\Delta p_c$ 成正比，与滤饼厚度（$V_c/A$）及滤液黏度成反比。

## 比阻 r（`#L5225-#L5227`）

滤饼阻力 $R_c=r\mu V_c/A$；$r$ 是**单位过滤面积上滤饼为 1 m³ 时的阻力**，称滤饼比阻，单位 1/m²。
$V_c=vV$（$v$ 为单位滤液对应的滤饼体积），故 $R_c=r\mu vV/A$（3-33）。

## 介质阻力折算成当量滤液体积（`#L5241-#L5253`）

把介质阻力折成"得到当量滤液量 $V_e$ 时所形成滤饼的阻力"：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $R_m=\dfrac{r\mu v V_e}{A}$，$R_c+R_m=\dfrac{r\mu v(V+V_e)}{A}$ | （3-34）（3-36） |
| **文字式** | $\text{介质阻力}=\dfrac{\text{比阻}\times\text{黏度}\times\dfrac{\text{滤饼体积}}{\text{滤液体积}}\times\text{当量滤液体积}}{\text{过滤面积}}$ |  |

## 过滤速率方程式（`#L5255-#L5263`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{dV}{d\tau}=\dfrac{A^2\Delta p}{r\mu v(V+V_e)}$ | （3-38） |
| **文字式** | $\dfrac{\text{过滤速率}_{\text{【m³/s】}}}{\text{}}=\dfrac{\text{过滤面积}^2\times\text{总压降}_{\text{【Pa】}}}{\text{比阻}\times\text{黏度}_{\text{【Pa·s】}}\times\dfrac{\text{滤饼体积}}{\text{滤液体积}}\times\left(\text{滤液体积}+\text{当量滤液体积}\right)}$ |  |

## 提高过滤速率的三条途径（`#L5271`）

原文给定：①适当增大 $\Delta p$；②升高温度以降低 $\mu$；③选阻力低的过滤介质。
注意原文说的是"适当地"增大压差——可压缩滤饼的 $r$ 随 $\Delta p$ 增大而增大，压差收益会被部分抵消（此句为判断，非原文）。

## 判断

- 该式的价值在于把"滤饼越积越厚"这一过程量收进 $(V+V_e)$ 一个因子，使速率衰减成为可积分的函数；恒压、恒速、先恒速后恒压的区别只体现在 $\Delta p$ 与 $dV/d\tau$ 谁是常数。
- $V_e$ 不是真实滤液量，只是把介质阻力折算成等价的滤饼厚度——所以它只用于计算，不能理解成"介质也形成了一层滤饼"。

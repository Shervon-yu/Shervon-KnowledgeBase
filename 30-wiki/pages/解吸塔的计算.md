# 解吸塔的计算

## 解吸是什么（`#L10304-#L10314`）

吸收液中的溶质若不作产品，需与吸收剂分离、把吸收剂再生循环——这就是**解吸**（脱吸），与吸收方向相反的过程。

用不互溶的惰性气体与吸收液接触：液相溶质分压 $p^{*}$ 大于气相分压 $p$（或液相浓度 $c$ 大于气相平衡浓度 $c^{*}$）→ 溶质由液相转入气相。

**推动力**：$(Y^{*}-Y)$ 或 $(X-X^{*})$。因方向相反，**操作线在平衡线下方**（图5-26b），与吸收正好颠倒。

强化手段：升温或减压 → $m$ 增大 → 平衡线远离操作线，推动力增大。

## 最小气液比（`#L10326-#L10334`）

设计时 $X_1$、$X_2$、$Y_2$ 已定（常取 $Y_2=0$），$Y_1$ 由气液比决定。

减小惰性气体量 → 出口 $Y_1$ 增大 → 操作线 $T$ 点向平衡线靠近；极限是与 $X_1$ 平衡的 $T^{*}$，此时解吸操作线斜率 $L/G$ 最大、气液比最小：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\left(\dfrac{G}{L}\right)_{\min}=\dfrac{X_1-X_2}{Y_1^{*}-Y_2}$ | （5-78 前式，书内未编号） |
| **文字式** | $\text{最小气液比}=\dfrac{\text{液相两端组成差}}{\text{与进塔液平衡的气相组成}-\text{进口气相组成}}$ |  |

实际气液比应大于最小值，以保证塔顶有推动力。

## 塔高与单元数（`#L10336-#L10362`）

以液相为推动力计算最方便：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Z=\dfrac{L}{K_Xa\Omega}\displaystyle\int_{X_2}^{X_1}\dfrac{\mathrm{d}X}{X-X^{*}}=H_{OL}N_{OL}$ | （5-79 前的 5-78） |
| **文字式** | $\text{填料层高度}=\text{液相总传质单元高度}\times\text{液相总传质单元数}$ |  |

$N_{OL}$ 三法：
- 图解积分：$N_{OL}=\int_{X_2}^{X_1}\frac{\mathrm{d}X}{X-X^{*}}$；
- 对数平均推动力法（亨利定律或线性化平衡）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_{OL}=\dfrac{X_1-X_2}{\Delta X_{\mathrm{m}}}$，$\Delta X_{\mathrm{m}}=\dfrac{(X_1-X_1^{*})-(X_2-X_2^{*})}{\ln\dfrac{X_1-X_1^{*}}{X_2-X_2^{*}}}$ | （5-79） |
| **文字式** | $\text{液相总单元数}=\dfrac{\text{液相组成变化}}{\text{液相对数平均推动力}}$ |  |

- 解吸因数法（$Y^{*}=mX$）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_{OL}=\dfrac{1}{1-\dfrac{L}{mG}}\ln\left[\left(1-\dfrac{L}{mG}\right)\dfrac{X_1-\dfrac{Y_2}{m}}{X_2-\dfrac{Y_2}{m}}+\dfrac{L}{mG}\right]$ | （5-80） |
| **文字式** | $\text{液相总单元数}=\dfrac{1}{1-\text{吸收因数}}\ln\left[(1-\text{吸收因数})\times\dfrac{\text{塔底液相推动力}}{\text{塔顶液相推动力}}+\text{吸收因数}\right]$ |  |

式5-80 与吸收的式5-76 结构相同，图5-23 可复用：吸收因数 $L/(mG)$ 换成解吸因数 $mG/L$，纵坐标换成 $\frac{X_2-Y_2/m}{X_1-Y_2/m}$，横坐标 $N_{OG}$ 换成 $N_{OL}$。解吸因数 $mG/L$ 增大 → $N_{OL}$ 减小。

## 判断

- 解吸的经济性通常比吸收更受关注：吸收剂再生越彻底（$X_2$ 越低），吸收塔越矮，但解吸要耗蒸汽/惰性气体、或抽真空。两塔的 $X_2$ 是同一个数——这是吸收-解吸联合装置的核心耦合点。
- 图5-23 的读数精度有限，解吸计算中 $mG/L$ 常不在推荐读数区，工程上优先用式5-80 直接算。

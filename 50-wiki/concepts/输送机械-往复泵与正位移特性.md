# 输送机械-往复泵与正位移特性

## 定义

**往复泵**：活塞（柱塞）在泵缸内往复移动，靠泵腔容积的周期性变化吸入并排出液体；活塞两端间移动的距离称**行程**（#L3936）。活塞往复一次只吸入和排出各一次称**单动泵**，排液周期间断、瞬时流量呈半波形；能在正反两个行程都排液的称**双动泵**，流量仍不均匀；三台单动泵以 $2\pi/3$ 相位差联合操作称**三联泵**（#L3958、#L3968）。

**正位移泵（容积式泵）**：靠减小泵腔容积把液体推挤排出（#L4012）。其共性称**正位移特性**——理论流量只由活塞截面积、行程、往复频率决定，与管路特性无关；泵对流体提供的压头只由管路特性决定（#L4016）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{V\text{理}}=A\,S\,n\,\eta_{v}$ | （2.2-1） |
| **文字式** | $\text{理论流量}_{\text{【m³/min】}}=\text{活塞截面积}_{\text{【m²】}}\times\text{行程}_{\text{【m】}}\times\text{往复频率}_{\text{【1/min】}}\times\text{容积效率}$ |  |

（$A=\frac{\pi}{4}D^{2}$，$D$ 为活塞直径；双动泵还需扣除活塞杆截面积 $a$，见 #L3980；$\eta_{v}$ 为容积效率，#L3986。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\eta_{v}=\dfrac{q_{V}}{q_{V\text{理}}}$ | （2.2-2） |
| **文字式** | $\text{容积效率}=\dfrac{\text{实际流量}_{\text{【m³/min】}}}{\text{理论流量}_{\text{【m³/min】}}}$ |  |

（$\eta_{v}$ 一般 0.9~0.97；转速提高会受汽蚀影响而下降，有时低于 0.8，#L3986。）

**流量调节**：改变活塞（柱塞）行程即可精确调节流量——计量泵靠偏心轮改变偏心距实现，多台共轴时称比例泵（#L4010）。

## 适用范围与边界

- 往复泵适合**小流量、高压头**；因是正位移式，**不能用出口阀关小来调节流量**（关小只会升压，本书未给安全阀条款，此处不扩写）。
- 理论流量与管路无关是正位移泵的判断依据（#L4016）；反之，离心泵流量随管路特性变——两者的运行调节逻辑不同。
- 容积效率随转速升高受汽蚀影响，#L3986；与离心泵汽蚀是同一个物理约束。
- 本书未给往复泵的压头-流量曲线。

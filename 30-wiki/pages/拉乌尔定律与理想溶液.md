# 拉乌尔定律与理想溶液

## 饱和蒸气压（`#L10990-#L10996`）

密闭容器中，一定温度下纯液体与蒸气达到平衡 → 饱和蒸气、饱和蒸气压 $p^{\circ}$。

$p^{\circ}$ 只是温度的函数，随温度升高而增大；同温下不同液体 $p^{\circ}$ 不同，**$p^{\circ}$ 越大液体越易挥发**。

$p^{\circ}$ 与 $t$ 的经验关系——安托因方程：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\lg p^{\circ}=A-\dfrac{B}{t+C}$ | （6-1） |
| **文字式** | $\lg\text{饱和蒸气压}_{\text{【kPa】}}=\text{常数}A-\dfrac{\text{常数}B}{\text{温度}_{\text{【℃】}}+\text{常数}C}$ |  |

$A$、$B$、$C$ 为安托因常数（查手册，本书附录十）。

## 拉乌尔定律（`#L10998-#L11006`）

混合液中 B 的存在使 A 的分压小于纯 A 的 $p^{\circ}$。对稀溶液（溶剂 A）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p_A=p_A^{\circ}x_A$ | （6-2） |
| **文字式** | $\text{组分}A\text{的蒸气分压}=\text{纯}A\text{的饱和蒸气压}\times\text{液相中}A\text{的摩尔分数}$ |  |

对组分 B 同理：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p_B=p_B^{\circ}x_B=p_B^{\circ}(1-x_A)$ | （6-3） |
| **文字式** | $\text{组分}B\text{的蒸气分压}=\text{纯}B\text{的饱和蒸气压}\times(1-\text{液相中}A\text{的摩尔分数})$ |  |

**微观解释**：稀溶液中溶剂分子周围几乎全是同类分子、逸出能力不变，只是浓度按 $x_A$ 打了折扣。

**适用范围**：大多数溶液只在低浓度时适用；但**性质极近似的物系**（苯-甲苯、正己烷-正庚烷、甲醇-乙醇）在全部浓度范围都适用。

## 理想溶液的定义与标志（`#L11008-#L11014`）

全部浓度范围都服从拉乌尔定律的溶液称**理想溶液**。

宏观标志（可用来判断）：各组分混合成溶液时**不产生热效应、不产生体积变化**——因为分子结构、大小接近、相互作用力几乎相等。

## 判断

- 工程上把苯-甲苯当理想溶液是常见简化，误差可接受（例6-2 用拉乌尔定律算苯-甲苯，与实测吻合）；但乙醇-水、丙酮-氯仿这类强非理想物系不能套用（见 [[非理想溶液与恒沸物]]）。
- 安托因方程是"相平衡计算的第一步"：任何 $t$-$y$-$x$ 计算都要先由 $t$ 算出 $p^{\circ}_A$、$p^{\circ}_B$。
- 压力升高 → 泡点升高 → $\alpha$ 减小（`#L11260`）：这是加压精馏分离变难的根源。

# 吸收-亨利定律

## 定义

当气液相平衡的溶解度曲线为直线时，气液两相组成之间的关系用**亨利定律**表示；亨利定律通常只适用于**稀溶液**，溶液越稀越服从（#L8727）。

适用条件分两类（#L8729）：

- 易溶气体（如 NH₃ 溶于水）：**温度高、浓度低**时才适用；
- 难溶气体（如 O₂、N₂、H₂ 溶于水）：总压 5 MPa 以下且分压 0.1 MPa 以下才适用。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_A^{*}=E\,x$ | （9-1） |
| **文字式** | $\text{平衡分压}_{\text{【kPa】}}=\text{亨利系数}_{\text{【kPa】}}\times\text{液相摩尔分数}$ |  |

原书编号：式(5-1)（#L8737）。$E$ 称亨利系数；**$E$ 越小溶解度越大**（易溶气体 $E$ 小、难溶气体 $E$ 大），且同一物系**温度升高 $E$ 增大**（#L8743-#L8745；表 5-1 列 15 种气体水溶液的 $E$，#L8749）。

液相组成改用浓度 $c_A$ 表示：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_A^{*}=\dfrac{c_A}{H}$ | （9-2） |
| **文字式** | $\text{平衡分压}_{\text{【kPa】}}=\dfrac{\text{液相浓度}_{\text{【kmol/m³】}}}{\text{溶解度系数}_{\text{【kmol/(kPa·m³)】}}}$ |  |

原书编号：式(5-2)（#L8777）。$H$ 可视作分压 1 kPa 时的平衡浓度；**$H$ 越大溶解度越大**，$H$ 随温度升高而减小（#L8781）。

原书另有气相组成用摩尔分数 $y$、以及摩尔比 $Y$、$X$ 表示的两种表达式（#L8773 起），换算关系见 §5.2 原文。

## 适用范围与边界

- 只适用于**稀溶液**与**直线段**溶解度曲线；浓度高、曲线弯曲时须用实测平衡数据或经验式（#L8727）。
- 难溶气体必须同时满足总压 <5 MPa、分压 <0.1 MPa 两个上限，否则偏离（#L8729）。
- 亨利系数随温度变化显著（$E$ 随 $T$ 升），亨利定律本身不含温度项，工程上按工况温度查 $E$ 表（#L8745）。
- 亨利定律描述的是**平衡**关系；实际吸收速率还要用双膜理论算传质系数（见 [[吸收-传质单元数与单元高度]]）。

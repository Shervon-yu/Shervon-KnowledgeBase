本文件由 DSH 用户全局指令链的用户级目录（`$DSH_AGENTS_HOME/AGENTS.md`，默认 `~/.agents/AGENTS.md`）注入。

与 `~/.dsh/AGENTS.md`（输出风格、诚实标准、执行类要求）**同一层级、同等重要，不分优先级**；两份规则同时适用。项目级 `AGENTS.md` 等更具体指令优先于本文件。

本文件规定 Markdown 文档的结构写法与工程/物理计算式的强制格式。

## 1. 工程/物理计算式：符号式 + 文字式成对写

凡文档、报告、笔记、答复、代码注释中出现工程或物理计算式（力、功率、流量、传热、强度、转速、浓度……），一律按下面格式写，不写成一段纯文字，也不只给一条式子。

### 1.1 版式

每条公式一个三列表格，**表头留空**，列对齐固定为「左─中─右」：

```markdown
|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=\dfrac{1}{1000\,\eta}\sum_{i=1}^{2}N_{pi}\,k_i\,\rho\left(\dfrac{n}{60}\right)^{3}d_i^{5}$ | （2-1） |
| **文字式** | $\text{轴功率}_{\text{【kW】}}=\dfrac{1}{1000\times\text{效率}}\sum_{i=1}^{2}\text{功率准数}_i\times\text{层数}_i\times\text{密度}_{\text{【kg/m³】}}\times\left(\dfrac{\text{转速}_{\text{【r/min】}}}{60}\right)^{3}\times\left(\text{叶轮直径}_{i,\text{【m】}}\right)^{5}$ |  |
```

- 左列只写 `**符号式**`、`**文字式**`，加粗。
- 中列公式居中，用 `$...$` 行内公式，分数用 `\dfrac`。
- 右列代号右对齐，全角括号，形态 `（节号-序号）`；一对符号式/文字式只占**一个**序号，序号只写在符号式行，文字式行留空；序号按出现顺序连号（2-1、2-2、2-3…）。
- 文字式只是符号式的文字解释（便于人读），不是独立公式，不单独编号。
- 不为单条公式另起标题；所属章节由节标题表达。

### 1.2 符号式

- 只出现字母符号，不写单位、不写中文。
- 变量用斜体；下标 `_{}`，上下标 `^{}`。
- 常数照实写（0.8、9550、9.81、29.7243），由单位换算来的系数要在解释里说明来历。

### 1.3 文字式

- 与符号式**一一对应**：同一位置、同样的括号/分数/幂次/求和结构，只把字母换成中文量名；不许换写法、合并项、改运算顺序。
- 中文量名包在 `\text{}` 里。
- 单位写成中文量名的**下标**，用全角中括号包裹：`\text{密度}_{\text{【kg/m³】}}`、`\text{转速}_{\text{【r/min】}}`。
- 无量纲量（效率、系数、准数、雷诺数、百分数）不标单位。
- 带序号时下标写成 `\text{叶轮直径}_{i,\text{【m】}}`（先序号、后单位）。

### 1.4 转义

- 公式内 `% # $ & _ { }` 一律转义，`\text{}` 里也不能省：`\text{【\%】}`。
- 单位里的乘号用 `\cdot` 或 `·`（Pa·s、N·m）。

### 1.5 解释与附录

- 每节公式后跟一段解释：符号含义、单位口径、常数/系数的来源、与代码实现的差异（常数合并、单位换算、取整）。
- 正文只写"式子是什么、为什么这样"；验证与对拍结果单独放附录（附录 A 对拍、附录 B 尚未闭合项），正文不重复。
- 同一物理量有多种写法时分开列并标明身份：物理原式 / 代码实现式 / 其他工况分支，并说明为何拆开。

### 1.6 图片与其他载体

- 图表里引用公式时用符号式，保证与正文一致。
- 生成 PNG/流程图时公式用符号式纯文本近似（如 `Re_i = ρ·(n/60)·d_i²/μ`），并避开字体缺字形的字符（下标数字、☑ 等）。
- 样板：`REA_一和计算软件_计算式与解释_v2.md`（磁力联轴器项目根目录）。

### 1.7 Word 文档：符号表达式一律用 {LaTeX} 源码

- 生成 Word（.docx）文档时，公式表的「符号式」栏与正文行内符号，一律写成**花括号包裹的 LaTeX 源码**，例如 `{P_{\mathrm{req}}=\dfrac{P_{\mathrm{shaft,op}}K}{\eta_{g}}}`、`{T_{\max}}`、`{Re_i=\dfrac{\rho n D_i^2}{\mu}}`。
- 花括号内必须是可直接复制、粘贴、编译的 LaTeX；不使用纯文本上下标、Unicode 上下标、`$...$` 或 OMML 渲染公式代替。
- 为便于 Word 自动换行，可在运算符、逗号后加空格；空格不改变 LaTeX 语义。
- 「文字式」仍按 1.3 写中文，不套 LaTeX；单位、代号（如 b1、c9）、数据表表头与数值不受此条约束。
- 本条只约束 Word 输出；Markdown 文档仍按 1.1–1.6 用 `$...$`。

# 螺栓法兰连接的设计

适用承受流体静压力与垫片压紧力的螺栓法兰连接（`#L8671`）。选用 NB/T 47020~47023、HG/T 20592、HG/T 20615、HG/T 20623 标准法兰时，**可免除本章计算**。

## 一、设计内容与分类

设计五项（`#L8673`）：①垫片材料/型式/尺寸；②螺栓材料/规格/数量；③法兰材料/密封面型式/结构/尺寸；④应力校核；⑤内压窄面法兰的刚度校核。

| 型式 | 定义 | 计算 |
|:--|:--|:--|
| 松式法兰 | 法兰未与容器或接管连成整体（活套等） | 表9-6 |
| 整体法兰 | 法兰、颈部、容器/接管连成整体 | 表9-5 |
| 任意式（焊接）法兰 | 板式平焊等 | 按整体法兰；满足 $\delta_0\le15$ mm、$D_i/\delta_0\le300$、$p\le2$ MPa、$T\le370$ ℃ 时可按活套法兰简化 |

宽面法兰（垫片跨螺栓中心圆内外）按 9.8；反向法兰按 9.6；筒体端部按 9.7。

## 二、垫片（9.5.1）

### 有效密封宽度

|  |  |  |
|:---|:---:|---|
| **符号式** | $b=b_0$（$b_0\le6.4$ mm）；$\quad b=2.53\sqrt{b_0}$（$b_0>6.4$ mm） | （9.5.1.2） |
| **文字式** | 基本密封宽度不超过 6.4 mm 时直接取用，超过时按平方根折算 |  |

### 垫片压紧力作用中心圆直径 $D_G$

- 活套法兰（图9-1 a-1、a-2）：$D_G$ = 法兰与翻边接触面的平均直径；
- 其他型式：$b_0\le6.4$ mm 取垫片接触面平均直径；$b_0>6.4$ mm 取接触面外径减 $2b$；
- 筒体端部结构：取密封面平均直径。

### 压紧力（式9-1、9-2）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_a=\pi D_Gby$；$\quad F_p=2b\pi D_Gmp_c$ | （9-1）（9-2） |
| **文字式** | $\text{预紧压紧力}=\pi\times\text{中心圆直径}\times\text{有效宽度}\times\text{垫片比压力}$；$\text{操作压紧力}=2\times\text{有效宽度}\times\pi\times\text{中心圆直径}\times\text{垫片系数}\times\text{计算压力}$ |  |

$m,y$ 查表9-2。垫片宽度按经验确定：预紧时压紧过度会失去密封性能。

## 三、螺栓（9.5.2）

### 布置

- 径向尺寸 $L_A,L_e$ 与螺栓间距 $\hat L$ 的最小值见表9-3（M12：$L_A$ 20/16、$L_e$ 16、$\hat L$ 32；M30 起 $\hat L$ 70）；
- 最大间距：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\hat L_{\max}=2d_B+\dfrac{6\delta_f}{m+0.5}$ | （9-3） |
| **文字式** | 最大螺栓间距 = 2×螺栓公称直径 + 6×法兰有效厚度/(垫片系数+0.5) |  |

- 螺栓公称直径不小于 M12；>M48 用细牙螺纹（`#L8693`）。

### 螺栓载荷（式9-4~9-6）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W_a=F_a$；$\quad F=\dfrac{\pi}{4}D_G^2p_c$；$\quad W_p=F+F_p$ | （9-4）（9-5）（9-6） |
| **文字式** | 预紧载荷=垫片预紧压紧力；操作时内压总轴向力按中心圆面积算，操作载荷=该力+操作压紧力 |  |

U 形管换热器夹持管板两侧成对法兰，须按两侧中**较大的螺栓载荷与较高的设计温度**设计。

### 螺栓面积（式9-7~9-8）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A_a=\dfrac{W_a}{[\sigma]_b}$；$\quad A_p=\dfrac{W_p}{[\sigma]_b^t}$ | （9-7）（9-8） |
| **文字式** | 预紧需要面积用常温许用应力；操作需要面积用设计温度许用应力；两者取大者 $A_m$，实际 $A_b\ge A_m$ |  |

螺栓截面积取螺纹小径与无螺纹部分最小直径计算值的**小值**。

### 螺栓设计载荷（式9-9、9-10）

|  |  |  |
|:---|:---:|---:|
| **符号式** | 预紧：$W=\dfrac{A_m+A_b}{2}[\sigma]_b$；$\quad$ 操作：$W=W_p$ | （9-9）（9-10） |
| **文字式** | 预紧工况取"需要面积与实际面积的平均值"乘常温许用应力；操作工况直接取 $W_p$ |  |

## 四、法兰力矩（式9-11~9-13）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_a=\dfrac{A_m+A_b}{2}[\sigma]_bL_G$ | （9-11） |
| **文字式** | $\text{预紧法兰力矩}=\text{平均螺栓面积}\times\text{常温许用应力}\times\text{螺栓中心到垫片压紧力作用线的力臂}$ |  |

操作状态：$F_D=\frac{\pi}{4}D_i^2p_c$（式9-12，作用在法兰内径截面上的内压轴向力），$F_T=F-F_D$（式9-13），分别对 $L_D$、$L_T$、$L_G$ 取矩后相加得到操作力矩。

## 判断

- 螺栓设计的核心是"两个工况取大"：预紧要压紧垫片（$F_a=\pi D_Gby$），操作要同时顶住内压和保持垫片残余压紧（$F+F_p$）——**低压大直径**法兰往往是预紧控制，**高压小直径**往往是操作控制；
- $W=\frac{A_m+A_b}{2}[\sigma]_b$ 是标准的保守处理：实际螺栓面积大于需要面积时，预紧力会按实际面积上升，故取平均值而非 $A_m$；
- 螺栓间距上限（式9-3）反映"法兰环在螺栓之间的弯曲"：间距过大，垫片在螺栓之间压不紧，会漏；
- 本章只给了载荷与力矩，**法兰应力（轴向/环向/径向）与刚度校核**在表9-5/9-6 的后续条款，需查表计算，不在本页范围。

# 管路计算-三类问题

## 定义

管路计算的基本式是同一套：摩擦阻力损失 $\sum h_{f}$ 与管长、内径、流速、摩擦系数、绝对粗糙度关联（式 1-42 一类的形式，变量说明见 #L2457）。按**已知量与未知量**的不同，本书把管路计算分成三类问题（#L2445、#L2447、#L2449）：

1. **摩擦损失计算问题**：已知 $l$、$d$、$\varepsilon/d$、$q_{V}$（或 $u$），求 $\sum h_{f}$；
2. **流量计算问题**：已知 $l$、$d$、$\varepsilon/d$、$\sum h_{f}$，求 $u$ 或 $q_{V}$；
3. **管径计算问题**：已知 $l$、$\sum h_{f}$、$\varepsilon$、$q_{V}$，求 $d$。

三类问题的差别不在公式，只在**未知量落在哪一侧**；后两类都要试差或迭代，因为 $\lambda$ 依赖 $Re$，而 $Re$ 依赖待求的 $u$ 或 $d$。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sum h_{\mathrm{f}}=\lambda\dfrac{l+\sum l_{e}}{d}\cdot\dfrac{u^{2}}{2}$ | （1.5-1） |
| **文字式** | $\text{摩擦阻力损失}_{\text{【J/kg】}}=\text{摩擦系数}\times\dfrac{\text{管长与当量长度之和}_{\text{【m】}}}{\text{管内径}_{\text{【m】}}}\times\dfrac{\left(\text{流速}_{\text{【m/s】}}\right)^{2}}{2}$ |  |

（式 1-42 形态；$l$ 为管长与管件当量长度之和、$d$ 为内径、$u$ 为流速、$\lambda$ 为摩擦系数、$\varepsilon$ 为绝对粗糙度，见 #L2457。）

**并联管路**：并联各支管的压力降相同，故单位质量流体经任一支管的摩擦损失相等（#L2676）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sum h_{\mathrm{f},1}=\sum h_{\mathrm{f},2}=\cdots=\sum h_{\mathrm{f},n}$ | （1.5-2） |
| **文字式** | $\text{第1支管摩擦损失}_{\text{【J/kg】}}=\text{第2支管摩擦损失}_{\text{【J/kg】}}=\cdots=\text{第}n\text{支管摩擦损失}_{\text{【J/kg】}}$ |  |

因此算并联管路的摩擦损失只需算一根支管（#L2680）；求某支管流量时把该式与支管阻力式联立（#L2700）。

**分支管路**：液体在主管处分支且不再汇合；本书只指出其计算方法参见有关资料，未给公式（#L2714）——本库据此不编造分支管路的解析式。

## 适用范围与边界

- 第 1 类可直接算；第 2、3 类因 $\lambda=f(Re)$ 必须试差，书中用「设 $\lambda$ → 算 $u$ → 校核 $Re$」的循环（同类试差见 §1.6 孔板 #L2840、#L2848）。
- 并联的前提是各支管两端为同一对节点（同一压力降），#L2676 的措辞是「A 与 B 两截面之间的压力降」。
- 分支管路本书无公式，只有定性说明（#L2714）。
- 本节未涉及可压缩流体管路、非牛顿流体管路。

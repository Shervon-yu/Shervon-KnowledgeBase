# 剪切型与循环型搅拌器

## 两种作用

搅拌器把机械能传给流体，产生两种作用（`#L4866`）：

| 作用 | 服务的单元操作 |
|:---|:---|
| **剪切** | 液-液体系液滴细化、固-液体系固体粒子破碎、气-液体系气泡细微化 |
| **循环** | 混合时间、传热、固体悬浮 |

能量主要消耗于循环者称**循环型**搅拌器；主要消耗于剪切者称**剪切型**搅拌器。

## 定量关系

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P\propto H_{e}\times Q_{d}$ | — |
| **文字式** | $\text{搅拌功率}\propto\text{剪切量}\times\text{循环量}$ |  |

（`#L4872`）功率一定时，剪切与循环是**两个相反的因子**。

## 判别指标

用功率准数与排量准数之比 $N_p/N_{qd}$（表示搅拌功率中消耗于剪切的比率）：

| $N_p/N_{qd}$ | 类型 |
|:---|:---|
| <1 | 轴流式（循环型） |
| 1~4 | 混合流型 |
| >4 | 径流式（剪切型） |

比值越大，功率消耗于剪切的比率越大；越小则消耗于循环的比率越大（`#L4872`）。

典型搅拌器的剪切/循环特性图（`图片\图5-3典型搅拌器的剪切与循环特性.jpg`）显示：**框式的循环作用最大，齿盘式的剪切作用最强**（`#L4874`）。

## 判断

$N_p/N_{qd}$ 是选型的第一道筛子：混合、传热、悬浮看循环，分散、破碎、传质看剪切。但它只表示"功率分配比例"，不表示绝对能力——大功率循环型搅拌器的绝对剪切仍可能超过小功率剪切型。

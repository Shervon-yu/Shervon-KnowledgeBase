# 幂律流体与表观黏度

## 流变方程

假塑性与胀塑性流体都可用幂律（Ostwald–de Waele）方程描述（`#L1277-#L1279`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=K_{\mathrm{psn}}\left|\dot{\gamma}\right|^{n-1}\dot{\gamma}$ | （2-4） |
| **文字式** | $\text{切应力}_{\text{【Pa】}}=\text{稠度系数}_{\text{【Pa·s}^n\text{】}}\times\left|\text{切应变速率}_{\text{【1/s】}}\right|^{n-1}\times\text{切应变速率}_{\text{【1/s】}}$ |  |

表观黏度（`#L1285-#L1287`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu_{\mathrm{a}}=K_{\mathrm{psn}}\left|\dot{\gamma}\right|^{n-1}$ | （2-5） |
| **文字式** | $\text{表观黏度}_{\text{【Pa·s】}}=\text{稠度系数}_{\text{【Pa·s}^n\text{】}}\times\left|\text{切应变速率}_{\text{【1/s】}}\right|^{n-1}$ |  |

## 用 n 判别类型

同一方程覆盖三种流体（`#L1285`）：

- $n<1$：假塑性流体（剪切变稀），黏度随 $\dot{\gamma}$ 增大而下降；
- $n=1$：牛顿流体，$K$ 退化为黏度；
- $n>1$：胀塑性流体（剪切增稠），黏度随 $\dot{\gamma}$ 增大而上升。

$K_{\mathrm{psn}}$ 越大表示流体越黏。

## 机理

- 假塑性：分子受剪切后重排、趋向与流动方向一致，流动阻力下降，表观黏度下降（`#L1289`）。
- 胀塑性：静止时固体间孔隙最小、液体起润滑作用；切变速率增大后液体不足以润滑固-固相互作用，应力急剧上升（`#L1311`，Osborne Reynolds 的解释）。

## 适用边界与常见物料

- 幂律模型只适用于**中等切变速率**范围；要覆盖更宽范围需用 Ellis、Cross、Carreau、Casson、Herschel-Bulkley 等模型（表2-3，`#L1291-#L1305`）。
- 搅拌与混合技术中研究最多的是假塑性流体：聚合物及其溶液、悬浮液、高分子溶液、羧甲基纤维素水溶液等（`#L1309`）。
- 胀塑性流体实际很少遇到，远不及假塑性常见（`#L1313`）。
- 用幂律算搅拌功率时，$n$ 与 $K$ 必须与所取切变速率范围匹配，否则表观黏度会差出数量级，见 [[搅拌剪切速率量级]]。

# 流体静力学基本方程

## 定义

描述静止流体内部压力沿高度变化的数学表达式，适用于不可压缩流体（《化工原理》§1.1，#L1098）。由静止液柱的三力平衡推出：下端面向上总压力 $p_2A$、上端面向下总压力 $p_1A$、液柱重力 $\rho gA(z_1-z_2)$，三力合力为零（#L1104-#L1118）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_2=p_1+\rho g\left(z_1-z_2\right)$ | （1-1） |
| **文字式** | $\text{压力}_{2,\text{【Pa】}}=\text{压力}_{1,\text{【Pa】}}+\text{密度}_{\text{【kg/m³】}}\times g\times\left(\text{高度}_{1,\text{【m】}}-\text{高度}_{2,\text{【m】}}\right)$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p=p_0+\rho g h$ | （1-2） |
| **文字式** | $\text{压力}_{\text{【Pa】}}=\text{液面压力}_{\text{【Pa】}}+\text{密度}_{\text{【kg/m³】}}\times g\times\text{深度}_{\text{【m】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{p-p_0}{\rho g}=h$ | （1-3） |
| **文字式** | $\dfrac{\text{压力}_{\text{【Pa】}}-\text{液面压力}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}\times g}=\text{液柱高度}_{\text{【m】}}$ |  |

原书编号：式(1-9)、(1-9a)、(1-9b)，见 #L1123、#L1129、#L1143。

三条推论（#L1136-#L1146）：

1. 同一连续静止液体内，同一水平面各点压力相等，此面称**等压面**。
2. 液面压力 $p_0$ 变化引起内部各点同量变化 —— **巴斯噶原理**。
3. 压力差可用液柱高度表示，液柱高度取决于密度 $\rho$。

## 适用范围与边界

- 只对**静止**、**连续**、**同一液体**成立；不同密度分层时等压面不连续（#L1136）。
- 推导假定密度不随压力变化（不可压缩）；气体密度随容器高度变化甚微，一般也可视为常数，故本式亦用于气体（#L1148）。
- 不用于流动流体：流动时须改用伯努利方程（[[流体流动-伯努利方程]]）。

# 往复式单螺杆捏合机

## 结构（`#L18871-#L18873`）

属**单螺杆、双阶**挤出机。第一阶：挤压系统（螺杆+机筒）、驱动、加料、温控；关键差异——

- 螺杆螺纹**不连续**，每转一圈中断三次；
- 机筒**剖分式**，可打开快速清理；
- 机筒内表面按规律装**三排捏合销**，可调整、更换；
- 螺杆积木式，元件套在中空芯轴上；芯轴与机筒夹套均可通液体介质加热/冷却。

第二阶是长径比较小的常规单螺杆挤出机，负责定压、定量、定温挤出与造粒。

## 工作原理（`#L18879`）

第一阶中螺杆除旋转外还作**轴向往复运动**，螺杆与销钉间的相对运动使物料承受很高剪切，且**每转一周剪切重复三次**。旋转+往复与销钉配合，相对运动轨迹呈 **∞ 形曲线**——径向与轴向同时混炼，分布与分散都强。因螺杆往复，末端挤出物料呈**脉动状**，故第二阶需常规螺杆稳压。

## 六个特点（`#L18883-#L18899`）

| 特点 | 机理/数据 |
|:---|:---|
| 长径比小、结构紧凑坚固 | 扭矩在短距离传递，螺杆扭转变形小；全长磨损均匀，很少咬缸；停留时间短、受热短，适合热敏物料 |
| 温控精确 | 波动 0.5~1 ℃ |
| 挤出压力低 | L/D=8 时甚至无压力产生 |
| 混合效率高 | 尤其轴向混合性能好 |
| 换料快、易清理 | 剖分机筒 + 积木式元件 |
| 能耗低 | RPVC：异向双螺杆 0.12 kWh/kg，本机 **0.0599 kWh/kg** |

系列：KG/WKG、PRL/PRW、MDK/KKG、PLK、PRK/PRK·E；公称直径 **50~600 mm**，功率可达 **1100 kW**。

## 国产化（SJW，`#L18915-#L18935`）

江苏江阴新达 1999 年开发，称 SJW 型往复式单螺杆混炼挤出机（双阶式单螺杆输送）。结构特点：

1. 机筒由多组开孔/闭孔筒体组成，**剖分式**；
2. 往复机构独特，螺块/内衬套/销钉积木式；
3. 销钉与每个螺块的相对轨迹呈 ∞ 形，机筒内表面全被螺杆扫过、无死角，自清洁；
4. 交流变频主电机（可选直流）；
5. 机头压力/熔体温度传感器，筒体另有四组深入机筒的熔体温度传感器；
6. 单螺杆或齿轮熔体泵出料，最大输送压力 **20 MPa**；
7. 机械/电气安全联锁。

## 判断

- 长径比小是优点而非妥协：混合靠「往复+销钉」的重复剪切，而不是靠长度堆积；由此换来停留时间短、热历史轻，这正是热敏物料（PVC）选它的理由。
- ∞ 形轨迹的工程含义是「无死角 + 自清洁」，这与双螺杆的积木式组合解决的是两类不同问题：前者解决均匀性与清理，后者解决配方适应性。
- 能耗 0.0599 对 0.12 kWh/kg 的数据说明：在 RPVC 这种高黏体系里，往复式比异向双螺杆省一半能量。

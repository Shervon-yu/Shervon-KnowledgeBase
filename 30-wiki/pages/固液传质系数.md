# 固液传质系数

固-液传质研究两件事：搅拌对固体表面积的影响，以及对颗粒周围液膜的影响（`#L3350`）。

## 功率的影响

图 3-6 是搅拌功率对固-液传质系数的影响曲线（`#L3352`）：

- **离底悬浮之前**：功率对提高传质系数影响大，但大量固体未悬浮，有效传质面很小，绝对传质系数太低；
- **离底悬浮之后**：功率的影响明显减弱，传质面不再是贡献因子，系数增加主要来自界面湍动改善。

推论：先把悬浮做到位（见 [[固液悬浮临界转速]]），再谈传质强化。

## 溶解速率方程

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{L}=\dfrac{Q\,C}{\overline{A}\,(C^{*}-C)}$ | （3-23） |
| **文字式** | $\text{液膜传质系数}_{\text{【m/s】}}=\dfrac{\text{液体体积流量}_{\text{【m³/s】}}\times\text{溶质主体浓度}_{\text{【kmol/m³】}}}{\text{固液相接触面积}_{\text{【m²】}}\times\left(\text{饱和浓度}_{\text{【kmol/m³】}}-\text{主体浓度}_{\text{【kmol/m³】}}\right)}$ |  |

（`#L3360`；OCR 左端作 $K_L$，下方符号说明作 $K_1$，按上下文取 $K_L$）

## 无因次关联

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Sh=r\,(Re)^{p}\,Sc^{q}$ | （3-24） |
| **文字式** | $\text{舍伍德数}=r\times\left(\text{雷诺数}\right)^{p}\times\left(\text{施密特数}\right)^{q}$ |  |

$Sc=\mu/(\rho D_V)$；常数 $r$ 与指数 $p$、$q$ 与桨型及几何特性有关（`#L3372-#L3384`）。

## 表 3-6 摘录

| 体系 | 挡板 | 颗粒 | 关联式 |
|:---|:---|:---|:---|
| 水-氯化钡/水-萘 | 无 | 片状 | $Sh_T=2.7\times10^{-5}Re_T^{1.45}Sc^{0.69}$（$Re_T<6.7\times10^4$）；$Sh_T=0.16Re_T^{0.62}Sc^{0.50}$（$>6.7\times10^4$） |
| 水-苯甲酸、甲醇-苯甲酸 | 无 | 球状 | $Sh_T=\alpha(Re_T)^{p}Sc^{0.50}(d_p/D)^{x}$，$0.20<p<0.67$，$-0.80<x<-0.32$ |
| 水-苯甲酸/水-硼酸/糖浆-苯甲酸 | 有 | 颗粒状 | $Sh_T=0.052Re_g^{0.833}Sc^{0.50}$ |
| 碘-铜 | 有 | 球状 | $Sh=2+0.109[(Nd^2d_p/\mu)(n_p/n_{p标准})^{1.3}]^{0.36}Sc^{0.5}$ |
| 乙醇-硝酸铵等 | 有 | 球状 | $Sh=2+0.47(d_p^{3/3}\varepsilon^{1/3}\rho/\mu)^{0.62}Sc^{0.36}$；$Sh_a=2+0.44Re_g^{0.504}Sc^{0.385}$ |

（`#L3388-#L3401`；$Sh_T=kD/D_V$ 釜舍伍德数、$Sh_a$ 搅拌器舍伍德数、$Sh$ 颗粒舍伍德数，$Re_g=Nd^2\rho/\mu$）

## 使用提醒

- 原文表格 OCR 失真较多（$d_p^{3/3}$、$Re_g$/$Re_z$ 混用、$\varepsilon$ 同时表孔隙率与单位质量功率），**逐式引用前必须核对原书**；本页只保留结构，指数以原书为准。
- 同一体系不同研究者指数差异大，选式要匹配挡板、颗粒形状与 $Re$ 范围。
- 液-液、气-液的对应内容见 [[液液传质系数]]、[[气液传质与容积传质系数]]。

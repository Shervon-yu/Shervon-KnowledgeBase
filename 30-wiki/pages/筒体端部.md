# 筒体端部

筒体端部是高压容器"用主螺栓直接锁死筒体"的那一段结构（图 9-11）：筒壁加厚成带螺孔的端部，主螺栓旋入螺孔、主螺母压住端盖或法兰。它不属于法兰，按 9.7 单独设计，要定四样东西：**螺栓直径、螺母尺寸、端部几何、纵向截面弯曲应力**。符号除 9.7.1 单列的（$a$、$D$、$D_o$、$d_0$、$H_g$、$h$、$h_1$、$h_s$、$L$、$r$、$\alpha$、$\delta_n$、$\sigma_m$、$C_2$）外，同 9.3。

## 一、主螺栓与主螺母（9.7.2、9.7.3）

螺栓无螺纹部分直径由所需螺栓面积反推：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_0=\sqrt{\dfrac{4A_m}{\pi n}}$ | （9-34） |
| **文字式** | $\text{主螺栓无螺纹部分直径}=\sqrt{\dfrac{4\times\text{需要的螺栓面积}}{\pi\times\text{螺栓数量}}}$ |  |

$A_m$ 按 9.5.2.3 定；$n$ 取**偶数**；螺纹小径须 $\ge d_0$；推荐细牙螺纹 M64×4、M80×4、M105×4、M125×4（`#L9482`）。

主螺母的硬度应**略低于**主螺栓（`#L9494`）——让螺母先于螺栓失效，换件便宜：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $a=(1.0\sim1.1)d_B$；$\quad D=(1.70\sim1.75)d_B$ | （9-35）（9-36） |
| **文字式** | $\text{主螺母高度}=(1.0\sim1.1)\times\text{主螺栓公称直径}$；$\quad\text{主螺母外接圆直径}=(1.70\sim1.75)\times\text{主螺栓公称直径}$ |  |

## 二、端部几何（9.7.4.1、9.7.4.2，`#L9506-#L9548`）

端部厚度只有一个条件：**不小于按内压确定的圆筒名义厚度**（`#L9508`）。其余尺寸由螺孔布置与扳手空间反推：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $D_b\ge D_2+1.5d_B$；$\quad D_o\ge D_b+1.8d_B$ | （9-37）（9-38） |
| **文字式** | $\text{主螺栓中心圆直径}\ge\text{垫片接触面外直径}+1.5\times\text{主螺栓公称直径}$；$\quad\text{端部外直径}\ge\text{主螺栓中心圆直径}+1.8\times\text{主螺栓公称直径}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_1\ge(1.3\sim1.5)d_B$；$\quad h\ge h_s+0.5d_B\ (\alpha=30^\circ)$；$\quad h\ge h_s+d_B\ (\alpha=45^\circ)$ | （9-39）（9-40）（9-41） |
| **文字式** | $\text{螺孔有效螺纹深度}\ge(1.3\sim1.5)\times\text{主螺栓公称直径}$；$\quad\text{端部外缘长度}\ge\text{螺孔深度}+0.5\times\text{主螺栓公称直径}$（倾角 $30^\circ$）或 $+\ 1\times$ 主螺栓公称直径（倾角 $45^\circ$） |  |

其余：$h_s=h_1+$ 螺孔加工所需无效螺纹长度；过渡圆角 $r\ge0.8\delta_n$；直边长度 $L=50$ mm。

## 三、纵向截面弯曲应力（9.7.4.3，`#L9550-#L9608`）

端部最危险的截面不是环向，而是**纵向截面**——螺栓拉力与内压把端部向外"掰"，沿轴向的截面受弯。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M=\dfrac{1}{2\pi}\left[\left(\delta_n-C_2+\dfrac{1}{3}D_i\right)F_D-\left(D_b-\dfrac{2}{3}D_G\right)F-\left(D_b-D_G\right)F_p\right]-p_cD_iH_gJ_o$ | （9-42） |
| **文字式** | $\text{纵向截面弯矩}=\dfrac{1}{2\pi}\left[\left(\text{端部厚度}-\text{腐蚀裕量}+\dfrac{1}{3}\text{内直径}\right)\times\text{孔盖区轴向力}-\left(\text{螺栓中心圆直径}-\dfrac{2}{3}\text{垫片中心圆直径}\right)\times\text{垫片压紧力}-\left(\text{螺栓中心圆直径}-\text{垫片中心圆直径}\right)\times\text{操作状态垫片压紧力}\right]-\text{计算压力}\times\text{内直径}\times\text{端部总高度}\times\text{参数}J_o$ |  |

$J_o=J_c-H_g/2$；各力与 $D_G$ 的意义同 9.3、9.5.1。三项的符号说明：$F_D$ 是内压把端盖往外推（加大弯矩），两支垫片力是螺栓拉力的反作用（减小弯矩），末项是内压沿端部高度产生的附加弯矩。

抗弯截面系数按"矩形外缘 + 梯形内壁"两块的组合截面算：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Z_g=\dfrac{I_c}{J_c}$ | （9-43） |
| **文字式** | $\text{抗弯截面系数}=\dfrac{\text{组合截面惯性矩}}{\text{组合截面形心位置}}$ |  |

其中（单位 mm、mm²、mm⁴）：

- 矩形部分：$A_1=hB$，$I_1=\dfrac{Bh^3}{12}$，$J_1=H_g-\dfrac{h}{2}$；
- 梯形部分：$A_s=\dfrac{(H_g-h)(\delta_e+B)}{2}$，$I_s=\dfrac{(H_g-h)^3(\delta_e^2+4\delta_eB+B^2)}{36(\delta_e+B)}$，$J_s=\dfrac{(H_g-h)(\delta_e+2B)}{3(\delta_e+B)}$；
- 形心与平行轴项：$J_c=\dfrac{A_1J_1+A_sJ_s}{A_1+A_s}$，$a_1=J_1-J_c$，$a_s=J_c-J_s$；
- 组合惯性矩：$I_c=2\left(I_1+A_1a_1^2+I_s+A_sa_s^2\right)$；
- 壁厚：$B=\dfrac{D_o-D_i}{2}-C_2$，$\delta_e=\delta_n-C_2$。

$2$ 倍来自"两侧对称、取整个纵截面"（图 9-12，形心 $0$、矩形部分形心 $0'$、梯形部分形心 $0''$）。

校核：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_m=\dfrac{M}{Z_g}\le[\sigma]_f^t$ | （9-44） |
| **文字式** | $\text{纵向截面弯曲应力}=\dfrac{\text{纵向截面弯矩}}{\text{抗弯截面系数}}\le\text{设计温度下法兰材料许用应力}$ |  |

锻制紧缩口封头的纵向截面弯矩式（7-46）与本节式（9-42）同构，可对照读 → [[锻制紧缩口封头]]。

## 判断

- 端部的设计逻辑是"先定几何、再验一处应力"：螺栓直径由所需面积定，螺母与外径由扳手空间定，厚度由内压圆筒定——**几何几乎全被工艺尺寸锁死**，最后只剩纵向截面弯曲应力一个自由度，所以 9.7 只有式 9-44 一个校核式。
- $D_b\ge D_2+1.5d_B$ 与 $D_o\ge D_b+1.8d_B$ 不是强度值，是"螺母能放进去、扳手能转"的空间值；这也解释了为什么端部设计比法兰更"笨重"——它靠几何保证，不靠计算优化。
- 螺母硬度略低于螺栓，是人为规定**失效顺序**：拧紧过头时宁可坏螺母也不坏螺栓，因为螺栓与端部螺孔是一体的，螺栓坏了整个端部报废。
- 式 9-42 里 $J_o=J_c-H_g/2$：末项 $p_cD_iH_gJ_o$ 是内压作用在端部高度范围内的偏心弯矩，$J_o$ 是压力作用线到截面形心的距离。形心算法（9-43）必须先算对，否则 M 与 Z_g 同时错，误差不是线性的。
- 纵向截面按两块组合截面算惯性矩，是因为端部外形是"外面直、里面斜"（图 9-11 的 $45^\circ$/$30^\circ$ 锥面），把它拆成矩形 + 梯形两块，用平行轴定理合成——这是唯一能把非矩形截面套进 $M/Z$ 的办法。

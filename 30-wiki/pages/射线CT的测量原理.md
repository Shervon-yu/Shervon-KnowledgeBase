# 射线CT的测量原理

## 两条路线（`#L384`）

- **X-CT**：医学普及，但 X 射线源发生系统复杂、穿透力不如 γ 射线，难适应工业设备；且 X 射线为**多能光谱**，易产生伪影。
- **γ-CT**：穿透力强，可测高温高压钢制容器；γ 射线为**单能射线**，伪影概率低。

## 衰减定律（Lambert-Bill）（`#L384-#L387`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{I}{I_0}=\mathrm{e}^{-\rho\mu l}=\mathrm{e}^{-\Phi l}$ | （1.7） |
| **文字式** | $\dfrac{\text{透射强度}}{\text{入射强度}}=\mathrm{e}^{-\text{线衰减系数}\times\text{路径长度}}$ |  |

两种介质、路径 $l_1$、$l_2$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{I}{I_0}=\mathrm{e}^{-(\Phi_1l_1+\Phi_2l_2)}$ | （1.8） |
| **文字式** | 同上，指数项为两段路径衰减之和 |  |

令 $l_1=\varepsilon_1L$、$l_2=(1-\varepsilon_1)L$，$L=l_1+l_2$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\varepsilon_{1,p}=\dfrac{\Phi_{2,p}-\Phi_{12,p}}{\Phi_{2,p}-\Phi_{1,p}}$ | （1.9） |
| **文字式** | $\text{像素气含率}=\dfrac{\text{全液时衰减}-\text{实测衰减}}{\text{全液时衰减}-\text{全气时衰减}}$ |  |

$L$ 为像素尺寸，由探测器排列紧密度与准直孔尺寸定，目前一般 1~2 mm（`#L402`）。

## γ-CT 的优点（`#L404`）

非接触、对流场无扰；可测钢制容器内不透明、高浓度、高温高压体系；一次得到**二维全流场气含率断面分布**；结果精确。

## 判断

- （1.9）本质是线性内插：像素内气液比例由衰减量在"全气—全液"两端之间插值，因此**必须**有全液（满液无气）与全气（空釜）两个标定基准，缺一不可。
- 像素尺寸 1~2 mm 决定了空间分辨率上限：再小则计数率不足、统计噪声压倒信号。
- "单能射线少伪影"是关键：X 射线束化后低能成分被优先吸收（束硬化），重建出杯状伪影；γ 单能则无此问题。

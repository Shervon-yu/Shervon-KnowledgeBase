# 差压波动测量与图像识别测量

## 差压波动法（`#L426-#L438`）

流动参数的强烈波动性是两相流普遍特性。申国强等对气液两相流过孔板的瞬时差压分析，实现总质量流量与干度的双参数测量。

劳力云给出直管道差压波动信号与空隙率的多项式关系（限空隙率 <50%）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $c=0.5125\times10^3\varphi^3-2.485\times10^3\varphi^2+2.578\times10^3\varphi$ | （1.11） |
| **文字式** | 无量纲差压波动系数与空隙率的三次多项式关系 |  |

其中 $c=\delta P/q_{ml}^{2-n}$、$n=0.84$（按流型定）。

其他工作：王芳等用环形管差压脉动振幅均方根与差压时均信号构成无量纲数，测容积含气率 <0.65，误差 <5%；张宏建等用文丘里管差压波动信号算气含率。但用于**气液搅拌釜**的报道很少。

局限：差压波动是复杂物理过程，需借助多相流、统计学、混沌理论、小波分析、神经网络等建立机理模型，**研究难度较大**。

## 图像识别法（`#L440-#L444`）

基于数字图像处理：高速摄像仪实时拍摄，边缘检测 + 图像填充提取气泡尺寸，进而算气含率。**实验相对误差约 15%**。

两条应用路线：①高速摄影直接拍流场、提取特征算相含率；②过程层析成像 + 图像重建，得二维/三维流动图像，实现在线监测。

## 判断

- （1.11）是纯经验拟合，且明确限定空隙率 <50%，外推到高气含率区无依据；三次多项式在 $\varphi\to0$ 时不趋于 0（截距为 0 实际成立，因三项均含 $\varphi$），但曲线形状无物理约束。
- 差压法的困难在于"波动信号同时含流量与相含率信息"，必须靠统计/混沌等手段解耦，这是它难以工程化的根源。
- 图像法的 15% 误差主要来自：气泡重叠、离焦模糊、边缘检测对光照与阈值的敏感，以及二维投影无法反映三维重叠。
- 两者共同的致命伤是**只能测透明体系**——钢制高温高压釜完全不适用，这正是 γ-CT 的立足点。

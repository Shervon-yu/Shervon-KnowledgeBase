# 气液固三相-功率与放大

## 功率：结构因素

**釜型**：Wiedmann 等发现大釜中临界悬浮时的单位质量功耗 $(P_m)_{JSG}$ 小于小釜（`#L2878`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{(P_{m})_{JSG}\,d_{p}^{40.33}}{v_{L}^{3}}=1.99\left(Re_{G}+1\right)^{0.035}\phi^{0.12}Ga^{0.677}\left(\dfrac{d_{p}}{d}\right)^{1.57}\left(\dfrac{\Delta\rho}{\rho_{L}}\right)^{0.53}$ | （2-130） |
| **文字式** | $\dfrac{\text{单位质量功耗}_{\text{【W/kg】}}\times\left(\text{颗粒直径}_{\text{【m】}}\right)^{40.33}}{\left(\text{液相运动黏度}_{\text{【m²/s】}}\right)^{3}}=1.99\times\left(\text{颗粒雷诺数}+1\right)^{0.035}\times\phi^{0.12}\times\text{格拉晓夫准数}^{0.677}\times\left(\dfrac{\text{颗粒直径}}{\text{搅拌器直径}}\right)^{1.57}\times\left(\dfrac{\text{密度差}}{\text{液相密度}}\right)^{0.53}$ |  |

$Re_G=V_sd_p/v_L$。注意：$d_p$ 的指数 40.33 明显异常（疑为 OCR 把 1.33 或 4.33 识别错），引用前必须核对原书（`#L2880`）。

Raghav Rao：$(P_m)_{JSG}$ 随釜径增大而减小、随搅拌器直径增大而增大，即随 $d/D$ 增大而减小 → 三相体系宜取**小的 $d/D$**（`#L2884`）。功率准数（基于液相密度，`#L2886-#L2890`）：

- PTD：$N_p^{*}\propto\phi^{0.05}d_p^{0.04}$（2-131）
- PTU：$N_p^{*}\propto\phi^{0.07}d_p^{11.04}$（2-132，指数疑为 0.04 的 OCR 失真）
- DT：$N_p^{*}\propto\phi^{0.05}d_p^{0.06}$（2-133）

**桨型**（`#L2894`）：通气使功率下降的程度 PTD<DT、6DT<4DT、PTU 最小；60° 六叶 PTU 最佳，$P_G$ 不随气量增大而变化或缓增。

**分布器**（`#L2898`）：单孔分布器易气泛、大气泡快升 → $P_G$ 降得快；多孔分布环不易气泛、功耗下降慢。$S$ 与 $C_0$ 越小越易形成大气穴、$P_G/P_0$ 降得越快、$N_{JSG}$ 越高。

## 功率：操作因素

`#L2900-#L2902`：高气量时 PTU 功耗低于 6DT 且分散稳定；低气量时 PTU 功耗最高（气升弱，规律接近液-固）。PTD 对颗粒悬浮最有效、功耗与临界转速皆低。低气量 PTD 最低、中等气量下压式双折叶圆盘涡轮最低、大气量 DT 最低。

Nienow：下压式与上推式涡轮在 $Q_v<0.5$ min⁻¹ 时 $(P_m)_{JSG}$ 降低；$Q_v>0.5$ 时下压式因气升干扰釜底流型而升高；上推式在 $Q_v>1.0$ 时气升与搅拌同向、控制流型，$(P_m)_{JSG}$ 继续降低。

结论：从功耗看以上推式桨为好（尤其高气量），分布器以多孔分布环为佳（`#L2904`）。

## 放大准则

`#L2906-#L2922`：

| 研究者 | 式号 | 准则 |
|:---|:---|:---|
| Chapman | 2-134 | $(P_m)_{JSG}\propto d^{0.28}$ |
| Frijlink（$Q_v$ 恒定，DT） | 2-135 | $(P_m)_{JSG}\propto d^{-0.33}$ |
| Frijlink（PTD） | 2-136 | $(P_m)_{JSG}\propto d^{0.3}$ |
| Frijlink（PTU） | 2-137 | $(P_m)_{JSG}\propto d^{0.4}$ |

四个指数（+0.28、−0.33、+0.3、+0.4）方向都不一致，说明放大准则与试验条件、过程目的强相关，**引用前必须核对条件**（`#L2922`）。

## 现状

三相混合研究起步迟、结果不系统不成熟，仍有待完善（`#L2924`）。工程上应：先按液-固选桨型与 $d/D$，再按气-液校核气泛与功率，最后中试验证临界悬浮转速。

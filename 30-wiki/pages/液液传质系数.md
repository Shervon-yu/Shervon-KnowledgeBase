# 液液传质系数

## 总速率式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r=K_{L}a\,\Delta C$ | （3-25） |
| **文字式** | $\text{传质速率}_{\text{【kmol/(s·m³)】}}=\text{总质量传质系数}_{\text{【1/s】}}\times\text{浓度推动力}_{\text{【kmol/m³】}}$ |  |

（`#L3431-#L3437`）

## 没有通用关联式

间歇液-液操作中 $K_La$ 是转速的函数（图 3-7，煤油-铜-水体系，`#L3439`）。该数据有代表性，但**不存在适用于各种情况的通用传质系数关联式**——少量杂质就能改变传质系数以及起泡、沉降性质（`#L3443`）。

## 工程做法：分开 K_L 与 a

工程上把传质系数 $K_L$ 与比界面积 $a$ 分开：先实验测传质速率，同时测比界面积，再反算 $K_L$（`#L3445`）。

## Schindler-Treybal 通用式

用物料连续流过搅拌釜、光透射测比界面积，得到（`#L3449-#L3461`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{Lc}=K_{s}+B\left(\dfrac{D_{A}}{\theta_{C}}\right)^{0.5}$ | （3-26） |
| **文字式** | $\text{连续相传质系数}_{\text{【m/s】}}=\text{稳态连续相传质系数}_{\text{【m/s】}}+B\times\left(\dfrac{\text{扩散系数}_{\text{【m²/s】}}}{\text{凝并时间}_{\text{【s】}}}\right)^{0.5}$ |  |

$B$ 取 3.94（`#L3457`）。物理含义：连续相传质系数由“稳态项”与“凝并-再分散强化项”叠加。

## 间歇与连续加料的差别

间歇操作时，开始分散和保持分散所需功率，与物料连续加入釜中所需功率有相当大的差别；当**较轻一相从釜底加入、较重一相从釜上部加入**时更明显（`#L3467-#L3469`）。

设计含义：加料位置改变会改变实际所需功率与传质，不能照搬间歇数据。

# 原书 §7.5–§7.8：带反应的液液传质

## §7.5 一个式子管三种极限

原书的出发点是"把占总体积 0.65% 的微溶组分分散到水中，溶解后进行一级水解"（`#L8541`）。这个极稀体系使界面面积变化、浓度变化可以分开处理。

### 通式与三个参数

|  |  |  |
|:---|:---:|---|
| **符号式** | $R=\beta KA\left\{C_B^{*}-\dfrac{C_B}{\cosh\gamma}\right\}$ | （7.49） |
| **文字式** | $\text{总反应速率}=\text{反应增强因子}\times\text{传质系数}\times\text{界面面积}\times\left\{\text{界面饱和浓度}-\dfrac{\text{主体浓度}}{\cosh\left(\text{Hatta 准数}\right)}\right\}$ |  |

其中（`#L8545`、`#L8549`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\beta=\dfrac{\gamma}{\tanh\gamma}$;\qquad $\gamma=\sqrt{\dfrac{k_wD_f}{k}}$ | （7.49′） |
| **文字式** | 反应增强因子 = Hatta 准数 / tanh(Hatta 准数)；$\gamma$ 为反应速率与液膜扩散速率之比 |  |

$K$ 为液膜传质系数【cm/s】、$C_B^*$ 为界面饱和浓度、$C_B$ 为主体浓度【g·mol/l】（`#L8551-#L8555`）。

**这个式子的价值在于：$\gamma$ 一个数就把"反应控制/传质控制"连续地过渡了**——$\gamma\ll1$ 时 $\cosh\gamma\to1$、$\beta\to1$，退化为物理吸收；$\gamma\gg1$ 时 $\beta\to\gamma$、$\cosh\gamma\to\infty$，退化为传质控制。

### 极限一：无化学反应

|  |  |  |
|:---|:---:|---|
| **符号式** | $R=KA\left(C_B^{*}-C_B\right)$ | （7.50） |
| **文字式** | $\text{总速率}=\text{传质系数}\times\text{界面面积}\times\text{界面与主体的浓度差}$ |  |

### 极限二：反应远快于扩散（扩散控制）

界面内产生化学反应的连续相体积远大于界面面积对应体积时，速率由扩散阻力控制（`#L8569`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $R=\beta KAC_B^{*}=\beta KAHC_A^{*}$;\qquad $C_B^{*}=HC_A^{*}$ | （7.51）（7.52） |
| **文字式** | 速率 = 增强因子 × 传质系数 × 界面面积 × 界面饱和浓度（可由另相平衡浓度乘分配系数得到） |  |

$H$ 是分配系数。**液滴溶解时界面面积同时缩小**（`#L8577`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $A_x=A_0(1-x)^{2/3}$;\qquad $R=VC_E\dfrac{\mathrm{d}x}{\mathrm{d}t}=\beta KA_0HC_A^{*}(1-x)^{2/3}$ | （7.53）（7.54） |
| **文字式** | 转化率为 $x$ 时的界面面积 = 初始面积 × $(1-x)^{2/3}$（球体积∝$r^3$、面积∝$r^2$ 的直接结果） |  |

积分得**可判定的线性关系**（`#L8587`、`#L8593`、`#L8601`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $1-(1-x)^{1/3}=k't$;\qquad $k'=\dfrac{\beta KA_0HC_A^{*}}{3C_EV}$ | （7.55）（7.56） |
| **文字式** | $1-(1-x)^{1/3}$ 对时间成直线，斜率即 $k'$——只要 $K$ 是常数 |  |

**工程用法**：把实验数据按 $1-(1-x)^{1/3}$ vs $t$ 作图，直线性本身就是"传质系数恒定、无界面失活、无二次分散"的验证（图7.11，`#L8585`）。

### 极限三：反应远慢于扩散（反应控制）

判断量（`#L8605`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\alpha v=\sqrt{\dfrac{k_w}{D_f}}\cdot\dfrac{V}{A}$;\qquad $R=k_wVC_B^{*}$ | （7.57） |
| **文字式** | 反应-扩散比 = $\sqrt{k_w/D_f}$ × 液体积 / 界面面积；该值接近 1 或更小时过程转为反应速率控制 |  |

$\alpha v\approx1$ 的物理含义：反应速率与扩散速率同量级，界面浓度不再等于饱和值，"传质"这一步不再是瓶颈。**此时提高转速毫无用处**——这是设计上最容易犯错的地方。

## §7.6 密度差小的体系：搅拌几乎不提 $K$

原书的核心判断（`#L8613`）：固液搅拌中两相密度差小时，$K$ 随转速增加的速率已经很慢；**两种不互溶液体的密度差一般更小**，故液滴外的扩散阻力几乎不随转速下降，密度差等于零时更是如此。

### 实验：I.V.C. 水解

异戊酰氯（I.V.C.）水解，用电导率跟踪，水解速率正比于界面面积（`#L8619`）。图7.12 中：

- 曲线（1）：几何平均滴径随转速，落在两条双曲线上，分界点是**临界转速 $N_a$**（此时开始吸入空气）；
- 曲线（2）：比界面积实测关联（`#L8633`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $A_0/V=1.77\times10^{-3}N^{1.35}$\quad（$\mathrm{dm^2/l}$） | （7.60） |
| **文字式** | 单位体积初始界面面积 ∝ 转速的 1.35 次方 |  |

- 曲线（3）：$R/V$ vs $N$，**平行于曲线（2）**（`#L8625`）——即 $R/V\propto A_0/V$，$K$ 不随转速变；
- 曲线（4）：$R_0/V=2.27\times10^{-5}N^{1.25}$；
- 曲线（6）：完全混合假设的理论值 $R/V=[2.38\times10^{-6}N^{1.35}m(1-x)(1-mx)^{-1/3}]_{m=0.2,\ x=0.4}$（`#L8641`）；
- 曲线（7）：分子扩散（无内循环）理论值，级数解（`#L8643`）。

### 密度差大时才有效

`#L8647`、`#L8649`：密度差大时 $R/V$ 的增长可以快于界面面积；苯甲酰氯（$\rho_0=1.22$）、富马酰氯（$\rho_0=1.41$）的水解中扩散阻力确实随转速略降。**但一般液液体系密度差小，降扩散膜阻力的作用微乎其微**——搅拌的作用几乎全部来自"把界面面积做大"。

## §7.7 从传质控制到反应控制（正丁酸酐）

正丁酸酐比重 0.9946，与水几乎同密度，反应速率与扩散速率同量级（`#L8669`）。

图7.13（`#L8671`）的三个区间：

1. **低转速**：$R_0/V$ 曲线（1）—（4）基本平行于 $A_0/V$ 曲线（5）→ 扩散控制，转速有效；
2. **高转速**：界面面积足够大后扩散速率超过反应速率，$R/V$ 饱和→ 转为水解控制；
3. 此时连续相中除水解产物丁酸外**必存在游离丁酸酐**（可用滴定验证）。

定量验证（`#L8671`）：取滤液（已除去分散液滴）测水解速率常数，$N=800$ r/min 得 $0.048$、$N=215$ r/min 得 $0.047$（文献临界值 $0.047$，单位原文作 [1/m]，按一级反应应为 [1/min]）——两者一致，证明高转速下"总速率=水相水解速率"。

**设计含义**：反应快、扩散慢的体系（如酰氯水解），转速与界面面积是杠杆；反应慢的体系，转速再高也白费，应改设计（延长停留时间、加催化剂）。

## §7.8 液滴内部混合：搅拌越强反而越不混合

搅拌对液液传质的三条途径（`#L8677`）：①分散相破裂使接触面积增加；②连续相扩散阻力减少；③搅拌对流引起**液滴内部混合**。前两条已讨论，第三条的实验（`#L8681`）：

用 $\alpha$-硝基丙烷稀释 I.V.C.（$\rho_0=1.015$、$25^\circ$C、$\mu=0.675$ cP、$\sigma=28.0$ dyn/cm），性质与纯 $\alpha$-硝基丙烷（$1.003$、$0.709$ cP、$30.0$ dyn/cm）相近但**稀释剂会在液滴内扩散**。

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{gx}=d_{g0}(1-mx)^{1/3}$;\qquad $A_x=A_0(1-mx)^{2/3}$ | （7.58）（7.59） |
| **文字式** | 转化率为 $x$ 时的滴径与比界面积，$m$ 为每单位转化率对应的体积收缩分数 |  |

取样 2~10 s 后测粒径分布定 $d_{gx}$（`#L8685`），$A_0/V$ 用式(7.60)。

**结果（图7.12 曲线1 与4 的对比）**：$N=160$ r/min、$d_g=0.75$ mm 时数据接近**完全混合**曲线；$N=800$ r/min、$d_g=0.15$ mm 时接近**分子扩散**（无内循环）曲线（`#L8699` 说明 A/V 观测曲线与 I.V.C.(100%) 曲线重叠）。

**结论**：滴越小、搅拌越强，液滴内部反而越接近"死水"，内部混合越差。原因是对流强度随滴径减小而迅速衰减，小滴内部只能靠分子扩散。**对快反应体系这是严重限制**：界面更新再快，滴内反应物供不上。

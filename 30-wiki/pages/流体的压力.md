# 流体的压力

## 定义（`#L950`）

流体**垂直作用于单位面积上的力**称为流体的压强，习惯上称为压力；作用于整个面积上的力称总压力。静止流体中，从各方向作用于某一点的压力大小均相等。

- 单位：法定单位制为 $N/m^2$，称帕斯卡（Pa）；
- **1 标准大气压 = 101325 Pa = 760 mmHg**。

## 三种计量基准（`#L952-#L966`）

| 名称 | 基准 | 关系 |
|:---|:---|:---|
| 绝对压力 | 绝对真空 | 流体的真实压力 |
| 表压 | 外界大气压 | 表压 = 绝对压力 − 大气压力；正值正压，负值负压 |
| 真空度 | 外界大气压 | 真空度 = 大气压力 − 绝对压力；测负压的表叫真空表 |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_{\text{表}}=p-p_{\text{atm}}$ | （无编号） |
| **文字式** | $\text{表压}_{\text{【Pa】}}=\text{绝对压力}_{\text{【Pa】}}-\text{大气压力}_{\text{【Pa】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_{\text{真}}=p_{\text{atm}}-p$ | （无编号） |
| **文字式** | $\text{真空度}_{\text{【Pa】}}=\text{大气压力}_{\text{【Pa】}}-\text{绝对压力}_{\text{【Pa】}}$ |  |

（两式由书内文字转写，书内未给出式号；1-1 已被密度式占用，勿混。）

**必须注明基准**：写流体压力时要说明是绝对压力、表压还是真空度（`#L966`）。

## 例 1-1（`#L976-#L978`）

真空表读真空度 30 kPa、出口压力表读表压 170 kPa，当地大气压 101 kPa：

- 进口绝对压力 $p_1=101-30=71$ kPa；
- 出口绝对压力 $p_2=170+101=271$ kPa。

## 判断

- 工程上压力表读的是表压，配方/物性表给的是绝对压力，两套数混用是常见错误来源；换算只有一个式子：绝对 = 表压 + 大气压。
- 真空度是"负表压取正"，只在低于大气压时有意义。

# 气泡周围液膜的传热与传质

## 先去掉气相阻力

搅拌容器或鼓泡柱中**气相阻力远小于液相阻力、可忽略**（`#L9670`）——只有两种例外：吸收高溶解度气体、吸收伴随极快化学反应。这与 §7 液液体系"密度差小则扩散阻力不随转速降"是同一类结构：阻力集中在哪一侧，决定了搅拌有没有用。

## 两条线：大气泡与小气泡

Calderbank–Moo-Young 用多孔板/烧结板通空气，把通气容器与鼓泡柱的液膜系数关联成图8.13 的**两条平行线**（`#L9672`）：

| 线 | 气泡条件 | 出现场合 | 对应图8.14 区间 |
|:---|:---|:---|:---|
| 上 | $d_p>2.5$ mm | 搅拌容器、筛板塔中向纯液体通气 | CD |
| 下 | $d_p<0.6$ mm | 搅拌容器中向**亲水性溶质水溶液**通气、烧结板通气 | AB |

## 大气泡：$Gr$ 关联

|  |  |  |
|:---|:---:|---|
| **符号式** | $Sh=0.42Gr^{1/3}Sc^{1/2}$ | （8.46） |
| **文字式** | 舍伍德数 = 0.42 × 格拉晓夫数^{1/3} × 施密特数^{1/2} |  |
| **符号式** | $k_L(Sc)^{1/2}=0.42\left(\dfrac{\Delta\rho\,\mu_c g}{\rho_c^{2}}\right)^{1/3}$ | （8.47） |
| **文字式** | 液膜系数 × 施密特数^0.5 = 0.42 × (密度差×黏度×重力/密度²)^{1/3} |  |

$Gr=d_p^{3}g\rho_c\Delta\rho/\mu_c^{2}$（`#L9682`）。

**注意 $Sc$ 的指数是 1/2**——这对应"自由对流/滑移主导"的传质，与常见的 2/3（表面更新）不同。

## 小气泡：$Ra$ 关联，且与传热同构

|  |  |  |
|:---|:---:|---|
| **符号式** | $Sh=Nu=0.31Ra^{1/3}$ | （8.48） |
| **文字式** | 舍伍德数 = 努塞尔数 = 0.31 × 雷利数^{1/3}——**传质与传热完全同构** |  |
| **符号式** | $k_L(Sc)^{2/3}=\dfrac{h_c}{C_p\rho_c}(Pr)^{2/3}=0.31\left(\dfrac{\Delta\rho\,\mu_c g}{\rho_c^{2}}\right)^{1/3}$ | （8.48′） |
| **文字式** | 液膜传质系数 × $Sc^{2/3}$ = 传热系数/($C_p\rho$)×$Pr^{2/3}$ = 0.31×(密度差×黏度×重力/密度²)^{1/3} |  |

$Ra=(d_p^{3}\Delta\rho g/D_f\mu)$、$Pr=C_p\mu/\lambda$（`#L9698`）。原书还给出与 $Gr$ 关联的等价式（8.49′，`#L9702`），并指出**该式也适用于悬浮在液体中的固体颗粒或液滴的传质**（`#L9704`）——即与 [[固液传质系数]] 中的小颗粒区同源。

### 一个重要的空缺

**式(8.48) 里没有粒子直径和速度**（`#L9706`）：连续相传热系数只由物性估算。物理含义——小气泡的界面更新由浮力驱动的自然对流控制，与气泡大小、搅拌强度都无关。

## 图8.14：$k_L$ 的平台与陡降

`#L9708`–`#L9725`：

- 转速增加，气泡沿 **DC 线**变小、界面面积 $a$ 增大，但 $k_L$ **直到 C 点保持定值**；
- 过 C 点（气泡小于 0.6 mm）进入过渡区，$k_L$ 沿 **CB 线急剧下降**；
- 到 B 点后又保持定值（小气泡区）；
- **$a$ 则一直随转速增加**。

所以 $k_La$ 随转速单调增，但 $k_L$ 本身有"平台—陡降—平台"三段。**只看 $k_La$ 会误判机理**：陡降段的 $k_La$ 增长完全来自 $a$。

## 小 $Ra$ 的修正

小雷利数范围内关联曲线偏离(8.48)，$Sh$ 或 $Nu$ 趋近纯分子扩散值 2.0（`#L9727`）。全范围用（`#L9729`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $Sh=Nu=2.0+0.31Ra^{1/8}$ | （8.50） |
| **文字式** | 舍伍德数 = 2.0（分子扩散下限）+ 0.31×雷利数^{1/8} |  |

**注意指数从 1/3 变成 1/8**：小 $Ra$ 时浮力对流弱，传质接近分子扩散，指数变小。式(8.48) 与 (8.50) 不可混用，先判 $Ra$ 量级。

## 工程用法

1. 算 $Ra$（或 $Gr$）判断大气泡/小气泡区间；
2. 大气泡用(8.46)(8.47)，小气泡用(8.48)(8.48′)；
3. $k_L$ 出来后乘 $a$ 得 $k_La$，$a$ 见 [[气泡尺寸与比界面积的关联式]]；
4. **转速只通过 $a$ 起作用**（在平台区间内）——这解释了为什么 Cooper 式中盘下直叶涡轮的功率指数高达 0.95，而桨式只有 0.38：前者把气泡打进小气泡区、$a$ 大增。

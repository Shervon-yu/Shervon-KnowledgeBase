# 激光多普勒测量

## 特点（`#L412`）

激光多普勒测速仪（LDA）20 世纪 60 年代发展起来，具有**非接触**、线性特性、**高空间分辨率**、快速动态响应等特点。

## 原理（`#L418`）

激光射到气液两相中的气泡时，散射光频率与入射光频率的**多普勒偏移**与流速成正比。

## 由速度算气含率（`#L418-#L421`）

N. Zuber 依漂移通量模型给出：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\alpha_g=\dfrac{U_g}{C(U_g+U_s)+U_{b,\infty}}$ | （1.10） |
| **文字式** | $\text{气含率}=\dfrac{\text{表观气速}}{\text{分布参数}\times(\text{表观气速}+\text{混合物循环速度})+\text{气泡终端上升速度}}$ |  |

## 信号处理方法（`#L424`）

A. Kulkarni、王国峰等用小波分析处理 LDA 测得的速度时序信号，按 LIM（局部间歇测量）法辨识与气泡特征相关的奇异点，取 LIM 均方根为基、选门限阈值，得到局部气含率的径向分布。也有用 LDA 测搅拌釜三维液速、二维时均速度场与湍流强度场的报道。

## 局限（`#L424`）

**LDA 只适用于低浓度体系**——气泡过密时激光被强烈散射、无法聚焦到测量体。

## 判断

- （1.10）是"把速度信息换算成气含率"的桥梁，依赖 $C$ 与 $U_{b,\infty}$ 两个经验量，故它不是纯测量，而是"测量 + 模型"。
- "只适用低浓度"与搅拌釜实际工况矛盾：通气搅拌釜中心区气含率可达 10%~20%，激光根本穿不透，这就是 LDA 在本书体系中只能作辅助手段的原因。
- LIM + 小波本质是"从单点速度时序里找出气泡经过的奇异点"，与探头法的事件计数同源，只是信号来自光学而非电学。

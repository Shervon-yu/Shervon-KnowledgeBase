# 显式隐式方法与稳定性分析

## 显式与隐式的取舍（§4.4）

- 显式：$\Delta t$ 不是自由参数，一旦 $\Delta x$ 定了，$\Delta t$ 必须小于某个稳定性上限；超限后推进很快不稳定，程序会因数值发散而中止（#L3302）。
- 隐式：没有这种稳定性限制，许多隐式方法可取比显式大得多的 $\Delta t$，有些是**无条件稳定**的（#L3302）。代价是每步要解线性方程组，单步更贵；但步数少得多，总时间常常反而更短（#L3302、#L3328）。
- 第 9 章库埃特流算例即用 Crank-Nicolson，明确说它无条件稳定，$\Delta t$（参数 $E$）从 1 取到 4000 仍稳定（#L9548、#L9568）。

## 数值误差与稳定性定义（§4.5）

把数值解写成真解加误差 $N=D+\varepsilon$（式 4-55，＃L3384）。舍入误差也服从同一个差分方程（4-56～4-58，＃L3390-3398），所以稳定性就转化为误差是否放大（#L3356、#L3402）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left|\dfrac{\varepsilon_i^{n+1}}{\varepsilon_i^{n}}\right|\leqslant1$ | （4-59） |
| **文字式** | $\left|\dfrac{\text{误差}^{n+1}}{\text{误差}^{n}}\right|\leqslant1$ |  |

误差不增长（或衰减）则稳定，放大则不稳定。

## von Neumann 方法

把误差展成 Fourier 级数（式 4-60、4-67、4-68，＃L3422-3494）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\varepsilon(x,t)=\sum_{m=1}^{N/2}A_m(t)\,\mathrm{e}^{\mathrm{j}k_mx}$ | （4-67） |
| **文字式** | $\text{误差}(x,t)=\sum\text{振幅}_m(t)\times\mathrm{e}^{\mathrm{j}\times\text{波数}_m\times x}$ |  |

代入差分方程得放大因子 $G=\mathrm{e}^{a\Delta t}$（式 4-74、4-90，＃L3542、＃L3668），稳定条件为 $|G|\le1$。

### 显式热传导：$\alpha\Delta t/\Delta x^2\le1/2$

把 $T$ 的模态代入显式格式（4-70，＃L3510），得（4-73，＃L3538）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mathrm{e}^{a\Delta t}=1-\dfrac{4\alpha\Delta t}{(\Delta x)^2}\sin^2\dfrac{k_m\Delta x}{2}$ | （4-73） |
| **文字式** | $\text{放大因子}=1-\dfrac{4\times\text{热扩散系数}\times\Delta\text{时间}}{(\Delta x)^2}\sin^2\dfrac{\text{波数}_m\times\Delta x}{2}$ |  |

要求 $|\mathrm{e}^{a\Delta t}|\le1$，得（式 4-77，＃L3568）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\alpha\Delta t}{(\Delta x)^2}\leqslant\dfrac{1}{2}$ | （4-77） |
| **文字式** | $\dfrac{\text{热扩散系数}\times\Delta\text{时间}}{(\Delta x)^2}\leqslant\dfrac{1}{2}$ |  |

超过此值误差持续增大，"最终导致数值推进的解在计算机上爆掉"（#L3574）。

### 一阶波动方程：CFL 条件

以 $\partial u/\partial t+c\,\partial u/\partial x=0$（式 4-78，＃L3580）为模型：

- 时间向前、空间中心（式 4-80，＃L3588）：von Neumann 分析表明**无论 $\Delta t$ 取多少都不稳定**——无条件不稳定（#L3590）。
- 改用 $u_i^n\approx\frac12(u_{i+1}^n+u_{i-1}^n)$（式 4-81、4-82，＃L3596-3600），放大因子 $\mathrm{e}^{at}=\cos(k_m\Delta x)-\mathrm{i}C\sin(k_m\Delta x)$（4-83，＃L3604），稳定条件（式 4-84，＃L3612）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C=|c|\dfrac{\Delta t}{\Delta x}\leqslant1$ | （4-84） |
| **文字式** | $\text{柯朗数}=|\text{波速}|\times\dfrac{\Delta\text{时间}}{\Delta x}\leqslant1$ |  |

$C$ 称柯朗数，此即 **CFL 条件**（Courant-Friedrichs-Lewy，1928）。

CFL 的物理解释（#L3646-3652）：**数值解的依赖区域必须包含解析解的依赖区域**。若 $C>1$，特征线跑到网格依赖区之外，信息来不及传到，计算必不稳定。
反过来，$C$ 远小于 1 时虽然稳定，但数值依赖区远大于解析依赖区，精度差（#L3654）。

### 二阶波动方程

$\partial^2u/\partial t^2=c^2\partial^2u/\partial x^2$（4-85，＃L3618）的显式格式稳定性条件同样是 $C\le1$；当 $C=1$ 时 $\Delta t=\Delta x/c$（4-87，＃L3628），数值解与解析解在节点上重合。

## 适用边界

- von Neumann 分析严格成立于**线性、常系数**差分方程；对非线性欧拉/N-S 方程"还没有严格的稳定性分析"，CFL 只能作指导（#L3342、#L6433）。
- 稳定性不等于精度：$C$ 太小、$\Delta t$ 太小都会让截断误差累积或耗散过大（#L3654）。
- 隐式格式取消的是稳定性限制，不是精度限制：要准确模拟瞬态，$\Delta t$ 仍要按时间精度取（#L9552）。

## 判断

CFL 条件不是"经验法则"，而是双曲型方程依赖区域包含关系的直接推论；显式热传导的 1/2 也不是拍脑袋，而是 Fourier 模态放大因子绝对值不超过 1 的解。反过来，看到"无条件不稳定"的中心显式格式（4-80）就该明白：中心差分的二阶精度救不了它，格式的空间-时间配比错了，精度再高也发散。

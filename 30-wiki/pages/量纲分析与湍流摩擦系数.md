# 量纲分析与湍流摩擦系数

## 管壁粗糙度（`#L2044-#L2064`）

管壁粗糙度用**绝对粗糙度** $\varepsilon$（mm，壁面凸出物平均高度）表示。常用值：

| 管材 | $\varepsilon$/mm |
|:---|:---|
| 无缝黄铜、铜、铝管 | 0.01~0.05 |
| 新无缝钢管、镀锌铁管 | 0.1~0.2 |
| 新铸铁管 | 0.3 |
| 轻度腐蚀的无缝钢管 | 0.2~0.3 |
| 显著腐蚀的钢管 | 0.5 以上 |
| 旧铸铁管 | 0.85 以上 |
| 干净玻璃管 | 0.0015~0.01 |

相对粗糙度 $\varepsilon/d$ 才是影响阻力的参数。

## 粗糙度如何影响阻力（`#L2066-#L2074`）

- 层流：层流底层厚，凸出物全被盖住，$\lambda$ 只随 $Re$；
- 湍流：若层流底层厚度 $\delta>\varepsilon$，仍如水力光滑管；
- $\delta<\varepsilon$ 时凸出物伸入湍流主体、产生旋涡，阻力增大；
- $Re$ 大到 $\delta$ 极薄，全部凸出物都起作用 → **完全湍流（完全粗糙管）**，$\lambda$ 只随 $\varepsilon/d$。

## 量纲分析导出关联式（`#L2076-#L2147`）

阻力压降与 $d$、$l$、$u$、$\rho$、$\mu$、$\varepsilon$ 有关：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p_f=f(d,l,u,\rho,\mu,\varepsilon)$ | （1-46） |
| **文字式** | $\text{压降}_{\text{【Pa】}}=\text{管内径、管长、流速、密度、黏度、绝对粗糙度的函数}$ |  |

物理量 7 个（$n=7$）、基本量纲 3 个（$m=3$），由 π 定理可得无量纲数 $N=n-m=4$ 个。设幂函数形式（1-48）$\Delta p=Kd^al^bu^c\rho^d\mu^e\varepsilon^f$，按量纲一致解得

$$a=-b-e-f,\qquad c=2-e,\qquad d=1-e$$

代回并整理成 4 个无量纲数：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\Delta p}{\rho u^2}=K\left(\dfrac{l}{d}\right)^{b}\left(\dfrac{du\rho}{\mu}\right)^{-e}\left(\dfrac{\varepsilon}{d}\right)^{f}$ | （1-49） |
| **文字式** | $\text{欧拉数}=\text{常数}\times\left(\dfrac{\text{管长}}{\text{管内径}}\right)^{b}\times\text{雷诺数}^{-e}\times\left(\dfrac{\text{绝对粗糙度}}{\text{管内径}}\right)^{f}$ |  |

因阻力与管长一次方成正比，实验取 $b=1$；再与 1-44 对比得：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\psi\left(Re,\dfrac{\varepsilon}{d}\right)$ | （1-50） |
| **文字式** | $\text{摩擦系数}=\text{雷诺数与相对粗糙度的函数}$ |  |

**量纲分析的价值**：把 7 个物理量的关系压缩成 3 个无量纲量的关系，变量数与实验量都大幅减少；具体函数形式仍需实验确定。

## λ 关联图的四个区域（`#L2153-#L2173`）

图 1-29 把层流与湍流的 $\lambda$ 画在一起：

| 区域 | 范围 | λ 规律 | $h_f$ 与 u |
|:---|:---|:---|:---|
| 层流区 | $Re\le2000$ | $\lambda=64/Re$，与 $\varepsilon/d$ 无关 | 一次方 |
| 过渡区 | $2000<Re<4000$ | 不稳定，**按湍流计算** | — |
| 湍流区 | 光滑管曲线至虚线 | 与 $Re$ 和 $\varepsilon/d$ 都有关 | 介于一次与二次 |
| 完全湍流区 | 虚线上方 | $\lambda$ 只随 $\varepsilon/d$，与 $Re$ 无关 | 平方（阻力平方区） |

## 关联式（`#L2179-#L2197`）

光滑管、$2.5\times10^3<Re<10^5$，布拉修斯式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\dfrac{0.3164}{Re^{0.25}}$ | （1-51） |
| **文字式** | $\text{摩擦系数}=\dfrac{0.3164}{\text{雷诺数}^{0.25}}$ |  |

湍流区、从光滑管到完全湍流都适用——考莱布鲁克式（隐函数）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{1}{\sqrt{\lambda}}=-2\lg\left(\dfrac{\varepsilon/d}{3.7}+\dfrac{2.51}{Re\sqrt{\lambda}}\right)$ | （1-52） |
| **文字式** | $\dfrac{1}{\sqrt{\text{摩擦系数}}}=-2\lg\left(\dfrac{\text{相对粗糙度}}{3.7}+\dfrac{2.51}{\text{雷诺数}\times\sqrt{\text{摩擦系数}}}\right)$ |  |

哈兰德式（显函数，便于计算）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{1}{\sqrt{\lambda}}=-1.8\lg\left[\left(\dfrac{\varepsilon/d}{3.7}\right)^{1.11}+\dfrac{6.9}{Re}\right]$ | （1-53） |
| **文字式** | $\dfrac{1}{\sqrt{\text{摩擦系数}}}=-1.8\lg\left[\left(\dfrac{\text{相对粗糙度}}{3.7}\right)^{1.11}+\dfrac{6.9}{\text{雷诺数}}\right]$ |  |

## 判断

- 过渡区"按湍流算"是安全侧的工程约定，不是物理事实：2000~4000 之间流型随扰动跳变。
- 1-52 是隐式，手算需迭代；1-53 显式且精度足够，工程计算优先用它，与查图结果误差通常在 1% 内。

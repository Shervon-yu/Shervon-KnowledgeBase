# q线方程与操作线的绘制

## 两操作线交点（`#L11886-#L11902`）

联立精馏段线（6-35）与提馏段线（6-40），得交点 $f(x_f,y_f)$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $x_f=\dfrac{(R+1)x_F+(q-1)x_D}{R+q}$，$y_f=\dfrac{Rx_F+qx_D}{R+q}$ | （6-45）（6-46） |
| **文字式** | 交点横坐标 = [(回流比+1)×进料组成 + (q−1)×馏出液组成]/(回流比+q) |  |

## q 线方程（`#L11904-#L11910`）

消去 $x_D$ 得：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y=\dfrac{q}{q-1}x-\dfrac{x_F}{q-1}$ | （6-47） |
| **文字式** | $\text{汽相组成}=\dfrac{q}{q-1}\times\text{液相组成}-\dfrac{\text{进料组成}}{q-1}$ |  |

**q 线是两操作线交点 f 的轨迹**，必过对角线上 $F$ 点 $(x_F,x_F)$：

- 斜率 $q/(q-1)$；$q=1$（饱和液体）→ 垂直；$q=0$（饱和蒸气）→ 水平；
- $q>1$（冷液）→ 斜率 >1，指向左上（第一象限方向）；$0<q<1$ → 斜率 <0，指向右上；$q<0$（过热蒸气）→ 斜率 0~1 之间，指向右下。

## 五种进料状态的 q 线方位（图6-22，`#L11910`）

| 进料状态 | q | 斜率 $q/(q-1)$ | 方位 |
|:--|:--|:--|:--|
| 冷液 | >1 | 正、>1 | 从 F 点向左上 |
| 饱和液体 | 1 | ∞（垂直） | 过 F 点竖直 |
| 汽液混合物 | 0~1 | 负 | 从 F 点向右上 |
| 饱和蒸气 | 0 | 0（水平） | 过 F 点水平 |
| 过热蒸气 | <0 | 0~1 | 从 F 点向右下 |

## 作图四步（`#L11914-#L11916`）

1. 作对角线，按 $x_D$、$x_F$、$x_W$ 作垂线交对角线于 D、F、W；
2. 在 $y$ 轴上按截距 $x_D/(R+1)$ 定 I 点，连 DI 即精馏段操作线（斜率 $R/(R+1)$）；
3. 从 F 点以斜率 $q/(q-1)$ 作 q 线，与 DI 交于 f；
4. 连 fW 即提馏段操作线（斜率 $L'/V'=(R'+1)/R'$，必过 $(x_W,x_W)$）。

## 例6-9（`#L11918-#L11942`）

苯-甲苯，$\alpha$=2.46、$x_D$=0.94、$x_W$=0.04、$W$=150 kmol/h、$R$=2.05、q 线 $y=6x-1.5$：

- 精馏段：$y=0.672x+0.308$；
- 由 q 线斜率 6 → $q=1.2$；由截距 1.5 → $x_F=0.3$；
- $D/F=\frac{0.3-0.04}{0.94-0.04}=0.289$；
- 提馏段：$y=1.658x-0.026$。

## 判断

- q 线不是"独立的操作线"，它是两段操作线交点的几何约束；用它可以**只凭 R、q、三个组成**作出两条操作线，无需流量绝对值。
- 进料板位置的最优解就在 q 线与操作线交点 f 附近：跨过 f 的那个梯级就是最佳进料板（见 [[理论板数的图解法]]）。
- q 线斜率的符号变化是"进料状态影响分离"的几何表达：冷液进料 q 线陡、交点左移，精馏段板数减少而提馏段板数增加。

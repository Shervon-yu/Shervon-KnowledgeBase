# 外压球壳与加强圈

## 外压球壳（6.4）

### 应变系数 A（式6-5）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=\dfrac{0.125}{R_o/\delta_e}$ | （6-5） |
| **文字式** | $\text{应变系数}=\dfrac{0.125}{\text{外半径}/\text{有效厚度}}$ |  |

### 应力系数 B 与许用外压力（式6-6）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $[p]=\dfrac{B}{R_o/\delta_e}$ | （6-6） |
| **文字式** | $\text{许用外压力}_{\text{【MPa】}}=\dfrac{\text{应力系数}}{\text{外半径}/\text{有效厚度}}$ |  |

B 的取法与圆筒相同（表6-1 查曲线，超端点取端点，低于最小值用式6-1）。

## 外压圆筒加强圈（6.5）

加强圈用来**缩短计算长度 L**，L 变小则 A 变大、B 变大、[p] 变大——不是直接"加强"材料。

### 惯性矩校核（式6-7~6-9）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $B=\dfrac{p_cD_o}{\delta_e+A_s/L_s}$；$\quad A=\dfrac{3B}{2E}$（B 低于曲线最小值时）；$\quad I=\dfrac{D_o^2L_s(\delta_e+A_s/L_s)}{10.9}A$ | （6-7）（6-8）（6-9） |
| **文字式** | $\text{应力系数}=\dfrac{\text{计算外压力}\times\text{外径}}{\text{有效厚度}+\text{加强圈截面积}/\text{加强圈间距}}$；$\quad \text{应变系数}=\dfrac{3\times\text{应力系数}}{2\times\text{弹性模量}}$；$\quad \text{所需惯性矩}=\dfrac{\text{外径}^2\times\text{间距}\times(\text{有效厚度}+\text{截面积}/\text{间距})}{10.9}\times\text{应变系数}$ |  |

- 组合截面 = 加强圈 + 圆筒有效段，有效段为**加强圈中心线两侧各 $0.55\sqrt{D_o\delta_e}$** 的壳体；
- 相邻加强圈有效段重叠时，重叠部分每侧按一半计；
- 要求 $I_s\ge I$，且尽量接近（不浪费）；
- 流程与圆筒相反：圆筒是 A→B，加强圈是 B→A（先由式6-7 得 B，再查图得 A）。

### 设置要求（6.5.2）

- 可设在容器内或外部，须**整圈**围绕筒体；
- 加强圈端部接合按图6-15 的 A、B 形式；
- 加强圈与筒体之间间隙不得超过**筒体名义厚度的 8 倍**（否则不参与组合截面）。

## 判断

- 加强圈的收益是指数性的：L 减半、$D_o/\delta_e$ 不变时 A 约翻倍，B 随之提高，[p] 近似翻倍；
- 但加强圈只对**短圆筒**有效（$\omega$ 小）；细长筒（L 很大于 $D_o$）本身已进入长圆筒区，再加圈收益递减；
- 工程上常见误区：把加强圈做得又高又薄追求惯性矩，实际 $I$ 按形心算，**离壳体中面越远的面积越有效**，所以 T 形截面比等面积矩形强；
- 外压球壳没有加强圈条款（球壳的失稳是整体性的），只能加厚或改结构。

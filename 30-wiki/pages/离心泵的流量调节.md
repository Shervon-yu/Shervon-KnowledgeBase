# 离心泵的流量调节

## 两条思路（`#L3589`）

调节流量 = 改变工作点。工作点是泵特性曲线与管路特性曲线的交点，所以只有两条路：

1. 改变**管路特性曲线**：排出管上装调节阀，改阀门开度（节流）；
2. 改变**泵特性曲线**：改转速（或切削叶轮）。

## 一、改变阀门开度（`#L3591-#L3597`）

关小阀门 → 局部阻力 $\zeta$ 增大 → 管路特性系数 $k$ 增大 → 曲线变陡 → 工作点由 $A$ 移到 $B$，流量由 $q_{VA}$ 降到 $q_{VB}$。

代价：阀门关小后额外消耗的压头 $H_B-H_C$（$C$ 为原管路曲线在 $q_{VB}$ 处的点），这部分压头白白节流掉了。

| 优点 | 缺点 |
|:---|:---|
| 简便灵活 | 不经济，有节流附加损失 |
| 广泛采用 | 只适合较小流量、调节幅度不大的系统 |

## 二、改变泵的转速（`#L3603-#L3605`）

管路曲线不动，把泵特性曲线从 $n$ 移到 $n'$，工作点沿管路曲线由 $A$ 移到 $C$，流量与压头同时下降。

- 无节流附加损失 → **经济**；
- 需变速装置或可变速原动机（直流电动机、汽轮机、变频器）；
- 转速**不得超过额定转速**，否则叶轮强度与电动机负荷超限。

## 三、变速调节的算法（例2-3，`#L3607-#L3689`）

要点：$A$（原工作点）与 $C$（目标工作点）一般**不在同一条等效率曲线**上，不能直接用比例定律。

步骤：

1. 由目标点 $C$ 写出等效率方程 $H=Kq_V^2$，其中

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K=\dfrac{H_C}{q_{VC}^2}$ | （2-12） |
| **文字式** | $\text{等效率常数}=\dfrac{\text{目标点扬程}_{\text{【m】}}}{\left(\text{目标点流量}\right)^2}$ |  |

2. 令等效率方程与额定转速下的泵特性方程联立，解出等效点 $D$（$q_{VD}$、$H_D$）；
3. 再用比例定律 $n_C=n_D\dfrac{q_{VC}}{q_{VD}}$ 求目标转速；
4. 校验转速变化是否 <20%，以判断比例定律是否适用。

例2-3 结果：$K$=9.2、$D$ 点 $q_{VD}$=1.33 m³/min、$H_D$=16.2 m、$n_C$=2660 r/min，降幅 8.3%<20%，可用。

## 判断

- 例2-3 第（3）问给出节流代价的定量尺度：流量从 1.41 降到 1.22 m³/min（−13%），阀门多耗 3.7 m 水柱压头，占原扬程 15 m 的 25%。这就是"关阀省流量、费电"的具体量级。
- 变速调节的节能本质在比例定律三次方：流量降 13%，功率约降 $(1.22/1.41)^3\approx0.65$，省 35%。

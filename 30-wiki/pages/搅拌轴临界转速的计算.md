# 搅拌轴临界转速的计算

## 刚性轴与柔性轴

轴转速达到自振频率时发生强烈振动、出现很大弯曲，该转速称**临界转速** $n_{cr}$（`#L11511`）。

- **刚性轴**：工作转速低于第一阶临界转速，要求 $n\le0.7n_{cr}$；
- **柔性轴**：工作转速高于第一阶临界转速，要求 $n\ge1.3n_{cr}$。

搅拌轴工作转速一般较低，很少达到第二、三阶临界转速，故只算**第一阶**。

## 允许转速比（表9-95，抗振条件）

| 介质 | 刚性轴 | 柔性轴 |
|:---|:---|:---|
| 气体 | $n/n_{cr}\le0.7$ | 不推荐 |
| 液体-液体、液体-固体 | $n/n_{cr}\le0.7$，且避开 $0.45\sim0.55$ | $n/n_{cr}=1.3\sim1.6$ |
| 液体-气体 | $n/n_{cr}\le0.6$ | 不推荐 |
| 叶片式高速搅拌器（桨式、开启涡轮、圆盘涡轮、三叶后掠、推进式） | 同上，另取 $\le0.4$ | — |

注：叶片式搅拌器指桨式、开启涡轮式、圆盘涡轮式、三叶后掠式、推进式；**不包括**锚式、框式、螺带式（`#L11691`）。表9-95 为 OCR 多列合并表，列序与「≤0.4」的归属**待核**。

## 等效质量法

大型设备轴径粗、轴质量不可忽略，用**等效质量法**：把轴的分布质量与各层搅拌器质量按等效原理折算到特定点（悬臂轴为末端 $S$），累加成**一个集中等效质量**，把多自由度问题化为单自由度（`#L11513`）。

### 1. 有效质量

刚性轴（锚式、框式除外）的有效质量 = 轴自身质量 + **轴附带液体质量**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $m_{L1e}=\dfrac{\pi}{4}d_{L1}^{2}L_{1}\left[\rho_{s}(1-N_{0}^{2})+\rho\right]\times10^{-9}$ | （9-13） |
| **文字式** | $\text{悬臂段有效质量}_{\text{【kg】}}=\dfrac{\pi}{4}\times\text{悬臂段外径}_{\text{【mm】}}^{2}\times\text{悬臂段长度}_{\text{【mm】}}\times\left[\text{轴材密度}_{\text{【kg/m}^{3}\text{】}}(1-\text{空心比}^{2})+\text{物料密度}_{\text{【kg/m}^{3}\text{】}}\right]\times10^{-9}$ |  |

单跨轴同理（式9-14）：$m_{Le}=\dfrac{\pi}{4}d_{L}^{2}L\left[\rho_{s}(1-N_{0}^{2})+\rho\right]\times10^{-9}$。

**柔性轴**及带锚式、框式的刚性轴：有效质量**等于轴自身质量**（式9-15、9-16）：
$m_{L1e}=m_{L1}$、$m_{Le}=m_{L}$。

搅拌器（含附件）有效质量，刚性轴：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $m_{ie}=m_{i}+\eta_{ki}\dfrac{\pi}{4}D_{Ji}^{2}h_{i}\rho\cos\theta_{i}\times10^{-9}$ | （9-17） |
| **文字式** | $\text{搅拌器有效质量}_{\text{【kg】}}=\text{搅拌器质量}_{\text{【kg】}}+\text{附加质量系数}\times\dfrac{\pi}{4}\times\text{搅拌器直径}_{\text{【mm】}}^{2}\times\text{叶片宽}_{\text{【mm】}}\times\text{物料密度}_{\text{【kg/m}^{3}\text{】}}\times\cos\text{叶片倾角}\times10^{-9}$ |  |

柔性轴及锚/框刚性轴：$m_{ie}=m_{i}$（式9-18）。

**附加质量系数 $\eta_{ki}$（表9-94）**

| 叶片数 | 叶片角 | $\eta_{ki}$ | 叶片数 | 叶片角 | $\eta_{ki}$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 2 | 0°（直叶） | 0.31 | 4 | 0° | 0.29 |
| 2 | 45°（斜叶） | 0.31 | 4 | 45° | 0.29 |
| 3 | 0° | 0.27 | 6 | 0° | 0.53 |
| 3 | 45° | 0.17 | 6 | 45° | 0.30 |

### 2. 悬臂轴（两轴段等直径）

轴有效质量的相当质量 $W$ 与各层搅拌器相当质量 $W_{i}$ 折算到末端 $S$：

$W=\dfrac{140a^{2}+231L_{1}a+99L_{1}^{2}}{420(L_{1}+a)^{2}}m_{L1e}$（9-19）；

$W_{i}=\dfrac{L_{i}^{2}(L_{i}+a)}{L_{1}^{2}(L_{1}+a)}m_{ie}$（9-20，原文分子分母 OCR 重复，按结构补出，**待核**）；

$W_{s}=W+\sum_{i=1}^{m}W_{i}$（9-21）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $n_{cr}=114.7\,d_{L1}^{2}\sqrt{\dfrac{E(1-N_{0}^{4})}{L_{1}^{2}(L_{1}+a)W_{s}}}$ | （9-22） |
| **文字式** | $\text{第一阶临界转速}_{\text{【r/min】}}=114.7\times\text{悬臂段外径}_{\text{【mm】}}^{2}\times\sqrt{\dfrac{\text{弹性模量}_{\text{【MPa】}}\times(1-\text{空心比}^{4})}{\text{悬臂长度}_{\text{【mm】}}^{2}\times(\text{悬臂长度}_{\text{【mm】}}+\text{跨间距离}_{\text{【mm】}})\times\text{相当质量总和}_{\text{【kg】}}}}$ |  |

### 3. 悬臂轴（两轴段直径不等）

以 $\lambda$ 代入：式（9-23）$W=\dfrac{140a^{2}\lambda^{2}+231L_{1}a\lambda+99L_{1}^{2}}{420(L_{1}+a\lambda)^{2}}m_{L1e}$；式（9-24）$W_{i}$ 同 9-20 形式、以 $L_{1}+\lambda a$ 修正；式（9-25）求和；式（9-26）：

$n_{cr}=114.7\,d_{L}^{2}\sqrt{\dfrac{E(1-N_{0}^{4})}{L_{1}^{2}(L_{1}+\lambda a)W_{s}}}$。

### 4. 单跨轴

① 两端**简支**：$W=\dfrac{17}{35}m_{Le}$（9-27）；$W_{i}=16K_{i}^{2}(1-K_{i})^{2}m_{ie}$（9-28）；$W_{s}=W+\sum W_{i}$（9-29）；

|  |  |  |
|:---|:---:|---:|
| **符号式** | $n_{cr}=458.9\,d_{L}^{2}\sqrt{\dfrac{E(1-N_{0}^{4})}{W_{s}L^{3}}}$ | （9-30） |
| **文字式** | $\text{第一阶临界转速}_{\text{【r/min】}}=458.9\times\text{跨间轴外径}_{\text{【mm】}}^{2}\times\sqrt{\dfrac{\text{弹性模量}_{\text{【MPa】}}\times(1-\text{空心比}^{4})}{\text{相当质量总和}_{\text{【kg】}}\times\text{跨长}_{\text{【mm】}}^{3}}}$ |  |

② 一端**固支**另一端**简支**：$W=\dfrac{15}{35}m_{Le}$（9-31，OCR 值偏低，**待核**）；$W_{i}=\dfrac{64}{7}K_{i}^{3}(1-K_{i})^{2}(4-K_{i})m_{ie}$（9-32）；$W_{s}$ 同（9-33）；$n_{cr}=693.7\,d_{L}^{2}\sqrt{\dfrac{E(1-N_{0}^{4})}{W_{s}L^{3}}}$（9-34）。

③ 一般单跨轴传动侧支点夹持系数 $K_{2}$ 介于两者之间，取中间值（式9-35）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $n_{cr}=n_{cr固简}(1-K_{2})+n_{cr简}K_{2}$ | （9-35） |
| **文字式** | $\text{临界转速}_{\text{【r/min】}}=\text{固支}-\text{简支值}_{\text{【r/min】}}\times(1-\text{夹持系数})+\text{两端简支值}_{\text{【r/min】}}\times\text{夹持系数}$ |  |

**夹持系数 $K_{2}$**（`#L11660-#L11666`）：

| 支架与联轴器 | $K_{2}$ | 接近的模型 |
|:---|:---:|:---|
| 单支点 + 弹性联轴器 | 0.7~0.9 | 两端简支 |
| 单支点 + 刚性联轴器 | 0.4~0.6 | 简支与固简之间 |
| 双支点 + 弹性联轴器 | 0.4~0.6 | 简支与固简之间 |
| 双支点 + 刚性联轴器 | 0.1~0.3 | 一端固支另一端简支 |

## 使用要点

1. 式（9-22）/（9-30）/（9-34）中的 $E$ 取轴材料的弹性模量（表9-105，碳钢 $2.1\times10^{6}$ MPa、不锈钢 $1.93\times10^{6}$ MPa）。
2. 算得 $n_{cr}$ 后与工作转速比对表9-95；不满足时**加粗轴径**或缩短悬臂（见 [[搅拌轴的支点类型与减挠措施]]）。
3. $\lambda$ 见 [[搅拌轴设计的任务与力学模型]]；$K_{i}=L_{i}/L$ 为第 $i$ 个搅拌器至传动侧轴承距离与跨长之比。

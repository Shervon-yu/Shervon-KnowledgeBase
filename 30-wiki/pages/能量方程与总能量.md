# 能量方程与总能量

## 第一定律用于运动微团（§2.7）

记 $A$＝微团总能量的时间变化率，$B$＝微团内加热率（体积加热 + 热传导），$C$＝表面力对微团做功的功率，则（式 2-59，＃L1530）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=B+C$ | （2-59） |
| **文字式** | $\text{总能量变化率}=\text{加热率}+\text{表面力做功功率}$ |  |

- 体积加热 $\rho\dot{q}\,\mathrm{d}x\mathrm{d}y\mathrm{d}z$（式 2-61，＃L1566）；热传导净加热 $-\left(\partial\dot{q}_x/\partial x+\partial\dot{q}_y/\partial y+\partial\dot{q}_z/\partial z\right)\mathrm{d}x\mathrm{d}y\mathrm{d}z$（式 2-62，＃L1574）；用 Fourier 定律 $\dot{q}_i=-k\,\partial T/\partial x_i$ 得（式 2-64，＃L1588）。
- 做功项 $C$ 含压力与全部粘性应力（式 2-60，＃L1550）。
- 总能量变化率 $A=\rho\,\dfrac{\mathrm{D}}{\mathrm{D}t}\left(e+\dfrac{V^2}{2}\right)\mathrm{d}x\mathrm{d}y\mathrm{d}z$（式 2-65，＃L1602），$e$ 为单位质量内能。

合并得到**总能量方程**（式 2-66，＃L1606）：左端是总能量（内能 + 动能）的物质导数，右端是加热、热传导、压力做功、粘性做功与体积力做功之和。

## 内能方程：减去机械能

把三个动量方程分别乘以 $u$、$v$、$w$ 相加，得到机械能方程（式 2-68～2-70，＃L1628-1636）；从（2-66）中减去它，得到内能方程（式 2-71，＃L1640；合并对称项后 2-72，＃L1646）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho\dfrac{\mathrm{D}e}{\mathrm{D}t}=\rho\dot{q}+\dfrac{\partial}{\partial x}\left(k\dfrac{\partial T}{\partial x}\right)+\dfrac{\partial}{\partial y}\left(k\dfrac{\partial T}{\partial y}\right)+\dfrac{\partial}{\partial z}\left(k\dfrac{\partial T}{\partial z}\right)-p\left(\dfrac{\partial u}{\partial x}+\dfrac{\partial v}{\partial y}+\dfrac{\partial w}{\partial z}\right)+\Phi$ | （2-73） |
| **文字式** | $\text{密度}\times\dfrac{\text{物质导数}_{\text{【内能】}}}{\text{时间}}=\text{密度}\times\text{体积加热率}+\text{热传导项}-\text{压力}\times(\text{速度散度})+\text{粘性耗散函数}$ |  |

$\Phi$ 是用 $\lambda,\mu$ 与速度梯度写出的粘性耗散项（式 2-73 的后三行，＃L1654）。物理上：内能变化来自加热、导热、压缩功与粘性耗散。

## 守恒（散度）形式

用与动量方程相同的改写（式 2-74～2-77，＃L1662-1682），内能方程写成（式 2-78，＃L1686）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial(\rho e)}{\partial t}+\nabla\cdot(\rho e\boldsymbol{V})=\rho\dot{q}+\nabla\cdot(k\nabla T)-p\nabla\cdot\boldsymbol{V}+\Phi$ | （2-78） |
| **文字式** | $\dfrac{\partial(\text{密度}\times\text{内能})}{\partial\text{时间}}+\nabla\cdot(\text{密度}\times\text{内能}\times\text{速度})=\text{体积加热}+\nabla\cdot(\text{导热系数}\times\nabla\text{温度})-\text{压力}\times\nabla\cdot\text{速度}+\text{粘性耗散}$ |  |

总能量方程的守恒形式为（式 2-80～2-81，＃L1702-1706）：左端是 $\rho\left(e+V^2/2\right)$ 的时间导数与散度，这也是 §2.10 里向量形式（2-93）所用到的形式。

## 无粘极限

删去热传导与粘性项，得欧拉方程的能量方程（式 2-85～2-86，＃L1830-1834）。此时总能量只随对流输运，右端仅剩体积加热与压力做功。

## 适用边界

- 不含辐射输运、化学反应放热与质量扩散（＃L1726），这些要在 $\dot{q}$ 或方程右端另加源项。
- 需要状态方程 $p=\rho RT$、$e=e(T,p)$ 才能封闭（§2.8.1，＃L1850-1858）。
- 不可压、无温度变化的流动（如第 9 章库埃特流）可不解能量方程，流动与温度解耦（第 9 章，＃L9290 起）。
- 式（2-73）里 $\Phi\ge 0$，粘性耗散永远加热流体，不会降温。

## 判断

CFD 里选总能量还是内能，取决于解什么：可压缩流动用总能量守恒形式（2-81/2-93 的第五个分量），因为激波与压缩功都体现在总能量通量里；低速传热问题可用内能或温度方程（2-26 型），把流动与传热分开解。书里第 7、8 章的超声速算例全部用总能量形式，第 9 章不可压库埃特流则完全不碰能量方程。

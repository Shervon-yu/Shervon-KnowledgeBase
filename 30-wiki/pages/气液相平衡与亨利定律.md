# 气液相平衡与亨利定律

## 平衡与溶解度的定义（`#L8696-#L8702`）

一定温度、总压下气液接触，溶质向液相传递；当液相饱和、进出液相的溶质速率相等时达到平衡。此时：

- 气相中溶质分压 = **平衡分压**（饱和分压）$p_A^{*}$；
- 液相中溶质浓度 = **平衡溶解度**（溶解度）。

平衡关系回答三件事：过程**能否进行、进行的方向、进行的极限**。

## 溶解度的三条规律（`#L8704-#L8732`）

1. **随分压增大、温度降低而增大**（图5-2 SO₂-水）；
2. **不同气体差别极大**：同一温度与分压下 NH₃ > SO₂ > O₂。得到同样浓度溶液，易溶气体所需分压低、难溶气体所需分压高（`#L8714-#L8720`）；
3. **总压的影响要分清口径**（`#L8722-#L8732`）：
   - 若只增加惰性气体量、溶质分压不变 → 溶解度**不变**；
   - 若按原摩尔比同时增加溶质与惰性气体 → 溶质分压增大 → 溶解度增大（摩尔分数 y 不变）；
   - 故用摩尔分数 $y$–$x$ 画溶解度曲线时**必须注明总压**（图5-4：40 ℃ 不同总压）。

## 亨利定律的四种写法（`#L8742-#L8830`）

适用条件：**稀溶液**。易溶气体（NH₃-水）需高温低浓度才适用；难溶气体（O₂、N₂、H₂-水）需总压 <5 MPa、分压 <0.1 MPa。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p_A^{*}=Ex$ | （5-1） |
| **文字式** | $\text{平衡分压}_{\text{【kPa】}}=\text{亨利系数}_{\text{【kPa】}}\times\text{液相溶质摩尔分数}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p_A^{*}=\dfrac{c_A}{H}$ | （5-2） |
| **文字式** | $\text{平衡分压}_{\text{【kPa】}}=\dfrac{\text{液相溶质浓度}_{\text{【kmol/m}^3\text{】}}}{\text{溶解度系数}_{\text{【kmol/(m}^3\cdot\text{kPa)】}}}$ |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $y^{*}=mx$ | （5-3） |
| **文字式** | $\text{气相平衡摩尔分数}=\text{相平衡常数}\times\text{液相溶质摩尔分数}$ |  |

摩尔比形式：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Y^{*}=\dfrac{mX}{1+(1-m)X}$，稀溶液 $Y^{*}=mX$ | （5-6）（5-7） |
| **文字式** | $\text{气相溶质摩尔比}^{*}=\dfrac{\text{相平衡常数}\times\text{液相溶质摩尔比}}{1+(1-\text{相平衡常数})\times\text{液相溶质摩尔比}}$ |  |

其中摩尔比定义 $Y=\frac{y}{1-y}$、$X=\frac{x}{1-x}$（5-4），反算 $x=\frac{X}{1+X}$、$y=\frac{Y}{1+Y}$（5-5）。

## 三个系数的含义与量级（`#L8756-#L8788`）

- **E（亨利系数，kPa）**：E 小 = 溶解度大 = 易溶；E 随温度升高而**增大**。表5-1 给 15 种气体水溶液的 E（0~100 ℃），量级差极大：20 ℃ 时 H₂ 6.92×10⁶ kPa、CO₂ 1.44×10⁵ kPa、SO₂ 3.55×10⁴ kPa（易溶）。
- **H（溶解度系数，kmol/(m³·kPa)）**：可理解为分压 1 kPa 时的平衡液相浓度；H 大 = 溶解度大；H 随温度升高而**减小**。
- **m（相平衡常数，无量纲）**：m 小 = 易溶；m 随温度升高而**增大**。

## 例5-1（`#L8888-#L8904`）

总压 101.325 kPa、20 ℃，1000 kg 水溶 15 kg NH₃，平衡分压 1.2 kPa：

- $x=\frac{15/17}{15/17+1000/18}=0.01563$；
- $E=p_A^{*}/x=1.2/0.01563=76.8$ kPa；
- $H\approx\frac{\rho_s}{EM_s}=\frac{1000}{76.8\times18}=0.723$ kmol/(m³·kPa)；
- $m=E/p=76.8/101.325=0.758$。

## 判断

- 三个系数是同一件事的三种度量：E 用分压-摩尔分数、H 用分压-浓度、m 用摩尔分数比。判断"易溶/难溶"看数值大小：E、m 越小越易溶，H 越大越易溶。
- 亨利定律只对稀溶液成立，而且不同气体的适用压力范围差别很大：难溶气体要压到 5 MPa 以下才可以用，工业上高压吸收（如甲醇洗）必须校核。

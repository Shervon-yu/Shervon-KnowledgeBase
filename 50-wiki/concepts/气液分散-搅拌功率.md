# 气液分散-搅拌功率

> **本页的诚实边界**：三本书里都没有「搅拌功率」的定量关联式——本书只给气液分散状态、临界搅拌速度与两个无量纲数的定义；《化工原理》无搅拌章；《机械密封》无关。凡涉及功率准数 N_p、通气功率 P_g/P_0 的公式，本库无出处，见「开放问题」。

## 定义

气体从釜底多孔圆环分布器以气泡形式上升，被旋转的搅拌桨打碎、被液相剪切分散成更小更多气泡，使气泡充满釜内，达到气液两相分散与混合的目的。§5.2.1 #L2919

固定通气量、逐渐提高转速，出现三种分散状态（图 5.4）：#L2921 #L2940

| 状态 | 现象 | 判据 / 后果 |
|:---|:---|:---|
| 气泛（flooding） | 低转速时部分气泡不经桨叶打碎、从叶轮间隙直通上升；气泡仅在桨上方呈「倒杯状」，多大气泡 | 气体明显未分散好，工业操作「绝对要避免」#L2942 |
| 临界载气 | 转速增至某临界值，桨上方「倒杯状」分散范围扩大到整个釜 | 气泛→临界载气是突变且可重复的过程 |
| 完全分散 | 转速继续升高 | 临界载气→完全分散是渐变，分散效果随转速增加「并没有多大改善」#L2942 |

临界搅拌速度：由实验观测确定（无解析式）；测量前必须先定出该通气量下的临界转速，避免在气泛状态下做 CT。§5.2.2 #L2952

## 计算式（本书只给两个无量纲数定义）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{1}=\dfrac{Q_{\mathrm{G}}}{N D_{\mathrm{i}}^{3}}$ | （5-1） |
| **文字式** | $\text{通气数}_{F_{1}}=\dfrac{\text{通气量}_{Q_{\mathrm{G}}}}{\text{搅拌转速}_{N}\times\text{桨径}_{D_{\mathrm{i}}}^{3}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_{\mathrm{r}}=\dfrac{N^{2}D_{\mathrm{i}}}{g}$ | （5-2） |
| **文字式** | $\text{弗劳德数}_{F_{\mathrm{r}}}=\dfrac{\text{搅拌转速}_{N}^{2}\times\text{桨径}_{D_{\mathrm{i}}}}{\text{重力加速度}_{g}}$ |  |

F₁ 反映纵向通气量与透平叶片离心泵出量之比，F_r 反映离心泵出力与重力之比；图 5.5 的流态区域图即以 F₁、F_r 为坐标（原文献基于气穴结构研究）。#L2944

## 判据 / 数据（表 5.1 实测）

标准 200 mm×240 mm Rushton 釜，圆环分布器 8 孔 ×1.5 mm：#L2887 #L3248

| 通气量 Q_G /(L/min) | 临界搅拌速度 N /(r/min) | F₁ | F_r |
|:---:|:---:|:---:|:---:|
| 9.44 | 350 | 0.09 | 0.23 |
| 18.88 | 470 | 0.14 | 0.42 |
| 28.32 | 530 | 0.18 | 0.53 |

结论：临界搅拌速度随通气量增加而增加。#L2952 #L2569

其他定性判据：#L2942
- 转速过高 → 机械震动 + 功率消耗增加，且分散效果几乎不再改善 → 操作区间取「临界转速 ~ 上限转速（本例 800 r/min）」。
- 影响气液分散的因素：釜形状、气体通入方式、通气量、桨形、搅拌速度、液体黏度。#L2952

## 与「功率」的关系（书中只有一句）

书中涉及功率的定量表述仅一句：「太大的搅拌转速会引起机械震动和功率消耗的增加」（#L2942）。没有 P=N_pρN³D⁵ 之类的功率式，也没有通气/不通气功率比 P_g/P₀ 的关联式——**这是三本书的共同缺口**，已在 [[搅拌功率关联式对比]] 中逐书核对。

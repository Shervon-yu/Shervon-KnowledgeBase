# 筒体内径与高度的计算

## 平底直立容器

|  |  |  |
|:---|:---:|---:|
| **符号式** | $V\phi=\dfrac{\pi}{4}D^{3}\left(\dfrac{H_L}{D}\right)$ | （6-3） |
| **文字式** | $\text{容积}_{\text{【m³】}}\times\text{装料系数}=\dfrac{\pi}{4}\times\left(\text{内径}_{\text{【m】}}\right)^{3}\times\text{装液高径比}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $D=\sqrt{\dfrac{4V\phi}{\pi H_L}}$ | （6-4） |
| **文字式** | $\text{内径}_{\text{【m】}}=\sqrt{\dfrac{4\times\text{容积}_{\text{【m³】}}\times\text{装料系数}}{\pi\times\text{装液高度}_{\text{【m】}}}}$ |  |

算出 D 后**圆整成标准直径**，再算筒高：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $V=\dfrac{\pi}{4}D^{2}H\quad\text{或}\quad H=\dfrac{4V}{\pi D^{2}}$ | （6-5） |
| **文字式** | $\text{容积}_{\text{【m³】}}=\dfrac{\pi}{4}\times\left(\text{内径}_{\text{【m】}}\right)^{2}\times\text{筒体高度}_{\text{【m】}}$ |  |

（`#L5944-#L5954`）

## 带封头容器

封头容积 $V_d$ 在内径未知时也未知，故**先忽略封头**按式（6-4）算出标准直径 D，再用：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=\dfrac{V-V_{d}}{\dfrac{\pi}{4}D_i^{2}}$ | （6-6） |
| **文字式** | $\text{筒体高度}_{\text{【m】}}=\dfrac{\text{容积}_{\text{【m³】}}-\text{封头容积}_{\text{【m³】}}}{\dfrac{\pi}{4}\times\left(\text{筒体内径}_{\text{【m】}}\right)^{2}}$ |  |

$V_d$：立式只算下封头，卧式算左右两封头之和。算出 H 后圆整，再**核算 $H_L/D$ 与容积 V**：只要 V 满足要求、$H_L/D$ 大致落在表6-1 范围即可（`#L5958-#L5964`）。

## 迭代的含义

式（6-6）隐含一次迭代：先按平底估 D → 圆整 → 扣封头容积算 H → 校核。若校核后 $H_L/D$ 明显偏离表6-1，应回调 D 重算，而不是硬改 H——因为 D 已被圆整到标准系列。

## 判断

圆整方向有讲究：D 向上圆整会使容积偏大、$H_L/D$ 偏小；向下圆整则偏紧。工程上优先**向上圆整**，再用 H 微调，避免容积不足返工。

# 守恒型方程与迎风格式

## 守恒形式与通量雅可比（§11.2）

三维守恒方程写成（式 11-1，＃L10667）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial U}{\partial t}+\dfrac{\partial F}{\partial U}\dfrac{\partial U}{\partial x}+\dfrac{\partial G}{\partial U}\dfrac{\partial U}{\partial y}+\dfrac{\partial H}{\partial U}\dfrac{\partial U}{\partial z}=J$ | （11-1） |
| **文字式** | $\dfrac{\partial\text{守恒变量}}{\partial t}+A\dfrac{\partial\text{守恒变量}}{\partial x}+B\dfrac{\partial\text{守恒变量}}{\partial y}+C\dfrac{\partial\text{守恒变量}}{\partial z}=\text{源项}$ |  |

其中 $A=\partial F/\partial U$、$B=\partial G/\partial U$、$C=\partial H/\partial U$ 称通量雅可比矩阵（式 11-2，＃L10671）。对一维 Euler 方程，$U=(\rho,\rho u,\rho E)^T$（11-8）、$F=(\rho u,\rho u^2+p,\rho uE+pu)^T$（11-9），$A$ 可显式写出（式 11-24、11-25，＃L10795-10799）。$A$ 的特征值由 $|A-\lambda I|=0$ 求出（式 11-32，＃L10835）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda_1=u,\quad\lambda_2=u+a,\quad\lambda_3=u-a$ | （11-34 前后） |
| **文字式** | 特征速度 = 流速、流速+声速、流速−声速 |  |

特征值的符号就是信息传播方向：$u+a>0$ 表示声波向下游走，$u-a<0$ 表示向上游走。这是迎风格式的物理依据。

## 守恒型 vs 非守恒型（§11.2 末）

同一流动可写成守恒形式（11-28）或非守恒形式（11-35）。数学上等价，数值上差别很大：只有守恒形式在跨激波时能正确满足 Rankine-Hugoniot 关系，非守恒形式算出的激波位置和强度会错（#L2084 已从第 2 章说明）。所以捕捉激波必须用守恒型方程。

## 迎风格式（§11.4）

标量模型 $\partial u/\partial t+c\,\partial u/\partial x=0$：若 $c>0$，信息从左来，用后向差分（式 11-54、11-55，＃L11101-11105）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{u_i^{n+1}-u_i^{n}}{\Delta t}=-c\dfrac{u_i^{n}-u_{i-1}^{n}}{\Delta x}$ | （11-55） |
| **文字式** | $\dfrac{\text{新值}-\text{旧值}}{\Delta\text{时间}}=-\text{波速}\times\dfrac{\text{本点值}-\text{上游值}}{\Delta x}$ |  |

$c<0$ 则改用前向差分。这叫**迎风**：差分方向跟着特征方向走，而不是像中心差分那样对称取点。

对 Euler 方程，$A$ 有正负特征值，不能简单取一侧。做法是**通量分裂**：把 $A$ 对角化（式 11-56～11-59，＃L11129-11145），

|  |  |  |
|:---|:---:|---:|
| **符号式** | $A=T[\lambda]T^{-1}$，$A^{\pm}=T[\lambda^{\pm}]T^{-1}$，$F=F^{+}+F^{-}$ | （11-59、11-61～11-63） |
| **文字式** | 通量按正、负特征方向拆成两部分，各自用对应侧的差分 |  |

于是 $F^{+}=A^{+}U$（11-64）、$F^{-}=A^{-}U$（11-65），格式为 $\partial U/\partial t+\partial F^{+}/\partial x+\partial F^{-}/\partial x=0$（11-66，＃L11189）。物理上就是把"往下游传的部分"和"往上游传的部分"分开处理。

## 二阶迎风与 TVD（§11.5–§11.6）

一阶迎风只有一阶精度、数值耗散大。用三点单侧差分可得二阶（式 11-67～11-69，＃L11269-11279）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{\partial u}{\partial x}\right)_i=\dfrac{3u_i-4u_{i-1}+u_{i-2}}{2\Delta x}$ | （11-68） |
| **文字式** | 二阶后向差分，用到本点与前两点 |  |

但二阶格式在激波附近会过冲/振荡。**TVD**（Total Variation Diminishing，总变差不增）给出抑制条件（式 11-71～11-73，＃L11303-11311）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mathrm{TV}(u)=\sum_i|u_{i+1}-u_i|$，$\mathrm{TV}(u^{n+1})\le\mathrm{TV}(u^{n})$ | （11-72、11-73） |
| **文字式** | 总变差=相邻点差的绝对值之和；推进后总变差不得增大 |  |

满足 TVD 的格式不会产生新的极值，因而不会在激波两侧振荡。实现办法是**通量限制器**：在光滑区用二阶通量，在激波附近把限制器压到一阶（如 minmod、Van Leer 限制器），从而既保精度又保单调。

## 多重网格与小结（§11.8–11.9）

- 多重网格：在粗网格上消除低频误差、细网格上消除高频误差，收敛速度与网格数几乎无关；是加速迭代的常用手段（＃L11383）。
- 第 11 章的主线：守恒形式 → 特征分解 → 迎风/通量分裂 → 高阶 + 限制器（TVD）。这条线是 1980 年代以后 CFD 格式发展的主干。

## 适用边界

- 迎风格式依赖特征方向，必须先知道方程的类型与特征值；对椭圆型方程没有"迎风"可言。
- 通量分裂（Steger-Warming 类）在声速点附近会出现特征值变号，需要熵修正，否则产生膨胀激波（书里未展开）。
- TVD 限制器会把极值削平，定常解在光滑极值处精度降到一阶；ENO/WENO 是后来的改进方向。
- 一阶迎风虽然稳定，但数值耗散大，网格粗时会把激波抹得很宽。

## 判断

守恒型 + 迎风 + TVD 三件事是一套：守恒保证激波关系正确，迎风保证信息方向正确，TVD 保证不振荡。缺少任何一条，激波捕捉都会出问题——非守恒格式激波位置错，中心差分在激波处振荡，无限制器的高阶格式过冲。

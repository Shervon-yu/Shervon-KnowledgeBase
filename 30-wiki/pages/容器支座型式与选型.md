# 容器支座型式与选型

## 定义

容器支座是焊接在容器上、把容器重量传给基础的支承元件。NB/T 47065.1~.5—2018 按结构型式分为五种：鞍式、腿式、耳式、支承式、刚性环，分别对应五个分册（《NBT 47065.1～47065.5-2018 容器支座》§1.3 等，#L190）。

## 五种型式的特征与适用范围

| 型式 | 系列/型号 | 结构要点 | 适用公称直径 DN/mm | 典型用途 |
| :--- | :--- | :--- | :--- | :--- |
| 鞍式 | 轻型 A；重型 BI~BV（焊制/弯制、120°/150° 包角、有/无垫板） | 双支点支承；分固定式 F 与滑动式 S | 168~6 000 | 卧式容器（#L192-#L196） |
| 腿式 | 角钢支柱 AN/A、钢管支柱 BN/B、H 型钢支柱 CN/C，支座号 1~6 | 带/不带垫板两种 | 300~2 000 | 立式小中型容器（#L1522-#L1535） |
| 耳式 | 短臂 A、长臂 B（支座号 1~8）、加长臂 C（1~8，带盖板） | 筋板+底板焊接耳座 | 300~4 000 | 立式容器（#L2426-#L2437） |
| 支承式 | 钢板焊制 A（1~6）、钢管制作 B（1~8） | 筋板/钢管+底板；B 型高度可调 | 800~4 000 | 立式容器（#L6834-#L6842） |
| 刚性环 | A 型（轻型）、B 型（重型） | 顶环+底环+筋板+底板；支耳带螺栓孔 | 按表 1~表 4 | 高耸立式设备，含抗震（#L7662-#L7704） |

## 判据与计算

### 2.1 鞍式支座的选用判据（§8.1，#L789-#L795）

- 按实际承载大小确定轻型或重型；
- 按容器圆筒强度需要确定 120° 或 150° 包角；
- 换热器优先选用 120° 或 150° 包角的重型鞍式支座。

### 2.2 鞍式支座必须设置垫板的条件（§8.3，#L803-#L813）

公称直径 DN ≤ 900 mm 的容器分带/不带垫板两种；符合下列条件之一时必须设置垫板：

1. 容器圆筒有效厚度 ≤ 3 mm；
2. 圆筒鞍座处周向应力大于规定值；
3. 圆筒有热处理要求；
4. 圆筒与鞍座间温差 > 200 ℃；
5. 圆筒材料与支座材料不具有相同或相近化学成分和性能指标。

另外：容器基础为钢筋混凝土时，滑动鞍座底板下必须装基础垫板（§8.5，#L821-#L823）。

### 2.3 腿式支座直接选用的五条件（§9.1，#L1817-#L1829）

全部满足才能直接按标准选支腿，否则按附录 A 计算（§9.2，#L1831-#L1832）：

1. 设计温度 > -20 ℃ 且 ≤ 200 ℃；
2. 设计基本风压 ≤ 800 Pa；
3. 地面粗糙度 A 类；
4. 抗震设防烈度 8 度、场地土 Ⅱ 类、设计基本地震加速度 0.2g、地震分组第三组；
5. 单根支腿允许最大重力载荷在表 2~表 4 范围内。

宜带垫板的情况（§9.3，#L1833-#L1839）：合金钢制容器；有焊后热处理要求；连接处圆筒有效厚度 δe 小于表 8 的最小厚度 δmin。

### 2.4 刚性环支座的选用判据（§5.2，#L7692-#L7704）

同时满足以下两条时，可按公称直径 DN 从表 1、表 2 选支座号：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W \lt [W]$ 且 $M_{0} \lt [M_{0}]$ | （2-1） |
| **文字式** | $\text{设计竖向载荷}<\text{许用竖向载荷}$，且 $\text{外力矩}<\text{许用力矩}$ |  |

结构要求（§4，#L7662-#L7684）：DN ≤ 800 mm 支耳 2~3 个；DN > 800 mm 不少于 4 个且宜为偶数；筒体有效厚度 ≤ 8 mm、材料不匹配、需热处理三种情况应设垫板。

### 2.5 支承式支座高度调整（§4.2，#L6846-#L6848）

B 型支承式支座高度可以改变，但不应大于支座高度上限值 hmax。

## 适用范围与边界

- 鞍式支座适用于双支点支承的钢制卧式容器，设计温度 -40~200 ℃（§1.2/§1.3，#L176-#L180）；多支点卧式容器可参照使用。
- 腿式支座直接选表法受 2.3 节五条件限制，超出必须按附录 A 计算。
- 刚性环支座选表法只保证 W 与 M0 两个载荷条件，其余设计（焊缝、热膨胀长圆孔等）见《刚性环支座的载荷与地震作用》页。
- 各型式的系列参数表、材料、标记、制造要求为查表/文书内容，不在此页展开，原文见各分册第 4~7 章。

# 混合时间与混合准数

## 定义

混合时间 $\theta_{\mathrm{M}}$：把两种完全互溶、但物理或化学性质（电导率、颜色、温度、折光率等）有差异的流体，通过搅拌达到**规定混匀标准**所需的时间（`#L1456`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\theta\mathrm{M}}=\theta_{\mathrm{M}}N$ | （2-24） |
| **文字式** | $\text{混合准数}=\text{混合时间}_{\text{【s】}}\times\text{搅拌转速}_{\text{【1/s】}}$ |  |

$N_{\theta\mathrm{M}}$ 的物理意义是达到规定混匀标准所需的**搅拌转数**，它是搅拌器几何形状的函数（`#L1460`）。

## 为什么能当常数

- 对特定搅拌器，$N_{\theta\mathrm{M}}$ 为常数；不同搅拌器数值不同；层流区与湍流区的数值也不同（`#L1460`）。
- 性能优良的搅拌器，其 $N_{\theta\mathrm{M}}$ 在层流区与湍流区**量级大致相同**（`#L1460`）——这就是工程上敢把它当常数的原因。
- 剪切变稀的假塑性流体，其假塑性与黏度对 $N_{\theta\mathrm{M}}$ 均无影响（`#L1754`），只有弹性会拉长混合时间（见 [[黏弹性流体搅拌]]）。

## 测量与比较的口径

- 必须给出混匀标准（如浓度偏差 ≤1%），否则 $\theta_M$ 无比较意义；图表中的数值只在相同测试条件下可比（`#L1462`）。
- 测量方法：湍流混合常用电导法、温差法，详见第三章第五节（`#L1462`）。
- 用 $N_{\theta\mathrm{M}}$ 横向比较时，要先确认两者几何相似、混匀标准一致。

## 与其他指标的关系

混合时间只回答"多久混匀"，不回答"花多少能量"；两者合起来才构成混合效率，见 [[混合效率指标]]。

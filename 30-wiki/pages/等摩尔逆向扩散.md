# 等摩尔逆向扩散

## 物理图像（`#L9048-#L9066`）

两容器同温同压、装不同浓度的 A-B 混合气，细管连通。A 向右扩散、B 向左扩散。因总压处处相等，A 向右的物质量必等于 B 向左的物质量——**等摩尔逆向扩散**（equimolar counter diffusion）。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $J_A=-J_B$ | （5-13） |
| **文字式** | $\text{A的扩散速率}=-\text{B的扩散速率}$ |  |

## 关键推论（`#L9084-#L9096`）

总压恒定：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $p=p_A+p_B=\text{常数}$，$\dfrac{\mathrm{d}p_A}{\mathrm{d}Z}=-\dfrac{\mathrm{d}p_B}{\mathrm{d}Z}$ | （5-15） |
| **文字式** | $\text{总压}=\text{A分压}+\text{B分压}=\text{常数}$，$\text{A分压梯度}=-\text{B分压梯度}$ |  |

代入 $J_A$、$J_B$ 两式并利用 $J_A=-J_B$，得 $D_{AB}=D_{BA}=D$：双组分等摩尔扩散时，A 在 B 中与 B 在 A 中的扩散系数**相等**。

## 传质速率方程（`#L9098-#L9108`）

此时 $N_A=J_A$，稳态积分（$Z_1=0$、$Z_2=Z$，两端分压 $p_{A1}$、$p_{A2}$）：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=\dfrac{D}{RTZ}(p_{A1}-p_{A2})=\dfrac{D}{Z}(c_{A1}-c_{A2})$ | （5-16b） |
| **文字式** | $\text{传质速率}=\dfrac{\text{扩散系数}}{\text{气体常数}\times\text{温度}\times\text{扩散距离}}\times\text{两端分压差}=\dfrac{\text{扩散系数}}{\text{距离}}\times\text{两端浓度差}$ |  |

要点：
- 分压（浓度）沿距离**线性分布**，梯度为常数；
- 没有漂流因子——因为没有净整体流动，A 向右的量正好由 B 向左补上。

## 当它出现在工业里（`#L9108`）

典型是**蒸馏**：易挥发组分 A 与难挥发组分 B 的摩尔汽化热近似相等时，冷凝 1 mol B 放出的热正好汽化 1 mol A，两组分等量逆向扩散，可按等摩尔逆向扩散处理。

## 判断

- 判断能不能用 5-16：看**是否有净整体流动**。若一侧组分被液体吸收（吸收、解吸），净流动存在，必须用单向扩散式；若两组分互为"镜像"（汽化-冷凝、精馏段），才可用 5-16b。
- 蒸馏中"摩尔汽化热相等"这个前提常不严格成立，工程上按近似处理，误差随两组分汽化热差增大而增大。

# 转筒真空过滤机

## 构造（`#L5473-#L5477`）

- 转筒转速约 0.1~3 r/min，表面金属网+滤布，下部浸入滤浆槽；
- 沿周边用隔板分成 **12 个小过滤室**，每室经细管通到端面转动盘上的一个孔；
- 转动盘与固定盘由弹簧压紧密封，固定盘上有 **3 个长短不等的圆弧凹槽**，分别接滤液排出管（真空）、洗水排出管（真空）、空气吹进管；
- 转筒旋转时，12 个小室依次与 3 个凹槽接通 → 每室依次经历过滤、洗涤、吸干、吹松卸渣；整个圆周同时被划分为**过滤区、洗涤区、吸干区、吹松卸渣区**；
- 凹槽之间留有间隔，防止两区串通。转动盘+固定盘合称**分配头**。

## 性能（`#L5487`）

能自动连续操作，适合处理量大、固体颗粒含量较多的滤浆；但真空操作推动力最高只有 0.1 MPa，对滤饼阻力大的物料适应差。

## 生产能力（`#L5491-#L5525`）

浸液率：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\psi=\dfrac{\text{转筒浸液面积}}{\text{转筒总表面积}}=\dfrac{\text{浸液角度}}{360^\circ}$ | （3-43） |
| **文字式** | $\text{浸液率}=\dfrac{\text{转筒浸液面积}}{\text{转筒总表面积}}=\dfrac{\text{浸液角度}_{\text{【°】}}}{360^\circ}$ |  |

转筒转速 $N$（1/s）时，旋转一周时间 $1/N$，有效过滤时间与单位面积滤液量：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\tau=\dfrac{\psi}{N},\quad q=\dfrac{Q}{AN}$ | （3-44）（3-45） |
| **文字式** | $\text{有效过滤时间}_{\text{【s】}}=\dfrac{\text{浸液率}}{\text{转速}_{\text{【1/s】}}},\quad \text{单位面积滤液量}=\dfrac{\text{生产能力}_{\text{【m³/s】}}}{\text{过滤面积}\times\text{转速}}$ |  |

代入恒压过滤方程式得

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\left(\dfrac{Q}{AN}\right)^2+2q_e\dfrac{Q}{AN}=K\dfrac{\psi}{N}$ | （3-46） |
| **文字式** | $\left(\dfrac{\text{生产能力}}{\text{面积}\times\text{转速}}\right)^2+2\times\text{单位面积当量滤液量}\times\dfrac{\text{生产能力}}{\text{面积}\times\text{转速}}=\text{过滤常数}\times\dfrac{\text{浸液率}}{\text{转速}}$ |  |

改写成 $Q/(AN)$ 对 $A\psi/Q$ 的线性式（3-47）可测 $K$ 与 $q_e$；解出生产能力：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=AN\left(\sqrt{q_e^2+\dfrac{K\psi}{N}}-q_e\right)$ | （3-48） |
| **文字式** | $\text{生产能力}={\text{过滤面积}\times\text{转速}}\times\left(\sqrt{\text{单位面积当量滤液量}^2+\dfrac{\text{过滤常数}\times\text{浸液率}}{\text{转速}}}-\text{单位面积当量滤液量}\right)$ |  |

忽略介质阻力时简化为

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=A\sqrt{K\psi N}$ | （3-49） |
| **文字式** | $\text{生产能力}=\text{过滤面积}\times\sqrt{\text{过滤常数}\times\text{浸液率}\times\text{转速}}$ |  |

## 判断

- 式(3-49)说明：提高转速与提高浸液率都能增大产能，但转速升高使每转的有效过滤时间变短、滤饼更薄，故两者对 $Q$ 的贡献都是平方根关系，实际存在最佳转速。
- 真空过滤机的 0.1 MPa 上限是物理上限（大气压），这也是它无法替代板框压滤机的根本原因——不是结构问题，而是压差天花板。

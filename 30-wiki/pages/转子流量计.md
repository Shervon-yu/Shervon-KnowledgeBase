# 转子流量计

## 结构与原理（`#L2895-#L2903`）

一根上粗下细的锥形玻璃管 + 内置转子（浮子）。流体自下而上流过，转子被托起到某一高度：位置越高、环隙越大、流量越大。**读数即转子的高度**。

## 恒压差（`#L2905-#L2911`）

转子稳定时，重力、浮力与流体作用力平衡，两侧压差恒定：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p A_f=V_f(\rho_f-\rho)g$ | （1-76） |
| **文字式** | $\text{转子两侧压差}_{\text{【Pa】}}\times\text{转子最大截面积}_{\text{【m²】}}=\text{转子体积}_{\text{【m³】}}\times(\text{转子密度}-\text{流体密度})\times\text{重力加速度}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=\dfrac{V_f(\rho_f-\rho)g}{A_f}$ | （1-77） |
| **文字式** | $\text{转子两侧压差}_{\text{【Pa】}}=\dfrac{\text{转子体积}\times(\text{转子密度}-\text{流体密度})\times\text{重力加速度}}{\text{转子最大截面积}}$ |  |

**关键**：压差只由转子与流体物性决定，与流量无关 → 称**恒压差流量计**（孔板是恒截面、变压差）。流量变化靠环隙面积 $A_R$ 变。

## 流量式（`#L2925-#L2931`）

按孔口流量形式写出：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_V=C_RA_R\sqrt{\dfrac{2gV_f(\rho_f-\rho)}{A_f\rho}}$ | （1-78） |
| **文字式** | $\text{体积流量}_{\text{【m³/s】}}=\text{流量系数}\times\text{环隙面积}_{\text{【m²】}}\times\sqrt{\dfrac{2\times\text{重力加速度}\times\text{转子体积}\times(\text{转子密度}-\text{流体密度})}{\text{转子最大截面积}\times\text{流体密度}}}$ |  |

对一定转子与流体，根号内为常数；若 $C_R$ 也为常数，则 $q_V\propto A_R$——所以刻度可均匀。

## 刻度与校正（`#L2933-#L2943`）

出厂刻度：液体用 20 ℃ 水、气体用 20 ℃、101.3 kPa 空气标定。测其他流体须校正（设 $C_R$ 相同）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{q_{V2}}{q_{V1}}=\sqrt{\dfrac{\rho_1(\rho_f-\rho_2)}{\rho_2(\rho_f-\rho_1)}}$ | （1-79） |
| **文字式** | $\dfrac{\text{实际流量}}{\text{刻度流量}}=\sqrt{\dfrac{\text{标定流体密度}\times(\text{转子密度}-\text{实际流体密度})}{\text{实际流体密度}\times(\text{转子密度}-\text{标定流体密度})}}$ |  |

气体时 $\rho_f\gg\rho$，简化为：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{q_{V2}}{q_{V1}}=\sqrt{\dfrac{\rho_1}{\rho_2}}$ | （1-80） |
| **文字式** | $\dfrac{\text{实际流量}}{\text{刻度流量}}=\sqrt{\dfrac{\text{标定气体密度}}{\text{实际气体密度}}}$ |  |

**方向要记牢**：气体密度变小（如温度升高、压力降低）时读数偏小，实际流量大于刻度值。

## 湿式气体流量计（`#L2945-#L2952`）

鼓轮式容积式计量：气体进入鼓轮内腔、推动鼓轮转动，转数经齿轮传动由指针或计数器显示，按排出的固定容积累计总量。用于低压气体的精确计量。

## 优缺点（`#L2943`）

- 优点：读数方便、阻力小、精度较高、适用流体广（含腐蚀性）、不易故障；
- 缺点：玻璃管不耐高温高压、易碎。

## 判断

- 恒压差是转子流量计与孔板最本质的区别：孔板压差随流量变、转子压差恒定，因此前者读数需开方、后者刻度近似线性。
- 校正公式只在 $C_R$ 不变时成立；黏度差异大的液体（如高黏油品）实标最稳。

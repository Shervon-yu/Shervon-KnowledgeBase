# 冷却蛇管的传热系数

## 为什么要另立一套式子

蛇管（coil）不是器壁：流体绕过管束，几何上多出圈径 $D_{c}$、管外径 $d_{co}$、管间距 $d_{g}$、叶轮与圈束的相对位置。文献里 $Re$ 的指数有三个推荐值——**0.67**（Oldshue、Jha、Skelland）、**0.62**（Chilton、Cummings、Kraussold）、**0.50**（Murakami），长期没有统一口径（`#L2802`）。

关键判据是**叶轮在蛇管圈内还是圈外**，而非有没有挡板（`#L2826`、`#L2864`）：

| 叶轮位置 | 有无挡板 | $Re$ 指数 | 依据 |
|:---|:---|:---:|:---|
| 圈内（C/H=1/2 及以上，叶轮在圈束底部边缘以上） | 无 | **0.56** | 实验（图2.5） |
| 圈内 | 有 | **0.56** | 实验（§2.2.2） |
| 圈下（C/H=1/8，叶轮在圈束下方） | 无 | **0.62** | 实验（图2.5） |
| 跨在圈束上下 | — | 0.60（取两式中间值） | `#L2850` |

## 无挡板：叶轮在圈内（2.9）

$Re>100$、$2<Pr<2000$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Nu_{c}=0.825\,Re^{0.56}Pr^{1/3}Vis^{0.14}\left(\dfrac{d}{D}\right)^{-0.25}\left(\dfrac{ib}{D}\right)^{0.15}\left(n_{p}\right)^{0.15}\left(\dfrac{d_{co}}{D}\right)^{-0.3}$ | （2.9） |
| **文字式** | $\text{蛇管侧努塞尔数}=0.825\times\text{搅拌雷诺数}^{0.56}\times\text{普朗特数}^{1/3}\times\text{黏度比}^{0.14}\times\left(\dfrac{\text{桨径}}{\text{釜径}}\right)^{-0.25}\times\left(\dfrac{\text{桨数}\times\text{叶宽}}{\text{釜径}}\right)^{0.15}\times\text{叶片数}^{0.15}\times\left(\dfrac{\text{管外径}}{\text{釜径}}\right)^{-0.3}$ |  |

$(C/H)$ 与 $(\sin\theta)$ 的指数都是 **0**：叶轮在圈束内时，离底高度与倾角对蛇管传热没有可测影响（`#L2832`）。圈径 $D_{c}$ 在表2.4 范围内变化时 $h_{c}$ 也**看不出差别**（`#L2846`）。

## 无挡板：叶轮在圈下（2.10）

$Re>100$、$2<Pr<2000$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Nu_{c}=1.05\,Re^{0.62}Pr^{1/3}Vis^{0.14}\left(\dfrac{d}{D}\right)^{-0.25}\left(\dfrac{ib}{D}\right)^{0.15}\left(n_{p}\right)^{0.15}\left(\dfrac{D_{c}}{D}\right)$ | （2.10） |
| **文字式** | $\text{蛇管侧努塞尔数}=1.05\times\text{搅拌雷诺数}^{0.62}\times\text{普朗特数}^{1/3}\times\text{黏度比}^{0.14}\times\left(\dfrac{\text{桨径}}{\text{釜径}}\right)^{-0.25}\times\left(\dfrac{\text{桨数}\times\text{叶宽}}{\text{釜径}}\right)^{0.15}\times\text{叶片数}^{0.15}\times\left(\dfrac{\text{圈径}}{\text{釜径}}\right)$ |  |

叶轮在圈下时 **$h_{c}$ 与圈径成正比**（指数 +1，`#L2838`、`#L2846`）——圈越大，吐出流扫过的管排越多。

## 有挡板（2.11）

四块挡板、$B_{w}=D/10$，不论叶轮在圈内圈外，指数恒为 0.56：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Nu_{c}=2.68\,Re^{0.56}Pr^{1/3}Vis^{0.14}\left(\dfrac{d}{D}\right)^{-0.3}\left(\dfrac{ib}{D}\right)^{0.3}\left(n_{p}\right)^{0.2}\left(\dfrac{\Sigma C_{i}}{iH}\right)^{0.15}\left(\sin\theta\right)^{0.5}\left(\dfrac{H}{D}\right)^{-0.5}$ | （2.11） |
| **文字式** | $\text{蛇管侧努塞尔数}=2.68\times\text{搅拌雷诺数}^{0.56}\times\text{普朗特数}^{1/3}\times\text{黏度比}^{0.14}\times\left(\dfrac{\text{桨径}}{\text{釜径}}\right)^{-0.3}\times\left(\dfrac{\text{桨数}\times\text{叶宽}}{\text{釜径}}\right)^{0.3}\times\text{叶片数}^{0.2}\times\left(\dfrac{\text{各桨离底高之和}}{\text{桨数}\times\text{液面高}}\right)^{0.15}\times\left(\sin\text{倾角}\right)^{0.5}\times\left(\dfrac{\text{液面高}}{\text{釜径}}\right)^{-0.5}$ |  |

**与夹套的最大差别**：有挡板时 $h_{c}$ 与无挡板时"大小差不多"，叶轮在圈内时两者相同（`#L2885`、`#L2889`）。夹套传热里挡板能提高 25%~35%（见 [[搅拌侧传热膜系数关联式]]），蛇管侧**不提高**——因为挡板贴壁，不改变管束区的绕流。

## 多层、多桨的换算

- 两叶轮都在圈内：当成一片叶轮、叶宽取两桨之和，直接代式(2.9)（`#L2850`）。
- 叶轮在圈下：$h_{c}$ 落在式(2.9) 与式(2.10) 之间，$Re$ 指数取 0.60。

## 别人给的式子（表2.5）

| 作者 | 主要形式 | $Re$ 范围 | 备注 |
|:---|:---|:---|:---|
| Chilton 等、Pratt | $0.87Re^{0.22}$；$34Re^{0.5}(d_{8}/L_{c})^{0.8}(b/D_{c})^{0.25}(dD/d_{co})^{0.1}$ | $3\times10^{2}\sim4\times10^{5}$ | 叶轮在圈下 |
| Cummings-West、Kraussold、Oldshue-Gretton | $1.01Re^{0.62}Pr^{1/3}Vis^{0.14}$ | $3\times10^{4}\sim7\times10^{5}$ | 叶轮在圈内 |
| Oldshue、Jha-Rao | $0.17Re^{0.67}Pr^{0.37}(d/D)^{0.1}(d_{co}/D)^{0.5}$；$0.18Re^{0.67}Pr^{0.33}(d_{co}/D)^{-0.48}(d/D)^{-0.27}$ | $4\times10^{2}\sim10^{6}$ | 有挡板 |
| Murakami | $23Re^{0.5}Pr^{0.3}(b\sin\theta/L_{c})^{0.15}(n_{p})^{0.16}(d_{co}/D_{c})^{1.7}$ | $10^{2}\sim3\times10^{5}$ | 叶轮在圈外；$b\sin\theta/L_{c}$ 超过 0.315 时截断 |

（`#L2868`、`#L2879`）把 $Pr$ 指数统一取 1/3 重标后，Oldshue 数据斜率 0.58、Pratt/Murakami 0.56，都靠近 0.56——**指数分歧主要来自 $Pr$ 指数取法不同，以及叶轮在圈内还是圈外**。

## 例2.1（`#L2891`）

$D=H=1$ m、$d=0.4$ m、$b=0.067$ m、$i=2$、$C_{1}/H=2/3$、$C_{2}/H=1/3$、$n_{p}=6$、$d_{co}=0.0334$ m、$D_{c}=0.8$ m；水与机油在 50 ℃ 冷却，管壁恒 37 ℃，60 r/min。

| 介质 | Cummings 式（$1.01Re^{0.62}$） | 永田式(2.10) | 差别 |
|:---|:---:|:---:|:---|
| 水 | 1960 | 1978 | +0.9% |
| 机油 | 118 | 119.2 | +1.0% |

单位 kcal/(m²·h·℃)。例中把叶轮高度处的蛇管拆除（$d'_{g}>d_{g}$），故只能用叶轮在圈下的式(2.10)；两式给出几乎相同的数值，说明 $Re$ 指数 0.56/0.62 的差别在实验范围内不显著（`#L2941`、`#L2963`）。

## 判断

工程上先用"叶轮在圈内/圈外"定 $Re$ 指数，再选式——这一步错了，$Re=10^{4}$ 时系数就差 3 倍以上。其次注意：**蛇管传热不靠挡板**，想提高 $h_{c}$ 只有加大圈径（叶轮在圈下时）或加多层桨。

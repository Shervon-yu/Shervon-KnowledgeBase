# 管内流动-摩擦阻力与摩擦系数

## 定义

- **直管摩擦阻力损失**：流体在一定直径直管中流动产生的摩擦损失（#L2145）。
- **局部摩擦阻力损失**：流经管件、阀门、设备进出口时产生的损失（#L2147）。
- **总摩擦阻力损失** = 直管 + 局部（#L2149）。

本书把 $h_{\mathrm f}$ 定义为每千克流体的能量损失（J/kg），对应伯努利方程中的 $\Sigma h_{\mathrm f}$；写成压头形式时记为 $H_{\mathrm f}=\Sigma h_{\mathrm f}/g$，单位 m（#L2149、#L3909）。

## 判据 / 计算

水平等直径管，测两截面静压能即可得摩擦损失：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{\mathrm f}=\dfrac{\Delta p}{\rho}$ | （2-1） |
| **文字式** | $\text{摩擦阻力损失}_{\text{【J/kg】}}=\dfrac{\text{压力差}_{\text{【Pa】}}}{\text{密度}_{\text{【kg/m³】}}}$ |  |

通用式（层流、湍流都适用，只是 $\lambda$ 算法不同）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h_{\mathrm f}=\lambda\dfrac{l}{d}\cdot\dfrac{u^{2}}{2}$ | （2-2） |
| **文字式** | $\text{摩擦阻力损失}_{\text{【J/kg】}}=\text{摩擦系数}\times\dfrac{\text{管长}_{\text{【m】}}}{\text{内径}_{\text{【m】}}}\times\dfrac{\left(\text{流速}_{\text{【m/s】}}\right)^{2}}{2}$ |  |

层流区摩擦系数（哈根-泊谡叶式导出，实验证明与实际完全符合）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\dfrac{64}{Re}$ | （2-3） |
| **文字式** | $\text{摩擦系数}=\dfrac{64}{\text{雷诺数}}$ |  |

原书编号：式(1-43)、(1-44)、(1-45)，见 #L2164、#L2188、#L2194、#L2197。

湍流区（#L2253-#L2261）：管壁凸出部分的平均高度称**绝对粗糙度** $\varepsilon$，$\varepsilon/d$ 称**相对粗糙度**；$\lambda$ 由 $Re$ 与 $\varepsilon/d$ 共同决定，原书以表 1-1（工业管绝对粗糙度）配合曲线/经验式给出，未在本节写出单一解析式。

## 适用范围与边界

- 式(2-1) 只对**水平等直径**管路成立；垂直管测得的压差含位能项，不能直接当 $\Delta p/\rho$（#L2171-#L2173）。
- 式(2-2) 对层流与湍流都成立，但层流用 $\lambda=64/Re$，湍流必须用 $\varepsilon/d$ 关系（#L2199）。
- $h_{\mathrm f}$ 不含局部阻力；局部阻力用 $\zeta u^2/2$ 或当量长度 $l_{\mathrm e}$ 另算（见 [[管路阻力-局部阻力与当量长度]]）。
- 层流判据 $Re<2000$、湍流 $Re>4000$、2000~4000 为过渡区（#L1860-#L1872）。

# 回转型混合设备的基本性能参数

## 一、最佳转速（`#L15603-#L15659`）

不同转速下，随机完全混合时的标准偏差 $\sigma$ 不同；$\sigma$ 最小时的转速称**最佳转速**。确定方法有三种：弗劳德数 Fr、临界转速、经验公式；通常以前两种为主。

### 1. 按弗劳德数确定（式13-1）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Fr=\dfrac{R_{max}\omega^{2}}{g}=\dfrac{\pi^{2}n^{2}R_{max}}{900g}$ | （13-1） |
| **文字式** | $\text{弗劳德数}=\dfrac{\text{最大旋转半径}_{\text{【m】}}\times\text{角速度}^{2}_{\text{【1/s】}}}{9.81}=\dfrac{\pi^{2}\times\text{转速}^{2}_{\text{【r/min】}}\times\text{最大旋转半径}_{\text{【m】}}}{900\times9.81}$ |  |

实验值（装料系数 0.3 时，`#L15621-#L15631`）：

| 型式 | 最佳 Fr |
|:---|:---|
| V 型 | 0.3~0.4 |
| 双重圆锥型 | 0.55~0.65 |
| 滚筒型 | 0.7~0.8 |
| 正立方体型 | 0.5 |

### 2. 按临界转速确定（式13-2）

料筒慢速回转，物料沿内壁上升至一定高度后落下实现混合。转速过高时，粉粒体受离心力贴壁不下落，出现该现象的最低转速称**临界转速**，此时重力与离心力平衡。

|  |  |  |
|:---|:---:|---|
| **符号式** | $n_{cr}=\dfrac{1}{2\pi}\sqrt{\dfrac{g}{R_{max}}}$ | （13-2） |
| **文字式** | $\text{临界转速}_{\text{【r/s】}}=\dfrac{1}{2\pi}\sqrt{\dfrac{9.81}{\text{最大回转半径}_{\text{【m】}}}}$ |  |

必须把转速控制在临界转速**以下**；具体低到多少因型式而异，见各节。V 型、双锥的实际操作转速一般为临界转速的 **50%~80%**。

### 3. 最佳转速经验公式（式13-3）

均一粒径时：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $n_{opt}=\dfrac{C}{D^{0.47}X^{0.14}}$ | （13-3） |
| **文字式** | $\text{最适宜转速}_{\text{【r/min】}}=\dfrac{\text{常数}}{\text{回转容器直径}^{0.47}_{\text{【m】}}\times\text{装料系数}^{0.14}_{\text{【\%】}}}$ |  |

$C\approx54\sim70$，依物性而定。注意 $X$ 用**百分数**（体积%）代入，与式13-1 的装料系数 0.3 是两种口径。

## 二、装料系数（`#L15661-#L15673`）

装料系数 = 装入物料容积 / 回转容器实际容积；与混合速度系数 $\phi$ 的关系见图13-1：

- <30% 时，$\phi$ 随装料系数增加**缓慢上升**（径向混合程度递增）；
- >30% 时，曲线**较快下降**；
- **30% 左右混合最快**。

理由：装料系数太小产量低、设备利用率低；太大则受物料流动分布空间限制，料流置换与对流区域减小、不利有效混合，且需更长混合时间。

各型最佳值：V 型 24%~35%、双锥 30%~40%（见各自页面）。

## 三、功率近似计算（式13-4，`#L15675-#L15687`）

重力式混合设备消耗功率 $P$ 与有效容积 $V_e$、Fr 成**线性关系**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=(0.015\sim0.02)\,V_{e}\,Fr$ | （13-4） |
| **文字式** | $\text{功率}_{\text{【kW】}}=(0.015\sim0.02)\times\text{有效容积}_{\text{【L】}}\times\text{弗劳德数}$ |  |

## 使用注意

- 式13-4 是**重力式**（回转型）专用，含系数 0.015~0.02 已把效率与单位换算吸收进去；产出 kW、容积用 L，不要混用 m³。
- 式13-1 用 r/min、式13-2 用 r/s，两式口径不同，是本页最容易算错的地方。
- 更大设备的具体轴力矩与指数法见 [[固体混合设备的功率计算]]。

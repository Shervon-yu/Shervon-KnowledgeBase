# 持气率与气泡直径

## 为什么看这两个量

持气率与气泡大小决定体系的**相界面积**，而界面积是传质的基础（`#L2233`）。传质系数本身另有关联式，但界面积不够时其他都无从谈起。

## 气泡平均直径

气泡大小不一，常用体表面积平均直径 $d_B$ 表示；空气-水系统 $d_B$ 通常 2~5 mm（`#L2235`）。设 $n$ 种尺寸（`#L2237`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{B}=\dfrac{\sum n_{Bi}d_{i}^{3}}{\sum n_{Bi}d_{i}^{2}}$ | （2-85） |
| **文字式** | $\text{气泡平均直径}_{\text{【m】}}=\dfrac{\sum\text{第}i\text{种气泡数}\times\left(\text{第}i\text{种直径}_{\text{【m】}}\right)^{3}}{\sum\text{第}i\text{种气泡数}\times\left(\text{第}i\text{种直径}_{\text{【m】}}\right)^{2}}$ |  |

## 比界面积

|  |  |  |
|:---|:---:|---:|
| **符号式** | $a=\dfrac{6\Phi}{d_{B}}$ | （2-86） |
| **文字式** | $\text{比界面积}_{\text{【1/m】}}=\dfrac{6\times\text{持气率}}{\text{气泡平均直径}_{\text{【m】}}}$ |  |

## $d_B$ 的三个体系式

气体-纯液体（`#L2249`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{B}=4.15\left[\dfrac{\sigma^{0.6}}{\left(\dfrac{P_{G}}{V_{L}}\right)^{0.4}\rho_{c}^{0.2}}\right]\Phi^{0.5}+9\times10^{-4}$ | （2-87） |
| **文字式** | $\text{气泡直径}_{\text{【m】}}=4.15\times\left[\dfrac{\text{表面张力}_{\text{【N/m】}}^{0.6}}{\left(\dfrac{\text{通气功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.4}\times\text{连续相密度}_{\text{【kg/m³】}}^{0.2}}\right]\times\text{持气率}^{0.5}+9\times10^{-4}$ |  |

气体-电解质溶液（`#L2255`，式2-88）：同结构，$\Phi$ 的指数为 0.4，再乘 $\left(\mu_d/\mu_c\right)^{0.25}$；系数 2.25。
气体-醇溶液（`#L2259`，式2-89）：$\Phi$ 的指数 0.65，再乘 $\left(\mu_d/\mu_c\right)^{0.25}$；系数 1.90。

三者说明：**持气率越高、气泡越大**，但不同体系的敏感度不同（醇类最强）。

## 持气率

$\Phi$ 定义为通气后分散体系中气体容积与气-液分散体系容积之比（`#L2271`）。

发泡体系（`#L2275`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Phi=0.0051\left(\dfrac{P}{V_{L}}\right)^{0.57}V_{G}^{0.24}$ | （2-90） |
| **文字式** | $\text{持气率}=0.0051\times\left(\dfrac{\text{功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.57}\times\text{表观气速}_{\text{【m/s】}}^{0.24}$ |  |

不生成泡沫的体系用表2-15（`#L2277-#L2284`）：

| 研究者 | 式号 | 关联式结构 |
|:---|:---|:---|
| Loiseau | 2-91 | $\Phi\propto(V_G/\sigma)^{0.36}(P/V_L)^{0.27}\mu^{-0.056}$ |
| Yung | 2-92 | $\Phi=0.52N_A^{0.5}\left(\rho N^{2}d^{3}/\sigma\right)^{0.65}(d/D)^{1.4}$ |
| 高正明 | 2-93 | $\Phi=0.195(P/V_L)^{0.28}V_G^{0.56}D^{0.45}$ |
| 张志斌 | 2-94 | $\Phi=C(P_G/V_L)^{0.35}V_G^{0.55}$，$C=0.053\sim0.059$ |

## 用法链条

1. 由功率关联式（见 [[通气搅拌功率]]）得 $P_G/V_L$；
2. 选 $\Phi$ 关联式算持气率，注意是否发泡；
3. 选对应体系式算 $d_B$；
4. 由式（2-86）得比界面积 $a$，再乘液相传质系数得体积传质系数。

这几步均为经验关联，体系一变（电解质、醇、发泡）系数就变，不能跨体系套用。

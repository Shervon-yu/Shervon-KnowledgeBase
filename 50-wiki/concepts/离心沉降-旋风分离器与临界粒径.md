# 离心沉降-旋风分离器与临界粒径

## 定义

**离心沉降**：依靠离心力使流体中的颗粒产生沉降运动（#L4836）。颗粒小、重力沉降速度太慢时，用离心力场强化重力场以提高生产能力（#L4836）。**离心分离因数** $K_{c}$ 是表示离心力相对重力大小的指标（#L4860）：$K_{c}=r\omega^{2}/g$。**旋风分离器**让含尘气体以切向高速进入筒体旋转，尘粒在离心力下沉向器壁、随外旋流下行成**底流**排出，净气形成向上的内旋流经中心管**溢流**排出（#L5004）。

|:---|:---:|---:|

| **文字式** | $\text{离心分离因数}=\dfrac{\text{颗粒旋转半径}_{\text{【m】}}\times\left(\text{角速度}_{\text{【rad/s】}}\right)^{2}}{\text{重力加速度}_{\text{【m/s²】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau_{\mathrm{t}}=\dfrac{9\mu b\left(D-b\right)}{\left(\rho_{\mathrm{p}}-\rho\right)d_{\mathrm{p}}^{2}u_{\mathrm{i}}^{2}}$ | （3.3-2） |
| **文字式** | $\text{颗粒沉降时间}_{\text{【s】}}=\dfrac{9\times\text{气体黏度}_{\text{【Pa·s】}}\times\text{进口宽度}_{\text{【m】}}\times\left(\text{筒径}_{\text{【m】}}-\text{进口宽度}_{\text{【m】}}\right)}{\left(\text{颗粒密度}_{\text{【kg/m³】}}-\text{气体密度}_{\text{【kg/m³】}}\right)\times\left(\text{颗粒直径}_{\text{【m】}}\right)^{2}\times\left(\text{进口气速}_{\text{【m/s】}}\right)^{2}}$ |  |

（式 3-23，#L4944；推导取 $n$ 圈旋转、平均半径 $r_{\mathrm{m}}=(D-b)/2$、旋转 $n$ 圈沉降距离为 $b$，#L4928、#L4936。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=\dfrac{2\pi r_{\mathrm{m}}n}{u_{\mathrm{i}}}$ | （3.3-3） |
| **文字式** | $\text{气体停留时间}_{\text{【s】}}=\dfrac{2\pi\times\text{平均旋转半径}_{\text{【m】}}\times\text{旋转圈数}}{\text{进口气速}_{\text{【m/s】}}}$ |  |

（式 3-24，#L4948。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{\mathrm{pc}}=3\sqrt{\dfrac{\mu b}{\pi n\left(\rho_{\mathrm{p}}-\rho\right)u_{\mathrm{i}}}}$ | （3.3-4） |
| **文字式** | $\text{临界粒径}_{\text{【m】}}=3\sqrt{\dfrac{\text{气体黏度}_{\text{【Pa·s】}}\times\text{进口宽度}_{\text{【m】}}}{\pi\times\text{旋转圈数}\times\left(\text{颗粒密度}_{\text{【kg/m³】}}-\text{气体密度}_{\text{【kg/m³】}}\right)\times\text{进口气速}_{\text{【m/s】}}}}$ |  |

（式 3-25，令 $\tau_{t}=\tau$ 求得，#L4950、#L4952；计算通常取 $n=5$，#L4954。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=\dfrac{\zeta\rho u_{\mathrm{i}}^{2}}{2}$，$\zeta=\dfrac{30bh\sqrt{D}}{d^{2}\sqrt{L+H}}$ | （3.3-5） |
| **文字式** | $\text{压力损失}_{\text{【Pa】}}=\dfrac{\text{阻力系数}\times\text{气体密度}_{\text{【kg/m³】}}\times\left(\text{进口气速}_{\text{【m/s】}}\right)^{2}}{2}$ |  |

（式 3-26、3-27，#L4960、#L4964；阻力系数中 $b$、$h$ 为进口宽高，$D$ 为筒径，$d$ 为排气管径，$L$、$H$ 为筒体与锥体高度。）

**书中给出的两个推论**：①只要进口气速相同，不管多大的旋风分离器，压力损失都相同；②压力损失相同时，小型分离器 $b=D/5$ 较小，由式 3-25 知其 $d_{pc}$ 更小（分离更细）（#L4966）。

## 适用范围与边界

- 式 3-23、3-25 建立在「颗粒在斯托克斯区沉降、旋转 $n$ 圈、沉降距离等于进口宽 $b$」的简化模型上（#L4882、#L4928）；实际流场有短路流与二次涡，书中未修正。
- $n=5$ 是计算惯例，不是物性（#L4954）。
- 压力损失的阻力系数只在图 3-9 的尺寸系列下有效（#L4966）；更换几何比例须重算 $\zeta$。
- 离心沉降的设计对象是小颗粒（#L4882）；粗颗粒仍用重力沉降更经济。

# 气体输送机械-通风机的风压与功率

## 定义

气体可压缩，压力变化程度用**压缩比**（排出与吸入绝对压力之比）表示，气体输送机械按出口压力或压缩比分类（#L4052）。**风量**指单位时间流过风机进口的气体体积流量 $q_{V}$（#L4102）；性能表上的风量是**标定条件**（20 ℃、101.3 kPa）下的 $q_{V0}$（#L4106）。**全风压** $p_{t}$ 是单位体积气体流经通风机后获得的总机械能，单位 Pa（#L4114）；**静压** $p_{s}$ 与**动压** $p_{d}=\rho u^{2}/2$ 之和为全压（#L4130）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_{t}=\left(p_{s2}-p_{s1}\right)+\left(p_{d2}-p_{d1}\right)$ | （2.3-1） |
| **文字式** | $\text{全风压}_{\text{【Pa】}}=\left(\text{出口静压}_{\text{【Pa】}}-\text{进口静压}_{\text{【Pa】}}\right)+\left(\text{出口动压}_{\text{【Pa】}}-\text{进口动压}_{\text{【Pa】}}\right)$ |  |

（#L4144；$p_{d}=\rho u^{2}/2$，通风机的动风压取出口截面动压 $p_{d}=p_{d2}$，#L4156。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_{e}=p_{t}\,q_{V}$ | （2.3-2） |
| **文字式** | $\text{有效功率}_{\text{【W】}}=\text{全风压}_{\text{【Pa】}}\times\text{风量}_{\text{【m³/s】}}$ |  |

（#L4200。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=\dfrac{P_{e}}{\eta}$ | （2.3-3） |
| **文字式** | $\text{轴功率}_{\text{【W】}}=\dfrac{\text{有效功率}_{\text{【W】}}}{\text{全风压效率}}$ |  |

（#L4208。）

**标定风量换算**：操作条件与标定条件不同时，按密度比换算风量与全风压（$p_{t0}$ 对应 101.3 kPa、20 ℃，#L4106、#L4174）。

## 适用范围与边界

- 通风机全风压可用实验测定（#L4114）；本书给的是测定式与换算关系，未给叶轮几何→风压的解析式。
- 压缩比大的场合（鼓风机、压缩机）按绝热/多变过程计算压缩功，涉及绝热指数 $\kappa$ 或多变指数 $m$（#L4232）、吸入比体积 $v_{1}$（#L4252）；本页不展开压缩功的具体积分式，只用书内已给的形式与行号。
- 风量按进口体积计，密度变化时不能直接用出口体积。
- 喷射泵（用水蒸气或高压水作工作流体，可抽真空）属另一类，靠静压能与动能转换，不按全风压-风量表征（#L4400、#L4402）。

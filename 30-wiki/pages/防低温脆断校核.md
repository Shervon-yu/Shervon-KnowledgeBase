材料标准给的「使用温度下限」不是硬墙：只要实际应力水平低，可以在更低温度下安全使用。附录 F 用**应力比 $R_{ts}$** 把最低允许使用温度往下调，最多降 50 ℃。

## 一、适用（F.1，`#L14272-#L14280`）

- 最低设计温度低于 GB/T 150.2 规定的材料使用温度下限时，可按本附录校核，确保设计温度**不低于**由本附录确定的最低允许使用温度；
- 仅适用于表 F.2 中交货状态为**正火态或调质态**的材料（含其复合钢板、堆焊元件）；
- 钢管、钢锻件元件的最低允许使用温度，可按相应化学成分与交货状态的**钢板牌号**确定；
- 受压元件以及用焊接方法连到容器本体的元件（衬板、垫板等）**各自作为独立元件**对待。

## 二、两个定义（F.2.1，`#L14290-#L14296`）

- **元件最低允许使用温度** $T_{MAT}^{Ci}$：该元件按本附录方法确定的、不会发生低温脆性断裂的最低金属温度；
- **压力容器最低允许使用温度** $T_{MAT}$：各组成元件最低允许使用温度中的**最高值**（即最不抗冷的那一件说了算）。

## 三、确定程序（F.3，`#L14310-#L14322`）

1. 按 F.4 定元件的**控制厚度** $\delta_g$；
2. 按牌号、使用状态、控制厚度查表 F.2 得 $T_{MAT}^{Ci}$；
3. 必要时按 F.6 降 $T_{MAT}^{Ci}$（或改设计参数），直到所有工况组合下的最低设计温度均**高于或等于**最低允许使用温度；
4. 取各元件中的最高值作为容器的最低允许使用温度。

控制厚度按表 F.1（18 种结构 + 三部件组合 2 种）取，本质是「取该元件与相邻件中较厚者、且法兰类按 $1/4$ 法兰厚度折算」：如筒体与封头对接取 $\delta_2$、带法兰的取 $\max\{\delta_2,\ \delta_f/4\}$、纯法兰件取 $\delta_f/4$。表中 $\delta_1,\delta_2,\delta_3,\delta_f$ 均为名义厚度，20 号线为 $\max\{\delta_2,\delta_3,\delta_f/4\}$。

表 F.2 是查表主体（`#L14486-#L14533`）：对每种牌号给出厚度范围、三种使用状态（焊态 / 局部或现场热处理 / 炉内整体热处理）在控制厚度 $\le10$ mm 至 $100$ mm 下的最低允许使用温度。几个代表值（控制厚度 $\le10$ mm）：

| 牌号 | 标准 | 厚度范围 | 焊态 | 局部/现场热处理 | 炉内整体热处理 |
|:--|:--|:--|:--|:--|:--|
| Q245R | GB/T 713.2 | 6~100 | $-10$ | $-20$ | $-20$ |
| Q345R | GB/T 713.2 | 6~100 | $-34$ | $-45$ | $-45$ |
| Q370R | GB/T 713.2 | 10~100 | $-50$ | $-50$ | $-50$ |
| Q420R | GB/T 713.2 | 10~30 | $-28$ | $-40$ | $-40$ |
| 16MnDR | GB/T 3531 | 6~100 | $-60$ | $-60$ | $-60$ |
| 07MnMoVR | GB/T 19189 | 10~60 | $-40$ | $-40$ | $-40$ |
| 07MnNiVDR | GB/T 19189 | 10~60 | $-50$ | $-50$ | $-50$ |
| 07MnNiMoDR | GB/T 19189 | 10~50 | $-47$ | $-60$ | $-60$ |

厚度落在表列值之间时允许**线性插值**；非焊接元件可选「炉内整体热处理」状态。

## 四、应力比与温度下调（F.6，`#L14334-#L14356`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R_{ts}=\max\left\{\dfrac{\delta_d\varphi}{\delta_n-C},\ \dfrac{\sigma_m^p}{[\sigma]^t}\right\}$ | （F.1） |
| **文字式** | $\text{应力比}=\max\left\{\dfrac{\text{设计厚度}\times\text{焊接接头系数}}{\text{名义厚度}-\text{厚度附加量}},\ \dfrac{\text{一次总体薄膜应力}}{\text{最低允许使用温度下许用应力}}\right\}$ |  |

- 不承受总体一次薄膜应力的元件（平封头、平盖、管板、法兰）用压力比代替：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R_{ts}=\dfrac{p_c}{[p_w]}$ | （F.2） |
| **文字式** | $\text{应力比}=\dfrac{\text{计算压力}_{\text{【MPa】}}}{\text{最大允许工作压力}_{\text{【MPa】}}}$ |  |

- $R_{ts}<0.27$ 时**取 0.27**；
- 用 $R_{ts}$ 查图 F.1~F.3（中间值内插）得最低允许使用温度的降低值 $\Delta T$；
- $\Delta T\le50\ ℃$；调整后的最低允许使用温度**不应低于 $-100\ ℃$**；
- $R_{ts}<0.27$ 时，免做母材冲击试验的最低允许使用温度为 $-70\ ℃$。

三张曲线按热处理状态分：图 F.1 焊态、图 F.2 局部或现场热处理、图 F.3 炉内整体热处理或非焊接件——**状态选错，$\Delta T$ 就查错**。

## 判断

- 容器取各元件温度的**最高值**，是「短板原理」的反面：最不抗冷（温度最高）的那个元件决定整台容器。
- 控制厚度不是元件自身厚度，法兰类要按 $\delta_f/4$ 折算，相邻件取大；用错控制厚度会查错整行数据。
- $R_{ts}$ 有 0.27 下限，意思是「应力再低也只能按 0.27 查」；$\Delta T$ 再有 50 ℃ 与 $-100\ ℃$ 双截止。
- 三个热处理状态三条曲线，不能用焊态曲线去算做过整体热处理的件（会偏保守但违背规范口径）。

# 坐标变换与网格生成

## 为什么变换（§5.1）

物理平面 $(x,y)$ 里物面是曲线、网格不均匀；计算平面 $(\xi,\eta)$ 里网格是均匀矩形，差分格式、边界条件处理都简单。做法是取 $x=x(\xi,\eta)$、$y=y(\xi,\eta)$，把流动方程整体变换过去，在计算平面上求解（#L3734-3780）。

## 导数怎么换（§5.2）

链式法则（式 5-2、5-3，＃L8455-8457）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial}{\partial x}=\dfrac{\partial}{\partial\xi}\dfrac{\partial\xi}{\partial x}+\dfrac{\partial}{\partial\eta}\dfrac{\partial\eta}{\partial x}$ | （5-2） |
| **文字式** | $\dfrac{\partial}{\partial x}=\dfrac{\partial}{\partial\xi}\times\dfrac{\partial\xi}{\partial x}+\dfrac{\partial}{\partial\eta}\times\dfrac{\partial\eta}{\partial x}$ |  |

二阶导数照此再做一次，得到含一阶、二阶度量的长表达式（5-9、5-13、5-15，＃L3848-3888）。若方程已写成强守恒形式（2-93），粘性项只含一阶导数，只需一阶变换式（5-2、5-3、5-5），两次套用即可，比变换原始二阶方程省事（#L3914）。

## 度量与雅可比（§5.3）

已知 $\partial x/\partial\xi$ 等正度量，求逆度量要用矩阵求逆（式 5-27～5-32，＃L4010-4036）。记雅可比行列式（式 5-34，＃L4048）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $J=\dfrac{\partial(x,y)}{\partial(\xi,\eta)}=\dfrac{\partial x}{\partial\xi}\dfrac{\partial y}{\partial\eta}-\dfrac{\partial x}{\partial\eta}\dfrac{\partial y}{\partial\xi}$ | （5-34） |
| **文字式** | $\text{雅可比行列式}=\dfrac{\partial x}{\partial\xi}\dfrac{\partial y}{\partial\eta}-\dfrac{\partial x}{\partial\eta}\dfrac{\partial y}{\partial\xi}$ |  |

逆度量由 $J$ 直接给出（式 5-35，＃L4052）：$\partial\xi/\partial x=(\partial y/\partial\eta)/J$、$\partial\xi/\partial y=-(\partial x/\partial\eta)/J$ 等。$J\ne0$ 保证变换一一对应。

## 变换后仍可强守恒（§5.4）

把（2-93）逐项代入（5-2/5-3），再乘 $J$ 并整理，可得（式 5-47，＃L4140）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial U_1}{\partial t}+\dfrac{\partial F_1}{\partial\xi}+\dfrac{\partial G_1}{\partial\eta}=0$ | （5-47） |
| **文字式** | $\dfrac{\partial\text{守恒变量}_1}{\partial\text{时间}}+\dfrac{\partial\text{通量}_{\xi}}{\partial\xi}+\dfrac{\partial\text{通量}_{\eta}}{\partial\eta}=0$ |  |

其中 $F_1=\left[F\,\partial\xi/\partial x+G\,\partial\xi/\partial y\right]/J$，$G_1=\left[F\,\partial\eta/\partial x+G\,\partial\eta/\partial y\right]/J$（式 5-48，＃L4140 前后）。结论：物理平面里的强守恒形式，在计算平面里仍是强守恒形式——这是变换后还能用守恒型格式、还能正确捕捉激波的前提（#L4090）。

## 网格生成的几条路线（§5.6–§5.9）

1. **代数拉伸**（§5.6）：用解析函数把均匀 $\eta$ 映射成壁面附近加密的 $y$，例如 $\Delta y=\mathrm{e}^{\eta}\Delta\eta$（式 5-52，＃L4214）或双曲正弦拉伸（5-61～5-64，＃L4272-4288）。优点是快、可解析求度量；缺点是不能贴合复杂外形。
2. **椭圆型贴体网格**（§5.7）：把 $\xi(x,y)$、$\eta(x,y)$ 取成 Laplace 方程的解（式 5-67、5-68，＃L4360-4362），在计算平面反解 $x(\xi,\eta)$、$y(\xi,\eta)$ 的椭圆型方程（5-69、5-70，＃L4366-4376），用松弛法迭代。网格光滑、贴体；但网格生成与流动无关，物面附近加密要靠源项或边界条件调节（#L4402、#L4418）。
3. **自适应网格**（§5.8）：让网格点随流场大梯度移动，变换里保留时间度量 $\partial\xi/\partial t$、$\partial\eta/\partial t$（式 5-71～5-84，＃L4450-4550）。流场定常后网格自动停止移动。优点是同等网格数下精度更高，缺点是实现复杂、稳定性需另加考虑（#L4442）。
4. **分块网格与非结构网格**（§5.9）：复杂外形分成多块贴体网格，块间用交界面连接；有限体积法还可用非结构网格、笛卡儿网格（#L4584、#L4644）。

## 适用边界

- 变换不改变方程的性质（双曲/抛物/椭圆），但会改变网格的均匀性与度量大小；度量算错，格式精度立刻掉。
- 椭圆型网格生成用的是 Laplace/Poisson 方程，与流动的数学类型无关——流动是双曲型的也照样能用（#L4402 译者注）。
- 自适应网格的变换含时间度量，控制方程的时间导数项必须完整保留；否则网格移动会被算成虚假流动（#L4472）。
- 有限体积法在物理平面直接对控制体积分，不必做这一套坐标变换；但网格生成的思想（贴体、自适应）通用。

## 判断

坐标变换不是"换个坐标写方程"的数学练习：它的实际价值在于让差分格式能在规则网格上运行，并且把强守恒性质带进计算平面（5-47）。代价是度量项——$J$ 与逆度量都要离散，度量误差会直接污染通量，这也是为什么书里反复强调"用强守恒形式时只需一阶导数变换"。

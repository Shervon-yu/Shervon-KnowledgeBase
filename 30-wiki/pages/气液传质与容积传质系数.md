# 气液传质与容积传质系数

## 两个速率式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r=K_{L}a\,\Delta C$ | （3-27） |
| **文字式** | $\text{传质速率}_{\text{【kmol/(s·m³)】}}=\text{液相容积传质系数}_{\text{【1/s】}}\times\text{液相浓度推动力}_{\text{【kmol/m³】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r=K_{G}a\,\Delta p$ | （3-28） |
| **文字式** | $\text{传质速率}_{\text{【kmol/(s·m³)】}}=\text{气相容积传质系数}_{\text{【kmol/(s·m³·MPa)】}}\times\text{分压推动力}_{\text{【MPa】}}$ |  |

（`#L3475-#L3485`）

## 推动力怎么取

1. 气液两相全混：出口推动力代表全过程；
2. 气体不混合、平推流通过：釜底与釜顶各一个推动力，取**对数平均值**。工业规模实践表明对数平均最符合实际、最实用（`#L3487`）。

## K_L 与 a 谁在变

实验证明 $K_La$ 的变化主要来自操作条件改变比界面积 $a$；$K_L$ 几乎不随操作条件变，只与体系性质有关（`#L3493`）：

| 体系 | $K_L$ 量级 |
|:---|:---|
| 聚并体系 | $1\sim6\times10^{-4}$ m/s |
| 非聚并体系 | $1\sim4\times10^{-4}$ m/s |
| 常取设计值 | $4\times10^{-4}$ m/s |

因此**比界面积直接决定传质速率**，它与气泡直径 $d_B$ 和气含率 $\Phi$ 的关系见式（2-86）及 [[持气率与气泡直径]]。

## 再回归式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{L}a=0.023(P/V_{L})^{0.49}V_{G}^{0.58}$ | （3-40） |
| **文字式** | $\text{液相容积传质系数}_{\text{【1/s】}}=0.023\times\left(\dfrac{\text{功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.49}\times\left(\text{空塔气速}_{\text{【m/s】}}\right)^{0.58}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{L}a=0.0016(P/V_{L})^{0.82}V_{G}^{0.3}$ | （3-41） |
| **文字式** | $\text{液相容积传质系数}_{\text{【1/s】}}=0.0016\times\left(\dfrac{\text{功率}_{\text{【W】}}}{\text{液体体积}_{\text{【m³】}}}\right)^{0.82}\times\left(\text{空塔气速}_{\text{【m/s】}}\right)^{0.3}$ |  |

（3-40）对低黏体系，（3-41）对高黏流体与电解质溶液（`#L3513-#L3521`）。

## 用法

1. 先按体系选式（黏度、是否电解质、是否聚并），再代入 $P/V_L$ 与 $V_G$；
2. 通气功率 $P_G$ 与不通风功率差别很大，见 [[通气搅拌功率]]；
3. 测得 $K_La$ 后乘推动力得速率；推动力取法见上。

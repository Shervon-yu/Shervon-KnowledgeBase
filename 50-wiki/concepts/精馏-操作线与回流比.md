# 精馏-操作线与回流比

## 定义

- **操作线方程**：表示两层塔板之间，下层塔板上升蒸气组成 $y_n$ 与上层塔板下降液体组成 $x_{n-1}$ 的关系式，用于计算塔板数（#L13007）。
- **回流比 $R$**：回流量 $L$ 与馏出液量 $D$ 之比；泡点回流时精馏段下降液体量 $L$ 等于回流量（#L13033）。
- 推导前提是**恒摩尔流量假设**：精馏段各层塔板下降液体 $L$ 相等、上升蒸气 $V$ 相等（#L12807-#L12809）。

## 判据 / 计算

精馏段物料衡算（总物料与易挥发组分）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $V=L+D,\qquad V y_n=L x_{n-1}+D x_D$ | （12-1） |
| **文字式** | $\text{上升蒸气}_{\text{【kmol/h】}}=\text{下降液体}_{\text{【kmol/h】}}+\text{馏出液}_{\text{【kmol/h】}}$；$\text{上升蒸气}\times\text{气相组成}_n=\text{下降液体}\times\text{液相组成}_{n-1}+\text{馏出液}\times\text{馏出液组成}$ |  |

精馏段操作线（液-汽比形式）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $y_n=\dfrac{L}{V}x_{n-1}+\dfrac{D}{V}x_D$ | （12-2） |
| **文字式** | $\text{气相组成}_n=\dfrac{\text{下降液体}}{\text{上升蒸气}}\times\text{液相组成}_{n-1}+\dfrac{\text{馏出液}}{\text{上升蒸气}}\times\text{馏出液组成}$ |  |

原书编号：式(6-32)（#L13022）。

回流比：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R=\dfrac{L}{D}$ | （12-3） |
| **文字式** | $\text{回流比}=\dfrac{\text{回流量}_{\text{【kmol/h】}}}{\text{馏出液量}_{\text{【kmol/h】}}}$ |  |

原书编号：式(6-34)（#L13036）。

以回流比表示的操作线（最常用形式）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $y_n=\dfrac{R}{R+1}x_{n-1}+\dfrac{x_D}{R+1}$ | （12-4） |
| **文字式** | $\text{气相组成}_n=\dfrac{\text{回流比}}{\text{回流比}+1}\times\text{液相组成}_{n-1}+\dfrac{\text{馏出液组成}}{\text{回流比}+1}$ |  |

原书编号：式(6-35)（#L13042）。

液-汽比与回流比的关系：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{L}{V}=\dfrac{R}{R+1}$ | （12-5） |
| **文字式** | $\dfrac{\text{下降液体}}{\text{上升蒸气}}=\dfrac{\text{回流比}}{\text{回流比}+1}$ |  |

原书编号：式(6-36)（#L13048）。

## 适用范围与边界

- 式(12-2)/(12-4) 只描述**精馏段**（进料板以上）；提馏段另有操作线，两段在进料处由 **$q$ 线**（进料热状况线）连接（#L13005）。
- 恒摩尔流量假设在两组分摩尔汽化热相近、塔内热损失可忽略时成立（#L12795-#L12797）。
- 泡点回流（冷凝液在泡点下回流）时才有 $L=R D$；冷回流、过冷回流须修正（#L13033）。
- 操作线在 $y$-$x$ 图上是一条直线：斜率 $R/(R+1)$、截距 $x_D/(R+1)$；与平衡线的距离决定理论板数（#L13045）。
- 最小回流比与理论板数的定量关系见 §6.3 后文（最小回流比 $R_{min}$，#L13613 起），本页不展开。

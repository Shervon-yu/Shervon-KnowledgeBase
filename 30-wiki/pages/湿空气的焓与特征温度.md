# 湿空气的焓与特征温度

## 焓（`#L13833-#L13857`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $I=I_g+HI_v$ | （7-14） |
| **文字式** | $\text{湿空气焓}=\text{干气比焓}+\text{湿度}\times\text{水汽比焓}$ |  |

以 0 ℃ 干空气与 0 ℃ 液态水为基准：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $I_g=c_gt$；$I_v=r_0+c_vt$ | （7-15a）（7-15b） |
| **文字式** | $\text{干气比焓}=\text{干气比热容}\times\text{温度}$；$\text{水汽比焓}=0\,\text{℃时的比汽化热}+\text{水汽比热容}\times\text{温度}$ |  |

$r_0$=2492 kJ/kg 水：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $I=(1.01+1.88H)t+2492H$ | （7-16） |
| **文字式** | $\text{湿空气焓}=(1.01+1.88\times\text{湿度})\times\text{温度}+2492\times\text{湿度}$ |  |

$I$ 随 $t$、$H$ 增大而增大。

## 四种温度（`#L13859-#L14003`）

**干球温度 $t$**：普通温度计测得的真实空气温度。

**露点 $t_d$**：等 $p$、等 $H$ 冷却到刚出现液滴的温度；此时 $H=H_s(t_d)$，$\varphi=100\%$。

**湿球温度 $t_w$**：湿纱布包裹的温度计在气流（>5 m/s）中达到的稳定温度。机理：水汽化带走热量 → 水温下降 → 空气向湿球传热 → 传热与汽化达到**动态平衡**。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $t_w=t-\dfrac{k_Hr_w}{\alpha}(H_w-H)$ | （7-19） |
| **文字式** | $\text{湿球温度}=\text{干球温度}-\dfrac{\text{传质系数}\times\text{比汽化热}}{\text{对流传热系数}}\times(\text{湿球饱和湿度}-\text{湿度})$ |  |

空气-水物系 $\alpha/k_H\approx1.09$ kJ/(kg 干气·℃)，且 $\alpha$、$k_H$ 均 ∝ $Re^{0.8}$，故该比值与流速无关。

**绝热饱和温度 $t_{as}$**：大量循环水与少量空气绝热接触，空气降温增湿至饱和的稳定温度；过程近似**等焓**。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $t_{as}=t-\dfrac{r_{as}}{c_{Has}}(H_{as}-H)$ | （7-21） |
| **文字式** | $\text{绝热饱和温度}=\text{干球温度}-\dfrac{\text{比汽化热}}{\text{湿比热容}}\times(\text{饱和湿度}-\text{湿度})$ |  |

## 为什么 $t_w\approx t_{as}$（`#L13989-#L13995`）

对空气-水物系 $\alpha/k_H\approx c_{Has}$，故（7-19）与（7-21）同形 → $t_w\approx t_{as}$。

但两者概念不同：

- $t_w$：**大量空气 + 少量水**，水达到稳定温度，属**动态平衡**；
- $t_{as}$：**大量水 + 少量空气**，空气达到饱和，属**静态平衡**。

## 四温度的关系（`#L13997-#L14003`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $t>t_w>t_d$（不饱和）；$t=t_w=t_d$（饱和） | （7-22） |
| **文字式** | 不饱和湿空气：干球温度 > 湿球温度 > 露点；饱和时三者相等 |  |

## 判断

- $t_d$ 只反映"水汽多少"（等 $H$），$t_w$ 同时反映"水汽多少 + 温度高低"，所以 $t_w$ 比 $t_d$ 更接近干球。
- 干燥计算中最常用的独立参数对是 $(t,H)$ 或 $(t,t_w)$；$t_d$ 用于测湿（露点法），$t_w$ 用于干湿球温度计。
- 只有空气-水物系才有 $\alpha/k_H\approx c_{Has}$；其他物系 $t_w\neq t_{as}$，不能混用。

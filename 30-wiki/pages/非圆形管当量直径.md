# 非圆形管当量直径

## 水力半径（`#L2203-#L2213`）

非圆管算阻力时，1-44、Re、$\varepsilon/d$ 中的管径要用当量直径 $d_e$ 代替。定义水力半径：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r_H=\dfrac{A}{\Pi}$ | （无编号） |
| **文字式** | $\text{水力半径}_{\text{【m】}}=\dfrac{\text{流通截面积}_{\text{【m²】}}}{\text{湿润周边长度}_{\text{【m】}}}$ |  |

湿润周边长度 = 管壁与流体接触的周长（不含自由液面）。

圆管：$r_H=\dfrac{\pi d^2/4}{\pi d}=\dfrac{d}{4}$，即 $d=4r_H$。推广到任意截面：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_e=4r_H=\dfrac{4A}{\Pi}$ | （1-54） |
| **文字式** | $\text{当量直径}_{\text{【m】}}=4\times\text{水力半径}_{\text{【m】}}=\dfrac{4\times\text{流通截面积}_{\text{【m²】}}}{\text{湿润周边长度}_{\text{【m】}}}$ |  |

## 三种常见截面（`#L2221-#L2231`）

- 圆管：$d_e=d$；
- 套管环隙（外管内径 $d_2$、内管外径 $d_1$）：$d_e=d_2-d_1$；
- 边长 $a$、$b$ 的矩形管：$d_e=\dfrac{2ab}{a+b}$。

**易错点**：算流速必须用真实截面积 $u=q_V/A$，不能用 $d_e$ 反算面积。

## 层流要修正（`#L2233-#L2237`）

湍流用 $d_e$ 计算已足够准；层流不准，需把 $\lambda=64/Re$ 的 64 换成与截面形状有关的常数 $c$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\lambda=\dfrac{c}{Re}$ | （1-55） |
| **文字式** | $\text{摩擦系数}=\dfrac{\text{截面形状系数}}{\text{雷诺数}}$ |  |

## 例 1-16：同面积三种截面（`#L2239-#L2281`）

$A=0.48$ m²：

| 截面 | 边长/管径 | 湿润周边 Π | 当量直径 $d_e$ |
|:---|:---|:---|:---|
| 正方形 | $a=0.693$ m | 2.77 m | 0.693 m |
| 矩形（宽=3×高） | $a=0.4$、$b=1.2$ m | 3.2 m | 0.6 m |
| 圆形 | $d=0.78$ m | 2.45 m | 0.78 m |

结论：**面积相同时，湿润周边越短、当量直径越大、摩擦损失越小** → 圆形截面最优，方形次之，矩形最差。

## 判断

- 这条结论只对"同一流通面积、同一流量"成立；工程上选圆管主要是制造与承压方便，阻力优势只是副产品。
- 环隙的 $d_e=d_2-d_1$ 常被误写成 $d_2$ 或平均值，套管内传热与压降计算都会因此偏小。

# 表面传热系数的无因次关联

## 边界层图像

按 Prandtl 边界层假设，黏性流体流动可分为两个流场：靠近固定表面的边界层（滞止层，黏性效应主导）与流体本体（黏性可忽略）。传热主要发生在边界层，边界层内以分子热传导为主，其厚度是关键参数（`#L3237`）。

实际边界层内同时存在温度梯度与黏度梯度，问题更复杂；固体壁面形状及其相对流动方向还会影响本体循环、湍流分布、排液量与功耗（`#L3239`）。

## 无因次关系式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{Nu}}=\dfrac{\alpha D}{\lambda}=f\left(\dfrac{d^{2}N\rho}{\mu},\ \dfrac{c_{p}\mu}{\lambda},\ \dfrac{\mu}{\mu_{w}},\ \dfrac{d}{D},\ \dfrac{w}{D}\right)$ | （3-10） |
| **文字式** | $\text{努塞尔数}=\dfrac{\text{表面传热系数}\times\text{搅拌设备内径}_{\text{【m】}}}{\text{流体热导率}_{\text{【W/(m·K)】}}}=f\left(\text{雷诺数},\ \text{普朗特数},\ \dfrac{\text{本体黏度}}{\text{壁温黏度}},\ \dfrac{\text{搅拌器直径}}{\text{设备内径}},\ \dfrac{\text{挡板或叶片宽度}}{\text{设备内径}}\right)$ |  |

（OCR 原文第三组变量写作 $\mu/\mu_3$，按上下文应为 $\mu/\mu_w$，即壁温黏度比。）

## 三类影响因素

以圆筒形搅拌设备为例（`#L3247-#L3257`）：

1. **几何性质**：设备内径 $D$、液深 $H$、釜底形状、挡板情况、$d/D$、夹套与内构件表面积、内冷管排列与管径、冷却管数量；
2. **搅拌器特征**：类型、直径、桨叶数、桨叶几何、桨叶角度、转速、安装方式；
3. **物料性质**：牛顿或非牛顿、黏度、热导率、热容。

## 用法

- 具体传热元件（夹套、盘管、内冷管）的 $\alpha$ 计算式见第七章 §7.2；
- 高黏刮壁釜有专门关联式，见 [[刮壁式搅拌釜的传热系数与功率关联式]]；
- 多相体系（气液、固液）的 $\alpha$ 通常要在单相式上乘修正，书中未给通用修正，需按实测或专门文献。

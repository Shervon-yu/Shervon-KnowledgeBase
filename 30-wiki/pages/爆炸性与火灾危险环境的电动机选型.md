# 爆炸性与火灾危险环境的电动机选型

依据 GB 50058《爆炸和火灾危险环境电力装置设计规范》分区，再按分区选设备（`#L8327`）。

## 区域划分（表9-11）

| 类别 | 分区 | 区域情况 |
|:---|:---|:---|
| 爆炸性气体 | 0 区 | 连续或长期出现爆炸性气体混合物 |
| | 1 区 | 正常运行时**可能**出现 |
| | 2 区 | 正常运行时不可能出现，或仅短时存在 |
| 爆炸性粉尘 | 10 区 | 连续或长期出现 |
| | 11 区 | 积尘扬起而偶然出现 |
| 火灾危险 | 21 区 | 闪点高于环境温度的可燃液体 |
| | 22 区 | 悬浮状、堆积状可燃粉尘或纤维 |
| | 23 区 | 固体状可燃物质 |

（`#L8329-#L8340`；"正常运行"含开车、运转、停车、装卸、开盖、安全阀排放等）

## 两个分级维度

爆炸性气体按**最大试验安全间隙 MESG 或最小点燃电流比 MICR** 分级（表9-12）：

| 级别 | MESG/mm | MICR |
|:---|:---:|:---:|
| II A | ≥0.9 | >0.8 |
| II B | 0.5~0.9 | 0.45~0.8 |
| II C | ≤0.5 | <0.45 |

（`#L8346-#L8354`）

按**引燃温度**分组（表9-13）：

| 组别 | 引燃温度 t/℃ | 组别 | 引燃温度 t/℃ |
|:---:|:---|:---:|:---|
| T1 | t>450 | T4 | 135<t≤200 |
| T2 | 300<t≤450 | T5 | 100<t≤135 |
| T3 | 200<t≤300 | T6 | 85<t≤100 |

（`#L8358-#L8364`）

常见举例（表9-14）：IIA 的 T1 有甲烷、丙烷、苯、甲苯、一氧化碳；IIB 的 T2 有乙烯、环氧乙烷；IIC 的 T2 有乙炔、T1 有氢。

粉尘按引燃温度分 T11（>270 ℃）、T12（200~270）、T13（150~200），取粉尘云与粉尘层引燃温度的**低值**（表9-15，`#L8377-#L8387`）。

## 防爆型式（表9-16）

| 型式 | 标志 | 原理 |
|:---|:---:|:---|
| 隔爆型 | d | 外壳承受内部爆炸并不让火焰传出去 |
| 增安型 | e | 提高防护等级，正常时不产生火花/危险温度 |
| 正压型 | p | 壳内充保护气体保持正压，阻止外部混合物进入 |
| 无火花型 | n | 正常无火花、不过热，用于低概率场合 |

另有本质安全型 i（ia、ib）、充油型 o、充砂型 q（`#L8413`）。

标志举例：II 类隔爆 B 级 T3 组 = `dII BT3`（`#L8426-#L8430`）。

I 类为煤矿井下用，II 类为工厂用，**不能简单代用**（`#L8399`）。

## 粉尘与火灾危险环境

| 环境 | 要求 |
|:---|:---|
| 爆炸性粉尘 10 区 | 尘密结构 DT |
| 爆炸性粉尘 11 区 | 可燃非导电粉尘与可燃纤维可用防尘 DP，其余仍用 DT |
| 粉尘设备表面温度 | 按表9-20：T11 无超负荷 215 ℃、超负荷 196；T12 100/145；T13 120/110（OCR 疑有串行，**待核**） |
| 火灾危险 21/22 区 固定安装 | IP44（23 区 IP21） |
| 火灾危险 移动/携带式 | IP54 |
| 21 区有滑环等火花部件 | 不宜 IP44，应用 IP54 |
| 23 区有滑环等火花部件 | 不宜 IP21，应用 IP44 |

（`#L8481-#L8513`）

## 表9-18 电动机型式与区域的适用性（摘）

表9-18 用 ○（适用）、△（慎用）、×（不适用）标注各型电机（隔爆、增安、正压、无火花、直流、电磁滑差离合器）在 0/1/2 区与 10/11 区、21/22/23 区的适用性（`#L8463`）：

- 绕线型感应电动机、同步电动机采用增安型时，主体为增安结构，产生火花的部分须为隔爆或正压结构；
- 无火花型在通风不良及户内存在比空气重的易燃物质区域慎用。

## 判断

选型的顺序是"分区 → 分级分组 → 型式"，不是"选个防爆电机就行"。同一台设备在 2 区可用无火花型 n，搬到 1 区就必须隔爆 d 或正压 p；而介质从丙烷（IIA/T1）换成氢（IIC/T1）时，隔爆间隙要求提高一个等级——外壳不能通用。

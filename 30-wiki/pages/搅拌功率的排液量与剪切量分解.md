# 搅拌功率的排液量与剪切量分解

## 功率=排液量×剪切量

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=\rho g\,Q_{d}H_{e}$ | （4-1） |
| **文字式** | $\text{搅拌功率}_{\text{【W】}}=\text{密度}_{\text{【kg/m³】}}\times9.81\times\text{排液量}_{\text{【m³/s】}}\times\text{剪切量}_{\text{【m】}}$ |  |

其中 $Q_d\propto Nd^3$，$H_e=N^2d^2$（相当于泵的压头），所以 $P\propto\rho N^3d^5$（`#L3855-#L3865`）。

## 两个准数

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q_{d}=N_{qd}Nd^{3}$ | （4-2） |
| **文字式** | $\text{排液量}_{\text{【m³/s】}}=\text{排出流量准数}\times\text{转速}_{\text{【1/s】}}\times\left(\text{桨径}_{\text{【m】}}\right)^{3}$ |  |

湍流区 $N_p$ 为常数，$P=\rho N_pN^3d^5$（4-3）；其他流域 $N$ 的指数 2~3.2、$d$ 的指数 3~5.2（`#L3869-#L3877`）。

## 恒功率下的排量与压头比

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\left(\dfrac{Q_{d}}{H_{e}}\right)_{P}\propto d^{\,\alpha}$ | （4-4） |
| **文字式** | $\text{排液量与剪切量之比}\propto\left(\text{桨径}_{\text{【m】}}\right)^{\text{放大指数}}$ |  |

湍流区 $\alpha=8/3$；过渡区与黏性区 $\alpha$ 在 7/3~9/3 之间（`#L3879-#L3881`）。

## 工程含义

1. 同一功率下**大桨=大排量、低剪切**；小桨=高剪切、低排量；
2. 需要大排量、低速度（易剪切敏感、需整体循环）→ 选大直径桨；
3. 需要高剪切（分散、破碎液滴）→ 小直径高转速；
4. 放大时若只保 $P_V$ 恒定，$Q_d/V$（翻转次数）必然下降，这正是"放大后混合变差"的根（见 [[放大因子与放大准则]]）。

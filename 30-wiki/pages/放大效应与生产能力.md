# 放大效应与生产能力

## 理想情形的生产能力

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\varepsilon=\dfrac{G_{L}}{G_{s}}=\dfrac{V_{L}}{V_{s}}=\dfrac{D_{L}^{2}H_{L}}{D_{s}^{2}H_{s}}=\gamma^{3}$ | （4-24） |
| **文字式** | $\text{生产能力放大倍数}=\dfrac{\text{大釜生产能力}}{\text{小釜生产能力}}=\dfrac{\text{大釜体积}}{\text{小釜体积}}=\left(\text{尺寸放大倍数}\right)^{3}$ |  |

其中 $\gamma=D_L/D_s=H_L/H_s$（`#L4090-#L4094`）。

## 由此推出的几个整数

| 生产能力 | 内径增加 |
|:---|:---|
| ×1（翻一倍） | 26% |
| ×2 | 44% |
| ×6 | 约 100%（翻一倍） |

（`#L4096`）

## 放大效应

实际大釜受结构尺寸、混合/传热效果、反应速率影响，与理想值有偏差，引入放大效应 $\varphi$（`#L4098`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\varphi=1\pm\chi\%$ | （4-25） |
| **文字式** | $\text{放大效应}=1\pm\text{放大效率比}$ |  |

- 放大后效率**增加**取负号（$\varphi<1$，实际产能高于理想）；
- 效率**下降**取正号（$\varphi>1$）；
- 相等取零。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $G_{L}=G_{s}\left(\dfrac{\gamma}{\varphi}\right)^{3}$ | （4-26） |
| **文字式** | $\text{大釜生产能力}=\text{小釜生产能力}\times\left(\dfrac{\text{尺寸放大倍数}}{\text{放大效应}}\right)^{3}$ |  |

（`#L4104`）

## 判断

1. 生产能力按**体积**增长（三次方），但混合时间、传热面积按更低的幂次增长——这是放大效应的物理根源；
2. $\varphi$ 的立方放大很敏感：$\varphi=1.26$ 时产能只剩理想值的 50%；
3. 实际放大时 $\varphi$ 只能由中试或同类装置经验估计，不能纯理论算出（`#L4096`）。

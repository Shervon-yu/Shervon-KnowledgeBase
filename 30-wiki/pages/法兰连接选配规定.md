# 法兰连接选配规定

## 定义

HG/T 20635 给出 Class 系列法兰、垫片、紧固件的选配规定与使用限制。PN 系列对应标准为 HG/T 20614（#L15468-#L15516）。

## 判据与计算

### 法兰选用（#L15468-#L15516）

| 法兰类型 | 密封面 | 常用 DN / Class | 使用场合 |
| :--- | :--- | :--- | :--- |
| 带颈平焊 SO | RF | DN15~600，Class150/300 | 公用工程、非易燃易爆介质，-45~+200 ℃ |
| 螺纹 Th | RF | DN15~150，Class150 | 仪表、锥管螺纹连接；压力较高推荐 NPT |
| 对焊环松套 LF/SE | RF | DN15~600，Class150/300 | 不锈钢、镍基合金、钛配管 |
| 承插焊 SW | RF | DN15~50，Class150~900 | ≤DN50、非剧烈循环 |
| 带颈对焊 WN / 整体 IF | RF | DN15~1500（＞600 分 A/B），Class150~900 | 经常使用 |
| 带颈对焊 WN / 整体 IF | RJ | DN15~1500，Class600~2500 | 高温高压，≥Class600 |
| 各类型 | FF | DN15~600，Class150 | 与铸铁法兰（Class125）配合 |
| 各类型 | 凹凸面/榫槽面 | DN15~600，≥Class300 | 仅阀盖与阀体等内部连接，极少外接 |

- 接头两法兰压力-温度额定值不同时取较低者（3.1.5）
- 螺纹、对焊环松套法兰禁用于剧烈循环工况，应选带颈对焊或整体法兰（3.1.6）
- 螺纹、承插焊法兰禁用于缝隙腐蚀或严重腐蚀场合（3.1.7）
- Class150 钢法兰与铸铁法兰连接宜用 FF 密封面＋全平面非金属平垫片；用 RF＋突面垫片须控制上紧扭矩（3.1.8）
- 带颈对焊法兰端部厚度 ≤ 相应钢管名义厚度；钢管屈服强度＞275 MPa 且高于法兰材料时按比例减薄（3.1.10）
- 法兰盖开孔异径法兰：不作补强的最大允许开孔 DN2 按表 3.1.11（如 DN1 25~40→DN2 15、DN1 100~125→DN2 40）（3.1.11）

### 垫片选用（#L15517-#L15567）

- 聚四氟乙烯包覆垫禁用于真空或嵌入层材料易被介质腐蚀的场合；一般用 PMF，PMS 利于减少管内液体滞留，PFT 用于 ≥DN350（3.2.4）
- 石棉/柔性石墨垫片用于不锈钢、镍基合金法兰时氯离子 ≤50×10⁻⁶（3.2.5）
- 柔性石墨用于氧化性介质时 ≤450 ℃（3.2.6）
- 石棉、非石棉垫片禁用于极度/高度危害介质和高真空（3.2.7）
- 有冷流倾向的 PTFE 平垫片宜用全平面密封面或 ≤100 ℃（3.2.8）
- Class150 标准法兰用缠绕垫、金属包覆垫等半金属垫或金属环垫时，应选带颈对焊等刚性较大法兰（3.2.9）
- 非金属平垫片/缠绕垫内环内径大于法兰内径且要求齐平时：采用整体/对焊/承插焊法兰，或向垫片厂提供法兰内径定制（3.2.10）
- 垫片型式选用表 3.2.11 汇总各垫片 Class/DN/温度/密封面/粗糙度/法兰型式组合（3.2.11）

### 紧固件选用（#L15568-#L15620）

- 六角头螺栓仅适用于 ≤Class150（3.3.8）；低强度紧固件仅用于 ≤Class300＋非金属平垫片，禁用于剧烈循环（3.3.7）
- 高温用紧固件材料应与法兰材料热膨胀系数相近（3.3.6）
- 选配组合见 20635 表 3.3.1（螺栓/螺母形式-规格-材料-强度等级-公称压力-使用温度）与表 3.3.10（各 Class 下垫片类型与螺栓强度等级的搭配，标注 a/b 者应控制上紧扭矩）

### 法兰接头（#L15621-#L15638）

- 全平面法兰应采用橡胶、石棉橡胶板、非石棉纤维橡胶板、填充改性 PTFE 等非金属平垫片（3.4.2）
- 密封面之间只允许装一个垫片（3.4.4）
- 重要场合（高压、高温、极度/高度危害介质）应用扭矩扳手或其他控制螺栓载荷的装置，遵循规定紧固步骤（3.4.5）
- 螺母应完全旋入螺纹；未啮合螺纹 ≤1 个螺距（3.4.6）
- 高温/低温接头应计及管道推力、力矩与元件热膨胀引起的垫片密封载荷变化和应力松弛（3.4.7）

## 适用范围与边界

- 本页为 Class 系（20635）口径；PN 系选配按 HG/T 20614，规则精神相同、具体表号不同
- 危险工况（3.4.3）法兰与垫片、紧固件配合参考表 3.3.1 并确定上紧扭矩与上紧顺序
- 具体垫片性能数值见各垫片页，本页只给选配规则

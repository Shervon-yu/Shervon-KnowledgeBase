# 连续流反应器的流动模型族

## 为什么用多区模型

低速搅拌或高黏液体中，不完全混合会出现**停滞区**与**沟流短路**；直接解 N-S 不可能，于是把容器切成几个"完全混合区 + 停滞区 + 活塞流"的组合（`#L5978`）。

## 四个代表模型

| 模型 | 切法 | 参数 | 适用 |
|:---|:---|:---|:---|
| Cholette–Cloutier（图5.4） | 完全混合区 $M$（容积分数 $m$）+ 停滞区 $S$ + 沟流（分数 $1-f$） | $m$、$f$ | 低速/高黏，有短路 |
| Inoue 等（图5.5） | 四区（1/2/3/4），叶轮输出流撞壁后分上下两路，分别经拟自由涡区与强制涡区返回叶轮 | 各区容积与流量 | **无挡板**间歇釜（有 CRZ） |
| Van de Vusse（图5.6） | 流线 1（进料）→ 流线 2（出料），流线 3 循环；每条行程用 $n$ 级串联 CSTR 代替 | 串联罐数 $n$、一阶平均停留时间 $T_c$ | 多层叶轮组（Sato 等应用） |
| Takamatsu–Sawada（图5.7、5.8） | 按流区分段：高黏区（停滞 A + 活塞 B）、过渡区（活塞 B + 完全混合 C）、湍流区（停滞 + CRZ $D$ + 沟流 $E$） | 各区容积分数 $V_d/V_P/V_b/V_k$ | 从低黏到高黏**全域** |

Takamatsu 的价值在于把 Cholette 的适用范围从低黏扩到高黏，并用改变 $Re$ 的方法定量求出各区容积分数（`#L6012`、`#L6016`）。

## 单参数混合指数

Otto 等用脉冲响应的一阶矩、二阶矩、三阶矩定义一个混合指数（`#L6036`、`#L6040`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\zeta=\dfrac{\tau_{1}^{2}}{\tau_{2}}$ | （5.12） |
| **文字式** | $\text{混合指数}=\dfrac{\text{平均停留时间}^{2}}{\text{停留时间方差}}$ |  |

判据（`#L6048`）：

- $\zeta=1$ → 完全混合（CSTR 的 $\tau_1=\theta$、$\tau_2=\theta^{2}$，恰好得 1）；
- $\zeta=\infty$ → 活塞流（方差为 0）；
- 一般 $\zeta>1$ → 非理想流。

**实测教训**：即使搅拌很强（$Re=31500$），$\zeta$ 也只到 1.61，始终不等于 1（`#L6048`）——真实釜永远有残余返混，做不到理想完全混合。

> OCR 提示：原书式(5.12) 印作 $(\tau_1/\tau_2)^2$，量纲不成立；按"$\zeta=1$ 对应完全混合、$\infty$ 对应活塞流"的原文判据，应为 $\tau_1^2/\tau_2$。

## 该选哪个

作者的取舍标准（`#L6054`、`#L6056`）：**用最少参数、能拟合观测数据的模型**。多区模型参数多、分析复杂，只适合"理解混合状态"；用于放大与设计时应选**单参数**的三个：

1. 扩散模型（活塞流 + 少量返混叠加）；
2. 串联 CSTR；
3. 完全混合流与活塞流的组合模型。

# 颗粒与流体的相对运动阻力

## 曳力（`#L4585-#L4593`）

流体绕过静止颗粒、或颗粒在静止流体中运动，都会因流体黏性产生作用力，统称**曳力**（drag force）或阻力。

关键性质：只要颗粒与流体有相对运动就产生阻力；**对一定颗粒与流体，相对速度相同则阻力相同**——不论哪一方在动。

## 计算式（`#L4593-#L4599`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $F_d=\zeta A\dfrac{\rho u^2}{2}$ | （3-1） |
| **文字式** | $\text{阻力}_{\text{【N】}}=\text{阻力系数}\times\text{颗粒投影面积}_{\text{【m²】}}\times\dfrac{\text{流体密度}\times\text{相对速度}^2}{2}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\zeta=\phi(Re)=\phi(d_pu\rho/\mu)$ | （3-2） |
| **文字式** | $\text{阻力系数}=\text{雷诺数的函数}$，$\text{雷诺数}=\dfrac{\text{颗粒直径}\times\text{相对速度}\times\text{流体密度}}{\text{流体黏度}}$ |  |

$A$ 为颗粒在运动方向上的投影面积，球形颗粒 $A=\pi d_p^2/4$。

## 三分区（`#L4603-#L4617`）

| 区 | Re 范围 | $\zeta$ | 名称 |
|:---|:---|:---|:---|
| 层流区 | $10^{-4}<Re<2$ | $\zeta=24/Re$ | 斯托克斯（Stokes）区 |
| 过渡区 | $2<Re<500$ | $\zeta=10/\sqrt{Re}$ | 阿仑（Allen）区 |
| 湍流区 | $500<Re<2\times10^5$ | $\zeta=0.44$ | 牛顿（Newton）区 |

**斯托克斯区的式子是准确的**（理论推导可得）；其他两区的式子是近似的（实验拟合）。

## 判断

- 三个区的物理含义：层流区黏性力主导、ζ∝1/Re；湍流区惯性力（涡流）主导、ζ≈常数；过渡区两者并存。
- 后续所有沉降公式都是"3-11 + 某一区的 ζ"联立的结果，所以分区判据决定了用哪条公式，也决定了是否需要试差（因为 Re 含待求的 $u_t$）。

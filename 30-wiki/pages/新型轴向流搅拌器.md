# 新型轴向流搅拌器

## 开发背景

每种搅拌器都只在特定范围内高效，各国一直致力于开发高效、节能、造价低、易大型化的**轴向流**搅拌器，典型代表是 LIGHTNIN 的 A310、A315 等（`#L5366`；图5-16）。

## 关键指标：叶片投影面积覆盖率

轴向流叶轮注重"叶片在水平投影面上所占叶端圆面积的百分数"，称**叶片投影面积覆盖率**，作为区分与选用叶轮的指标（`#L5386`）：

| 叶轮 | 覆盖率 |
|:---|:---:|
| 常用 45° 四斜叶涡轮 | 43% |
| A310 | 22% |
| A320 | 67% |
| A315 | 87% |

规律：覆盖率越大，轮毂处叶片倾角越大，越适合较高黏度液体 → **A310 只适合低黏**；A315 倾角不大但叶片面积大，大叶片像圆盘涡轮的圆盘一样阻止气体穿过，延长气液接触时间，故适用于气-液体系（`#L5386`）。

## 各叶轮要点

| 叶轮 | 特点 |
|:---|:---|
| A310 | 钢板按规律弯曲成型，不需铣削或精密铸造；三叶片螺栓固定或焊接；小型可铸造；适合均相混合、固液悬浮——同样悬浮效果比传统 45° 斜叶涡轮**节能 50%** |
| A315 | 适合气液发酵体系；大型已用于几百 m³ 发酵设备；分散能力不如圆盘涡轮，常与圆盘涡轮组合（底层圆盘涡轮 + 上层 A315），能耗低、混合好 |
| A6000 | 叶片像机翼、曲线形；耐蚀高强、强度重量比高的玻璃纤维复合材料；同功耗下排量比 A310 大 30% |
| INTERPRO（EKATO） | 主叶片上增加辅助叶片，消除主叶片后方流动剥离，降低功率；可用于数千 m³ 大型固液悬浮 |
| HPM（ROBIN） | 轮毂处倾角 45°、叶端约 17°（变倾角）；可用于数百 m³ 大型搅拌槽 |

（`#L5366-#L5392`）

## 判断

新型轴流桨的节能来源有两条：**一是变倾角/弯曲叶片减少流动分离**（A310、A6000、HPM），**二是用大投影面积代替高转速**（A315）。前者降功耗，后者在低转速下维持循环与持气——发酵罐大型化正是靠后者。

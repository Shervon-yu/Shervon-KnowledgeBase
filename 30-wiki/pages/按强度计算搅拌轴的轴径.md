# 按强度计算搅拌轴的轴径

## 强度条件

搅拌轴同时承受**扭转与弯矩**，按第三强度理论合成当量扭矩（`#L11697-#L11713`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau_{\max}=\dfrac{M_{te}}{W_{p}}\le[\tau]$ | （9-36） |
| **文字式** | $\text{最大剪应力}_{\text{【MPa】}}=\dfrac{\text{当量扭矩}_{\text{【N}\cdot\text{m】}}}{\text{抗扭截面模量}_{\text{【m}^{3}\text{】}}}\le\text{许用剪应力}_{\text{【MPa】}}$ |  |

其中：

- 当量扭矩 $M_{te}=\sqrt{M_{n}^{2}+M^{2}}$，$M_{n}$ 为按传动效率算的传递扭矩，$M$ 为弯矩总和；
- 弯矩总和 $M=M_{A}+M_{R}$（9-37）：$M_{A}$ 由轴向推力引起、$M_{R}$ 由径向力引起；
- 抗扭截面模量（空心圆轴）$W_{p}=\dfrac{\pi d^{3}}{16}(1-N_{0}^{4})$；
- 许用剪应力 $[\tau]=\sigma_{b}/16$，或按表9-96 取。

## 轴径公式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{2}=17.2\left(\dfrac{M_{te}}{[\tau](1-N_{0}^{4})}\right)^{\frac{1}{3}}$ | （9-38） |
| **文字式** | $\text{轴径}_{\text{【mm】}}=17.2\times\left(\dfrac{\text{当量扭矩}_{\text{【N}\cdot\text{m】}}}{\text{许用剪应力}_{\text{【MPa】}}\times(1-\text{空心比}^{4})}\right)^{\frac{1}{3}}$ |  |

## 许用剪应力（表9-96）

| 材料 | Q235-A、20 | 35 | 45 | 10Cr（调质） | 1Cr13（退火） | 2Cr13（退火） | 1Cr18Ni9Ti |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| $[\tau]$/MPa | 12~20 | 20~30 | 30~40 | 40~52 | 18~24 | 40~50 | 15~25 |

## 计算顺序（关键）

1. 先按式（9-49）/（9-50）**粗算** $M_{A}$（见 [[搅拌轴轴向推力弯矩与轴向合力]]），加上 $M_{R}$ 得 $M$，代入式（9-38）得**初算 $d_{2}$**；
2. 用初算 $d_{2}$ 计算精确的 $M_{A}$（式9-51/9-52）；
3. 若精确 $M_{A}$ **大于**粗略值 → 返回式（9-37）重算 $M$ 与 $d_{2}$；小于则不必重算（`#L11953`）。

**为什么**：$M_{A}$ 的精确式要含轴径 $d$（回转半径 $I_{0}$）、压缩系数 $K_{B}$，与 $d_{2}$ 互为隐式，只能迭代一次收敛。

## 使用要点

- $d_{2}$ 的含义：悬臂轴为**搅拌侧轴承处**轴径，单跨轴为**跨间段**轴径（符号说明 `#L11323`）。
- 实心轴 $N_{0}=0$；空心轴代入内外径比。
- 强度算出的 $d_{2}$ 还要与扭转 $d_{1}$、临界转速所需轴径、轴封位移允许轴径比较，取最大后加腐蚀裕量并圆整（`#L11435`）。

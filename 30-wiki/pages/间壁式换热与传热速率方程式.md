# 间壁式换热与传热速率方程式

## 间壁式换热器（`#L5736-#L5742`）

冷热两流体被壁面隔开、通过壁面换热。最简单的是**套管式**：两直径不同的直管套在一起，一种流体走内管，另一种走环隙；内管壁表面积即传热面积。

$$A=\pi d l$$

热流体温度 $T_1\to T_2$，冷流体 $t_1\to t_2$。

## 两个基本量（`#L5744-#L5748`）

| 量 | 定义 | 单位 |
|:---|:---|:---|
| 传热速率 $Q$（热流量） | 单位时间通过传热面传递的热量 | W（J/s） |
| 热流密度 $q$（热通量） | 单位时间通过单位传热面积的热量 | W/m² |

$$q=Q/A$$

## 稳态与非稳态（`#L5750-#L5754`）

- 稳态传热：物体中各点温度不随时间变化，同一热流方向上传热速率为常量；
- 非稳态传热：温度随时间变化（开车、停车、改变操作条件时）。

连续生产中的传热多为稳态；本章只讨论稳态。

## 三过程串联（`#L5756-#L5766`）

冷热流体通过间壁的传热由三个过程串联：

1. 热流体以**对流**把热量传给壁面一侧；
2. 热量以**导热**从一侧壁面传到另一侧壁面；
3. 壁面以**对流**把热量传给冷流体。

流体与壁面之间的传热以对流为主、伴有分子导热，统称**对流传热**（convective heat transfer）。

## 传热速率方程式（`#L5774-#L5784`）

推动力是两流体温度差；沿管长温差不同，故用平均温度差 $\Delta t_m$（K 或 ℃）。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=KA\Delta t_m=\dfrac{\Delta t_m}{\dfrac{1}{KA}}$ | （4-1） |
| **文字式** | $\text{传热速率}_{\text{【W】}}=\text{总传热系数}\times\text{传热面积}\times\text{平均温度差}=\dfrac{\text{平均温度差}}{\text{热阻}}$ |  |

- $K$：总传热系数，W/(m²·K)，包含对流与导热两方面的影响；
- 传热三要素：$K$、$A$、$\Delta t_m$。

## 判断

- 把 $1/(KA)$ 记成"热阻"，是把电学欧姆定律的直觉移植到传热：串联热阻相加、总推动力分配，后续总传热系数的倒数叠加式正是这一直觉的展开。
- 式(4-1)本身不含机理，它是"定义式+比例式"；真正的工程内容全在 $K$ 里，所以第二、三节先分别解决导热与对流，第四节再合成 $K$。

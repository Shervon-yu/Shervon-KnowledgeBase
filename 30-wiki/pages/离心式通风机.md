# 离心式通风机

## 工作原理与结构（`#L4067-#L4095`）

原理同离心泵：气体经旋转叶轮，离心力使静压与速度均升高；进机壳流道后流速减慢、动能转静压，进一步提高静压。

机壳为蜗壳形，流道有矩形（低、中压）与圆形（高压）两种。一般为单级，按叶片分两类：

| 型式 | 叶片 | 特点 | 用途 |
|:---|:---|:---|:---|
| 多翼式 | 前弯、36~64 片，径向短、宽度约为叶轮外径 1/2，内外径比大 | 尺寸小、大风量、低风压、低转速、功率与噪声小 | 通风换气、空调 |
| 涡轮式 | 后弯、12~24 片，较长 | 风压较高、性能稳定、效率较高 | 应用最广 |

## 性能参数（`#L4099-#L4207`）

### 1. 风量（`#L4101-#L4109`）

单位时间流过风机进口的气体体积，$q_V$（m³/s、m³/min、m³/h）。通风机内压力变化小、可忽略压缩性，故体积流量在机内各处基本相同。

性能表上的风量是标定条件（20 ℃、101.3 kPa）下的值 $q_{V0}$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{V0}=q_V\dfrac{\rho}{\rho_0}$ | （2-20） |
| **文字式** | $\text{标定风量}=\text{操作风量}\times\dfrac{\text{操作密度}}{\text{标定空气密度}_{\text{【1.2 kg/m³】}}}$ |  |

### 2. 风压（`#L4111-#L4175`）

**全风压** $p_t$：单位体积气体经风机获得的总机械能，单位 Pa（=J/m³）。

在进、出口截面间列伯努利方程（忽略位差与阻力），压头式：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=\dfrac{p_{s2}-p_{s1}}{\rho g}+\dfrac{u_2^2-u_1^2}{2g}$ | （2-21） |
| **文字式** | $\text{风机压头}_{\text{【m气柱】}}=\dfrac{\text{出口静压}-\text{进口静压}}{\text{密度}\times\text{重力加速度}}+\dfrac{\text{出口流速}^2-\text{进口流速}^2}{2\times\text{重力加速度}}$ |  |

乘 $\rho g$ 得全风压：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_t=(p_{s2}+p_{d2})-(p_{s1}+p_{d1})$ | （2-24） |
| **文字式** | $\text{全风压}_{\text{【Pa】}}=\text{出口全压}-\text{进口全压}$ |  |

其中动压 $p_d=\rho u^2/2$。三者关系：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_t=p_{st}+p_d,\qquad p_d=p_{d2},\qquad p_{st}=(p_{s2}-p_{s1})-p_{d1}$ | （2-25） |
| **文字式** | $\text{全风压}=\text{静风压}+\text{动风压}$；$\text{动风压}=\text{出口动压}$；$\text{静风压}=(\text{出口静压}-\text{进口静压})-\text{进口动压}$ |  |

**密度换算**：$H$ 一定时 $p_t\propto\rho$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_t'=p_t\dfrac{\rho'}{\rho},\qquad p_{t0}=p_t\dfrac{1.2}{\rho}$ | （2-26）（2-27） |
| **文字式** | $\text{新密度下全风压}=\text{原全风压}\times\dfrac{\text{新密度}}{\text{原密度}}$；$\text{标定全风压}=\text{操作全风压}\times\dfrac{1.2}{\text{操作密度}}$ |  |

选风机前必须把操作条件下的 $p_t$ 换算成标定条件下的 $p_{t0}$ 才能查性能表。**操作密度越大 → 标定全风压越小**。

### 3. 功率与效率（`#L4195-#L4207`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_e=p_tq_V,\qquad P=\dfrac{P_e}{\eta}$ | （2-28）（2-29） |
| **文字式** | $\text{有效功率}_{\text{【W】}}=\text{全风压}_{\text{【Pa】}}\times\text{风量}_{\text{【m³/s】}}$；$\text{轴功率}=\dfrac{\text{有效功率}}{\text{全风压效率}}$ |  |

计功率时用"操作条件的 $q_V$ 与 $p_t$"或"标定条件的 $q_{V0}$ 与 $p_{t0}$"，结果相同。

## 例2-7（`#L4177-#L4187`）

入口 $p_{s1}$=−368 Pa、$p_{d1}$=64 Pa；出口 $p_{s2}$=186 Pa、$p_{d2}$=123 Pa：

$$p_t=(186+123)-(-368+64)=613\ \text{Pa},\qquad p_{st}=613-123=490\ \text{Pa}$$

## 例2-8（`#L4189-#L4193`）

$\rho$=1.2 kg/m³ 时 $p_t$=600 Pa；改送 $\rho'$=1.0 kg/m³：$p_t'=600\times1.0/1.2=500$ Pa。

## 判断

- 进口静压为**负**是通风机的常态（吸入口处于负压），这是例2-7 里出现"减负得加"的原因，也是全风压可能远大于单侧读数的地方。
- 密度换算是选型最容易出错的一步：样本给的是 1.2 kg/m³ 的空气值，输送热烟气或富氧气体时必须先换算。

# 亨利系数的关系与温度压力影响

## m 与 E（`#L8834-#L8846`）

由分压定律 $p_A^{*}=py^{*}$ 代入 $p_A^{*}=Ex$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $m=\dfrac{E}{p}$ | （5-8） |
| **文字式** | $\text{相平衡常数}=\dfrac{\text{亨利系数}_{\text{【kPa】}}}{\text{总压}_{\text{【kPa】}}}$ |  |

推论：
- 总压 $p$ 增大 → $m$ 减小；
- 温度降低 → $E$ 减小 → $m$ 减小；
- $m$ 减小意味着同样 $y$ 下 $x$ 增大 → **对吸收有利**。故"**降温、加压**"是吸收的两个基本手段。

## H 与 E（`#L8848-#L8880`）

由 $p_A^{*}=Ex$ 与 $p_A^{*}=c_A/H$ 联立，且 $c_A=cx$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $H=\dfrac{c}{E}$，稀溶液 $H\approx\dfrac{\rho_s}{EM_s}$ | （5-9a）（5-9b） |
| **文字式** | $\text{溶解度系数}=\dfrac{\text{溶液总浓度}_{\text{【kmol/m}^3\text{】}}}{\text{亨利系数}_{\text{【kPa】}}}$，稀溶液用$\dfrac{\text{溶剂密度}}{\text{亨利系数}\times\text{溶剂摩尔质量}}$ |  |

要点：
- $c$ 为溶液总浓度 = $\rho/M$（$M$ 为溶液平均摩尔质量）；
- 稀溶液时溶剂浓度近似等于溶液总浓度，于是用 $\rho_s/M_s$；
- 所以 H 与 E 成反比，与溶剂的密度/摩尔质量有关——**同一气体换溶剂，E 不变但 H 会变**。

## 三者统一关系（`#L8882-#L8886`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $E=mp\approx\dfrac{\rho_s}{HM_s}$ | （5-8 与 5-9b 合成，书内未编号） |
| **文字式** | $\text{亨利系数}_{\text{【kPa】}}=\text{相平衡常数}\times\text{总压}_{\text{【kPa】}}\approx\dfrac{\text{溶剂密度}_{\text{【kg/m}^3\text{】}}}{\text{溶解度系数}\times\text{溶剂摩尔质量}_{\text{【kg/kmol】}}}$ |  |

## 温度、压力影响的完整链条

| 变量 | 变化 | E | H | m | 对吸收 |
|:--|:--|:--|:--|:--|:--|
| 温度 | 升高 | ↑ | ↓ | ↑ | 不利 |
| 温度 | 降低 | ↓ | ↑ | ↓ | 有利 |
| 总压 | 升高（y 不变） | 不变 | 不变 | ↓ | 有利 |
| 总压 | 降低 | 不变 | 不变 | ↑ | 不利（解吸有利） |

注意：E、H 是**温度的函数**，与总压无关；只有 m 同时含温度与总压的影响（$m=E/p$）。这一点是判断"改变压力能不能改变平衡"的关键——加压只改变 m，不改变 E。

## 判断

- 换算时先判"稀溶液"：只有稀溶液才能用 $H\approx\rho_s/(EM_s)$；浓溶液必须用 $H=c/E$，否则误差可达百分之几十。
- "降温加压有利吸收"这句话要拆开：降温动的是 E（溶质-溶剂本性），加压动的是 m（气相分压与总压之比）。所以对难溶气体（E 极大），单靠加压往往不够，还要降温或改化学吸收。

# 对流传质-吸收系数与总传质系数

## 定义

湍流流体与界面之间的传质称**对流传质**，用「通量 = 系数 × 推动力」描述（#L9328）。按**双膜模型**，界面两侧各有一层停滞膜，膜内为分子扩散；界面处气液两相达到平衡（#L9396 的 $p_{Ai}$ 与 $c_{Ai}$ 满足亨利定律）。用气相分压差写的系数记 $k_{G}$（#L9338），用液相浓度差写的记 $k_{L}$（#L9354）；用摩尔分数、摩尔比的写法相应记 $k_{y}$、$k_{Y}$、$k_{x}$、$k_{X}$（#L9398、#L9400、#L9410、#L9412）。

把界面浓度消去、改用**相平衡浓度**作推动力，得到**总传质系数** $K_{Y}$、$K_{X}$（#L9474、#L9510）。气相总阻力 = 气膜阻力 + 液膜阻力折算值（#L9480）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{A}}=k_{G}\left(p_{\mathrm{A}}-p_{\mathrm{Ai}}\right)=\dfrac{p_{\mathrm{A}}-p_{\mathrm{Ai}}}{\dfrac{1}{k_{G}}}$ | （5.3-4） |
| **文字式** | $\text{传质通量}_{\text{【mol/(m²·s)】}}=\text{气膜吸收系数}_{\text{【mol/(m²·s·Pa)】}}\times\left(\text{气相主体A分压}_{\text{【Pa】}}-\text{界面A分压}_{\text{【Pa】}}\right)$ |  |

（式 5-21、5-25，#L9338、#L9396；$1/k_{G}$ 为气膜阻力。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{A}}=k_{L}\left(c_{\mathrm{Ai}}-c_{\mathrm{A}}\right)$ | （5.3-5） |
| **文字式** | $\text{传质通量}_{\text{【mol/(m²·s)】}}=\text{液膜吸收系数}_{\text{【m/s】}}\times\left(\text{界面A浓度}_{\text{【mol/m³】}}-\text{液相主体A浓度}_{\text{【mol/m³】}}\right)$ |  |

（式 5-23、5-28，#L9354、#L9408。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{A}}=K_{Y}\left(Y-Y^{*}\right)$，$\dfrac{1}{K_{Y}}=\dfrac{1}{k_{Y}}+\dfrac{m}{k_{X}}$ | （5.3-6） |
| **文字式** | $\text{传质通量}_{\text{【mol/(m²·s)】}}=\text{气相总传质系数}\times\left(\text{气相摩尔比}-\text{与液相平衡的气相摩尔比}\right)$ |  |

（式 5-34、5-35，#L9474、#L9480；$m$ 为平衡线斜率。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{A}}=K_{X}\left(X^{*}-X\right)$，$\dfrac{1}{K_{X}}=\dfrac{1}{mk_{Y}}+\dfrac{1}{k_{X}}$，$K_{X}=mK_{Y}$ | （5.3-7） |
| **文字式** | $\text{传质通量}_{\text{【mol/(m²·s)】}}=\text{液相总传质系数}\times\left(\text{与气相平衡的液相摩尔比}-\text{液相摩尔比}\right)$ |  |

（式 5-38、5-39、5-40，#L9510、#L9516、#L9522。）

**控制步骤判据**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{m}{k_{X}}\gg\dfrac{1}{k_{Y}}\Rightarrow K_{Y}\approx k_{Y}$；$\dfrac{1}{k_{X}}\gg\dfrac{1}{mk_{Y}}\Rightarrow K_{X}\approx k_{X}$ | （5.3-8） |
| **文字式** | $\text{液膜阻力折算值远大于气膜阻力}\Rightarrow\text{总系数约等于气膜系数（气膜控制）}$ |  |

（式 5-41、5-42，#L9536、#L9560；$m$ 很大（易溶气体）时液膜阻力占优→气膜控制；$m$ 很小（难溶气体）→液膜控制。）

**系数换算**（同一状态的不同写法）：$k_{y}=pk_{G}$、$k_{x}=ck_{L}$、$K_{y}=pK_{G}$ 等（式 5-46，#L9588），以及 5-47~5-50 的摩尔比与摩尔分数换算（#L9592、#L9596、#L9598、#L9600）。

## 适用范围与边界

- 双膜模型假定界面处平衡、膜内稳态分子扩散、膜外完全湍流（#L9328、#L9396）；对高湍流度、界面更新快的系统偏差大，本书未给渗透/表面更新模型。
- $k_{G}$、$k_{L}$ 的绝对值须由实验关联式或经验式给出（本书 §5.3 只给定义与换算，未给 $Sh$ 关联式，这是本页的诚实边界）。
- 界面浓度 $(p_{Ai},c_{Ai})$ 须与平衡线联立求解（式 5-31，#L9424）；平衡线为直线时可用 $m$ 直接换算总系数。
- 式 5-41/5-42 是「阻力项相比」的近似判据，不是严格等式。

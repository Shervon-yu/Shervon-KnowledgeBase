锻制紧缩口封头不带成形封头的曲面，靠纵向截面的弯曲强度定尺寸：取轴线一侧的纵向截面，算弯矩 $M$、截面系数 $Z$，再校核弯曲应力（图7-26、图7-27，`#L7268`）。

## 一、结构与直边段（7.10.1，`#L7268-#L7274`）

- 直边段厚度按公式（5-1）计算，但**有效厚度不应小于与之对接的圆筒有效厚度**；
- 直边段长度 $l$ 一般不小于 50 mm；
- 其余尺寸一般按结构要求确定；
- 强度校核范围与内容见图 7-27（带直边 / 不带直边两种形式）。

## 二、纵向截面弯矩（式7-46，`#L7350-#L7371`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M=\dfrac{1}{6.28}\left[\left(\delta_e+\dfrac{1}{3}D_i\right)F_D-\left(D_b-\dfrac{2}{3}D_G\right)F-\left(D_b-D_G\right)F_p\right]-p_cA_nL_o$ | （7-46） |
| **文字式** | $\text{纵向截面弯矩}_{\text{【N·mm】}}=\dfrac{1}{6.28}\left[\left(\text{有效厚度}+\dfrac{1}{3}\text{封头内直径}_{\text{【mm】}}\right)\times\text{内径截面静压轴向力}_{\text{【N】}}-\left(\text{螺栓孔中心圆直径}_{\text{【mm】}}-\dfrac{2}{3}\text{垫片压紧力作用中心圆直径}_{\text{【mm】}}\right)\times\text{静压总轴向力}_{\text{【N】}}-\left(\text{螺栓孔中心圆直径}_{\text{【mm】}}-\text{垫片压紧力作用中心圆直径}_{\text{【mm】}}\right)\times\text{最小垫片压紧力}_{\text{【N】}}\right]-\text{计算压力}_{\text{【MPa】}}\times\text{内腔纵向截面面积}_{\text{【mm²】}}\times\text{两中性轴间距}_{\text{【mm】}}$ |  |

式中（`#L7373-#L7379`）：

$$F_D=0.785D_i^2p_c,\qquad F=0.785D_G^2p_c,\qquad F_p=6.28D_Gbm p_c,\qquad L_o=L_c-L_n,\qquad A_n=\sum A_{ni}$$

- $F_D$：作用于法兰内径截面上的流体静压轴向力；
- $F$：流体静压总轴向力（按垫片压紧力作用中心圆直径算）；
- $F_p$：操作状态下需要的最小垫片压紧力，含垫片系数 $m$ 与有效密封宽度 $b$（见第 9 章）；
- $L_o$：纵向截面中性轴与内腔纵向截面中性轴的距离；
- $A_n$：内腔纵向截面面积。

## 三、截面系数（式7-47、7-48，`#L7381-#L7400`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Z=\dfrac{I}{L_c}$（$L_c\ge\dfrac{H}{2}$）；$Z=\dfrac{I}{H-L_c}$（$L_c<\dfrac{H}{2}$） | （7-47）（7-48） |
| **文字式** | $\text{截面系数}_{\text{【mm³】}}=\dfrac{\text{纵向截面惯性矩}_{\text{【mm⁴】}}}{\text{形心离 }Y\text{-}Y\text{ 轴距离}_{\text{【mm】}}}$，形心偏高（$L_c\ge H/2$）时取形心距，形心偏低（$L_c<H/2$）时取最远端距离 $H-L_c$ |  |

$$I=2\left[\sum I_i+\sum\left(L_i^2A_i\right)\right],\qquad L_c=\frac{W}{A},\qquad W=\sum L_{ci}A_i$$

常用截面的 $A_i$、$S$、$I_i$ 查表 7-11（矩形 $bh$、梯形、三角形、半圆、1/4 圆等）。

## 四、弯曲应力校核（式7-49，`#L7401-#L7403`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_m=\dfrac{M}{Z}\le0.8[\sigma]^t$ | （7-49） |
| **文字式** | $\text{纵向截面弯曲应力}_{\text{【MPa】}}=\dfrac{\text{弯矩}_{\text{【N·mm】}}}{\text{截面系数}_{\text{【mm³】}}}\le0.8\times\text{设计温度下许用应力}_{\text{【MPa】}}$ |  |

## 判断

- **限值是 $0.8[\sigma]^t$，不是 $[\sigma]^t$**。锻制件截面厚、应力梯度大，规范留了 20% 余量，算漏这个 0.8 会偏危险。
- 校核对象是**纵向截面**（含螺栓孔削弱区），不是回转壳的薄膜应力；$F_p$ 里必须带垫片系数 $m$，否则弯矩偏小。
- $Z$ 的取法按 $L_c$ 与 $H/2$ 的大小分叉，取反了会高估截面系数（应力偏小）。$H$ 是**不包括直边段**的封头高度。
- 式（7-46）与 9.7 筒体端部的式（9-42）同构：都是「压力项 − 螺栓/垫片项 − 内腔压力矩」，可对照读。

# 汽蚀现象与汽蚀余量

## 现象（`#L3725-#L3739`）

以槽面 0—0 与泵入口 1—1 列伯努利方程：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{p_1}{\rho g}=\dfrac{p_0}{\rho g}-H_g-\dfrac{u_1^2}{2g}-\sum H_f$ | （2-12） |
| **文字式** | $\dfrac{\text{入口压力}_{\text{【Pa】}}}{\text{密度}\times\text{重力加速度}}=\dfrac{\text{槽面压力}_{\text{【Pa】}}}{\text{密度}\times\text{重力加速度}}-\text{安装高度}_{\text{【m】}}-\dfrac{\text{入口流速}^2}{2\times\text{重力加速度}}-\text{吸入管压头损失}$ |  |

安装高度越高、管内流速越大、损失越大 → $p_1$ 越小。当**叶轮入口最低压力点 K** 处压力降到该温度下的饱和蒸气压 $p_v$ 时：

1. 液体部分汽化、溶解气体解吸，生成大量小气泡；
2. 气泡随液体流到压力高于 $p_v$ 的区域时突然破裂，蒸气迅速凝结；
3. 周围液体以高速冲向气泡中心，产生很高局部冲击压力，冲击叶轮，伴随噪声与振动；
4. 金属表面在压力冲击 + 气泡内氧气等活泼气体的电化学腐蚀下，呈海绵状、鱼鳞状剥蚀。

这种现象称**汽蚀**（cavitation）。轻微汽蚀对工作无明显影响；发展到一定程度后，液体流动连续性遭破坏，**流量、扬程、效率均明显下降**，不能正常操作。

## 有效汽蚀余量 $\Delta h_a$（`#L3749-#L3755`）

液体到达泵入口时的压头，除克服阻力推进叶轮外，还应高于饱和蒸气压头，其差值：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta h_a=\left(\dfrac{p_1}{\rho g}+\dfrac{u_1^2}{2g}\right)-\dfrac{p_v}{\rho g}$ | （2-13） |
| **文字式** | $\text{有效汽蚀余量}_{\text{【m】}}=\left(\dfrac{\text{入口压力}}{\text{密度}\times\text{重力加速度}}+\dfrac{\text{入口流速}^2}{2\times\text{重力加速度}}\right)-\dfrac{\text{饱和蒸气压}}{\text{密度}\times\text{重力加速度}}$ |  |

特点：**由吸入管路条件决定（安装高度、管径、流速、损失），与泵本身无关**。安装高度越高、$H_f$ 越大，$\Delta h_a$ 越小。

## 必需汽蚀余量 $\Delta h_r$（`#L3757-#L3773`）

液体从泵入口流到叶轮内最低压力点 K 的全部压头损失。**由泵结构与流量决定**：同一台泵流量不变则 $\Delta h_r$ 不变。

判据：

| 条件 | 结果 |
|:---|:---|
| $\Delta h_a>\Delta h_r$ | $p_K>p_v$，不汽蚀 |
| $\Delta h_a=\Delta h_r$ | $p_K=p_v$，开始汽蚀 |
| $\Delta h_a<\Delta h_r$ | $p_K<p_v$，严重汽蚀 |

## 允许汽蚀余量（`#L3789-#L3799`）

$\Delta h_r$ 只能实验测定。为保证安全，加 0.3 m 余量作为**允许汽蚀余量**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta h=\Delta h_r+0.3$ | （2-17） |
| **文字式** | $\text{允许汽蚀余量}_{\text{【m】}}=\text{必需汽蚀余量}_{\text{【m】}}+0.3$ |  |

泵样本规格表中列的"汽蚀余量"就是 $\Delta h$。操作中不产生汽蚀的条件是 $\Delta h_a\ge\Delta h$。

## 判断

- 两个余量的分工是理解本题的关键：$\Delta h_a$ 是"管路给得起多少"，$\Delta h_r$ 是"泵需要多少"，前者随安装高度变化、后者是泵的固有属性。
- 0.3 m 安全余量是书给的工程经验值，不是物理常数。

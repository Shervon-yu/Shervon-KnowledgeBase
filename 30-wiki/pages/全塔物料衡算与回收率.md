# 全塔物料衡算与回收率

## 衡算式（`#L11440-#L11458`）

连续精馏塔：进料 $F$、馏出液 $D$、釜液 $W$（kmol/s 或 kmol/h），组成 $x_F$、$x_D$、$x_W$（易挥发组分摩尔分数）。

|  |  |  |
|:---|:---:|--:|
| **符号式** | $F=D+W$，$Fx_F=Dx_D+Wx_W$ | （6-16）（6-17） |
| **文字式** | $\text{总物料}=\text{馏出液}+\text{釜液}$；$\text{进料中易挥发组分}=\text{馏出液中}+\text{釜液中}$ |  |

解得采出率：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{D}{F}=\dfrac{x_F-x_W}{x_D-x_W}$，$\dfrac{W}{F}=\dfrac{x_D-x_F}{x_D-x_W}$ | （6-18）（6-19） |
| **文字式** | $\text{馏出液采出率}=\dfrac{\text{进料组成}-\text{釜液组成}}{\text{馏出液组成}-\text{釜液组成}}$ |  |

## 两条推论（`#L11464-#L11468`）

1. 若 $x_D$、$x_W$ 已知 → 可求 $D$、$W$；
2. $D$、$W$、$x_D$、$x_W$ 四个量中，已知**一个流量 + 一个组成** → 可求另一个流量与组成。

## 回收率（`#L11470-#L11478`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\eta_A=\dfrac{Dx_D}{Fx_F}$，$\eta_B=\dfrac{W(1-x_W)}{F(1-x_F)}$ | （6-20）（6-21） |
| **文字式** | $\text{易挥发组分回收率}=\dfrac{\text{馏出液量}\times\text{馏出液组成}}{\text{进料量}\times\text{进料组成}}$；难挥发组分同理 |  |

## 例6-4（`#L11480-#L11500`）

正戊烷-正己烷，$F$=5000 kg/h、$x_F$=0.4、$x_D$=0.95、$x_W$=0.05。

- 平均摩尔质量 $M=0.4\times72+0.6\times86=80.4$ kg/kmol；
- $F=5000/80.4=62.2$ kmol/h；
- $D=62.2\times\frac{0.4-0.05}{0.95-0.05}=24.2$ kmol/h；
- $W=62.2-24.2=38$ kmol/h；
- $\eta_A=\frac{24.2\times0.95}{62.2\times0.4}=0.924$（92.4%）。

## 判断

- 物料衡算与分离难度**无关**：只要给定两端组成，采出率就定死了——塔板数再多也不能改变 $D/F$。这是"衡算优先、速率其次"的典型。
- 回收率与产品纯度是两个独立指标：$\eta_A$ 高只说明易挥发组分收得多，不代表 $x_D$ 高（可通过加大回流同时提高，但代价是能耗）。
- 进料质量流量换算成摩尔流量是必做第一步，忽略摩尔质量换算是最常见的错。

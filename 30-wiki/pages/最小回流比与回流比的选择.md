# 最小回流比与回流比的选择

## 定义（`#L12308-#L12320`）

R 减小 → 两操作线向平衡线靠近 → 板数增多。当交点 P 落在平衡线上时，在 P 点附近汽液组成不再变化（**恒浓区**），需要无穷多梯级才能达到分离要求。

这时的回流比即**最小回流比** $R_{\min}$；P 点称**夹点**（pinch point）。

## 计算式（`#L12322-#L12336`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $R_{\min}=\dfrac{x_D-y_P}{y_P-x_P}$ | （6-51） |
| **文字式** | $\text{最小回流比}=\dfrac{\text{馏出液组成}-\text{夹点汽相组成}}{\text{夹点汽相组成}-\text{夹点液相组成}}$ |  |

$(x_P,y_P)$ 是 q 线与平衡曲线的交点：可作图读出，也可联立 q 线方程与相平衡方程求解。

**非理想物系**（平衡曲线下凹，如乙醇-水）：操作线先与平衡线**相切**于 P，此时式（6-51）仍适用，但 $(x_P,y_P)$ 改取 q 线与精馏段操作线交点 f 的坐标；也可读精馏段截距 $x_D/(R_{\min}+1)$ 反算。

## 例6-14（`#L12338-#L12378`）

正戊烷-正己烷，$x_F$=0.4、$x_D$=0.98、$\alpha$=2.92：

| 进料状态 | q | $(x_P,y_P)$ | $R_{\min}$ |
|:--|:--|:--|:--|
| 冷液 | 1.2 | (0.451, 0.706) | **1.07** |
| 饱和液体 | 1 | (0.4, 0.66) | **1.23** |
| 汽液混合物（55 ℃） | 0.65（杠杆定律） | (0.309, 0.565) | **1.36** |

结论：进料越热（q 越小），$R_{\min}$ 越大——因为热进料使 q 线更平，交点 P 更靠近平衡线。

## 回流比的选择（`#L12380-#L12440`）

操作回流比介于 $R_{\min}$ 与 $\infty$ 之间。工程取：

$$R=(1.1\sim2.0)R_{\min}$$

- $R/R_{\min}$ 太小：板数急增（靠近夹点，板数对 R 极敏感）；
- 太大：$Q_C$、$Q_B$ 线性增大，操作费上升；
- 经济最优点：**总费用（设备折旧 + 操作费）最低**处，通常在 $R/R_{\min}=1.1\sim1.5$，具体由优化算。

## 判断

- 夹点的物理含义是"该处汽液两相已达平衡、再传质也无增浓"——所以再多板也无用，板数趋于无穷。
- $R_{\min}$ 随进料热状态变化：饱和蒸气进料 $R_{\min}$ 最大、冷液进料最小，这与"q 线方位"的几何一致。
- 工程上不会取 $R=R_{\min}$（板数无穷），也不会取全回流（无产品），而是取某个倍数；倍数由费用优化定。
- 非理想物系的 $R_{\min}$ 必须按"切点"算，用 q 线交点会低估。

# 板式塔-板效率与塔高

## 定义

理论板是理想化的平衡级，实际塔板上的汽液接触时间有限、混合不完全，故实际板数大于理论板数。**全塔效率** $E_{0}$ 为理论板数与实际板数之比（式 6-67，#L13113）。**默弗里板效率**（Murphree efficiency）按单板的实际增浓与平衡增浓之比定义（气相 $E_{MV}$、液相 $E_{mL}$，式 6-68、6-69，#L13139、#L13145）。

塔高由实际板数与**板间距** $H_{T}$ 决定（式 6-70，#L13169）。降液管尺寸须保证液体有足够停留时间脱气（式 6-65，#L12967）。

## 判据 / 计算

|  |  |  |
|:---|:---:|---:|
| **符号式** | $E_{0}=\dfrac{N_{\text{理}}}{N_{\text{实}}}$ | （6.6-1） |
| **文字式** | $\text{全塔效率}=\dfrac{\text{理论板数}}{\text{实际板数}}$ |  |

（式 6-67，#L13113。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $E_{\mathrm{MV}}=\dfrac{y_{n}-y_{n+1}}{y_{n}^{*}-y_{n+1}}$ | （6.6-2） |
| **文字式** | $\text{气相默弗里板效率}=\dfrac{\text{离开该板的气相组成}-\text{进入该板的气相组成}}{\text{与离开该板液相平衡的气相组成}-\text{进入该板的气相组成}}$ |  |

（式 6-68，#L13139；液相形式 $E_{mL}=\frac{x_{n-1}-x_{n}}{x_{n-1}-x_{n}^{*}}$，式 6-69，#L13145。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Z=N_{\text{实}}\cdot H_{\mathrm{T}}$ | （6.6-3） |
| **文字式** | $\text{塔高}_{\text{【m】}}=\text{实际板数}\times\text{板间距}_{\text{【m】}}$ |  |

（式 6-70，#L13169；$H_{T}$ 常取 300~500 mm，须满足降液管液封与液泛气速要求，具体取值见本节塔径/液泛计算。）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\text{停留时间}=\dfrac{\text{降液管截面积}\times\text{降液管中液体高度}}{\text{液体体积流量}}$ | （6.6-4） |
| **文字式** | $\text{降液管停留时间}_{\text{【s】}}=\dfrac{\text{降液管截面积}_{\text{【m²】}}\times\text{降液管液层高度}_{\text{【m】}}}{\text{液相体积流量}_{\text{【m³/s】}}$ |  |

（式 6-65，#L12967；停留时间过短则气泡来不及分离，易液泛。）

## 适用范围与边界

- $E_{0}$ 是经验值，通常 0.3~0.7，随物系表面张力、黏度、板型变化（#L13113 的语境）；本书未给 $E_{0}$ 的通用关联式。
- 默弗里效率只描述单板，不等于全塔效率；两者关系须逐板累加（#L13139 的推导前提）。
- 式 6-70 的塔高不含塔顶空间、塔底釜液空间与裙座。
- 液泛、雾沫夹带、漏液等水力学限制决定 $H_{T}$ 与塔径，本页只给停留时间判据，未展开负荷性能图（#L12967 之后为水力学计算）。

# 湍流微尺度与能谱

## 从相关系数到微尺度

湍流是统计连续场：相距 $r$ 的两点速度相关张量 $Q_{ij}(r)=\overline{u_i(X)u_j(X+r)}$（式3.12）。各向同性时用两个标量表示（`#L3990`、`#L3994`、`#L4002`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $f(r)=\dfrac{\overline{u_{r}(X)u_{r}(X+r)}}{\bar{u}^{2}},\qquad g(r)=\dfrac{\overline{u_{n}(X)u_{n}(X+r)}}{\bar{u}^{2}}$ | （3.13）（3.14） |
| **文字式** | $\text{纵向相关系数}=\dfrac{\text{径向波动速度的两点乘积平均}}{\text{波动速度均方值}}；\text{横向同构}$ |  |

$r$ 很小时 $f,g$ 近似抛物线，定义**泰勒微尺度**（`#L4024`、`#L4032`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $f(r)\cong1-\dfrac{r^{2}}{\lambda_{f}^{2}},\qquad \dfrac{1}{\lambda_{f}^{2}}=-\dfrac{1}{2}\left[\dfrac{\partial^{2}f}{\partial r^{2}}\right]_{r=0}=\dfrac{1}{2\bar{u}^{2}}\overline{\left[\dfrac{\partial u_{r}}{\partial r}\right]^{2}_{r=0}}$ | （3.15）（3.17） |
| **文字式** | $\text{微尺度}^{-2}\ \propto\ \text{速度梯度均方值}/\text{波动速度均方值}$ |  |

**物理含义**：$\lambda_f$ 是"局部速度变化有多大"的度量，而 $\overline{[\partial u/\partial r]^2}$ 正是湍动能耗散成热的速率，所以 $\lambda$ 同时是**小涡含能尺度**与**耗散尺度**（`#L4036`）。

## 能谱与耗散

一维能谱 $E_r(n)$ 是 $f(r)$ 的傅里叶变换，且 $\int_0^\infty E_r(n)\,\mathrm{d}n=\bar{u}_r^2$（3.25)(3.26)。由谱矩给出耗散（`#L4138`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\varepsilon=30\nu\dfrac{\bar{u}_{r}^{2}}{\lambda_{f}^{2}}$ | （3.40） |
| **文字式** | $\text{单位质量能耗率}=30\times\text{运动黏度}\times\dfrac{\text{径向波动速度均方值}}{\text{纵向微尺度}^{2}}$ |  |

由 N-S 谱方程 $\partial E/\partial t=T(k)-2\nu k^{2}E(k)$（3.35）可看出：高波数（小涡）因黏性耗散掉能量快，靠低波数通过惯性逐级补给它（`#L4145`）。

## 五个尺度分区（图3.16）

| 区 | 含义 | 尺度/判据 |
|:---|:---|:---|
| A 定态大涡 | 与容器同量级（循环流即一例） | $\lambda\sim D$ |
| B 储能涡 | 含主要湍动能，**至多占总动能 20%** | $k_e=1/\lambda$ |
| C 惯性子域 | 黏性可忽略，能量只靠惯性传递 | $k_e\ll k\ll k_d$（3.53） |
| D 全平衡域 | 统计稳态、各向同性、与外界条件无关 | $\bar{u}\lambda/\nu^{3/4}\ll1$（3.52） |
| E 黏滞耗散域 | 黏性控制，湍动能主要在此耗散 | $k_d=1/\eta$（3.46） |

## Kolmogorov 尺度

D 区只由 $\varepsilon$ 与 $\nu$ 决定，故可构造唯一长度/速度尺度（`#L4179`、`#L4181`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\eta=\left(\dfrac{\nu^{3}}{\varepsilon}\right)^{1/4},\qquad v=\left(\nu\varepsilon\right)^{1/4},\qquad \dfrac{\eta v}{\nu}=1$ | （3.43）（3.44）（3.45） |
| **文字式** | $\text{最小涡尺度}_{\text{【m】}}=\left(\dfrac{\text{运动黏度}^{3}}{\text{单位质量能耗率}}\right)^{1/4}$ |  |

惯性子域的谱定律（`#L4231`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $E(k)=C\,\varepsilon^{2/3}k^{-5/3}$ | （3.55） |
| **文字式** | 能谱 ∝ 耗散率的 $2/3$ 次方 × 波数的 $-5/3$ 次方 |  |

更高波数（耗散域）Heisenberg 给出 $E(k)\propto\varepsilon^{2}\nu^{-4}k^{-7}$（3.56）。

## 用的时候注意

- **$\varepsilon$ 用单位质量功率**：$\varepsilon=P_v g_c/\rho$，别直接代 $P/V$（差一个 $\rho$）（见 [[搅拌容器中的湍动与能耗分布]]）。
- **$\eta$ 与转速无关的悖论**：搅拌釜实测 $\eta$ 随位置变化极大、却几乎不随转速变；原因是能耗项与时间平均速度项随转速的变化互相抵消（`#L4369`、`#L4382`）。
- **$E\propto k^{-5/3}$ 在釜内成立**，即惯性子域确实存在，这为"微混合理想化"提供了依据（`#L4359`）。
- **各向同性只是局部**：只有叶轮周围约 10% 的区域是非各向同性的，其余 90% 近似各向同性（`#L4335`）。

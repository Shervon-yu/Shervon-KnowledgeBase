# 搅拌剪切速率量级

## 为什么重要

非牛顿流体的黏度是切变速率 $\dot{\gamma}$ 的函数，不同 $\dot{\gamma}$ 下黏度可差三个数量级以上（`#L1229`）。所以"取黏度算功率"之前，必须先确定过程对应的 $\dot{\gamma}$ 量级。

## 常见过程的量级（表2-2，`#L1231-#L1247`）

| 过程 | $\dot{\gamma}$ / s⁻¹ | 行业 |
|:---|:---:|:---|
| 悬浮液中细粉沉降 | $10^{-6}\sim10^{-4}$ | 医药、涂料 |
| 表面张力作用下流平 | $10^{-2}\sim10^{-1}$ | 涂料、油墨 |
| 重力作用下流淌 | $10^{-1}\sim10^{1}$ | 涂层流挂 |
| 挤出 | $10^{0}\sim10^{2}$ | 聚合物 |
| 咀嚼与吞咽 | $10^{1}\sim10^{2}$ | 食品 |
| 浸涂 | $10^{1}\sim10^{2}$ | 涂料、甜食 |
| **混合和搅拌** | $10^{1}\sim10^{4}$ | 液体加工 |
| 管流 | $10^{0}\sim10^{3}$ | 泵送、血液 |
| 喷雾与涂刷 | $10^{3}\sim10^{4}$ | 喷雾干燥、燃油雾化 |
| 抹涂 | $10^{4}\sim10^{5}$ | 护肤膏 |
| 颜料研磨 | $10^{3}\sim10^{5}$ | 油漆、油墨 |
| 高速涂层 | $10^{5}\sim10^{6}$ | 造纸 |
| 润滑 | $10^{3}\sim10^{7}$ | 内燃机 |

## 用法

- 搅拌取 $10^{1}\sim10^{4}$ s⁻¹，跨度三个数量级：釜内不同位置（叶轮区 vs 主体循环区）本来就不在同一量级，用单一黏度只是工程近似。
- 计算顺序：先由转速与叶轮直径估出量级 → 在该量级上取 $K_{\mathrm{psn}}$、$n$ 算表观黏度 $\mu_a$ → 代入 $Re$ 与功率式，见 [[幂律流体与表观黏度]] 与 [[搅拌功率计算]]。
- 同一物料在不同工序（输送、搅拌、研磨）要用不同量级的黏度，不能拿管线黏度算搅拌功率。

## 边界

表2-2 是"大致范围"（`#L1229`），用于估量级，不用于精确设计；精确值要靠流变仪在该切变速率范围内实测。

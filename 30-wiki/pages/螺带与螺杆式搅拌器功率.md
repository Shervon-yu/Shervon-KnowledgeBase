# 螺带与螺杆式搅拌器功率

## 适用范围

层流区螺带式混合效率较高、应用广泛（`#L1661`）。以下关联式均以 $N_p\cdot Re^{*}$ 或 $N_p\cdot Re$ 形式给出，$Re^{*}$ 为表观雷诺数（式2-44）。

## 双螺带式

朱秀林、王凯等（`#L1665-#L1679`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}\cdot Re^{*}=329.4\left(\dfrac{d/D}{1-d/D}\right)^{0.341}\left(\dfrac{w}{d}\right)^{0.43}\left(\dfrac{p}{d}\right)^{0.41}\left(\dfrac{L}{d}\right)^{0.78}$ | （2-36） |
| **文字式** | $\text{功率准数}\times\text{表观雷诺数}=329.4\times\left(\dfrac{\text{叶轮直径}/\text{釜内径}}{1-\text{叶轮直径}/\text{釜内径}}\right)^{0.341}\times\left(\dfrac{\text{螺带宽}}{\text{叶轮直径}}\right)^{0.43}\times\left(\dfrac{\text{螺距}}{\text{叶轮直径}}\right)^{0.41}\times\left(\dfrac{\text{螺带高}}{\text{叶轮直径}}\right)^{0.78}$ |  |

平均相对误差 8.33%，适用 $d/D=0.8\sim0.95$、$w/d=0.09\sim0.15$、$p/d=0.5\sim1.0$、$L/d=0.94\sim2.32$。

Shamlou 式（`#L1681-#L1685`）：$N_p\cdot Re^{*}=150(L/d)\sqrt{2(p/d)^{-0.67}(w/c)^{0.67}}$（式2-37），误差 8.73%，适用 $d/D=0.8\sim0.98$。

## 单螺带式

王凯、王嘉骏收集 53 组数据回归（`#L1687-#L1691`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}\cdot Re^{*}=174.93\left(\dfrac{d}{c}\right)^{0.269}\left(\dfrac{w}{d}\right)^{0.401}\left(\dfrac{p}{d}\right)^{-0.46}\left(\dfrac{L}{d}\right)^{0.804}$ | （2-38） |
| **文字式** | $\text{功率准数}\times\text{表观雷诺数}=174.93\left(\dfrac{\text{叶轮直径}}{\text{间隙}}\right)^{0.269}\left(\dfrac{\text{螺带宽}}{\text{叶轮直径}}\right)^{0.401}\left(\dfrac{\text{螺距}}{\text{叶轮直径}}\right)^{-0.46}\left(\dfrac{\text{螺带高}}{\text{叶轮直径}}\right)^{0.804}$ |  |

平均相对误差 13.1%；适用 $d/D=0.753\sim0.98$。

注意 $\left(p/d\right)$ 的指数为负：螺距越大，单位高度的功率越小——与双螺带式（正指数）相反，不能混用。

## 螺带-螺杆式

Masiuk 与 Lacki（`#L1701-#L1703`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}\cdot Re=473\left(\dfrac{w}{d}\right)^{0.38}\left(\dfrac{p}{d}\right)^{-0.2}$ | （2-40） |
| **文字式** | $\text{功率准数}\times\text{雷诺数}=473\times\left(\dfrac{\text{螺带宽}}{\text{叶轮直径}}\right)^{0.38}\times\left(\dfrac{\text{螺距}}{\text{叶轮直径}}\right)^{-0.2}$ |  |

## 内外单螺带式

王嘉骏、王凯等（`#L1705-#L1729`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}\cdot Re=418.5\left(\dfrac{d}{D}\right)^{3.286}\left(\dfrac{w}{d}\right)^{0.452}\left(\dfrac{p}{d}\right)^{0.731}\left(\dfrac{d_{i}}{d}\right)^{0.322}\left(\dfrac{w_{i}}{d}\right)^{-0.268}\left(\dfrac{p_{i}}{d}\right)^{0.119}\left(\dfrac{h}{d}\right)^{0.964}$ | （2-41） |
| **文字式** | $\text{功率准数}\times\text{雷诺数}=418.5\left(\dfrac{\text{外径}}{\text{釜内径}}\right)^{3.286}\left(\dfrac{\text{外带宽}}{\text{外径}}\right)^{0.452}\left(\dfrac{\text{外带螺距}}{\text{外径}}\right)^{0.731}\left(\dfrac{\text{内径}}{\text{外径}}\right)^{0.322}\left(\dfrac{\text{内带宽}}{\text{外径}}\right)^{-0.268}\left(\dfrac{\text{内带螺距}}{\text{外径}}\right)^{0.119}\left(\dfrac{\text{搅拌器高}}{\text{外径}}\right)^{0.964}$ |  |

标准平均偏差 9.66%。结论：外螺带尺寸影响大于内螺带，尤其 $d/D$；功率随外螺带叶宽增大、螺距减小而增大，且几乎与搅拌器高度 $h/d$ 成正比（`#L1729`）。

## 直接计算法

不借表观黏度法、直接以流变参数计算的路子有三支（`#L1861-#L1927`）：

- Beckner、Smith：锚式通用式（式2-46），适用 $0.2\le Re\le90$、$0.0177\le c/D\le0.1584$、$0.27\le n\le0.77$；
- Chavan、Ulbrecht：二重圆筒模型（式2-47~2-49），覆盖螺带、螺杆、螺带-螺杆、螺杆-导流筒；
- Chavan 的螺杆-导流筒式（式2-50~2-51）。

这些式子参数多、需先量几何，工程上多数场合仍用"表观黏度 + 曲线"法，见 [[表观黏度法与Metzner常数]]。

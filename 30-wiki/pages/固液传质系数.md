# 固液传质系数

固-液传质研究两件事：搅拌对固体表面积的影响，以及对颗粒周围液膜的影响（`#L3350`）。

## 功率的影响

图 3-6 是搅拌功率对固-液传质系数的影响曲线（`#L3352`）：

- **离底悬浮之前**：功率对提高传质系数影响大，但大量固体未悬浮，有效传质面很小，绝对传质系数太低；
- **离底悬浮之后**：功率的影响明显减弱，传质面不再是贡献因子，系数增加主要来自界面湍动改善。

推论：先把悬浮做到位（见 [[固液悬浮临界转速]]），再谈传质强化。

## 无因次关联

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Sh=r\,(Re)^{p}\,Sc^{q}$ | （3-24） |
| **文字式** | $\text{舍伍德数}=r\times\left(\text{雷诺数}\right)^{p}\times\left(\text{施密特数}\right)^{q}$ |  |

$Sc=\mu/(\rho D_V)$；常数 $r$ 与指数 $p$、$q$ 与桨型及几何特性有关（`#L3372-#L3384`）。

# 原书《混合原理与应用》§6.2–§6.3

## 溶解速率方程与三种测定法

基本方程（`#L6874`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $-\dfrac{\mathrm{d}W}{V\,\mathrm{d}t}=K\dfrac{A}{V}(C_s-C)$ | （6.8） |
| **文字式** | $-\dfrac{\text{固体质量减少}}{\text{液体容积}\times\text{时间}}=\text{传质系数}\times\dfrac{\text{接触面积}}{\text{液体容积}}\times(\text{饱和浓度}-\text{实际浓度})$ |  |

$K$ 称传质系数或**溶解速率系数**，单位 cm/s。

**A. 立方根定律**（Hixson–Crowell）。代入 $A=\alpha_wW^{2/3}$、$C_s=W_s/V$、$C=(W_e-W)/V$ 后积分（`#L6898`）：

$$K_t=\dfrac{V}{\alpha_wm^{2/3}}\Big\{\sqrt3\tan^{-1}\dfrac{2\sqrt3\,m^{1/3}(W_0^{1/3}-W^{1/3})}{3m^{2/3}+(2W_0^{1/3}-m^{1/3})(2W^{1/3}-m^{1/3})}+1.1513\log\Big(-\dfrac{m^{1/3}+W_0^{1/3}}{m^{1/3}+W^{1/3}}\Big)^{2}\Big\}\cdot\dfrac{m^{2/3}-m^{1/3}W^{1/3}+W^{2/3}}{m^{2/3}-m^{1/3}W_0^{1/3}+W_0^{2/3}}$$

（6.9，$m=W_s-W_0$）其形式即"固体重量的立方根随时间线性下降"，故称立方根定律。

**B. Wilhelm 法**。把液体容积按饱和度线性膨胀 $V=(1+\alpha X)V_0$，得图解积分式（6.10）；氯化钠溶于水时 $\alpha=0.13$。与 A 法的差别是**A 忽略容积变化，B 认为容积与饱和度成反比**（`#L6918`）。

**C. 图解微分**。取溶解初期浓度曲线的斜率（`#L6924`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $-\left(\dfrac{\mathrm{d}W}{A\,\mathrm{d}t}\right)_{t=0}=\dfrac{KA_0C_s}{V}$ | （6.11） |
| **文字式** | 初始溶解速率 $=\text{传质系数}\times\text{初始面积}\times\text{饱和浓度}\div\text{容积}$ |  |

## 传质关联式的骨架

无挡板、四叶斜桨与推进式（`#L6932`、`#L6940`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{KD}{D_f}=\mathrm{Sh}=c\,Re^{p}Sc^{q}$ | （6.12）（6.12'） |
| **文字式** | 釜舍伍德数 $=c\times\left(\dfrac{D^2n\rho_l}{\mu}\right)^{p}\times\left(\dfrac{\mu}{\rho_lD_f}\right)^{q}$ |  |

四叶斜桨：$Re\le6.7\times10^4$ 时 $Sh=2.7\times10^{-5}Re^{1.4}Sc^{0.5}$（6.13）；$Re\ge6.7\times10^4$ 时 $Sh=0.16Re^{0.62}Sc^{0.5}$（6.13'）。推进式 $3300<Re<3.3\times10^5$：$Sh=0.0043Re^{1.0}Sc^{0.5}$（6.13''）。**折点基本落在流化临界速度对应的雷诺数 $R_f$**（`#L6952`）。

### 指数 p 不是常数（本节最重要的一点）

$Re>R_f$ 时 $p$ 随**密度差与粒径**变化（`#L6954`）。苯甲酸-水体系在 $D=15.2\sim61.0$ 的五个容器中，"标绘点都落在斜率为 0.2 的平行线上"——即 $Sh\propto Re^{0.2}$，而不是 Hixson 报的 0.62（`#L6958`）。其他体系：岩盐-水 0.52、氯化钡-水 0.67。

关联（`#L7028`、`#L7032`、`#L7036`、`#L7042`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $p_{2}=0.48\{\log(\Delta+0.043)+1.35\}\,\Delta^{-13.5\delta}$ | （6.20） |
| **文字式** | $\text{指数}=0.48\times\{\log(\text{无因次密度差}+0.043)+1.35\}\times\text{密度差的}^{(-13.5\times\text{无因次粒径})}$ |  |

其中 $\Delta=(\rho_s-\rho_l)/\rho_l$、$\delta=d_p/D$；精化形式 $p_2=0.0802(D^3g/\nu^2)^{0.0772}\{\log(\Delta+0.043)+1.35\}10^{-13.5\delta}$（6.22）。低转速段 $p'=0.36\Delta^{0.22}\delta^{-0.23}$（6.21）。**粒径越大、密度差越小，$p$ 越小**；$\Delta\to0$ 时 $p\to0$（颗粒已随液体环流，加转速无用）。固体形状影响不显著。

完整关联（15 组体系，`#L7070`、`#L7078`）：

$$\frac{KD}{D_f}=3.6\times10^{12}\left(\frac{D^2n}{\nu}\right)^{p}\left(\frac{\nu}{D_f}\right)^{q}\left(\frac{D_f}{D^3g}\right)^{0.627}\left(\frac{d_p}{D}\right)^{3.08}\left(\frac{\rho_s-\rho_l}{\rho_l}\right)^{-2.82}\left(\frac{\phi_s}{\pi}\right)^{-1}$$

（6.23；$q=14.4\delta+1.84\Delta^{0.116}$，6.24）适用 $(d_p/D)^2>4\times10^{-5}$，更小的颗粒不适用。

## 挡板容器

挡板便于放大，在美国广泛使用；但底部常积料，且**叶轮功率是无挡板的 5~6 倍、有时超过 10 倍**，效率很低（`#L7084`）。

Humphrey–Van Necc（1 ft 釜，$d/D=1/3$ 三叶推进式）：$c=0.47$、$p=0.58$、$q=0.5$（$Re=6.3\times10^4\sim3.3\times10^5$）；六叶涡轮：$c=0.022$、$p=0.87$、$q=0.5$（$3.1\times10^4\sim8.9\times10^4$）。粒径 4~12 Mesh 内无显著影响（`#L7098`）。

Barker–Treybal（$D=2\sim12$ m、六叶平直涡轮）：$\ln(10K)=I+0.85V^{0.02875}\ln(Re/10^4)$（6.25），取 $0.833$ 为平均指数后得（`#L7130`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{KD}{D_f}=0.02\,Re^{0.833}Sc^{0.5}$ | （6.26） |
| **文字式** | 挡板容器固液传质：指数固定 0.833，$Sc$ 指数 0.5 |  |

作者的反驳：挡板容器中**较大密度颗粒的 $Re$ 指数也更大**（图6.11）；Treybal 得到常数 0.833 大概只是因为其密度差区间太窄（`#L7134`）。

## 用湍流波动速度统一起来

思路（`#L7144`）：颗粒传质由**相对速度**与**表面更新率**控制，后者取决于颗粒周围的湍动强度。

Kolmogorov 最小涡尺度（`#L7150`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\eta=\dfrac{\mu_c^{3/4}}{\rho_c^{1/2}}P_v^{-1/4}$ | （6.27） |
| **文字式** | $\text{最小涡尺度}=\text{运动黏度的}^{3/4}\times\text{单位体积功率的}^{-1/4}$ |  |

前提 $L\gg d_p\gg\eta$（$L$ 为叶轮产生的初级涡尺度）。距离 $d_p$ 处的均方波动速度（6.28）：$\overline{u^2}=P_v^{2/3}(d_p/\rho_c)^{2/3}$。举例：输入 $10$ HP/1000 gal 时 $\eta=25\ \mu$m，叶宽 5 cm 给出 $L/\eta=2000$，足以假设局部各向同性（`#L7158`）。

把 $\sqrt{\overline{u^2}}$ 当作颗粒的相对速度代入 $Re_p$，得（6.29）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $Re_p\propto\dfrac{d_p^{4/3}\rho_c^{2/3}P_v^{1/3}}{\mu_c}$ | （6.29） |
| **文字式** | 颗粒雷诺数由粒径、密度、单位体积功率与黏度组合而成，不含叶轮直径 |  |

要求"$K$ 与 $d_p$ 无关、$K\propto D_f^{2/3}$"这两条实验事实（6.31），唯一可行的指数是 $p=3/2$、$q=1/3$（`#L7178`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $K\propto\dfrac{(P_v\mu_c/\rho_c^{2})^{1/4}}{(\mu_c/\rho_cD_f)^{2/3}}$ | （6.32a） |
| **文字式** | 传质系数 $\propto$ 单位体积功率与黏度的 $1/4$ 次方，除以施密特数的 $2/3$ 次方 |  |

传热的相似式（6.32b）：$h/(C_p\rho_c)\propto(P_v\mu_c/\rho_c^2)^{1/4}/(C_p\mu_c/\lambda_v)^{2/3}$。Calderbank 汇总多作者数据（`#L7192`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $K\,Sc^{2/3}=\dfrac{h}{C_p\rho_c}Pr^{2/3}=0.13\left(\dfrac{P_v\mu_c}{\rho_c^{2}}\right)^{1/4}$ | （6.33） |
| **文字式** | 传质与传热可用同一条 $P_v^{1/4}$ 型关系，两式数值等价（$j$ 因子类比） |  |

**优点是式子不含叶轮尺寸**——换桨型不用改式。但作者对"$K$ 与 $d_p$ 无关"这个前提本身存疑（`#L7194`）。

# §6.3 微米级颗粒：传质系数与搅拌强度无关

## 为什么单独研究

小颗粒溶解太快、测不了，文献几乎都是毫米级颗粒；而**悬浮固体催化剂上的液相反应**恰恰是微米级（`#L7204`）。实验对象：球形铜溶于含 $0.01$ N $\mathrm{K_2Cr_2O_7}$ 的 1 N 硫酸（6.34，$d_p$ 从 2.2 mm 到 $13\ \mu$m）、离子交换树脂、石膏 $\mathrm{CaSO_4\cdot2H_2O}$、硫酸钡 $\mathrm{BaSO_4}$（`#L7212`、`#L7224`）。传质系数用（`#L7226`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $K=\dfrac{\left[1-(W/W_0)^{1/3}\right]3W_0^{1/3}}{\alpha Wn^{1/3}C_st}$ | （6.35） |
| **文字式** | 由剩余质量分数与初始质量的立方根反算传质系数 |  |

## 实测的三个特征

1. 毫米级颗粒：$K\propto n^{p}$，$p\approx0.83$（6.36，`#L7252`）；
2. $K$ 随粒径减小而**增大**，在 $40\sim50\ \mu$m 达峰值，之后下降；$d_p\approx10\ \mu$m 后**转速影响消失**（`#L7260`）；
3. 从无挡板 120 r/min（$P_v=0.272$ PS/m³）改到有挡板 650 r/min（$P_v=140$ PS/m³），**搅拌强度增加 500 倍，传质系数不变**（`#L7268`）。

Ranz–Marshall 理论认为 $Re\to0$ 时 $Sh\to2$，按此外插与实测矛盾（`#L7270`）。

## 三个粒径区（解释）

`#L7274`、`#L7280`：

| 粒径区 | 主导机理 |
|:---|:---|
| 几 mm | 宏观滑移速度引起的**剪应力**控制 |
| 几十 $\mu$m | 微涡旋作用下的**表面更新**控制 |
| $\mu$m 及更小 | 颗粒小于 Kolmogorov 最小涡，被包在极小涡内运动，**黏性效应**为主；$<1\ \mu$m 时由**布朗运动**控制，与搅拌强度无关 |

（$0.9\ \mu$m 的 $\mathrm{BaSO_4}$ 在 9000 倍显微镜下可见布朗运动，`#L7284`。）

## 工程结论

**对有悬浮固体催化剂的液相反应，使催化剂保持悬浮的搅拌强度已经足够，再加强搅拌纯属浪费**——无挡板 120 r/min（$P_v=0.722$ PS/m³）即相当于这个强度（`#L7286`）。这与"传质系数只由 $P_v^{1/4}$ 决定"的式(6.33) 相互印证：$P_v$ 涨 500 倍，$K$ 只涨 $500^{1/4}\approx4.7$ 倍，而微米级连这 4.7 倍也没有。

# 搅拌功率计算

## 定义与用途

搅拌功率是单位时间输入釜内物料的能量，**不包括轴封与传动装置中的损耗**（`#L998`）。算它有两个用途：设计或校核搅拌器、搅拌轴的强度与刚度；选择电动机与变速器。

## 影响因素

四大类（`#L1000-#L1010`）：叶轮几何尺寸与转速（直径、桨宽、桨叶倾角、转速、叶片数、离底距离）；容器结构（内径、液面高度、挡板数与宽度、导流筒尺寸）；介质特性（密度、黏度）；重力加速度。

## 关联式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{\mathrm{p}}=\dfrac{P}{\rho N^{3}d^{5}}=K\,(Re)^{r}(Fr)^{q}f\left(\dfrac{d}{D},\dfrac{B}{D},\dfrac{H}{D},\dots\right)$ | （1-1） |
| **文字式** | $\text{功率准数}=\dfrac{\text{搅拌功率}_{\text{【W】}}}{\text{密度}_{\text{【kg/m³】}}\times\left(\text{转速}_{\text{【1/s】}}\right)^{3}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{5}}=\text{系数}\times\text{雷诺数}^{r}\times\text{弗鲁德准数}^{q}\times f\left(\dfrac{\text{叶轮直径}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}},\dfrac{\text{桨宽}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}},\dfrac{\text{液面高}_{\text{【m】}}}{\text{釜内径}_{\text{【m】}}},\dots\right)$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=N_{\mathrm{p}}\,\rho\,N^{3}d^{5}$ | （1-2） |
| **文字式** | $\text{搅拌功率}_{\text{【W】}}=\text{功率准数}\times\text{密度}_{\text{【kg/m³】}}\times\left(\text{转速}_{\text{【1/s】}}\right)^{3}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{5}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re=\dfrac{d^{2}N\rho}{\mu}$ | （1-3） |
| **文字式** | $\text{雷诺数}=\dfrac{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\text{转速}_{\text{【1/s】}}\times\text{密度}_{\text{【kg/m³】}}}{\text{黏度}_{\text{【Pa·s】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Fr=\dfrac{N^{2}d}{g}$ | （1-4） |
| **文字式** | $\text{弗鲁德准数}=\dfrac{\left(\text{转速}_{\text{【1/s】}}\right)^{2}\times\text{叶轮直径}_{\text{【m】}}}{\text{重力加速度}_{\text{【m/s²】}}}$ |  |

符号：$B$ 桨叶宽度（m）、$d$ 叶轮直径（m）、$D$ 容器内径（m）、$H$ 液面高度（m）、$N$ 转速（1/s）、$P$ 功率（W）、$\rho$ 密度（kg/m³）、$\mu$ 黏度（Pa·s）、$K$ 系数、$r,q$ 指数（`#L1016-#L1040`）。

## 计算口径

- 一般情况下 $Fr$ 的影响较小，$D$、挡板宽度 $b$ 等几何参数可并入系数 $K$（`#L1042`）。工程上常退化为 $N_p$ 仅随 $Re$ 变化：低 $Re$（层流）$N_p\propto Re^{-1}$，充分湍流 $N_p$ 趋于常数。
- 由式（1-2），已知 $\rho$、$N$、$d$ 时**关键只在于求 $N_p$**；$N_p$–$Re$ 关系可在特定设备上实测，双对数坐标即功率曲线（`#L1046`）。具体关联式见第二章。
- 单位口径注意：$N$ 用 1/s（不是 r/min），$P$ 得 W；$Re$ 无量纲，与 $d$、$N$、$\rho$、$\mu$ 同一单位制即可。
- 非牛顿物料：$\mu$ 必须取对应切变速率的表观黏度，见 [[幂律流体与表观黏度]] 与 [[搅拌剪切速率量级]]。

## 边界

- 功率准数曲线只对**几何相似**的系统成立；改变挡板、导流筒、叶轮离底距离都会改动 $N_p$，这正是 $f(d/D,B/D,H/D)$ 存在的原因。
- 算出的 $P$ 是流体获得的功率；选电机还要加上轴封与传动损耗，见 [[搅拌设备设计步骤]]。

- 实测方法见 [[搅拌功率的测量方法]]

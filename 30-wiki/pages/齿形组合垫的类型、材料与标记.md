# 齿形组合垫的类型、材料与标记

## 定义

齿形组合垫（HG/T 20611 PN 系 / HG/T 20632 Class 系）＝金属齿形环＋非金属覆盖层，分三种结构类型（#L5970-#L5989、#L13706-#L13725）。

## 判据与计算

### 类型与代号（#L5970-#L5989、#L13706-#L13725）

| 代号 | 类型 | 适用密封面 |
| :--- | :--- | :--- |
| A | 基本型 | 榫槽面、凹凸面 |
| B | 带整体对中环 | 突面 |
| C | 带活动对中环 | 突面（亦适用全平面） |

### 使用温度（#L5990-#L6014、#L13726-#L13750）

| 覆盖层材料 | 温度范围 |
| :--- | :--- |
| 柔性石墨 | -200~+650 ℃（氧化性介质限 450 ℃） |
| 聚四氟乙烯 PTFE | -200~+200 ℃ |

齿形环材料：304 / 304L / 316 / 316L / 321 / 347 / 310。

### 材料与覆盖层性能（#L6015-#L6034、#L13751-#L13770）

- 整体对中环材料同齿形环材料；活动对中环用碳钢（GB/T 912），表面喷涂/电镀处理
- 覆盖层性能（表 3.4.3）：石墨氯离子含量 ≤50×10⁻⁶；PTFE 拉伸强度 ≥15 MPa、熔点 327±10 ℃，禁止使用再生料

### 标记（#L6189-#L6224、#L13942-#L13988）

五要素：标准名称、类型（A/B/C）、公称尺寸（＞DN600 加 A 或 B 系列）、公称压力（PN 或 Class）、材料代号（齿形环/覆盖层，活动对中环碳钢省略）。

材料缩写（表 7.1.1，Class 系）：304 / 304L / 316 / 316L / 321 / 347 / 310 / TI / MON / HAST B / HAST C / INC 600 / IN 800 / ZIRC；覆盖层 FG / PTFE。

示例：
- PN 系：`HG/T20611 齿形垫 C 100-40 304/FG`
- Class 系：`HG/T20632 齿形垫 C 100-900 304/FG`；DN1000 B 系列为 `…C1000B-900…`

### 标志（#L6189-#L6224、#L13989-#L14018）

- 对中环上打钢印（永久性）；基本型在包装标签上标志
- 内容：厂名或商标、标准编号、公称压力、公称尺寸、齿形环/覆盖层/对中环材料代号（碳钢省略）

## 适用范围与边界

- 本页收录 20611/20632 的类型、材料、标记口径；尺寸（第 4 章）与技术要求（第 5 章）不在本页
- 齿形组合垫的选配限制（配什么法兰、什么紧固件）见 [[法兰连接选配规定]]

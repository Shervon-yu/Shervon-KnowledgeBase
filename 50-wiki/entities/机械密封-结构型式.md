# 机械密封-结构型式

## 组成（先给零件骨架）

机械密封一般主要由四大部分组成：①由静止环（静环）和旋转环（动环）组成的一对密封端面，该密封端面有时也称为摩擦副，是机械密封的核心；②以弹性元件（或磁性元件）为主的补偿缓冲机构；③辅助密封机构；④使动环和轴一起旋转的传动机构。§3.1.4 #L1354

四个密封部位（图 4-1）：A 处为端面密封（旋转环与静止环端面相对滑动的动密封，又称主密封）；B 处为静环与压盖端面之间的密封；C 处为动环与轴（或轴套）配合面之间的密封（能随补偿环轴向移动，又称副密封）；D 处为压盖与泵壳端面之间的密封。B、C、D 三处是静止密封。§4.1.1 #L2157

补偿环：端面磨损时，动环连同动环密封圈在弹簧推动下沿轴向产生微小移动，达到一定补偿能力，故称补偿环；静环不具补偿能力，称非补偿环；补偿环可由动环或静环承担，由补偿环、弹性元件和副密封构成的组件称补偿环组件。§4.1.1 #L2155

## 分类（表 4-1，按十个维度，§4.1.2 #L2189）

| 维度 | 型式 | 判据 / 口径 | 适用 |
|:---|:---|:---|:---|
| 端面对数 | 单端面 | 一对端面；结构简单，一般不需外供封液，但要设自冲洗 | 一般液体（油品等）；配辅助装置可用于含颗粒、高温高压 |
| | 双端面 | 两对端面，分轴向/径向布置；腔内注入高于介质压力 0.05~0.15 MPa 的外供封液，起「堵封」与润滑作用 | 腐蚀、高温、液化气带颗粒纤维、易挥发易燃有毒易结晶贵重介质 |
| | 多端面 | 两对以上，典型是中间环多端面 | 旋转中间环用于高速下降 pv；不转中间环用于高压高温减小变形 |
| 流体压力是否卸荷 | 平衡式 | 载荷系数 K<1（部分平衡 0<K<1、过平衡 K≤0）；结构复杂，端面比压随液体压力缓增 | 一般介质 p≥0.7 MPa；外装式 K=0.15~0.3 时仅 0.2~0.3 MPa |
| | 非平衡式 | K≥1，流体压力不卸荷；结构简单，高压下端面比压增大易磨损 | 一般介质 p<0.7 MPa |
| 静止环位置 | 内装式 | 静止环装在端盖内侧（面向工作腔）；受力好、泄漏小（泄漏方向与离心力相反）、冷却润滑好 | 应用最广；介质无强腐蚀、不影响弹性元件 |
| | 外装式 | 静止环在端盖外侧；泄漏方向与离心力同向，泄漏较大，工作压力较低 | 强腐蚀、易结晶影响弹性元件、黏稠介质、低压 |
| 弹性元件 | 弹簧式 | 用弹簧压紧端面，有时用弹簧传转矩；制造简单，受辅助密封圈材质限制 | 多数密封 |
| | 波纹管式 | 用波纹管压紧端面，不需辅助密封圈，使用温度不受密封圈材质限制 | 高温或腐蚀性介质 |
| 弹簧位置 | 弹簧内置式 / 外置式 | 内置可利用介质压力助封、端面受力与冷却润滑好；外置零件少接触介质、便于观察维修，但介质压力与弹簧力反向，压力波动易致密封不稳 | 内置于无强腐蚀；外置于强腐蚀/易结晶/黏稠低压 |
| 弹簧个数 | 单弹簧 / 多弹簧 | 单弹簧受力不均、高速离心变形大；多弹簧端面受力均匀、可调 | 单弹簧：轻载小轴颈、强腐蚀；多弹簧：重载大轴颈苛刻工况 |
| 补偿环是否随轴转 | 旋转式 / 静止式 | 旋转式结构简单径向尺寸小，但弹性元件受离心力变形；静止式结构复杂、性能稳定 | 旋转式 v<25 m/s；静止式 v>25 m/s 或易结晶 |
| 泄漏方向 | 内流式 / 外流式 | 内流式泄漏方向与离心力相反，泄漏小、可靠；外流式泄漏较大 | 内流式配内装式、含颗粒或高压；外流式配外装式，p 一般 <1 MPa |
| 补偿环背面压力侧 | 背面高压式 / 背面低压式 | 背面低压式弹簧一般置于低压侧，避免接触高压流体腐蚀 | 高压式封弱腐蚀；低压式封强腐蚀 |
| 端面是否接触 | 接触式 / 非接触式 | 接触式靠弹力+流体压力贴合，端面通常边界润滑，泄漏小但磨损功耗发热大；非接触式靠静/动压形成完整流体膜，无固相接触，功耗小、无磨损、可零泄漏 | 接触式绝大多数场合；非接触式特殊要求 |
| 非接触时膜的状态 | 流体静压式 / 流体动压式 | 静压式靠外部引入流体或被封介质经界面压降产生静压效应，需外供液系统、泄漏较大；动压式靠端面特殊几何形状相对旋转自行产生动压 | 静压式高压高速、常与动压组合，应用较少 |

表内十四个维度均出自 §4.1.2 表 4-1 的「概念及特点 / 适用范围」两列（#L2189 单行 HTML 表，原文未拆行）。

## 典型派生型式

- **干气密封**（干运转气体密封）：将开槽密封技术用于气体介质，端面外侧开 2.5~10 μm 流体动压槽，旋转时把高压隔离气体泵入端面间形成 1~3 μm 气膜，工作在非接触状态，实现零泄漏或零逸出。§4.5.2 #L3256；同书 §3.2.3 亦称气膜密封、单端面干气密封 #L1546
- **液膜密封**：普通机械密封的端面由低流量高压力的「端面泵」代替，靠螺旋槽等动压槽输运隔离流体，开槽区在低压侧、未开槽密封坝区靠近高压过程流体。§3.2.4 #L1614
- **金属波纹管密封**：波纹管既是辅助密封又可作弹性元件，摩擦副挠性安装环的相对位移全由波纹管补偿。§4.2.2 #L2458 #L2460
- **可控机械密封**：利用压电晶体在不同电压下产生不同变形控制端面密封比压，从而控制泄漏率。§4.5.6 #L3360

## 选型入口（结构选型表）

按工作条件（温度、介质腐蚀性、含固体颗粒、压力、转速等）查表选型：高温、强腐蚀、易溶解介质、含颗粒介质各有对应「机械密封形式的选择」与「采取措施」两列。§4.2.1 #L2303 #L2321

温度分档（#L2297）：介质温度 0~80 ℃ 为普通密封（辅助密封圈常用丁腈橡胶 O 形圈）；80~150 ℃ 为普通热密封；>150 ℃ 为高温密封；<-20 ℃ 为普通低温密封；<-50 ℃ 为深冷密封。

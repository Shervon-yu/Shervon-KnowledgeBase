# 过滤-过滤速率基本方程

## 定义

- **过滤速率**：单位时间内滤过的滤液体积，m³/s（#L5163）。
- **过滤速度**：单位过滤面积的过滤速率，$\mathrm dV/(A\mathrm d\tau)$，m/s（#L5163）。
- **滤饼比阻 $r$**：单位过滤面积上滤饼量为 1 m³ 时的阻力，单位 1/m²（#L5211）。

过滤的特点：随过程进行滤饼增厚、阻力增大；定压差操作时过滤速率必逐渐下降，若要维持速率则须逐步升压（#L5167）。

## 判据 / 计算

过滤速度 = 推动力 / 阻力：

|  |  |  |
|:---|:---:|---:|
| **符号式** | \text{过滤速度}=\dfrac{\text{过滤推动力}}{\text{过滤阻力}} | （7-1） |
| **文字式** | $\text{过滤速度}_{\text{【m/s】}}=\dfrac{\text{压力差}_{\text{【Pa】}}}{\text{滤饼阻力}_{\text{【1/m】}}+\text{介质阻力}_{\text{【1/m】}}}$ |  |

原书写作式(3-31)（#L5169）。推动力与阻力分解（#L5171、#L5231-#L5233）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta p=\Delta p_c+\Delta p_m$ | （7-2） |
| **文字式** | $\text{总压力降}_{\text{【Pa】}}=\text{滤饼层压力降}_{\text{【Pa】}}+\text{过滤介质压力降}_{\text{【Pa】}}$ |  |

原书编号：式(3-35)（#L5233）。

滤饼阻力与介质阻力（把介质阻力折算为"当量滤液量 $V_e$"）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R_c=r\mu v\dfrac{V}{A}$ | （7-3） |
| **文字式** | $\text{滤饼阻力}_{\text{【1/m】}}=\text{比阻}_{\text{【1/m²】}}\times\text{黏度}_{\text{【Pa·s】}}\times\text{单位滤液对应滤饼体积}\times\dfrac{\text{滤液体积}_{\text{【m³】}}}{\text{过滤面积}_{\text{【m²】}}}$ |  |

原书编号：式(3-33)（#L5221）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R_m=r\mu v\dfrac{V_e}{A}$ | （7-4） |
| **文字式** | $\text{介质阻力}_{\text{【1/m】}}=\text{比阻}_{\text{【1/m²】}}\times\text{黏度}_{\text{【Pa·s】}}\times\text{单位滤液对应滤饼体积}\times\dfrac{\text{当量滤液体积}_{\text{【m³】}}}{\text{过滤面积}_{\text{【m²】}}}$ |  |

原书编号：式(3-34)（#L5227）。

瞬时过滤速度（由哈根-泊谡叶式描述滤饼毛细孔道内的层流）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm dV}{A\mathrm d\tau}=\dfrac{\Delta p_c}{r\mu\,V_c/A}$ | （7-5） |
| **文字式** | $\dfrac{\mathrm d\text{滤液体积}}{\text{过滤面积}_{\text{【m²】}}\times\mathrm d\text{时间}_{\text{【s】}}}=\dfrac{\text{滤饼层压力降}_{\text{【Pa】}}}{\text{比阻}_{\text{【1/m²】}}\times\text{黏度}_{\text{【Pa·s】}}\times\text{滤饼体积}_{\text{【m³】}}/\text{过滤面积}_{\text{【m²】}}}$ |  |

原书编号：式(c)（#L5195-#L5201）；其中 $V_c=vV$（式(e)，#L5215）。

## 适用范围与边界

- 推导假定滤饼内孔道流动为**层流**，故借用哈根-泊谡叶式（#L5173-#L5175）；湍流过滤不适用。
- 滤饼不可压缩时 $r$ 为常数；可压缩滤饼的 $r$ 随压差变化，须用经验式（本节不展开）。
- $V_e$ 是"当量滤液量"，把介质阻力折算成滤饼阻力的等效量，便于与 $R_c$ 同式相加（#L5225-#L5227）。
- 过滤速率随时间下降，故工程上按"恒压"或"恒速"两种操作方式积分求时间；本页只给瞬时式。

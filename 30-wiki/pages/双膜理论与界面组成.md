# 双膜理论与界面组成

## 三条假定（`#L9372-#L9380`）

吸收 = 溶质先从气相主体到界面、再从界面到液相主体。双膜理论把这段路简化成两个膜层的分子扩散：

1. **膜层假定**：界面两侧各有一层呈层流流动的稳定膜层（即有效层流膜），溶质以分子扩散连续通过；膜外两相主体为湍流。膜厚主要随流速变，流速越大膜越薄。
2. **界面平衡假定**：界面上气液两相互成平衡，**界面上没有传质阻力**。
3. **主体均匀假定**：膜外主体因充分湍动，浓度基本均匀，浓度梯度全部集中在两个膜层内。

三条合起来：整个相际传质阻力 = 气膜阻力 + 液膜阻力；膜外"零阻力"。

## 气、液两相的速率式（`#L9390-#L9414`）

稳态下两膜串联、速率相等：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=k_G(p_A-p_i)=k_y(y-y_i)=k_Y(Y-Y_i)$ | （5-25）~（5-27） |
| **文字式** | $\text{传质速率}=\text{气膜系数}\times\text{气相主体与界面的组成差}$（分压/摩尔分数/摩尔比三种口径） |  |

|  |  |  |
|:---|:---:|--:|
| **符号式** | $N_A=k_L(c_i-c_A)=k_x(x_i-x)=k_X(X_i-X)$ | （5-28）~（5-30） |
| **文字式** | $\text{传质速率}=\text{液膜系数}\times\text{界面与液相主体的组成差}$（浓度/摩尔分数/摩尔比三种口径） |  |

## 界面组成怎么定（`#L9418-#L9430`）

以 $Y$、$X$ 口径为例，两式相除消去 $N_A$：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\dfrac{Y-Y_i}{X_i-X}=\dfrac{k_X}{k_Y}$，即 $\dfrac{Y-Y_i}{X-X_i}=-\dfrac{k_X}{k_Y}$ | （5-31） |
| **文字式** | $\dfrac{\text{气相主体与界面的摩尔比差}}{\text{界面与液相主体的摩尔比差}}=\dfrac{\text{液膜系数}}{\text{气膜系数}}$ |  |

作图法（图5-14）：在 $Y$-$X$ 图上，从操作点 O$(Y,X)$ 画一条斜率为 $-k_X/k_Y$ 的直线，与**平衡线**的交点 I 的坐标即 $(Y_i,X_i)$。物理含义很清楚——界面在平衡线上（假定2），而两段推动力之比由两膜阻力之比决定（斜率）。

## 两条推论（`#L9430-#L9438`）

- 想算 $N_A$ 就得知道界面组成，而界面组成又要求先知道 $k_X$、$k_Y$——两个都难测。所以工程上干脆**消去界面组成**，改写为总传质速率方程（下一步）。
- 推导总速率时，平衡关系若不能用亨利定律，就在操作范围内用直线 $Y^{*}=mX+b$ 局部线性化；用 $Y^{*}=mX$ 与 $Y^{*}=mX+b$ 推出来的结果形式相同。

## 判断

- 双膜理论之所以长期主导，是因为它把两相问题拆成两个单膜问题，且给出"界面平衡"这个可直接作图的约束。它的软肋在假定1：高速湍流下膜并非稳定层流，实测 $k$ 与理论膜厚对不上，于是才有溶质渗透理论、表面更新理论等修正模型。
- 强化吸收的着手点由此明确：增大流速（减薄膜）、增大相界面（填料）、选对吸收剂（改变平衡与溶解度），三者对应膜厚、界面积、推动力。

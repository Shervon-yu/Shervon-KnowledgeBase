# 黏弹性流体搅拌

## 三个特征

黏弹性流体的典型特征是**法向应力差、弹性回缩、应力突增（Overshoot）**，它们对混合产生巨大负效应（`#L2024`）：弹性使材料试图维持原有形状而不参与混合。

## 爬杆（Weissenberg 效应）

运动时产生垂直于剪切面的法向应力差，引发二次流：流体从桨叶端部吸入，沿搅拌轴向上排出，把轴"抱"住（`#L2028`）。

## 流型判据

法向应力与惯性力的相对大小（`#L2042-#L2044`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r=\dfrac{Wi}{Re}$ | （2-58） |
| **文字式** | $r=\dfrac{\text{韦森伯格数}}{\text{雷诺数}}$ |  |

$Wi$ 表示法向应力与黏性力之比。判据（`#L2048`）：

- $r<0.055$：流型由惯性力控制（正常循环）；
- $0.1<r<0.3$：出现**孤立漩涡**，漩涡内流体与釜内其余流体不混合；
- $r>0.3$：流型完全由法向应力控制（反向循环）。

White 等提出类似判据 $r'$（式2-59，`#L2050-#L2058`），分界为 $0.083$ 与 $0.25$；但**螺旋推进器例外**：不管 $r'$ 多大都产生轴向流——法向应力有加强轴向流的作用。因此黏弹性物料宜用有强制推进作用的螺杆-导流筒式或螺带式搅拌器（`#L2058`）。

## 混合时间变长

- Carreau 等：螺带搅拌器混合黏弹性流体，混合时间是牛顿流体的 **4.3 倍**（`#L2060`）。
- 王凯等：内外单螺带-锚式，$N_{\theta M}$ 比牛顿流体增加近一倍。
- Ulbrecht 等：螺杆-导流筒式，$Re^{*}\le10^{5}$ 时 $N_{\theta M}\propto(1+0.45Wi)^{0.8}$。

## 功率

- **层流区**：$N_p\cdot Re^{*}=$ 常数（式2-60）；盘式涡轮测得 $N_p$–$Re^{*}$ 仍是斜率 −1 的直线，但 $N_p$ 比相同 $Re^{*}$ 的牛顿流体**高 60%**（`#L2068`）。
- Yap 等给出螺带式关联式（式2-61，`#L2070-#L2072`）；20-md 该式 OCR 有缺字（$(d/L)$ 的指数缺失），引用前须核对原书。
- 王凯、朱秀林等给出统一式（式2-62，`#L2086-#L2098`）：形如 $N_pRe^{*}f_s^{1-n}=K_p\left[1+\left(F_{1av}/k_s\right)f_s^{\,m-n}\cdot Wi\right]$，其中 $f_s=\exp\left[C_0Wi/n(m-n)\right]$；$Wi=0$ 时 $f_s=1$、退化为 $N_pRe^{*}=K_p$，即牛顿/假塑性公式。平均误差 <15%，可同时用于牛顿、假塑性、黏弹性（含 Boger 流体）。参数见表2-12（锚式 $K_p=205$、$k_s=25$、$C_0=0.27$；内外单螺带-锚 307/28.1/0.325；四螺带-锚 478/39/0.282）。式（2-62）的 OCR 亦有符号缺损，引用前核对。
- **过渡区**：弹性使功率**降低**（Olbrecht：$Re^{*}=100\sim2000$ 时扭矩明显小于牛顿流体）；但 Höcker 发现弹性很强时并未出现确定的层流区、功率显著高于牛顿流体，此时 Metzner 常数法不适用（`#L2110-#L2112`）。两种结论需按物料弹性强弱区分。

## 工程结论

| 目标 | 对策 |
|:---|:---|
| 避免孤立漩涡 | 控制 $r<0.055$（低弹性/高惯性工况） |
| 保证全釜循环 | 用螺杆-导流筒或螺带，利用法向应力强化轴向流 |
| 预估混合时间 | 按牛顿值的 4 倍以上留裕量 |
| 预估功率 | 层流按式2-60/2-62；过渡区不能默认"弹性降功率"，须按弹性强弱分别判断 |

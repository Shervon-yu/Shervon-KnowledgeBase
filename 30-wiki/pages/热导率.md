# 热导率

## 定义（`#L5822-#L5826`）

由傅里叶定律反解：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\lambda=-\dfrac{Q}{A\dfrac{\mathrm{d}t}{\mathrm{d}x}}$ | （4-3） |
| **文字式** | $\text{热导率}_{\text{【W/(m·K)】}}=-\dfrac{\text{传热速率}_{\text{【W】}}}{\text{传热面积}_{\text{【m²】}}\times\text{温度梯度}_{\text{【K/m】}}}$ |  |

数值上等于温度梯度为 1 K/m 时、单位时间通过单位面积的热量；表征物质的导热能力，是重要热物性参数，通常由实验测定。

## 量级排序与典型值（表4-1，`#L5862-#L5871`）

| 物质种类 | $\lambda$ 范围 / W·m⁻¹·K⁻¹ | 常用物质（约值） |
|:---|:---|:---|
| 纯金属 | 20~400 | 20 ℃：银 427、铜 398、铝 236、铁 81 |
| 合金 | 10~130 | 黄铜 110、碳钢 45、灰铸铁 40、不锈钢 15 |
| 建筑材料 | 0.2~2.0 | 普通砖 0.7、耐火砖 1.0、水泥 0.30、混凝土 1.3 |
| 液体 | 0.1~0.7 | 水 0.6、甘油 0.28、乙醇 0.172 |
| 绝热材料 | 0.02~0.2 | 保温砖 0.15、石棉粉 0.16、矿渣棉 0.06、玻璃棉 0.04 |
| 气体 | 0.01~0.6 | 0 ℃ 常压：氢 0.163、空气 0.0244、CO₂ 0.0137 |

排序：纯金属 > 合金 > 建筑材料 > 液体 > 绝热材料 > 气体（原文概括）。

## 三条规律（`#L5846-#L5860`）

1. **物态**：同一物质熔融或汽化后 $\lambda$ 变小——铝常温固态 230，700 ℃ 熔融态 92；水由冰→水→水蒸气依次变小。合金小于对应纯金属。
2. **液体**：水的 $\lambda$ 最大（约 0.6），有机液体 0.1~0.2，有机水溶液高于对应纯有机液体。
3. **气体**：氢最大（0 ℃ 常压 0.163），一般气体 0.01~0.1；相当宽的压力范围内压力无明显影响，只有很低（<2.7 kPa）或很高（>200 MPa）时才随压力增大而增大。

## 绝热材料的密度与湿度（`#L5852-#L5873`）

- 绝热材料呈纤维状或多孔结构，孔隙中空气 $\lambda$ 小，故密度越小、空气越多、$\lambda$ 越小；
- 但密度太小则孔隙尺寸大，空气自然对流与辐射增强，$\lambda$ 反而增大 → 存在**最佳密度**，由实验测定；
- 多孔结构易吸水，吸水后 $\lambda$ 增大、保温变差 → 露天设备必须防水；
- 选用时还要考虑材料耐温。

## 温度关系（`#L5875-#L5881`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $\lambda=\lambda_0(1+\alpha t)$ | （4-4） |
| **文字式** | $\text{热导率}_{\text{【W/(m·K)】}}=\text{0 ℃热导率}\times\left(1+\text{温度系数}_{\text{【1/℃】}}\times\text{温度}_{\text{【℃】}}\right)$ |  |

$\alpha$ 对大多数金属与液体为**负**，对大多数非金属与气体为**正**。计算时取 $\lambda$ 为两壁温下 $\lambda_1$、$\lambda_2$ 的算术平均值，或按平均温度 $t=(t_1+t_2)/2$ 取 $\lambda$。

## 判断

- "绝热材料越轻越好"只在孔隙尺寸足够小的前提下成立；泡沫类材料密度低到孔隙变大时，对流与辐射会把 $\lambda$ 重新推高，这就是最佳密度存在的原因。
- 表4-1 中绝热材料与气体只差一个数量级，说明保温层的效果主要来自"把大空隙里的对流锁死"，而不是材料本身不导热。

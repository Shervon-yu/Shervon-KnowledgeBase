# 实际流体机械能衡算式

## 压头损失（`#L1496-#L1514`）

实际流体有黏性、速度分布不均。等直径水平直管两截面的测压管显示 $p_1/\rho g>p_2/\rho g$，而 $z_1=z_2$、$u_1=u_2$，差值即该段压头损失。故能量衡算须加损失项：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $z_1+\dfrac{p_1}{\rho g}+\dfrac{u_1^2}{2g}=z_2+\dfrac{p_2}{\rho g}+\dfrac{u_2^2}{2g}+\sum H_f$ | （1-30） |
| **文字式** | $\text{位压头}_1+\text{静压头}_1+\text{动压头}_1=\text{位压头}_2+\text{静压头}_2+\text{动压头}_2+\text{总压头损失}$ |  |

$\sum H_f$ 为压头损失，m。含义：只有 1 截面总压头大于 2 截面总压头，流体才能克服内摩擦流向 2 截面。

## 外加压头（`#L1516-#L1530`）

把流体从总压头小处送往大处，需外界输入机械压头 $H$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $z_1+\dfrac{p_1}{\rho g}+\dfrac{u_1^2}{2g}+H=z_2+\dfrac{p_2}{\rho g}+\dfrac{u_2^2}{2g}+\sum H_f$ | （1-31） |
| **文字式** | $\text{上游总压头}+\text{外加压头}=\text{下游总压头}+\text{总压头损失}$ |  |

换算成单位质量（J/kg）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $z_1g+\dfrac{p_1}{\rho}+\dfrac{u_1^2}{2}+W=z_2g+\dfrac{p_2}{\rho}+\dfrac{u_2^2}{2}+\sum h_f$ | （1-32） |
| **文字式** | $\text{位能}_1+\text{静压能}_1+\text{动能}_1+\text{外加机械能}=\text{位能}_2+\text{静压能}_2+\text{动能}_2+\text{机械能损失}$ |  |

其中 $\sum h_f=g\sum H_f$、$W=gH$。**1-31 与 1-32 也统称伯努利方程式**。

## 解题四条规则（`#L1560-#L1570`）

1. **选截面**：两截面间流体必须连续、稳态、充满衡算系统；已知量与待求量应在截面上或两截面之间；截面与流向垂直。**不能选"流体已脱离管路"的下游截面**（例 1-9 中不能选 3—3）。
2. **定基准面**：一般取两截面中较低者的水平面，使 $z_1=0$；截面不水平时 $z$ 取截面中心到基准面的垂直距离。
3. **压力口径**：$p_1$ 与 $p_2$ 必须**同时**用表压或同时用绝对压力，不得混用。
4. **外加机械能**：$W$ 是每千克流体的量；算泵轴功率要乘质量流量再除以效率（第二章）。

## 例 1-9（`#L1538-#L1558`）

贮槽液面送碱液到蒸发器：垂直距离 7 m，进口管 φ89×3.5（内径 82 mm）、流速 1.5 m/s；出口管 φ76×3（内径 70 mm）；损失 40 J/kg；蒸发器表压 20 kPa；密度 1100 kg/m³。

- $u_2=1.5\times(82/70)^2=2.06$ m/s；
- $W=7\times9.81+\dfrac{20\times10^3}{1100}+\dfrac{2.06^2}{2}+40=68.7+18.2+2.12+40=129$ J/kg。

## 例 1-10（`#L1574-#L1592`）

高位槽向塔内加料，两端均为大气压、管内流速 0.5 m/s、总压头损失 1.2 m 液柱：

$x=\dfrac{0.5^2}{2\times9.81}+1.2=1.21$ m —— **动压头很小，位压头主要用来克服阻力**。

## 判断

- 例 1-10 的结果（0.013 m 动压头 vs 1.2 m 损失）说明常压自流管路里，位差几乎全部消耗在阻力上，估算时可先忽略动压头。
- 四条规则里最容易错的是第 1 条：选了脱离管路的截面，方程形式上仍成立，但含义已变。

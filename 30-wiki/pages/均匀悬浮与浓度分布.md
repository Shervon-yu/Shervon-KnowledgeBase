# 均匀悬浮与浓度分布

## 典型分布

釜内很难达到真正均匀。典型分布（图2-21，`#L2670-#L2674`）：低转速时上部浓度低于平均、下部高于平均；转速增加后趋于均匀；再增加，均匀性不再提高，沿液深始终存在一个高浓度区。

## 判据：浓度分布标准偏差

广泛采用（`#L2676-#L2682`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\bar{\sigma}=\sqrt{\dfrac{1}{n}\sum_{i=1}^{n}\left(\dfrac{c_{i}}{c_{0}}-1\right)^{2}}$ | （2-127） |
| **文字式** | $\text{浓度分布标准偏差}=\sqrt{\dfrac{1}{\text{测点数目}}\sum\left(\dfrac{\text{测点固相浓度}}{\text{全釜平均固相浓度}}-1\right)^{2}}$ |  |

$\bar{\sigma}$ 越小越均匀（`#L2688`）。

## 均匀悬浮临界转速怎么定

作 $\bar{\sigma}$ 随功率（转速）的变化曲线（图2-22）：随功率增加 $\bar{\sigma}$ 减小并趋于定值，即达到均匀悬浮；此时所需的最小转速（功率）即均匀悬浮临界转速（`#L2688`）。

注意：达到均匀悬浮时的均匀度（$\bar{\sigma}$ 值）与叶轮型式、转速有关——并不存在一个通用的"$\bar{\sigma}$ 合格线"。

## 研究现状

影响均匀悬浮的因素与完全悬浮一致；受测量技术限制，均匀悬浮临界转速的关联式发表得很少（`#L2692-#L2698`）。

## 与完全离底悬浮的关系

| 项 | 完全离底悬浮 | 均匀悬浮 |
|:---|:---|:---|
| 目标 | 釜底无静止颗粒 | 全釜浓度一致 |
| 判据 | 釜底停留 ≤1~2 s | $\bar{\sigma}$ 趋于定值 |
| 所需转速 | 低 | 高（功耗可达 4~10 倍） |
| 关联式 | 多（表2-22） | 很少 |

工程上先用离底悬浮定下限，再按出料/工艺要求往上加级别；两套判据不可混用。

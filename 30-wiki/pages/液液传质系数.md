# 液液传质系数

## 总速率式

|  |  |  |
|:---|:---:|---:|
| **符号式** | $r=K_{L}a\,\Delta C$ | （3-25） |
| **文字式** | $\text{传质速率}_{\text{【kmol/(s·m³)】}}=\text{总质量传质系数}_{\text{【1/s】}}\times\text{浓度推动力}_{\text{【kmol/m³】}}$ |  |

（`#L3431-#L3437`）

## 没有通用关联式

间歇液-液操作中 $K_La$ 是转速的函数（图 3-7，煤油-铜-水体系，`#L3439`）。该数据有代表性，但**不存在适用于各种情况的通用传质系数关联式**——少量杂质就能改变传质系数以及起泡、沉降性质（`#L3443`）。

## 工程做法：分开 K_L 与 a

工程上把传质系数 $K_L$ 与比界面积 $a$ 分开：先实验测传质速率，同时测比界面积，再反算 $K_L$（`#L3445`）。

## Schindler-Treybal 通用式

用物料连续流过搅拌釜、光透射测比界面积，得到（`#L3449-#L3461`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $K_{Lc}=K_{s}+B\left(\dfrac{D_{A}}{\theta_{C}}\right)^{0.5}$ | （3-26） |
| **文字式** | $\text{连续相传质系数}_{\text{【m/s】}}=\text{稳态连续相传质系数}_{\text{【m/s】}}+B\times\left(\dfrac{\text{扩散系数}_{\text{【m²/s】}}}{\text{凝并时间}_{\text{【s】}}}\right)^{0.5}$ |  |

$B$ 取 3.94（`#L3457`）。物理含义：连续相传质系数由“稳态项”与“凝并-再分散强化项”叠加。

## 间歇与连续加料的差别

间歇操作时，开始分散和保持分散所需功率，与物料连续加入釜中所需功率有相当大的差别；当**较轻一相从釜底加入、较重一相从釜上部加入**时更明显（`#L3467-#L3469`）。

设计含义：加料位置改变会改变实际所需功率与传质，不能照搬间歇数据。

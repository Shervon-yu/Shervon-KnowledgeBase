# 搅拌器流型：径向流、轴向流、切向流

## 前提

对工业上最常见的**立式圆筒、顶插、中心安装**搅拌机，釜内产生三种基本流型（`#L4838`）。流型主要取决于搅拌方式、搅拌器型式、容器形状、挡板等几何特征，以及流体性质与转速。

## 三种流型

| 流型 | 流动方向 | 产生原因 | 后果 |
|:---|:---|:---|:---|
| 径向流 | 垂直于搅拌轴，沿径向流动，碰壁后分成上下两股再回到叶端，**不穿过叶片**，形成上下两个循环 | 搅拌器的**圆盘**是产生径向流的主要原因 | 上下分区，轴向混合差 |
| 轴向流 | 平行于搅拌轴，桨叶把流体向下推，碰底翻上形成上下循环 | 流体对旋转叶片产生的**升力的反作用力** | 全釜循环好 |
| 切向流 | 无挡板时流体绕轴旋转，流速高时液面形成漩涡 | 无挡板容器的整体旋转 | 从桨叶周围周向卷吸的流量很小，混合效果很差 |

（`#L4840-#L4844`；图5-2 a/b/c 见 `图片\图5-2 搅拌器的流型.jpg`）

## 关键结论

三种流型通常**同时存在**：轴向流与径向流对混合起主要作用，**切向流应加以抑制**；采用挡板可削弱切向流、增强轴向流与径向流（`#L4846`）。

## 判断

"径向流"与"轴流型"只是**主导**流型：圆盘涡轮也带轴向分量，推进式也带少量径向分量。图5-2 的 (c) 之所以危险，是因为切向流把输入功率几乎全部变成液体的整体旋转（刚体转动），既不产生剪切也不产生上下交换——这正是"打漩"要加挡板的物理原因。

## 原书 §3.2：流型随雷诺数的四个区

把切线流当主分量，圆筒内的流动就是 **Rankine 复合涡流**：叶轮直径 70% 以内是强制涡流区（C.R.Z.），外面是拟自由涡流区；黏度升高时 $r_{c}$ 缩小，到过渡黏度时 $r_{c}=0$，湍流转层流（`#L3658`）。

| 区 | 判据 | 流动状态 | $N_{p}$ | $N_{qd}$（输出流数） |
|:---|:---|:---|:---|:---|
| A 完全层流 | $Re\leq10$ | 叶轮周围液体随叶轮转，远处**停滞** | $N_p\propto Re^{-1}$ | 极小 |
| B 部分层流 | $Re>10$ | 离心力产生输出流，远处开始流动，上下仍有环形停滞区 | 偏离 $Re^{-1}$ 延长线 | 陡升 |
| C 过渡 | $Re\approx$ 数十~数百 | 叶轮周围湍流、远处层流共存 | 转折 | **最大**（$Re\approx90$） |
| D 完全湍流 | $Re>10^{3}$ | 切线流为主 + 弱二次循环流 | 恒定 $N_{p\infty}$ | 有挡板时最大 |

要点（`#L3680`、`#L3688`、`#L3692`、`#L3696`）：

- A 区远处停滞 → 应选**大直径、能产生循环流**的叶轮（图3.3 A₂）。
- B 区输出流陡升，但叶轮上下仍有两个环形停滞流。
- C 区 $N_{qd}$ 峰值不在全湍流，而在 $Re\approx90$——因为远处液体几乎不转，液体与叶轮的速度差最大，离心效应支配。
- **插入挡板后 $N_{qd}$ 改为在湍流域最大**；Ito 观测到 $Re=300\sim500$ 时叶轮周围间歇性湍动。
- A、B、C 区液面降落不显著，**不需要挡板**；挡板后有停滞区，加了反而有害。

### 切线速度的实测式

理想 Rankine 分布（1.12)(1.13）只能定性；实际数据用下式关联更好（`#L3730`、`#L3734`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $r_{c}\geq r\gg0:\ v_{t}=r\omega;\qquad D/2\geq r\geq r_{c}:\ v r^{0.8}=\text{常数}$ | （3.1） |
| **文字式** | 强制涡流区切线速度正比半径；外侧按 $v\propto r^{-0.8}$ 衰减（比自由涡的 $r^{-1}$ 慢） |  |

最大切线速度 $v_{t,\max}=2\pi nr_{c}$，故任意半径处的 $v_{t}$ 可由式(3.1) 反推。$r_{c}$ 由 Yamamoto 归纳（`#L3742`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{r_{c}}{r_{1}}=1.23\left\{0.57+0.35\dfrac{d}{D}\right\}\left(\dfrac{b}{D}\right)^{0.036}n_{p}^{0.116}\{1\mp0.165(\sin\alpha)^{7.6}\}(\sin\theta)^{0.156}\left\{\dfrac{Re}{1000+1.43Re}\right\}$ | （3.2） |
| **文字式** | 强制涡流半径比 = 几何项 × 叶片数项 × 弯叶后倾角项 × 倾角项 × 雷诺数项；$\alpha>0$ 取负号、$\alpha<0$ 取正号 |  |

与 §1.1 的简式 `r_c/r_1=Re/(1000+1.6Re)` 相比，式(3.2) 多出 $d/D$、$b/D$、$n_p$、$\alpha$、$\theta$ 五个几何修正，工程估算用 1.28 即可，多叶/大 $b/D$ 时才需要。

### 输出流与循环流不是同一个量

用速度数据沿控制面做积分（`#L3770`、`#L3774`、`#L3778`）：

$$q_{d}=4\pi r_{s}\int_{0}^{Z_{p}}v_{r}\,\mathrm{d}Z\tag{3.3}$$

$$q_{c}=4\pi\int_{0}^{D/2}v_{z}r\,\mathrm{d}r\tag{3.3'}$$

$$q_{t}=4\pi r_{s}\int_{Z_{p}}^{Z_{s}}v_{r}\,\mathrm{d}Z+4\pi\int_{0}^{r_{s}}r v_{z}\,\mathrm{d}r\tag{3.3"}$$

且 $q_{t}=q_{d}$（进叶轮=出叶轮）。实测（$D=58.5$、$d=30$、$b=6$ cm、16 叶、72 r/min，`#L3806`）：

| 量 | 无挡板 | 有挡板 |
|:---|:---:|:---:|
| 输出流率 $q_{d}$ | 10.6 L/s | — |
| 感应流 $q_{i}$ | 8.4 L/s | — |
| 二次循环流 $q_{c}=q_{d}+q_{i}$ | 19 L/s | **74 L/s（4 倍）** |
| 水平循环流 $q_{H}$ | **110 L/s** | — |

结论：无挡板时水平循环占了绝大部分流量（110 vs 19），**垂直交换很差**；挡板的作用正是"堵住水平循环、把它转成垂直流"（`#L3806`）。

## 原书 §3.6：螺旋叶轮的流型另有专章

螺旋式叶轮（螺带、螺旋桨式）的高黏液体流型与混合速率、不均匀性直接相关，原书把这条放到第四章讨论（`#L4517`），因为高黏层的流动是"液体整体随桨叶作拟柱塞流"，切向流几乎不存在，判断标准已不是 $Re$ 分区而是**混合时间**。

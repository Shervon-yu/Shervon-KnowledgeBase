# 托马斯算法

## 问题形式

$M$ 个未知数 $u_1,\dots,u_M$ 的三对角方程组（式 A-1～A-5，＃L11631-11645）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $b_i u_{i-1}+d_i u_i+a_i u_{i+1}=c_i$，$i=1,\dots,M$ | （A-3 的一般形式） |
| **文字式** | $\text{下对角系数}\times\text{前一未知数}+\text{对角系数}\times\text{本未知数}+\text{上对角系数}\times\text{后一未知数}=\text{右端项}$ |  |

非零系数只在对角线 $d_i$、下对角线 $b_i$、上对角线 $a_i$ 上，首末两行分别缺 $b_1$ 与 $a_M$。二维隐式格式、ADI 的每一步、压力修正方程的逐线求解都会产生这种方程组。

## 消元（前向）

托马斯算法就是高斯消去法用在这种结构上（#L11649）。做法：从第二行起丢掉下对角线项，同时修正对角系数与右端项。逐行推导（A-6～A-16，＃L11651-11695）后得到通用递推式（A-21、A-22，＃L11717-11721）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_i'=d_i-\dfrac{b_i a_{i-1}}{d_{i-1}'}$，$c_i'=c_i-\dfrac{c_{i-1}' b_i}{d_{i-1}'}$，$i=2,\dots,M$ | （A-21、A-22） |
| **文字式** | $\text{新对角系数}=\text{对角系数}-\dfrac{\text{下对角}\times\text{上对角}}{\text{上一行新对角}}$；$\text{新右端}=\text{右端}-\dfrac{\text{上一行新右端}\times\text{下对角}}{\text{上一行新对角}}$ |  |

$i=1$ 时取 $d_1'=d_1$、$c_1'=c_1$。消元后方程组变成上二对角（A-23、A-24，＃L11729-11731），最后一式只含 $u_M$。

## 回代（后向）

由最后一式解出（A-25，＃L11735）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_M=\dfrac{c_M'}{d_M'}$ | （A-25） |
| **文字式** | $\text{末未知数}=\dfrac{\text{末新右端}}{\text{末新对角}}$ |  |

再逐个向上（A-27，＃L11743）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u_i=\dfrac{c_i'-a_i u_{i+1}}{d_i'}$，$i=M-1,\dots,1$ | （A-27） |
| **文字式** | $\text{本未知数}=\dfrac{\text{本新右端}-\text{上对角}\times\text{后一未知数}}{\text{本新对角}}$ |  |

## 运算量与适用条件

- 消元 $M-1$ 次、回代 $M-1$ 次，每次常数次乘除，总运算量 $O(M)$；而一般高斯消去是 $O(M^3)$。这是隐式格式能实用的关键。
- 需要 $d_i'\ne0$；若矩阵对角占优（$|d_i|\ge|b_i|+|a_i|$），消元不会出现零主元，数值也稳定（这是由高斯消去法的性质推出的判断，书里未单列此条件）。
- 三对角结构来自"每个方程只耦合相邻两个未知数"；二维问题逐线隐式时，每条网格线就是一个三对角方程组，扫描所有线即可。
- 书里把第 9 章库埃特流的 FORTRAN 程序作为托马斯算法的完整示例（＃L11749-11755），可直接对照 A-21/A-22/A-27 阅读。

## 适用边界

- 只适用于三对角（或经块化后的块三对角）结构；五对角、九对角要改用其他带状矩阵解法。
- 周期性边界会破坏三对角结构（首尾耦合），需用 Sherman-Morrison 或循环三对角算法处理——书里未涉及。
- 并行性差：消元与回代都是串行递推；大规模并行计算常用其他迭代法或并行扫描。

## 判断

托马斯算法不是"另一种解法"，而是高斯消去法在三对角结构上的特化；它的价值在于 $O(M)$ 的运算量，使隐式格式每步的代价从"解大矩阵"降到"扫一遍线"。凡是看到"逐线隐式""ADI""三对角"这些词，背后都是这个算法。

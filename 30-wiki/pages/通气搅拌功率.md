# 通气搅拌功率

## 现象

通入气体后搅拌功率 $P_G$ 明显低于通气前 $P_0$，并随气速增大而减小；高气速下变化趋缓（图2-16，`#L2195-#L2201`）。原因不是气体"帮忙搅拌"，而是桨叶背面形成的气穴使旋转阻力减小——功率曲线不同区段对应不同气穴状态（`#L2201`）。反过来说，停气瞬间功率会突增（`#L2322`）。

## Michel 式（最早、最常用）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P_{G}=C\left(\dfrac{P_{0}^{2}Nd^{4}}{Q_{G}^{0.56}}\right)^{0.45}$ | （2-75） |
| **文字式** | $\text{通气功率}_{\text{【W】}}=C\times\left(\dfrac{\text{通气前功率}_{\text{【W】}}^{2}\times\text{转速}_{\text{【1/s】}}\times\left(\text{搅拌器直径}_{\text{【m】}}\right)^{4}}{\text{通气速率}_{\text{【m³/s】}}^{0.56}}\right)^{0.45}$ |  |

$C$ 随 $d/D$ 变（`#L2211`）：$d/D=1/3$ 时 0.705；$2/5$ 时 0.543；$1/2$ 时 0.166。

**注意**：20-md 此式印/识为 $d^{4}$，而后面的 Yung（2-80）、Abrardi（2-83）同一结构均为 $d^{3}$；引用前核对原书（`#L2211` vs `#L2223`）。

该式简练实用、能在很宽操作范围内关联良好，尤其适用于湍流状态的低黏体系（`#L2203`）。

## Hughmark 式（适用范围宽）

研究者在七篇文献数据上统计各特征数对 $P_G$ 的显著性后回归（`#L2203-#L2205`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{P_{G}}{P_{0}}=0.1\left(\dfrac{Q_{G}}{NV}\right)^{-0.25}\left(\dfrac{N^{2}d^{4}}{g\,b\,V^{2/3}}\right)^{-0.2}$ | （2-81） |
| **文字式** | $\dfrac{\text{通气功率}}{\text{通气前功率}}=0.1\left(\dfrac{\text{通气速率}}{\text{转速}\times\text{装液体积}}\right)^{-0.25}\left(\dfrac{\text{转速}^{2}\times\left(\text{搅拌器直径}\right)^{4}}{g\times\text{叶片宽}\times\text{装液体积}^{2/3}}\right)^{-0.2}$ |  |

式中 $b$ 为叶片宽、$V$ 为装液体积（`#L2229`）。OCR 把 $V^{2/3}$ 识别成 `V^{23}`，按量纲还原并标注待核。

## 永田进治式（Rushton 涡轮专用，宽气速范围）

对 $d=D/4$、$D/3$、$D/2$、$3D/4$ 四种六叶 Rushton 涡轮，$b=d/5$、$l=d/4$，容器 $D=0.15/0.30/0.585$ m、四块 $B_{w}=0.1D$ 挡板、环形分布器进气，全部数据关联为（`#L1926`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\log\dfrac{P_{g}}{P_{0}}=-192\left(\dfrac{d}{D}\right)^{4.38}\left(\dfrac{d^{2}n}{\nu}\right)^{0.115}\left(\dfrac{dn^{2}}{g}\right)^{1.96(d/D)}\left(\dfrac{q}{nd^{3}}\right)$ | （1.67） |
| **文字式** | $\log\dfrac{\text{通气功率}}{\text{通气前功率}}=-192\times\left(\dfrac{\text{叶轮直径}_{\text{【m】}}}{\text{容器内径}_{\text{【m】}}}\right)^{4.38}\times\left(\dfrac{\text{叶轮直径}_{\text{【m】}}^{2}\times\text{转速}_{\text{【1/s】}}}{\text{运动黏度}_{\text{【m²/s】}}}\right)^{0.115}\times\left(\dfrac{\text{叶轮直径}_{\text{【m】}}\times\text{转速}_{\text{【1/s】}}^{2}}{g}\right)^{1.96\frac{\text{叶轮直径}_{\text{【m】}}}{\text{容器内径}_{\text{【m】}}}}\times\left(\dfrac{\text{气体流率}_{\text{【m³/s】}}}{\text{转速}_{\text{【1/s】}}\times\text{叶轮直径}_{\text{【m】}}^{3}}\right)$ |  |

要点（`#L1942`、`#L1944`）：

- 通气功率比是**通气数 $q/(nd^{3})$、弗鲁德数 $dn^{2}/g$、雷诺数 $d^{2}n/\nu$、几何比 $d/D$** 的函数；$d/D$ 在指数上又出现一次（$1.96d/D$），故几何影响比 Michel 式强。
- 气体由**中央单喷管**加入时，$P_{g}/P_{0}$ 的下降比环形分布器**深得多**——进气位置改变了气穴形态，不能混用同一条曲线。
- 大气量下 $P_{g}$ 降到 $P_{0}$ 的 30~50%（`#L1914`）。

例1.9（`#L1946`）：$D=0.60$ m、$d=0.20$ m、$n=3$ s⁻¹、$q=0.002$ m³/s、清水。代入式(1.67) 得 $\log\left(P_{g}/P_{0}\right)=-0.165$，即 $P_{g}/P_{0}=0.684$；由 Rushton 图 Np=6.2 算得 $P_{0}=5.45$ kg·m/s，故 $P_{g}=3.73$ kg·m/s（`#L1961`、`#L1969`）。

## 电机选型的两条路

1. 按**不通气**功率选电机——保险，但能量利用率低；
2. 按**通气**功率选电机——利用率高，但要配多级或无级调速：不通气/少通气时低转速，正常通气时再升到设定转速（`#L2322`）。

工程折中：若用固定转速电机按方案 2 选型，停气瞬间的功率突增可能过载，必须校核；变速方案是正解。

电机选型与结构细节见 [[气液搅拌设备设计要点]]。

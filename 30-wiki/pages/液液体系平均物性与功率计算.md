# 液液体系平均物性与功率计算

## 计算思路

液-液分散的轴功率可直接用**单相液体**中测得的功率准数 $N_p$ 计算，但必须先把两相物性折算成合理的平均值（`#L2517`）。

## 敞口设备（通用）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu_{av}=\mu_{d}^{X}\mu_{c}^{Y}$ | （2-110） |
| **文字式** | $\text{平均黏度}_{\text{【Pa·s】}}=\text{分散相黏度}_{\text{【Pa·s】}}^{X}\times\text{连续相黏度}_{\text{【Pa·s】}}^{Y}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho_{av}=\varphi_{d}\rho_{d}+\varphi_{c}\rho_{c}$ | （2-111） |
| **文字式** | $\text{平均密度}_{\text{【kg/m³】}}=\text{分散相体积分数}\times\text{分散相密度}_{\text{【kg/m³】}}+\text{连续相体积分数}\times\text{连续相密度}_{\text{【kg/m³】}}$ |  |

20-md 未印出 $X$、$Y$ 的取法，引用前核对原书（`#L2519-#L2523`）；工程上常取 $X$、$Y$ 为两相体积分数。

## 封闭设备、无挡板（Laity-Treybal）

水相体积比 >40%（`#L2529`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu_{av}=\dfrac{\mu_{w}}{\varphi_{o}}\left(1+\dfrac{6.0\varphi_{o}\mu_{o}}{\mu_{w}+\mu_{o}}\right)$ | （2-112） |
| **文字式** | $\text{平均黏度}_{\text{【Pa·s】}}=\dfrac{\text{水相黏度}_{\text{【Pa·s】}}}{\text{有机相体积分数}}\times\left(1+\dfrac{6.0\times\text{有机相体积分数}\times\text{有机相黏度}_{\text{【Pa·s】}}}{\text{水相黏度}_{\text{【Pa·s】}}+\text{有机相黏度}_{\text{【Pa·s】}}}\right)$ |  |

水相体积比 <40%（`#L2533`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu_{av}=\dfrac{\mu_{o}}{\varphi_{o}}\left(1-\dfrac{1.5\varphi_{w}\mu_{w}}{\mu_{w}+\mu_{o}}\right)$ | （2-113） |
| **文字式** | $\text{平均黏度}_{\text{【Pa·s】}}=\dfrac{\text{有机相黏度}_{\text{【Pa·s】}}}{\text{有机相体积分数}}\times\left(1-\dfrac{1.5\times\text{水相体积分数}\times\text{水相黏度}_{\text{【Pa·s】}}}{\text{水相黏度}_{\text{【Pa·s】}}+\text{有机相黏度}_{\text{【Pa·s】}}}\right)$ |  |

下标 $w$ 水相、$o$ 有机物（`#L2535-#L2539`）。

## 有挡板（Vermeulen）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu_{av}=\dfrac{\mu_{c}}{1-\varphi_{d}}\left(1+\varphi_{d}\dfrac{1.5\mu_{d}}{\mu_{c}+\mu_{d}}\right)$ | （2-114） |
| **文字式** | $\text{平均黏度}_{\text{【Pa·s】}}=\dfrac{\text{连续相黏度}_{\text{【Pa·s】}}}{1-\text{分散相体积分数}}\times\left(1+\text{分散相体积分数}\times\dfrac{1.5\times\text{分散相黏度}_{\text{【Pa·s】}}}{\text{连续相黏度}_{\text{【Pa·s】}}+\text{分散相黏度}_{\text{【Pa·s】}}}\right)$ |  |

## 液-液乳化液的功率估算（永田）

《混合原理与应用》§1.4.3 明确说：**至今没有液-液乳化液叶轮功率的直接实测关联**，只能借用沉降浆（悬浮液）的两条式子（`#L2065`）：

1. 用 $P_{s}g_{c}=K\bar{\rho}n^{3}d^{5}$（式1.68）与 $\bar{\rho}=\phi\rho_{s}+(1-\phi)\rho_{w}$（式1.70）算，但把固相密度 $\rho_{s}$ 换成分散相密度 $\rho_{0}$；
2. 平均黏度用 Laity-Treybal 式（即上面式2-112 / 2-113 的同源形式，原书编号 1.74 / 1.74′）：水相 $>40\%$ 用 $\mu_{m}=\dfrac{\mu_{w}}{x_{w}}\left[1+\dfrac{6.0x_{0}\mu_{0}}{\mu_{w}+\mu_{0}}\right]$，水相 $<40\%$ 用 $\mu_{m}=\dfrac{\mu_{0}}{x_{0}}\left[1-\dfrac{1.5x_{w}\mu_{w}}{\mu_{w}+\mu_{0}}\right]$，$x$ 为体积分率、下标 0=有机相、$w$=水相（`#L2067`、`#L2073`）。

作者把这一条定为**估算**而非关联：乳化液的内相黏度效应、界面膜与液滴变形都没有进入式子，误差可能远大于悬浮液。

## 用法

1. 判断敞口/封闭、有无挡板，选对应平均黏度式；
2. 算 $\rho_{av}$；
3. 用 $\mu_{av}$、$\rho_{av}$ 算 $Re$，查单相 $N_p$–$Re$ 曲线得 $N_p$；
4. 按式（1-2）或 $P=N_p\rho_{av}N^{3}d^{5}$ 算功率。

注意：平均物性法只是工程近似，两相体系真实剪切场不均，误差可能达 10%~20%；关键工况应做中试实测。

# 黏弹性流体的反常流动

## 定义

黏弹性流体兼有黏性液体与弹性固体的特性，变形后能弹性恢复；聚合物熔体与溶液是典型代表。定态剪切下表现纯黏性非牛顿特性，剪切发生变化（扩大、收缩、非定态）时表现出弹性（`#L1335`）。

## 六种反常流动

1. **爬杆效应（Weissenberg 效应）**：用搅拌轴搅拌时，转轴处液面沿轴上升、离轴远处液面下降——与牛顿流体相反（`#L1337`）。
2. **膨胀效应（Barus 效应）**：从圆管或小孔流出时射流膨胀，最大直径 $d_{\max}$ 可达管内径的 2~3 倍；圆管越长膨胀越小，充分长时膨胀比趋于定值（`#L1343`）。
3. **记忆现象（弹性滞后）**：移去压力梯度后流体反向移动一段距离才停止（`#L1347`）。
4. **反向次流**：旋转圆盘形成切向主流；牛顿流体次流为轴心向上、四周向下，黏弹性流体相反（`#L1349`）。
5. **湍流减阻（Toms 效应）**：含高分子聚合物的溶液在湍流时阻力明显低于纯溶剂，含量甚微也有效（`#L1351`）。
6. **应力松弛**：恒剪切下应力先快降后缓降，趋于零；理想黏性流体则瞬间无穷大再回零（`#L1353`）。

此外还有无管虹吸、熔体破裂等（`#L1355`）。

## 描述所需的三个物质函数

与牛顿流体不同，剪切流动需三个物质函数（`#L1357-#L1377`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu(\dot{\gamma})=\dfrac{\tau_{12}}{\dot{\gamma}}$ | （2-14） |
| **文字式** | $\text{黏度}_{\text{【Pa·s】}}=\dfrac{\text{切应力}_{\text{【Pa】}}}{\text{切应变速率}_{\text{【1/s】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\psi_{1}(\dot{\gamma})=\dfrac{\tau_{11}-\tau_{22}}{\dot{\gamma}^{2}}=\dfrac{N_{1}}{\dot{\gamma}^{2}}$ | （2-15） |
| **文字式** | $\text{第一法向应力系数}_{\text{【Pa·s}^2\text{】}}=\dfrac{\text{第一法向应力差}_{\text{【Pa】}}}{\left(\text{切应变速率}_{\text{【1/s】}}\right)^{2}}$ |  |

第二法向应力系数 $\psi_2=(\tau_{22}-\tau_{33})/\dot{\gamma}^2=N_2/\dot{\gamma}^2$（式2-16）。通常 $N_1>0$，$N_2<0$ 且比 $N_1$ 小一个数量级，多数情况下可忽略（`#L1379`）。

## 对搅拌的后果

- 爬杆效应会让**物料整体包裹在搅拌器上、与轴同步旋转**，混合与传热都无法正常进行（`#L1341`）——这是黏弹性物料选叶轮时最硬的一条限制：不能用纯剪切型、细轴小间距的叶轮。
- 反向次流改变釜内循环方向与传热面更新方式，传热与混合时间的关联式不能照搬牛顿流体结果。
- 减阻效应意味着同样的叶轮、转速下实际湍流强度与功耗关系偏离牛顿流体。

## 附件

- 描述黏弹性的力学模型有三类：经验模型、线性黏弹性模型（Maxwell 串联、Kelvin-Voigt 并联等，表2-4）、分子模型（`#L1381-#L1430`）。搅拌工程中通常只用经验模型拟合 $\mu(\dot{\gamma})$ 与 $\psi_1(\dot{\gamma})$。

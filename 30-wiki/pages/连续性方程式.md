# 连续性方程式

## 稳态与非稳态（`#L1344-#L1348`）

| 类型 | 定义 | 例 |
|:---|:---|:---|
| 稳态流动 | 任一点的流速、压力等参数**不随时间**改变 | 正常运行的管路 |
| 非稳态流动 | 参数部分或全部随时间改变 | 变动水位水槽经小孔流出 |

化工厂中多为稳态流动；本书除特别指明外均按稳态处理。

## 连续性方程（`#L1350-#L1382`）

取截面 1—1 流入、2—2 流出，无漏损，则质量守恒：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $q_{m_1}=q_{m_2}$ | （1-19） |
| **文字式** | $\text{进口质量流量}_{\text{【kg/s】}}=\text{出口质量流量}_{\text{【kg/s】}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho_1A_1u_1=\rho_2A_2u_2$ | （1-20） |
| **文字式** | $\text{密度}_1\times\text{截面积}_1\times\text{流速}_1=\text{密度}_2\times\text{截面积}_2\times\text{流速}_2$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\rho Au=\text{常数}$ | （1-21） |
| **文字式** | $\text{密度}\times\text{截面积}\times\text{流速}=\text{常数}$ |  |

不可压缩流体 $\rho$ 为常数：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Au=\text{常数}$ | （1-22） |
| **文字式** | $\text{截面积}\times\text{流速}=\text{常数}$ |  |

圆形管：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{u_1}{u_2}=\left(\dfrac{d_2}{d_1}\right)^2$ | （1-23） |
| **文字式** | $\dfrac{\text{截面1流速}}{\text{截面2流速}}=\left(\dfrac{\text{截面2内径}}{\text{截面1内径}}\right)^2$ |  |

即不可压缩流体流速与管径**平方成反比**：截面大处流速小。

## 例 1-8（`#L1384-#L1414`）

输水管路 $d_1=2.5$ cm、$d_2=10$ cm、$d_3=5$ cm，流量 4 L/s：

- $u_1=4\times10^{-3}/(0.785\times0.025^2)=8.15$ m/s；
- $u_2=8.15\times(2.5/10)^2=0.51$ m/s；
- $u_3=8.15\times(2.5/5)^2=2.04$ m/s；
- 流量加倍，三段流速都加倍（16.3 / 1.02 / 4.08 m/s）；减半则各减半（4.08 / 0.26 / 1.02 m/s）。

## 判断

- 1-22 只对不可压缩流体成立；气体必须用 1-21，因为 $\rho$ 随压力变。
- 例 1-8 说明连续性方程是"比例关系"：任何一段流量变化，所有截面同比例变。

# 流动类型与雷诺数

## 雷诺实验（`#L1694-#L1706`）

装置：恒液面水槽 + 喇叭口玻璃管 + 阀门 + 有色指示液细管。现象三种：

| 流速 | 现象 | 流型 |
|:---|:---|:---|
| 小 | 有色液成一条清晰细直线 | 层流 |
| 增大到某值 | 细线波动成波浪形、不规则 | 过渡 |
| 再增大 | 细线被冲断、全管均匀着色 | 湍流 |

## 两种流型（`#L1708-#L1718`）

- **层流（滞流）**：质点沿管轴平行作直线运动、互不混合，像同心圆筒一层层平行流动；
- **湍流（紊流）**：质点除前进外速度大小方向都随机变化，相互碰撞混合。

## 雷诺数（`#L1720-#L1728`）

影响因素：流速 $u$ ↑、管径 $d$ ↑、密度 $\rho$ ↑、黏度 $\mu$ ↓ → 易转湍流。四者组成的复合数群 $\dfrac{du\rho}{\mu}$ 即判据：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re=\dfrac{du\rho}{\mu}=\dfrac{du}{\nu}$ | （无编号） |
| **文字式** | $\text{雷诺数}=\dfrac{\text{管内径}_{\text{【m】}}\times\text{流速}_{\text{【m/s】}}\times\text{密度}_{\text{【kg/m³】}}}{\text{黏度}_{\text{【Pa·s】}}}$ |  |

（书内该式未单独编号，位于 `#L1720` 附近；本书式 1-36 是层流速度分布微分方程，勿混。）

量纲：$\dim Re=\dfrac{(L)(L/T)(M/L^3)}{M/(LT)}=L^0M^0T^0=1$ ——**无量纲**，任何单位制下数值相同。

## 判据（`#L1726`）

| $Re$ | 流型 |
|:---|:---|
| ≤2000 | 层流区 |
| 2000~4000 | 过渡区（不稳定，取决于外界扰动：截面突变、障碍物、锐角入口、震动） |
| ≥4000 | 湍流区 |

**相似原理**：两管中 $Re$ 相同、边界几何相似，则流动状态相同。

## 三个算例

- 例 1-12（`#L1730-#L1750`）：1/10 模型，生产 80 ℃ 空气 2.5 m/s → 模型 20 ℃ 空气需 $u_2=2.5\times10\times\dfrac{1}{1.2}\times0.858=17.9$ m/s（$\rho_2/\rho_1=353/293=1.2$、$\mu_2/\mu_1=18.1/21.1$）。
- 例 1-13（`#L1754-#L1768`）：φ25 mm 水管、20 ℃ 水 1 m/s → $Re=2.5\times10^4$ 湍流；层流最大 $u=2000\times0.001/(0.025\times998.2)=0.08$ m/s。
- 例 1-14（`#L1770-#L1780`）：φ200 mm 风管、40 ℃ 空气 3 m/s、$\nu=16.96\times10^{-6}$ m²/s → $Re=3.54\times10^4$ 湍流；层流最大 0.17 m/s。

## 判断

- 例 1-13 与 1-14 的对比很说明问题：同是"常温常压"，水的层流上限 0.08 m/s、空气约 0.17 m/s，量级接近——因为 $Re$ 把 $d$、$\rho$、$\mu$ 都折进去了。
- 过渡区不能当稳定工况设计：2000~4000 之间流型随扰动跳变，阻力与传热都会跳。

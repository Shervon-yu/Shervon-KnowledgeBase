# 双流体模型的基本方程

## 方程组成（`#L3085`）

无温度变化时**不考虑能量方程**，只有连续性方程与动量守恒方程。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial \rho_i\alpha_i}{\partial t}+\nabla\cdot(\rho_i\alpha_i\mathbf{u}_i)=\sum_{j=1}^{n}m_{ji}$ | （7.1） |
| **文字式** | $\dfrac{\partial(\text{密度}_i\times\text{体积分率}_i)}{\partial\text{时间}}+\nabla\cdot(\text{密度}_i\times\text{体积分率}_i\times\text{速度}_i)=\sum_{j=1}^{n}\text{从相}_{j}\text{到相}_{i}\text{的质量传递通量}_{ji}$ |  |

- $\alpha_i$ 体积分率、$\mathbf{u}_i$ 速度、$m_{ji}$ 从 $j$ 相到 $i$ 相的质量传递通量；
- **不考虑传质** → $\sum_j m_{ji}=0$（7.2）。

## 动量守恒（`#L3099-#L3111`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial \rho_i\alpha_i\mathbf{u}_i}{\partial t}+\nabla\cdot(\rho_i\alpha_i\mathbf{u}_i)=-\alpha_i\nabla P+\nabla\cdot(\alpha_i\boldsymbol{\tau}_i)+\mathbf{F}_{i,j}+\rho_i\alpha_i\mathbf{g}$ | （7.3） |
| **文字式** | $\dfrac{\partial(\text{密度}_i\times\text{体积分率}_i\times\text{速度}_i)}{\partial\text{时间}}+\nabla\cdot(\text{密度}_i\times\text{体积分率}_i\times\text{速度}_i)=-\text{体积分率}_i\times\nabla\text{压力}+\nabla\cdot(\text{体积分率}_i\times\text{应力张量}_i)+\text{相间作用力}_{i,j}+\text{密度}_i\times\text{体积分率}_i\times\text{重力加速度}$ |  |

## 应力张量与有效黏度（`#L3105-#L3115`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\boldsymbol{\tau}_i=-\mu_{\mathrm{eff},i}\left[\nabla\mathbf{u}_i+(\nabla\mathbf{u}_i)^{\mathrm{T}}-\dfrac{2}{3}I(\nabla\cdot\mathbf{u}_i)\right]$ | （7.4） |
| **文字式** | $\text{应力张量}_i=-\text{有效黏度}_i\times\left[\nabla\text{速度}_i+(\nabla\text{速度}_i)^{\mathrm{T}}-\dfrac{2}{3}\times\text{单位张量}\times(\nabla\cdot\text{速度}_i)\right]$ |  |

$$\mu_{\mathrm{eff},i}=\mu_{i,\mathrm{L}}+\mu_{t,\mathrm{L}}+\mu_{\mathrm{BIT},\mathrm{L}}\tag{7.5}$$

**有效黏度 = 分子黏度 + 湍流黏度 + 气泡引起湍流项**（三项的物理来历：层流黏性、湍流涡扩散、气泡运动产生的额外搅动）。

## 封闭问题（`#L3117`）

双流体模型的**关键**是对相间作用项封闭：

- 相间作用力 $\mathbf{F}_{i,j}$（曳力、附加质量力、升力、湍动扩散力、壁面润滑力）；
- 相间湍动项 $\nabla\cdot(\alpha_i\boldsymbol{\tau}_i)$。

> 这两项的模型选择，直接决定模拟能否收敛、结果是否合理——第7章后续大半篇幅都在处理它。

## 判断

- 方程本身是"两套 N-S + 相间交换项"，形式并不复杂；**难在封闭**；
- $\mu_{\mathrm{BIT}}$（气泡诱导湍流）项常被忽略，但在高气含率下有量级影响；本书在湍流模型里通过相含率变量引入；
- 注意 7.3 的动量方程左边第二项在原文写作 $\nabla\cdot(\rho_i\alpha_i u_i)$，量纲上应为 $\nabla\cdot(\rho_i\alpha_i\mathbf{u}_i\mathbf{u}_i)$——原文如此，按原文照录，**使用时按标准双流体形式补全**。

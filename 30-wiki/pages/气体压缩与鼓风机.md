# 气体压缩与鼓风机

## 压缩外功（`#L4229-#L4273`）

绝热压缩后温度：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $T_2=T_1\left(\dfrac{p_2}{p_1}\right)^{(\kappa-1)/\kappa}$ | （2-28） |
| **文字式** | $\text{排气温度}=\text{吸气温度}\times\left(\dfrac{\text{排出压力}}{\text{吸入压力}}\right)^{(\text{绝热指数}-1)/\text{绝热指数}}$ |  |

压缩功推导：吸入选 $p_1v_1$、压缩 $\int_1^2 p(-\mathrm{d}v)$、排出 $p_2v_2$，三项代数和化简为：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W=\int_1^2 p(-\mathrm{d}v)+p_2v_2-p_1v_1=\int_1^2 v\,\mathrm{d}p$ | （2-29） |
| **文字式** | $\text{压缩功}=\text{压缩过程功}+\text{排出功}-\text{吸入功}=\int\text{比体积}\,\mathrm{d}\text{压力}$ |  |

等温压缩（$pv$=常数）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W_{\text{iso}}=\dfrac{RT_1}{M}\ln\dfrac{p_2}{p_1}$ | （2-32） |
| **文字式** | $\text{等温压缩功}_{\text{【kJ/kg】}}=\dfrac{\text{气体常数}\times\text{吸气温度}}{\text{摩尔质量}}\times\ln\dfrac{\text{排出压力}}{\text{吸入压力}}$ |  |

绝热压缩（$pv^\kappa$=常数）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W_{\text{ad}}=\dfrac{\kappa}{\kappa-1}\dfrac{RT_1}{M}\left[\left(\dfrac{p_2}{p_1}\right)^{(\kappa-1)/\kappa}-1\right]$ | （2-34） |
| **文字式** | $\text{绝热压缩功}_{\text{【kJ/kg】}}=\dfrac{\text{绝热指数}}{\text{绝热指数}-1}\times\dfrac{\text{气体常数}\times\text{吸气温度}}{\text{摩尔质量}}\times\left[\left(\dfrac{\text{压比}}\right)^{(\text{绝热指数}-1)/\text{绝热指数}}-1\right]$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $W_{\text{ad}}=\dfrac{\kappa}{\kappa-1}\dfrac{R}{M}(T_2-T_1)$ | （2-35） |
| **文字式** | $\text{绝热压缩功}=\dfrac{\text{绝热指数}}{\text{绝热指数}-1}\times\dfrac{\text{气体常数}}{\text{摩尔质量}}\times\text{温升}$ |  |

等温压缩功最小（图2-31 中 $C'BC$ 面积即两者之差）。

## 例2-9（`#L4275-#L4293`）

氧气 7 ℃、2.4 kg/s，230 → 630 kPa（绝压），$\kappa$=1.4、$M$=32 kg/kmol：

- $T_2$=373.4 K=100.4 ℃；
- $W_{\text{iso}}$=73.3 kJ/kg → 176 kW；
- $W_{\text{ad}}$=84.9 kJ/kg → 204 kW。

结论：**绝热压缩外功比等温压缩大**（本例大 16%）。

## 离心式鼓风机与压缩机（`#L4295-#L4319`）

| 设备 | 特点 |
|:---|:---|
| 离心鼓风机 | 单级进、出口最大压差约 20 kPa；需更压差则多级；压比不大、各级叶轮直径近似相等、无冷却装置 |
| 离心压缩机 | 压比大、多级；排气温度可达 100 ℃ 以上，需冷却；冷却两法：机壳外水夹套、分段+段间中间冷却器；气体体积逐级缩小，叶轮直径与宽度也逐级缩小 |

共同优点：流量大而均匀、效率高、运转平稳、结构紧凑、气体不与润滑油接触。大型合成氨高压离心压缩机出口可达 30 MPa。

## 罗茨鼓风机（`#L4321-#L4327`）

原理同齿轮泵：机壳内两转子反向旋转，间隙很小，气体从一侧吸入、另一侧排出。

- 流量与转速成正比；定转速下出口压力升高时，间隙泄漏增多、流量略减，通常视为基本不变；
- 出口压力一般 <80 kPa、流量约 <10 m³/s；
- 一般用**旁路阀**调节流量；操作温度不得超过 85 ℃（转子热膨胀卡死）；
- 出口应装安全阀与气体稳压罐。

## 往复式压缩机（`#L4329-#L4371`）

### 余隙与排气量（`#L4337-#L4341`）

排气终了活塞与缸盖间必须留余隙，残余高压气体在吸气初期先膨胀，导致**一次循环吸气量小于活塞扫过体积**。

- 余隙比 $\varepsilon$=余隙体积/活塞扫过体积，一般 **0.03~0.10**；
- 余隙与压缩比越大 → 吸气量越小 → 排气量越小，故两者都受限。

### 分级与中间冷却（`#L4343-#L4371`）

压比太大时应分级压缩，各级间设中间冷却器把气体冷却回 $T_1$。绝热压缩无法在短行程内传出热量，故实际偏离等温；分级+冷却使过程近似等温，压缩功减少（图2-34 中 $C'B'B''C''$ 面积）。级数过多则设备投资抵消动力节省。

| 级数 | 1 | 2 | 3 | 4~5 | 5~6 | 6~7 |
|:---|:---|:---|:---|:---|:---|:---|
| 压力/MPa | ~0.7 | 0.7~1 | 2~6 | ~20 | ~30 | ~100 |

| 排气量/m³·min⁻¹ | 0.1~1.5（小型） | 1.5~15（中型） | ≥20（大型） |
|:---|:---|:---|:---|
| 压缩比 | 6~12 | 5~8 | 2~4 |

各级压比相等时总功耗最小：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R=\sqrt[z]{p_2/p_1}$ | （2-36） |
| **文字式** | $\text{每级压缩比}=\sqrt[\text{级数}]{\dfrac{\text{最终压力}}{\text{初始压力}}}$ |  |

特点：适应性强、排出压力范围最广（低压到高压），但外形大、结构复杂、易损件多、气流脉动，多用于中、小流量高压场合。

## 判断

- 2-34 与 2-35 是同一件事的两种写法：知道温升用 2-35，知道压比用 2-34。
- 分级+中间冷却的本质是"用设备投资换回接近等温的功"，级数由经济性而非物理极限决定。
- 罗茨鼓风机是正位移式，故流量与压头解耦、靠旁路调节、必须装安全阀——与齿轮泵同一套逻辑。

# 混合设备的放大准则

## 现状：资料少、难度大（`#L15523-#L15527`）

已发表的固体混合放大资料较少；国内厂家积累的经验与试验数据不丰富；影响放大的因素复杂——不仅有粉粒体在混合过程中的运动与动力因素，混料特性在某种程度上还具**可变性**。

- **几何相似的转筒式**：把速度调整到给出相似的运动、并使加入物料所占体积百分数相同，放大**已基本成功**；
- **内部有旋转装置的设备**：还有间隙、相对于混合物体积的刮板面积、旋转装置尺寸与转速等放大问题待解决；
- 厂家应根据经验尽可能提供放大数据。

## 三个相似（`#L15529`）

与搅拌设备一样：几何相似、运动相似、动力相似。

## 无量纲方程（式12-8，`#L15531-#L15549`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $f_1\left(\dfrac{n^{2}R}{g},\ \dfrac{Kt}{L_{\mathrm{e}}^{2}},\ \dfrac{P}{n^{3}R^{5}\rho},\ J,\ \dfrac{R}{L_{\mathrm{e}}}\right)=0$ | （12-8） |
| **文字式** | $f_1\left(\dfrac{\text{回转速}^{2}_{\text{【r/s】}}\times\text{回转半径}_{\text{【m】}}}{9.81},\ \dfrac{\text{混合速度系数}\times\text{混合时间}_{\text{【s】}}}{\text{有效混合长度}^{2}_{\text{【m】}}},\ \dfrac{\text{功率}_{\text{【W】}}}{\text{回转速}^{3}_{\text{【r/s】}}\times\text{回转半径}^{5}_{\text{【m】}}\times\text{密度}_{\text{【kg/m³】}}},\ \text{装料系数},\ \dfrac{\text{回转半径}_{\text{【m】}}}{\text{有效混合长度}_{\text{【m】}}}\right)=0$ |  |

## 几何相似后（式12-9，`#L15551-#L15555`）

$R/L_e$ 为常数，式12-8 简化为：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $f_2\left(\dfrac{n^{2}R}{g},\ \dfrac{Kt}{L_{\mathrm{e}}^{2}},\ \dfrac{P}{n^{3}R^{5}\rho},\ J\right)=0$ | （12-9） |
| **文字式** | $f_2\left(\dfrac{\text{回转速}^{2}_{\text{【r/s】}}\times\text{回转半径}_{\text{【m】}}}{9.81},\ \dfrac{\text{混合速度系数}\times\text{混合时间}_{\text{【s】}}}{\text{有效混合长度}^{2}_{\text{【m】}}},\ \dfrac{\text{功率}_{\text{【W】}}}{\text{回转速}^{3}_{\text{【r/s】}}\times\text{回转半径}^{5}_{\text{【m】}}\times\text{密度}_{\text{【kg/m³】}}},\ \text{装料系数}\right)=0$ |  |

$n^{2}R/g$ 是**离心力与重力之比**，即弗劳德准数，表示力学相似条件。若这一比值是实验装置与几何相似工业装置性能唯一明显不同的因素，则按 **Fr 不变**放大。

## 再简化（式12-10、12-11，`#L15557-#L15567`）

几何相似 + 运动相似、装料系数保持不变（一般为 **30%~40%**，随设备型式略变）时：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $f_3\left(\dfrac{n^{2}R}{g},\ \dfrac{P}{n^{3}R^{5}\rho}\right)=0$ | （12-10） |
| **文字式** | $f_3\left(\dfrac{\text{回转速}^{2}_{\text{【r/s】}}\times\text{回转半径}_{\text{【m】}}}{9.81},\ \dfrac{\text{功率}_{\text{【W】}}}{\text{回转速}^{3}_{\text{【r/s】}}\times\text{回转半径}^{5}_{\text{【m】}}\times\text{密度}_{\text{【kg/m³】}}}\right)=0$ |  |

于是动力系数可表示为：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{P}{n^{3}R^{5}\rho}=f_4\left(\dfrac{n^{2}R}{g}\right)$ | （12-11） |
| **文字式** | $\dfrac{\text{功率}_{\text{【W】}}}{\text{回转速}^{3}_{\text{【r/s】}}\times\text{回转半径}^{5}_{\text{【m】}}\times\text{密度}_{\text{【kg/m³】}}}=f_4\left(\dfrac{\text{回转速}^{2}_{\text{【r/s】}}\times\text{回转半径}_{\text{【m】}}}{9.81}\right)$ |  |

动力系数的具体数值**需通过试验确定**（`#L15567`）。

## 功率与特征尺寸（式12-12，`#L15569-#L15573`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P\propto L^{3\sim3.5}$ | （12-12） |
| **文字式** | $\text{功率}\propto\text{特征尺寸}^{3\sim3.5}$ |  |

比例系数也需试验确定。

## 判断

- 式12-12 的指数 3~3.5 与搅拌釜的「单位体积功率随 $D$ 下降」同源：体积按 $L^3$ 涨、功率按 $L^{3\sim3.5}$ 涨，所以大设备的 Pv 反而略升或持平，但**混合时间通常会变长**，这是固体混合放大比液体更依赖试验的根本原因。
- 转筒式之所以「Fr 不变 + 装料体积百分数相同」就够了，是因为其混合完全由料层的重力–离心力平衡决定；一旦内部有桨叶，桨叶–料层间隙、刮板相对面积成为新的自由度，无量纲化不再充分。
- 工程做法：能实验就实验（这是原文反复强调的）；不能实验时，按 Fr 不变定转速、按式12-12 估功率，并把装料系数控制在 30%~40% 区间内。

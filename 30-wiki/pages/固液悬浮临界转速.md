# 固液悬浮临界转速

## 定义

釜内悬浮操作达到某一指定悬浮状态时所需的最小转速（`#L2620`）；只有定了临界转速，才能算过程所需的最小功率。

## 怎么测

- **直接观察法**：肉眼观察釜底颗粒，全部运动且釜底停留不超过 1~2 s 即判定（`#L2624`）；实验室可得到满意结果。
- **电导法**：釜底装多个电导元件，按电信号变化判定（`#L2626`）；可用于不透明釜体。

## Zwietering 式（最经典）

Zwietering 发现釜结构尺寸、固相浓度、液体黏度、粒径、两相密度差是主因，并提出最早、被广泛证实的关联式（`#L2628-#L2650`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $N_{c}=K\,d^{-0.85}d_{p}^{0.2}X^{0.13}v^{0.1}\left|g\dfrac{\rho_{p}-\rho}{\rho}\right|^{0.45}$ | （2-117） |
| **文字式** | $\text{临界转速}_{\text{【1/s】}}=K\times\left(\text{搅拌器直径}_{\text{【m】}}\right)^{-0.85}\times\left(\text{颗粒直径}_{\text{【m】}}\right)^{0.2}\times X^{0.13}\times\left(\text{运动黏度}_{\text{【m²/s】}}\right)^{0.1}\times\left|g\dfrac{\text{颗粒密度}_{\text{【kg/m³】}}-\text{液体密度}_{\text{【kg/m³】}}}{\text{液体密度}_{\text{【kg/m³】}}}\right|^{0.45}$ |  |

单位与符号（`#L2632-#L2650`）：$N_c$ 1/s；$K$ 与釜结构、桨型、单位有关的常数；$d_p$ 粒径 m；$X=100\times$固-液质量比；$v$ 液体运动黏度 m²/s；$\rho_p$、$\rho$ 固/液密度；$d$ 搅拌器直径 m；$g$ 重力加速度。

要点：$K$ 是唯一需要按设备标定的量；$X$ 用"100×质量比"而非体积分数，代入前先核对。

各式的指数差异来自实验体系（粒径范围、相比、桨型），选用时须匹配实验条件；20-md 的 OCR 对 2-119~2-126 有若干符号失真（如 $d'$、$\varphi$ 下标），引用前核对原书。

## 用法

1. 定悬浮判据（离底 or 几级均匀）→ 选式；
2. 由式（2-117）算 $N_c$，按 1.1~1.3 倍取操作转速；
3. 用平均物性算 $Re$、$N_p$，得功率（见 [[固液悬浮功率与平均物性]]）；
4. 若功耗过高，改结构（桨型、离底高度、底形、导流筒）而不是硬提转速——见 [[固液搅拌设备设计]]。

三相体系的临界悬浮转速见 [[气液固三相体系-临界悬浮转速]]。

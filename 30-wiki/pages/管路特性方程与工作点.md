# 管路特性方程与工作点

## 管路需要多少压头（`#L3507-#L3519`）

对 1—1 与 2—2 两截面列伯努利方程，泵必须提供的压头：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=\Delta z+\dfrac{\Delta p}{\rho g}+\dfrac{\Delta u^2}{2g}+\sum H_f$ | （2-6） |
| **文字式** | $\text{所需压头}_{\text{【m】}}=\text{液位差}_{\text{【m】}}+\dfrac{\text{压差}_{\text{【Pa】}}}{\text{密度}\times\text{重力加速度}}+\dfrac{\text{流速平方差}}{2\times\text{重力加速度}}+\text{总压头损失}$ |  |

对特定管路，$\Delta z+\dfrac{\Delta p}{\rho g}$ 是**固定项**：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H_0=\Delta z+\dfrac{\Delta p}{\rho g}$ | （2-7） |
| **文字式** | $\text{固定压头}_{\text{【m】}}=\text{液位差}_{\text{【m】}}+\dfrac{\text{压差}_{\text{【Pa】}}}{\text{密度}\times\text{重力加速度}}$ |  |

两槽截面远大于管路，$\Delta u^2/2g\approx0$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=H_0+\sum H_f$ | （2-8） |
| **文字式** | $\text{所需压头}=\text{固定压头}+\text{管路总压头损失}$ |  |

## 损失换成流量的二次式（`#L3527-#L3549`）

把 $\sum H_f=\left(\lambda\dfrac{l+\sum l_e}{d}+\sum\zeta\right)\dfrac{u^2}{2g}$ 中的 $u=q_V/(\pi d^2/4)$ 代入：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sum H_f=\dfrac{8}{\pi^2g}\left(\lambda\dfrac{l+\sum l_e}{d^5}+\dfrac{\sum\zeta}{d^4}\right)q_V^2$ | （2-9） |
| **文字式** | $\text{总压头损失}=\dfrac{8}{\pi^2\times\text{重力加速度}}\left(\lambda\dfrac{\text{直管长}+\sum\text{当量长度}}{\text{管内径}^5}+\dfrac{\sum\text{局部阻力系数}}{\text{管内径}^4}\right)\times\text{流量}^2$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $k=\dfrac{8}{\pi^2g}\left(\lambda\dfrac{l+\sum l_e}{d^5}+\dfrac{\sum\zeta}{d^4}\right)$ | （2-10） |
| **文字式** | $\text{管路特性系数}=\dfrac{8}{\pi^2\times\text{重力加速度}}\left(\lambda\dfrac{\text{直管长}+\sum\text{当量长度}}{\text{管内径}^5}+\dfrac{\sum\text{局部阻力系数}}{\text{管内径}^4}\right)$ |  |

## 管路特性方程（`#L3551-#L3555`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=H_0+kq_V^2$ | （2-11） |
| **文字式** | $\text{所需压头}=\text{固定压头}+\text{管路特性系数}\times\text{流量}_{\text{【m³/s】}}^2$ |  |

**注意单位**：$q_V$ 必须是 m³/s。画在 $H-q_V$ 图上即**管路特性曲线**（抛物线，顶点在 $H_0$）。$k$ 大 → 高阻力管路；$k$ 小 → 低阻力管路。改变阀门开度即改变 $\sum\zeta$，从而改变 $k$ 与曲线斜率。

## 工作点（`#L3557-#L3585`）

泵装在管路上工作时，流量与压头由**泵特性曲线与管路特性曲线的交点**决定，此点称工作点（duty point）。

- 该点的 $q_V$、$H$ 既是管路所要求、又是泵所能提供；
- 若工作点落在高效区，则操作适宜。

## 判断

- 2-11 里 $k$ 含 $\lambda$，而 $\lambda$ 随 $q_V$ 变，所以严格说曲线不是标准抛物线；工程上在湍流区把 $\lambda$ 当常数，才写成二次式。
- 工作点不是"调出来的"而是"算出来的"：改变阀门或转速，是改变其中一条曲线，交点是结果。

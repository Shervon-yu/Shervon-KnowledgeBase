# 按扭转变形计算搅拌轴的轴径

## 为什么要按扭转定轴径

搅拌轴受**扭矩与弯矩的联合作用**。扭转角过大会引起轴的振动、使轴封失效，因此要把轴**单位长度的最大扭转角** $\gamma$ 限制在允许范围内，这就是轴的**扭矩刚度条件**（`#L11485`）。

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\gamma=\dfrac{5836M_{n\max}}{Gd^{4}(1-N_{0}^{4})}\times10^{5}\le[\gamma]$ | （9-11） |
| **文字式** | $\text{单位长度扭转角}_{\text{【°\cdot m}^{-1}\text{】}}=\dfrac{5836\times\text{最大扭矩}_{\text{【N}\cdot\text{m】}}}{\text{剪切模量}_{\text{【MPa】}}\times\text{轴外径}_{\text{【mm】}}^{4}(1-\text{空心比}^{4})}\times10^{5}$ |  |

刚度条件反解出轴径：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $d_{1}=155.4\left(\dfrac{M_{n\max}}{[\gamma]\,G\,(1-N_{0}^{4})}\right)^{\frac{1}{4}}$ | （9-12） |
| **文字式** | $\text{传动侧轴径}_{\text{【mm】}}=155.4\times\left(\dfrac{\text{最大扭矩}_{\text{【N}\cdot\text{m】}}}{\text{许用扭转角}_{\text{【°\cdot m}^{-1}\text{】}}\times\text{剪切模量}_{\text{【MPa】}}\times(1-\text{空心比}^{4})}\right)^{\frac{1}{4}}$ |  |

## 最大扭矩

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M_{n\max}=9553\dfrac{P_{N}}{n}\eta$ |  |
| **文字式** | $\text{最大扭矩}_{\text{【N}\cdot\text{m】}}=9553\times\dfrac{\text{电动机额定功率}_{\text{【kW】}}}{\text{转速}_{\text{【r/min】}}}\times\text{传动装置效率}$ |  |

传动装置效率 $\eta$ 按**表9-5**选取（摆线针轮 $>0.9$、单级圆柱 0.97~0.98、双级 0.95~0.96、V 带 0.95~0.96、滚动轴承 0.99~0.995 等，见 [[搅拌用电动机的选用原则]]）。

## 许用扭转角

- 悬臂梁：$[\gamma]=0.35\ (^\circ/\text{m})$；
- 单跨梁：$[\gamma]=0.7\ (^\circ/\text{m})$。

**取值理由**：悬臂轴只有一端支承，轴端挠曲对轴封影响大，故取单跨值的一半（`#L11497`）。

## 使用要点

1. 式（9-12）给出的是**传动侧轴承处**的轴径 $d_{1}$（符号说明 `#L11321`），不是全轴统一直径；其余轴段轴径还要分别按临界转速、强度确定。
2. 空心轴用 $N_{0}$ 修正；实心轴取 $N_{0}=0$。
3. 扭转轴径只是**刚度下限**，最终轴径取扭转、临界转速、强度、径向位移四项中的**最大值**再圆整（`#L11435`）。

# 耐压试验与泄漏试验

## 三种耐压试验（`#L1008-#L1028`）

液压试验（首选）、气压试验、气液组合试验；试验种类与压力值须**在图样上注明**。外压容器以内压试验。多腔容器各腔按自身设计压力分别试验，公用元件须校核稳定性；不满足时先泄漏检查、再在相邻腔保压条件下试。

## 试验压力最低值

### 内压容器（式15、16）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_T=1.25p\dfrac{[\sigma]}{[\sigma]^t}$（液压）；$\quad p_T=1.1p\dfrac{[\sigma]}{[\sigma]^t}$（气压/气液组合） | （15）（16） |
| **文字式** | $\text{试验压力}_{\text{【MPa】}}=1.25\times\text{设计压力}\times\dfrac{\text{试验温度许用应力}}{\text{设计温度许用应力}}$；气压改为 1.1 |  |

- 铭牌有最高允许工作压力时，用其代替 $p$（注1）；
- 各主要受压元件材料不同时，取各元件 $[\sigma]/[\sigma]^t$ 比值中**最小者**（注2）。

### 外压容器（式17、18）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_T=1.25p$（液压）；$\quad p_T=1.1p$（气压/气液组合） | （17）（18） |
| **文字式** | $\text{试验压力}_{\text{【MPa】}}=1.25\times\text{设计压力}$；气压改为 1.1 |  |

### 应力校核（`#L1102-#L1110`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma_T\le0.9R_{eL}\varphi$（液压）；$\quad \sigma_T\le0.8R_{eL}\varphi$（气压） |  |
| **文字式** | $\text{试验应力}_{\text{【MPa】}}\le0.9\times\text{试验温度屈服强度}\times\text{焊接接头系数}$；气压 0.8 |  |

## 免除条件（`#L1112-#L1114`）

不能按 5.6.1~5.6.3 试验的容器，设计文件须提出**确保安全运行的替代措施**，经设计单位技术负责人批准并在图样注明。

## 泄漏试验（`#L1116-#L1128`）

| 项目 | 规定 |
|:--|:--|
| 种类 | 气密性试验、氨检漏、卤素检漏、氦检漏 |
| 何时必须 | 介质毒性程度为极度/高度危害，或不准许微量泄漏 |
| 顺序 | 耐压试验**合格后**进行 |
| 气密性压力 | 等于设计压力 |

## 判断

- 1.25 与 1.1 的差别是**储能风险**：气压试验储能量约为液压的数十倍，故降到 1.1 并配 0.8 的应力上限；
- 试验压力"水压 1.25p"不是保守拍脑袋，而是用 $[\sigma]/[\sigma]^t$ 把常温强度折算回设计温度——所以高温容器水压试验压力常明显高于 1.25p；
- 泄漏试验不是耐压试验的替代，是**补充**；气密性压力只到设计压力，查的是密封面与接头致密性，不是承压能力。

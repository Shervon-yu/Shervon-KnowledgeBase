# 动力相似与相似准数

## 四种力

| 力 | 作用 | 无因次数 |
|:---|:---|:---|
| 惯性力 $F_I$（搅拌动力） | 促进混合 | — |
| 黏性力 $F_V$ | 阻碍混合 | $Re$ |
| 重力 $F_g$ | 阻碍混合 | $Fr$ |
| 表面张力 $F_\sigma$ | 阻碍混合 | $We$ |

惯性力来自搅拌器，其余三种阻碍混合（`#L3955-#L3957`）。

## 三个准数

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re=\dfrac{\text{惯性力}}{\text{黏性力}}=\dfrac{Nd^{2}\rho}{\mu}$ | （4-7） |
| **文字式** | $\text{雷诺数}=\dfrac{\text{转速}_{\text{【1/s】}}\times\left(\text{桨径}_{\text{【m】}}\right)^{2}\times\text{密度}_{\text{【kg/m³】}}}{\text{黏度}_{\text{【Pa·s】}}}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Fr=\dfrac{\text{惯性力}}{\text{重力}}=\dfrac{N^{2}d}{g}$ | （4-8） |
| **文字式** | $\text{弗劳德数}=\dfrac{\left(\text{转速}_{\text{【1/s】}}\right)^{2}\times\text{桨径}_{\text{【m】}}}{9.81}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $We=\dfrac{\text{惯性力}}{\text{表面张力}}=\dfrac{Nd^{3}\rho}{\sigma}$ | （4-9） |
| **文字式** | $\text{韦伯数}=\dfrac{\text{转速}_{\text{【1/s】}}\times\left(\text{桨径}_{\text{【m】}}\right)^{3}\times\text{密度}_{\text{【kg/m³】}}}{\text{表面张力}_{\text{【N/m】}}}$ |  |

## 为什么做不到全相似

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{(F_{I})_{s}}{(F_{I})_{L}}=\dfrac{(F_{V})_{s}}{(F_{V})_{L}}=\dfrac{(F_{g})_{s}}{(F_{g})_{L}}=\dfrac{(F_{\sigma})_{s}}{(F_{\sigma})_{L}}$ | （4-10） |
| **文字式** | $\text{小釜惯性力}/\text{大釜惯性力}=\text{小釜黏性力}/\text{大釜黏性力}=\text{小釜重力}/\text{大釜重力}=\text{小釜表面张力}/\text{大釜表面张力}$ |  |

大、小釜用同一种流体，这四个等式**互相矛盾**：$Re$ 恒定要求 $N\propto d^{-2}$，$Fr$ 恒定要求 $N\propto d^{-1/2}$，$We$ 恒定要求 $N\propto d^{-1}$，三者不可能同时成立（`#L3969`）。

## 退而求其次

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{P}{\rho N^{4}d^{5}}\propto\left[\dfrac{Nd^{2}\rho}{\mu}\right]^{\alpha}\left[\dfrac{N^{2}d}{g}\right]^{\beta}\left[\dfrac{d}{T}\right]^{\gamma}$ | （4-11） |
| **文字式** | $\text{功率数}\propto\text{雷诺数}^{\alpha}\times\text{弗劳德数}^{\beta}\times\left(\dfrac{\text{桨径}}{\text{釜径}}\right)^{\gamma}$ |  |

传热与混合时间同理可写（4-12、4-13），见 [[表面传热系数的无因次关联]]、[[混合过程的混合时间与循环时间]]（`#L3973-#L3981`）。

## 判断

1. 相似理论只能保证**有量纲量成比例**，不能保证过程结果相同；实际放大是"抓主要矛盾、舍次要因素"；
2. 判定哪个准数主导，要看过程类型：传质/分散看 $We$、$Re$；打漩/吸气看 $Fr$；高黏看 $Re$ 与 $We$ 退化；
3. 因此才有"放大因子"这一说（见 [[放大因子与放大准则]]）。

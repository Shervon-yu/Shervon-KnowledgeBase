# 液滴破碎凝并与稳定三角区

## 动态平衡

搅拌互不相溶的两相时，连续相内液滴不断被破碎、又不断凝并；一段时间后破碎速率=凝并速率，形成稳定的分散体系（`#L2360`）。

## 三个区与稳定三角区

以液滴平均直径 $d_D$ 对转速 $N$ 作图（图2-19，`#L2360`）：

| 位置 | 含义 |
|:---|:---|
| BC 线右侧 | **破碎区**：滴径大于该转速下的最大稳定滴径，继续破碎 |
| AB 线下方 | **凝并区**：滴径小于最小稳定滴径，凝并占优 |
| AC 线左侧 | **悬浮区**：转速不足，液滴不能悬浮 |
| 三角形 ABC 内（阴影） | **稳定三角区**：与某转速相对应的稳定滴径落在此处 |
| 三角形 $b_1Bb_2$ 内 | 破碎与凝并**频频发生**——需要靠反复破碎凝并强化传质的场合应把操作点放这里 |

## 判据的物理来源

- **破碎**：湍流场内液滴直径大于漩涡最小尺度时，若湍流动压头作用于液滴的力大于表面张力，液滴就破碎成更小的（`#L2366`）。BC 线即"稳定分散体中能存在的最大滴径"。
- **凝并**：两液滴碰撞不一定合并，只有**附着能大于液滴动能**时才凝并（`#L2368`）。AB 线即"能存在的最小滴径"。

## 推论

- 加大转速把最大稳定滴径压小 → 界面面积增大，但也把系统推向破碎区，能耗上升。
- 需要"传质强化"（如萃取）时应落在 $b_1Bb_2$ 区，让液滴反复破碎凝并，而不是一味追求滴径最小。
- 稳定三角区随物系（表面张力、黏度、密度差）移动，不能跨物系套用图2-19 的位置。

定量表达（$d_{32}$、$We$ 关联式）见 [[液液分散的均匀度与滴径]]。

不定分散区与逆分散见 [[液液逆分散操作]]。

# 原书 §7.9：凝并的直接证据与三个实验

## 釜内滴径不均匀就是凝并的证据

同一釜内不同取样点的滴径差很大（`#L8721`）：**叶轮端部最小、釜底最大**。图7.14 是 MIBK 体系（$\phi=0.25$、1000 r/min、$d=D/3$）两个取样点的分布，一个在叶轮端部、一个接近液面——两者不是同一条分布。

叶轮端部用双对数坐标标绘时**斜率约 $-3/2$**（对应式7.29 的惯性破碎），釜底数据则**斜率 $-3/4$**（对应式7.33 的粘滞剪切/凝并区）。同一个釜同时给出两个不同的指数，说明**底部液滴是凝并长大的，不是被破碎的**。

## §7.9.1 Harada 的碰撞周期

假设（`#L8738`–`#L8744`）：

1. 进入的分散相被分裂成两个**等体积**液滴（远小于反应器体积）；
2. 两滴每平均 $t_2$ 秒碰撞凝并一次，凝并后立即又被破碎成两个等体积滴；
3. 凝并瞬间两滴内溶质浓度**已均匀**；
4. 分散相密度不随反应进展变化。

用 $\mathrm{IO_4^-}+\mathrm{AsO_3^{2-}}\to\mathrm{IO_3^-}+\mathrm{AsO_3^{3-}}$（7.61，原书写作 $\mathrm{ASO_2^-}$）作探针反应，连续相为环己烷/辛醇/白油，分散相为 $\mathrm{NaIO_4}$ 与 $\mathrm{NaAsO_2}$ 水溶液（流量比 1~9）（`#L8748`、`#L8750`）。

$t_c$ 实测（`#L8752`）：

| 体系 | $t_c$ |
|:---|:---|
| 辛醇-水 | 1~3 min（随转速变） |
| 环己烷-水 | $\to\infty$（几乎不凝并） |
| 白油-水 | <30 s（猛烈反复凝并再分散） |

$\phi_d<25\%$ 时 $t_c$ 无显著变化（`#L8752`）。经验判据（`#L8754`）：**$\mu_c/\mu_d>1$ 且界面张力相当小时（如辛醇-水），凝并与再分散频繁**；两相都能溶解的第三组分对凝并条件影响极大。

## §7.9.2 Madden：凝并频率 ∝ $N^{2.4}$

碘-甲苯为连续相、海波（$\mathrm{Na_2S_2O_3}$）水溶液为分散相，两种分散相离子强度相同（4.84）。先分散不活泼的 $\mathrm{NaNO_3}$，再倒入海波：海波滴与含 $\mathrm{NaNO_3}$ 的滴反复凝并、与甲苯中的 $\mathrm{I_2}$ 反应，故**还原速率即凝并频率的度量**（`#L8764`）。

结论（`#L8766`）：凝并频率 $\propto N^{2.4}V_d^{0.5}$。

# 原书 §7.10：三类分散液与稳定三角区的定量边界

## 三类分散液

Shinnar–Church 用 Kolmogoroff 理论分三类（`#L8772`–`#L8778`）：

1. **稳定分散液/乳化液**：制备后在良好贮存条件下长时间不变；
2. **不稳定分散液**：随时分离——机械搅拌下颗粒不断凝并破裂过程中制备的；
3. **湍动稳定分散液**：湍流搅拌下加保护胶体，只要同转速不停搅就稳定。

分散相 >5% 时液滴不断互撞，两次碰撞平均时间可能不到 1 s；但只有一部分碰撞立刻凝并——**碰撞后反弹来自液膜弹性，加保护胶体则膜强度增大**（`#L8780`）。

## 三条边界式

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{p\min}=C_1\rho^{-3/8}\varepsilon^{-1/4}A(s)^{-3/8}$ | （7.62） |
| **文字式** | 能发生凝并的最小滴径：$\varepsilon$ 越大、附着能 $A(s)$ 越大，这个下限越小 |  |

$\varepsilon$ 为单位质量平均能耗，等于 $Cn^3D^2$ 或 $C'n^3d^2$；$A(s)$ 是分开两个粘附液滴所需能量，取决于吸附胶体膜的厚度与性质（`#L8786`、`#L8788`）。

|  |  |  |
|:---|:---:|---|
| **符号式** | $We_{\text{临界}}=C_2\dfrac{\varepsilon^{2/3}d_p^{5/3}\rho}{\sigma}=\text{常数}$ | （7.63） |
| **文字式** | 破碎判据：湍动惯性力与表面张力之比达临界值即破碎（仅在 $\rho_d/\rho_c$ 不很大时正确） |  |

代入 $\varepsilon=C'n^3d^2$、$d_p=C''d$ 即回到式(7.26)（`#L8798`）。

|  |  |  |
|:---|:---:|---|
| **符号式** | $d_{p\max}=C_3\varepsilon^{2}\left(\dfrac{\rho_c}{\rho_d-\rho_c}\right)^{3}\dfrac{1}{g^{3}}f(\phi')$ | （7.64） |
| **文字式** | 靠密度差沉降前能保持悬浮的最大滴径：$\varepsilon$ 越大、密度差越小，能悬住的滴越大 |  |

**适用范围**：$d_p$ 必须小于湍动宏观尺度 $L$ 而大于 Kolmogoroff 尺度 $\eta$（`#L8806`）。图7.15 中译者注指出图中标号 (7.60)(7.61)(7.59) 应为 (7.62)(7.63)(7.64)（`#L8812`）。

## 稳定条件：三条线围成的 ABC 区

每个液滴必须**大于 $d_{p\min}$（凝并，AB 线）且小于 $d_{p\max}$（破裂，CB 线）和 $d_{p\max}$（悬浮，AC 线）**——只有图7.15 中 ABC 剖面线区域内才满足（`#L8818`、`#L8820`）。

两个失效模式（`#L8822`）：

- $\varepsilon<\varepsilon_{\text{最小}}$：$d_{p\min}$（凝并，$Aa_1$）大于 $d_{p\max}$（悬浮，$Aa_2$）→ **分两层**；
- $\varepsilon>\varepsilon_{\text{最大}}$：$d_{p\min}$（凝并，$Bb_2$）大于 $d_{p\max}$（破裂，$Bb_1$）→ **不稳定**。

**保护胶体防不住小颗粒凝并**——它只提高液膜强度（抬高 $\varepsilon_{\text{最大}}$），改不了 $d_{p\min}$ 随 $\varepsilon$ 下降的规律。这就是"加了乳化剂反而分出细渣"的机理。

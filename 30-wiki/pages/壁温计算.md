# 壁温计算

## 稳态热阻链（`#L7131-#L7139`）

稳态下两侧对流与壁导热速率相等：

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Q=\dfrac{T-T_w}{\dfrac{1}{\alpha_1A_1}}=\dfrac{T_w-t_w}{\dfrac{b}{\lambda A_m}}=\dfrac{t_w-t}{\dfrac{1}{\alpha_2A_2}}$ | （4-46） |
| **文字式** | $\text{传热速率}=\dfrac{\text{热流体与热壁温差}}{\text{热侧对流热阻}}=\dfrac{\text{壁两侧温差}}{\text{壁导热热阻}}=\dfrac{\text{冷壁与冷流体温差}}{\text{冷侧对流热阻}}$ |  |

有污垢时把 $R_{d1}$、$R_{d2}$ 串入分母（4-47）。

**要点**：壁温总是接近 $\alpha$ 较大一侧的流体温度；$\alpha_1\approx\alpha_2$ 时 $t_w\approx(T+t)/2$。

## 例4-17（`#L7143-#L7173`）

φ25×2.5 碳钢管废热锅炉：管内高温气体 500→400 ℃、$\alpha_1=250$；管外 1 MPa 水沸腾（饱和 180 ℃）、$\alpha_2=10000$；忽略污垢。

1. $K_1=\left[\frac{1}{250}+\frac{0.0025}{45}\frac{20}{22.5}+\frac{1}{10000}\frac{20}{25}\right]^{-1}=242$ W/(m²·℃)；
2. $\Delta t_m=(320+220)/2=270$ ℃；
3. $Q/A_1=242\times270=65340$ W/m²；
4. 热流体平均 450 ℃ → $T_w=450-65340/250=188.6$ ℃；$t_w=188.6-\frac{0.0025}{45}\times65340\times\frac{20}{22.5}=185.4$ ℃。

**三条结论**：
1. 水侧 $\alpha_2$ 远大于气侧 $\alpha_1$，故壁温（约 186~189 ℃）接近水沸腾温度 180 ℃，而不是气体温度 450 ℃；
2. 管壁热阻很小，两侧壁温几乎相同（差 3.2 ℃）；
3. 若水侧有污垢（$R_{d2}=5\times10^{-4}$ m²·K/W），则 $T_w=211$ ℃、$t_w=208$ ℃——污垢使壁温显著升高，这是"结垢会加速腐蚀/超温"的定量依据。

## 判断

- 壁温估算的实用价值在于：选材（碳钢/不锈钢的许用温度）、判断是否结垢、以及给冷凝/沸腾关联式提供 $\mu_w$。原书反复强调"壁温未知需试差"，例4-17 展示的正是不试差、直接由热阻链反算壁温的替代路径。
- 壁温接近大 $\alpha$ 侧，本质是"热阻小的一侧温差小"；这与多层平壁"热阻大者分配大温差"是同一条规则的两种说法。

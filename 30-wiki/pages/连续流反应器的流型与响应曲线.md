# 连续流反应器的流型与响应曲线

## 三种流型

连续流反应器有两个极端流型加一个中间现实（`#L5840`）：

| 流型 | 特征 | 反应后果 |
|:---|:---|:---|
| 活塞流 | 无轴向混合，径向浓度均匀 | 转化率最高、容积最省 |
| 完全混合流 | 进料瞬间被稀释到出口浓度 | 反应速率被拉低，容积最费 |
| 非理想流（非完全混合） | 有返混、停滞区、沟流 | 介于两者，需模型描述 |

关键取舍（`#L5850`）：**要保持高转化率，进料组分只需径向混合；但"横截面浓度均匀"这件事本身就会带来轴向混合**。横向混合太弱则出现停滞区与沟流。

## 两条响应曲线

**逐步响应法**（`#L5854`）：$t=0$ 把进料从水切换成浓度 $C_i$ 的盐溶液，测出口 $C/C_i=F(t)$，即 **F 曲线**；反向切换（盐→水）得 $R(t)$，二者对 $C/C_i=0.5$ 对称（`#L5856`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $R(t)=1-F(t)$ | （5.1） |
| **文字式** | $\text{残留分数}=1-\text{已流出分数}$ |  |

**脉冲响应法**（`#L5882`）：瞬间注入总量 $Q$ 的示踪物，测出口浓度，得出口年龄分布 $E(t)$：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\int_{0}^{\infty}E(t)\,\mathrm{d}t=1,\qquad E(t)=\dfrac{Cv}{Q}=\dfrac{1}{\theta}\cdot\dfrac{CV}{Q}$ | （5.2）（5.4'） |
| **文字式** | 年龄分布对时间积分等于 1；$E(t)$ 由出口浓度乘体积流率除以注入总量得到 |  |

年龄小于 $t_2$ 的分数 $\int_0^{t_2}E\mathrm{d}t$，大于的为 $1-\int_0^{t_2}E\mathrm{d}t$（5.3、5.3'）。无因次化用 $\theta=V/v$：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\theta E(t)=E\!\left(\dfrac{t}{\theta}\right)=\dfrac{CV}{Q}$ | （5.5） |
| **文字式** | 无因次年龄分布 = 出口浓度 × 釜容积 ÷ 注入量（无量纲） |  |

两者的换算关系是核心（`#L5944`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{C}{C_{i}}=F\!\left(\dfrac{t}{\theta}\right)=\int_{0}^{t/\theta}E\!\left(\dfrac{t'}{\theta}\right)\mathrm{d}\!\left(\dfrac{t'}{\theta}\right)$ | （5.8） |
| **文字式** | F 曲线是 E 曲线的积分；E 是 F 的导数 |  |

**所以测 F 再求导就够了**——这正是逐步响应法比脉冲法实用的原因：脉冲要求"注入不扰动主流"，操作困难（`#L5922`）。

## 两个极端的解析形式

- 活塞流：$E=0$（$t\ne\theta$）、$E=\infty$（$t=\theta$），即 Dirac $\delta$ 函数（`#L5952`）。
- 完全混合：由 $V\mathrm{d}C/\mathrm{d}t=C_iv-Cv$ 积分（`#L5956`、`#L5966`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $F\!\left(\dfrac{t}{\theta}\right)=1-e^{-t/\theta},\qquad E\!\left(\dfrac{t}{\theta}\right)=e^{-t/\theta}$ | （5.9）（5.10） |
| **文字式** | 完全混合的 F 曲线是指数上升，E 曲线是同参数的指数衰减 |  |

# 离心泵的性能参数与扬程

## 主要性能参数（`#L3381`）

流量 $q_V$、扬程 $H$、功率 $P$、效率 $\eta$、转速 $n$、汽蚀余量 $\Delta h_r$ 等。

## 流量（`#L3383-#L3385`）

单位时间输送的液体体积，单位 m³/s、m³/min 或 m³/h。

## 扬程（`#L3387-#L3391`）

**定义**：单位重量（1 N）液体流经泵所获得的能量，单位 J/N = m（液柱）。

工程习惯用"被输送液体的液柱高度 m"表示。对一定泵、一定液体、一定转速，$H$ 随 $q_V$ 变。

## 扬程的测定（`#L3393-#L3409`）

泵进出口两截面 1、2 间列伯努利方程（进/出口分别装真空表与压力表）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=h_0+\dfrac{p_M-p_v}{\rho g}+\dfrac{u_2^2-u_1^2}{2g}+\sum H_f$ | （2-1） |
| **文字式** | $\text{扬程}_{\text{【m】}}=\text{两表间垂直距离}_{\text{【m】}}+\dfrac{\text{压力表读数}-\text{真空表读数}_{\text{【Pa】}}}{\text{密度}\times\text{重力加速度}}+\dfrac{\text{排出管流速}^2-\text{吸入管流速}^2}{2\times\text{重力加速度}}+\text{两表间压头损失}$ |  |

两表间管路很短，$\sum H_f$ 与动压头差通常忽略：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $H=h_0+\dfrac{p_M-p_v}{\rho g}$ | （2-2） |
| **文字式** | $\text{扬程}_{\text{【m】}}=\text{两表垂直距离}_{\text{【m】}}+\dfrac{\text{压力表读数}-\text{真空表读数}_{\text{【Pa】}}}{\text{密度}\times\text{重力加速度}}$ |  |

注意 $p_v$ 是**真空表读数（负表压）**，代入时要带负号。

## 例 2-1（`#L3411-#L3421`）

20 ℃ 清水、$q_V=720$ m³/h、出口压力表 0.4 MPa、入口真空表 −0.028 MPa、两表垂直距离 0.41 m、$\rho=998.2$ kg/m³：

$H=0.41+\dfrac{4\times10^5-(-2.8\times10^4)}{998.2\times9.81}=44.1$ m。

## 扬程与升扬高度的区别（我的整理，非原文）

- **升扬高度** $\Delta z$ 只是管路特性方程中的一项；
- **扬程** $H$ 还要克服压差 $\Delta p/\rho g$ 与全部阻力 $\sum H_f$；
- 所以 $H\ge\Delta z$，且当出口有压力或阻力大时 $H$ 可远大于 $\Delta z$。例：把水送入 196 kPa 表压的塔，扬程中约 20 m 来自压差项。

## 判断

- 2-2 是把"泵进出口"当作一个整体测能量差，因此不需要知道泵内部结构；这也是泵样本能在试验台上标定扬程的原因。
- 扬程与密度无关（液柱高度），但**压差**与密度成正比——同一台泵送不同密度液体，压力表读数会变、扬程不变。

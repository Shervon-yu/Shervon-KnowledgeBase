# 射流混合的原理与参数计算

## 混合机理（`#L17772`）

射流自喷嘴喷出，在紧靠喷嘴的短过渡区内形成**剪切层**；剪切层自然不稳定迅速增长形成漩涡，漩涡卷吸周围流体，同时高速液体的动量迅速传给槽内流体，引起**全槽性流动**。局部速度梯度可达 $30\sim1000$ 1/s 级，巨大速度差促成激烈混合。

## 流型（图15-12，`#L17774-#L17780`）

大型槽需要**多个喷嘴**才能完成混合；喷嘴位置不同产生不同流型。使较稠厚液体与槽内液体混匀时，喷嘴应**略向上翘**。

## 射流现象（`#L17784-#L17808`）

- 射流扩大角约 **14°**，沿程夹带周围流体；
- 流态判据用喷嘴出口雷诺数：$Re<300$ 层流，$Re>2100$ 湍流，工程上多为湍流；
- **层流射流不是有效混合方法**（无分子级混合、卷吸能力差）；
- 轴对称自由射流四区域：Ⅰ 势流核心、Ⅱ 不连续区、Ⅲ 混合区（速度梯度大、湍动强）、Ⅳ 混合区与核心合并；
- $Z/d_0=15\sim20$ 时动能利用最有效；有吸液能力的距离约 $(80\sim100)d_0$。

## 与循环泵、螺旋桨的比较（表15-15，`#L17812-#L17821`）

| 比较项 | 普通循环泵混合 | 螺旋桨混合 | 射流混合 |
|:---|:---|:---|:---|
| 投资成本 | 低 | 高 | 低 |
| 操作动力成本 | 高 | 低 | 低 |
| 对泵与管道要求 | 高 | 低 | 中 |
| 对储槽要求 | 高 | 低 | 低 |

射流混合的特点：功率消耗一般较低、混合时间较短、对泵流量要求低于循环泵系统，但**对压头要求较高**；泵与管线使用时间短，寿命较长。

## 结构与布置（`#L17823`）

喷嘴收缩角一般 **15°**；喷嘴距槽底 600 mm；沿槽截面直径方向放置，防止打漩。

## 基本参数计算

**① 距喷口 $Z$ 处的夹带流量（式15-16，`#L17837`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Q_Z=\left[0.234\left(\dfrac{Z}{d_0}\right)-1\right]Q_0$ | （15-16） |
| **文字式** | $\text{夹带流量}_{\text{【m³/s】}}=\left[0.234\times\dfrac{\text{距喷口距离}_{\text{【m】}}}{\text{喷嘴直径}_{\text{【m】}}}-1\right]\times\text{喷嘴出口流量}_{\text{【m³/s】}}$ |  |

其中 $Q_0=\dfrac{\pi}{4}d_0^2v_0$。

**② 循环泵压头损失（式15-17，`#L17853`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\Delta h=\zeta_p\dfrac{v_p^2}{2g}+\zeta_0\dfrac{v_0^2}{2g}$ | （15-17） |
| **文字式** | $\text{压头损失}_{\text{【m】}}=\text{管路阻力系数}\times\dfrac{\text{管内流速}^2_{\text{【m/s】}}}{2\times\text{重力加速度}_{\text{【m/s²】}}}+\text{喷嘴阻力系数}\times\dfrac{\text{喷嘴出口流速}^2_{\text{【m/s】}}}{2\times\text{重力加速度}_{\text{【m/s²】}}}$ |  |

**③ 喷嘴直径的确定（`#L17863`）**：以 $d_0$ 为参变数，在泵特性曲线上画式15-17 的管路特性曲线，工作点落在**泵最高效率点附近**的 $d_0$ 为最佳（图15-15）。

**④ 循环泵功率（式15-18，`#L17867`）**

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=\dfrac{Q_0}{10^3\eta}\left(\dfrac{\rho}{2}v_0^2\right)$ | （15-18） |
| **文字式** | $\text{循环泵功率}_{\text{【kW】}}=\dfrac{\text{喷嘴出口流量}_{\text{【m³/s】}}}{10^3\times\text{泵效率}}\times\left(\dfrac{\text{料液密度}_{\text{【kg/m³】}}}{2}\times\text{喷嘴出口流速}^2_{\text{【m/s】}}\right)$ |  |

**⑤ 混合时间（式15-19，`#L17883`）**

适用于互溶、低黏液体，且喷嘴出口 $Re=4500\sim80000$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $t=\dfrac{8D^2}{\sqrt{Q_0v_0}}$ | （15-19） |
| **文字式** | $\text{混合时间}_{\text{【s】}}=\dfrac{8\times\text{混合槽直径}^2_{\text{【m】}}}{\sqrt{\text{喷嘴出口流量}_{\text{【m³/s】}}\times\text{喷嘴出口流速}_{\text{【m/s】}}}}$ |  |

## 判断

- 射流的混合能力来自**动量注入**，不是叶轮剪切；因此它适合大容积、低黏、需要整体循环的场合（大型储槽调合），不适合需要局部强剪切的分散/乳化。
- 式15-16 的线性形式隐含「夹带量与 $Z/d_0$ 成正比」的湍流射流假设，$Z/d_0<4.3$ 时算得负值，说明近场不适用。
- 压头高、流量低是射流系统的特征：选泵时应选**高扬程小流量**泵，而不是循环泵那种大流量泵。

# 气力式混合器

## 原理（`#L18355`）

利用料仓内**向上气流**把粉粒体升起并强烈翻滚，物料又因重力下落，多次循环后达到较高混合度。

## 适用物料（`#L18357-#L18371`）

| 适合 | 不适合 |
|:---|:---|
| 流动性好、静止角 <35° | 吸湿性 |
| 粒径 >1.0 mm，或 0.1~1.0 mm | 凝聚性 |
| 物性差小 | 飞散性微粉 |
| 磨耗性大 | 可压缩性粉粒体 |
| 含水量低或干燥 | — |

结构简单、维修方便、生产费用低；装料系数可达 **70%**，有时可与大容量储槽兼用。

## 与机械式的对比（`#L18377-#L18379`）

| 指标 | 气力式 | 机械搅拌式 |
|:---|:---|:---|
| 有效容积上限 | 100 m³ | 20~60 m³ |
| 单粒子分散 | 容易 | 较难 |
| 功率消耗 | 一般更低（图15-31：脉冲旋流、内外管重力式远低于螺旋叶片、双锥、强制式） | 较高 |

## 四种型式

### ① 外管重力式（`#L18383-#L18385`）

料仓 + 下部集料斗为主体，仓周沿螺旋方向装 **32 个外管**，从不同高度取料汇入集料斗，再由风机送回仓内。关键是外管设计：管内流速均匀，集料斗内汇合时不宜相互冲击。工作容积最大 **100 m³**。

### ② 内管重力式（`#L18411-#L18413`）

风机使物料沿**内管上升**，到顶部由罩向四周分散，气流自顶部排出；物料沿外管下落回入口，循环混合。工作容积最大 **150 m³**。

### ③ 旋管重力式（`#L18415-#L18417`）

圆筒仓上部沿切向设 **3 个进管**，物料如旋风分离器般沿壁下沉而混合，气体上逸，靠仓外气送装置反复进行。

### ④ 脉冲旋流式（`#L18419-#L18431`）

锥形底部设特殊混合器头，向仓内提供**脉冲式向上空气旋流**：脉冲停止时颗粒下降，下一次气旋时从另一地点升起，反复移动实现强混合。

| 参数 | 数值 |
|:---|:---|
| 脉冲周期 | 约 1 s |
| 混合时间 | ≤60 s |
| 装料至卸料总时间 | ≤4 min |
| 工作容积 | 1~45 m³ |
| 可处理密度差 | 高达 6:1 |
| 微量添加剂 | 0.001%（质量分数）仍可混匀 |
| 适用粒度 | 0.05~3 mm |
| 物料损失 | 0.5%~1.0%（或再处理回收） |

特点：气力混合器中效率较高；混合仓可兼作**气力输送发送罐**，混好后直接气力卸出；耗气量较低（图15-36）。

## 判断

- 气力式混合器的能力上限来自「没有运动部件」：容积可到 100~150 m³，机械式只能 20~60 m³。
- 它只处理「干、粗、差小」的物料；吸湿、凝聚、飞散的微粉是硬禁区，不是调参能解决的。
- 脉冲旋流式是四类里唯一能处理 6:1 密度差与 0.001% 微量组分的，选型时优先考虑它；外管/内管重力式胜在大容积。

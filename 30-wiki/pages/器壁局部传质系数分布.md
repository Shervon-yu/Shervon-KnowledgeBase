# 器壁局部传质系数分布

## 为什么用电化学法测

热膜与皮托管都难以贴近器壁安装；电化学法（铁氰化钾/亚铁氰化钾氧化还原）测的是壁面传质系数 $k$，直接对应壁面剪应力，正好补上"器壁附近流率与湍动"这一格（`#L4478`）。实验容器 $D=20$ cm、143 r/min（`#L4496`）。

## 分布特征

| 位置 | $k$ | 原因 |
|:---|:---|:---|
| 挡板后约 15°、与叶轮高度交点（M 点） | **极大值** | 液体绕过挡板后撞上器壁（`#L4482`） |
| 紧贴挡板**后**（$B_1$） | **极小值（停滞区）** | 挡板背风面死区（`#L4484`） |
| 紧贴挡板**前**的根部（$B_2$） | 大 | 输出流进入挡板根部，未受扰动（`#L4486`） |
| 容器底（及顶盖下） | 略升 | 沿挡板上下流动的液流撞底转为径向，产生额外湍动（`#L4488`） |

除挡板前后外，$k$ 的等值线几乎与展开的圆周线平行——即**周向均匀、只在挡板处被破坏**。

## 定量判据

局部传质系数用 $Sh/Sc^{1/3}$ 对 $Re$ 关联（`#L4501`）：

|  |  |  |
|:---|:---:|---|
| **符号式** | $\dfrac{Sh}{Sc^{1/3}}\propto Re^{2/3}$ |  |
| **文字式** | $\dfrac{\text{舍伍德数}}{\text{施密特数}^{1/3}}\propto\text{雷诺数}^{2/3}$ |  |

要点：

- **在容器壁的任何高度，$Re$ 的指数都是 2/3**——与夹套壁传热系数的指数完全一致（见 [[搅拌侧传热膜系数关联式]]）。这是"传热与传质类比"在釜壁上的直接证据。
- Akse 等认为输出流与器壁垂直相撞处的指数应为 0.85，**与原书结论不一致**（`#L4505`）；原书的实测支持 2/3。
- 无挡板时分布**平坦**，最大值与最小值只差 20%（`#L4494`）；有挡板时挡板前后会造成成倍的局部差异。

## 设计含义

1. 局部系数差异成倍 → 用平均系数算夹套面积时，挡板背后的低效区实际贡献很小；夹套/内冷件的布置要让"死区"尽量小。
2. 挡板背面既是传质死区，也是**结垢/沉积**的高发区。
3. 底部传热系数偏高不是漏热，而是挡板导流撞底产生的真实湍动（`#L4490`）。

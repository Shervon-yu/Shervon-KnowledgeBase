# 塔高的确定

## 板式塔（`#L13167-#L13181`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Z=N_{实}H_T$ | （6-70） |
| **文字式** | $\text{塔高}=\text{实际板数}\times\text{板间距}$ |  |

$N_{实}=N_{理}/E_0$。板间距 $H_T$ 要与塔径同时选定：

- 取大：液沫夹带少、允许气速高、塔径可小，但塔高与造价增；
- 取小：塔高低，但夹带多、易液泛。

**初选板间距**（表6-8）：

| 塔径 $D$/mm | 板间距 $H_T$/mm |
|:--|:--|
| 800~1200 | 300~500 |
| 1400~2400 | 400~700 |
| 2600~6600 | 450~800 |

选定后须校验液泛与液沫夹带。

## 填料塔（`#L13183-#L13197`）

|  |  |  |
|:---|:---:|--:|
| **符号式** | $Z=N_{理}\times HETP$ | （6-71） |
| **文字式** | $\text{填料层高度}=\text{理论板数}\times\text{等板高度}$ |  |

**等板高度 HETP**（表6-9）：与填料类型、尺寸、物系、操作条件有关，通常由实验或经验取值：

| 工况 | HETP/m |
|:--|:--|
| 25 mm 填料 | 0.46 |
| 38 mm 填料 | 0.66 |
| 50 mm 填料 | 0.90 |
| 吸收操作 | 1.5~1.8 |
| 小直径塔 | ≈塔径 |
| 真空操作 | ≈塔径+0.1 |

## 判断

- 板式塔"板间距"与"塔径"是联立变量：夹带限制要求 $H_T$ 足够大，而 $H_T$ 大又使塔高增加——初选表只是起点，必须回代校验。
- 填料塔的 HETP 随填料尺寸增大而增大、随比表面积下降而恶化，所以高效塔常用小填料，代价是压降与堵塞风险。
- 真空塔的 HETP 要加 0.1 m，是因为低压下气相体积流量大、液泛倾向强，需要更高的单元。

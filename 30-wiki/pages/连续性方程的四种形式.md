# 连续性方程的四种形式

## 四种流动模型与四个方程（§2.5）

书里用同一套三步法（写物理原理 → 选流动模型 → 得方程）把质量守恒先后用到四个模型上，得到四个形式（#L1084-#L1102、图 2-6 #L1152-#L1156）：

| 流动模型 | 方程 | 形式 | 式号 |
|:--|:--|:--|:--|
| 空间位置固定的有限控制体 | 积分守恒型 | 控制体有限 → 积分；位置固定 → 守恒 | （2-19） |
| 随流体运动的有限控制体 | 积分非守恒型 | 控制体有限 → 积分；随流运动 → 非守恒 | （2-21） |
| 空间位置固定的无穷小微团 | 微分守恒型 | 微团无穷小 → 微分 | （2-25） |
| 随流体运动的无穷小微团 | 微分非守恒型 | 同上，随流运动 | （2-29） |

积分守恒型（#L1144-#L1150）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial}{\partial t}\iiint_{\mathcal{V}}\rho\,\mathrm{d}\mathcal{V}+\iint_{S}\rho\boldsymbol{V}\cdot\mathrm{d}\boldsymbol{S}=0$ | （2-19） |
| **文字式** | $\dfrac{\partial}{\partial\text{时间}}\iiint_{\text{控制体}}\text{密度}\,\mathrm{d}\text{体积}+\iint_{\text{控制面}}\text{密度}\times\text{速度}\cdot\mathrm{d}\text{面积}=0$ |  |

积分非守恒型（#L1162-#L1170）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{D}}{\mathrm{D}t}\iiint_{\mathcal{V}}\rho\,\mathrm{d}\mathcal{V}=0$ | （2-21） |
| **文字式** | $\dfrac{\text{物质导数}}{\text{时间}}\iiint_{\text{控制体}}\text{密度}\,\mathrm{d}\text{体积}=0$ |  |

微分守恒型（#L1214-#L1222）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial\rho}{\partial t}+\nabla\cdot(\rho\boldsymbol{V})=0$ | （2-25） |
| **文字式** | $\dfrac{\partial\text{密度}}{\partial\text{时间}}+\nabla\cdot(\text{密度}\times\text{速度})=0$ |  |

微分非守恒型（#L1240-#L1252）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{D}\rho}{\mathrm{D}t}+\rho\nabla\cdot\boldsymbol{V}=0$ | （2-29） |
| **文字式** | $\dfrac{\text{物质导数}_{\text{【密度】}}}{\text{时间}}+\text{密度}\times\nabla\cdot\text{速度}=0$ |  |

## 四种形式的互相转换（§2.5.5）

- 积分守恒 → 微分守恒：对面积分用散度定理（式 2-31，#L1268），把面积分换成体积分，被积函数为零即得（2-25）（#L1276-#L1282）。
- 微分守恒 → 微分非守恒：展开 $\nabla\cdot(\rho\boldsymbol{V})=\rho\nabla\cdot\boldsymbol{V}+\boldsymbol{V}\cdot\nabla\rho$（式 2-34，#L1288），合并成物质导数即得（2-29）（#L1292-#L1296）。
- 积分非守恒 → 积分守恒：对物质导数积分号下求导，引入微团体积变化率（式 2-37～2-39，#L1306-#L1320），再用（2-14）即回到（2-19）型（#L1336-#L1348）。

结论：四个方程是同一个质量守恒的不同写法；守恒/非守恒的差别只来自"控制体是否固定"这一建模选择，不来自物理。

## 适用边界

- 推导假设连续介质、无质量源项、无相变与化学反应；含源项时右端加 $\dot{m}$。
- 积分形式对有限控制体成立，是有限体积法的出发点；微分形式要求流场可微（#L1214）。
- 定常流动时 $\partial\rho/\partial t=0$，仅剩散度项。
- 不可压流动 $\mathrm{D}\rho/\mathrm{D}t=0$，由（2-29）得 $\nabla\cdot\boldsymbol{V}=0$。

## 判断

CFD 里"用守恒型还是非守恒型"，本质是选离散对象：有限体积法直接用（2-19）的离散面通量，天然守恒；差分法常写（2-25）的散度形式，差分离散后是否守恒取决于通量差分格式是否 telescoping。书里 2.10 节把守恒型控制方程列成统一向量形式（式 2-93 起），就是为后面第 6、11 章的格式讨论铺路。

所有壁厚公式里的 $p_c$、$[\sigma]^t$ 与 $C$ 都从这里来：设计压力定荷载、设计温度定许用应力、厚度附加量定名义厚度。

## 一、要考虑的载荷（5.3.2，`#L565-#L590`）

必须考虑：a）内压、外压或最大压差；b）液柱静压力——**液柱静压力小于设计压力的 5% 时可忽略不计**。

需要时还要考虑：容器自重（含内件、填料、正常工作或耐压试验时内装介质的重力）；附属设备、隔热材料、衬里、管道、扶梯、平台的重力；风、地震、雪载荷；支座与支耳等支承反力；连接管道与其他部件的作用力；温度梯度或热膨胀差引起的作用力；冲击载荷（压力急剧波动的冲击、流体冲击反力）；运输或吊装作用力。

## 二、设计压力（5.3.3，`#L592-#L610`）

| 情形 | 规定 |
|:--|:--|
| 装有超压泄放装置 | 按附录 B 确定设计压力 |
| 盛装液化气体、有可靠保冷设施 | 按工作条件下介质可能达到的最高温度定设计压力 |
| 盛装液化气体、无可靠保冷设施 | 按 TSG 21 确定 |
| 外压容器（真空、液下、埋地） | 计算压力须计及正常工作情况下可能出现的最大内外压力差 |
| 真空容器**有**安全控制装置（如真空泄放阀） | 取 $\min\{1.25\times\text{最大内外压力差},\ 0.1\ \text{MPa}\}$ |
| 真空容器**无**安全控制装置 | 取 0.1 MPa |
| 多压力室（如夹套） | 各室分别定设计压力；公用元件的计算压力须计及相邻室之间的最大压力差 |

## 三、设计温度（5.3.4，`#L612-#L626`）

- 最高设计温度**不应低于**元件金属在工作状态可能达到的最高温度；最低设计温度**不应高于**元件金属可能达到的最低温度；
- 各部分金属温度不同时，可分别设定每部分的设计温度；
- 金属温度由三条途径之一确定：传热计算、同类在用容器实测、由介质温度结合外部条件推定；
- 定最低设计温度时须考虑大气环境低温：取**历年来月平均最低气温的最低值**（当月各天最低气温之和除以当月天数）。

## 四、工况（5.3.5，`#L628-#L630`）

多工况容器按**最苛刻工况**设计，必要时考虑工况组合，并在图样或技术文件中注明各工况操作条件与设计条件下的压力、温度值。

## 五、厚度附加量（5.3.6，`#L632-#L668`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C=C_1+C_2$ | （1） |
| **文字式** | $\text{厚度附加量}_{\text{【mm】}}=\text{材料厚度负偏差}_{\text{【mm】}}+\text{腐蚀裕量}_{\text{【mm】}}$ |  |

- $C_1$：板材或管材的厚度负偏差，按材料标准的规定；
- $C_2$：腐蚀裕量，按预期设计使用年限与介质腐蚀速率（及磨蚀速率）确定；各元件腐蚀程度不同时可用不同的 $C_2$；**介质为压缩空气、水蒸气或水的非合金钢或低合金钢容器，$C_2$ 不小于 1 mm**。

**最小厚度**（5.3.6.4，壳体加工成形后**不包括腐蚀裕量**的最小厚度）：

| 材料 | 下限 |
|:--|:--|
| 非合金钢、低合金钢制容器 | $\ge3$ mm |
| 高合金钢制容器 | 不宜 $<2$ mm |

## 六、设计文件（5.3.7，`#L670-#L732`）

- 内容：风险评估报告（需要时）、强度计算书或应力分析报告、设计图样、制造技术条件，必要时含安装与使用维护说明；装超压泄放装置的还须有安全泄放量、安全阀排量、爆破片泄放面积的计算书；
- 签署：风险评估报告、强度计算书、设计总图至少**设计、校核、审核 3 级签署**；**第Ⅲ类容器**还须设计单位技术负责人或其授权人批准（**4 级签署**）；
- 保存期限不少于容器的设计使用年限；
- 设计总图至少注明 14 项内容（名称分类、工作条件、设计条件、材料牌号、特性参数、设计使用年限、特殊制造要求、热处理、无损检测、耐压与泄漏试验、防腐蚀、安全附件、铭牌位置、包装运输安装），另有 6 条特殊要求（多腔各腔试验压力、触媒与填料容器的定期检验、不能内部检验者的计算厚度、不能做耐压试验者、隔热衬里防超温、保温保冷措施）。

## 判断

- $C$ 是**加在计算厚度上**的：名义厚度 $=\delta+C$ 向上圆整，而最小厚度是「成形后不含 $C_2$」的构造下限，两者不是同一口径，混用会把最小厚度当成计算结果的比较值。
- 液柱静压 5% 是**设计压力**的 5%，不是工作压力的 5%；忽略与否直接改 $p_c$，进而平方级影响壁厚（球壳）或一次方影响（圆筒）。
- 真空容器两个数取小：1.25 倍压差与 0.1 MPa 取低值；无安全控制装置才直接取 0.1 MPa——「有阀门就放松」是常见误读。
- 第Ⅲ类容器的 4 级签署是文件闸门，不是计算内容；设计总图的 14 项也是同样的性质。

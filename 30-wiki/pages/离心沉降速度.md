# 离心沉降速度

## 三力平衡（`#L4863-#L4875`）

径向沉降方向上三个力：

- 离心力（向外）：$\dfrac{\pi}{6}d_p^3\rho_pr\omega^2$；
- 浮力（向中心）：$\dfrac{\pi}{6}d_p^3\rho r\omega^2$；
- 阻力（向中心）：$\zeta\dfrac{\pi d_p^2}{4}\dfrac{\rho(\mathrm{d}r/\mathrm{d}\tau)^2}{2}$。

平衡时：

$$\frac{\pi}{6}d_p^3r\omega^2(\rho_p-\rho)-\zeta\frac{\pi d_p^2}{4}\frac{\rho(\mathrm{d}r/\mathrm{d}\tau)^2}{2}=0$$

解出径向相对速度即离心沉降速度：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{d}r}{\mathrm{d}\tau}=\sqrt{\dfrac{4d_p(\rho_p-\rho)}{3\zeta\rho}r\omega^2}$ | （3-20） |
| **文字式** | $\text{离心沉降速度}_{\text{【m/s】}}=\sqrt{\dfrac{4\times\text{粒径}\times(\text{密度差})}{3\times\text{阻力系数}\times\text{流体密度}}\times\text{半径}\times\text{角速度}^2}$ |  |

## 与重力沉降的对比（`#L4879`）

（3-20）与（3-11）形式相同，只是 $g$ 换成了 $r\omega^2$。

**关键差别**：重力沉降速度一定；**离心沉降速度随颗粒所在半径变化**——$r$ 越大，$r\omega^2$ 越大，速度越大。

## 斯托克斯区（`#L4881-#L4885`）

小颗粒沉降通常在斯托克斯区（$\zeta=24/Re$），代入得：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\mathrm{d}r}{\mathrm{d}\tau}=\dfrac{d_p^2(\rho_p-\rho)}{18\mu}r\omega^2$ | （3-21） |
| **文字式** | $\text{离心沉降速度}=\dfrac{\text{粒径}^2\times(\text{密度差})}{18\times\text{黏度}}\times\text{半径}\times\text{角速度}^2$ |  |

由（3-21）：$\mathrm{d}r/\mathrm{d}\tau\propto r$，沉降过程中速度随半径增大而**不断加快**。

## 判断

- "重力场均匀、离心场不均匀"是离心分离的实质：颗粒越往外越快，所以分离主要发生在靠近壁面的区域。
- 设计计算只针对小颗粒（大的用重力法已够），这也是 3-21 只给斯托克斯区的原因。

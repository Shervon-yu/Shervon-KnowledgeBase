# 混合度的定义与计算

## 概念（`#L15182-#L15190`）

衡量混合物质量的尺度称**混合度或均匀度**。粉粒体操作中以混合为最终目的很少，混合常只是预处理；因此均质度须与最终制品品质对应才能评定。单独评价混合操作时，用统计学定义的混合度。

均一混合物：混合物中任一点检出的主成分概率都相等，称**统计上的完全混合状态**。混合度可用颜色、示踪剂、粒度分布等物理量的变化判断。

## 间歇操作：标准方差法（式12-1，`#L15192-#L15200`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma^{2}=\dfrac{1}{N-1}\sum_{i=1}^{N}\left(X_i-\overline{X}\right)^{2}$ | （12-1） |
| **文字式** | $\sigma^{2}=\dfrac{1}{\text{试样数}-1}\sum_{i=1}^{\text{试样数}}\left(\text{第}i\text{个试样浓度}-\text{试样浓度算术平均值}\right)^{2}$ |  |

$N$ 为任取的试样数，$X_i$ 为任一试样中某指定组成的浓度，$\overline{X}$ 为这些试样浓度测定值的算术平均值。$\sigma$ 随混合进行而减小。

## 连续操作：标准偏差法（式12-2，`#L15202-#L15212`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\sigma=\left[\dfrac{1}{N}\sum_{i=1}^{N}\left(\dfrac{X_i}{X_0}-\dfrac{\overline{X}}{\overline{X}_0}\right)^{2}\right]^{\frac{1}{2}}$ | （12-2） |
| **文字式** | $\sigma=\left[\dfrac{1}{\text{试样数}}\sum_{i=1}^{\text{试样数}}\left(\dfrac{\text{出口组成含量}_i}{\text{进口组成含量}}-\dfrac{\text{出口平均组成含量}}{\text{进口平均组成含量}}\right)^{2}\right]^{\frac{1}{2}}$ |  |

在混合设备出口处随机或固定时间间隔取 $N$ 个试样。$X_t$（原文符号）为出口组成含量，$X_0$ 为进口组成含量，$\overline{X}$ 为出口平均组成含量。

## 变异系数法（式12-3、12-4，`#L15214-#L15228`）

|  |  |  |
|:---|:---:|---:|
| **符号式** | $C_{\mathrm{v}}=\dfrac{\sigma}{\overline{X}}\times100\%$ | （12-3） |
| **文字式** | $\text{变异系数}_{\text{【\%】}}=\dfrac{\text{标准偏差}}{\text{平均组成含量}}\times100$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $M=100\%-C_{\mathrm{v}}$ | （12-4） |
| **文字式** | $\text{混合度}_{\text{【\%】}}=100-\text{变异系数}_{\text{【\%】}}$ |  |

## 为什么需要变异系数（`#L15216`）

标准偏差没有考虑试样**含量水平**：某组分含量 50% 时测得 $\sigma=2\%$，含量仅 5% 时 $\sigma$ 也是 2%，两者标准偏差相同，但混合质量显然不同。因此**含量相差悬殊时必须用 $C_v$**；$M=100\%-C_v$ 即把变异系数折算成百分制混合度。

## 取样要求（`#L15230-#L15236`）

| 因素 | 规则 |
|:---|:---|
| 试样大小 | 试样越大越接近均匀值（与配料单一致）。两种确定法：①取一系列大小不同、已接近均匀的试样，**最小试样的量**即取样准则；②按将来单个产品的质量大小定试样大小 |
| 试样个数 | 个数多结果可靠，**一般取 20~50 个** |

## 使用注意

- 12-1 是**样本方差**（分母 $N-1$）、12-2 是总体形式（分母 $N$），两者不可混用；
- $M$ 只在同一体系、同一取样口径下可比，跨物料比较没有意义；

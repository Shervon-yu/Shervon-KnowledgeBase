# 静力学方程式的应用

## 一、U 形管液柱压差计（`#L1110-#L1144`）

结构：内装指示液的 U 形玻璃管，两端接被测两截面。**指示液要求**：与被测流体不互溶、不起化学作用、密度大于被测流体；常用汞、四氯化碳、水、液体石蜡。

U 形管下部为指示液（密度 $\rho_0$），上部为被测流体（$\rho$）。a、b 两点在同一静止指示液的同一水平面上，故 $p_a=p_b$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_1-p_2=R(\rho_0-\rho)g$ | （1-10） |
| **文字式** | $\text{压差}_{\text{【Pa】}}=\text{读数}_{\text{【m】}}\times\left(\text{指示液密度}_{\text{【kg/m³】}}-\text{流体密度}_{\text{【kg/m³】}}\right)\times\text{重力加速度}_{\text{【m/s²】}}$ |  |

测气体时 $\rho_0-\rho\approx\rho_0$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_1-p_2=R\rho_0g$ | （1-10a） |
| **文字式** | $\text{压差}_{\text{【Pa】}}=\text{读数}_{\text{【m】}}\times\text{指示液密度}_{\text{【kg/m³】}}\times\text{重力加速度}_{\text{【m/s²】}}$ |  |

**倒 U 形管压差计**：用被测液体本身作指示液（`#L1146`）。

**例 1-4**（`#L1148-#L1168`）：常温水、汞指示液、$R=100$ mmHg，水 1000、汞 13600 kg/m³ → $p_a-p_b=0.1\times(13600-1000)\times9.81=12.4$ kPa。

## 二、斜管压差计（`#L1170-#L1176`）

压差小时读数 $R$ 太小，把测量管倾斜角 $\alpha$：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $R'=\dfrac{R}{\sin\alpha}$ | （1-11） |
| **文字式** | $\text{斜管读数}_{\text{【m】}}=\dfrac{\text{垂直读数}_{\text{【m】}}}{\sin\text{倾斜角}}$ |  |

$\alpha$ 愈小，放大倍数愈大。

## 三、微差压差计（`#L1180-#L1198`）

U 形管放两种密度不同、互不相溶的指示液，上端有足够大截面的扩张室（读数变化时扩张室液面不明显变化）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $p_1-p_2=Rg(\rho_a-\rho_b)$ | （1-12） |
| **文字式** | $\text{压差}_{\text{【Pa】}}=\text{读数}_{\text{【m】}}\times\text{重力加速度}_{\text{【m/s²】}}\times\left(\text{重指示液密度}_{\text{【kg/m³】}}-\text{轻指示液密度}_{\text{【kg/m³】}}\right)$ |  |

$(\rho_a-\rho_b)$ 愈小，同样压差下读数 $R$ 愈大——所以用两种密度**接近**的指示液。

## 四、液面测定（`#L1200-#L1234`）

图 1-8：U 形压差计一端接容器底部、一端接平衡室；平衡室上方用气相平衡管与容器相连，室内装与容器相同的液体，液面维持在容器允许最高液位。**液面越高读数越小，达到最高允许液位时读数为零。**

**例 1-5**（`#L1210-#L1234`）：吹气管鼓泡法测石油产品液面，汞指示液。由 $z_1=R_1\rho_{Hg}/\rho_p$、$z_2=R_2\rho_{Hg}/\rho_p$ 相减得

- $\rho_p=\dfrac{R_1-R_2}{z_1-z_2}\rho_{Hg}=\dfrac{0.15-0.06}{1.5}\times13600=816$ kg/m³；
- $z_1=0.15\times\dfrac{13600}{816}=2.5$ m。

## 五、确定液封高度（`#L1236-#L1252`）

安全液封（水封）作用：设备内压力超过规定值时气体从液封管排出。设备允许最高表压 $p$ 时：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $h=\dfrac{p}{\rho_{\mathrm{H_2O}}g}$ | （1-13） |
| **文字式** | $\text{插入深度}_{\text{【m】}}=\dfrac{\text{允许表压}_{\text{【Pa】}}}{\text{水的密度}_{\text{【kg/m³】}}\times\text{重力加速度}_{\text{【m/s²】}}}$ |  |

实际安装时插入深度应比计算值**略低**（安全起见）。

## 判断

- 五个用法共用一条思路：找"同一静止液体的同一水平面"作等压面，一侧写到已知压力、另一侧写到待求压力。
- 微差压差计能放大的原因不是结构，而是两指示液密度差小；这跟斜管放大是两种不同手段。

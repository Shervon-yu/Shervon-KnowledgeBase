# 竖式挡板的结构与尺寸

## 为什么装挡板

中心安装、低黏、高转速时液体随桨叶一起转：中间液体受离心力涌向内壁上升、中心液面下降，形成**打漩区**；转速再高，漩涡中心下凹到接触桨叶，空气被吸入液体，混合效果反而下降（`#L7734`）。

挡板把回转的切向流改变为径向与轴向流，作用有三：消除漩涡改善主体循环；增大湍动程度；降低搅拌载荷波动使功率稳定（`#L7734`）。

## 通用尺寸

| 参数 | 取值 |
|:---|:---|
| 挡板宽度 $W_b$ | $(1/12\sim1/10)D$ |
| 数量 $Z_b$，$D\le1000$ mm | 2~4 块 |
| 数量 $Z_b$，$D>1000$ mm | 4~6 块 |

达到上述组合即满足**全挡板条件**——再加宽加多，功率不再增加（`#L7736`、`#L7778`）。

## 间隙 $S_b$（表8-1）

| 黏度 | 处理 |
|:---|:---|
| $\mu<100$ mPa·s（低黏） | $S_b=0$，贴壁 |
| $100\sim2500$ mPa·s（中黏）或固-液两相 | $S_b>0$，按搅拌器型式（下表） |
| $\mu>2500$ mPa·s（高黏） | 倾斜固定，倾向与液流同向，避免死角 |
| $\mu\ge5000$ mPa·s | **一般不设挡板**（挡板反而干扰流动、降低效果） |

（`#L7782-#L7795`）

| 搅拌器型式 | $S_b$ |
|:---|:---|
| 桨式 | $(0.2\sim0.5)W_b$（标准值 $0.2W_b$） |
| 锚式、框式（平底） | $0.0275D$ |
| 锚式、框式（圆弧底） | $0.06D$ |
| 开式、圆盘涡轮式 | $(0.2\sim0.5)W_b$（标准值 $0.2W_b$） |
| 推进式 | $0$（无间隙） |

（`#L7784-#L7791`）

## 上下缘位置

- 上缘一般与液面齐平；液面有轻质易浮、不易润湿的固体时，上缘低于液面 100~150 mm，故意留漩涡把固体卷下去润湿（`#L7799`）。
- 下缘一般与下封头切线齐平；若希望较重物料沉降分离，下缘要高于搅拌器，让釜底维持水平回转流（`#L7803`）。

## 与其他内件的配合

| 情形 | 挡板宽度 |
|:---|:---|
| 无盘管 | 标准宽度 $W_b$ |
| 单层盘管（挡板装在盘管内侧） | 标准挡板的 50% |
| 双层盘管 | 25% |
| 三层及以上盘管 | 不装 |
| 竖式蛇管 | 本身能起挡板作用（不及挡板有效），可不装 |

（`#L7746-#L7748`）

## 判断

挡板宽度随黏度减小不是"优化"而是"必需"：黏度到 10 Pa·s 时挡板已无意义，≥5 Pa·s 就该拆掉。工程上最常见的错误是**高黏体系照抄低黏的 4 块 D/12 挡板**——结果既没消除死角，又把循环流堵死。

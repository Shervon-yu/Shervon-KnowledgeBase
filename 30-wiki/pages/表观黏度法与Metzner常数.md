# 表观黏度法与Metzner常数

## 思路

釜内各点切变速率不同，表观黏度也不同。Metzner 等人的设想：用**同一套搅拌器-釜体系**搅拌牛顿流体，当所耗功率与搅拌该假塑性流体相同时，这个牛顿流体的黏度就定义为该假塑性流体的表观黏度 $\mu_a$——于是可以直接套用牛顿流体的 $N_p$–$Re$ 曲线（`#L1764`）。

## 三个基本关系

平均切变速率与转速成正比（`#L1766`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dot{\gamma}_{\mathrm{av}}=k_{s}N$ | （2-42） |
| **文字式** | $\text{平均切应变速率}_{\text{【1/s】}}=\text{梅茨纳常数}\times\text{搅拌转速}_{\text{【1/s】}}$ |  |

幂律流体的表观黏度与表观雷诺数（`#L1772-#L1776`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\mu_{a}=K_{\mathrm{psn}}\left(k_{s}N\right)^{n-1}$ | （2-43） |
| **文字式** | $\text{表观黏度}_{\text{【Pa·s】}}=\text{稠度系数}_{\text{【Pa·s}^n\text{】}}\times\left(\text{梅茨纳常数}\times\text{转速}_{\text{【1/s】}}\right)^{n-1}$ |  |

|  |  |  |
|:---|:---:|---:|
| **符号式** | $Re^{*}=\dfrac{d^{2}N^{2-n}\rho\,k_{s}^{\,n-1}}{K_{\mathrm{psn}}}$ | （2-44） |
| **文字式** | $\text{表观雷诺数}=\dfrac{\left(\text{叶轮直径}_{\text{【m】}}\right)^{2}\times\left(\text{转速}_{\text{【1/s】}}\right)^{2-n}\times\text{密度}_{\text{【kg/m³】}}\times\left(\text{梅茨纳常数}\right)^{n-1}}{\text{稠度系数}_{\text{【Pa·s}^n\text{】}}}$ |  |

功率式（`#L1780`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $P=K_{p}N^{n+1}d^{3}K_{\mathrm{psn}}k_{s}^{\,n-1}$ | （2-45） |
| **文字式** | $\text{搅拌功率}_{\text{【W】}}=\text{功率常数}K_{p}\times\left(\text{转速}_{\text{【1/s】}}\right)^{n+1}\times\left(\text{叶轮直径}_{\text{【m】}}\right)^{3}\times\text{稠度系数}_{\text{【Pa·s}^n\text{】}}\times\left(\text{梅茨纳常数}\right)^{n-1}$ |  |

## 计算步骤

1. 由式（2-42）算 $\dot{\gamma}_{\mathrm{av}}$，$k_s$ 查表2-8（Metzner 常数，`#L1804-#L1857`）或实测；
2. 在流变曲线上由 $\dot{\gamma}_{\mathrm{av}}$ 读出 $\mu_a$（也可用式2-43算），再算非牛顿雷诺数 $Re_n=k_s^{\,n-1}Re^{*}$（`#L1786`）；
3. 用牛顿流体 $N_p$–$Re$ 曲线或关联式，按 $Re_n$ 查 $N_p$（`#L1788`）；
4. 按功率式算 $P$（`#L1802`）。

## $k_s$ 的取值（表2-8 摘要）

| 搅拌器 | $d/D$ | $k_s$ | 研究者 |
|:---|:---:|:---:|:---|
| 六叶盘式涡轮（单/双层，有无挡板） | 0.285~0.98 | 11.5±1.5 | Metzner |
| 45° 六叶扇形涡轮 | 0.333~0.75 | 13±2 | Metzner |
| 三叶推进式 | 0.21~0.71 | 10±0.9 | Metzner |
| 平桨式（2/3/6 叶） | — | 10.5 | Nagata |
| 弯曲叶桨 | — | 7.1 | Taniyama |
| 锚式 | 0.95 | 25 | Nagata |
| 双螺带式 | 0.95 | 30.0 | Nagata |
| 螺杆-导流筒式 | 0.574 | 8.2 | 王凯等 |

锚式、斜锚式的 $k_s$ 常写成 $k_s=a(1-n)$ 形式，$a$ 与 $d/D$ 有关（`#L1816-#L1818`）；这意味着**$k_s$ 随流变指数 n 变化**，不能当纯几何常数。

## 原书 §1.6：Metzner 原始步骤与偏离

Metzner 法（`#L2380`、`#L2390`、`#L2400`）：

1. 先做出**牛顿流体**的 $N_{\mathrm{p}}$–$Re$ 曲线；
2. 同一叶轮、同一转速下测拟塑性液体的功率，得 $N_{\mathrm{p}1}$；
3. 在牛顿曲线上反查对应的 $Re'_{1}$；
4. 反算表观黏度 $\mu_{a}=d^{2}n\rho/Re'_{1}$（1.98）；
5. 由实测流动曲线（图1.51b）在 $\dot{\gamma}_{av}=Kn$ 处读出 $\mu_{a}$，最后按 $N_{\mathrm{p}}=\beta_{\mathrm{N}}\left(Re'\right)^{-1}$（1.100）算功率。

拟塑性流动曲线与表观黏度（`#L2364`、`#L2372`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\tau=k\dot{\gamma}^{m}\ (m<1),\qquad \mu_{a}=k\dot{\gamma}^{m-1}$ | （1.95）（1.97） |
| **文字式** | $\text{剪应力}_{\text{【Pa】}}=\text{稠度系数}_{\text{【Pa·s}^m\text{】}}\times\text{剪切率}_{\text{【1/s】}}^{m}\ (m<1),\qquad \text{表观黏度}_{\text{【Pa·s】}}=\text{稠度系数}_{\text{【Pa·s}^m\text{】}}\times\text{剪切率}_{\text{【1/s】}}^{m-1}$ |  |

$K$ 的实测值（表1.10，`#L2416`）：螺带 30.0、锚式 25.0、桨式 10.5、六叶涡轮 11.83、弯叶桨 7.1、Brumargine 式 10.5、推进式 10.0；其他作者在涡轮上给 10.0~13.0。本作者取 **$K=11.83$** 作通用值（`#L2434`）。

试验介质（表1.11，`#L2448`）：CMC 水溶液（0.3~6.2%，$m=1.00\sim0.270$，$k=0.01\sim690$）、PVAL 水溶液（10~15%，$m=0.71\sim0.57$）、PVAC 甲苯溶液（30~35%，$m=0.72\sim0.64$）。只有 CMC 的 WS-C、HESS 两牌号在 $8\sim1000$ s⁻¹ 全段服从幂律，其余**只在高剪切段服从**——这正是 Metzner 法在高剪切工况好用的原因（`#L2462`）。

螺带式叶轮的牛顿功率常数另有专用式（间隙比与螺距修正，`#L2444`）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\beta_{\mathrm{N}}=74.3\left\{\dfrac{D-d}{d}\right\}^{-0.5}\left(\dfrac{d}{s}\right)^{0.5}$ | （1.102） |
| **文字式** | $\text{牛顿功率常数}=74.3\times\left\{\dfrac{\text{釜内径}_{\text{【m】}}-\text{叶轮直径}_{\text{【m】}}}{\text{叶轮直径}_{\text{【m】}}}\right\}^{-0.5}\times\left(\dfrac{\text{叶轮直径}_{\text{【m】}}}{\text{螺距}_{\text{【m】}}}\right)^{0.5}$ |  |

**偏离与失效**（`#L2468`、`#L2472`、`#L2478`）：

- 螺带式 $N_{\mathrm{p}}$–$Re'$ 曲线从层流到湍流都与牛顿曲线重合（`#L2436`）——因为全釜流型不变。
- 六叶 Rushton 涡轮的过渡区曲线**低于**牛顿曲线，最低功率点与宾汉塑性液的**恰好相等**：$N_{\mathrm{p,min}}$ 附近叶轮开始出现输出流，转矩回升，最终趋近牛顿曲线。
- Midler 指出式(1.99) 严格只在层流区成立；把它外推到过渡区必然造成偏离，无挡板时更明显。
- 螺带式的混合时间与黏度无关：$n\theta=$ 常数（1.101，`#L2440`），这是它全釜流型单一的又一证据（混合时间见 [[混合时间与混合准数]]）。

## 什么时候能用

- 涡轮、桨式、推进式在层流区，用式（2-43）算表观黏度后，$N_p$–$Re$ 曲线与牛顿流体**重合**（`#L1782`）。
- 过渡流区：低黏流体用叶轮（$d/D=0.3\sim0.6$）的 $N_p$–$Re^{*}$ 曲线**低于**牛顿曲线，不重合；高黏流体用叶轮（锚、螺带、螺杆等）仍重合，可用表观黏度法（`#L1943`）。
- 过渡区也可用二次曲线近似（`#L1945`）：$\ln N_p=A_1+A_2\ln Re^{*}+A_3(\ln Re^{*})^{2}$（式2-52），$A_1,A_2,A_3$ 见表2-10。

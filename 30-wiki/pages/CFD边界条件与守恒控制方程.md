# CFD边界条件与守恒控制方程

## 边界条件决定特解（§2.9）

同一套 N-S/欧拉方程可以描述波音 747 绕流、风洞流动或风车绕流，差别全在边界条件（#L1872）。所以"任何流动控制方程的数值解，必须从数值上令人信服地反映给定的边界条件"（#L1876）。

### 粘性流动的物面条件

|  |  |  |
|:---|:---:|---:|
| **符号式** | $u=v=w=0\quad\text{在物面}$ | （2-87） |
| **文字式** | $\text{速度}_x=\text{速度}_y=\text{速度}_z=0\quad\text{在物面}$ |  |

温度条件三选一（#L1884-1898）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $T=T_{\mathrm{w}}$；$\left(\dfrac{\partial T}{\partial n}\right)_{\mathrm{w}}=-\dfrac{\dot{q}_{\mathrm{w}}}{k}$；$\left(\dfrac{\partial T}{\partial n}\right)_{\mathrm{w}}=0$ | （2-88～2-91） |
| **文字式** | $\text{温度}=\text{壁面温度}$；$\text{壁面法向温度梯度}=-\dfrac{\text{传给物面的热流}}{\text{导热系数}}$；$\text{壁面法向温度梯度}=0$（绝热壁） |  |

- 壁面只能给速度与温度条件；物面压力、密度等是解的一部分（#L1910）。$T_{\mathrm{w}}$ 已知时，壁面温度梯度与热流成为解的一部分；绝热壁时绝热壁温 $T_{\mathrm{aw}}$ 成为解的一部分（#L1904）。
- 书里承认一般的热-结构耦合边界（2-90）至今难以建立，多数粘性计算取定壁温或绝热壁（#L1902）。

### 无粘流动与外部边界

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\boldsymbol{V}\cdot\boldsymbol{n}=0\quad\text{在物面}$ | （2-92） |
| **文字式** | $\text{速度}\cdot\text{物面单位法向量}=0\quad\text{在物面}$ |  |

无粘物面只有不可穿透条件，速度大小、温度、压力、密度都是解的一部分（#L1918）。管道要给出入口/出口条件；外流问题在远场给自由来流条件（#L1920）。此外还有"数值边界条件"这一层：物理边界条件正确，不代表离散实现正确（#L1922）。

## 强守恒与弱守恒（§2.10）

把 N-S 方程写成向量形式（式 2-93，＃L1950）：

|  |  |  |
|:---|:---:|---:|
| **符号式** | $\dfrac{\partial U}{\partial t}+\dfrac{\partial F}{\partial x}+\dfrac{\partial G}{\partial y}+\dfrac{\partial H}{\partial z}=J$ | （2-93） |
| **文字式** | $\dfrac{\partial\text{守恒变量向量}}{\partial\text{时间}}+\dfrac{\partial\text{通量}_x}{\partial x}+\dfrac{\partial\text{通量}_y}{\partial y}+\dfrac{\partial\text{通量}_z}{\partial z}=\text{源项向量}$ |  |

守恒变量 $U=\{\rho,\rho u,\rho v,\rho w,\rho(e+V^2/2)\}^{\mathrm{T}}$（式 2-94，＃L1954），通量 $F,G,H$ 与源项 $J$ 见式 2-95～2-97（＃L1956-1962）。所有量都写进导数里、没有流动变量单独留在导数外，这种写法叫**强守恒形式**（#L2042）；而（2-56a～c）、（2-81）右端直接出现一堆导数项，叫**弱守恒形式**（#L2042）。

- 原始变量可由守恒变量反解：$u=\rho u/\rho$、$e=\rho(e+V^2/2)/\rho-(u^2+v^2+w^2)/2$（式 2-100～2-104，＃L1980-1988）。
- 无粘时删去粘性通量，得欧拉方程的向量形式（式 2-105～2-109，＃L1994-2006）。
- 高雷诺数下保留法向粘性项、丢弃流向粘性项，得**薄层 N-S 方程**（式 2-110，＃L2012）。

## 为什么激波捕捉必须用守恒形式

两种处理激波的方法（#L2044-2054）：激波捕捉法让激波作为解的一部分自然出现；激波装配法把激波当间断、用兰金-许贡钮关系式匹配波前波后。

经验结论：**激波捕捉法应当使用守恒形式**——用非守恒形式时，激波上下游会出现空间振荡（抖动），激波位置可能错，甚至发散；激波装配法则两种形式都能得到满意结果（#L2068）。

原因（#L2074-2088）：跨正激波时，原始变量 $p$、$\rho$、$u$ 都不连续，但通量组合 $p+\rho u^2$ 连续（式 2-113、2-114，＃L2082-2086）。守恒形式以通量为未知量，跨激波不出现该量的间断；非守恒形式以原始变量为未知量，间断直接进入离散。

## 适用边界

- 边界条件必须与方程类型匹配：亚声速入口给 3 个条件、出口给 1 个，超声速入口全给——给错会导致不适定（§3.5，见 [[拟线性偏微分方程的分类]]）。
- 强守恒形式在一般曲线坐标下仍可保持（式 5-47，＃L4152），但通量里要带雅可比行列式。
- 薄层近似只在附面层很薄、流向粘性项可忽略时成立（#L2012 附近）。

## 判断

边界条件不是"设置项"，而是问题定义的一部分：给错了，方程还是那套方程，解却不再是你要的流动。守恒形式的必要性则只在有间断时才尖锐——光滑流动用非守恒形式也能算，但一旦捕捉激波，守恒形式就成了正确性的前提，这也是第 7、8、10、11 章反复强调同一点的原因。
